CargoVerse 的源码、构建配置、问题反馈与版本发布统一由主仓库管理。

## 文档组织

```text
docs/
├─ 01货柜系统/
├─ 02贸易点系统/
├─ 03功能方块/
├─ 04商店系统/
├─ 05兼容/
└─ 06开发与运维/
```

- “实现文档”描述当前代码与数据格式。
- “内容设计”及“设计草案”用于记录规划，不代表内容已经实现。
- 实现文档与旧示例冲突时，以当前主仓库代码和最新实现文档为准。

## 维护约定

- 使用 UTF-8 编写 Markdown。
- 使用仓库相对链接连接同一文档仓库内的页面。
- 数据字段、命令或运行逻辑变化时，应与主仓库代码变更同步更新。
- 不在文档中记录本机绝对路径、用户名、测试存档或私有整合包目录。
- 二进制贴图、模型和结构源文件不放入本仓库。

## 项目状态

CargoVerse 仍处于开发阶段，目前只维护当前数据格式，不承诺兼容早期开发版本中已经废弃的字段。
