# CargoVerse 文档

本仓库保存 CargoVerse NeoForge 1.21.1 的当前实现文档，包括数据格式、运行规则、功能方块、世界表面 UI、内容制作与服务器维护。

源码、构建配置、问题反馈与版本发布位于 [CargoVerse-NeoForge-1.21.1](https://github.com/xiaobaiYWX/CargoVerse-NeoForge-1.21.1)。

货物已切换为实际物品与固定数量运输损耗；玩家贸易点手动注册管理核心，默认每位玩家最多 3 个，再沿物流隧道激活设备，默认最短路径 32 格。隧道已接入平面组合及固定轴斜通模型，斜通本体不能转弯或分支，两端节点可直接转弯或分支，不直接竖直连接。每核心最多接入 3 个 Create 保险库和 5 个普通储罐，物品可交易、流体当前只读。仓库终端提供管理装卸及所有者专用 SET。完整方案与状态见[物流网络设计与实施清单](docs/设计草案/玩家贸易点物流网络设计与实施清单.md)。40 张正式自然站货物表待填充，A／B 测试站已覆盖 149 种实际物品；当前实现与待验收项见[当前工程边界](<docs/00一级系统总览/02_货物与贸易工程边界.md>)。旧抽象货物和自有仓库不提供存档迁移。

当前 2312 份逐物品属性直接维护质量、形态、准入、运输条件和贴花；物品悬停不再显示分类，只在佩戴护目镜时补充必要的装载限制和需求。下一阶段从[专项总入口](<docs/设计草案/运输专项推进边界.md>)分别确认[液体运输](<docs/设计草案/液体运输首版设计.md>)和[生物运输](<docs/设计草案/生物运输首版设计.md>)，尚未开放相应载荷或制造能力。

当前导航支持航运手册个人目标与航行引导台独立地图：共用探索资料，目标互不覆盖。引导台空手右键打开地图、手持手册右键复制目标、潜行右键配置 PID；详见[航行引导台](docs/13载具仪表/01_航行引导台与PID控制.md)。

载具圆盘仪表采用空基座安装模块的方式，最多四个且允许重复；气压计使用独立圆盘模块，质量与最大静态升力仍使用翻牌方块。详见[模块化载具仪表](docs/09世界表面UI系统/04_载具仪表方块.md)。

航图台现为独立单方块原版地图桌，可放入、旋转、取回一张已绘制地图；不再拼接或展示三维地形／载具模型。详见[航图台与原版地图](docs/13载具仪表/02_航图台与原版地图.md)。

货柜轨道采用逐格直轨，支持任意激活轨格捕获滑车，并可在末端放置完整碰撞的止冲器；旧节点／虚拟区间系统已移除。详见[货柜轨道系统](docs/03功能方块/08_货柜轨道系统概览.md)。
