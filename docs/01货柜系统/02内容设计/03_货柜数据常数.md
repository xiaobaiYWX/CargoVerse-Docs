## CargoType 基础经济常数表

实现文件位于 `data/cargoverse/cargo_value_constants/default.json`。本页是平衡方案草案；正式生效数值以该 JSON 为准。货柜定义保留五项可选微调倍率，最终值按“货物类型基础值 × 货柜等级倍率 × 模板微调倍率”计算。

每个 `cargo_level_constant` 还必须定义非负整数 `cargo_units`，表示该规格货柜承载的基础货物单位数。货柜定义可在各 CargoType 下使用 `cargo_units_modifier` 修正该值，默认 `1.0`；最终值为 `round(等级 cargo_units × cargo_units_modifier)`。当前 S/M/L/X/XL/SP 基础值分别为 10/20/40/80/160/10。

## CargoType 默认词条

CargoType 的初始词条及参数统一由 `cargo_value_constants/default.json` 的 `cargo_type_affixes` 维护。货柜定义不得在 `cargo_type.<type>` 内填写 `affixes`，只允许在根节点使用 `blocked_affixes` 屏蔽该货柜能够消除的风险。

```text
最终词条 = CargoType 默认词条 - 货柜 blocked_affixes
```

| CargoType | 默认词条 ID |
| --- | --- |
| `agriculture` | `time_limit` |
| `livestock` | `height_limit` |
| `ore` | 无 |

| `stone` | 无 |
| `fuel_resource` | `flammable`、`radioactive`、`cold_proof` |
| `textile` | 无 |
| `security` | 无 |
| `component` | `fragile` |
| `machinery` | `keep_upright`、`fragile` |

### 价格单位说明

假设：

- 货币：遗留资源单位（当前测试可使用绿宝石）
- S级货柜为基础单位
- M~XL根据货柜等级倍率成长

货柜等级倍率：

|等级|价格倍率|经验倍率|
|---|---|---|
|S|1.0|1.0|
|M|2.2|1.8|
|L|4.5|3.5|
|X|8.5|6.0|
|XL|15|10|
