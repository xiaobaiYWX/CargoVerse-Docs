# 天穹联合工业

## Aether Union Industries

**缩写：AUI**

> 天穹联合工业是现今最大的综合工业制造商之一，致力于恢复前文明时代的标准化生产体系。其产品遍布各个聚落与贸易网络，从基础货柜到大型工业模块，AUI 制定了现代天空运输的大部分通用标准。

## 定位

> 最大规模的通用工业制造商。

参考形象：

- 星域大型船厂；
- 现代波音、空客；
- EVE 中的通用工业集团。

## 视觉风格

- 灰白金属；
- 标准化；
- 工程感；
- 大量编号标识。
