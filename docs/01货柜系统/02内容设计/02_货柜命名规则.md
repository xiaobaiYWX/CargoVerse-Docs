# 命名框架
```
[MFG]-[MODEL]-[INTERFACE]-[SIZE]-[OPTION]
```

## 第三段：货柜接口类型 [INTERFACE]

Cargo Interface Standard（CIS）
货柜接口标准。

| 代码  | 英文                | 中文   | 物理方式 | 说明                                                      |
| --- | ----------------- | ---- | ---- | ------------------------------------------------------- |
| LC  | Loose Cargo       | 散装承载 | 物理托盘 | - 无主动锁定；<br>- 靠摩擦和物理碰撞保持；<br>- 需要运输载具提供货斗；<br>- 适合低速运输。 |
| LM  | Lashing Mount     | 绑扎固定 | 绳索   | 货柜自身提供：<br>- 吊环<br><br>玩家需要：<br>- 绳索<br>- 固定装置          |
| SD  | Standard Docking  | 标准对接 | 锁定器  | 货柜具有：<br>- 结构接口<br><br>玩家需要：<br>- 货柜对接器                 |
| SM  | Specialized Mount | 专用接口 | 特殊设备 | 特殊安装接口。<br><br>用于：<br>不是标准货柜的东西。                        |

## 第四段：货柜等级[SIZE]

许可等级，同时代表货柜综合规格：

| 代码  | 英文          | 说明   | 对应体积(含)    |
| --- | ----------- | ---- | ---------- |
| S   | Small       | 小号   | 0≤128      |
| M   | Medium      | 中号   | 129≤256    |
| L   | Large       | 大号   | 257≤512    |
| X   | Extra       | 特大   | 513≤1024   |
| XL  | Extra Large | 超规格  | 1025+      |
| SP  | Special     | 特殊规格 | 特种货物不按体积计算 |

---
## 第五段：特殊后缀[OPTION]

用于特殊版本，所有特殊版本应该在有初始版本的情况下才能被继续定义。注意，这里需要手动调整相应的词条和数值，此项仅用于定义命名规则。

此后缀最多仅允许有一个，工业产品不会无限叠加改装。

| 代码  | 英文                 | 中文    | 说明                            |
| --- | ------------------ | ----- | ----------------------------- |
| R   | Reinforced         | 结构加强  | 初始完整性更高，但通常更重也更贵。             |
| A   | Armored            | 装甲加强  | 受到撞击后完整性降低更少，但通常更重也更贵。        |
| W   | Waterproof         | 防水    | 不应该再有“防潮”词条，但造价更高。            |
| TP  | Thermal Protection | 热环境防护 | 不应该再有“防寒”词条，但应该添加“限时”词条，造价更高。 |
| L   | Lightweight        | 轻量化   | 更容易受到撞击影响且初始完整度更低，但通常更轻更便宜。   |
