# 深岩矿业集团

## Deepcore Mining Corporation

**缩写：DMC**

> 深岩矿业集团专注于矿产资源开发与重型运输设备制造。面对极端环境与高强度工业需求，DMC 制造的货柜通常采用强化结构设计，是矿区、采掘站以及大型工程项目中的主要运输设备。

## 定位

> 矿业和资源运输企业。

## 视觉风格

- 黑色；
- 黄色警示；
- 粗犷装甲。
