# 遗民贸易协会

## Remnant Exchange

**缩写：REX**

> 遗民贸易协会并非传统意义上的制造企业，而是由探险者、收藏家以及遗迹回收商组成的松散贸易网络。他们交易来自旧时代的设备、未知材料以及无法归类的特殊货物。

## 定位

> 玩家后期接触的综合贸易组织。

遗民贸易协会主要经营：

- 二手货柜；
- 改装货柜；
- 前文明兼容设备。

## 视觉风格

- 混杂；
- 拼接；
- 不统一。
