# 云港物流集团

## Skyport Logistics

**缩写：SPL**

> 云港物流集团起源于早期飞艇运输商联盟，如今负责连接分散于天空各处的贸易网络。其设计理念强调快速周转与低维护成本，是小型聚落与远距离贸易中最常见的物流设备供应商。

## 定位

> 专业运输公司。

参考形象：

- 亚马逊物流；
- 星际快递公司。

## 视觉风格

- 橙白配色；
- 明亮警示条；
- 快速识别设计。
