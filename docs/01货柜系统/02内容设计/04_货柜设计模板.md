# 货柜设计模板

> 预留：这是内容设计填写模板，不是已注册型号。字段依据已实现的[容器定义](../01核心系统/02_货柜定义系统.md)；填写并创建实际 JSON 后才能验收。

一份文档记录一个系列，可复制下方规格章节。保留背景、美术和接口命名信息，但不得重新添加接口数据字段，也不按货物类型拼装完整商品模板。

## 系列信息

| 项目 | 待填写 |
| --- | --- |
| 制造商 ID | 已定义的完整制造商 ID |
| 系列名／定位 | 产品定位、使用场景 |
| 显示命名 | 可参考[命名规则](02_货柜命名规则.md) |
| 接口展示名 | 仅写展示文案／结构设计，不解析为容器参数 |
| 规格 | S/M/L/X/XL；SP 按特别订单单独记录 |
| 实现状态 | 预留／已实现／待验收，并附实际资源路径 |

## 每个规格独立填写

| JSON 字段 | 内容要求 |
| --- | --- |
| schema_version | 1 |
| template | 结构模板 ID |
| manufacturer | 制造商 ID |
| display_name | 直接显示字符串 |
| description | 直接描述字符串，可写名称、系列与接口文案 |
| size_class | 本型号规格 |
| trade_currency | 已定义的货币组 ID |
| dispatch_points | 玩家拥有该货柜时占用的调度点数 |
| capacity | 基础容量，t |
| empty_mass | 空柜基础质量 |
| max_durability | 设备耐久，不是货物完整度 |
| allowed_cargo_classes | 固定 CargoClass ID 数组 |
| special_designs | 可移除的运输词条 ID |
| design_defects | 装载时附加给货物的运输要求 |
| tags | 型号标签 |

附：容器定义 ID、JSON 路径、模型预览图、模板尺寸、质量占位块数量、结构实际质量和运输空间。

制造币种和价格不要写进本模板的货柜定义参数；为该型号建立制造选项时，在贸易点的货柜制造台定义中填写 `currency_cost.currency` 与 `currency_cost.amount`。

## 兼容货物核对

| CargoClass ID | 覆盖的大类 | 基础容量 | 已有货物的厂商修正 | 最终运输要求 | 说明 |
| --- | --- | ---: | ---: | --- | --- |
| 待填写 | 该类下全部 CargoGood | 待填写 | 可按具体 CargoGood 修正容量 | 根据实际货物、防护、缺陷解析 | 大类决定装载许可，不合并货物身份 |

货物的质量、价值、币种、科技、标签和运输要求应维护在 CargoGood 中，本表只引用，不另建一套单位参数。最终数值见[计算规则](../01核心系统/06_货柜数值与词条常量.md)。

## 待验收

- [ ] 容器／厂商／货物／货币引用有效，JSON 无注释。
- [ ] 容器显示名称与描述不是多语言 key，没有接口数据字段。
- [ ] 结构符合作业空间和[制作规范](05_货柜结构制作规范.md)。
- [ ] 空柜制造、兼容装载、非兼容拒绝、部分卸货及卸空可用。
- [ ] 目标质量、实物质量、贴花和存档重进结果已检查。
- [ ] 重载补装与重复词条未依赖尚未完成的保证。

既有系列文档的旧整柜数值仅用于历史平衡参考；不能直接复制为新 JSON。
