# 密封等级

货柜能力 ID：`cargoverse:sealing`。影响：[有效密封等级](../04货柜核心数值/02_有效密封等级.md)、[内部气压](../04货柜核心数值/04_内部气压.md)、[内部湿度](../04货柜核心数值/05_内部湿度.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:sealing": {
    "level": 2
  }
}
```

整数 `level` 为 0～2；0 未密封，1 液密，2 气密。

## 对核心数值的作用

等级控制压湿内外平衡阀门，气密仍有有限交换，压差不触发自动泄压。液体柜必须显式配置至少液密 1；能力不自动生成易挥发需求。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。
