# 围护等级

货柜能力 ID：`cargoverse:containment`。影响：[有效围护等级](../04货柜核心数值/01_有效围护等级.md)、[内部温度](../04货柜核心数值/03_内部温度.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:containment": {
    "level": 2
  }
}
```

整数 `level` 为 0～2，0 表示无该项能力。一级覆盖碎料，二级覆盖粉料并覆盖一级。

## 对核心数值的作用

提供直接围护并小幅减慢被动换热，倍率见内部温度。不能因围护高就假定液密、气密、缓冲或主动制冷。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。

## 图标

GUI 一级图案区域为 `(1, 36, 27, 25)`，图集为 252×254 的 `textures/gui/transport/icons.png`。二、三级分别将 v 增加 64／128，只读取本能力支持的等级。 能力不注册世界警示贴花；遮光、照明、朝向保持只用一级图案，围护和密封最高二级。
