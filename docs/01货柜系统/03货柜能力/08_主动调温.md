# 主动调温

货柜能力 ID：`cargoverse:thermal_control`。影响：[内部温度](../04货柜核心数值/03_内部温度.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:thermal_control": {
    "level": 2,
    "supported_modes": [
      "cooling",
      "heating"
    ],
    "target_min": -20,
    "target_max": 80,
    "rate_per_second": 0.3
  }
}
```

`supported_modes` 可含 `cooling`／`heating`，至少一项且不可重复；目标为有限 TU，范围不得倒置；`rate_per_second` 为正数 TU／秒。可选整数 `level` 1～3，默认 1。

## 对核心数值的作用

主动调节直接给内部温度恒定变化量，和被动阀门不同。推荐目标来自货物，未推荐只做最小必要调节；仅有老化曲线不擅自无限制冷。旧调温 0／1／2／3 的速度为 0／0.1／0.3／0.6 TU／秒，非零旧档位仍需根级 thermal_control。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。
