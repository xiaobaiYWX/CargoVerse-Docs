# 压力调节

货柜能力 ID：`cargoverse:pressure_control`。影响：[内部气压](../04货柜核心数值/04_内部气压.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:pressure_control": {
    "level": 1,
    "supported_modes": [
      "pressurizing",
      "depressurizing"
    ],
    "target_min": 0,
    "target_max": 2,
    "rate_per_second": 0.1
  }
}
```

`supported_modes` 可含 `pressurizing`／`depressurizing`，至少一项且不可重复。`target_min`／`target_max` 为非负相对压力且顺序合法，`rate_per_second` 为正数压力系数／秒。可选整数 `level` 1～3，默认 1。

## 对核心数值的作用

按货物合法范围或推荐目标恒定增压／减压，受本设备声明的目标范围与速率限制。被动泄漏与主动输出共同推进；输出不足时保持实际结果，不能强行达标。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。
