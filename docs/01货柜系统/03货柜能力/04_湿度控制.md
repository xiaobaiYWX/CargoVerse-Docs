# 湿度控制

货柜能力 ID：`cargoverse:humidity_control`。影响：[内部湿度](../04货柜核心数值/05_内部湿度.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:humidity_control": {
    "level": 1,
    "supported_modes": [
      "dehumidifying"
    ],
    "target_min": 0,
    "target_max": 100,
    "rate_per_second": 1
  }
}
```

`supported_modes` 可含 `dehumidifying`／`humidifying`，至少一项且不可重复。目标范围在 0～100，`rate_per_second` 为正数湿度指数／秒。可选整数 `level` 1～3，默认 1。

## 对核心数值的作用

主动控湿直接给内部湿度恒定增减量，不通过加热／制冷隐式推算湿度。入水只提高外部湿度，密封和烘干仍能共同起作用。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。
