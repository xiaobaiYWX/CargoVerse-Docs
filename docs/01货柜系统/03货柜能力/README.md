# 货柜能力

能力写在货柜定义的 `abilities`，决定配备及物理响应；不把能力名称当货物条件，不直接授予免损。参数只在逐项页面维护。

| --- | --- | --- |

| [密封等级](02_密封等级.md) | `cargoverse:sealing` | [有效密封等级](../04货柜核心数值/02_有效密封等级.md)、[内部气压](../04货柜核心数值/04_内部气压.md)、[内部湿度](../04货柜核心数值/05_内部湿度.md) |
| [压力调节](03_压力调节.md) | `cargoverse:pressure_control` | [内部气压](../04货柜核心数值/04_内部气压.md) |

10 种能力已注册并接入求值；具体型号是否配备以实际定义为准。可选等级与实际响应分别配置，不根据图案自动增加强度。主动设备按需求自动，现有 PDA 提供详细查看，不另列复杂操作界面待办。能力不注册贴花。
