# 真空隔层

货柜能力 ID：`cargoverse:vacuum_insulation`。影响：[内部温度](../04货柜核心数值/03_内部温度.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:vacuum_insulation": {
    "level": 1,
    "exchange_time_seconds": 120
  }
}
```

`exchange_time_seconds` 为有限正数时间常数（游戏秒），可选整数 `level` 1～3，默认 1。

## 对核心数值的作用

被动温度阀门取围护基础时间常数与本声明时间常数的较大者。它不是差值减半时间，不与围护乘积叠加；也不抽空货物腔。旧隔热 0／1／2／3 的时间常数为 1200／2400／4800／9600 tick。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。
