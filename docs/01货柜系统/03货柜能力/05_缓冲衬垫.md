# 缓冲衬垫

货柜能力 ID：`cargoverse:cushioning`。影响：[速度变化](../04货柜核心数值/07_速度变化.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:cushioning": {
    "level": 2,
    "velocity_change_bonus": 2
  }
}
```

`velocity_change_bonus` 为有限非负速度增量，单位格／游戏秒。可选整数 `level` 1～3，默认 1。

## 对核心数值的作用

最终易碎耐受＝货物基础耐受＋所填增量。基础 10、增量 2／8 时为 12／18；不缩小读到的速度差、不改 10 tick 采样、不免除倾斜。仍在使用的旧缓冲 0／1／2／3 分别映射增量 0／2／5／8。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。
