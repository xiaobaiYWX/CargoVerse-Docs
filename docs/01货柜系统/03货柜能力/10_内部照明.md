# 内部照明

货柜能力 ID：`cargoverse:internal_lighting`。影响：[内部光照](../04货柜核心数值/06_内部光照.md)。能力描述柜体配备，实际保护由核心数值与货物条件共同判定。

## 声明

以下片段放入货柜定义的 `abilities`；参数是协议示例，正式型号按其产品数据赋值。

```json
{
  "cargoverse:internal_lighting": {
    "level": 1,
    "max_light": 12
  }
}
```

整数 `max_light` 为 0～15；只支持 `level:1`，可不填等级。

## 对核心数值的作用

自动时仅补足当前货物最低光照需求，上限由 max_light 限制。不能压暗外光，不做逐 tick 渐亮，也不把壳体遮光重复施加到灯具输出。

数值响应直接采用所填参数。等级用于能力身份和图案，不从等级推导速度／时间／强度，也不按连续参数反推等级。未声明表示未配备；数值零是否允许按本项参数约束判断。

主动能力初次按需自动，没有对应需求时待机；已有关闭选择保留。设置与实际内部状态分开，不能从“配备／开启”推断已经满足货物要求。现有 PDA 用于详细查看，本轮不扩展设备操作界面，见[生命周期](../01核心系统/16_运输观测与生命周期.md#自动设备与查看)。

## 图标

GUI 一级图案区域为 `(160, 2, 28, 29)`，图集为 252×254 的 `textures/gui/transport/icons.png`。二、三级分别将 v 增加 64／128，只读取本能力支持的等级。 能力不注册世界警示贴花；遮光、照明、朝向保持只用一级图案，围护和密封最高二级。
