# 货柜与货物数值边界

本页只列数值归属；公式、参数和数据在对应正式章节维护。

| 数值 | 维护入口 | 边界 |
| --- | --- | --- |
| 原生数量、操作份数、容量换算 | [多类型载荷与计量](12_多类型载荷与计量.md) | pcs／mB 分开，定义容量不等于所有介质的原生量；零质量货物仍占容量 |
| 每组质量与千件载重 | [物品运输质量](11_物品运输质量.md) | 逐物品基础属性决定运输质量，不读取物品放置后的方块质量 |
| 液体质量与尾量 | [液体运输](13_液体运输.md#身份与计量) | 使用完整原生 mB 计算质量；公共交易与管理均可转移不足一份的实际尾量 |
| 实际物理总质量 | [结构制作规范](10_货柜结构制作规范.md#3-质量占位方块) | 不低于结构基线；补充质量经已绑定锚点更新，不逐块向上取整 |
| 柜型能力与货物需求 | [能力](../03货柜能力/README.md)／[条件](../02货物运输条件/README.md) | 二者独立配置，货柜能力不授予其他介质许可；损耗扣原生数量 |
| 核心数值、环境与损耗 | [核心数值](../04货柜核心数值/README.md)／[生命周期](16_运输观测与生命周期.md) | 只结算有效观测，固定原生扣量不超过现有数量，追加不洗运输状态 |
| 价格、经验与库存 | [多类型报价边界](12_多类型载荷与计量.md#报价与显示) | 价格／经验属于站点报价；玩家库存来自 Create 原生仓库，不维护固定 5000 的影子容量 |

不同介质的存储、显示、计价和质量基数分别核对。界面格式化不回写原生数量、质量或取得成本；组大小、尾量和取整统一见[计量边界](12_多类型载荷与计量.md)。
