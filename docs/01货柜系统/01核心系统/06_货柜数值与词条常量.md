# 货柜与实际物品数值

- 货柜容量按实际物品个数计算，不按物品栈，不使用 t 表示数量。
- 兼容许可来自设备的允许分类；分类容量修正不额外授予分类许可。
- 总质量 = 空柜质量 + 实际物品数量 × 冻结的单位质量。
- 当前通用默认单位质量为 0.1 Kpg/个，可在运输配置中覆盖；内置参数为 0～1 的整数或一位小数，零质量仍占容量。
- 2312 份独立属性文件覆盖现有非空气物品；质量由各自 JSON 维护，损耗使用固定整数参数。详见[物品运输配置](<../../10数据包定义与模板/01_物品运输/README.md>)，不表示已完成全部物品平衡。
- 玩家仓库使用 Create 保险库原生槽位容量，不再固定 5000；单价与上架配置不预留容量；保留数量和收购目标已移除。
- 单位买卖价格为非负整数，与仓库容量无关。公共交易按实际转移数量计价，不乘完整度；物品运输数据不包含价格或经验。
- 运输每次损耗固定整数原生数量，不足时最多扣到零。新数值模型分别配置暴露宽限、周期和每次扣量；不再运行旧绝对时限。
- 货柜、制造商、调度点与结构模板的独立定义保留；旧抽象货物的质量、价值、经验和完整度数值表不保留。
