# 货柜定义系统

货柜定义是整个系统的核心数据。一个货柜定义 JSON 对应一种可购买、可出售、可显示信息的货柜。

## 文件位置

```text
data/<namespace>/cargo_definitions/<path>.json
```

示例：

```text
data/cargoverse/cargo_definitions/basic/box_test.json
```

对应货柜定义 ID：

```text
cargoverse:basic/box_test
```

## 基础示例

```json
{
  "template": "cargoverse:cargo/example_small",
  "display_name": "示例货柜",
  "cargo_description": "这里填写自定义货柜描述，可输入较长文本。",
  "cargo_level": "S",
  "currency_id": "minecraft:emerald",
  "max_owned": 1,
  "max_integrity": 100,
  "cargo_type": {
    "agriculture": {
      "weight": 3,
      "mass_modifier": 1.0,
      "price_modifier": 1.0,
      "license_modifier": 1.0,
      "prosperity_modifier": 1.0,
      "affixes": [
        {
          "id": "time_limit",
          "time_tick": 24000
        }
      ]
    },
    "wood": {
      "weight": 1,
      "affixes": []
    }
  },
  "tags": [
    "cargo"
  ]
}
```

## 字段说明

| 字段                       | 类型    | 必填  | 说明                                                       |
| ------------------------ | ----- | --- | -------------------------------------------------------- |
| `template`               | 字符串   | 是   | 货柜结构模板 ID，对应 `data/<namespace>/structure` 下的 `.nbt` 文件。 |
| `display_name`           | 字符串   | 否   | 货柜显示名称。不填时使用定义 ID 路径。                                    |
| `cargo_type`             | 对象    | 是   | 该模板允许生成的货物类型。键为固定 `cargo_type`，值为该类型的权重、经验、预留质量与词条。 |
| `cargo_level`            | 字符串   | 否   | 货柜规格，可填 `S`、`M`、`L`、`X`、`XL` 或 `SP`，默认 `M`。              |
| `currency_id`            | 字符串   | 否   | 交易物品 ID，例如 `minecraft:emerald`。                          |
| `max_owned`              | 整数    | 否   | 单个玩家同时可持有的最大数量，默认 `1`。                                   |
| `max_integrity`          | 整数    | 否   | 最大完整度，默认 `100`。                                          |
| `tags`                   | 字符串数组 | 否   | 维护者自定义标签，目前主要用于分类和后续扩展。                                  |
| `cargo_description`      | 字符串   | 否   | 自定义货柜描述，显示在出售、收购界面；支持 `\n` 手动换行以及 Minecraft 原版 `§` 颜色和样式代码。 |

## 货物类型 cargo_type

`cargo_type` 是模板可用类型对象，不再是单个字符串。开发阶段不读取旧的字符串格式。贸易点生成出售列表时，先按贸易点中的模板权重抽取模板，再从模板与贸易点 `output_resources` 的交集中按类型 `weight` 抽取最终类型。抽取结果会固化到该终端本轮列表，预览、价格、词条、经验、贴花和实际生成均使用同一结果。

每个类型支持：

| 字段                       | 说明                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------- |
| `weight`                 | 该模板在可选类型交集内抽中此类型的相对权重，最小为 `1`。<br>某 cargo_type 的概率<br>= 该类型 weight ÷ 所有候选类型的 weight 总和 |
| `mass_modifier`          | 可选质量微调倍率，默认 `1.0`。                                                                    |
| `price_modifier`         | 可选价格微调倍率，同时作用于基础买入价与基础卖出价，默认 `1.0`。                                                   |
| `license_modifier`       | 可选运输许可经验微调倍率，默认 `1.0`。                                                               |
| `prosperity_modifier`    | 可选贸易点繁荣经验微调倍率，默认 `1.0`。                                                              |
| `affixes`                | 此类型实例使用的词条及内联参数。不同类型可以拥有完全不同的词条组合。[[04_词条与完整度系统]]                                      |

## 货物数值常量

统一数值文件位于：

```text
data/cargoverse/cargo_value_constants/default.json
```

其中：

- `cargo_type_constant`：每个货物类型的 `base_mass`、`base_buy_price`、`base_sell_price`、`license_experience`、`trade_point_experience`。
- `cargo_level_constant`：每个货柜等级的 `price_multiplier`、`license_multiplier`、`prosperity_multiplier`、`mass_multiplier`。
- 等级倍率和货柜定义中的四项微调倍率均可省略，默认 `1.0`。
- 货柜定义内旧的 `mass`、两项基础价格和两项具体经验字段不再读取。

最终值：

```text
最终质量 = 类型 base_mass × 等级 mass_multiplier × 模板 mass_modifier
最终基础买入价 = 类型 base_buy_price × 等级 price_multiplier × 模板 price_modifier
最终基础卖出价 = 类型 base_sell_price × 等级 price_multiplier × 模板 price_modifier
最终许可证经验 = 类型 license_experience × 等级 license_multiplier × 模板 license_modifier
最终繁荣经验 = 类型 trade_point_experience × 等级 prosperity_multiplier × 模板 prosperity_modifier
```

价格和经验采用四舍五入后的受限整数；质量上限为 `1000000`。

| `stone` | 石材 |
| `fuel_resource` | 能源原料 |
| `textile` | 纺织与轻工业品 |

| `machinery` | 机械设备 |
| `electronics` | 电子设备 |

| `construction` | 建筑材料 |

贸易点会使用 `cargo_type` 进行：

- 购买价格修正。
- 收购价格修正。
- 繁荣经验倍率。
- 贸易点输入、产出库存的 CargoType 分项。
- 商店、买入和出售终端的类型图标与交易匹配。

### 最终质量

结构模板使用 `cargoverse:cargo_mass_placeholder` 承担可调质量。生成货柜前，系统先计算模板中非占位方块的实际质量，再将尚需补足的质量平均分配给所有质量占位方块：

```text
待补足质量 = max(0, 计算质量目标 - 非占位方块结构质量)
单个占位方块质量 = ceil(待补足质量 ÷ 占位方块数量)
```

- 多个占位方块平分质量，遇到小数统一向上取整。
- 若计算目标低于模板实际质量，货柜仍正常生成并使用模板实际质量。
- 若模板没有质量占位方块，货柜仍正常生成，但无法补足目标质量，最终使用结构实际质量。
- 分配结果直接写入方块实体，并由 Sable 的方块质量查询读取；不再使用结构八角虚拟质量注入。
- 旧的固定 5–25 kps 压载块及其数据接口已经删除。
## 货柜规格

`cargo_level` 用于显示规格，并从 `cargo_level_constant` 读取：

- 价格倍率；
- 运输许可经验倍率；
- 贸易点繁荣经验倍率；
- 质量倍率；
- `cargo_units`。

`cargo_units` 是贸易点输入、产出库存使用的抽象货物单位，不是货柜质量、方块数量或本地货柜库存。

## 基础繁荣度经验

`trade_point_experience` 来自数值常量文件中的货物类型基础值，再乘等级和模板的繁荣倍率。

实际加入贸易点的繁荣经验还会受到贸易点 `consumed_resources.<cargo_type>.prosperity_experience_modifier` 影响：

```text
实际繁荣经验 =
trade_point_experience × prosperity_experience_modifier
```

只有玩家向贸易点出售货柜时增加繁荣经验。贸易点向玩家出售货柜不获得繁荣经验；未配置倍率时默认 `1.0`。

## 生成原点

货柜结构不再使用货柜定义中的 `offset` 字段。所有货柜定义共用同一套生成原点规则，避免每个 JSON 单独维护偏移值。

生成时系统会将买入终端配置的生成点视为货柜模板的底面中心点，并根据结构模板尺寸自动计算实际放置角点。买入终端仍可配置 X/Y/Z 生成偏移，用于整体移动这个底面中心点，默认偏移为 `(0, 1, 0)`。

制作结构模板时，只需要让模板自身从结构文件的 `(0, 0, 0)` 角点正常保存即可，不需要为了不同尺寸的货柜额外调整 JSON。

## 货柜定义与终端

货柜定义直接由数据包加载。买入终端和出售终端不再拥有各自的定义 ID：买入终端通过 `tradePointId` 读取贸易点定义中的 `cargo_sale`，出售终端只按 `consumed_resources` 检查扫描到的真实货柜实例。

添加新货柜时：

1. 新建货柜定义 JSON。
2. 如需由贸易点出售，在目标贸易点定义的 `cargo_sale.cargo` 中引用该货柜定义 ID；如需被贸易点收购，只需令实例 CargoType 存在于 `consumed_resources`。
3. 确认模板允许类型与贸易点 `output_resources` 或 `consumed_resources` 存在交集。
