# 玩家档案与货柜调度点

玩家档案是服务端数据包中的玩家规则定义。第一版统一使用 `data/cargoverse/player_profiles/default.json`，资源 ID 为 `cargoverse:default`；该定义必须存在且结构完整，否则数据包重载失败。

## 完整结构

```json
{
  "schema_version": 1,
  "display_name": "默认玩家档案",
  "radar_chart": {
    "shipping_count_k": 50.0,
    "earned_amount_k": 5000.0,
    "carrier_time_k_seconds": 21600.0,
    "total_weight_k": 500.0,
    "integrity_score_step": 0.1
  },
  "license": {
    "initial_level": "S",
    "levels": [
      { "level": "S", "required_experience": 0.0 },
      { "level": "M", "required_experience": 120.0 },
      { "level": "L", "required_experience": 420.0 },
      { "level": "X", "required_experience": 900.0 },
      { "level": "XL", "required_experience": 1800.0 }
    ]
  },
  "cargo_container_points": {
    "point_budget_by_license": {
      "S": 4,
      "M": 8,
      "L": 12,
      "X": 18,
      "XL": 24
    }
  }
}
```

## 字段约束

| 字段 | 约束与职责 |
| --- | --- |
| `schema_version` | 必填整数，第一版固定为 1 |
| `display_name` | 必填非空字符串，档案显示名 |
| `radar_chart` | 必填完整对象；取代旧 `shipping_stats_config`，包含四个正数归一化 K 值和 `0.001～1.0` 的完整度步长 |
| `license.initial_level` | 必填许可证等级，当前为 S |
| `license.levels` | 必须按 S、M、L、X、XL 完整且唯一排列；经验为非负整数并严格递增，首级为 0 |
| `cargo_container_points.point_budget_by_license` | 必须完整包含 S、M、L、X、XL；预算为非负整数且随等级不下降 |

## 调度点规则

货柜定义使用 `dispatch_points` 表示持有成本。内置换算为 S=1、M=2、L=4、X=6、XL=8。

占用依据唯一货柜运行时仓库按玩家所有权实时汇总：active、invalid、pending_removal 等状态都占用，状态不能用于规避限制；资产真正销毁并从仓库移除后自然释放。获得新货柜前，服务端检查 `当前占用 + 新货柜成本 <= 当前许可证预算`。

数据包重载可能降低预算或提高成本。若玩家已经超限，现有货柜完整保留，只拒绝后续新增，直到销毁货柜、提高许可证等级或再次调整数据后恢复可用额度。

许可证经验仍保存在玩家 SavedData 中，档案只定义“累计经验对应哪个等级”；修改阈值不会重写或清零玩家经验。
