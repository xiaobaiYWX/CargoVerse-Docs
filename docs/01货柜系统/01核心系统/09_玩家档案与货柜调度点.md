# 玩家档案、许可证与货柜调度点

玩家规则定义位于：

```text
data/cargoverse/player_profiles/default.json
```

资源 ID 固定为 `cargoverse:default`。该定义提供航运风格统计窗口、许可证经验门槛和各等级调度点预算。

## 定义结构

```json
{
  "schema_version": 1,
  "display_name": "默认玩家档案",
  "radar_chart": {
    "window": {
      "mode": "recent_cargo_units",
      "cargo_units": 3000.0,
      "minimum_cargo_units": 100.0
    },
    "load_scale": {
      "size_factors": {
        "S": 0.2,
        "M": 0.4,
        "L": 0.6,
        "X": 0.8,
        "XL": 1.0
      }
    },
    "cargo_value": { "reference_unit_value": 100.0 },
    "richness": { "target_effective_goods": 8.0 },
    "coverage": { "target_effective_trade_points": 6.0 },
    "reliability": {}
  },
  "license": {
    "initial_level": "S",
    "levels": [
      { "level": "S", "required_experience": 0.0 },
      { "level": "M", "required_experience": 120.0 },
      { "level": "L", "required_experience": 420.0 },
      { "level": "X", "required_experience": 900.0 },
      { "level": "XL", "required_experience": 1800.0 }
    ]
  },
  "cargo_container_points": {
    "point_budget_by_license": {
      "S": 4,
      "M": 8,
      "L": 12,
      "X": 18,
      "XL": 24
    }
  }
}
```

许可证等级必须按 `S`、`M`、`L`、`X`、`XL` 完整排列，经验门槛非负且严格递增，首级门槛为 0。调度点预算必须包含全部五个等级并随等级不下降。

## 注册档案

玩家完成许可证注册后才创建运行时档案。档案保存：

- 玩家 UUID 与登记时名称；
- 执照 ID、注册时间、许可证类型与许可证等级；
- 签发机构名称和签发制造商 ID；
- 基础货柜权益定义及当前基础货柜 ID；
- 按制造商 ID 划分的声望点数；
- 航运风格统计。

未注册玩家不记录航运统计，也不能进行装载、卸货或货柜制造交易，但仍可通过个人航运档案查看和管理名下已有货柜。

注销许可证会删除玩家档案、许可证经验、航运风格与制造商声望，并删除所有带基础货柜标记的资产；普通购买或制造的货柜保留。

## 调度点

货柜定义的 `dispatch_points` 表示持有成本。服务端按玩家所有的有效货柜实时汇总；基础货柜同样占用调度点。

获得新货柜前必须满足：

```text
当前占用 + 新货柜调度点 <= 当前许可证预算
```

`pending_removal` 和资产级无效记录不计入占用；仍为有效资产但内部货物失效的货柜继续占点。配置变化导致玩家超限时不会删除既有货柜，只拒绝新增资产，直至占用重新回到预算内。

许可证经验独立保存在 SavedData 中，定义文件只负责把累计经验映射为等级；修改门槛不会主动重写玩家经验。
