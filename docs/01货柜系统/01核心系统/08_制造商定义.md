# 制造商定义

制造商定义同时提供货柜物理修正、玩家声望规则和签约承运人价格修正。

## 路径与 ID

```text
data/<namespace>/manufacturers/<path>.json
```

文件生成 `<namespace>:<path>` 形式的制造商 ID。货柜定义和贸易点定义都引用该 ID；贸易点也可以使用字符串 `none` 表示无制造商归属。

## 完整结构

```json
{
  "schema_version": 1,
  "code": "AUI",
  "display_name": { "translate": "manufacturer.cargoverse.aui" },
  "description": { "translate": "manufacturer.cargoverse.aui.description" },
  "container_traits": {
    "capacity_multiplier": 1.1,
    "empty_mass_multiplier": 1.0,
    "durability_multiplier": 1.0,
    "cargo_modifiers": {},
    "special_designs": [],
    "design_defects": []
  },
  "reputation": {
    "levels": [
      { "level": 0, "required_points": 0, "display_name": "陌生人员" },
      { "level": 1, "required_points": 100, "display_name": "登记承运人" },
      { "level": 2, "required_points": 300, "display_name": "农业合作承运人" }
    ],
    "trade_contribution": {
      "value_per_point": 100.0,
      "supply_preferences": [
        {
          "match_mode": "any",
          "tags": ["ore", "wood"],
          "priority": 1.5
        }
      ]
    },
    "signed_courier_bonus": {
      "buy_price_modifier": 0.95,
      "sell_price_modifier": 1.05
    }
  }
}
```

## 基础字段

| 字段 | 规则 |
| --- | --- |
| `schema_version` | 必填整数 `1` |
| `code` | 必填，2～8 位大写字母或数字；全部制造商中唯一 |
| `display_name` | 必填，支持直接字符串或 Minecraft 文本组件 |
| `description` | 可省略；文本规则同上 |
| `container_traits` | 可省略；倍率默认为 `1.0`，映射与列表默认为空 |

## 货柜特性

| 字段 | 作用 |
| --- | --- |
| `capacity_multiplier` | 货柜基础容量倍率 |
| `empty_mass_multiplier` | 空柜质量倍率 |
| `durability_multiplier` | 最大耐久倍率 |
| `cargo_modifiers.<cargo_good_id>.capacity_multiplier` | 指定 CargoGood 的容量倍率 |
| `special_designs` | 屏蔽货物运输风险的词条 ID |
| `design_defects` | 装载时附加到货物的运输词条对象 |

最终货柜数值由货柜定义与制造商特性共同解析。制造费用不属于制造商定义，由贸易点绑定的货柜制造台配方提供。

## 声望等级

`reputation.levels` 必须至少包含等级 0，并满足：

- `level` 从 `0` 开始连续递增；
- 等级 0 的 `required_points` 必须为 `0`；
- 相邻等级的门槛必须严格递增；
- `display_name` 使用制造商等级称号。

玩家声望按制造商 ID 分别保存，当前点数达到的最高门槛决定显示等级。

## 交易贡献

玩家向有制造商归属的贸易点出售货物时，为该贸易点的制造商增加声望：

```text
cargo_value = cargo_amount × cargo_good.base_value
reputation = cargo_value / value_per_point × priority
```

`supply_preferences` 根据 CargoGood 的 `tags` 选择 `priority`：

- `match_mode: any`：任意一个标签匹配即可；
- `match_mode: all`：必须包含规则列出的全部标签；
- 同时匹配多条规则时只采用最高 `priority`，不叠加；
- 没有匹配、没有标签或货物未知时使用 `1.0`。

例：`value_per_point = 100`，出售 `100t`、`base_value = 10` 的货物，并命中 `priority = 1.5`：

```text
100 × 10 / 100 × 1.5 = 15 声望
```

贸易点的 `manufacturer` 为 `none` 时不产生制造商声望。

## 签约承运人价格修正

玩家注册时会把许可证签发贸易点的制造商写入个人档案。只有该制造商与当前贸易点制造商相同，才应用 `signed_courier_bonus`。

```text
装载价格 = 基础价值 × 数量 × 贸易点出售倍率 × 动态价格因子 × buy_price_modifier
卸货价格 = 基础价值 × 数量 × 贸易点收购倍率 × 动态价格因子 × 完整度 × sell_price_modifier
```

制造商修正位于价格计算的最后一层。无制造商贸易点、未注册玩家或制造商不匹配时，修正固定为 `1.0`。
