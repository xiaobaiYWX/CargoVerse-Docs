# 制造商定义

制造商定义提供货柜空重与词条修正、CargoClass 供货偏好，以及按声望等级变化的签约承运人价格修正。货柜容量规则属于具体货柜定义。

## 路径与 ID

```text
data/<namespace>/manufacturers/<path>.json
```

文件生成 `<namespace>:<path>` 形式的制造商 ID。货柜定义和贸易点定义都引用该 ID；贸易点也可以使用字符串 `none` 表示无制造商归属。

## 结构示例

以下缩略示例展示字段格式；正式八家制造商使用 0～5 级声望，完整数据见[制造商设计](<../../10数据包定义与模板/02_制造商/README.md>)。

```json
{
  "schema_version": 1,
  "code": "AUI",
  "display_name": { "translate": "manufacturer.cargoverse.aui" },
  "description": { "translate": "manufacturer.cargoverse.aui.description" },
  "container_traits": {
    "empty_mass_multiplier": 1.0,
    "special_designs": [],
    "design_defects": []
  },
  "reputation": {
    "levels": [
      { "level": 0, "required_points": 0, "display_name": "陌生人员", "buy_price_modifier": 1.0, "sell_price_modifier": 1.0 },
      { "level": 1, "required_points": 100, "display_name": "登记承运人", "buy_price_modifier": 0.99, "sell_price_modifier": 1.01 },
      { "level": 2, "required_points": 300, "display_name": "工业合作承运人", "buy_price_modifier": 0.98, "sell_price_modifier": 1.02 }
    ],
    "trade_contribution": {
      "value_per_point": 100.0,
      "cargo_class_preferences": {
        "refined_resource": 1.5,
        "mechanical_parts": 1.5
      }
    }
  }
}
```

## 基础字段

| 字段 | 规则 |
| --- | --- |
| `schema_version` | 必填整数 `1` |
| `code` | 必填，2～8 位大写字母或数字；全部制造商中唯一 |
| `display_name` | 必填，支持直接字符串或 Minecraft 文本组件 |
| `description` | 可省略；文本规则同上 |
| `container_traits` | 可省略；空重倍率默认为 `1.0`，列表默认为空 |

## 货柜特性

| 字段 | 作用 |
| --- | --- |
| `empty_mass_multiplier` | 空柜质量倍率 |
| `special_designs` | 屏蔽货物运输风险的词条 ID |
| `design_defects` | 装载时附加到货物的运输词条对象 |

货柜容量和 CargoClass 容量修正由货柜定义维护。最终空重仍由货柜基础空重与制造商 `empty_mass_multiplier` 共同解析。货柜本体不设耐久，制造费用也不属于制造商定义，而由贸易点绑定的货柜制造台配方提供。

## 声望等级

`reputation.levels` 必须至少包含等级 0，并满足：

- `level` 从 `0` 开始连续递增；
- 等级 0 的 `required_points` 必须为 `0`；
- 相邻等级的门槛必须严格递增；
- `display_name` 使用制造商等级称号。
- 每级必须填写有限正数 `buy_price_modifier` 与 `sell_price_modifier`；
- 更高等级的买入倍率不得上升、卖出倍率不得下降，并且至少一项必须严格改善。

玩家声望按制造商 ID 分别保存，当前点数达到的最高门槛决定显示等级和签约价格修正。等级称号支持翻译组件；等级本身不解锁配方。

## 发现与手册排序

制造商首次通过以下任一事件写入玩家档案：注册该制造商签发的运输许可证，或在归属于该制造商的贸易点首次成功装载、卸载货物。档案按事件发生顺序保存制造商 ID，个人航运档案第三章也严格按该发现顺序分页显示。后续重复交易只更新业务数据与声望，不会重新排序。

制造商归属为 `none` 的贸易点不会触发发现。未发现的制造商不显示在手册中。

## 交易贡献

玩家向有制造商归属的贸易点出售货物时，为该贸易点的制造商增加声望：

```text
cargo_value = cargo_amount × cargo_good.base_value
reputation = cargo_value / value_per_point × priority
```

`cargo_class_preferences` 以 CargoClass ID 为键、声望倍率为值。货物所属大类命中时使用对应倍率；未配置的大类固定使用 `1.0`。`none`、未知分类、零值、负数和非有限值均拒绝加载。

例：`value_per_point = 100`，出售 `100t`、`base_value = 10` 的货物，并命中 `priority = 1.5`：

```text
100 × 10 / 100 × 1.5 = 15 声望
```

贸易点的 `manufacturer` 为 `none` 时不产生制造商声望。

## 声望价格修正

玩家注册时会把许可证签发贸易点的制造商写入个人档案。只有该制造商与当前贸易点制造商相同，才应用交易开始时玩家已达到声望等级的 `buy_price_modifier` 或 `sell_price_modifier`。

```text
装载价格 = 基础价值 × 数量 × 贸易点出售倍率 × 动态价格因子 × buy_price_modifier
卸货价格 = 基础价值 × 数量 × 贸易点收购倍率 × 动态价格因子 × 完整度 × sell_price_modifier
```

制造商修正位于价格计算的最后一层。无制造商贸易点、未注册玩家或制造商不匹配时，修正固定为 `1.0`。本次卸货跨越等级门槛时，新倍率从下一笔交易开始生效。
