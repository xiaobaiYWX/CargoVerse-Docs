# 制造商定义

> 已实现：基础特性解析及应用。预留：声望等级数据已解析，但没有玩家声望运行系统。

## 目录和文本规则

`data/<namespace>/manufacturers/<path>.json` → `<namespace>:<path>`。

制造商作为独立资源，供容器引用，也为后续其他设备与声望扩展留出边界。当前仅实现 container_traits 和 reputation 的定义结构，不表示任意新字段已有运行效果。

注意：制造商的 display_name／description 当前仍采用 CargoDataText，支持直接字符串与 Minecraft 文本组件；这与只支持直接字符串的货物和容器不同。不要把后两者的文本约束套到制造商。

## 已实现：内置 AUI 示例

```json
{
  "schema_version": 1,
  "code": "AUI",
  "display_name": { "translate": "manufacturer.cargoverse.aui" },
  "description": { "translate": "manufacturer.cargoverse.aui.description" },
  "container_traits": {
    "capacity_multiplier": 1.1,
    "empty_mass_multiplier": 1.0,
    "durability_multiplier": 1.0,
    "cargo_modifiers": {},
    "special_designs": [],
    "design_defects": []
  },
  "reputation": {
    "tiers": [
      { "id": "hostile", "min_reputation": -1000 },
      { "id": "neutral", "min_reputation": 0 },
      { "id": "trusted", "min_reputation": 1000 }
    ]
  }
}
```

| 字段 | 规则 |
| --- | --- |
| `schema_version` | 必填整数 1 |
| `code` | 必填，2～8 位大写字母／数字；全部制造商中唯一 |
| `display_name` | 必填文本内容 |
| `description` | 可省略 |
| `container_traits` | 可省略，所有倍率默认 1，映射与词条列表默认空 |
| `capacity_multiplier` | 容器基础容量倍率 |
| `empty_mass_multiplier` | 空柜质量倍率，不乘货物单位质量 |
| `durability_multiplier` | 最大耐久倍率 |
| `cargo_modifiers` | 完整 CargoGood ID → 对象；当前仅支持 capacity_multiplier |
| `special_designs` | 屏蔽货物运输风险的已支持词条 ID |
| `design_defects` | 装载时附加的运输词条对象 |
| `reputation.tiers` | 预留等级数组；id 唯一，min_reputation 为整数且严格递增 |

表中三个倍率和后三类特性字段位于 container_traits 内。倍率要求有限非负数并通过最终数值上限校验。旧 `value_multiplier` 已删除，继续填写会拒绝加载；制造费用由制造台配方的 `currency_cost` 决定。

同名词条目前按“货物→移除厂商／容器防护→厂商缺陷→容器缺陷”处理，后加入参数覆盖；设计中的按词条叠加尚未落地，见[词条与完整度](04_词条与完整度系统.md)。

## 预留边界

配置 reputation 不会自动生成玩家声望、解锁、折扣或任务。不得把 tiers 中的 trusted 写成已经可以通过运输获得的奖励等级。

依据：`cargo/data/ManufacturerDefinition.java`、`CargoDataText.java`、`CargoDataSet.java`。
