# 运输词条与实际货物损耗

没有独立完整度、加权完整度或尾数损耗账本。损耗直接删除固定整数个物品，降到零后载荷清空，货柜仍是可用资产。

## 触发与取整

- 易碎品：符合撞击条件时，每次扣 `loss_count` 个。
- 环境要求：符合不利条件的实测采样累计到 `loss_interval_ticks` 后扣 `loss_count` 个，不把物品扣量转换成小数。
- 环境、速度和温度仍可用必要的浮点物理数据；区块未加载时不推测环境或撞击。
- 放射性等非扣货效果继续按其要求执行。
- 清空载荷后，空柜不再运行货物词条；质量与贴花按剩余实际载荷刷新。

## 时限

`protection_ticks` 是保护期，结束后再经过一个完整 `loss_interval_ticks` 首次扣货，随后每隔该间隔扣 `loss_count` 个。超时不把整柜标为失效。

使用服务端游戏时间，停服不推进；区块卸载后恢复或交互时通过有界整数算术结算，不逐周期循环。成功追加正数货物时先结算旧损耗，再刷新整柜保护期；部分卸货不刷新。入库结束运输状态，重新出库使用当前配置开始新运输。

## 调度

按载具货柜 ID 错峰进行环境和物理采样；编译后的冻结词条描述复用。时间损耗由实际物品时钟维护，读取/交互和短周期调度共用同一结算结果，不重复扣货。
