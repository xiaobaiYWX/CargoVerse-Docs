# 运输物性与实际货物损耗

没有独立完整度或尾数货物账本。损耗直接删除固定整数原生数量：物品为 pcs，液体为 mB；降到零后清空载荷，货柜仍是可用资产。

当前已经接通数值运输会话，旧按词条 ID 调度的 Handler 与旧限时时钟已删除。详细数据入口、装载冻结、调度及暂未切换的内容见[运输数值运行时](14_运输数值运行时.md)。

## 运行规则

- 货物固有物性不因柜体保护而消失；围护、密封、缓冲、隔热、调温、遮光与承压共同改变实际暴露。
- 温度、压力、老化、累计暴露余数和冲击去重保存于原生内容的同一 TransportSession。各原因损耗汇总后封顶，一次扣量。
- 连续冲击按事件去重，同一事件最多扣一次；安全阶段暂停危险暴露，不清空剩余宽限和累计余数。
- 老化依有效温度及连续观测时间推进，不再用绝对保护截止时间推算。追加不刷新，部分卸货不重置状态。
- 区块／结构不可读、停机及超长采样缺口不外推；恢复建立新基线。单因素未知时暂停其依赖链。
- 原生卸出不附加永久运输寿命；卸空再装开始新运输。工作设置可保留，但空柜不做预冷模拟。
- 数量改变沿用质量、贴花与终端刷新；放射、燃烧等旧特殊行为不再由旧词条引擎继续执行。

## 数据和显示的阶段边界

新逐内容数据为 schema 2 的 transport。内置逐物品／逐流体参数与旧 UI 投影尚未完成第三轮切换：schema 1 的 transport_requirements 目前只保留显示资料，不执行旧行为，也不按旧 ID 自动猜测新物性。

因此当前旧 Tooltip 不能用于判断完整的新运行风险，候选 TU／J 也不等于已经完成正式货物的平衡。下一轮将按[重构实施方案](../../设计草案/运输词条重构草案/重构实施方案.md)统一数值定义和显示来源，不恢复双引擎。
