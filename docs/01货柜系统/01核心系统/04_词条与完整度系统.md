# 运输条件、货柜能力与内部状态

本页记录当前已实现的概念边界；参数与逐项支持状态见[类型与参数](15_运输类型与参数.md)，整体进度见[运行时](14_运输数值运行时.md)，尚未落地的玩法保留在[剩余目标](../../设计草案/待完成事项清单.md#运输条件与能力专项)。

## 两条判断路径

- 直接防护：货物的围护／封存需求与有效围护／密封比较。泄压时封存和液态水屏障复用同一个有效密封，不由显示名授予保护。
- 实际状态：能力、外部环境及工作设置先影响货物所处的实际状态，再按货物阈值、保存曲线和周期决定损耗。

货物条件不会因为装入保护柜而消失；“当前被保护”是实际状态的结论。条件、能力、状态与损耗由一条已有会话和事务链路维护，不建立逐 ID 独立免疫／扣量引擎。

## 五组内部数据的当前范围

| 分组 | 当前实际支持 | 尚未落地 |
| --- | --- | --- |
| 温度 | 围护基础隔热与专用隔层、按需自动调温、上下界损伤、温度驱动老化 | 正式柜型／货物参数与实运验收 |
| 气压 | 航空学真实世界点取样、有限交换及泄压、按需主动增减、压敏损耗 | 正式参数与控制界面 |
| 湿度 | 群系气候及不看遮蔽的当地降水、基础水检测、有限密封交换、主动控湿、干燥损耗与保存 | 正式内容赋值与实机验收 |
| 光照 | 遮光后直接补光、上下限独立累计损耗、不渐变 | 正式内容与界面验收 |
| 内部结构 | 4 tick 速度窗口差值、一次性事件扣量、倾角暴露损耗及按需朝向保持 | 正式内容／缓冲参数、控制界面及实运验收 |

五组状态不是五个能力等级，内部结构也不是单个防护分。未知保持未知；零重力缺少朝上参考时不能填 0°。速度取样不依赖重力有效性；缓冲增加速度变化耐受，朝向保持只改变内部承载面倾角，不削减撞击。

当前玻璃使用 schema 3 易碎条件，4 tick 速度窗口候选耐受 10 格／游戏秒、每事件扣 1pcs；等速急转与急加减速同样计入，无自由落体特判。液态水接触损伤也不是湿度；不能未经内容审查同时叠加两种同源受潮损耗。

## 条件与能力

源码已注册 13 种条件、11 种能力；13 种条件、11 种能力均已执行，但设备操作界面、正式内容与实机验收仍未完成。注册 ID 固定参数语义及共同过程，数据包只选择类型并填数值，不自定义状态、脚本、图标或规则表达式。

新能力中的速度耐受增量、换热时间、速度、削光量和压差为直接数值，不转换回旧档位。温压湿度的被动交换与主动恒定增减分开，并按环境周期共同推进；装有设备不等于设备工作，更不等于实际环境达标。

温度上下限可组合且各自保存暴露预算，共用实际温度。冷冻与高温敏感同占温度上限，重复配置报错；直接温度损伤期间不再叠加同源老化货损。

## 数量、生命周期与显示

货损直接扣原生库存数量，固体使用 pcs、液体使用 mB，不另维护完整度库存或生成损坏货物。百分比是读数投影，不是第二套货物身份。

首笔正数成功装载冻结本次规则与能力；追加、切换设备、部分卸出或重启不刷新年龄／暴露。全卸清会话，原生物品／流体不携带运输寿命。停机和未知窗口不补算；坏会话保留原文隔离，不视为空柜。详见[观测与生命周期](16_运输观测与生命周期.md)。

名称、图标、结构缺口和当前风险由公共只读投影产生。13 种条件与 10 种能力共用 GUI 图集，承压能力仍使用铁锭占位；世界条件贴花使用独立 PNG。图片不会启用未完成的功能。新设备工作设置和详细状态 UI 仍列为待实现／验收。
