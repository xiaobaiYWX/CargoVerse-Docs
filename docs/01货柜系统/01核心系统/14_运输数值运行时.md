## 数据到实例

| 层次 | 当前入口与职责 |
| --- | --- |
| 内容定义 | ItemPropertyDefinition／FluidPropertyDefinition：身份、准入、质量、贴花与运输条件 |
| 柜体定义 | CargoContainerDefinition：介质、能力及已实现调温约束 |
| 源码类型 | TransportTypes：ID、强类型参数、语义位置、名称／说明、图标与共用过程分类 |
| 配置编译 | TransportConfiguration：组合校验及共用过程编译，不创建逐 ID Handler |
| 本次冻结 | TransportSnapshot：实际条件、承运能力、调温约束和完整候选换算 |
| 唯一会话 | CargoContent.session 中的 TransportSession：设置、内部状态、累计量与事件去重 |
| 瞬时运动 | TransportWorldSampler／TransportImpactSampler.Samples／CargoTransportMotionCache：真实参考点、相邻端点与当前批次运行缓存，不另存数量或扣货状态 |
| 物理推进 | TransportAbilityResponse／TransportControls／TransportDynamics：能力响应、需求控制和实际状态路径，不直接改库存 |
| 权威提交 | TransportEvaluator → CargoTransportService 的不可变提案 → 现有 Repository／装卸事务 |
| 表现 | TransportPresentation／TransportLabels／TransportReport：只读规则和最近有效结果 |

物品、液体和气体共用一条求值和提交链路，不新增运输库存、平行载荷或第二份损耗账本。旧行为 Handler、墙钟限时结算不再运行；仍存活的旧定义读取、字段和图标工具不等于旧引擎仍在扣货。

## 源码注册类型：已接入的配置架构

- 逐物品／逐流体 schema 3 使用 transport_conditions，拒绝与 transport／transport_requirements 混填。
- 货柜 abilities 与 transport_capabilities／根级 thermal_control 互斥，不能叠加两套能力。
- 速度耐受增量、秒数、调节速度和亮度削减直接采用配置值，不回量化为旧等级。
- 未知 ID／参数、缺字段、非法范围、重复键和同一语义位置重复声明报错；完整有效新定义才原子发布。
- 冷冻与高温敏感复用温度上限，重复配置报错；温度上下限可组合并拥有独立损耗预算，共用一份内部温度。
- 推荐目标已检查一致性和安全范围，并接入温压湿自动控制；未推荐则最小必要调节，只有老化曲线不擅自降温。
- 新运输缺少保留设置时默认自动、按需工作；显式关闭保持。围护提供候选基础隔热，专用隔层取更强值；压湿密封阀门和主动输出分开。
- 冻结封套保存一份注册声明，编译视图不另作第二套持久化配置；未知／未接入规则原文隔离。

逐项参数、图标和示例分别见[货物运输条件](../02货物运输条件/README.md)与[货柜能力](../03货柜能力/README.md)，运行判断值见[核心数值](../04货柜核心数值/README.md)。[公共协议](15_运输类型与参数.md)只说明共用格式、校验和仍被资源依赖的过渡输入。

## 展示来源与时效

- 固有条件、配备能力、结构缺口、实际暴露和已损耗分开；能力名和图标不直接授予免损。
- 护目镜只同步必要准入与有效条件名称的稳定位集（VarInt）；碎料／粉料／易挥发使用独立特性位，不为每个物品展示固体形态或默认来源。
- [货箱信息 PDA](../../03功能方块/20_货箱信息PDA.md) 详情读取冻结规则、已提交的近期报告和历史最高速度差，展示数值仪表和条件状态；简短 HUD 只显示名称、货物图标/数量和归属。过期读数不续命，剩余老化预算不当作现实倒计时。
- 环境报告最多有效 20 tick，冲击报告最多有效 10 tick；实时状态在暂停、重启、过期或观测未知时不显示为安全。历史最高速度差为单独统计，暂停与重载后保留，不用它冒充新观测。查询不刷新时效或重复扣量。
- 装载／制造仪表和航运档案共用显示编码；有货读冻结能力，空柜读当前定义。固定槽每 60 tick 轮换完整标签列表。
- 原生数量按 pcs／mB 展示；空液体柜容量也转换为 mB。mob 目前是预留显示单位，不表示活体后端完成。
- 13 种条件与 10 种能力使用公共 GUI 图集并按源区域比例显示，过渡标签复用对应图案。13 种条件的世界警示贴花使用独立 PNG。液态水接触不混同湿度。
- 详细状态查看由现有 PDA 承担；HUD 和详情共用 CargoInspectionProjection，数值仪表由 CargoInspectionGauges 生成，不从显示字符串反推。旧文字回包已删除，当前协议只查统一版本表。查看与原有清空权限保持各自的服务端校验，不继续扩展复杂设备控制。

## 保存、采样与性能

装载冻结、追加不刷新、部分卸出保持、原生卸出不携带运输寿命、停机不补算等契约见[观测与生命周期](16_运输观测与生命周期.md)。新增状态和设备仍须沿此链路接入，不能单独维护一份仓库或时钟。

温度不检测淋雨，湿度独立读取群系天气。环境按 20 tick 错峰；易碎柜按 10 tick 分桶取样，比较相邻两次速度向量，每次最多一次比较、最多两个端点。普通安全采样不写回会话，新的历史峰值仅提交统计元数据；事件损耗即时沿原事务提交。到期门控先于物理读取，重复装卸与查询不增加采样；纯易碎柜不读无关环境、重力或倾角。瞬时速度变化与倾角独立，断样／恢复重建基线，不补算离线变化。总货量不增加逐物品／逐 mB 工作，纯状态变化不刷新质量或空间索引。跨柜总预算、真实多人负载和整账本存档停顿仍需实测，详见[成本边界](16_运输观测与生命周期.md#数值与成本边界)。

版本只在[当前数据契约](07_运行时与存档.md#当前数据契约)维护。温压和已知湿度可保存；光照、机械瞬时读数及连续基线恢复为未知。未知／旧 Load 原文隔离，不做猜测迁移，不覆盖为空柜。
