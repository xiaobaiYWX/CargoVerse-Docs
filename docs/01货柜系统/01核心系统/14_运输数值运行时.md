## 数据到实例

| 层次 | 当前入口与职责 |
| --- | --- |
| 内容定义 | ItemPropertyDefinition／FluidPropertyDefinition：身份、准入、质量、贴花与运输条件 |
| 柜体定义 | CargoContainerDefinition：介质、能力及已实现调温约束 |
| 源码类型 | TransportTypes：ID、强类型参数、语义位置、名称／说明、图标与共用过程分类 |
| 配置编译 | TransportConfiguration：组合校验及共用过程编译，不创建逐 ID Handler |
| 本次冻结 | TransportSnapshot：实际条件、承运能力、调温约束和完整候选换算 |
| 唯一会话 | CargoContent.session 中的 TransportSession：设置、内部状态、累计量与事件去重 |
| 瞬时运动 | TransportWorldSampler／TransportImpactSampler.Window／CargoTransportMotionCache：真实参考点、固定数组和当前批次运行缓存，不另存数量或扣货状态 |
| 物理推进 | TransportAbilityResponse／TransportControls／TransportDynamics：能力响应、需求控制和实际状态路径，不直接改库存 |
| 权威提交 | TransportEvaluator → CargoTransportService 的不可变提案 → 现有 Repository／装卸事务 |
| 表现 | TransportPresentation／TransportLabels／TransportReport：只读规则和最近有效结果 |

物品与液体共用一条求值和提交链路，不新增运输库存、平行载荷或第二份损耗账本。旧行为 Handler、墙钟限时结算不再运行；仍存活的旧定义读取、字段和图标工具不等于旧引擎仍在扣货。

## 源码注册类型：已接入的配置架构

- 逐物品／逐流体 schema 3 使用 transport_conditions，拒绝与 transport／transport_requirements 混填。
- 货柜 abilities 与 transport_capabilities／根级 thermal_control 互斥，不能叠加两套能力。
- 速度耐受增量、秒数、调节速度、亮度削减和最大压差直接采用配置值，不回量化为旧等级。
- 未知 ID／参数、缺字段、非法范围、重复键和同一语义位置重复声明报错；完整有效新定义才原子发布。
- 冷冻与高温敏感复用温度上限，重复配置报错；温度上下限可组合并拥有独立损耗预算，共用一份内部温度。
- 推荐目标已检查一致性和安全范围，并接入温压湿自动控制；未推荐则最小必要调节，只有老化曲线不擅自降温。
- 新运输缺少保留设置时默认自动、按需工作；显式关闭保持。围护提供候选基础隔热，专用隔层取更强值；压湿密封阀门和主动输出分开。
- 冻结封套保存一份注册声明，编译视图不另作第二套持久化配置；未知／未接入规则原文隔离。

13 种条件和 11 种能力逐项的参数、可执行范围、图标和可复制示例均见[类型与参数](15_运输类型与参数.md)。当前资源仍依赖的过渡数值格式也在那里说明，不在草案中保留另一套推荐格式。

## 展示来源与时效

- 固有条件、配备能力、结构缺口、实际暴露和已损耗分开；能力名和图标不直接授予免损。
- 护目镜只同步必要准入与有效条件名称的稳定位集（VarInt），协议 77；碎料／粉料／易挥发使用独立特性位，不为每个物品展示固体形态或默认来源。
- [货箱信息 PDA](../../03功能方块/20_货箱信息PDA.md) 详情读取冻结规则及近期只读摘要，展示传感器和条件状态；简短 HUD 只显示名称、货物图标/数量和归属。过期读数不续命，剩余老化预算不当作现实倒计时。
- 环境报告最多有效 20 tick，冲击报告最多有效 2 tick；暂停、重启、过期和观测未知不显示为安全。查询不刷新时效或重复扣量。
- 装载／制造仪表和航运档案共用显示编码；有货读冻结能力，空柜读当前定义。固定槽每 60 tick 轮换完整标签列表。
- 原生数量按 pcs／mB 展示；空液体柜容量也转换为 mB。mob 目前是预留显示单位，不表示活体后端完成。
- 13 种条件与 10 种能力使用公共 GUI 图集并按源区域比例显示，过渡标签复用对应图案。承压能力仍使用铁锭占位；13 种条件的世界警示贴花使用独立 PNG。液态水接触不混同湿度。
- 详细状态与所有主动设备的操作入口、权限和故障反馈尚未完整实现；资源存在和说明生成 API 不等于每个界面都已展示全部参数。

## 保存、采样与性能

装载冻结、追加不刷新、部分卸出保持、原生卸出不携带运输寿命、停机不补算等契约见[观测与生命周期](16_运输观测与生命周期.md)。新增状态和设备仍须沿此链路接入，不能单独维护一份仓库或时钟。

温度已移除淋雨检测与雨冷参数；湿度保留群系天气修正。环境 20 tick 错峰、有易碎需求时每 tick 采样速度窗口，只为实际有需求的有效载荷建任务；同载体短周期共享基础帧。状态推进及周期扣量有界，不随物品数、mB 数或离线时长线性回放。纯状态更新不重建空间索引或刷新物理质量，必要派生变化沿既有队列处理。新批次采用 4 tick／5 样本固定环形数组，精确增量计算每 tick 最多 4 次新增速度比较；安全采样不写回完整货柜会话，发生损耗才即时提交事件去重与数量。环境按需求裁剪查询，单纯易碎柜不建立环境任务；撞击不读取重力／倾角。当前仍没有跨货柜总处理预算，整账本存档、剩余取样分配与真实多人规模仍须验收。详见[成本边界](16_运输观测与生命周期.md#数值与成本边界)。

当前版本：根账本 DataVersion 5，条目 FormatVersion 12，内容封套 2，物品内容 3，液体内容 2，内部运输状态格式 2、规则快照格式 4、机械采样器格式 2，网络协议 77。温压和已知湿度可保存；光照、机械瞬时读数及连续基线恢复为未知。未知／旧 Load 原文隔离，不做猜测迁移，不覆盖为空柜。
