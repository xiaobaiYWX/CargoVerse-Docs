# 运输观测与生命周期

物理来源和逐项计算分别在[核心数值](../04货柜核心数值/README.md)维护；配置在[公共协议](15_运输类型与参数.md)。本页只维护共同推进、事务、冻结与成本边界。

## 观测与推进

使用货柜真实世界参考点，不用玩家位置或载具存储坐标。有效物理点速度保留角速度项；环境按冻结需求读取温压湿光，只有正放需求才读有效重力与倾角。未知不补零、不强制加载区块、不补算离线时间。

环境通常每 20 tick 推进一次，内部温压湿被动交换与恒定主动输出共同求解：

```text
dX/dt = (X_out - X_inside) / tau + active_rate
```

主动每秒速率换算到 tick。步内输入不变时采用解析指数解，并在目标、货物阈值和老化曲线边界分段，不逐 tick、逐物品或逐 mB 重放。接近目标时只输出抵消泄漏所需部分；输出不足不伪造达标。光照按周期直接合成。

冲击另按 10 tick 相邻端点速度比较，每柜每次最多一对样本；严格阈值、事件再武装及接受的漏检边界只在[速度变化](../04货柜核心数值/07_速度变化.md)维护。它不是加速度／能量，也不要求碰撞回调。

## 自动设备与查看

- 新运输未保留设置时，已配主动能力默认按需自动；没有对应需求时待机，初始内部值取实际环境。
- 显式关闭沿现有持久工作设置保存；追加、卸空和重启不偷偷改回自动。当前为一份共同环境工作设置，不承诺逐设备独立开关。
- 目标来自货物合法推荐值或最小必要安全边界，再受设备方向、范围、速率限制；不凭设备开启就宣布货物符合。
- 自动调节在服务端运行，不要求所有者在线；载体／区块不可用时仍暂停。切换设置不洗年龄、温压湿和预算。
- [货箱信息 PDA](../../03功能方块/20_货箱信息PDA.md) 已提供详细状态查看及原有权限受限的清空功能。当前范围不再深化设备控制、手动目标或独立管理界面，不将这些列作本轮遗漏；既有内部手动温控兼容路径不作为新 GUI 承诺。

## 冻结与重载

- 空柜首笔正数成功提交冻结货物需求、承运能力、响应参数和完整校准表；预览、取消、失败、零转移不产生批次。
- 有货读冻结值，空柜下次装载读最新有效定义；制造不永久冻结运输能力。
- 追加要求精确身份和计算规则兼容，规则／准入／能力变化时拒绝混代追加，但现有有效载荷可安全卸出。
- 工作设置属于实例，改设置不刷新实际状态与损耗预算。空柜保留设置不再受支持时安全退回关闭。
- 版本只在[数据契约](07_运行时与存档.md#当前数据契约)维护。当前机械封套仅保存事件检查点，不保存连续速度基线；旧规则及旧采样封套原文隔离，不保留旧窗口算法或猜测迁移。
- 正常环境提交、同批追加和部分卸出保留运行缓存；卸空、停用、重绑、批次替换、会话恢复及失效取样清理缓存。

## 追加与卸出

| 事件 | 当前语义 |
| --- | --- |
| 首次装入 | 必要温压以有效环境初始化，不瞬间预冷、增压或生成理想状态 |
| 追加 | 先结算已有有效观测，新量继承整柜温压、年龄、预算、余数和事件状态，不加权返老还童 |
| 部分卸出 | 先结算再转移，剩余载荷状态保持 |
| 原生卸出 | ItemStack／FluidStack 不写运输寿命；卸入原生库存后再装是新一次运输，这是明确接受的边界 |
| 全卸／损耗归零 | 清载荷及会话，保留货柜身份与工作设置 |
| 世界／载体卸载、停机 | 保存并暂停，不按离线时长补算；恢复重建基线 |
| 取消、失败、重试 | 数量与状态沿同一事务提交／补偿，不重复扣量、不生成影子库存 |

首版不模拟追加开口时的混合温度或压力瞬变；不新增柜间保持载荷的直接转移。更改控制设置、追加与重启都不能洗掉既有状态。

## 数值与成本边界

损耗以有效暴露／等效老化的商余数结算；安全暂停并保留余数，直接温度损伤期间抑制同源老化，独立风险合计封顶到现存原生数量。内部高精度与 UI 舍入分开。

- 环境任务按 ID 分 20 个桶，运动任务分 10 个桶，每 tick 只处理对应桶。设有环境需求的加载柜为 N、易碎柜为 F，平均约 N/20 次环境推进与 F/10 次速度取样／tick；桶不是硬性毫秒或数量预算。
- 每个易碎柜仅保留相邻两端速度，每次有效样本做一次向量差。1000 个柜平均约 100 次比较／tick、2000 次／秒；这是操作量估算，不是实测 CPU 耗时或承载保证。
- 到期门控先于物理提供者读取，装卸与重复调用不会在间隔内追加取样。PDA 查询只读取已提交的近期报告与历史统计；冲击读数有效期 10 tick，环境读数 20 tick，不以查询续命。
- 同载体同 tick 共享姿态、质心和基础速度，同参考点共享点速度。每柜保留自身角速度项；纯易碎柜不建立环境任务，速度取样不读重力／倾角。
- 普通无损采样及未创新高的同事件峰值增长不写回完整载荷；新增损耗即时生成提案，事件去重与原生数量沿原事务提交。PDA 所需的自上次装载以来最大速度差仅在创新高时生成 `PeakImpactSpeed` 元数据提案，不额外取样。未提交提案不消费事件，重试对照权威状态；装载清零显示峰值不清零扣货事件。
- 纯状态更新不刷新物理质量或重建空间索引；数量／质量、载体、贴花变更进入各自派生队列。同步只发必要摘要，不逐 tick 广播整仓或物性。
- 自动存档仍编码整份货柜账本，速度基线不保存，显示历史最高值独立保留；未加载但有需求的资产可能留在调度桶做可用性检查。当前没有跨柜总预算，真实多人负载、分配／GC 和存档停顿仍待实测。
