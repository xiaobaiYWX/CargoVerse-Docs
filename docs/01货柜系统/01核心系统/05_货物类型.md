# 实际物品身份与十四种运输分类

更新：2026-10-20。基础环境为 Minecraft 1.21.1、Create 6.0.10、航空学 1.3.0、Sable 2.0.3，以及随航空学提供的 Simulated、Offroad。分类边界以这些内容共同确定，不只围绕原版物品。

## 身份与分类

内容身份是物品 ID＋完整组件。名称、耐久、附魔、染色等不同的物品分别记账，不能混装。数量不属于身份，1 个物品占 1 库存/货柜容量单位，质量另算。

CargoClass 只负责运输分类、货箱兼容性和分类贴花。分类通过明确的物品标签与默认运输规则匹配，不按物品 ID 路径、名称、配方或安装位置自动推断；仍不定义独立 CargoGood。

## 分类边界

- 原料资源：原矿、粗矿、原木、原石、砂砾及待冶炼粉碎矿石。加工材料：金属锭、粒、板、棒、线、合金、纸张与皮革等。
- 农业物资包括种子、树苗、小麦、甘蔗；食品与食材包括鱼肉、蔬菜、糖、Create 小麦面粉、面团及加工食品。
- 烈焰蛋糕和蛋糕胚是燃料，余烬面粉是化工材料，不能按名称中的“蛋糕/面粉”归类。胶黏剂、染料、火药和药剂归化工与药剂。
- 齿轮、传动杆、齿轮箱、通用轴承、精密构件、陀螺仪构件和引擎组件归机械零件；压片机、搅拌机和完整动力设备归机械设备。
- 电子管、红石元件、遥控器及姿态/速度/高度传感器归红石与控制，不因安装于飞行器就归载具部件。
- 螺旋桨及专用轴承、气球蒙皮、车轮/悬架、列车转向架归载具与部件；普通船和矿车的物品形态也归此类，不包含把完整物理结构装入货柜。
- 箱子、保险库、漏斗、隧道、溜槽、传送带、Create 打包机/理包机、过滤器及仓储链接设备归物流与仓储；纸板等原材料仍为加工材料。
- 扳手、砂纸、护目镜、背罐、手持工具、武器和防具归工具与装备；书籍、地图、唱片、铭牌及未配置物品由通用物资兜底。
- 浮空材料按材料属性归原料或加工材料，不因为来自航空学而整体划入载具。

上述边界已开始写入明确物品标签：首批 77 个专用运输分组覆盖 1122 个原版、Create、航空学及随附模块物品，全部 14 类均有具体成员。尚未配置的可装柜物品仍使用 general_supplies / 0.001 Kpg / 无词条。自然贸易货物表保持为空，货箱容量与空重未调整；首批质量及损耗参数不是最终平衡值。覆盖清单见[首批运输数据](../../10数据包定义与模板/01_物品运输/首批运输数据.md)。

## 删除与合并

旧 23 个业务类保留修订 12 个，新增 food、logistics_equipment，删除 11 个：

| 旧 ID | 处理 |
| --- | --- |
| aquatic | 食品或相应材料；水产不作为来源大类 |
| livestock | 删除实体语义；农业、食品、材料按物品形态归类 |
| refined_resource | 合并加工材料 |
| hazardous_material | 危险性改为运输要求 |
| prefab_structure | 建筑构件、机械或物流设备按自身用途归类 |
| medical_supply | 合并化工与药剂 |
| weapon_armor | 合并工具与装备 |
| valuables | 按材料或物品用途归类，不按价格 |
| research_sample | 按物品形态归类，科研用途不做主类 |
| anomalous_cargo | 按物品形态及运输要求配置 |
| special_resource | 按原料/加工材料配置，不保留泛化特殊类 |

这不是运行时迁移对照表。60 份内置货箱白名单按 24 个产品系列逐项调整，8 家制造商偏好同时更新。保留原容量、空重和保护设计，后续再平衡；BioPod 生物物资舱改用农业、食品和化工类别，不运输活体。原活体倍率在 BioPod 改为食品、Eden 改为农业，倍率数值不变。

## 运输要求和准入

易碎、冷藏、危险、避光、防潮不作为互斥大类；价值、归属、任务用途也不改变物品主类。一个物品仅一个主类，同类内可有不同的质量和运输要求。

已知装有其他内容的包裹、容器、流体桶等仍按装柜安全检查拒绝或处理，分类不授予准入资格。本轮不开放实体、流体或非空嵌套容器运输；无法无损保存的物品拒绝输入，未知已存内容保留原文并隔离。

## 图标和贴花

使用用户提供的 V4.0 原图，不重绘、不缩放文件；每张宽 32px、高度按表中尺寸。GUI 分类图标与货箱贴花共用同一来源，1x1、2x2、3x3 各档保持宽高比。旧十一类贴图、模型、方块状态、物品模型和零质量资源删除，none 空柜图标保留。
