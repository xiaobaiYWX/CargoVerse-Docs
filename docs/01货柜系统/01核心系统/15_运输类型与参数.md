# 运输配置公共协议

逐项规则、数值和图标分开维护：[货物运输条件](../02货物运输条件/README.md)、[货柜能力](../03货柜能力/README.md)、[核心能力数值](../04货柜核心数值/README.md)。本页仅维护共用数据契约。

## 配置归属

| 入口 | 职责 |
| --- | --- |
| `TransportTypes` | 源码注册条件／能力 ID、强类型参数、语义位置、名称和图标 |
| `TransportConfiguration` | 严格解析、组合校验，编译为共同过程，不为每个 ID 新增扣量 Handler |
| 逐物品／逐流体属性 | 精确身份、质量、贴花、准入与 `transport_conditions` |
| 货柜定义 | `abilities`；介质、容量、空重、模板和制造材料仍在原位置 |
| 运行会话 | 冻结声明、工作设置、内部状态、预算余数和事件去重；动态值不由作者填写 |

物品路径为 `data/<namespace>/cargoverse_item_properties/solid/<item>.json`；流体路径为 `data/<namespace>/cargoverse_fluid_properties/liquid/<fluid>.json`。一文件对应一实际对象。物品 `unit_mass` 按该物品最大堆叠组计重，流体 `mass_per_bucket` 按 1000mB；价格和经验在具体贸易报价中配置。

新物品／流体属性为 schema 3，`transport_conditions` 与旧 `transport`／`transport_requirements` 互斥。货柜沿用 schema 1，`abilities` 与 `transport_capabilities`／根级 `thermal_control` 互斥。不新增独立 profile、继承覆盖或规则脚本。

## 组合与校验

- 未配置即无此条件／能力，不从用途、名称、形态或制造商猜测。注册参数对象不能统一用数值 0 代替，合法零边界按各项说明解释。
- 条件与能力使用不同注册表，不允许混填；未知 ID、未知字段、缺必填、非有限数、非法范围、非整数原生扣量及重复 JSON 键拒绝发布。
- 碎料／粉料共占围护需求位置；冷冻运输／高温敏感共占温度上限，重复声明拒绝。温度及光照上下限可组合，不得倒置，各方向预算独立。
- 温压湿推荐目标必须一致且在最终安全范围，主动设备仍受支持方向、目标范围、速率与压差限制。
- 完整有效的一代数据才原子发布；失败保留上一代。首次成功正数装载冻结规则，不用 reload 追改在途状态。

## 共用损耗

```json
"loss": {"grace_ticks": 100, "interval_ticks": 200, "amount": 1}
```

`grace_ticks` 为非负累计不利暴露预算，`interval_ticks` 为正周期；首次扣量发生在累计达到 grace＋interval 时。安全期间暂停累计，保留余数，不重新赠送预算。时间使用服务端 tick，20 tick＝1 游戏秒，不跟随现实墙钟。

`amount` 为正整数原生数量：固体 pcs、液体 mB，不是栈或桶。周期结算使用商／余数，合计封顶到现存数量，不逐物品、逐 mB 或逐周期遍历。

易腐坏用 `budget_ticks` 表示保存预算，`loss` **只能**包含 `interval_ticks` 和 `amount`。有效老化时间耗尽预算后开始周期扣量；直接温度损伤期间不叠加同源老化损耗。独立风险仍可并行。


## 显示与资源公共约定

GUI、仪表、PDA、档案使用 `textures/gui/transport/icons.png`（252×254）；裁剪区域和等级限制在各项页面维护。绘制保持源区域比例，扫描动画限制在区域内部，同图集切换等级也触发动画。能力等级不推导物理强度。

只有货物条件注册独立世界 PNG 贴花，能力不注册贴花。护目镜只显示有效条件名称和必要准入；物品栏不重复显示固体形态，不显示无需求标签。途中展示读冻结规则，查询不运行第二份损耗逻辑。

## 仍在使用的过渡输入

这些是当前资源依赖，不是保留另一套引擎：schema 1 的 `transport_requirements` 可读为待清理资料但不执行旧行为；schema 2 的 `transport` 仍支持已接入的围护、密封、液水、温压光、老化和速度变化规则。旧 J 字段不重新解释。

柜体 `transport_capabilities` 仍支持围护／密封 0～2，以及旧缓冲／隔热／调温／遮光 0～3；各项现行换算只在对应能力页说明。注册 `abilities` 直接用参数，不回量化为旧等级。内置迁入后才能删除仍被使用的读取入口；未知旧载荷原文隔离，不清空当作无货。
