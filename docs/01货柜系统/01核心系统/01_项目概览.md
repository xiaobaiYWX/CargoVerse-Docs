# 项目概览：货柜资产与货物运输

CargoVerse 将货柜视为玩家长期持有的物流资产。货柜制造、货物装载、运输和卸货结算是相互独立的业务步骤。

## 数据职责

| 对象 | 职责 |
| --- | --- |
| `CargoClass` | 一级货物分类与货柜分类贴花 |
| `CargoGoodDefinition` | 具体货物的单位质量、基础价值、币种、科技等级、标签、经验和运输词条 |
| `CargoContainerDefinition` | 货柜型号、结构模板、制造商、规格、调度点、基础数值与兼容分类 |
| `ManufacturerDefinition` | 厂商物理特性、声望等级、供货偏好和签约承运人价格修正 |
| `CargoContainerInstance` | 所有权、设备快照、当前货物、耐久、物理位置、状态及基础货柜标记 |
| 贸易点 | 库存、生产、价格、活跃度、繁荣度、制造商归属和功能模块 |
| 玩家航运档案 | 注册身份、许可证、签发制造商、基础货柜权益、制造商声望和航运风格统计 |

## 玩家流程

1. 在许可证注册终端完成注册，创建玩家档案与运输许可证。
2. 在注册终端领取档案中记录的基础货柜，或在货柜制造台制造普通空柜。
3. 货柜占用许可证等级对应的调度点预算，基础货柜同样计入占用。
4. 装载机从贸易点输出库存购买货物并写入货柜。
5. 运输期间按货物词条更新货物完整度；货物完整度与货柜耐久分别保存。
6. 卸载机按数量出售货物，写入贸易点输入库存、货币结算、许可证经验、航运风格与制造商声望。
7. 完全卸空后货柜仍归原玩家，可继续使用或在个人航运档案中删除。

单个货柜同时只承载一种完整的 CargoGood ID。补装相同货物会合并数量与批次状态，不按 CargoClass 混装不同货物。

货物数量使用 `t` 作为项目货物单位；质量由 `unit_mass × units` 计算，不由世界结构质量反推货物数量。

## 定义与运行时

定义资源决定新建资产、首次装载和实时经济规则。货柜制造时保存设备快照，首次装载时保存货物快照；运行中的资产由服务端仓库和交易服务维护，客户端界面只读取同步后的展示数据。
