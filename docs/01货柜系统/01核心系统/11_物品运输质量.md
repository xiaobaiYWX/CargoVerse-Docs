# 物品运输质量

> **正式落地规则 · 2026-10-21。** 已更新全部 2316 项设计记录及 2315 个运行成员；质量和逐 ID 依据已合并至唯一分类清单，不再维护第二套目标表。

## 1. 先确定整柜负担，再确定单件质量

**物品的运输质量是独立的游戏平衡参数，不是该物品放置后的方块质量。** 数千块石头进入货柜时，不按数千个真实石质方块的物理重量相加。

本期继续“件数×单位运输质量”的简单模型，不读取 physics_block_properties，不按模型体积或方块密度推导，不添加货柜隐藏减重倍率、按数量递减或隐式压缩物品机制。载具上真正放置的方块继续采用自身物理规则，物品打包和世界放置可有不同质量。

常规大宗建材使用 **0.1 Kpg／件**：1000 件为 100、3000 件为 300、5000 件为 500。单价、稀有度和合成成本不成为增重理由。不能用“50 件装得动”证明“5000 件也装得动”。

**所有目标单位质量只允许 0、整数或一位小数。** 最小非零档位为 0.1；不允许隐藏 0.01、0.055556 或仅在界面舍入。若 5000 件常规建材的 500 Kpg 仍超出目标载具能力，需调整运力、装载规模或明确将相应物品设为 0；不能暗中突破精度要求。本轮没有实测最大升力，不承诺所有载具都能起吊任意满柜。

## 2. 本版质量档位

| 单位运输质量 Kpg | 明确定位 | 示例 |
| --- | --- | --- |
| 0 | 可以忽略的散件、薄片、单份轻料 | 纸、种粒、染料、羽毛、单份食品、部分粉料、空瓶、煤炭散件 |
| 0.1 | 常规大宗物品与轻型成品 | 石材、木材、玻璃构件、土砂、方块级混凝土粉末、普通金属锭、药水 |
| 0.2 | 致密矿材、中型部件、空容器 | 黑曜石、箱型设备壳体、轴承组件、重型护具 |
| 0.3 | 完整机台、便携动力、重型框架 | 常规机器、便携式引擎、压缩粗金属、部分铜构件 |
| 0.4 | 较重成套机械 | 蒸汽引擎、机械压力机、搅拌机、钻头与机械锯 |
| 0.5 | 重型核心与常规实心金属块 | 粉碎轮、重核、铁块、铜块、黄铜块 |
| 0.8 | 少量高密度压缩物品 | 金块 |
| 1 | 本版单件质量上限 | 下界合金块 |

这是运输档位，不是现实密度表。台阶、楼梯、同材质整块可能统一为 0.1，允许舍弃最低档内的细微差别，避免为显示差别把普通建材推回 1～3 Kpg。

## 3. 零质量和默认值

全部 2316 项中 **668 项目标为 0**：**552 项是可进入普通／空态验证流程的轻微物品**，其余 116 项是 A4／空气占位。后者不意味着允许运输。

- 零质量仍逐件消耗货柜容量，仍需对应形态、准入与保护，正常结算价格和经验。纸张的防潮、细粉的防漏粉承载不会因为零质量消失。
- 总载重仍包含货柜本体；零载货质量不能抵消结构质量，也不让货柜无限装载。
- 明确轻微的 ID 才设零。未知新物品的默认值为 **0.1**，显示未适配默认，后续按 ID 校准。
- 石材、机器和面板按逐 ID 明确档位计重，不因未声明用途而自动成为零质量。

不要求压缩配方严格守恒。例如铁粒为 0、铁锭 0.1、铁块 0.5。完整块仍重于单锭，但九锭压缩后的打包质量可低于九个散锭；这是压缩运输与容量效率的设计取舍。散件零质量则用更多容量换取较低载重。无隐藏重量、无“累计几百件突然补重”；若实测出现过强路线，调整该类明确 ID 的档位。

## 4. 同族规则

- 末地石／末地石砖及对应台阶、楼梯、墙，统一 0.1。其他常规石材加工族同样采用 0.1。
- 木料与主要木构件 0.1；微小木按钮、薄标牌可为 0；木舟 0.2、带箱木舟 0.3。
- 完整铜块 0.5，铜台阶／楼梯 0.3；铜屋面等薄材 0.1，镂空铜格栅／灯壳 0.2。氧化和涂蜡不改变对应档位。
- 常规金属锭 0.1、压缩金属块 0.5；金锭 0.2／金块 0.8；下界合金锭 0.2／块 1。
- 粗矿 0.1／粗矿块 0.3；单份粗碎矿料 0.1。煤炭散件 0／煤炭块 0.1。
- 空瓶 0，装填药瓶 0.1；空碗 0，汤碗 0.1。空满仍属于相同基础交付形态。
- 方块级混凝土粉末 0.1，与凝固块同档；单份火药、面粉等轻料可为 0，基本装载要求不变。
- 颜色、纹理、附魔、命名、耐久、药效不运行时增重。设备按已装配物品运输档位计重，不按其放置后的机器方块质量计算。
- 被阻止装载的内容桶、背罐等也有目标值，供未来启用参考，本轮不因此改变准入。

所有具体例外以逐 ID 表为准。规则只用于设计审阅与生成，游戏运行不按名称猜测材质。

## 5. 千件规模对照

下表只有**载货增量**，不包含货柜本体、载具本体或其他货柜。

| 代表物品 | 单件 Kpg | 1000 件 | 3000 件 | 5000 件 |
| --- | ---: | ---: | ---: | ---: |
| 纸／轻微食品／单份火药 | 0 | 0 | 0 | 0 |
| 石块／木板／玻璃块 | 0.1 | 100 | 300 | 500 |
| 黑曜石／中型组件 | 0.2 | 200 | 600 | 1000 |
| 常规机台／便携式引擎 | 0.3 | 300 | 900 | 1500 |
| 蒸汽引擎／机械压力机 | 0.4 | 400 | 1200 | 2000 |
| 铁块／粉碎轮 | 0.5 | 500 | 1500 | 2500 |
| 金块 | 0.8 | 800 | 2400 | 4000 |
| 下界合金块 | 1 | 1000 | 3000 | 5000 |

常规石材 5000 件为 500 Kpg。普通材料占最低非零档，重材仍形成专门运力需求；不保证满柜稀有重材和满柜木料一样容易运输。

Atlas S 的定义容量为 50 件、空重配置 20，其他尺寸也不是全部数千件。上表是**高装载量设计工况**，不是货柜容量表。各型号容量、空重和制造价格以对应定义为准。

CargoMassPlaceholderHelper 中实际容器基础质量取 `max(模板结构质量, 配置空重)`，再叠加载货质量。因而不能把配置空重 20 直接当作实际物理空重。实测需记录结构、容器、载货和载具总质量，判断是否由模板自身重量限制起吊。

## 6. 运行配置与存量

- 唯一维护源为每个物品的基础属性 JSON；分类清单和质量说明是查阅投影。使用 Java 属性解析／资源测试和真实注册 GameTest 核验，不分组生成或覆盖手调属性。
- 基础属性共 2315 份独立文件，新运输条件使用 schema 3，旧资源读取边界见[类型与参数](15_运输类型与参数.md)；源码默认 solid、0.1 Kpg、standard、无需求、none 贴花。运输冻结快照 schema 3，不发布共享 profile/tag。
- 不改变分类、准入、保护、价格、经验、货柜容量／空重和世界方块物理质量。0 质量也正常逐件占容量、结算、扣损；blocked 仍拒装。
- 新的十分位质量使用 long 十分位×件数再除以 10 传给 double 物理接口。旧精度快照和高精度外部配置不舍入，不因档位变更丢失资产。
- 已载货保持冻结质量；重载不会原地给存量补重。不同规则快照不能追加，先卸空再按新规则装货。
- 千件运力、最大升力与全航线表现仍待实机验收，不保证所有载具均能起吊满柜。

## 7. 精度与验证边界

- 每个目标值必须是非负的 0.1 整数倍，范围 0～1；生成端以十分位整数计算，输出整数或一位小数。
- 内置新规则质量累加已使用十分位整数×件数再展示，避免出现 0.30000000000000004；不强制重构现有 double 物理接口。
- 旧快照保留原精度，不因新档位校验失败而丢失旧资产。
- 零质量仍消耗容量、需要合适柜体、受有效损耗词条影响；不能抵消模板结构与载具本体质量。
- 校验全部 ID 唯一覆盖、逐物品 JSON 与查阅表一致、颜色／氧化族一致、关键代表值与千件计算一致；不从文档反向覆盖已微调属性。
- 运输质量的减小是有意的体验调整；是否能起吊必须用具体载具和模板验证，本轮未运行航行测试。
