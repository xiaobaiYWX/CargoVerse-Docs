# 液体运输

## 当前实现

液体已接入同一套货柜资产、装卸确认、冻结运输规则、时限与损耗、质量刷新和自然点交付经验。本章的“液体运输”涵盖所有标准 Fluid，包括带 c:gaseous 标签的气体。气态 Fluid 统一使用 liquid 类型，不提供独立气体页面或后端；活体尚未开放运输。

玩家点使用收发器连接最多 5 组普通 Create 储罐。管理终端切至液体页后可设置出售／收购价格，或者免费管理装卸；公共装卸终端检测液体柜后自动选择液体业务，加载和卸载均经过确认界面。归属、有效隧道、操作区域、权限、货柜所有权和钱包仍由服务端校验。

贸易点只连接储罐、不连接物品保险库时也能营业。储罐内的实际流体是库存，不另外保存一份影子库存；核心只保存报价配置。先在储罐存入一种流体，才能在仓库 SET 中为其上架。已有收购报价可在库存归零后继续接收该流体。

## 身份与计量

- 一柜一种完整 `FluidStack` 组件变体；不同组件不能混装，不把流体换成虚拟桶物品。
- 原生量保存为整数 mB。常规数量旋钮 1 表示 1000mB，实际装卸取请求、来源库存及可用空间的原生最小值，允许尾量。
- 交易单价、自然站库存／补货／每日收购限额及经验按每 1000mB 一份配置，实际成交按 mB 比例折算；金额向上取整、经验每笔向下取整，不存经验余数。界面实际数量仍显示 mB，不显示桶数冒充 mB。
- 请求 1 份、库存 1300mB 时转移 1000mB；请求 2 份时转移 1300mB。库存只有 300mB 也可以响应 1 份请求，金额按 0.3 份结算。
- 柜内损耗或仓库不足一份的尾量，正常装卸、公共买卖和免费管理装卸均可处理；转移量仍受目标原生剩余空间限制。
- 总载货质量为 `实际 mB / 1000 × mass_per_bucket`，最终向上取至一位小数；1300mB、每桶 1Kpg 时为 1.3Kpg，1mB 为 0.1Kpg，不逐 mB 取整或累加。
- 已注册 Fluid 无论是否带 `c:gaseous` 标签，均使用 liquid 运输类型；缺失定义时采用液体默认属性；不根据模组名称或桶物品推断身份。

所有柜型定义的 `allowed_cargo_classes` 必须恰好包含一个现行介质。固体柜 `capacity: 120` 为 120 组；液体柜同一数值为 120000mB。保存的柜体配置容量仍是定义单位，载荷及界面容量是原生单位，仅在公共容量入口换算一次，并校验溢出。

## 逐流体属性数据包

位置：`data/<流体命名空间>/cargoverse_fluid_properties/liquid/<流体路径>.json`。

水的内置示例：

```json
{
  "schema_version": 2,
  "form": "liquid",
  "mass_per_bucket": 1.0,
  "decal": "cargoverse:decal_none",
  "transport": {
    "sealing": {
      "required_level": 1,
      "loss": { "grace_ticks": 0, "interval_ticks": 1200, "amount": 1000 }
    }
  }
}
```

没有文件时，源码默认每 1000mB 为 1Kpg、无运输词条、无贴花；不要求其他模组补齐数据包才能装载。文件可覆盖质量、运输条件和贴花，但不包含价格或经验。按同一原子数据重载发布，未知字段、错误路径、未注册流体和不合法贴花拒绝发布。

新注册属性使用 schema 3 的 `transport_conditions`，现有水仍使用过渡 schema 2 的 `transport`；液体 `loss.amount` 按原生 mB 扣量。装柜冻结物性、能力和完整候选换算规则，柜体不删除固有物性。途中 `/reload` 不改变已装质量、贴花或本次规则；物性／能力不兼容则拒绝追加，但允许正常卸出。成功补货与部分卸货均保持状态，卸空再装才开始新运输。旧 `transport_requirements` 不执行行为或生成有效需求，内置条件和能力迁入仍待实施；完整协议见[类型与参数](15_运输类型与参数.md)，当前数据见[运行时](14_运输数值运行时.md)。

## 自然点报价

资源表仍为 schema 3。液体行使用 `type: "liquid"` 和 `fluid`，不使用 `item`：

```json
{
  "schema_version": 3,
  "sales": [
    {
      "rule_id": "water_sale",
      "type": "liquid",
      "fluid": "minecraft:water",
      "unit_price": 5,
      "stock": { "initial": 120, "capacity": 240, "daily_restock": 20 }
    }
  ],
  "acquisitions": []
}
```

上述起始库存是 120 份，即 120000mB。收购行同样使用 `type/fluid/components`，原有 `license_experience_per_item`、`prosperity_experience_per_item` 字段在液体行表示每桶经验，尾量按比例折算后每笔向下取整，缺省为 0。只在向已验证自然贸易点交付时增长经验，玩家点收购和管理装卸不增长。正式自然站交易表仍待内容设计，本轮不自动填表。

运行时选择键为 `cargoverse:liquid/<namespace>/<path>`，组件变体追加摘要；组件原文才是身份依据。该带类型的内部键不是数据包里的流体 ID，避免与同名物品的库存、报价混用。

## 柜型与显示

当前开放 Cistern、Crucible、Boreas 的 M／L 六款；首轮容量暂定 M=120 桶、L=240 桶，分别为 120000／240000mB，后续平衡直接改柜型定义。暂用对应规格 AUI 标准干柜结构，未宣称已有独立液体结构或衬层抗腐蚀机制。测试全型号制造目录已有六款配方。

各终端单位统一为 solid=`pcs`、liquid=`mB`、living=`mob`。空液体柜的显示快照也显式携带介质，不因没有已选货物变回 pcs。图标监视器接受纹理、物品、流体及静态生物来源；模型先生成平面图像再绘制，保留扫描切换效果。缓存最多 256 张 64px 图像、每帧最多新建 2 张，退出世界和资源重载时释放。生物显示来源不等于生物运输实现。

## 气态 Fluid 与岩浆燃气

运输类型只有 solid、liquid、living。气体使用同一 liquid 选择键、属性目录、仓库页面、报价、装卸后端和存档编码；c:gaseous 保留为原生流体语义标签，不决定运输准入或自动产生运输条件。温度、压力和密封需求均由逐流体数据声明，不模拟压缩、相变或装载率决定的罐内压力。

所有液体柜至少液密1，可以装载任意原生流体。Boreas M／L 的气密2适合易挥发内容，普通液体同样可以装入；反过来普通液体柜也可以装气体，保护不足时按该流体声明的条件损耗。一柜仍只能装一种精确 Fluid ID 和组件，不因合并运输类型混装水与燃气。Boreas 现行空重 M=90／L=190Kpg、容量120000／240000mB，仍用 AUI 占位结构。

测试介质为 `cargoverse:magma_gas`（岩浆燃气），flowing 变体为 `cargoverse:flowing_magma_gas`；两者加入 c:gaseous，但分别维持精确原生 ID。`/give @p cargoverse:magma_gas_bucket` 可取得1000mB测试桶，创意物品栏也可获取；通过原生流体接口注入 Create 储罐，不在世界中放置流体方块。当前借用原版岩浆纹理与桶图标，没有燃烧、爆炸或燃料用途。

两份属性均在 `data/cargoverse/cargoverse_fluid_properties/liquid/` 中，form 为 liquid，每1000mB=1Kpg，并声明：

```json
"transport_conditions": {
  "cargoverse:volatile": {
    "loss": {"grace_ticks": 0, "interval_ticks": 1200, "amount": 1000}
  }
}
```

易挥发要求密封2，保护不足时每累计1200tick损失1000mB。缺失逐流体声明仍采用默认质量、无特殊需求，不能将此测试配置自动套用于所有气体。

测试站 A 以 `type: "liquid", "fluid": "cargoverse:magma_gas"` 出售，每1000mB基础5VB；B收购，基础6VB，许可证与繁荣度经验各每1000mB为1点。尾量、市场和签约修正沿共同规则；同一自然站不同时出售、收购相同货物。正式自然表仍待配置。

## 安全与验证边界

原生储罐转移采用受控 Create 槽位日志，整笔计划可完成后才修改，核对模拟／执行数量与精确组件；失败恢复本次触及的槽位，不覆盖无关变化。付款、核心钱包、货柜、库存、经验及统计使用现有事务补偿。取消确认不触发提取，确认时重验，令牌不可重放，不强制加载区块。

已进行相关单元及服务端世界测试，覆盖液体身份和保存、1300mB 质量、尾量、原生储罐、报价、金额、失败回滚、玩家装卸终端确认及免费管理路径。客户端平面图像的实际视觉、更多模组自定义流体表现、Sable 运动货柜及多人压力仍需专项验收，不能以自动测试替代。
