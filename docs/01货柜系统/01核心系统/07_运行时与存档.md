# 货柜运行时与存档

唯一的货柜权威存储为 `CargoContainerSavedData`，业务通过 `CargoInstanceRepository` 访问。

```text
CargoContainerInstance
├─ 所有权、型号与资产状态
├─ CargoContainerSnapshot：设备、容量、分类许可、空柜质量、取得成本
├─ CargoLoad：通用原生载荷包络
│  ├─ CargoContent：ItemCargoLoad 或 FluidCargoLoad
│  │  ├─ 原生精确身份与数量：物品 count 或液体 mB
│  │  ├─ ItemTransportSnapshot / FluidTransportSnapshot：冻结规则
│  │  └─ TransportSession：冻结承运能力／校准、动态温压／年龄／余数及去重
│  ├─ 异常原文隔离
│  └─ 取得成本与异常隔离状态
├─ 调温工作设置：卸空保留，不模拟空柜预冷
└─ CargoPhysicalState：维度、结构与定位
```

设备和物理信息不再保存另一份货物快照；仓库也不保存抽象库存列表。`Content` 以 `Version/Type/Data` 保存带类型内容，当前实现 solid／liquid。未知类型、缺失注册内容或损坏组件整包隔离并保留原文，不能被当成空柜重新装货。损耗归零则清空有效载荷，设备不作废。共用层与原生实现的职责见[多类型载荷与计量](12_多类型载荷与计量.md)。

| 货柜 DataVersion | 5 |
| 货柜条目 FormatVersion | 11 |

开发阶段破坏性重构：不迁移旧运输状态；格式 10 资产外壳仅用于定位／隔离，旧载荷保留完整原文且禁止使用，不当空柜覆盖。不解析旧抽象 Load.Good 或旧 WarehouseListings。货柜根账本名称不变，不新建按介质划分的平行账本。物品／液体共同保存新数值 `TransportSession`，不再保存旧时钟。自然贸易表使用 schema 3；报价与经验结算入口已实现，40 张自然站买卖表仍为空，A／B 两张指令测试表已更新。

入库前只结算有效连续观测并结束该部分数量的运输；部分卸货保留温度、压力、年龄、暴露余数和冲击去重，取得成本按剩余数量分配；追加不刷新，卸空再装按新运输初始化。停机／不可读环境不补算，恢复首样本只建立基线。后台派生质量、贴花、空间索引与待清理队列沿用同一资产生命周期，不创建第二套库存。

货柜不保存来源批次，经验只按自然收购目的地和实际成交件数计算；损耗与部分卸货只改变实际载荷。航运风格存档独立保存航段出发时的平均实际购入成本，小数不截断，也不作为货柜权威库存或经验来源资格。

现行数值数据入口、调度频率及第三轮边界见[运输数值运行时](14_运输数值运行时.md)。
