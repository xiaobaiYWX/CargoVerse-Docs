# 货柜运行时与存档

唯一的货柜权威存储为 `CargoContainerSavedData`，业务通过 `CargoInstanceRepository` 访问。

```text
CargoContainerInstance
├─ 所有权、型号与资产状态
├─ CargoContainerSnapshot：设备、容量、分类许可、空柜质量、取得成本
├─ CargoLoad：通用原生载荷包络
│  ├─ CargoContent：ItemCargoLoad 或 FluidCargoLoad
│  │  ├─ 原生精确身份与数量：物品 count 或液体 mB
│  │  ├─ ItemTransportSnapshot / FluidTransportSnapshot：冻结规则
│  │  └─ CargoLossClock：原生扣量与可选时限
│  ├─ 实测词条状态
│  └─ 取得成本与异常隔离状态
└─ CargoPhysicalState：维度、结构与定位
```

设备和物理信息不再保存另一份货物快照；仓库也不保存抽象库存列表。`Content` 以 `Version/Type/Data` 保存带类型内容，当前实现 solid／liquid。未知类型、缺失注册内容或损坏组件整包隔离并保留原文，不能被当成空柜重新装货。损耗归零则清空有效载荷，设备不作废。共用层与原生实现的职责见[多类型载荷与计量](12_多类型载荷与计量.md)。

| 货柜 DataVersion | 5 |

开发阶段破坏性重构：不迁移旧货柜条目，已有测试货柜需重建；不解析旧抽象 Load.Good 或旧 WarehouseListings。货柜根账本名称不变，不新建按介质划分的平行账本。时钟字段为原生 `AmountPerInterval`，不再以物品命名。自然贸易表使用 schema 3；报价与经验结算入口已实现，40 张自然站买卖表仍为空，A／B 两张指令测试表已更新。

入库结算到期损耗并结束运输；部分卸货保留剩余时钟，取得成本按剩余数量分配；重新出库按当前规则开始保护期。后台派生质量、贴花、空间索引与待清理队列沿用同一资产生命周期，不创建第二套库存。

货柜不保存来源批次，经验只按自然收购目的地和实际成交件数计算；损耗与部分卸货只改变实际载荷。航运风格存档独立保存航段出发时的平均实际购入成本，小数不截断，也不作为货柜权威库存或经验来源资格。
