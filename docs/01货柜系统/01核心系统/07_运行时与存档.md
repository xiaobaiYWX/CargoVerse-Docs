# 货柜运行时与存档

唯一的货柜权威存储为 `CargoContainerSavedData`，业务通过 `CargoInstanceRepository` 访问。

```text
CargoContainerInstance
├─ 所有权、型号与资产状态
├─ CargoContainerSnapshot：设备、容量、分类许可、空柜质量、取得成本
├─ CargoLoad：实际物品运输包络
│  ├─ ItemCargoLoad
│  │  ├─ ItemCargoPayload：ItemCargoIdentity + count
│  │  ├─ ItemTransportSnapshot：冻结分类、质量与要求
│  │  └─ CargoLossClock：可选时限时钟
│  ├─ 实测词条状态
│  └─ 取得成本与异常隔离状态
└─ CargoPhysicalState：维度、结构与定位
```

设备和物理信息不再保存另一份货物快照；仓库也不保存抽象库存列表。未知实际物品/组件整包隔离并保留原文，不能被当成空柜重新装货。损耗归零则清空有效载荷，设备不作废。

| 项目 | 当前版本 |
| --- | --- |
| 货柜 DataVersion | 5 |
| 货柜条目 FormatVersion | 9 |
| 物品载荷包络 | 1 |
| 贸易点经济 DataVersion | 15 |
| 网络协议 | 64 |

开发阶段破坏性重构：不迁移旧货物/经济存档，不解析旧抽象 Load.Good 或旧 WarehouseListings。自然贸易表使用 schema 3；报价与经验结算入口已实现，40 张自然站买卖表仍为空，A／B 两张指令测试表已更新。

入库结算到期损耗并结束运输；部分卸货保留剩余时钟，取得成本按剩余数量分配；重新出库按当前规则开始保护期。后台派生质量、贴花、空间索引与待清理队列沿用同一资产生命周期，不创建第二套库存。

货柜不保存来源批次，经验只按自然收购目的地和实际成交件数计算；损耗与部分卸货只改变实际载荷。航运风格存档独立保存航段出发时的平均实际购入成本，小数不截断，也不作为货柜权威库存或经验来源资格。
