# 货柜运行时与存档

唯一的货柜权威存储为 `CargoContainerSavedData`，业务通过 `CargoInstanceRepository` 访问。

货柜搭建器的施工记录和托管材料保存在同一账本的`BuilderJobs`中；对应资产在完工前为`building`状态并预留调度点。方块实体仅保存普通输入和任务引用，卸载暂停，拆除按托管记录返还，不创建平行货柜库存。流程见[货柜搭建器](18_货柜搭建器.md)。

```text
CargoContainerInstance
├─ 所有权、型号与资产状态
├─ CargoContainerSnapshot：设备、容量、分类许可、空柜质量、取得成本
├─ CargoLoad：通用原生载荷包络
│  ├─ CargoContent：ItemCargoLoad、FluidCargoLoad 或 LivingCargoLoad
│  │  ├─ 原生精确身份与数量：物品 count、液体 mB 或逐只生物；物品冻结 StackSize，生物保存UUID与原生NBT
│  │  ├─ ItemTransportSnapshot / FluidTransportSnapshot：冻结规则
│  │  └─ TransportSession：冻结承运能力／校准、动态温压湿／年龄／余数及事件检查点
│  ├─ 异常原文隔离
│  └─ 取得成本与异常隔离状态
├─ 环境工作设置：沿用调温设置承载自动／关闭选择，卸空保留，不模拟空柜预冷
└─ CargoPhysicalState：维度、结构、定位及冻结部件布局
```

速度采样使用独立运行缓存，每 10 tick 读取一次，只保留相邻两个端点；安全比较不写回完整会话。损耗事件即时沿原事务提交，保存序号、峰值及扣货去重；恢复清连续基线并先解除武装。PDA 只读已提交的近期报告与独立保存的历史峰值，不读取或推进实时物理缓存。

`TransportLoss` 与 `PeakImpactSpeed` 是本次装载以来的显示统计：前者累计原生损耗（生物仅累计死亡只数，不累计受伤HP），后者保存有效相邻速度采样差的最高值。二者卸空／全损保留，下一次装载或追加重置；重置不影响运输事件去重、内部状态与预算。峰值仅创新高时提交元数据，存档缺字段时默认为 0；历史统计不作为恢复后的连续速度基线。

设备和物理信息不再保存另一份货物快照；仓库也不保存抽象库存列表。`Content` 以 `Version/Type/Data` 保存带类型内容，当前实现 solid／liquid／living。未知类型、缺失注册内容或损坏组件整包隔离并保留原文，不能被当成空柜重新装货。损耗归零则清空有效载荷，设备不作废。共用层与原生实现的职责见[多类型载荷与计量](12_多类型载荷与计量.md)。

## 当前数据契约

本表统一维护货柜、载荷、运输状态及网络版本；其他章节引用本表，不另设版本清单。

| 项目 | 当前版本 |
| --- | --- |
| 货柜 DataVersion | 5 |
| 货柜条目 FormatVersion | 14 |
| 内容封套 | 2 |
| 物品载荷包络 | 4（冻结 StackSize） |
| 统一流体载荷包络 | 2（统一 liquid 原生流体，无独立 Kind 字段） |
| 生物载荷包络 | 1（逐只原生NBT、舱位、冻结舱室及规则；无尺寸／数量上限字段） |
| 贸易点经济 DataVersion | 16 |
| 网络协议 | 87 |

| 运输内部状态 | 3 |

开发阶段破坏性重构：不迁移旧运输状态；条目保存实例运行时展示／质量锚点布局；旧条目及旧运输规则／机械封套不迁移，需要重新生成或重新建立有效载荷。现行格式内无法解码的载荷仍原文隔离，不当空柜覆盖。不解析旧抽象 Load.Good 或旧 WarehouseListings。货柜根账本名称不变，不新建按介质划分的平行账本。物品／液体／生物共同保存新数值 `TransportSession`，不再保存旧时钟。自然贸易表使用 schema 3；报价与经验结算入口已实现，40 张自然站买卖表已接入，A／B 两张指令测试表已更新。

入库前只结算有效连续观测并结束该部分数量的运输；部分卸货保留温度、压力、年龄、暴露余数和冲击去重，取得成本按剩余数量分配；追加不刷新，卸空再装按新运输初始化。停机／不可读环境不补算，恢复首样本只建立基线。后台派生质量、贴花、空间索引与待清理队列沿用同一资产生命周期，不创建第二套库存。

货柜不保存来源批次，经验只按自然收购目的地和实际成交操作份数折算、每笔向下取整；损耗与部分卸货只改变实际载荷。航运风格存档独立保存航段出发时的平均实际购入成本，小数不截断，也不作为货柜权威库存或经验来源资格。

生物捕获／释放还在同一账本保存UUID归属索引与待释放意图。涉及原生实体区块的持久化、恢复预算和经济边界见[生物运输](17_生物运输.md#原生保存与唯一归属)。PDA仅同步固定大小LivingSummary，最低生命、数量和舱位不放进运输条件仪表行。

现行数据入口、调度频率及实际完成度见[运输数值运行时](14_运输数值运行时.md)。
