# 有效围护等级

核心数值的单位／范围：**整数 0～2**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

冻结的 containment 能力直接产生有效等级，供碎料／粉料比较。围护不足只在运输运动时累计散失；围护 2 覆盖 1。它不是温度、缓冲或密封的总防护分。围护同时对被动温度交换提供小幅倍率，详见内部温度。
