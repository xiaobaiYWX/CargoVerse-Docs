# 有效密封等级

核心数值的单位／范围：**整数 0～2**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

等于本次运输冻结的 sealing 等级，不按内外压差自动降低。气压、湿度的有限交换、易挥发的直接封存与现有液水屏障共用此等级；内部气压未知不影响已有密封和湿度的独立判定。
