# 速度变化

核心数值的单位／范围：**格／游戏秒的速度向量差，非加速度／J**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

有易碎需求时，每隔 **10 tick（0.5 游戏秒）**采样一次实际货柜参考点速度，只比较相邻两次采样：

```text
velocity_change = length(v_now - v_previous)
final_tolerance = cargo.max_velocity_change + container.velocity_change_bonus
velocity_change > final_tolerance → 本事件扣 damage_amount
```

保留两个端点，每次只做一次向量差；不逐 tick 取样，不搜索窗口内峰值，不累计多次抖动。直线匀速差为零，等速急转可有向量差；不扣重力、不检测自由落体。采样间发生并恢复的变化可漏检，是明确接受的边界。

货箱信息 PDA 使用固定 0～50 m/s 的撞击指示条，显示自上次装载以来观测到的最大相邻速度差，数值只升不降；装载或追加后与运输损耗一起重置。`PeakImpactSpeed` 随货柜资产存档保存，暂停和卸空不清零；它是查看用历史统计，不替代当前撞击事件或改变扣货规则。每次既有采样后只比较一次最大值，创新高才生成元数据提案，未创新高不增加写入。

同一持续超限事件只扣一次；下一次有效比较落回耐受以内即结束，之后再次超限才是新事件。首次采样只建基线。断样（不再恰好相隔 10 tick）、载体／质量／质心／参考点变化或重启先清基线并解除武装，随后一次安全比较才重新武装；不将位置跳变当冲击，不补算离线变化。未知显示 ---。


## PDA 历史显示

PDA 的撞击仪表显示自上次装载／追加以来已提交的最高相邻速度差，而非持续下降的实时值。该显示历史在暂停和重载后保留，载荷装入／追加时重置；每次采样只在创新高时提交元数据。历史峰值不代替事件判断、不延长实时报告有效期，也不作为重启后的速度基线。实际货损仍按上述相邻采样与事件去重规则执行。
