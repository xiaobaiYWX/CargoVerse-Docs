# 货柜核心能力数值

能力先影响实际运行数值，货物条件再读取数值计算损耗。按独立读数列出以下 8 项，不将“围护、密封”等能力名称放到货物需求列表中。

| 核心数值 | 单位／范围 |
| --- | --- |
| [有效围护等级](01_有效围护等级.md) | 整数 0～2 |
| [有效密封等级](02_有效密封等级.md) | 整数 0～2 |
| [内部温度](03_内部温度.md) | 有限 TU（游戏温度，不是摄氏度） |
| [内部气压](04_内部气压.md) | 非负相对压力系数，1 为参考压力 |
| [内部湿度](05_内部湿度.md) | 0～100 游戏湿度指数 |
| [内部光照](06_内部光照.md) | 0～15 整数亮度 |
| [速度变化](07_速度变化.md) | 格／游戏秒的速度向量差，非加速度／J |
| [内部承载面倾角](08_内部承载面倾角.md) | 0～180°，相对有效重力参考 |

源码 `TransportInteriorState` 按温度、气压、湿度、光照、内部结构分为五组，内部结构包含速度变化和承载面倾角；有效围护／密封为直接防护比较值。这是实现分组，不是“五个等级”或单一防护总分。每个实际读数在独立页面维护来源、公式和对应条件。

年龄、保存预算与暴露余数属于条件的生命周期账本，不另增加核心能力维度。缓冲当前通过提高速度差耐受起作用，不伪造缩小实测速度；应同时显示实际读数与最终耐受。
