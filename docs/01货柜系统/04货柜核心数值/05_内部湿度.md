# 内部湿度

核心数值的单位／范围：**0～100 游戏湿度指数**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

外部基础湿度为 `20+60×clamp(biome.downfall,0,1)`。当前世界有降水且当地群系降雨时至少 90，降雪时至少 80；按群系降水类型判断，**不看屋顶或货柜是否淋到雨**。以接口可用的中心／六邻域基础水检测将外部接触值提高到 100，不直接修改内部湿度。水接触优先；天气取下限，不反复叠加。不由温度推算湿度。

有效密封 0／1／2 的湿度差减半时间分别为 30 秒／5 分钟／20 分钟。`tau=H/ln(2)`，无主动输出时按 `H_next=H_out+(H_inside-H_out)×2^(-dt/HalfLife)`。主动控湿再叠加恒定每秒加湿／除湿输出。因此入水后密封和烘干仍有作用。
