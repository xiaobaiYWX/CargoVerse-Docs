# 内部温度

核心数值的单位／范围：**有限 TU（游戏温度，不是摄氏度）**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

外部温度取货柜实际世界位置：

```text
base = 20 + 20 × clamp(biome_temperature, -0.5, 2)
T_out = base + 10 × effective_sky_light / 15
```

显式维度基温配置替代 base。有效天空光受环境遮挡影响；水接触采用基温，火／岩浆热接触为 100 TU。**不检测淋雨，不做雨水降温**；湿度天气规则独立。

被动阀门使内部追随外部：基础时间常数 1200 tick，围护 0／1／2 倍率为 1／1.25／1.5。最终 `tau=max(围护基础tau, 真空隔层exchange_time_seconds×20)`，不乘积叠加。主动调温按货物目标给恒定增减量，与阀门共同求解。首次初始化取实际环境，不预冷；关闭仍被动演化。
