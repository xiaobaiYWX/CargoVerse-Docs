# 内部承载面倾角

核心数值的单位／范围：**0～180°，相对有效重力参考**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

真实倾角来自载具姿态与当地有效重力方向，通常随 20 tick 环境周期读取；零重力／无有效姿态时未知，不能补 0°。倾角与速度变化独立。

朝向保持已配备、自动开启、有正放需求且实际角度有效时，内部承载面近似 0°；这只是内部状态模型，不旋转载具。关闭则读取实际角度。严格超过货物阈值累计暴露，安全暂停并保留预算余数，未知／卸载不补算。
