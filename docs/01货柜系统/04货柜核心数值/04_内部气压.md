# 内部气压

核心数值的单位／范围：**非负相对压力系数，1 为参考压力**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

外部压力通过航空学 `DimensionPhysicsData.getAirPressure` 在货柜实际世界点读取。有效 0 正常判断；缺失或非有限值保持未知，不能用存储空间 Y 或玩家位置代替。

被动差值减半时间由有效密封决定：0 为 5 秒，1 为 15 秒，2 为 10 分钟。`tau=H/ln(2)`，无主动输出时：

```text
P_next = P_out + (P_inside-P_out) × 2^(-dt/H)
```

主动压力调节按自身支持方向、目标范围和恒定每秒速率工作，与密封控制的被动交换共同推进。压差不触发额外泄压或降低密封。
