# 内部光照

核心数值的单位／范围：**0～15 整数亮度**。这是运输运行时的判断量，不是新的物品条件 ID 或货柜能力声明。

## 来源与计算

每个环境周期（通常 20 tick）直接合成，不做渐变或时间惯性：

```text
transmitted = max(0, outside_light - light_blocking.reduction)
inside_light = max(transmitted, min(cargo_min_light, internal_lighting.max_light))
```

未配灯、无最低需求或设备关闭时不补光。灯只补最低值，不能降低过亮外光，也不再经壳体遮挡第二次。货物上下限可组合、分别累计暴露，共用一份内部亮度。
