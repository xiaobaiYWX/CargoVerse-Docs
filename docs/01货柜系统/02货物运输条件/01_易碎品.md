# 易碎品

货物运输条件 ID：`cargoverse:fragile`。判断对象：[速度变化](../04货柜核心数值/07_速度变化.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:fragile": {
    "max_velocity_change": 10,
    "damage_amount": 1
  }
}
```

## 判断与损耗

`max_velocity_change` 为正数，单位格／游戏秒；`damage_amount` 为正整数原生数量。每 10 tick 只取一次速度，两次向量差严格大于货物耐受＋缓冲增量时触发事件。持续超限只扣一次，一次安全比较后才允许新事件。急加速、急刹、等速急转与撞击等同；不检测自由落体。间隔内急停再恢复可能漏检，是接受的采样误差。

缓冲衬垫增加耐受，不改变采样速度、倾角或原始需求。玻璃现行基础耐受为 10，每事件损失 1 pcs；其他货物需单独校准。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
