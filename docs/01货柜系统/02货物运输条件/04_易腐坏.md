# 易腐坏

货物运输条件 ID：`cargoverse:perishable`。判断对象：[内部温度](../04货柜核心数值/03_内部温度.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:perishable": {
    "budget_ticks": 18000,
    "temperature_rates": {
      "breakpoints": [
        10,
        30
      ],
      "rates": [
        0.25,
        1,
        2
      ]
    },
    "preferred_temperature": 8,
    "loss": {
      "interval_ticks": 1200,
      "amount": 1
    }
  }
}
```

## 判断与损耗

`budget_ticks` 为正整数等效老化预算；`temperature_rates.breakpoints` 严格递增（最多 32 个），`rates` 比断点多一项且每项为有限正数，表示分段常量倍率。可选 `preferred_temperature` 参与自动调温。`loss` 仅含周期和原生扣量，不能再写 grace。

实际温度决定等效老化速度；保存预算用尽后再累计一个损耗周期才首次扣量。直接温度损伤期间抑制同源老化扣量。隔热仅减慢温度变化；主动调温按需求工作，不凭品牌或曲线自动授予永久保鲜。示例温区与倍率仅用于写法演示，须内容校准。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
