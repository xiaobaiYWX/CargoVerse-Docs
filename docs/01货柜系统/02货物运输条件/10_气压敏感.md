# 气压敏感

货物运输条件 ID：`cargoverse:pressure_sensitive`。判断对象：[内部气压](../04货柜核心数值/04_内部气压.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:pressure_sensitive": {
    "min_pressure": 0.8,
    "max_pressure": 1.2,
    "preferred_target": 1,
    "loss": {
      "grace_ticks": 600,
      "interval_ticks": 600,
      "amount": 1
    }
  }
}
```

## 判断与损耗

非负 `min_pressure`／`max_pressure` 至少写一项；范围不得倒置。可选 `preferred_target` 位于最终安全范围。边界相等安全，区间外累计损耗；有效零气压不是缺数据。

密封减慢内外交换，压力调节按自身支持方向、目标范围和速率主动增减。是否符合只看实际内部气压，配备或开启不代表立即达标。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
