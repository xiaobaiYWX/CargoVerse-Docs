# 粉料

货物运输条件 ID：`cargoverse:powder`。判断对象：[有效围护等级](../04货柜核心数值/01_有效围护等级.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:powder": {
    "loss": {
      "grace_ticks": 0,
      "interval_ticks": 1200,
      "amount": 1
    }
  }
}
```

## 判断与损耗

固定需要有效围护 ≥2。只写 `loss`，不写 `required_level`。运输运动期间围护不足时累计散失。

与碎料共占围护需求位置。红石粉可据细粉物性配置本条件；这说明需要围护 2，不把“围护等级”当成货物标签。是否还怕湿必须另配保持干燥，不能从粉料名称自动推出。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
