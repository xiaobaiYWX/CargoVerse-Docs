# 保持光照

货物运输条件 ID：`cargoverse:requires_light`。判断对象：[内部光照](../04货柜核心数值/06_内部光照.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:requires_light": {
    "min_light": 8,
    "loss": {
      "grace_ticks": 600,
      "interval_ticks": 600,
      "amount": 1
    }
  }
}
```

## 判断与损耗

`min_light` 为 0～15 整数；0 归一为无需求。严格低于下限才累计损耗。

内部照明仅补足最低需求并受灯具最大亮度限制；没有需求、关闭或未配灯时不补光。可以与避光上限组合，光照每个环境周期直接合成，不做渐变。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
