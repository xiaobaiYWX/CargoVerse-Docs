# 易挥发

货物运输条件 ID：`cargoverse:volatile`。判断对象：[有效密封等级](../04货柜核心数值/02_有效密封等级.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:volatile": {
    "loss": {
      "grace_ticks": 0,
      "interval_ticks": 1200,
      "amount": 1
    }
  }
}
```

## 判断与损耗

固定需要有效密封 ≥2。只写 `loss`，不写 `required_level`。有效密封不足时累计挥发，不要求货柜运动。

直接比较本次冻结的密封等级；内外压差不改变此项保护。液体柜液密 1 不等于满足易挥发 2；普通液体不自动加易挥发，也不因气体形态自动加毒性或易燃。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
