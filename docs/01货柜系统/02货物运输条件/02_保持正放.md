# 保持正放

货物运输条件 ID：`cargoverse:keep_upright`。判断对象：[内部承载面倾角](../04货柜核心数值/08_内部承载面倾角.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:keep_upright": {
    "max_tilt_degrees": 15,
    "loss": {
      "grace_ticks": 60,
      "interval_ticks": 100,
      "amount": 1
    }
  }
}
```

## 判断与损耗

`max_tilt_degrees` 在 0～180°；严格超过才累计暴露。180° 归一为无约束；0° 是有效的严格正放要求，不表示关闭。

朝向保持在有效观测、自动开启及有正放需求时将内部承载面近似为 0°，不转动物理载具，也不免除冲击。无有效重力参考时倾角未知，不补成 0°。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
