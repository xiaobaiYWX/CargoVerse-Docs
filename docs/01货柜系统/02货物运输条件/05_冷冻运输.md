# 冷冻运输

货物运输条件 ID：`cargoverse:frozen_transport`。判断对象：[内部温度](../04货柜核心数值/03_内部温度.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:frozen_transport": {
    "max_temperature": 0,
    "preferred_target": -5,
    "loss": {
      "grace_ticks": 600,
      "interval_ticks": 600,
      "amount": 1
    }
  }
}
```

## 判断与损耗

`max_temperature` 为有限 TU 上限；可选 `preferred_target` 必须位于最终安全温区。严格超上限才累计损耗。

与高温敏感共占 `temperature.max`，不能同时声明；可以与低温敏感组合安全温区。隔热保留当前内部冷量，主动调温提供降温；外界寒冷也能满足条件，不要求特定品牌。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
