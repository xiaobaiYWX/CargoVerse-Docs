# 低温敏感

货物运输条件 ID：`cargoverse:cold_sensitive`。判断对象：[内部温度](../04货柜核心数值/03_内部温度.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:cold_sensitive": {
    "min_temperature": 5,
    "preferred_target": 10,
    "loss": {
      "grace_ticks": 600,
      "interval_ticks": 600,
      "amount": 1
    }
  }
}
```

## 判断与损耗

`min_temperature` 为有限 TU 下限；可选 `preferred_target` 必须处于组合后的安全范围。严格低于下限才累计损耗。

可与一个温度上限组合，两个方向各有独立损耗预算，共用一份内部温度。过度制冷也会触发低温损伤，不能以有制冷设备代替真实温度判断。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
