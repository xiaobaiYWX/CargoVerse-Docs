# 保持干燥

货物运输条件 ID：`cargoverse:keep_dry`。判断对象：[内部湿度](../04货柜核心数值/05_内部湿度.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:keep_dry": {
    "max_humidity": 50,
    "preferred_target": 40,
    "loss": {
      "grace_ticks": 2400,
      "interval_ticks": 1200,
      "amount": 1
    }
  }
}
```

## 判断与损耗

`max_humidity` 为 0～100 的湿度指数；可选 `preferred_target` 必须落在最终安全范围。内部湿度严格超上限时累计损耗。

密封减慢内外交换，湿度控制提供恒定加湿／除湿输出。群系降水修正不判断货柜是否有屋顶，入水提高外部湿度而非瞬间浸满内部；液态水接触旧规则与湿度不能未经审查同源双扣。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
