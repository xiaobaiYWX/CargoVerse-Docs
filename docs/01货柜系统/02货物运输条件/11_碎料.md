# 碎料

货物运输条件 ID：`cargoverse:fragments`。判断对象：[有效围护等级](../04货柜核心数值/01_有效围护等级.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:fragments": {
    "loss": {
      "grace_ticks": 0,
      "interval_ticks": 1200,
      "amount": 1
    }
  }
}
```

## 判断与损耗

固定需要有效围护 ≥1。只写 `loss`，不写 `required_level`。运输运动期间围护不足时累计散失；静止不按此项散失。

与粉料共占同一围护需求位置，不得同时声明。围护 1 和 2 均可满足碎料需求，不附带密封或免碰撞。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
