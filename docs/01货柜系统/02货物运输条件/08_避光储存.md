# 避光储存

货物运输条件 ID：`cargoverse:light_sensitive`。判断对象：[内部光照](../04货柜核心数值/06_内部光照.md)。本条件属于货物，不声明货柜设备。

## 声明

以下片段放入物品／流体属性的 `transport_conditions`；数值只演示参数写法，不代表该条件对所有物品的正式取值。

```json
{
  "cargoverse:light_sensitive": {
    "max_light": 5,
    "loss": {
      "grace_ticks": 600,
      "interval_ticks": 600,
      "amount": 1
    }
  }
}
```

## 判断与损耗

`max_light` 为 0～15 整数；15 归一为无约束，0 则是有效的严格避光上限。严格超限才累计损耗。

遮光结构削减外部传入亮度；灯具不能降低过亮外光。可以与保持光照组合，区间不得倒置，两个方向分别累计暴露。

时间预算、首次扣量与原生 pcs／mB 约定见[通用配置](../01核心系统/15_运输类型与参数.md#共用损耗)。未声明即无此需求；零边界按本项定义解释，不能统一当作关闭。新装冻结，装卸、追加和重启不得洗掉已累计状态。
