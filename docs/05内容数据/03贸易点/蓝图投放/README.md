# 货柜制造台定义与当前投放

本目录维护贸易点蓝图打印目录。材料托管和逐层施工设备见[货柜搭建器](<../../../03组件手册/货柜施工/01_货柜搭建器.md>)；独立配方使用`cargo_manufacturing_recipes`目录，搭建器不继承贸易点繁荣度或VB打印费。

更新：2026-11-05。系统使用 schema 3 投放表，打印费读取独立配方的`blueprint_cost`；打印检查许可和繁荣度，调度点与材料在搭建器开工时检查。定影器存取与表面UI见[蓝图打印机](<../../../04数据规范/贸易点/05_货柜制造台定义.md>)。

正式目录共 95 条投放，覆盖 57 款（含8款基础型）。A／B 另提供 Reliquary 两款及 BioPod 三款，共 62 款。

[当前材料、费用、门槛与投放总表](<制造配方与投放总表.md>) · [现行型号与实际结构](<../../02货柜/README.md>)

当前投放、材料、费用和门槛以总表与运行 JSON 为准。

材料的唯一维护入口为[独立货柜制造配方](<../../../04数据规范/货柜/02_制造配方.md>)。本目录只维护蓝图目录投放和门槛，表中的材料是共用配方的查阅投影。
