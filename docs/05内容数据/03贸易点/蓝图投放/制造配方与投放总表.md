# 货柜制造材料与投放

三层材料已于2026-11-26写入73个已开放制造配方（65个普通型号、8个基础权益型）。制造时间、费用、许可、声望门槛及货柜能力保持原值；普通型号由八家站点和A/B测试打印目录引用；8款初始型号仅在注册时赠图，保留独立制造配方。逐型号正式页同步维护现行材料。

## 主材料、辅材料、特殊材料

- 主材料：固体柜和生物柜统一铁锭，液罐统一铜锭。材质跟随主体结构，不跟随制冷、缓冲等能力改变。S基准32件；M/L/X/XL为64/128/256/512件。
- 辅材料：限定标准紧固件箱、工业构件箱、密封接头组。常规柜S基准紧固件8件＋构件4件；SPL构件2件，DMC/BDS构件6件；液罐为紧固件8件＋密封接头4件。生物柜使用铁制框架的常规辅材。
- 特殊材料：实现新增保护功能，每种S基准1～4件。普通柜允许没有特殊材料，不为凑齐三栏硬加材料。按当前型号核算，主材料数量大于辅材料合计，辅材料合计大于特殊材料合计；这是清单数量关系，不代表材料价值或质量关系。

所有材料用量按尺寸×1/2/4/8/16。独立初始系列为紧凑S型：铁锭16、紧固件4、工业构件2，无能力和特殊材料；不再按旧普通系列副本计料。结构NBT中的玻璃、木质装饰不逐块反算配方。玻璃仅可成为光学组件的生产原料，不再成为每个柜的固定材料。

## 能力对应与去重

| 能力/结构 | S基准材料 | 处理 |
| --- | --- | --- |
| 基础围护、防雨、遮光 | 已包含在主辅材 | 普通封闭壳体不重复加料 |
| 缓冲1/2/3 | 缓冲组件1/2/4 | 按实际能力等级 |
| 保持正放 | 校准陀螺仪箱1 | 与缓冲功能不同 |
| 调温 | 调温机组1 | 不额外加入冷却液桶 |
| 稳压 | 稳压组件1 | 不与气压样品混用 |
| 真空隔层 | 高纯陶瓷粉2 | 为隔层支撑/隔热填料，不是创造真空的独立机器 |
| 固体柜专项密封 | 密封接头组2 | 液罐基础辅材已含，不再收费 |
| 内部照明 | 光学镜片箱1 | 作为灯具透光/匀光组件，壳内接线计入结构件 |
| 生物舱环境设备 | 生命维持组件2 | 集成温控、稳压、密封、隔热、一级缓冲；只对更高缓冲额外收1组件 |

这张表是本轮内容编写规则，不是新增运行时推导系统。配方逐ID保存在item_costs。同用途材料取一次，不根据词条个数机械累加；新增能力重新审查材料作用和成本。
