# 乡野机修所 · 贸易点定义

## 当前状态

整站结构、经济定义、绑定及生成配置已接入；正式货物买卖表已接入，报价与库存见本站资源表。地形、装卸与营业流程仍待实机验收。

## 身份与定位

编号 **G10**；归属 **独立经营（无制造商）**；资源 ID `cargoverse:factory/ground_station/rural_repair_shop`。

**轻型维修耗材与传动备件。** 独立作坊提供新扳手、砂纸与通用轴齿轮，收购金属板、合金和齿轮箱。当前精确变体报价不能表达任意损坏工具收购，因此不承诺修复或拆解服务。

本站保持地方集货和有限消费，不设制造、注册、领柜功能，也不成为天空站的附属库存。
