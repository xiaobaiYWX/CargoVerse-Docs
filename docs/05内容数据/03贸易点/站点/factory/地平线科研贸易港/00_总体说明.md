# 地平线科研贸易港

HRI 所属天空贸易点。经营定义：`cargoverse:factory/sky_station/precision_center`。本站有三套建筑变体，共用交易列表、升级供应、蓝图目录和生成规则；每个生成实例独立保存库存、额度与繁荣度。

| 制造商背景 | [HRI](../../../../04配套内容/制造商/hri.md) |
