# 绿洲生物工程站 · 生成规则

归入 **绿洲农业贸易港**。先按站型权重抽取，再在三套建筑模板中等权抽取，各占1/3。绑定 `cargoverse:factory/sky_station/biosystems_station`。

| 参数 | 值 |
| --- | --- |
| 结构 ID | `cargoverse:trade_point/factory/sky_station/biosystems_station` |
| 天空结构集权重 | 48／312 |
| 间距／最小分离 | 32／24 区块 |
| 起始高度 | 192～208 |
| 地形适配 | none |

群系合并原三站范围：minecraft:jungle、minecraft:sparse_jungle、minecraft:bamboo_jungle、minecraft:flower_forest、minecraft:mangrove_swamp、minecraft:mushroom_fields、minecraft:dark_forest、minecraft:river、minecraft:swamp、minecraft:ocean、minecraft:lukewarm_ocean、minecraft:warm_ocean、minecraft:plains、minecraft:sunflower_plains、minecraft:forest、minecraft:birch_forest、minecraft:old_growth_birch_forest、minecraft:taiga、minecraft:meadow。实际生成概率受群系筛选影响。

随机变体：`/place structure cargoverse:trade_point/factory/sky_station/biosystems_station`。

仅查看本建筑：`/place template cargoverse:trade_points/factory/sky_station/biosystems_station`。此指令只放模板，不等同于结构生成注册。
