# 净水与环境处理站 · 生成规则

归入 **赫利俄斯能源贸易港**。先按站型权重抽取，再在三套建筑模板中等权抽取，各占1/3。绑定 `cargoverse:factory/sky_station/chemical_works`。

| 参数 | 值 |
| --- | --- |
| 结构 ID | `cargoverse:trade_point/factory/sky_station/chemical_works` |
| 天空结构集权重 | 60／312 |
| 间距／最小分离 | 32／24 区块 |
| 起始高度 | 192～208 |
| 地形适配 | none |

群系合并原三站范围：minecraft:desert、minecraft:badlands、minecraft:eroded_badlands、minecraft:stony_shore、minecraft:savanna、minecraft:taiga、minecraft:old_growth_pine_taiga、minecraft:cold_ocean、minecraft:deep_cold_ocean、minecraft:snowy_taiga、minecraft:frozen_ocean、minecraft:river、minecraft:frozen_river、minecraft:swamp、minecraft:mangrove_swamp、minecraft:beach、minecraft:ocean、minecraft:lukewarm_ocean、minecraft:warm_ocean、minecraft:deep_lukewarm_ocean。实际生成概率受群系筛选影响。

随机变体：`/place structure cargoverse:trade_point/factory/sky_station/chemical_works`。

仅查看本建筑：`/place template cargoverse:trade_points/factory/sky_station/reclamation_station`。此指令只放模板，不等同于结构生成注册。
