## 指令生成

`/place structure cargoverse:trade_point/factory/sky_station/biosystems_station`

该指令走结构生成与经营绑定流程，随机选择本站建筑。单独查看模板可使用下列指令，但它们不等同于结构生成注册：

- 梯田农林站：`/place template cargoverse:trade_points/resource/sky_station/terrace_farm`。
- 云泽水产与育种站：`/place template cargoverse:trade_points/resource/sky_station/aquaculture_station`。
- 绿洲生物工程站：`/place template cargoverse:trade_points/factory/sky_station/biosystems_station`。

自然分布、高空净空和运行设备仍需新生成区块实机验证，静态参数对账不代替实机验收。

## 密度调整（2026-11-28）

天空站候选网格边长为 96 区块（1536 格），候选通过率为 75%。同组候选区块起点的理论最小水平距离为 73 区块（1168 格），不是建筑边缘距离或不可见保证。群系／结构过滤前的期望候选密度约为原 32 区块、100% 配置的 1/12。

本站的群系、集内权重、起始高度、结构模板与经营内容沿用现值。频率作用于共享候选点，不是每个群系或每个站型分别追加一次生成机会。天空与地面两组仍独立，不承诺跨组最小间距。仅对新生成区块生效，既有站点不会自动清理；测试新旧区块交界时可能仍看到密集站点。
