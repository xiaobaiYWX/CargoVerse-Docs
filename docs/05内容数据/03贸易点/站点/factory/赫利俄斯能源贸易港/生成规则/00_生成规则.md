## 指令生成

`/place structure cargoverse:trade_point/factory/sky_station/chemical_works`

该指令走结构生成与经营绑定流程，随机选择本站建筑。单独查看模板可使用下列指令，但它们不等同于结构生成注册：

- 赫利俄斯燃料供应站：`/place template cargoverse:trade_points/factory/sky_station/fuel_depot`。
- 工业化学品供应站：`/place template cargoverse:trade_points/factory/sky_station/chemical_works`。
- 净水与环境处理站：`/place template cargoverse:trade_points/factory/sky_station/reclamation_station`。

自然分布、高空净空和运行设备仍需新生成区块实机验证，静态参数对账不代替实机验收。
