## 指令生成

`/place structure cargoverse:trade_point/factory/sky_station/airship_yard`

该指令走结构生成与经营绑定流程，随机选择本站建筑。单独查看模板可使用下列指令，但它们不等同于结构生成注册：

- 标准建材装配港：`/place template cargoverse:trade_points/factory/sky_station/standard_assembly`。
- 通用机电装备厂：`/place template cargoverse:trade_points/factory/sky_station/modular_equipment`。
- 飞艇总装与航修港：`/place template cargoverse:trade_points/factory/sky_station/airship_yard`。

自然分布、高空净空和运行设备仍需新生成区块实机验证，静态参数对账不代替实机验收。
