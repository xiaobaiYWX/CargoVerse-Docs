# 通用机电装备厂 · 生成规则

归入 **天穹工业贸易港**。先按站型权重抽取，再在三套建筑模板中等权抽取，各占1/3。绑定 `cargoverse:factory/sky_station/airship_yard`。

| 参数 | 值 |
| --- | --- |
| 结构 ID | `cargoverse:trade_point/factory/sky_station/airship_yard` |
| 天空结构集权重 | 36／312 |
| 间距／最小分离 | 32／24 区块 |
| 起始高度 | 192～208 |
| 地形适配 | none |

群系合并原三站范围：minecraft:plains、minecraft:savanna、minecraft:beach、minecraft:stony_shore、minecraft:ocean、minecraft:deep_ocean、minecraft:windswept_savanna、minecraft:forest、minecraft:birch_forest、minecraft:taiga、minecraft:old_growth_pine_taiga、minecraft:sunflower_plains、minecraft:savanna_plateau。实际生成概率受群系筛选影响。

随机变体：`/place structure cargoverse:trade_point/factory/sky_station/airship_yard`。

仅查看本建筑：`/place template cargoverse:trade_points/factory/sky_station/modular_equipment`。此指令只放模板，不等同于结构生成注册。
