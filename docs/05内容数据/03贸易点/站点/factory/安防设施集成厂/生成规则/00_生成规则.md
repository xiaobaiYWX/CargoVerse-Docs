# 安防设施集成厂 · 生成规则

归入 **铁壁防务贸易港**。先按站型权重抽取，再在三套建筑模板中等权抽取，各占1/3。绑定 `cargoverse:factory/sky_station/defense_arsenal`。

| 参数 | 值 |
| --- | --- |
| 结构 ID | `cargoverse:trade_point/factory/sky_station/defense_arsenal` |
| 天空结构集权重 | 36／312 |
| 间距／最小分离 | 32／24 区块 |
| 起始高度 | 192～208 |
| 地形适配 | none |

群系合并原三站范围：minecraft:taiga、minecraft:snowy_taiga、minecraft:savanna_plateau、minecraft:stony_shore、minecraft:plains、minecraft:savanna、minecraft:forest、minecraft:windswept_forest、minecraft:snowy_plains、minecraft:grove、minecraft:frozen_ocean、minecraft:deep_frozen_ocean、minecraft:frozen_river、minecraft:snowy_beach、minecraft:ice_spikes、minecraft:windswept_hills、minecraft:windswept_savanna。实际生成概率受群系筛选影响。

随机变体：`/place structure cargoverse:trade_point/factory/sky_station/defense_arsenal`。

仅查看本建筑：`/place template cargoverse:trade_points/factory/sky_station/security_works`。此指令只放模板，不等同于结构生成注册。
