# 测试贸易点 B

> **已接入 · 仅限指令测试：** 不参与自然生成，不计入自然贸易点的经济与生成统计。使用新实例验证，旧测试点不会自动变成 A／B。

复用云港民生集配站的完整天空模板。本站出售 93 种、收购 102 种精确商品身份，与对站互补；覆盖固体、液体和生物。报价、库存及许可证经验按本站[资源表](../../../交易列表/market/test_station/b.md)执行。

两站共用65款普通货柜的蓝图打印目录；8款初始货柜由对应制造商注册赠图，不在打印目录中。材料与加工费见共享制造目录，制造仍执行正常许可和资产上限校验。测试身份沿用云港物流集团，跨品牌目录不代表正式站的经营范围。
