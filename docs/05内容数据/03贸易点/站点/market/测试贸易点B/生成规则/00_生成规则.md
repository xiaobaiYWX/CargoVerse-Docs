# 测试贸易点 B · 生成规则

> **已接入 · 仅限指令测试：** 不参与自然生成，不计入 40 个正式贸易点的经济与生成统计。使用新实例验证，旧测试点不会自动变成 A／B。

| 项目 | 当前值 |
| --- | --- |
| 世界结构 | `cargoverse:trade_point/market/test_station/b` |
| 起始池 | `cargoverse:trade_point/market/test_station/b/start` |
| 模板 | `cargoverse:trade_points/market/sky_station/civic_distributionw` |
| 结构集 | 无；不得加入任何自然生成 structure_set |
| 起始高度 | absolute=192；固定高度，未投影到地表 |
| terrain_adaptation | none |
| size／投影 | 1／rigid |

在主世界、开启作弊或具有操作员权限时执行。建议两站横向相隔至少 256 格，避开已有建筑：

```mcfunction
/place structure cargoverse:trade_point/market/test_station/b ~ ~ ~
```

使用世界结构指令完成经济绑定；直接加载 NBT 模板不会建立 A／B 的业务实例。起始高度由结构定义控制，指令的 Y 参数不用于改变固定高度；生成后飞到天空平台检查信息柜。

首次测试先在注册终端注册。需要查看全部许可证柜型时，注册后执行 `/cargoverse license set XL`；备齐配方材料和 VB 加工费。既有调度点、货柜类别、防护及生成净空规则仍有效。

从本站购买出售货物，运至 A 站卸货；返程改装对站出售的另一组货物。验证库存扣减、资金结算与运输状态。两站收购虽然配置了经验，但指令创建的目的地不具备自然生成身份，正常往返经验应为 0；不要以此判定自然运输奖励失效。测试跨日补货可执行 `/cargoverse trade_point advance <实例UUID> 1`，参数使用实例 UUID，不是经济定义资源 ID。重载资源后仍应创建新实例验证目录。
