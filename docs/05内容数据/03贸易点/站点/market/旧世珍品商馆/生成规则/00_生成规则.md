# 旧世珍品商馆 · 生成规则

归入 **遗民遗产贸易港**。先按站型权重抽取，再在三套建筑模板中等权抽取，各占1/3。绑定 `cargoverse:resource/sky_station/remnant_exchange`。

| 参数 | 值 |
| --- | --- |
| 结构 ID | `cargoverse:trade_point/resource/sky_station/remnant_exchange` |
| 天空结构集权重 | 3／312 |
| 间距／最小分离 | 32／24 区块 |
| 起始高度 | 192～208 |
| 地形适配 | none |

群系合并原三站范围：minecraft:flower_forest、minecraft:cherry_grove、minecraft:old_growth_birch_forest、minecraft:dark_forest、minecraft:deep_frozen_ocean、minecraft:ice_spikes、minecraft:mushroom_fields、minecraft:deep_ocean、minecraft:deep_lukewarm_ocean、minecraft:warm_ocean、minecraft:eroded_badlands。实际生成概率受群系筛选影响。

随机变体：`/place structure cargoverse:trade_point/resource/sky_station/remnant_exchange`。

仅查看本建筑：`/place template cargoverse:trade_points/market/sky_station/heritage_gallery`。此指令只放模板，不等同于结构生成注册。
