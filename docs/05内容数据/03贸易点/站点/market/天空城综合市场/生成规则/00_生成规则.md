# 天空城综合市场 · 生成规则

归入 **云港综合贸易港**。先按站型权重抽取，再在三套建筑模板中等权抽取，各占1/3。绑定 `cargoverse:market/sky_station/skycity_market`。

| 参数 | 值 |
| --- | --- |
| 结构 ID | `cargoverse:trade_point/market/sky_station/skycity_market` |
| 天空结构集权重 | 60／312 |
| 间距／最小分离 | 32／24 区块 |
| 起始高度 | 192～208 |
| 地形适配 | none |

群系合并原三站范围：minecraft:plains、minecraft:sunflower_plains、minecraft:forest、minecraft:birch_forest、minecraft:taiga、minecraft:snowy_plains、minecraft:savanna、minecraft:ocean、minecraft:deep_ocean、minecraft:cold_ocean、minecraft:deep_cold_ocean、minecraft:lukewarm_ocean、minecraft:deep_lukewarm_ocean、minecraft:stony_shore、minecraft:beach、minecraft:snowy_beach、minecraft:flower_forest、minecraft:cherry_grove、minecraft:meadow。实际生成概率受群系筛选影响。

随机变体：`/place structure cargoverse:trade_point/market/sky_station/skycity_market`。

仅查看本建筑：`/place template cargoverse:trade_points/market/sky_station/skycity_market`。此指令只放模板，不等同于结构生成注册。
