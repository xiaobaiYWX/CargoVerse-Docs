# 野地居民点 · 贸易点定义

## 当前状态

整站结构、经济定义、绑定及生成配置已接入；正式货物买卖表已接入，报价与库存见本站资源表。地形、装卸与营业流程仍待实机验收。

## 身份与定位

编号 **G07**；归属 **独立经营（无制造商）**；资源 ID `cargoverse:market/ground_station/wilderness_settlement`。

**居民消费与乡间副业。** 出售羊毛、皮革和鸡蛋等家庭副业产品，收购口粮、建材、照明和日用品。水泵属于少量设施更新需求，不让定居点变成工业整机买方。

本站保持地方集货和有限消费，不设制造、注册、领柜功能，也不成为天空站的附属库存。

## 功能模块

```json

```

空对象表示本站不提供额外模块；模块和结构设备不能互相替代。

所有设备绑定同一实例 UUID；装载机、卸载机及定位点按发布结构中的范围工作。收购不触发制造或邻站库存转化；繁荣成长不会自动扩建站点。
