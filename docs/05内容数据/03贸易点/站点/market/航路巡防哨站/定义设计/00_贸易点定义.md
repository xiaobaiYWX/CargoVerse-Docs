# 航路巡防哨站 · 贸易点定义

## 当前状态

整站结构、经济定义、绑定及生成配置已接入；正式货物买卖表已接入，报价与库存见本站资源表。地形、装卸与营业流程仍待实机验收。

## 身份与定位

编号 **G08**；归属 **铁壁防务集团（BDS）**；资源 ID `cargoverse:market/ground_station/route_watchpost`。

**巡防消耗与少量回程材料。** BDS 派驻哨提供少量羽毛、燧石和金属零料，需求集中在箭、盾、通信和生活补给。零料低值低经验，不冒称损坏装备被自动拆解。

本站保持地方集货和有限消费，不设制造、注册、领柜功能，也不成为天空站的附属库存。
