# 贸易点商品与供给设计

2026-11-25 同步。专用产业物资承担大宗贸易，建筑成品支持建设，基础资源维持少量补给。

| 供给类型 | 小站初始／上限／日补 | 大站初始／上限／日补 |
| --- | --- | --- |
| 基础物资 | 1／2／1 组 | 2／4／1 组 |
| 建筑成品 | 64／256／64 组 | 256／1024／256 组 |
| 通用与单条件物资 | 128／256／64 份 | 2048／4096／1024 份 |
| 复合条件与部件 | 32／64／16 份 | 512／1024／256 份 |
| 生物补给 | 2／4／1 只 | 2／4／1 只 |

普通物品收购限额小站至多16组／日，大站至多64组／日。专用物资在大站通常不限收购，小站限256份，复合条件货物与部件限小站64份、大站1024份。普通无条件专用品基价16VB、单条件32VB、双条件64VB、部件48VB，按组或桶报价。对应收购溢价为4、12、24VB，部件按条件数量计算。基础物资供给按单站计，多站采购可累积。

精密机构、成套加工机器、烈焰生产物及升力关键矿料退出自然站出售，其采购需求继续存在。建筑白名单包含石砖、裂纹石砖、苔石、砖、玻璃、方解石和选定装饰成品。新增可逆拆解或加工配方时需复核。
