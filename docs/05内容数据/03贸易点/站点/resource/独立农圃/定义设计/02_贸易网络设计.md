## 按经营功能设计的交易表（候选）

小农户出售自种菜和鸡蛋，补进肥料、种子与农具。

以下方向均从本站看。现行报价仍在下文及本站资源表中，本表供确定下一版商品范围。

| 方向 | 品类 | 候选商品 ID | 经营依据 |
| --- | --- | --- | --- |
| 收购 | 补种与维护 | `minecraft:wheat_seeds`、`minecraft:bone_meal`、`minecraft:iron_hoe` | 种子与肥料可持续消耗，锄头只设少量日需求。 |
| 出售 | 当季农货 | `minecraft:potato`、`minecraft:carrot`、`minecraft:egg` | 根茎作物有日常库存，鸡蛋来自小规模养殖。 |
| 出售 | 家禽 | `minecraft:chicken` | 按只少量供货，单只占 1 舱位。 |

农圃以原料和鲜货为主，梯田站承担集货与食品加工。小站的出售库存、日补和收购日限额分别设置。

自然站活体供应已接入：使用 living 与只数报价，有限库存、每日补货和云港收购去向见[自然站活体交易](../../../../自然站活体交易.md)。

## 经营身份与职责

编号 **G03**；归属 **独立经营（无制造商）**；资源 ID `cargoverse:resource/ground_station/independent_farmstead`。

**地方谷物与蔬菜供应。** 独立农户以三种普通作物形成稳定货源；收购肥料、锄头和传动维修件，不提供整条农业生产线。

本站保持地方集货和有限消费，不设制造、注册、领柜功能，也不成为天空站的附属库存。

## 业务边界

- 收购不增加本站库存，也不驱动本站产出；出售仅按本站库存与日补工作。
- 不将“废料”“设备”“研究样本”等用途名称作为额外货物身份；以实际物品 ID 和完整状态交接。
- 不设置全品类通吃目录。同站同一默认变体只经营一个方向，昂贵装备、研究与收藏需求有独立限额。
- 本轮不涉及流体、实体、带药效药水、装有内容的容器或任意损坏装备；它们需要明确的载荷支持或组件报价设计。
- 相同类别不代表相同报价，也不赋予市场资格。玩家自产货物在自然生成目的地成功出售时，也按本地收购配置获得许可证与繁荣度经验。
