# 虚空相位研究站 · 生成规则

归入 **地平线科研贸易港**。先按站型权重抽取，再在三套建筑模板中等权抽取，各占1/3。绑定 `cargoverse:factory/sky_station/precision_center`。

| 参数 | 值 |
| --- | --- |
| 结构 ID | `cargoverse:trade_point/factory/sky_station/precision_center` |
| 天空结构集权重 | 21／312 |
| 间距／最小分离 | 32／24 区块 |
| 起始高度 | 192～208 |
| 地形适配 | none |

群系合并原三站范围：minecraft:meadow、minecraft:cherry_grove、minecraft:birch_forest、minecraft:old_growth_birch_forest、minecraft:windswept_forest、minecraft:jungle、minecraft:sparse_jungle、minecraft:bamboo_jungle、minecraft:old_growth_spruce_taiga、minecraft:grove、minecraft:mushroom_fields、minecraft:dark_forest、minecraft:deep_frozen_ocean、minecraft:ice_spikes、minecraft:deep_ocean、minecraft:deep_cold_ocean。实际生成概率受群系筛选影响。

随机变体：`/place structure cargoverse:trade_point/factory/sky_station/precision_center`。

仅查看本建筑：`/place template cargoverse:trade_points/resource/sky_station/phase_station`。此指令只放模板，不等同于结构生成注册。
