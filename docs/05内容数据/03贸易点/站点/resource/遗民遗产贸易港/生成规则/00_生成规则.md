## 指令生成

`/place structure cargoverse:trade_point/resource/sky_station/remnant_exchange`

该指令走结构生成与经营绑定流程，随机选择本站建筑。单独查看模板可使用下列指令，但它们不等同于结构生成注册：

- 遗民打捞交换所：`/place template cargoverse:trade_points/resource/sky_station/remnant_exchange`。
- 旧世珍品商馆：`/place template cargoverse:trade_points/market/sky_station/heritage_gallery`。
- 远界异常交换站：`/place template cargoverse:trade_points/resource/sky_station/far_reach_exchange`。

自然分布、高空净空和运行设备仍需新生成区块实机验证，静态参数对账不代替实机验收。
