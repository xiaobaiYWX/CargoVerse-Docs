# 地层采样站 · 贸易点定义

## 当前状态

整站结构、经济定义、绑定及生成配置已接入；正式货物买卖表已接入，报价与库存见本站资源表。地形、装卸与营业流程仍待实机验收。

## 身份与定位

编号 **G05**；归属 **地平线研究院（HRI）**；资源 ID `cargoverse:resource/ground_station/stratigraphic_sampling_station`。

**地层矿物样本与调查耗材。** HRI 派驻采样队提供安山岩、方解石和燧石；采购便携观测与少量钻探设备，物资规模小于天空科研站。

本站保持地方集货和有限消费，不设制造、注册、领柜功能，也不成为天空站的附属库存。
