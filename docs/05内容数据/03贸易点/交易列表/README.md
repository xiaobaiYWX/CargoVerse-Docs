# 自然贸易点货物交易表

当前为8个制造商天空主站、16个地面小站及A／B指令测试站。天空建筑变体共用主站资源表，每个生成实例独立保存库存与额度。自然站共221条出售、389条收购；详细参数只在各站表维护。

先读[贸易网络与定价设计](../站点/设计总览.md)，字段语义见[资源表定义](../../../04数据规范/贸易点/03_资源表定义.md)。
