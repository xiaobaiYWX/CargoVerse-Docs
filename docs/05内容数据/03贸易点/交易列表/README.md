# 自然贸易点货物交易表

40 个自然站采用 149 种可装柜物品，共 189 条出售和 315 条收购。A／B 互补提供全部 149 种物品及 9 种流体主体。单位为整组物品或一桶流体，库存、日补、限额、单价及经验均按份配置。
