# 新版货柜模板系列代号（G2）

确定日期：2026-11-12。全部系列统一采用 **`原系列英文名_g2`** 作为新版模板系列代号。产品品牌和中文系列名保留；G2表示第二代结构资产，不表示许可证等级、接口等级或运输能力提升。

## 使用规则

- 新版示例：`cargoverse:cargo/aui/atlas_g2/aui_atlas_g2_sd_s`；NBT为 `aui_atlas_g2_sd_s.nbt`。目录与文件名都含g2，导出不会覆盖旧模板。
- 保留既有货柜定义ID、series标签、制造配方和运行template；本轮只分配制作代号。新模板逐款验收后再切换引用，不重命名已有NBT或删除旧资源。
- 基础型共用普通型号模板，不制作starter专属副本。旧兼容ID仅记录归属，不构成新产品。
- 实际规格按size_class，不能根据旧定义后缀推断。Apollo的旧s／m／l定义实际是M／L／X。
- 接口代号沿既定系列命名保留；统一长宽高、轨距、接口坐标和净空尚未确定。G2命名本身不意味着已经满足标准化机械规格。
- HEC旧版授权分配仅用于现行资产：Apollo用Reactor HD，Boreas用Apollo SD。新版分别独立使用apollo_g2_hd与boreas_g2_sd，不继续混用历史家族名称。

覆盖 23 个系列、90 个现有定义，合计 72 个不重复的G2规格路径。其中 **65 份属于当前产品线重制或已确定待模板型号**；另外 7 份仅预留，不要求制作。全部新版尚未接入。

## 导出目录

结构方块内填写系列页列出的完整资源ID。导出后的存档相对路径为：

```text
generated/cargoverse/structures/cargo/<制造商>/<系列>_g2/<制造商>_<系列>_g2_<接口>_<实际规格>.nbt
```

工程接入路径为 `data/cargoverse/structure/cargo/...`。每个型号页提供完整路径；不需要同时维护另一份草案。数值对比仍见[货柜信息表](型号能力与结构质量.md)。
