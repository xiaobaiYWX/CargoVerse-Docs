# HEC Boreas 温控液罐

**正式产品线。核对：2026-11-06。**

**本系列缺失规格：M、L。** 有同系列 NBT 但引用错误：无。

## 产品定位

温敏工业液体批量运输，不再设独立气体柜。主要取舍：空重高，无主动稳压。
