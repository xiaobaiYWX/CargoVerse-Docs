# 货柜制作与实运验收

固体容量按单件，流体按桶、生物按舱位。各系列的能力组合及数值见[货柜对比](型号能力与结构质量.md)。

实机验证应覆盖以下情形。

- 普通 S 柜分别装满64堆叠、16堆叠和不可堆叠物品，三者均以4096件为容量上限，操作步长分别为64、16和1件。
- 每件0.1 Kpg的4096件货物共重409.6 Kpg，测量实际空重、满载起吊、对接与转弯。结构质量仍构成空重下限。
- 光学镜片对照普通柜与Hermes，飞控总成对照Hermes与Sentinel，验证缓冲及正放分别生效。
- 高纯陶瓷粉对照Silo与Vulcan，分别观察粉料围护和降雨防水保护。
- 育苗托盘使用Harvest的内部照明；保温发酵料和冷冻菌种使用主动调温；易析晶试剂与热敏蜡使用真空隔层。
- 冷冻校准试剂使用Explorer的调温和气压保护，分别验证关闭或缺少一种能力后的风险。
- 比较Cistern、Boreas、Crucible的液体运输，比较BioPod与Aquarium的舱位和冲击保护。
- 以新建自然站测试库存、每日补货、收购额度和繁荣解锁；验证A／B商品分组互补。既有站点保存报价快照。

本轮数据和自动检查通过情况应与实机验证分别记录，自动检查无法确认载具动力是否足够。
