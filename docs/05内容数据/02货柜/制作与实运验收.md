# 货柜制作与实运验收

货柜的公共制作与运输验收在本页统一维护；型号是否开放、模板是否缺失仍见[型号状态](型号状态与制作安排.md)。以下为待实测场景，不是已通过结果。

## 首批航程场景

以5分钟短程、15分钟标准程、30分钟长程作为候选观察窗口，均指已加载且运输系统实际推进的游戏时间，不把卸载离线时长算入。

| 同批货物 | 对照货柜 | 应观察到的差异 |
| --- | --- | --- |
| 3200pcs完整石料 | Courier S／Atlas S | 都无条件货损，只有柜体自重和被动能力差别 |
| 红石粉 | 无围护／一级围护 | 持续缺少围护时每分钟损失 8 pcs，一级围护防止散失 |
| 保持干燥的货物 | 普通柜／防水柜体 | 在同一场雨或浸水条件下核对防水保护 |
| 玻璃 | Atlas／Hermes／Sentinel | 速度变化耐受10／12／15；完全相同轨迹下缓冲有明确收益 |
| 蛋糕 | 普通柜／朝向保持／主动调温 | 分别验证持续倾斜与冷冻运输时限 |
| 生牛肉 | 普通柜／Harvest | 缺少主动调温时累计运输 30 分钟耗尽时限，随后每分钟扣量 |
| 带药效组件的药液 | Cistern／Crucible | 分别暴露与遮光；卸出药效组件完全一致 |
| 不同体积和敏感性的代表生物 | BioPod／Aquarium | 按现行物种条件与柜型能力核验只数、舱位、货重、最低生命及缓冲收益 |
| 僵尸 | BioPod遮光开／关的受控对照 | 光照≤5时无光损；超限20秒后首次每只1HP；不按原版日晒机制推断 |
| 气压敏感活体 | 无气压调节／有气压调节 | 在相同航线上越过物种的世界高度上限，核验暴露和扣血 |

生物对照在目标终端关联的有效围场内进行，配置每只报价。自然站测试从正式交易表选择已投放的物种。对照可用临时验证定义。命名个体走管理权限，普通未命名个体验证公共报价。覆盖装备拒绝、驯服主人权限、不同生命状态的个体扣血和逆序部分卸载。

运输按原生数量定量扣损。测试时覆盖满载以及一组、一桶等小批量，核对首次扣量时间、后续周期及尾量。

## 路线与计时检查

- 经过冷、热群系时核验对应敏感条件与真空隔层保护。
- 越过世界高度边界、经过降雨区或柜体浸水时核验对应防护。
- 测试冷冻和保温运输的在途时限、主动调温、追加及存档恢复后的计时。

## 制作阶段检查

- 按型号页的模板路径制作，使用统一的标准货柜接口，缺失直接记录。
- 检查质量标记、接口、分类和能力贴花槽位，清理导出时的所有者、货物及运行态残留。现有槽位保留0～4编号；槽位不足只影响展示，不改变实际能力。
- 核对模板尺寸、装配、对接、空重下限和满载起吊；新模板不自动改写旧实例。
- Sable 运输使用世界坐标对应的航空学环境；未知采样不能推定为安全。

各系列特有的模板和投放工作只在系列、型号页维护，不在本页另存型号任务清单。
