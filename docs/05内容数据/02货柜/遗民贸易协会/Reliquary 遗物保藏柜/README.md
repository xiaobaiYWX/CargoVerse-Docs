# REX Reliquary 遗物保藏柜

**正式产品线。核对：2026-11-06。**

**本系列缺失规格：S、M。** 有同系列 NBT 但引用错误：无。

## 产品定位

被动保温、气密与机械保护。主要取舍：无主动调节；初始状态不合格时不能主动修复。
