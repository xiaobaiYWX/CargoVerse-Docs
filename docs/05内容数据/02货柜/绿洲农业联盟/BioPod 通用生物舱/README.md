# VBS BioPod 通用生物舱

统一系列代号：`biopod`。普通产品系列，使用 `biopod_g2` 模板。各规格按同一个系列命名，不按运行定义中的旧别名拆分产品线。

## 保护与制作

密封结构、缓冲衬垫、主动调温、真空隔层、气压调节、遮光结构。各型号的能力完整参数、制造材料、投放渠道、模板路径与结构尺寸直接维护在上方型号页。实际空重仍受结构质量下限约束。

本页只列正式型号，未开放规格与未使用模板统一留在[历史归档](../../99历史归档/README.md)。运行资源尚存的旧别名只在各型号页“运行资源对应”中查阅，不用作新的文档文件名。
