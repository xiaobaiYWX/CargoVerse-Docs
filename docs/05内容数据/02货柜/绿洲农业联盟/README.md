## 本制造商的系列边界

NBT 的制造商、系列、接口和规格以目录及文件名为准；不同系列不能通过改显示名、改标签或历史合并而互相借用。缺失数按正式产品需要的系列＋规格统计，不把未规划规格算作缺失。

本页沿用现有产品设计名称核对模板，不通过更改系列名称掩盖缺失。例如 Courier 所需的模板必须命名为 courier，Cargo NBT 始终属于 Cargo。具体系列的全部 NBT、接口、规格和引用情况在各系列页就地维护。
