# 八家制造商专用初始货柜

2026-11-26已接入八个独立系列，每系列一款S型，使用用户导出的start_cargo结构。全部无货柜能力，不再采用普通系列基础副本。

## 共用参数

统一用料：铁锭16件＋标准紧固件箱4件＋工业构件箱2件；无特殊材料。现有产业物资可直接采购，玩家生产配方仍待讨论。低门槛、无保护、较小容量承担起步运输；专业保护与更大运力由普通产品提供。

## 接入范围

制造商初始绑定与独立制造配方均已接入。成功注册只赠送签发制造商的一张已打印初始蓝图，无其他物资、货币或声望；背包满时掉落至玩家身边。所有打印目录排除初始型号。注销保留已制造货柜，注销后重注册再次赠图；已持有效许可证时重复点击不再赠图。名额在实际删除货柜或取消施工后释放。模板资源ID保持 start_cargo/制造商/系列_s。
