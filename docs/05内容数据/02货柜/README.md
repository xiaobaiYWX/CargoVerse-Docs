# 货柜设计与制作总目录

更新：2026-11-09。**这是货柜设计的唯一维护入口。** 已实现、待制作、待验证及暂不开放内容全部按“制造商全称 → 系列全称 → 型号定义”放在本目录，不再另建货柜设计草案。

制作时先看系列页的状态与规格，再打开对应型号页查看模板路径、缺失情况、数值和制造信息。正式文档收录未完成内容不表示运行中已经开放；关闭的兼容型号不属于补建任务。
