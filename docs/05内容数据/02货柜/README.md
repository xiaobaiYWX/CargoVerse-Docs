# 货柜设计与制作总目录

已绑定普通产品共 **21 个系列、65 个型号**；另有 **8 个已接入的专用初始系列、8 款S型**，全部无能力。各规格统一使用标准货柜接口。打开制造商目录选择系列，再从型号页复制 G2 模板资源 ID 与导出路径。

每款型号页的“货柜介绍”与数据包 `description` 保持一致，供蓝图详情和打印机展示。介绍通过用途、制造商习惯与航运生活补充背景；容量、专项保护和制造要求仍以型号数据为准。同系列各规格保留各自的使用场景，停用型号仅在历史归档中维护。
