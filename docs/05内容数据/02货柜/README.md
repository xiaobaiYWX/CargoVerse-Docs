# 货柜设计与制作总目录

更新：2026-11-12。**这是货柜设计的唯一维护入口。** 已实现、待制作、待验证及暂不开放内容全部按“制造商全称 → 系列全称 → 型号定义”放在本目录，不再另建货柜设计草案。

制作时先看系列页的状态与规格，再打开对应型号页查看模板路径、缺失情况、数值和制造信息。正式文档收录未完成内容不表示运行中已经开放；关闭的兼容型号不属于补建任务。

2026-11-13：专用重型对接套件已下架，涉及旧 NBT 已清除相应部件并保留主体。定义开放、模板存在均不等于旧结构仍具备对接能力；受影响系列、兼容性及重建要求见[组件删减与开发维护](<../../06制作与开发/开发实现/02_组件删减与开发维护.md>)。

## 制作与维护入口

- **[新版模板系列代号（G2）](新版模板系列代号.md)**：后续搭建命名入口；逐系列、型号给出新路径。旧模板状态仅作现行运行参考。

- [型号状态与制作安排](型号状态与制作安排.md)：90 个定义逐项索引，包含待模板、待验证和关闭状态。
- [制作与实运验收](制作与实运验收.md)：公共检查及代表货物对照；结果待实测。
- [产品线设计原则](产品线设计原则.md)：定位、竞争、能力和模板边界。
- [基础型号](基础型号/README.md)：八家制造商的基础权益型号。
- [货柜信息对比表](型号能力与结构质量.md)：90款定义的容量、空重、调度效率、能力与制造费用；含各许可证规格分布及X／XL价值分析。
- [未使用 NBT 系列清单](未使用NBT系列清单.md)：已有但未被定义引用的资产，不自动构成新产品。
- [模板核对规则](../../06制作与开发/结构制作/货柜/04_系列归属核对.md)。

新增或调整设计直接修改所属型号页；共用取舍写在系列页。候选数值注明未采用，当前数据以工程 JSON 为准。禁止在草案目录维护第二份型号、能力或缺失清单。
