## 型号与模板命名

| 用途 | 规则与示例 |
| --- | --- |
| 文档型号代号 | 制造商／系列_规格，如 `dmc/boreal_x`；不含接口缩写 |
| 型号文件名 | `boreal_x.md`；规格以定义中的 `size_class` 为准 |
| 普通结构模板 | `cargoverse:cargo/dmc/boreal_g2/dmc_boreal_g2_x` |
| 初始结构模板 | `cargoverse:start_cargo/aui/origin_s` |
| 实际运行ID | 以型号页“运行资源对应”为准；Boreal X当前仍为 `cargoverse:dmc/titanhaul_hd_x` |

文档代号不是已注册资源ID，不能直接替代指令或JSON引用。运行数据中的旧系列别名及sd、hd、mc、lm尚未迁移，不代表现行产品另有系列或接口。模板须匹配制造商、系列与规格；缺失在对应系列和型号页注明，不借用其他系列占位。

## 初始货柜获取

八家各有独立的无能力S型固体柜，参数与用料见上方型号页。成功注册仅赠送签发制造商的一张已打印蓝图，不赠物资、货币或声望；背包满时掉落至玩家身边。所有打印目录排除初始型号，制造仍需实体材料。

八品牌共享每名玩家同时一个初始货柜的名额，施工占用也计入。注销保留已制造货柜；重新注册可再次赠图，但不会重置名额。已有有效许可证时重复注册不额外赠图。

## 设计与维护原则

货柜按固体、液体、生物介质及保护需求定位，同介质内不按商品用途限制装载；保护不足由货物声明的损耗规则体现。常用系列允许跨制造商竞争，同厂系列应在容量、空重、保护或运输场景上有明确差异。BioPod与Aquarium共用生物舱室规则，不设陆生／水生柜型门禁。

能力统一使用现行 `abilities` 配置。真空隔层与主动调温、密封与主动稳压分别承担不同保护；完整对应关系见[能力规范](../../04数据规范/货柜/能力/README.md)。不另设品牌保存倍率或第二套词条。

容量、空重、调度点与成本一起平衡；实际空重受结构质量下限约束，不能将定义空重当作实测值。材料由实体物品投入，蓝图打印费用与投放渠道见[制造规则](../03贸易点/蓝图投放/制造配方与投放总表.md)，物资获取见[产业物资](../01运输物品/04_产业物资.md)。存在配方或能力配置不等于任意自然站都会出售其蓝图。

新增或调整数据时先同步对应型号页，再更新系列比较和数值总表。顶层不再保存另一份型号任务表；未开放型号留在历史归档，模板和实机验收状态分别记录。
