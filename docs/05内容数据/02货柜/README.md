## 当前结论

- 正式 51 型号中：32 个已引用同系列同规格 NBT；4 个已有正确 NBT 但引用错误；15 个缺少同系列规格模板。
- 缺失：Courier L；Cistern M／L；Silo L／X／XL；Apollo X；Boreas M／L；Crucible M／L；Sentinel L／X；Reliquary S／M。
- 引用错误但文件已有：Courier S／M、Apollo M／L。基础 Courier S 和 Apollo M 变体同步存在相同问题，但不重复计数。
- 本轮仅纠正文档与重新统计，运行 JSON、NBT 文件、接口及制造状态未改变。候选正确模板仍须接入验收。
