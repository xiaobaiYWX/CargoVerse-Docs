# AUI Origin 启航货柜 S型

## 货柜介绍

Origin是AUI交给新承运人的起步货柜，没有专项保护设备。集团希望新人从第一张装配图就熟悉它的标准。以后你可能会更换货柜、船只，甚至合作的制造商，但工具箱里大概还会留着按这份图纸准备的工具。

## 型号资料

2026-11-26已接入。无围护、密封、防雨、缓冲、正放、调温、稳压、隔热、遮光或照明能力，配置为 `abilities: {}`。外形封闭和模板展示标记不授予运输保护。

| 项目 | 现行值 |
| --- | --- |
| 定义ID | `cargoverse:aui/origin_s` |
| 运输介质 | 固体 |
| 尺寸/容量 | S／2048件；装卸按组 |
| 调度点 | 0 |
| 定义空重 | 12 Kpg；实际空重仍受结构质量下限约束 |
| 能力 | 无 |
| 许可/制造商声望 | S／0级 |
| 蓝图费 | 0 VB |
| 制造时长 | 400 tick |
| 权益 | 每名玩家同时一个初始货柜，八品牌共享名额 |

## 制造材料

| 层次 | 物品 | 数量（件） |
| --- | --- | --- |
| 主材料 | 铁锭 | 16 |
| 辅材料 | 标准紧固件箱 | 4 |
| 辅材料 | 工业构件箱 | 2 |
| 特殊材料 | 无 | 0 |

材料直接消耗实体物品；紧固件与工业构件可通过Create生产，也可从贸易点采购。与同介质普通货柜一样可以装载有运输条件的物品，但不提供保护，货损照常求值。

## 结构模板

- 资源ID：`cargoverse:start_cargo/aui/origin_s`。
- 导出相对路径：`start_cargo/aui/origin_s.nbt`。
- 已同步尺寸：4×5×5；独立品牌外观，标准接口。
- 来源文件原样同步；无实体、所有权和运行载货状态，质量标记及分类展示完整。
- 不将显示用词条贴花标记视为能力；空能力柜不会因此获得运输保护。

## 制造入口

本型号由制造商 starter_container 指定，成功注册该制造商许可证时赠送一张已打印蓝图。正式站点、A/B 测试站和单方块测试打印机均不提供本型号打印；独立制造配方保留，使用搭建器并支付上述材料。注销保留已制造货柜，重注册再赠图但不重置唯一名额。
