# 货柜产品线设计原则



## 定位与竞争

货柜按固体、液体、生物介质及保护能力定位，同一介质内不因商品用途拒绝装载。常用柜允许跨制造商竞争；同厂系列需有容量、空重、保护或运输场景差异。保护不足通过货物声明的运输损耗体现，不强制所有货物拥有特殊运输条件。

容量、定义空重、调度点和制造成本应一起平衡，实际空重还受模板结构质量下限约束。

## 能力与边界

保护通过现行 abilities 配置，不新增一套词条或品牌保存倍率。隔热减慢温度交换，主动调温需要时间；设备关闭状态不能被自动重置。密封与主动稳压是不同能力。BioPod／Aquarium 使用统一生物舱室，按舱位、载重、缓冲与环境保护形成差别。

每个型号页记录完整配置；不在本页再复制一份能力数值表。能力名称、字段与运行语义见[能力规范](../../04数据规范/货柜/能力/README.md)，现有参数汇总见[型号能力与结构质量](型号能力与结构质量.md)。



## 模板与未完成内容

后续新版统一采用系列名加 `_g2` 的代号，见[新版模板系列代号](新版模板系列代号.md)，正式型号已逐款绑定对应模板。

模板按 NBT 名称核对制造商、系列和实际规格；缺失必须在型号和系列页面标出，不用其他系列临时填补。



制造采用实体材料与蓝图打印费用，具体配方和渠道见[制造投放总表](../03贸易点/蓝图投放/制造配方与投放总表.md)。Reliquary 等特殊获取型号不因完成保护配置而自动加入所有自然站。
