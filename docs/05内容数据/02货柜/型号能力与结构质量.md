新版结构代号已统一为G2，见[新版模板系列代号](新版模板系列代号.md)。本表数值和模板状态反映当前运行定义；新模板制作以各型号G2路径为准。

## 统计口径

- 普通可制造 55 款（含 BioPod 验证型号 3 款）；基础型 8 款；制造关闭 27 款。基础型不重复计算许可证新增选择，关闭型号不计可用选择。
- 固体容量为物品组，液体为桶（1000 mB），生物为舱位；舱位不是只数。三种容量不能横向相加或按数值大小判断优劣。
- 空重列是定义值 Kpg，实际空重取定义与结构质量的较大值。容量／空重只作定义效率指标，不能据此保证可起吊。旧表的模板质量估算缺少同一轮复测证据，停止用作当前结构质量结论；结构质量与满载起吊仍需实测。
- 调度效率＝容量÷调度点；基础型为0调度点，不计算无穷效率。按原生物品质量计算货重，不把容量单位视为吨。
- 许可按制造配方 required_license，规格按 size_class；不从旧 ID 后缀猜测。蓝图费是配方 blueprint_cost，不包含实体材料；时间为 duration_ticks÷20 的理想运行秒数。
- “可制造”指数据未关闭，不代表自有模板、自然站投放或实机验证均完成。模板状态与运行状态分别列出。

## X／XL 许可证价值判断

**存在业务覆盖断层，但不能仅凭型号数量认定许可证没有价值。**

| 方向 | 当前上限与事实 | 对升级价值的影响 |
| --- | --- | --- |
| 常规大宗固体 | Titan、Boreal、Silo 到XL；Atlas到X | 已有明显单柜容量和调度效率提升，但相近路线集中 |
| 干燥固体 | Vulcan到X；CoreVault到M | X有大批量干燥价值，XL没有对应延伸 |
| 温敏固体 | Apollo到X；Harvest到L；CryoVault关闭 | 食品冷链停在L；Apollo最低目标0TU不能覆盖所有低温货物需求 |
| 冲击与正放 | Sentinel到X；Fortress仅XL | XL有较强保护与大容量选择，但不能代替温控、干燥或稳压柜 |
| 普通／温敏／样品流体 | Cistern、Boreas、Crucible均到L | 液体主业玩家在X、XL没有同介质新增柜型 |
| 生物 | BioPod到L；Aquarium仅M/L且关闭 | 活体主业玩家在X、XL没有新增容量或保护选择 |
| 多条件样品 | Explorer到L；Reliquary到M | 专业保护集中于小中型；不宜简单让每个系列都扩至XL |

X型号中 Silo X、Sentinel X 仍缺本系列模板；XL型号中 Silo XL 仍缺本系列模板。这些定义虽然未关闭，不能算作已经完成结构验收的升级内容。其余型号也仍需实运验证。
