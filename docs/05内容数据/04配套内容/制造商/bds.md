# 铁壁防务集团（`manufacturer.cargoverse.bds`）

## 品牌设定

英文名：**Bastion Defense Systems**

> 守护每一条航线。

铁壁防务最初是一家安保器械生产机构。随着航路、贸易点和资源竞争增加，它逐渐将业务扩展至武装护航、驻点保护与成建制战斗服务，最终发展为最大的雇佣兵机构。装备制造仍是基础，但人员、指挥与后勤已经成为同样重要的商品。

集团内部更接近一支职业军队，靠层级、纪律和任务安排运转；对外则以合同明确服务边界。只要价格合适，BDS能够提供完整的战斗人员、重型武器和支援体系，其积累的资源足以发动一场小型战争。它的行动不应被统一描绘为无条件保护所有人。

“守护每一条航线”是品牌宣言，实际保护范围由委托关系决定。某些地方依靠铁壁维持通航，另一些地方则会紧张地观察它的部队调动。老兵可以务实、疲惫或带有冷幽默，公司也不必把每份合同都向普通承运人解释。

### 势力关系与信息边界

- 与客户的关系以合同和报酬为核心，本轮不指定唯一的政治阵营或永久敌人。
- 工业体系为其提供武器、机械与补给，但不据此额外虚构与其他制造商的排他同盟。
- 军事动员能力属于背景设定，不代表当前版本已经实现战争、护航AI或雇佣兵召唤。

### 货柜与人物文案基调

描述应从泛泛的安保设备转向驻军轮换、武装护航、军需清点与合同后勤。货柜保护能力仍按定义，不暗示防弹、爆炸免疫或附带武器。

声望页使用承运人可接触到的公开介绍与个人批注。批注属于人物口吻，不作为数值承诺；幕后事实与未证实传闻按上文分别维护。以下为世界观设定，不新增对应功能或变更交易规则。

## 建筑特征色

代表色为**深绿与深灰**，在旗下贸易点中作为局部点缀，例如安防设施集成厂。主体材质与主色优先按建筑功能、结构形式和使用环境确定；品牌色仅用于标牌、入口饰条、局部面板或短段色带，不因品牌归属大面积覆盖墙面、屋顶或框架。各单体和共用平台保持一致的局部识别，主体材料仍可随用途变化，功能标线按需要搭配。

这是后续新建与重制的视觉设计参考，既有模板不自动换色。流程见[制造商归属与特征色](<../../../06制作与开发/结构制作/贸易点/结构搭建说明/结构模板工作流.md#制造商归属与特征色>)。

## 声望页介绍

铁壁防务最初制造安保器械，如今已是最大的雇佣兵机构。它的组织更像军队，合同则决定这支军队向哪里开拔。只要报价得到确认，集团便能提供人员、重型武器与成套后勤，足以发动一场小型战争。“航线安全”因此既是它的业务，也是客户在谈判桌上常用的一句话。承运人最好分清补给目的地，以及谁在支付运费。

老兵批注：他们确实守护航线。请看合同附图。
