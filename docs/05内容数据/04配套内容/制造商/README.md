# 制造商设计

八家制造商页面维护背景、业务特点、势力关系及货柜文案基调；游戏内声望介绍使用中英文正文与个人批注。HRI 中文名沿用**地平线研究院**。

## 势力关系与叙事边界

| 制造商 | 核心特色 | 关系与矛盾 |
| --- | --- | --- |
| AUI | 最大飞艇制造商与工业巨头，零件和标准无处不在 | DMC原料、HEC能源、HRI技术支撑其工业体系 |
| DMC | 最大矿业开发商与重型机械商，月度配额优先 | 各家订单持续施压，员工福利让位于产量 |
| HEC | 能源与化工巨头，以供应影响航线和贸易点 | 运输安全严谨，却回避污染治理成本；与VBS关系不佳 |
| HRI | 据点有限、技术顶尖，内部也存在知识与权限壁垒 | 为AUI提供技术，与SPL频繁合作；暗中与REX交换技术和样本 |
| BDS | 从安保器械厂发展为最大雇佣兵机构 | 军队式组织，合同决定行动范围，具备发动小型战争的能力 |
| SPL | 最多运输飞艇、最完善导航图，频繁而准确的物流 | 不过问包裹内容，精细运输深受HRI使用 |
| VBS | 最大有机物供应商，集约培养与快速克隆并行 | 重视环境，与HEC冲突；技术来自坠毁HRI数据中心的说法未经证实 |
| REX | 最大回收网络，废船与遗迹都是资源入口 | 秘密向HRI提供样本和数据换取技术，并资助神秘黑市 |

设计文档区分**确定幕后事实**与**未证实传闻**：REX与HRI的秘密合作、REX资助黑市是前者，VBS技术来源是后者。公开声望页通过设备、货单、人物态度留下线索，不替玩家揭晓全部关系。个人批注来自不同岗位，可以偏颇、自嘲或抱怨，不作为能力、数值或新功能承诺。现实及其他作品的参考仅用于把握创作方向，不写进游戏内设定。

八家制造商均配置了 0～5 级声望的中英文称号与签约价格修正。货柜容量、空重与能力由具体货柜定义维护。

## 制造商代表色

以下为各制造商已确定的品牌代表色。用于贸易点建筑时，**功能决定主体材质与主色，制造商颜色形成清晰可见的局部识别**。适当增加入口饰条、重复立面面板、局部门架与平台边缘等元素，让不同方向都能辨认制造商；避免整站只有一两块很小的色板。各模块和共用平台保持一致的识别方式，不将整面墙、整片屋顶或全部框架涂满品牌色。材料本色与品牌色相近时仍可按功能正常使用。

| 制造商 | 代表色／识别方式 |
| --- | --- |
| [AUI · 天穹联合工业](<aui.md>) | 青色、浅灰、白色 |
| [BDS · 铁壁防务集团](<bds.md>) | 深绿、深灰 |
| [DMC · 深岩矿业集团](<dmc.md>) | 黑色、黄黑警戒 |
| [HEC · 赫利俄斯能源集团](<hec.md>) | 红色、黑色 |
| [HRI · 地平线研究院](<hri.md>) | 蓝色、灰色 |
| [REX · 遗民贸易协会](<rex.md>) | 无固定点缀色；按回收机构定位表现 |
| [SPL · 云港物流集团](<spl.md>) | 橙色、白色、深灰 |
| [VBS · 绿洲农业联盟](<vbs.md>) | 黄绿色、白色 |

DMC 的黄黑警戒以作业边缘、设备边界等局部条纹表现；各站必要的安全标线与 H 标识仍按功能设置。REX 不补造统一品牌配色，可保留回收材料原色和局部修补痕迹，具体组合服从建筑用途。规则从概念图延续至 NBT，具体见[制造商归属与特征色](<../../../06制作与开发/结构制作/贸易点/结构搭建说明/结构模板工作流.md#制造商归属与特征色>)。

## 共同数值基准

- 声望等级 0～5 的累计门槛为 **0、100、300、700、1500、3000**，沿用既有 AUI 基准。
- 个人声望由[物资供应](<../../../02系统规则/自然贸易点/03_物资供应.md>)发放。每笔按站点实际接收量占该项需求目标的比例，折算供应表中配置的整项奖励。
- 签约承运人按当前制造商声望等级获得优惠：0～5 级买入倍率依次为 **1.00、0.99、0.98、0.97、0.95、0.92**，卖出倍率依次为 **1.00、1.01、1.02、1.03、1.05、1.08**。
- 常规买卖和许可证注册均不会增加制造商声望。独立站点的物资供应可推进站点繁荣度。
