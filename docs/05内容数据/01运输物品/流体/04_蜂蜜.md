# 蜂蜜

> 当前内置数据，2026-11-07 专项细化。数值已写入数据包；实机航程平衡仍待验证。

## 身份与质量

| 项目 | 当前配置 |
| --- | --- |
| 源流体 | `create:honey` |
| 流动变体 | `create:flowing_honey` |
| 定位 | 耐储食品液体 |
| 每桶质量 | 1.2 Kpg／1000 mB |
| 120 桶货重 | 144 Kpg |
| 240 桶货重 | 288 Kpg |
| 货类贴花 | `cargoverse:decal_food` |

两种注册身份参数相同，仍各有一份属性文件；不等于可以将不同 ID 混装。货重不含柜体，整批最终向上保留一位小数。

## 运输条件

无特殊运输条件。`transport_conditions` 明确为空；温度、压力、光照不产生本流体的条件损耗。

## 选柜与调整依据

Cistern 已满足本轮需求，不要求气密 2 或制冷。

保留较高的每桶质量；作为无需冷链的耐储食品。不因结晶、黏稠或食物用途自动增加低温敏感／易腐坏。

通用液体柜允许装载本流体，选柜差异通过保护效果体现。柜型的模板缺失状态以各型号文档为准，本页不替代模板验收。
