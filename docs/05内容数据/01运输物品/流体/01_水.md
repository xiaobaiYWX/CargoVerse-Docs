# 水

> 当前内置数据，2026-11-07 专项细化。数值已写入数据包；实机航程平衡仍待验证。

## 身份与质量

| 项目 | 当前配置 |
| --- | --- |
| 源流体 | `minecraft:water` |
| 流动变体 | `minecraft:flowing_water` |
| 定位 | 基础供水 |
| 每桶质量 | 1 Kpg／1000 mB |
| 120 桶货重 | 120 Kpg |
| 240 桶货重 | 240 Kpg |
| 货类贴花 | `cargoverse:decal_general_supplies` |

两种注册身份参数相同，仍各有一份属性文件；不等于可以将不同 ID 混装。货重不含柜体，整批最终向上保留一位小数。

## 运输条件

无特殊运输条件。`transport_conditions` 明确为空；温度、压力、光照不产生本流体的条件损耗。

## 选柜与调整依据

Cistern 已满足本轮需求。

保持普通流体基准，不增加结冰、蒸发或光照风险；原生水的温度不会自动变成保存温度需求。

通用液体柜允许装载本流体，选柜差异通过保护效果体现。柜型的模板缺失状态以各型号文档为准，本页不替代模板验收。
