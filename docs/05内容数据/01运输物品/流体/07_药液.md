# 药液（全部药水变体）

> 当前内置数据，2026-11-07 专项细化。数值已写入数据包；实机航程平衡仍待验证。

## 身份与质量

| 项目 | 当前配置 |
| --- | --- |
| 源流体 | `create:potion` |
| 流动变体 | `create:flowing_potion` |
| 定位 | 避光精细流体 |
| 每桶质量 | 1 Kpg／1000 mB |
| 120 桶货重 | 120 Kpg |
| 240 桶货重 | 240 Kpg |
| 货类贴花 | `cargoverse:decal_chemical_material` |

两种注册身份参数相同，仍各有一份属性文件；不等于可以将不同 ID 混装。货重不含柜体，整批最终向上保留一位小数。

## 运输条件

运输条件：`cargoverse:light_sensitive`（避光储存）。内部光照 **≤5** 安全，**>5** 时累计不利暴露。

累计宽限 3600 tick（3 分钟），周期 1200 tick（1 分钟），每次整批扣 125 mB；持续超限首次在 4800 tick（4 分钟）扣量。回到安全光照只暂停累计，不重置预算。

普通、延长、增强药效，以及普通／喷溅／滞留来源只要实际转换成 `create:potion`，均共用上述数据。药效、药水类型等原生组件保留；不同组件属于不同货物身份，不可混装。瓶装药水仍属固体物品，按固体属性处理；未转为 FluidStack 的内容不纳入本页。

普通水瓶是例外：Create 将其转为 `minecraft:water`，因此使用水的属性。喷溅／滞留水瓶仍按其实际转换后的流体 ID 处理，不仅凭物品名称决定运输属性。

## 选柜与调整依据

Crucible／Boreas 均有遮光结构；Cistern 可装，但内部光照超限会耗费预算。

全部药效、等级、时长与瓶型组件变体使用同一份运输属性。不按正面／负面药效另定运输难度，不把散装药液按玻璃瓶处理。

通用液体柜允许装载本流体，选柜差异通过保护效果体现。柜型的模板缺失状态以各型号文档为准，本页不替代模板验收。
