# 牛奶

> 当前内置数据，2026-11-07 专项细化。数值已写入数据包；实机航程平衡仍待验证。

## 身份与质量

| 项目 | 当前配置 |
| --- | --- |
| 源流体 | `minecraft:milk` |
| 流动变体 | `minecraft:flowing_milk` |
| 定位 | 短保食品液体 |
| 每桶质量 | 1 Kpg／1000 mB |
| 120 桶货重 | 120 Kpg |
| 240 桶货重 | 240 Kpg |
| 货类贴花 | `cargoverse:decal_food` |

两种注册身份参数相同，仍各有一份属性文件；不等于可以将不同 ID 混装。货重不含柜体，整批最终向上保留一位小数。

## 运输条件

冷冻运输（`cargoverse:frozen_transport`）的在途时限为 **18000 tick**（15 分钟）。时限耗尽后，每 1200 tick 扣除整批 125 mB。缺少主动调温时，首次扣量在累计运输 16 分钟后发生。主动调温暂停倒计时。

## 选柜

短途可用 Cistern。长途可选有主动调温的 Boreas 或 Crucible。
