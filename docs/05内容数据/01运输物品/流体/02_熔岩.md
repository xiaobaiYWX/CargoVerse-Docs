# 熔岩

> 当前内置数据，2026-11-07 专项细化。数值已写入数据包；实机航程平衡仍待验证。

## 身份与质量

| 项目 | 当前配置 |
| --- | --- |
| 源流体 | `minecraft:lava` |
| 流动变体 | `minecraft:flowing_lava` |
| 定位 | 重质工业流体 |
| 每桶质量 | 1.5 Kpg／1000 mB |
| 120 桶货重 | 180 Kpg |
| 240 桶货重 | 360 Kpg |
| 货类贴花 | `cargoverse:decal_energy_fuel` |

两种注册身份参数相同，仍各有一份属性文件；不等于可以将不同 ID 混装。货重不含柜体，整批最终向上保留一位小数。

## 运输条件

无特殊运输条件。`transport_conditions` 明确为空；温度、压力、光照不产生本流体的条件损耗。

## 选柜与调整依据

Cistern 可运输。耐热、耐腐蚀不是当前独立能力，不额外指定不存在的耐热柜。

保留较重的每桶质量。未实现凝固产物、容器灼损及熔岩对内部环境供热，不用低温敏感来模拟这些行为。

通用液体柜允许装载本流体，选柜差异通过保护效果体现。柜型的模板缺失状态以各型号文档为准，本页不替代模板验收。
