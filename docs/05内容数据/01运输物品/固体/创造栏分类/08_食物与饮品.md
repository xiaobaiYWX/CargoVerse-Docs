# 食物与饮品

更新：2026-11-07。本页 43 个显式属性 ID；这是查阅分组，不是运行时运输分类。

## 专项细化重点

区分耐储根茎、干粮、鲜食、成品餐食与饮品容器。保鲜预算、温度曲线、正放和易碎分别设计，不能给所有食物套同一腐坏时间。

本轮展示工程现值与审核方向，未批量改质量、准入或运输条件。每组质量最多一位小数；组大小按装载时的实际 ItemStack 冻结。条件中的 amount／damage_amount 为原生件数，时间字段单位 tick。
