## 归类口径

- 原版分组参考工程 1.21.1 依赖的 CreativeModeTabs.java 显式展示条目；这是文档整理，不宣称复现客户端最终标签页或顺序。
- 同一物品可能出现在多个标签页；为避免重复维护，本清单按建筑、染色、自然、功能、红石、工具、战斗、食物、原材料顺序选一个主目录。动态药水、附魔书等按物品 ID 归并，不建立逐组件属性。
- 刷怪蛋和管理员栏内容移入 99；搜索、快捷栏、背包不是物品分类，不单列。原版不可常规获得物品优先于标签页归属。
- Create 与航空相关模组、CargoVerse 分别保留查阅页，模组内仍可按具体物品继续拆细；这不是根据中文名称生成的运行规则。
- 99 为本轮按默认版本规则确认的特殊获取条目；获取方式不确定的在模组页明确待核对，不以“无配方”推断不可获取。
- blocked 与不可正常获取不是一回事。普通鱼桶、背罐、胶水可能因载荷恢复限制而禁运，却仍在正常模组／工具页。玩家装卸标记不因带 marker 后缀就并入管理员类。
- 新标签页不会修改 form、unit_mass、admission_policy 或 transport_conditions。价格、经验不在本章维护。

## 数据来源与覆盖边界

- 当前属性：src/main/resources/data/*/cargoverse_item_properties/solid；JSON 是现行参数唯一来源。
- 默认堆叠数：本轮服务端 GameTest 重新导出的 build/reports/transport/item-registry.json 注册报告；新增或删除注册内容需重新运行覆盖检查。
- 原版分组：本机 NeoForge 依赖 sourcesAndCompiledWithNeoForge 中的 CreativeModeTabs.java；特殊世界方块与收纳袋另核对 stripServer resources 中的掉落表和 bundle 实验配方。生成辅助文件位于 build/item-doc-audit。
- 中文名沿用逐 ID 历史查阅表并补充项目语言文件；未读取附魔、耐久、饱食度作为分类条件。
- 本轮注册报告仅 minecraft:air 空值不列为显式属性；旧报告中的 container_spawn_point、magma_gas_bucket 已不在当前注册表，不根据历史报告恢复旧 ID。
