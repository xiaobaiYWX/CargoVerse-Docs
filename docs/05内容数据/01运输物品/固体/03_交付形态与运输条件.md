# 固体运输条件与损耗参数

更新：2026-11-03。所有物品属性均为schema 3，只使用transport_conditions；装载介质统一solid，保护需求与准入分离。液态和气态Fluid共用liquid，实际活体使用living。

## 当前赋值

| 条件 | 内容选择 | 参数基准 |
| --- | --- | --- |
| fragments | 碎矿、原矿碎块、砾石、煤炭、种子等已明确颗粒 | 需要围护1；宽限0 |
| powder | 沙、混凝土粉末、颜料与明确粉末 | 需要围护2；宽限0 |
| keep_dry | 怕湿粉末、颜料 | 湿度上限60，推荐40，宽限2400 |
| keep_dry | 纸张、书、图纸与纸板制品 | 湿度上限70，推荐50，宽限2400 |
| fragile | 玻璃瓶、玻璃及框件、陶器等 | 基础速度变化耐受10，事件扣1pcs |
| fragile | 鸡蛋等脆壳物 | 耐受8，事件扣1pcs |
| fragile | 精密裸件与明确仪表 | 耐受16，事件扣1pcs |
| perishable | 生肉、生鱼、浆果、蛋糕、汤、部分新鲜加工食品 | 预算36000tick；10／30TU断点，倍率0.25／1／2，目标8TU |
| frozen_transport | 普通冰 | 上限10TU，目标5TU，宽限3600 |
| light_sensitive | 三种瓶装药水 | 上限5，宽限3600 |
| keep_upright | 蛋糕、四种汤、建筑工茶 | 最大倾角30°，宽限60 |

原生牛奶桶当前blocked，不因保鲜方案而开放；浮冰和蓝冰不复制普通冰的融化风险。药水避光是本轮新增玩法数据，不代表原版自带该效果；以后液体阶段需保持散装药液的一致保存条件。旧flammable不机械转换成高温敏感，尚无依据的爆炸、辐射、腐蚀等效果不写入。

## 组比例与整数扣量

普通持续损耗以每1200tick损失默认一组的1/8为基准。正放风险采用更快的200tick基准；其余宽限和老化预算保持原值，不随组大小变化。

| 默认组大小 | 普通持续损耗／老化预算耗尽后 | 正放超限 |
| ---: | --- | --- |
| 64 | 8pcs／1200tick | 8pcs／200tick |
| 16 | 2pcs／1200tick | 2pcs／200tick |
| 1 | 1pcs／9600tick | 1pcs／1600tick |

一般暴露首次扣量是宽限＋一次间隔。老化预算耗尽后才推进损耗间隔；正放和老化可同时有损耗。不同风险不合并成一个总上限。比如蛋糕普通温区30分钟耗尽预算，再累计8分钟损失1件；倾斜超限的首次损失为60＋1600tick。

冲击事件仍为1pcs，不按上述周期折算，非堆叠物品一次损失完整一件。这是物品不可分割的边界，不新增概率货损、部分耐久货损或隐含损耗池。

固体参数固定到每个物品ID，实际组件可能改变组大小，因而只能保证默认物品的组比例。质量、容量和结算仍按精确组件的冻结组大小运作；不在运行时擅自重算JSON中的amount。
