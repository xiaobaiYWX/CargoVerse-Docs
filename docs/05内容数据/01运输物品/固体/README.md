# 物品运输属性：按创造栏专项细化

更新：2026-11-07。当前 **2319 份显式固体属性**，统一采用 schema 3。按创造栏主题和模组来源分类查阅，管理员及生存不可正常获取物品独立成类。

## 当前入口

- [创造栏分类索引](创造栏分类/README.md)：全量逐 ID 当前质量、组大小、准入、条件参数与源 JSON。
- [专项细化安排](<../../../90设计草案/物品运输属性专项细化.md>)：逐类审核目标、质量和损耗尺度、代表物品与特殊获取边界。
- [分类原则](<../../../02系统规则/货物与货柜/21_物品分类与准入.md>)：查阅分组不改变运输介质或货柜兼容性。
- [运输条件与损耗参数](03_交付形态与运输条件.md) · [质量计量](<../../../02系统规则/货物与货柜/11_物品运输质量.md>)。

管理员／非正常获取类 130 项；其余 2189 项按原版九类及模组主题查阅。剩余条目不表示所有物品的获取渠道均已实机验证，特别是项目设备仍需分别核对交易、掉落和产出。

## 维护约定

JSON 是运行参数唯一来源。文档分组不是运行分类或默认继承；原石、石砖、玻璃、食品仍根据固体形态、准入和各自条件装载。分类改变不自动改重量、条件、报价或制造配方。
