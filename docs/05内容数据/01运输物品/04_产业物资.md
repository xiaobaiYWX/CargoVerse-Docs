# 产业物资与玩家生产

本页维护30种产业物资的来源。2026-11-26已接入10种基础固体、4种中阶固体与工业密封胶，共15条 Create 生产配方。复用现有物资ID、运输数据和堆叠数，贸易来源继续保留。

## 物资定位与计量

产业物资是实际物品或流体，可以由贸易点供应，也可以由玩家生产。低阶商品的产地不再独占；高级专业货物和不同地区的收购需求继续形成运输动机。玩家产品与站点产品使用相同ID、组件和运输数据，不增加“玩家制造版”或来源认证。

制造配方按件、流体配方按mB；交易与升级按组或桶。当前25种固体专用品以64件为一组，1桶为1000mB。名称里的“箱、组、包”都是单个商品名称，不代表一件等于64件。一柜4096件能装64组，若一批产8件，需要512批填满。

玩家物资可以直接用于货柜制造；提交贸易和繁荣升级仍走已有货柜装卸与供应终端。不会因为允许制作商品而让交易终端直接收玩家背包。制造机器的原料区、液体接口沿现有系统设计，不新增第二套贸易库存扣料源。

## 货柜、升级与经济联动

基础S干货柜以铁锭32＋紧固件8＋工业构件4起步。按当前产率，可折算为铁锭35.5、安山合金1及对应加工：紧固件总需求12件，需生产2批得16件，余4件；构件所需2铁板由另2铁锭提供。因此首次离散批次实际投入铁锭36，长期稳定批量摊销为35.5铁锭/柜。SPL少用构件，DMC/BDS增加结构件；专用柜再添少量能力组件。具体见[制造材料方案](../03贸易点/蓝图投放/制造配方与投放总表.md)。

天空站0→1需紧固件8组＋工业构件8组，另有专项物资。这不是8件：仅固定基础就需512件紧固件和512件构件。工业构件还会内部消耗512件紧固件；合计紧固件产1024件，需128铁板，构件另需256铁板和128安山合金，总计384铁锭＋128安山合金。一次升级面向批量供应，明显大于造一个S柜；本轮保留升级数量，实测若过重，应明确调供应数量，不能暗改单位。

现行通用工业构件/紧固件外站收购通常为20VB/组，具体以逐站报价为准。紧固件1铁锭产8件，对应售出一组投入8铁锭，毛收入20VB，即2.5VB/铁锭；尚未扣加工时间与物流成本。工业构件一组需40铁锭＋16安山合金（包括自身消耗的紧固件），以20VB/组出售时回报明显弱于紧固件。因此既有同价仍有收益差异，配方开放不代表报价已经完成产线经济校准。

本轮按已确认的原料产出比例开放生产，保留贸易报价、库存、每日额度、货柜用料及升级数量。下一轮通过实际产线记录原料取得成本、每分钟成品数与运输收益，再决定是否降低纯紧固件收购价或提高复合组件收购价；必要时使用现有逐商品每日额度控制当地需求。本轮未进行转速、物流和售货闭环的吞吐实测，不能声称经济平衡已经验证。

允许生产线持续获利，这是接入自动化的目的；需要控制的是低加工成本配合无限收购导致VB增长过快。高级贸易货物、跨站差价和特殊材料仍应有价值，但不保证每种货物都必须跨区。玩家在收购站附近建厂本身是有效选择；达到当地需求上限后再向其他站扩展销量。
