# 第一趟航运

欢迎入行。先别急着签字，抬头看看：各制造商的大站都浮在天上，注册终端也在上面。你得先弄一艘自己的飞行载具。

集团把这叫“入职考验”。我干了这么多年，觉得这项考验最明确的内容，就是公司不提供船。

## 先把自己送上去

准备一艘能抵达天空站的载具，还要给货柜留出接驳位置和运载余量。空船能飞，只说明你能来面试；装上货以后还能起飞，才算有本事上班。

你当然可以搭方块爬上去，或者另想办法。终端不会因为你没停船就拒绝注册。不过许可证不会替你搬货柜，那根通天石柱也不会自己飞往下一站。到得了柜台，和运得走货，是两回事。

## 办手续，备货柜

抵达天空站后，在注册终端办理许可证，收好赠送的初始蓝图。随后准备搭建器与材料，造出自己的货柜。集团给了图纸，材料还得你出——欢迎了解这份工作的成本结构。

再带上有购货余额的虚空结算器，查好卖方和买方。先确认目的地收购什么、是否已经解锁、今天还收多少，再决定装什么。

> [!NOTE]
> 初始货柜没有专项保护。先挑没有特殊运输要求的固体商品，少装一点试航。第一趟的目标是连人带货抵达，不是给港口留下一个满载起飞的传说。

## 带着货回来

把自己的货柜送入出售终端对应的装载区域，选好商品和数量，核对价格与货柜后确认购买。看清装载结果，接好货柜，再启程。

抵达买方后，将货柜送入收购终端对应的卸载区域，确认出售并检查到账。卸空的柜子仍是你的，记得带走；它刚开始替你挣钱。

具体手续看[注册与初始蓝图](entry:cargoverse:getting_started/registration)，出发前也翻翻[结算器与航运资金](entry:cargoverse:getting_started/settlement)。
