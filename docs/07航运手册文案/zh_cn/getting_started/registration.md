# 注册与初始蓝图

既然你已经上了天空站，就算通过了集团的第一轮考验。接下来找许可证注册终端，把名字写进承运人名单。地面小站不办这项业务，别让人家修钓具的替你盖章。

## 办理注册

先看清终端上的签发机构，再进入注册功能。用上一页、下一页读完协议，最后一页按 OK 确认，BACK 用于返回。我的建议是至少看看自己签给了谁，日后抱怨时也好找对名字。

注册成功后，你会得到签发制造商的一张已打印初始货柜蓝图。背包放不下时，蓝图会掉在身边。打开航运手册的档案页，确认签发机构和许可证状态。

送的是蓝图，成品货柜、材料和启动资金都不在里面，声望也得自己挣。我第一次拿到图纸时也翻过背面，没有藏着第二份福利。已有有效许可证时，重复注册不会再领一张。

## 领图以后

手持已打印蓝图右键查看型号与材料，再为搭建器准备场地。具体施工留到[从蓝图到货柜](entry:cargoverse:containers/blueprints)逐步做；初始蓝图已经打印好了，打印机也不提供初始型号，不必排第二次队。

八家初始系列都没有专项保护，也共用每名玩家一个初始货柜的名额；正在施工的也算。多攒几张图纸可以练习整理文件，不能多开几个名额。

> [!WARNING]
> 注销会清除当前许可证经验、航运风格和签发制造商声望，但保留货柜。重新注册可以再次领取蓝图，却不会增加初始柜名额。不要把注销当作补领成品货柜的方法。

收好图纸后，先看[结算器与航运资金](entry:cargoverse:getting_started/settlement)备齐资金，再按[第一趟航运](entry:cargoverse:getting_started/first_delivery)准备出发。
