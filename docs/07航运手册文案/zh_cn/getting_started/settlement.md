# 结算器与航运资金

虚空结算器就是你的钱包，余额以 VB 表示。我出门检查两样东西：船能不能飞，钱包能不能收钱。货柜到了而钱包还在家里，柜台可不会先把欠款记在餐巾纸上。

## 带在身上

交易会使用主物品栏或副手中的结算器。放在箱子里的结算器不参与付款或收款。哪怕那箱子就在旁边，也请把钱包带在自己身上。

可以携带多台结算器：付款时依次扣除余额，收款时写入仍有空间的结算器。单台最多保存 1,000,000 VB；剩余容量不足以接收整笔货款时，交易不会只付一部分。

## 算清出发成本

- 购买货物需要 VB，确认数量后再检查总价。
- 普通货柜蓝图按打印目录收费；注册赠送的初始蓝图不需要另付打印费。
- 搭建货柜消耗实体材料。搭建器目前不另收 VB施工费，准备余额不能代替备齐材料。

注册不发启动资金。若暂时买不起第一柜货，先查收购目录，把自己采集或生产、且买方接收的货物装柜运过去卖。结算器可以空着去收款，但不能空着去付款；自产货也要走货柜装卸，终端不直接收你的背包。

## 柜台不肯成交时

先确认结算器是否随身携带，再核对付款余额或收款余量。交易前查看确认页，完成后检查货量和结算结果；一次交易未成功，不要仅凭动画判断已经付款。

> [!NOTE]
> 别往结算器里灌虚空混合物。那东西可以当货物运，但目前没有注入钱包兑换余额的服务，旁边接一根管道也不行。
