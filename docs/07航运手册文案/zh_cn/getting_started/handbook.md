# 读懂航运手册

这是企业配发的航运手册。百科里的补充说明由我这个退下来的运输员整理：柜台负责告诉你能不能办，我尽量告诉你怎样少跑一趟冤枉路。

## 先找到要看的那页

手持手册右键打开。左侧书签切换前五章，右上地图标签进入第六章，书页箭头在当前章节内翻页。飞行前先熟悉位置，别一边找书签一边找降落场。

## 六章分别看什么

- **航运档案**：签发机构、许可证等级、经验进度和剩余调度点。尚未注册时，相关档案为空。
- **货柜管理**：查看名下货柜、位置、装载情况与质量。它是资产目录，不是购买新货柜的商店。
- **制造商声望**：查看已发现制造商的介绍、关系称号与声望进度。想知道替谁跑单，翻这里；我就不在百科里替他们再念一遍宣传稿了。
- **生涯统计**：回顾承运、收支和近期成交站点。到访只在交易成功后记入。这里记得你挣过多少钱，却不会替你保管已经花掉的钱。
- **航运百科**：按主题查操作步骤、运输规则和常见问题。
- **贸易地图**：查看已知地点、贸易信息和个人目的地，帮助规划下一趟行程。

## 查阅百科

在百科首页先选分类，再点右侧条目。箭头只翻当前文章；页码旁的返回图标回到百科首页，不是回到上一次跳转前的文章。

图片可以点击放大。按Esc或背包键时，先关闭图片等当前展开内容，再退出手册。阅读位置会在当前游戏会话中保留，不保证重启游戏后仍停在同一页。

> [!WARNING]
> 货柜管理中的删除操作会删除资产和物理货柜，不返还货物、货币或材料。需要卸货时去装卸设施。把整个柜子删掉确实能让事情变少，但少掉的也包括你的财产。

运输途中需要查看柜内状态，可使用货箱信息PDA对准货柜，再右键查看详情。

从[第一趟航运](entry:cargoverse:getting_started/first_delivery)开始，或先办理[注册与初始蓝图](entry:cargoverse:getting_started/registration)。
