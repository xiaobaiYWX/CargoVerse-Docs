# 规划一条运输路线

一条航线至少要回答三个问题：哪里有货，哪里肯收，你有没有本事把它完整运过去。第四个问题是回程干什么。

## 起飞前的短清单

1. 查卖方当前商品、价格和可售量，再查买方同一货物的收购、繁荣解锁和今日余量。
2. 选对介质与保护能力，核对货柜容量、满载质量和载具承载余量。
3. 计算购货资金、预计收入及可能货损，给结算器留足收款空间。
4. 设定目的地，观察高度差、地形、装卸场地和回程补给。

第一次先小批量试跑，摸清进港、停柜和交货位置。玩家站可能缺钱缺空间，自然站的货也可能被先买走；熟悉一条线，是熟悉它会在哪里出岔子。

## 回程也算一趟

目的地有没有返程货，下一站缺什么，能否顺路提交供应，都可以一起考虑。换货前正常卸空；不要为了省一次靠泊，把不同商品都塞进同一柜。

例如顺路送了一批升级物资，柜子会空出来，钱包却不会因为这次供应增加。下趟购货资金要另留。算收益时也把货损与绕行时间记上，进价便宜只是开头。

抵达后重新检查报价，再确认卸货。记下实际到账、剩余货量和满载操纵表现，第二次再决定扩大运量。我更信跑完这一趟的账，而不是出发前最乐观的那一行。
