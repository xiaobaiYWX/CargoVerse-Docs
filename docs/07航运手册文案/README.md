## 叙述口吻与信息边界

手册为企业配发，由一位从业多年的前运输员整理，以“我”的经验对“你”说明。允许适量经验、吐槽和案例，不额外编造姓名、职务、重大亲历或企业权益。关键操作、费用与不可逆后果明确写出，笑话不能代替限制说明。

制造商背景由声望页表达，百科只说明注册、声望和实际权益。货运磁铁不纳入正文。天空大站的注册流程被视作入职考验：公司不配船，玩家要解决实际运载条件；搭方块等方式登站仍可注册，不虚构终端检测载具的准入规则。

使用玩家可观察的名称和反馈，不在正文写代码类名、配置字段、存档迁移或测试报告。区分件、组、mB、只、舱位与 Kpg；价格、库存、配方和能力优先引导看当前界面。当前未提供生存配方的仪表与配平方块如实说明，不让玩家追查不存在的配方。
