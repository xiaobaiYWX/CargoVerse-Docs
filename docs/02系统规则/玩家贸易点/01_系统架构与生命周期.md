# 玩家贸易点：系统架构与生命周期

玩家贸易点将站点身份、终端商品配置和实际物流分开。站点归属通过 GUI 显式选择，隧道链接器决定终端关联的仓储地址，物流隧道只在实际转移时核验可达性，不传播所有权。

## 1. 职责

| 对象 | 保存的内容 | 不承担的内容 |
| --- | --- | --- |
| 管理核心 | 站点 UUID、名称、所有者、管理员、结算器、交易统计和已绑定终端地址 | 商品报价、原生库存、物流网络占用 |
| 货物出售／收购终端 | 本台报价与上架状态、绑定站点 UUID、固定装卸区对齐、表面选择 | 站点公共库存或其他终端的价格 |
| 仓库管理终端 | 本台物流视图、管理区域与免费装卸设置 | 公共商品报价 |
| 物流隧道入口／链接器 | 原生容器接触位置、目标终端地址与设备 UUID | 核心归属、内容副本、仓储独占预留 |
| 物流隧道 | 几何连接及运行时可达缓存 | 站点身份与授权 |

物品与流体保存在支持通用能力接口的原生容器，包括箱子、木桶、炼药锅、Create 保险库和储罐；生物库存是打包机区域内实体的只读识别视图。不同站点的终端通过各自入口及链接器可以使用同一管线及同一容器，实际转移仍由服务端串行重验和结算，不复制库存。

## 2. 核心认领与绑定

核心放置时生成 UUID，未认领时不加入已注册站点索引。手持结算器插入槽位即可认领，所有者为插入者，名称默认“玩家名称的贸易点”。实际结算器及余额保存在核心内，创造模式也不能复制。每位玩家可认领的核心数量不限，不设置所有者配额。AUTH 只管理名称和授权，不再提供注册／注销操作。

终端 GUI 的侧栏列出同维度、广播范围内已加载的已注册站点，不预先按权限或可接入状态过滤；点击时由服务端检查权限、核心状态和组件接入条件。标签显示站点名称，过长以 `...` 省略，悬停可查看完整名称、所有者及距离。最多显示 9 条，超出后滚动；已绑定站点显示绿色勾，再次点击可解除绑定。玩家主动选择绑定；不自动寻找最近核心，不因隧道连接自动换绑。每台终端最多属于一个站点，每站可拥有多台同类终端。广播范围为直线距离，`bindingRange` 默认 32 格，可配置 1～512；与物流路径距离分别计算。仅读取已加载核心，不为搜索强制加载区块；列表出现不代表当前可绑定，失败时提示原因并保留原绑定。

玩家出售、收购终端的任意成员空白处可右键打开管理员 GUI，仅对无归属设备或站点所有者／授权管理员适用。表面按钮、拉杆和滑条优先执行其原有交互，交易条件不满足也不会转而打开管理员页；空手及手持物品行为一致。所有玩家均可通过表面按钮浏览、选择与确认交易。其他功能终端可空手右键本体空白处打开带绑定侧栏的管理入口，既有表面按钮保留原功能，连接工具也可打开该入口；管理及生物区域仍使用 Create 扳手形成。

核心、信息柜、航标塔不需要接物流隧道。核心 PWR／STOP 保留模型和按钮位置，本版不执行激活、暂停或改线动作。注册且有效的核心即可提供管理身份，公共成交还需已安装的结算器、有效终端及本次库存路径。

## 3. 生命周期

- 切断隧道只阻止实际库存转移；显式绑定的已加载库存仍可查看，保留终端绑定、报价和区域配置。
- 临时缺货或拆除容器保留本台报价，重接后恢复；不给断线库存生成副本。
- 核心暂时卸载保留绑定，公共交易暂停；不强制加载核心或库存区块。
- 核心改名不改变 UUID；弹出结算器或拆除核心使旧 UUID 失效并解除终端归属，原生内容和终端本地报价不随核心清空。
- 所有人都能拉下结算器面板的拉杆，动画完成后才检查所有者权限。仅所有者可以将结算器从基座抛出；不会直接返回背包。弹出解除归属并清理站点名称、授权、统计和绑定，为原方块生成新 UUID，旧菜单不能管理新身份。
- 结算器弹出后公共交易立即不可用，原生容器内容和终端本地报价保留；重新插入可认领，终端需按新身份重新绑定。三个接入指示灯只显示收购终端、出售终端及航标塔是否接入，缺项不阻止其他交易。
- 装卸区域固定为终端模型南面的 16×16×8，独立保存左／中／右对齐。仓库管理和生物打包机继续使用本台与三根对应颜色标记杆形成区域。

## 4. 权限与边界

无主核心由插入结算器的玩家认领；弹出、改名和授权仅由所有者控制。交易终端商品配置、归属选择及区域设置允许当前站点所有者和授权管理员操作；每次请求重新核验当前菜单、设备实例、8 格操作距离、身份、范围和实时权限，撤权后旧菜单立即失效。无归属终端允许附近玩家打开并配置，绑定目标必须是该玩家有管理权的站点。

绑定不赋予原生容器领地保护；通过真实管线接通即可共用仓储，外部 Create 自动化不受站点权限保护。隧道不再属于某个站点，也不因接通不同站点而破坏或拒绝放置。

设施可放置在 Sable 上但不能绑定、组成有效物流或使用，不做设施坐标换算；普通 Sable 货柜仍可进入静态终端范围装卸。大型玩家终端质量继续为每台 1000 Kpg，仅控制器计重。

## 5. 代码职责与维护入口

- `PlayerTradePointBlockEntity` 统一处理插入认领、所有者弹出、账户读写及解除归属，其他交互入口不得单独改写所有者或复制结算器余额。
- `PlayerTradePointSavedData` 维护站点地址和空间索引；加载注册只写元数据，不在加载回调查询相邻方块或容器。不维护另一份所有者配额缓存。
- `PlayerTradePointSurfaces` 统一表面控件与结算器槽位坐标，渲染和物品弹出共用锚点。指示灯只用于展示，交易继续核验 `isOperational()` 和终端自身条件。
- `PlayerTradeCoreMenu`／快照与改名包只管理名称和管理员。物品插入、拉杆交互及解除归属走服务端物理交互路径，菜单持有打开时的核心 UUID，身份变化后失效。
- 核心 GUI 使用 240×256 图集，背景只绘制上方 240×206；管理员标签、加号与滚动条独立裁切，不包含认领或注销按钮。
