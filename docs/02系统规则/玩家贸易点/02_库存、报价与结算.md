# 玩家贸易点：库存、报价与结算

## 本台库存与商品配置

每台设备通过隧道链接器显式关联入口及其背面的原生容器，库存浏览不触发隧道搜索，实际转移才核验物流路径。站点绑定只提供管理权限和结算账户，不提供远程库存；同一核心下两台终端不自动共享仓库，不同核心下的终端可以分别配置入口及链接器，共享同一容器。

出售终端保存自己的出售价格和上架状态，收购终端保存自己的收购价格和上架状态。管理员右键终端任意成员打开编辑器，复用仓库网格，但只显示本台对应的一种业务模式。按名称／ID／运输类型筛选及名称、数量、价格排序；先选择一个有实际库存的精确变体，再输入价格并上架，删除只清理当前选择。侧栏按搜索结果逐条绘制归属标签，最多显示 9 条，支持滚动、绑定及再次点击解除；范围内站点不按权限预筛选。管理 GUI 使用玩家贸易点管理图集，搜索、价格和固定按钮使用背景现有图案，仅补充动态内容、状态标记和交互反馈。现有报价在库存为零时保留，编辑网格仍只展示有库存的变体。

仓库管理终端仅查看本台库存并执行免费管理装卸，不再配置公共买卖。生物按物种汇总，个体颜色、年龄及生命保留在实体载荷中。

## 原生存储

物品使用通用物品能力接口，流体使用通用流体能力接口，包含原版箱子、木桶、炼药锅及 Create 储存设施；入口从背面接触点解析容器，Create 控制器和双箱去重。结构拆分后跟随实际附着点，不保存旧控制器地址，不维护影子库存。

不设置保险库或储罐的玩法数量配额。内部安全边界统一见[物流预算](../../03组件手册/玩家物流/04_物流隧道.md#距离与内部安全预算)，超限视图不可用于交易，不截取一部分库存后冒充完整视图。

## 交易与守恒

公共目录和表面只读取本台报价与本台显式关联的已加载库存。出售目录选货更新本台表面；收购目录选货只供当前浏览者查看价格，实际卸载显示柜内载荷，未报价货物仍可查看。公共交易统一进入玩家私有确认页。

服务端提交时重验站点身份、绑定范围、核心及结算器、终端实例、当前物流路径、精确货物、货柜所有权与容量、原生库存和资金。交易经串行执行与原生转移回执处理，失败补偿货物和货币；共享管线、多终端或多站点不产生第二份余额或库存。

价格按操作单位填写：固体一组为该物品最大堆叠数，流体为 1000 mB，生物为一只。原生数量使用 pcs／mB／mob；尾量按实际比例结算，货币向上取整为整数 VB、质量向上取整至 0.1 Kpg。公共交易款项记入本台绑定核心的结算器，与同管线上其他站点的账户分开。

玩家目的地不奖励许可证经验、自然站繁荣度或制造商声望。免费管理装卸不收费、不记公共贸易统计；权限、货柜占用及失败恢复仍然检查。
