# 贸易点运行时与经济

自然贸易点分别处理常规交易和物资供应。常规出售与收购按站点报价使用 VB，物资供应推进公共繁荣度并为交付者提供制造商声望。

## 身份与绑定

贸易点定义 ID 描述配置，实例 UUID 区分具体站点。世界生成时，结构配置首次预填定义和同结构子终端的 UUID。手动放置时，管理员填写定义并在子终端选择站点。两种站点都可通过同一套 GUI 管理。右键信息柜可编辑定义并复制 UUID。空手潜行右键子终端或装卸定位点可选择同维度 128 格内已加载的信息柜，点击带勾的条目解除绑定。管理员的修改和解绑会保存，并优先于后续生成。

## 资源目录初始化

定义通过 resource_table 引用资源表。首次建立状态时严格解析实际物品及完整组件，生成精确变体的出售/收购目录；同侧不能重复，同站同一变体不能双向交易。出售侧有 stock 才建立有限库存，省略为无限供应；收购侧 daily_limit 省略或 0 表示不设限。

站点保存报价、库存与额度策略、收购侧许可证经验和最低繁荣度等级。通过繁荣度解锁的报价随等级提升持续开放。普通 reload 保留既有实例的报价快照。管理员可在信息柜确认应用不同或相同的定义 ID，丢弃旧库存、额度和供应进度，按当前数据包重新初始化库存、繁荣度、供应阶段和模块选择。站点 UUID、子终端关系和累计交易总额继续沿用。字段见[报价定义](<../../04数据规范/贸易点/03_资源表定义.md>)。

## 出售库存与收购额度

出售库存仅为有限供应条目保存整数物品数，购买后扣减，各条目独立容量。自然站收购不保存实物仓库；交付计入所有玩家共享的当日额度，不转成出售库存，也不自动生产其他物品。

玩家贸易点使用另一套[Create 保险库存储规则](<../玩家贸易点/02_库存、报价与结算.md>)，不能将自然站虚拟供需库存复制成玩家仓库。

## 贸易日结算

跨过完整贸易日时一次性处理补货和动态价格，清空当日收购、售货机计数和贸易额：

```text
出售库存 = min(容量, 当前库存 + 每日补货 × 经过天数)
```

未用每日额度不累积。日长来自 ticks_per_day。信息柜的当日贸易额是自然贸易点出售、收购和售货机成交的实际 VB 金额之和。

## 繁荣度

繁荣度由[物资供应](<03_物资供应.md>)推进，并解锁报价和相应商店模块。常规运输仍可按[许可证经验规则](<../../04数据规范/贸易点/03_资源表定义.md#运输经验资格>)发放许可证经验。

## 价格、制造商与声望

- 每个站点用自己的 unit_price 定价，应用动态行情和最后一层制造商签约修正；没有全局物品基础价格。
- 按实际转移数量结算，货损已经扣掉件数，不再乘完整度。
- 动态价格按精确物品变体独立记录并按贸易日恢复。
- 签约价格修正仅在许可证签发制造商与站点制造商匹配时生效。
- 沿用许可证签发与蓝图资格中的相关规则。货运贡献的制造商声望由所属贸易点的物资供应需求单独配置与结算。
- manufacturer 为 none 不产生制造商声望或签约修正。

普通物品商店、货柜制造台和注册点保留独立功能配置及结算边界，不向货物资源表隐式添加商品。

## 加载与存档

设备、运输、制造商、功能、资源表和站点定义与服务端物品标签统一校验发布。经济存档 DataVersion=17。读取版本 16 时延用已结算贸易日、库存、额度、繁荣度和供应进度，当日贸易额从首次升级后的实际成交金额重新累计；货柜、内容封套和网络版本以[运输数值运行时](<../货物与货柜/14_运输数值运行时.md#保存采样与性能>)为准。开发期不迁移旧实例或旧抽象经济/完整度/自有仓库，不保留旧版本逐级转换链。损坏或未知原生类型的新载荷保留原文隔离，不静默恢复成空柜。

实现入口：TradePointState、TradePointStateCodec、TradePointInventoryService、TradePointAcquisitionLimit、TradePointDayProcessor、TradePointTransactionService、NaturalTransportExperienceService、TradePointSupplyService。
