# 商品展示牌

使用 `cargoverse:trade_point_commodity_panel` 屏板竖向拼装。有效尺寸为 2×3 和 4×6（宽×高），组成屏幕的方块须同朝向且共面。相邻整屏留一格空隙。自然生成时按所在结构绑定贸易点实例。手工布置时，管理员空手潜行右键屏板，从列表中选择贸易点。

每张卡片显示制造商标识、货物图标、收购或出售方向、货物名和每份公开单价。展示牌依次轮播站点当前繁荣度开放的出售与收购报价，每 100 tick 切换。旧卡片向上移出，新卡片从下方移入，过渡用 12 tick。无制造商使用默认标识。

公开单价取本站基准价乘行情倍率，结果向上取整为 VB。个人签约修正以实际交易为准。每份按组、1000 mB 或一只结算。屏幕仅展示报价，库存、当日额度和交易资格由交易终端核验。
