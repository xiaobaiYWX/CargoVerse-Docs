# 繁荣度显示屏

贸易点繁荣度屏板的 ID 为 `cargoverse:trade_point_prosperity_panel`。屏板竖向放置，正面朝向放置者。将同朝向的屏板放在同一平面，拼成 4×2、6×3 或 8×4 的完整矩形（宽×高），即可自动组成整屏。相邻整屏之间留一格空隙。

整屏显示站点名称、繁荣度等级和距离下一级的经验进度。达到最高等级时，进度条填满并显示满级提示。

整屏根据绑定站点定义的 `manufacturer` 选取背景。AUI、SPL、DMC、VBS、BDS、HEC 和 REX 各有专用背景。无制造商归属或未配置专用背景的站点使用独立贸易站底图。所有背景共用等级图标、数字与十节辉光管，每累计完成当前等级所需经验的 10% 点亮一节，管组上方显示还需多少 XP。未绑定屏幕采用默认底图，站名铭牌显示“未绑定贸易点”，辉光管全灭。

绑定后，站名显示在右侧铭牌，等级数字下方显示繁荣度阶段。0 至 5 级依次为荒僻站点、小型贸易站、标准贸易站、区域集散站、大型货运港和核心物流枢纽。数据包设定的更高等级沿用最高阶段名称与图标，等级数字显示实际值。

繁荣度显示屏、贸易点信息柜和贸易地图上的自然贸易点标记共用公共图集里的六个等级图标。

手工建设时，在管理员模式下用终端连接器右键已注册的自然贸易点信息柜，再右键整屏任意一块屏板即可绑定。在自然贸易点结构模板中放入屏板，自然生成时会随同一结构实例绑定。一个站点可有多块屏幕。

破坏任意一块屏板会使原屏解体，其余屏板留在原位。手工绑定的屏幕重新组装后需要再用终端连接器绑定。
