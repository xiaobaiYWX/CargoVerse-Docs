# 玩家生涯统计

航运手册第四章显示服务端存档中的累计数据。注销许可证后，已累计的生涯统计仍然保留。未完成航段随航运风格记录清除。

| 字段 | 计算规则 |
|---|---|
| 累计运输质量 | 累加各完成航段的启运货物质量。固体、流体和活体均按货物快照计入，单位为 Kpg。 |
| 累计承运量 | 累加各完成航段启运时的固体物品件数。流体和活体只计入质量。 |
| 完成航段数 | 同一玩家的同一货柜在两个不同自然贸易点先后成功装卸，且在下一站操作前仍装有同一货物时记一段。同站交易刷新启运快照。 |
| 货物采购支出 | 累加在自然贸易点购买并装柜实际支付的 VB。 |
| 货物销售收入 | 累加在自然贸易点卸货出售实际收到的 VB。 |
| 到访贸易点数量 | 按成功交易的自然贸易点实例去重。货柜买卖和售货机购买均计入。 |

右页的优先合作贸易点按个人与各自然贸易点累计成交额排名。成交额为购买与出售的结算金额之和，售货机金额计入站点成交额。达到相同成交额时按站点实例 ID 决定展示顺序。页面显示站点名称、繁荣度图标及成交额。

近期到访按最近一次成功结算排序，最多显示九个站点。同站再次成交会更新记录并移到首位。地图章读取同一列表中的前三条。经过站点、打开界面、物资供应和失败结算均不产生到访记录。

交易统计与结算共享回滚机制。旧存档中明确记录为固体的承运量可继续累计。已记录的到访站点继续计数，已有的最近成交记录可继续显示。站点成交额从新版的实际结算开始累计。
