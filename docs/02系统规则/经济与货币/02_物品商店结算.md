# 物品商店结算与交付

## 价格结算

最终付款值按以下顺序计算：

```text
offer.price × 购买份数 × 制造商签约声望购买修正
```

结果按统一整数货币规则四舍五入并从玩家携带的虚空结算器中扣除。玩家未签约该贸易点制造商时，制造商修正为 `1.0`。世界表面仪表是多人共享显示面，只显示基础 VB 价格；最终服务端成交值以购买玩家自身的签约与声望为准。


## 购买事务

购买在服务器串行事务内完成：

1. 复核玩家许可证、终端结构、贸易点绑定和模块定义；
2. 重新读取繁荣等级、选中 offer、购买份数与当日共享库存；
3. 计算制造商优惠后的 VB 总价并检查虚空结算器余额；
4. 扣除 VB；
5. 有限库存记录本次已售份数，无限库存跳过；
6. 将结果物品写入该售货机的待领取区；
7. 将实际付款计入贸易点交易总额；
8. 提交后刷新仪表。

付款、有限库存、待领取物和经济记账均注册逆序补偿。任一步失败都不会留下部分成交状态。


## 待领取区

- 购买结果不会直接进入购买者背包。
- 任何玩家都可右键出货成员领取。
- 背包只能容纳一部分时，仅提取实际插入的数量。
- 待领取物跨存档和区块卸载保存。
- 多方块终端拆除时，剩余物品只在控制器位置掉落一次。
