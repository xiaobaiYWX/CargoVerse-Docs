# 运输系统的三层职责

| 层 | 声明／产生位置 | 独立文档 |
| --- | --- | --- |
| 货物运输条件 | 物品／流体的 `transport_conditions`，表达需求和损耗参数 | [逐项条件](<../../04数据规范/运输属性/运输条件/README.md>) |
| 货柜能力 | 货柜的 `abilities`，表达配备及物理响应 | [逐项能力](<../../04数据规范/货柜/能力/README.md>) |
| 货柜核心能力数值 | 柜体防护、直接观测和条件判定 | [逐项核心数值](<../运输状态/README.md>) |

装入有保护能力的货柜后，货物仍保留原运输条件。路线风险按实际高度、群系、降雨或浸水判断。

粉料由围护等级 1 保护。易碎品比较相隔 10 tick 的速度向量差和基础耐受加缓冲增量。冷冻及保温运输由主动调温保护，持续缺少保护时产生货损。

货损直接扣真实原生库存（固体 pcs、液体 mB），没有第二份完整度库存或损坏货物替代物。百分比只是显示。统一会话保存冻结规则、内部状态、当前的条件计时和事件去重；不建立逐 ID 免疫或独立扣量引擎。

现有 [PDA](<../../03组件手册/手册与导航/04_货箱信息PDA.md>) 提供详细状态查看，不继续扩展复杂设备操作。正式内容和实机参数仍需校准，见[待完成清单](<../../90设计草案/待完成事项清单.md#运输条件与能力专项>)。
