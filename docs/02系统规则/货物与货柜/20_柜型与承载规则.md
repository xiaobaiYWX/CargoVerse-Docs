# 现行货柜规则

更新：2026-11-06。能力以当前数值定义和装载冻结规则为准，仍带旧字母保护的型号资料不能作为运行效果依据。

## 承载与保护

- 介质为 solid、liquid、living。气态 Fluid 使用 liquid 通道，粉末和颗粒使用 solid，活体按已配置物种准入。
- 单柜保持同一精确身份。固体容量按冻结最大堆叠组计，流体按桶计，活体按物种舱位计。嵌套内容执行独立准入检查。
- 形态不匹配或准入失败拒装；数值能力不足通常只提示结构缺口，实际暴露由环境与运行求值决定，不按用途或品牌独占许可。
- 内置货柜统一使用 abilities，具体参数在型号页维护。液体柜至少显式配置密封 1。
- 遮光、温压调节、朝向保持与其他能力按实际配置生效，保存需求与承运能力在装载时冻结。

## 参数和规格

| 规格 | 参照容量（组） | 参照空重 Kpg | 普通调度点 |
| --- | ---: | ---: | ---: |
| S | 50 | 20 | 1 |
| M | 120 | 45 | 2 |
| L | 300 | 95 | 4 |
| X | 600 | 180 | 6 |
| XL | 1000 | 300 | 8 |

各系列有明确整数参数，不从 NBT 体积自动求容量或规格，也不新增隐藏承重上限。物品单位质量独立计入；实际空重至少为结构质量，质量占位补齐不足部分。数值用于开发验证，仍需载具运输实测。

## 接口、制造和初始权益

定义 ID 稳定，不从 ID 后缀判断实际 size_class 或接口。接口代号必须与 NBT 命名及实际接口块一起核对；不得借用其他系列的结构或接口作为已完成设计。8 家各一份初始货柜权益，只有标记为基础资产才免调度点，普通同型号正常计点；HEC 当前初始为 Apollo M，DMC 为 Boreal M，其余为 S。

制造配方按实际规格检查许可证。Silo 已在矿物分选精炼站投放。Reliquary 两款及 BioPod 三款通过测试站获取。制造材料和费用见制造总表。已有载荷保留冻结身份，物理结构不自动换壳。
