# 物品运输质量

`mass_per_item` 表示一件固体物品的运输质量，单位 Kpg。正质量以 0.1 Kpg 为增量，最轻为 0.1 Kpg。配置为 0 的物品仍占用货柜容量，照常计算货损和交易。

载货质量＝实际件数×单件质量。最大堆叠量用于装卸步长和报价折算。物品的运输质量由逐物品数据决定，放置为方块后的物理质量独立配置。

| 物品 | Kpg／件 | 50 件货重 Kpg |
| --- | ---: | ---: |
| 石头、橡木原木、铁锭、玻璃、鸡蛋 | 0.1 | 5 |
| 铁镐 | 0.5 | 25 |
| 羽毛 | 0 | 0 |

换算基准为原每组质量除以注册表中的默认堆叠量，再向上取至 0.1 Kpg。原有零质量保留。具体数值以逐物品 JSON 为准。缺少数据包定义的物品默认 0.1 Kpg／件。

首次装载时冻结单件质量和操作组大小。已有的按组计重载荷继续按保存的组质量结算至卸空，使用新数据重新装载后按件计重。货柜总质量为结构基线与定义空重中的较大值加上载货质量。
