# 物品运输质量

更新：2026-11-03。unit_mass表示完整ItemStack一整组的质量；默认最大堆叠从实际注册读取，组件改变上限时以首次装载的精确变体冻结。所有内置固体属性已按整组重新赋值，不是旧按件质量统一乘倍率。

## 计量

载货质量＝原生件数÷冻结组大小×每组质量，整柜最终向上取至0.1Kpg。不逐件向上取整；零质量仍占容量、受损和结算。容量50表示50组：64堆叠3200pcs、16堆叠800pcs、不可堆叠50pcs。

普通石料基准1Kpg／组；50组石料货重50Kpg。木材完整族0.5、致密原矿与锭1.5、实心金属块2，大型装配3、重型工业设备5。轻质成品使用0.1／0.2，微小薄片可为0。加工用途不改装载形态，石头与石砖、末地石与末地石砖保持相同质量档。
