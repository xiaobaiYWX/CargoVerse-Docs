# 运输观测与生命周期

物理来源和逐项计算分别在[核心数值](<../运输状态/README.md>)维护；配置在[公共协议](<../../04数据规范/运输属性/00_配置公共协议.md>)。本页只维护共同推进、事务、冻结与成本边界。

## 观测与推进

每 20 tick 按有效货柜的冻结条件判断外部群系、降雨、浸水、世界高度及光照。Sable 货柜按姿态转换到主世界坐标，浸水只从柜体内的采样点判断。气压调节可跳过受保护的气压采样。保持干燥仍读取降雨及浸水，用于绘制示意指针。含温度条件的货柜采集一份统一温度，柜体防护按各词条规则判断。观测缺失时暂停对应的条件计时。未加载的区块不强制加载。

冷冻及保温运输在持续缺少主动调温时各自产生货损。冲击继续按间隔 10 tick 的端点速度差结算。保持正放才额外采样重力与承载面倾角。光照保留遮光及补光规则。

## 冻结与重载

- 空柜首笔正数成功提交冻结货物需求、承运能力、响应参数和完整校准表；预览、取消、失败、零转移不产生批次。
- 有货读冻结值，空柜下次装载读最新有效定义；制造不永久冻结运输能力。
- 追加要求精确身份和计算规则兼容，规则／准入／能力变化时拒绝混代追加，但现有有效载荷可安全卸出。
- 工作设置属于实例，改设置不刷新实际状态与损耗预算。空柜保留设置不再受支持时安全退回关闭。
- 版本只在[数据契约](07_运行时与存档.md#当前数据契约)维护。当前机械封套仅保存事件检查点，不保存连续速度基线；旧规则及旧采样封套原文隔离，不保留旧窗口算法或猜测迁移。
- 正常环境提交、同批追加和部分卸出保留运行缓存；卸空、停用、重绑、批次替换、会话恢复及失效取样清理缓存。

## 追加与卸出

| 事件 | 当前语义 |
| --- | --- |
| 首次装入 | 冻结条件与能力，建立有效观测基线并初始化计数 |
| 追加 | 先结算已有有效观测，新量继承整柜当前的条件计时和事件状态 |
| 部分卸出 | 先结算再转移，剩余载荷状态保持 |
| 原生卸出 | ItemStack／FluidStack 不保存条件计时；卸入原生库存后再装会建立新会话 |
| 全卸／损耗归零 | 清载荷及会话，保留货柜身份与工作设置 |
| 世界／载体卸载、停机 | 保存并暂停，不按离线时长补算；恢复重建基线 |
| 取消、失败、重试 | 数量与状态沿同一事务提交／补偿，不重复扣量、不生成影子库存 |

## 数值与成本边界

每个持续型词条独立计时。相邻两次有效观测均不符合要求时，按两次观测的间隔推进计时。确认恢复合规时重置该词条的宽限和扣量周期。同一轮各项货损相加，固体和流体实际扣除量以剩余数量为上限。

- 环境任务按 ID 分 20 个桶，运动任务分 10 个桶，每 tick 只处理对应桶。设有环境需求的加载柜为 N、易碎柜为 F，平均约 N/20 次环境推进与 F/10 次速度取样／tick；桶不是硬性毫秒或数量预算。
- 每个易碎柜仅保留相邻两端速度，每次有效样本做一次向量差。1000 个柜平均约 100 次比较／tick、2000 次／秒；这是操作量估算，不是实测 CPU 耗时或承载保证。
- 到期门控先于物理提供者读取，装卸与重复调用不会在间隔内追加取样。PDA 查询只读取已提交的近期温度、状态与致损撞击历史，环境读数有效期为 20 tick。
- 同载体同 tick 共享姿态、质心和基础速度，同参考点共享点速度。每柜保留自身角速度项；纯易碎柜不建立环境任务，速度取样不读重力／倾角。
- 无货损的速度采样留在运行缓存。货损、撞击事件去重与最近一次致损速度沿原事务提交。未提交提案不消费事件，装载重置显示记录时保留事件去重。
- 纯状态更新不刷新物理质量或重建空间索引；数量／质量、载体、贴花变更进入各自派生队列。同步只发必要摘要，不逐 tick 广播整仓或物性。
- 自动存档仍编码整份货柜账本，速度基线不保存，最近一次致损撞击速度随账本持久化；未加载但有需求的资产可能留在调度桶做可用性检查。当前没有跨柜总预算，真实多人负载、分配／GC 和存档停顿仍待实测。
