# UI 信息显示与数据入口

## 权威数据

| 内容 | 服务端来源 | 客户端用途 |
| --- | --- | --- |
| 货柜、所有权、实际物品载荷、时限、物理状态 | `CargoContainerInstance`、`CargoInstanceRepository` | 模型、数值、图标 |
| 贸易点定义、模块、库存与经济 | 贸易点注册表及运行时状态 | 终端仪表 |
| 装载候选与价格 | `ContainerLoaderBlockEntity` 展示快照 | 选择和预览 |
| 卸载候选与价格 | `CargoUnloaderBlockEntity` 展示快照 | 选择和预览 |
| 玩家执照与基础货柜资格 | 玩家档案 SavedData | 航运档案、注册终端 |
| 许可证经验与航运风格 | 对应 SavedData | 等级、进度与雷达图 |
| 实际物品名称与图标 | `ItemCargoPresentation`、`ItemCargoNames`、`ItemCargoIcon` | 普通 GUI 与世界表面仪表 |

客户端快照只用于展示。按钮、滑轨和删除请求到达服务端后必须重新读取权威状态并验证，不能从显示文本反推业务字段。

## 世界表面终端

下列终端的日常操作直接发生在模型表面：

- 贸易点信息柜；
- 仓库信息柜；
- 货柜制造台；
- 货柜装载机；
- 货物卸载机；
- 物品售货机；
- 许可证注册终端。

仪表基座属于方块模型。运行时只在表面绘制动态内容、按钮与滑轨。模型姿态、命中面、高亮、音效和动画由世界表面 UI 公共组件统一处理。

## 管理员绑定

普通贸易点信息柜是实例注册锚点，其管理员界面选择已加载的站点定义。手动普通点由管理员手持终端连接工具选定信息柜，再右键连接终端或定位点，范围为 128 格；不再手工复制实例 UUID 到各终端。

自然生成结构在生成阶段绑定内部终端，生成后锁定，管理员也不能用工具解绑或二次绑定。普通手动点不设置必须终端清单，实际装卸仍需对应终端和区域。

玩家点以核心为锚点、范围 32 格，绑定和解绑只允许所有者，管理授权不包含连接工具权限。普通终端绑定后继承核心归属，区域标记杆只以成功创建的整体区域绑定；仓库通过专用收发器定位 Create 保险库，不直接绑定保险库。详细交互见[玩家贸易点](../11玩家贸易点/README.md)。仓库管理终端恢复为可选管理组件，SET 只限所有者、管理装卸向授权管理员开放；商品菜单宿主为仓库终端，报价仍存于核心。

注册终端不保存交互玩家 UUID；每次按钮请求使用当前请求玩家并重新验证权限。

## 未绑定状态

手动放置的终端初始不绑定贸易点。空 UUID、未知实例、缺失模块或无效定位点都不会选择默认值。

未绑定时：

- 终端模型、仪表外壳、按钮和滑轨继续绘制；
- 主状态仪表显示未绑定；
- 业务数据栏为空或零位；
- 服务端拒绝业务动作；
- 不创建默认贸易点经济状态；
- 装卸和生成不会回退到终端坐标。

## 实际物品图标

`ItemCargoPresentation` 提供精确物品变体的有界展示信息，普通 GUI 与世界表面共用原生物品名称与图标：

- 图标按实际物品及组件绘制，不维护抽象货物专属 PNG 目录；
- 货柜贴花由物品属性直接指定，独立于三大形态，不代替具体物品图标；
- 展示目录不能当作交易准入、报价或完整载荷的权威来源；
- 货柜保存完整物品身份，名称或图标缓存不能改写它；
- 数据发布、退出服务器和资源包重载时清理客户端缓存。

护目镜下的物品悬停只显示装载限制和需求，不显示固体／液体／气体／活体分类或默认来源。blocked 仅“无法装载”；empty_storage 为“仅允许空容器”；需求为“运输需求：词条名称”，无括号说明。普通无需求物品不添加运输提示。后台分类仍可供专用界面筛选，悬停本身不请求网络。

## 传统界面

传统 Screen 用于需要文本录入的管理员配置、玩家航运档案、地图与轨道管理等独立界面。管理员 Screen 先绘制模糊，再绘制半透明背景、面板、输入框和按钮，以保持字体与控件清晰。
