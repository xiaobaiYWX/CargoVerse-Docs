# UI 信息显示与数据入口

## 权威数据

| 内容 | 服务端来源 | 客户端用途 |
| --- | --- | --- |
| 货柜、所有权、耐久、Load、物理状态 | `CargoContainerInstance`、`CargoInstanceRepository` | 模型、数值、图标 |
| 贸易点定义、模块、库存与经济 | 贸易点注册表及运行时状态 | 终端仪表 |
| 装载候选与价格 | `ContainerLoaderBlockEntity` 展示快照 | 选择和预览 |
| 卸载候选与价格 | `CargoUnloaderBlockEntity` 展示快照 | 选择和预览 |
| 玩家执照与基础货柜资格 | 玩家档案 SavedData | 航运档案、注册终端 |
| 许可证经验与航运风格 | 对应 SavedData | 等级、进度与雷达图 |
| CargoGood 名称与图标 | `CargoGoodPresentation`、`CargoGoodIcon` | 普通 GUI 与世界表面仪表 |

客户端快照只用于展示。按钮、滑轨和删除请求到达服务端后必须重新读取权威状态并验证，不能从显示文本反推业务字段。

## 世界表面终端

下列终端的日常操作直接发生在模型表面：

- 生产线终端；
- 贸易点信息柜；
- 仓库信息柜；
- 货柜制造台；
- 货柜装载机；
- 货物卸载机；
- 物品售货机；
- 许可证注册终端。

仪表基座属于方块模型。运行时只在表面绘制动态内容、按钮与滑轨。模型姿态、命中面、高亮、音效和动画由世界表面 UI 公共组件统一处理。

## 管理员绑定

贸易点信息柜是贸易点实例的注册锚点。其管理员界面显示自动生成的只读实例 UUID，并编辑贸易点定义 ID。其他终端保存该实例 UUID，从注册表解析定义与模块。

| 设备 | 管理员配置 |
| --- | --- |
| 贸易点信息柜 | 贸易点定义 ID |
| 生产线终端 | 贸易点实例 UUID |
| 仓库信息柜 | 贸易点实例 UUID |
| 货柜装载机 | 贸易点实例 UUID、多个装载点 ID |
| 货物卸载机 | 贸易点实例 UUID、多个卸载点 ID |
| 货柜制造台 | 贸易点实例 UUID、一个生成点 ID |
| 物品售货机 | 贸易点实例 UUID |
| 许可证注册终端 | 贸易点实例 UUID、一个生成点 ID |
| 三类货柜定位点 | 原点偏移、范围尺寸 |

注册终端不保存玩家 UUID。每次按钮请求以当前交互玩家为目标。

非自然生成贸易点的配置顺序为：

1. 放置信息柜并选择已加载的贸易点定义；
2. 复制信息柜生成的贸易点实例 UUID；
3. 配置所需定位点并复制定位点 ID；
4. 将贸易点 UUID 与定位点 ID 写入对应业务终端。

自然生成结构在生成阶段注入这些绑定。

## 未绑定状态

手动放置的终端初始不绑定贸易点。空 UUID、未知实例、缺失模块或无效定位点都不会选择默认值。

未绑定时：

- 终端模型、仪表外壳、按钮和滑轨继续绘制；
- 主状态仪表显示未绑定；
- 业务数据栏为空或零位；
- 服务端拒绝业务动作；
- 不创建默认贸易点经济状态；
- 装卸和生成不会回退到终端坐标。

## CargoGood 图标

`CargoGoodDefinition.icon` 保存可选的静态 PNG 资源 ID。普通 GUI 与世界表面仪表共享同一展示目录：

- 专属图标缺失或损坏时显示问号；
- 图标不从 CargoClass 贴花回退；
- 名称与资源路径可同步，PNG 由资源包提供；
- 图标不写入货柜 Load 或存档；
- 数据发布、退出服务器和资源包重载时清理客户端缓存。

## 传统界面

传统 Screen 用于需要文本录入的管理员配置、玩家航运档案、地图与轨道管理等独立界面。管理员 Screen 先绘制模糊，再绘制半透明背景、面板、输入框和按钮，以保持字体与控件清晰。
