# UI 信息显示与数据入口

> 当前基线：主要装卸操作已迁移到世界表面 UI；旧装卸固定 Screen 和旧贸易点终端经济 GUI 已删除。传统 GUI 只保留确实需要文本／UUID 输入的管理员配置，以及尚未迁移的独立功能界面。

## 数据职责

| 信息 | 权威／展示来源 |
| --- | --- |
| 货柜、所有权、耐久、Load、物理状态 | `CargoContainerInstance` 与 `CargoInstanceRepository` |
| 装载候选、库存、价格与交易 | `ContainerLoaderBlockEntity` 展示快照；`CargoLoadingService` 服务端结算 |
| 卸载候选、需求、价格与交易 | `CargoUnloaderBlockEntity` 展示快照；`CargoUnloaderTransactionService` 服务端结算 |
| 世界表面终端展示 | 各 `*DisplaySnapshot`／`*ViewState`；只负责同步和显示，不是交易权威 |
| 结构预览 | `CargoStructurePreviewSnapshot`；不是世界实体贴花更新器 |
| CargoGood 名称与 UI 图标 | `CargoGoodPresentation`、`CargoGoodNames`、`CargoGoodIcon`；专属缺图回退问号，不读取 CargoClass 贴花 |
| 通用价格与数量 | `CargoPricePreview`、`CargoTransactionQuantity`、`CargoUnitFormatter` |
| 贸易点经济摘要 | `TradePointSnapshot` 与贸易点信息柜世界表面仪表 |
| 贸易点实例注册 | 贸易点信息柜保存 UUID 与贸易点定义 ID；其他终端只保存 UUID，并从注册表解析定义 |

客户端不得从显示文本反推业务字段，也不得直接修改库存、货柜或货币。装卸按钮进入服务端后，交易服务会重新读取当前资产与贸易点状态。

## 当前界面划分

### 世界表面主操作

以下终端的常用操作不打开 `Screen`：

- 生产线终端：产线信息与槽位操作；
- 贸易点信息柜：倒计时、活跃度、当日贸易额、名称和繁荣度；
- 仓库信息柜：Input／Output 库存单列分页；
- 货柜装载机：选柜、选货、数量和 `LOAD`；
- 货物卸载机：选柜、数量和 `UNLOAD`。

这些终端通过[世界表面 UI 系统](../10世界表面UI系统/README.md)共享画布、仪表、组件化控件、命中和服务端动作。模型自带底板的区域使用 `OVERLAY`，不额外绘制默认背景或内框。

### 传统管理员配置

贸易点信息柜是贸易点实例的唯一注册锚点。管理员界面显示自动生成且只读的贸易点 UUID，并提供唯一可编辑的“贸易点定义”字段；关闭界面时保存。输入值使用数据包定义 ID，例如 `cargoverse:resource/general/default`，不是磁盘绝对路径。服务端会复核管理员状态、距离、控制器和定义是否已加载；非法或不存在的定义会拒绝绑定。

非自然生成贸易点的配置顺序固定为：先放置信息柜并填写贸易点定义，再把信息柜显示的 UUID 填入装载机、卸载机、仓库信息柜、生产线终端、商店等功能终端。功能终端不提供贸易点定义输入框，也不接受结构生成桥额外注入定义 ID；同一 UUID 的定义、模块选择和经济状态均由信息柜注册记录解析。

所有手动放置的终端初始均处于“未绑定”状态，不再把空 UUID 或空定义字段解释为 `cargoverse:resource/general/default`。未绑定只影响仪表的内容层和服务端业务层：终端本体、仪表外壳、按钮和滑块照常绘制；主状态仪表显示“未绑定”，其余数据栏保持空白或零位。此时不会创建默认贸易点经济状态，按钮／滑块产生的服务端业务动作也会被拒绝。只有信息柜持有已加载定义、功能终端填写了对应实例 UUID 后，仪表才显示真实数据并启用操作。内置默认定义仍是可被明确选择的数据文件，但不再是终端空值的隐式回退。

货柜装载机和货物卸载机复用同一套管理员配置内容：

- 贸易点实例 UUID；
- 扫描中心 X／Y／Z 偏移；
- 扫描盒 X／Y／Z 尺寸；
- 保存设置和显示范围。

只有 CargoVerse 管理员模式下右键结构成员才打开。打开、保存和显示范围都由服务端检查管理员状态、距离、结构和控制器；模糊必须先于半透明背景绘制。

旧 `trade_point_terminal` 已降级为装饰方块，没有管理员 GUI、方块实体或同步状态。贸易点注册、定义绑定与经济展示均由贸易点信息柜承担。

## 已删除的旧装卸 GUI

旧 `cargo_loading_terminal`、`cargo_handling_terminal` 及其固定 `413×233` 三栏 Screen、Menu、滚动列表、网络包和专用支持类不再属于当前实现。文档、资源或历史记录中的以下描述均仅供追溯：

- “货物装载终端”／“货物装卸终端”旧方块 ID；
- `CargoTransferScreenSupport` 的固定尺寸；
- 从 Screen 菜单快照直接组织装卸交易；
- 贸易点终端三个经济面板的传统 GUI。

不要为新终端恢复这些旧入口，也不要让世界表面按钮模拟点击旧 Screen。

## CargoGood 图标

`CargoGoodDefinition.icon` 是可选静态 PNG 资源 ID。普通 GUI 调用 `CargoGoodIcon`；世界表面仪表调用同一展示目录生成 `IconMonitor.Icon`。统一规则：

1. 专属图标缺失或损坏时直接显示问号，不按 CargoClass 查贴花；
2. 展示目录只同步名称与资源路径，不同步 PNG，也不授予交易权威；
3. 数据目录发布、退出服务器和资源包重载时清理缓存；
4. 图标不写入 `CargoGoodSnapshot`、Load 或存档；CargoClass 外部贴花保持独立；
5. 普通 GUI 悬浮提示通过统一组件延后绘制，并遵守 pose 与 scissor；世界表面信息按终端布局显示名称。

## 独立界面

大型货柜制造台使用世界表面仪表显示型号、空柜质量、容量、耐久、制造价格和材料成本；复杂配置仅保留在管理员 GUI。商店、地图、轨道和航运界面也保留各自规范，本次同步不表示它们已完成实机验收。

## 验收重点

- 管理员 GUI 的模糊与背景绘制顺序、输入校验和距离失效；
- 手工贸易点由信息柜绑定定义后，所有只填写相同 UUID 的终端解析到同一注册与模块选择；
- 世界表面终端的六向、多方块、斜面、远近距离与低光显示；
- CargoGood 名称／图标在 `/reload`、资源重载和多人同步后的原子更新；
- 客户端快照过期、结构拆除或控制器卸载时不执行旧动作；
- 装卸交易实际改变货币、贸易点库存、货柜 Load 和物理质量。
