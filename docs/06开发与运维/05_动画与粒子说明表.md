# 动画与粒子说明表

本文用于美术、策划与程序之间交接简单方块动画和粒子效果。建模细节另见 [CargoVerse 简单动画方块制作规范](CargoVerse%20简单动画方块制作规范.md)。

## 一、当前能力总览

### 1. 简单变换动画

| 能力 | 当前状态 | 可调参数 | 典型用途 | 美术需提供 |
|---|---|---|---|---|
| X/Y/Z 平移 | 已支持 | 起点、终点、方向、距离 | 锁定轴、活塞、滑门 | 独立部件模型、初始位置、移动距离 |
| X/Y/Z 旋转 | 已支持 | 轴心、旋转轴、起止角度 | 舱盖、把手、指针 | 独立部件模型、Pivot、角度 |
| X/Y/Z 缩放 | 已支持 | 轴心、各轴起止比例 | 能量核心、管道膨胀 | 独立部件模型、Pivot、缩放比例 |
| 组合变换 | 已支持 | 平移、旋转、缩放组合 | 展开机构、复杂舱门 | 每项变换的参数和执行顺序 |
| 多活动部件 | 已支持 | 每个部件独立参数 | 双门、多活塞、多转子 | 每个部件分别导出 |
| 状态过渡反向 | 已支持 | 当前值、目标值 | 开到一半后关闭 | 无需额外动画资源 |
| Partial Tick 插值 | 已支持 | 自动 | 消除 Tick 间跳动 | 无需美术处理 |

### 2. 插值模式

| 模式 | 当前状态 | 表现 | 推荐用途 |
|---|---|---|---|
| `LINEAR` | 已支持 | 近似固定速度追踪目标 | 活塞、锁定轴、滑门、机械直线运动 |
| `EXPONENTIAL` | 已支持 | 初期较快，接近目标时减速 | 指针、操作杆、发光强度、柔和开合 |
| 固定时长关键帧 | 未支持 | 指定总时长和多个关键帧 | 后续确有需求再扩展 |
| 贝塞尔曲线 | 未支持 | 自定义速度曲线 | 当前不在范围内 |

系统使用 Create/Catnip 的 `LerpedFloat`。方块同步逻辑状态或目标值，客户端自行计算平滑过程，不会逐帧同步模型位置。

### 3. 持续动画

| 类型 | 当前状态 | 可调参数 | 计算方式 | 典型用途 |
|---|---|---|---|---|
| 匀速旋转 | 已支持 | 轴、每 Tick 角度、方向 | 渲染时间 × 速度 | 风扇、转盘、扫描器 |
| 正弦往复 | 已支持 | 轴、周期、振幅 | `sin(time)` | 上下浮动、机械振动 |
| 呼吸缩放 | 已支持 | 周期、振幅、缩放轴 | `1 + sin(time) × amplitude` | 能量核心、压力管 |
| 状态过渡与持续动画叠加 | 已支持 | 两套参数 | 组合模型变换 | 展开后持续旋转 |
| Create 动力旋转 | 已支持 | Create RPM、轴向、相位 | Create 动力渲染角度 | 齿轮、轴、动力部件 |

对于参加 Create 动力网络的齿轮和轴，应优先使用 Create 的 `KineticBlockEntity`、标准角度计算及 `AllPartialModels`，不使用普通匀速动画模拟。

### 4. 当前不支持的动画

- Blockbench 时间轴动画直接导入；
- 骨骼、蒙皮和模型形变；
- GeckoLib 动画格式；
- 任意数量的关键帧序列；
- 动画事件轨道和可视化动画编辑器；
- 自动读取 Blockbench 组层级作为骨骼。

## 二、粒子能力总览

当前注册了一种可复用的透明纹理粒子：`cargoverse:simple_effect`。同一粒子类型可以在调用时改变参数。

| 参数/能力 | 当前状态 | 说明 |
|---|---|---|
| RGB 颜色 | 已支持 | 使用 `0xRRGGBB` 指定，颜色与纹理相乘 |
| 粒子大小 | 已支持 | `scale`，必须大于 0 |
| 生命周期 | 已支持 | `lifetime`，单位为 Tick |
| 重力 | 已支持 | `gravity`，可为 0 或正负值 |
| 初速度 X/Y/Z | 已支持 | 每个粒子调用时传入速度向量 |
| 阻力 | 已支持但固定 | 当前固定为 `0.96` |
| 透明淡出 | 已支持但固定 | 按粒子年龄线性淡出 |
| 多帧 Sprite | 已支持 | 粒子 JSON 可列出多张纹理，按年龄切换 |
| 半透明渲染 | 已支持 | 使用 `PARTICLE_SHEET_TRANSLUCENT` |
| 方块碰撞 | 当前关闭 | `hasPhysics = false` |
| 客户端本地生成 | 已支持 | 适合点击、界面或即时反馈 |
| 服务端广播 | 已支持 | 适合所有附近玩家都应看到的效果 |
| 数量、扩散范围、速度 | 服务端广播已支持 | 使用原版 `sendParticles` 参数 |
| 点/盒/球/圆环发射器 | 未封装 | 目前需要调用方自行计算位置和速度 |
| JSON 编辑颜色、寿命和运动 | 未支持 | 这些参数当前由 Java 调用时传入 |
| 粒子可视化编辑器 | 未支持 | 当前通过纹理和参数表交接 |

### 粒子纹理要求

- 路径：`assets/cargoverse/textures/particle/`；
- 建议尺寸：8×8、16×16 或 32×32；
- 背景必须透明；
- 需要程序染色时，主体使用白色或灰度；
- 多帧粒子每帧使用独立 PNG，并在粒子 JSON 的 `textures` 数组中按顺序列出；
- 当前 `simple_effect` 暂用原版通用纹理，占位纹理可替换为正式资源。

## 四、已接入示例：重型接口

| 项目 | 当前实现 |
|---|---|
| 方块 ID | `cargoverse:heavy_docking_interface` |
| 结构 | 水平两格，控制器统一渲染动态部件 |
| 默认模型方向 | `EAST` |
| Create 部件 | `AllPartialModels.SHAFTLESS_COGWHEEL` |
| 齿轮动画 | 读取实际 Create 动力速度、方向与位置相位 |
| 锁定轴模型 | `block/heavy_docking/connector_rod` |
| 锁定轴初始范围 | BB `(16,8,6)` → `(26,12,10)` |
| 锁定轴运动 | 沿局部 `-X` 移动 9 px |
| 动画进度 | 跟随实际有限行程 `engagementProgress` |
| 插值 | `LINEAR` + Partial Tick |
| 停机表现 | 保持当前行程位置 |
| 粒子 | 当前无 |

## 五、交付检查

- [ ] 静态主体和活动部件使用同一坐标空间；
- [ ] 活动部件没有重复留在静态模型内；
- [ ] 每个旋转或缩放部件提供了 Pivot；
- [ ] 默认正面和旋转正方向明确；
- [ ] 多方块结构明确了主方块及所有相对格坐标；
- [ ] 给出了动画后的最大模型边界；
- [ ] Create 齿轮注明使用的 `AllPartialModels` 类型；
- [ ] 粒子纹理为透明背景，染色纹理使用白色或灰度；
- [ ] 表中“当前支持”和“计划支持”没有混写。
