# 命令

所有项目命令以 `/cargoverse` 为根节点，并要求原版命令权限等级 `2`。

带 `[targets]` 的命令省略目标时作用于执行玩家。服务器控制台和命令方块必须显式填写在线玩家选择器。

## 速查

| 命令 | 作用 |
| --- | --- |
| `/cargoverse license reset [targets]` | 重置许可证经验 |
| `/cargoverse license set <S\|M\|L\|X\|XL> [targets]` | 设置已注册玩家的许可证等级 |
| `/cargoverse shipping_stats reset [targets]` | 重置航运风格统计 |
| `/cargoverse admin_mode on [targets]` | 开启 CargoVerse 管理员模式 |
| `/cargoverse admin_mode off [targets]` | 关闭 CargoVerse 管理员模式 |
| `/cargoverse trade_point advance <tradePointId> [days]` | 推进贸易点交易日 |
| `/cargoverse summon <containerDefinitionId> <pos>` | 生成测试用空货柜 |
| `/cargoverse container add_cargo <containerId> <cargoGoodId> <units>` | 向货柜添加测试货物 |
| `/cargoverse physics monitor <structure> <time>` | 监控物理结构接口载荷 |

## 许可证

```text
/cargoverse license reset [targets]
```

将许可证经验归零，不删除玩家档案、货柜、航运风格或贸易点数据。

```text
/cargoverse license set <S|M|L|X|XL> [targets]
```

把已注册玩家的许可证经验设为所选等级在 `player_profiles` 定义中的最低门槛。未注册玩家会被跳过；所有目标都未注册时命令失败。该命令不创建玩家档案，也不修改货柜或航运风格。

示例：

```text
/cargoverse license set XL PlayerName
```

## 航运风格

```text
/cargoverse shipping_stats reset [targets]
```

清除目标玩家已完成的航运风格统计，以及其货柜尚未完成的航段候选。不会重置许可证或删除货柜。

## 管理员模式

```text
/cargoverse admin_mode on [targets]
/cargoverse admin_mode off [targets]
```

管理员模式控制 CargoVerse 的终端配置入口和货柜资产保护绕过，状态按玩家 UUID 保存。它不授予或撤销原版 OP 权限。

## 推进贸易点

```text
/cargoverse trade_point advance <tradePointId> [days]
```

`tradePointId` 是世界中的贸易点实例 UUID，不是数据包定义 ID。`days` 范围为 `1..10000`，省略时为 `1`。

命令按指定天数结算生产、库存、活跃度与动态价格，并以当前服务器 `gameTime` 继续正常计时；不修改原版昼夜时间，也不重抽已保存的生产线或模块。

示例：

```text
/cargoverse trade_point advance aa7f0caa-b50d-4e26-8a9e-8204eb 7
```

## 生成空货柜

```text
/cargoverse summon <containerDefinitionId> <x> <y> <z>
```

定义必须已加载，坐标支持原版相对坐标且目标区块必须加载。命令创建满耐久、空 Load 的货柜资产并放置物理结构，不扣货币、库存或调度点，也不记录购买交易。

玩家执行时货柜归执行玩家；控制台或命令方块执行时使用系统零 UUID。成功消息包含货柜数字实例 ID。

示例：

```text
/cargoverse summon cargoverse:aui/atlas_sd_s ~ ~1 ~
```

## 添加测试货物

```text
/cargoverse container add_cargo <containerId> <cargoGoodId> <units>
```

- `containerId` 必须大于 `0`；
- `cargoGoodId` 必须是已加载的完整 CargoGood ID；
- `units` 范围为 `1..1000000`；
- 目标必须是已登记、有效、活动中的货柜；
- 货柜必须兼容该货物；
- 已有 Load 时只允许添加同一种 CargoGood；
- 容量不足时整条命令失败，不自动截断；
- 新增货物完整度为 `100%`。

成功后保存 Load，并刷新物理质量与货物贴花。命令不扣贸易点库存或货币，也不增加交易、许可证经验或航运风格统计。

示例：

```text
/cargoverse container add_cargo 42 cargoverse:raw_resource/ore 12
```

## 物理接口监控

```text
/cargoverse physics monitor <structure> <time>
```

`structure` 使用 Sable 单结构选择参数；`time` 为 `1..3600` 秒。命令必须由在线玩家执行。

监控开始时固定目标结构 UUID，每个物理子步采样线性载荷、角向载荷与接口负载率，并每秒向执行玩家输出各自峰值。同一玩家再次执行会替换当前监控会话。该命令只读，不修改世界、存档或断裂阈值。
