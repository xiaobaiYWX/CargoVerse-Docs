# 服务器性能检查

本页记录 CargoVerse 的主要持续开销与服务器测量方法。Sable 的刚体碰撞成本属于物理模组本身，应与 CargoVerse 逻辑开销分开采样。

## 持续任务

### 运输词条

`CargoAffixTicker` 每 `20 tick` 处理一次有效且带词条的货柜。同一货柜在一个周期内复用物理快照，不为每个词条重复查询 Sable。

- 防潮执行有限数量的包围盒与水体采样；
- 易碎品保存上一周期速度；
- 易燃物读取环境与温度状态；
- 放射性只遍历当前维度在线玩家，半径钳制为 `2..16`；
- 失效货柜不继续执行词条检测。

### 连接与轨道

- 未通电接口只执行常数级状态判断；
- 已锁定连接器使用已保存对端和约束引用；
- 通电未配对连接器每 `5 tick` 查询附近接口；
- 接口索引按区块组织，并复用同一时间片结果；
- 轨道 PrePhysics 阶段读取缓存，不遍历节点方块；
- 约束恢复使用有界队列与退避，不永久逐 Tick 重试。

### 终端与档案

- 世界表面终端由各控制器方块实体 renderer 驱动，不全局扫描世界；
- 展示快照按终端节流，并只在内容变化时推进 revision；
- 结构预览结果按货柜定义缓存，数据包重载时失效；
- 单个结构预览最多同步 `2048` 个方块；
- 玩家航运档案只在打开或服务端刷新后同步完整快照。

## 存档与缓存

- 货柜资产、Load、词条运行状态和待物理刷新队列随有效记录线性增长；
- 物理快照缓存按世界和时间片复用；
- 空间索引与连接索引不保存逐 Tick 历史；
- 贸易点离线生产使用汇总公式，不按离线天数逐日循环；
- 航运风格只保留玩家档案定义限定的窗口数据。

## 压力场景

服务器基准至少覆盖：

1. 空载，以及 `50`、`200`、`500` 个活动货柜；
2. 雨天防潮、持续翻滚、频繁速度变化、升温和多人靠近放射性货柜；
3. 多个未配对连接器同时通电并执行磁力引导；
4. 多玩家同时装载、卸载、购买或制造；
5. 多个贸易点同时跨日生产；
6. 打开包含大量货柜与大型结构预览的个人航运档案。

记录平均 MSPT、95% 分位 MSPT、GC、存档写入时间、网络流量和客户端帧时间。使用 Spark 或同类采样器定位热点，并分别查看服务器主线程、Sable 物理线程与客户端渲染线程。
