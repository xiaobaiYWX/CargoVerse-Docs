# 服务器性能检查

本页记录 CargoVerse 的主要持续开销与服务器测量方法。Sable 的刚体碰撞成本属于物理模组本身，应与 CargoVerse 逻辑开销分开采样。

## 持续任务

### 运输词条

`CargoAffixTicker` 每 `20 tick` 处理一次有效且带词条的货柜。同一货柜在一个周期内复用物理快照，不为每个词条重复查询 Sable。

- 防潮执行有限数量的包围盒与水体采样；
- 易碎品保存上一周期速度；
- 易燃物读取环境与温度状态；
- 放射性只遍历当前维度在线玩家，半径钳制为 `2..16`；
- 失效货柜不继续执行词条检测。

### 连接与轨道

- 未通电接口只执行常数级状态判断；
- 已锁定连接器使用已保存对端和约束引用；
- 通电未配对连接器每 `5 tick` 查询附近接口；
- 接口索引按区块组织，并复用同一时间片结果；
- 轨道 PrePhysics 阶段读取缓存，不遍历节点方块；
- 约束恢复使用有界队列与退避，不永久逐 Tick 重试。

### 终端与档案

- 世界表面终端由各控制器方块实体 renderer 驱动，不全局扫描世界；
- 展示快照按终端节流，并只在内容变化时推进 revision；
- 结构预览结果按货柜定义缓存，数据包重载时失效；
- 单个结构预览最多同步 `2048` 个方块；
- 玩家航运档案只在打开或服务端刷新后同步完整快照。

### 航行引导与 PID

- 无目标的引导台不查询 Sable 结构姿态；有目标每 Tick 使用实时姿态做固定规模的局部坐标数学和 PID，不执行碰撞、射线或周边结构搜索。
- PID 内部保留必要小数，最终转速为 0 或 ±1～256 RPM，且不超过输入；档位未变化不刷新应力网络。下游机械变比继续由 Create 计算。
- 源树索引每网络共享，拓扑稳定时复用后代列表，实时检查父源/成员防止同数量换节点的缓存误用；索引值仅持有坐标，弱网络键不保留世界。
- 实际变速仍有 O(N + D) 成员检查与 Create 应力重算，另同步 D 个下游；大网络中大量引导台同时变速仍需重点采样。
- 客户端速度不变的更新不追溯源链；首次分类在当前 Tick/源版本内复用正负路径，源变更即时失效，避免无关长网络按每个方块重复扫描。仪表显示面的静态变换按朝向缓存，GUI 参数只在编辑时解析。
- 不重复标记瞬时输出/角度为持久化配置变更；目标与参数真正变更时仍正常保存。
- 引导台独立地图共用手册地形和标记缓存，不启动第二套采样。目标匹配只在编辑器目标变化时扫描一次，不逐帧遍历已知库；相同选择不重复发送目的地更新。前台宿主标识阻止后台预热争抢纹理焦点。
- 地图编辑、PID 配置和手册写入共用加载状态/维度/8 格物理距离规则，目的地可远程但不加载目的地区块；界面与服务端各自复核，界面检查不代替服务端授权。

自动回归覆盖 10,000 节点稳定拓扑复用及动态拆装，尚未做大型实船 MSPT/GC/流量测量。算法复杂度检查不等于实际物理性能测试；详见[航行引导台与 PID 控制](../13载具仪表/01_航行引导台与PID控制.md)。

## 存档与缓存

- 货柜资产、Load、词条运行状态和待物理刷新队列随有效记录线性增长；
- 物理快照缓存按世界和时间片复用；
- 空间索引与连接索引不保存逐 Tick 历史；
- 贸易点离线生产使用汇总公式，不按离线天数逐日循环；
- 航运风格只保留玩家档案定义限定的窗口数据。

## 压力场景

服务器基准至少覆盖：

1. 空载，以及 `50`、`200`、`500` 个活动货柜；
2. 雨天防潮、持续翻滚、频繁速度变化、升温和多人靠近放射性货柜；
3. 多个未配对连接器同时通电并执行磁力引导；
4. 多玩家同时装载、卸载、购买或制造；
5. 多个贸易点同时跨日生产；
6. 打开包含大量货柜与大型结构预览的个人航运档案。
7. 1/10/50 台引导台与 100/1,000/10,000 个加载动力节点，分别测静止目标、持续旋转、频繁整数档位变化以及多引导台共享网络；
8. 在引导过程中拆装传动节点、切断输入、卸载/重载结构，并分开采样 Sable 物理姿态更新与 Create 动力网络重算。

记录平均 MSPT、95% 分位 MSPT、GC、存档写入时间、网络流量和客户端帧时间。使用 Spark 或同类采样器定位热点，并分别查看服务器主线程、Sable 物理线程与客户端渲染线程。
