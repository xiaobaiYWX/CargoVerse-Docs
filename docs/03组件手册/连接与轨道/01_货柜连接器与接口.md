# 货柜连接器与货柜接口

货柜连接器和货柜接口用于在运输载具与货柜之间建立可控的物理锁定。它们是 CargoVerse 内部的货柜对接系统，不依赖 `simulated:docking_connector`。

## 方块 ID

| 方块    | ID                                   | 角色      |
| ----- | ------------------------------------ | ------- |
| 货柜连接器 | `cargoverse:cargo_docking_connector` | 主动搜索与控制 |
| 货柜接口  | `cargoverse:cargo_docking_port`      | 被动接受连接  |

两个方块均使用原生点击面的六向放置规则，正面朝向被点击表面的外侧。Sable 物理结构中的朝向由原生放置上下文提供。只有正面相对、位于不同 Sable 物理结构上的连接器与接口才能配对。

## 货柜连接器

货柜连接器一般安装在运输载具、吊装设备或固定装卸设施上。

它负责：

- 接收红石控制信号。
- 搜索附近可用的货柜接口。
- 引导两个物理结构互相靠近。
- 在接口进入锁定范围后建立固定物理约束。
- 维护连接器组的共享状态。

### 状态

连接器具有三种 BlockState：

```text
off
searching
connected
```

| 状态 | 含义 |
|---|---|
| `off` | 关闭，不执行目标搜索 |
| `searching` | 搜索并引导可用接口 |
| `connected` | 已建立物理连接 |

关闭状态收到一次红石信号后进入搜索状态。搜索基础持续时间为 `60 tick`，即约3秒；发现有效目标后会刷新搜索时间，直到完成连接或目标失效。若同组连接器数量少于目标货柜接口数量，该目标不会进入引导，也不会刷新搜索时间，倒计时正常结束后回到关闭状态。

连接状态再次收到红石信号时，当前接口组断开并返回关闭状态。

## 货柜接口

货柜接口是完全被动的目标方块，通常随货柜结构模板一起保存。

- 不接受红石控制。
- 不主动搜索连接器。
- 不配置接口组。
- 不传输物品、流体或动力。
- 只负责提供物理连接锚点。

一个接口同时只能参与一组有效物理连接。

## 接口组

多个货柜连接器可以配置为同一个接口组。接口组由以下内容共同区分：

```text
所在物理结构 UUID + 字母频率（A–Z）+ 信道（0–9）
```

### 设置方式

普通右键连接器打开图集 GUI。鼠标悬停右侧“频率”一行，用滚轮切换 `A–Z`；悬停右侧“信道”一行，用滚轮切换 `0–9`。按住 Shift 滚动可加速，到边界时停止。左侧显示最终编号预览，例如 `C-9`。默认值为 `A-0`，共 `260` 种组合。

点击右下角勾选按钮或按 E 提交，收到服务端确认后关闭界面。按 Esc 可放弃未提交的改动。底栏显示已经保存的组合，未提交的滚轮改动只影响预览。同一物理结构上，字母频率和信道均相同的连接器属于同一组；不同结构上的相同组合不会合并。

修改频率会解除原接口组的连接并停止旧频率下的恢复，随后更新组索引；设置完成后重新给予红石信号开始搜索。频率保存在 BlockEntity 中，存档重载和服务器重启后保留。服务器会检查当前菜单、编辑权限、方块身份和投影后的世界距离，移动结构同样适用。

物品编组、侧面物品展示和手动数字输入均已移除。旧物品编组与单数字频率不迁移，缺失或无效配置使用 `A-0`。保存协议见[开发实现](<../../06制作与开发/开发实现/01_标准货柜对接.md#频率与保存协议>)。

### 共享状态

同一物理结构上的同组连接器共享红石和显示状态，避免一个连接器已连接而其他连接器错误进入搜索状态。

同一接口组同时只允许连接一个其他物理结构：

- 一个连接器被选为物理主连接器，负责建立实际约束。
- 组内其他连接器作为视觉副连接器，不额外创建物理约束。
- 副连接器只有通过对应货柜接口校验后才显示为已连接，并计入接口组的有效连接器数量。
- 若载具需要同时连接多个独立结构，应配置多个不同的接口组。

被动货柜连接点无需设置频率。频率只用于划分主动连接器组。

### 副连接器校验

创建固定约束前，系统统计目标 Sable 货柜结构上的全部标准货柜接口，并检查同一个连接器组能否一对一覆盖所有接口。只有完整覆盖才会建立一个主物理约束；其余匹配由副连接器负责校验与显示。接口距离远近以及搜索索引注册先后不会减少所需接口数量。

搜索和持续引导前还会做数量预检查：按完整物理结构统计同频率、同信道的连接器与目标货柜上的全部接口，仅当连接器数量不少于接口数量时允许引导。允许多余连接器不参与连接；数量足够仍须通过一对一几何匹配。引导期间数量变为不足时会清除目标并恢复正常倒计时。

同一货柜上的接口不能分摊给多个连接器组。组内允许存在多余的未匹配连接器，它们保持关闭状态。存档恢复也必须重新通过完整覆盖检查。

副连接器匹配需要满足：

- 主动连接器和被动接口分别位于当前连接的两个物理结构上。
- 两个接口的世界空间朝向相反。
- 新匹配的接口表面距离不超过 `0.20` 格。
- 已经建立的有效副匹配在距离不超过 `0.25` 格时可以继续保留，避免边界抖动。
- 被动接口没有参与其他真实连接或其他接口组的副连接校验。
- 一个副连接器只能匹配一个被动接口，一个被动接口也只能支持一个副连接器。

系统使用一对一最大匹配计算有效副连接器，避免多个副连接器重复占用同一个货柜接口。主连接器在真实约束有效时固定计为一个有效连接器，因此：

```text
有效连接器数量 N = 1 个主连接器 + 通过校验的副连接器数量
```

连接后每 10 tick 复核完整覆盖；副接口被移除、被其他组占用、位置或朝向失效，或货柜新增接口而无法重新完整匹配时，解除整组连接。有效旧匹配优先保留，必要时重新匹配。

始终只有主连接器和主接口共享一个固定约束；副连接器不创建额外约束。

## 搜索与物理锁定

### 标准半格模型

连接器使用 `turnlock_connector` 的预拆分底座与接头，货柜连接点使用 `twistlock`。两端底座均为 `8px` 高，正面对接后底座外侧总间距为 `16px`（一格），接头伸入连接点槽内。以模型原始朝上姿态为准，对接面位于 `(8,8,8)`，即方块中心；六向旋转和 Sable 子结构旋转均使用相同锚点。

锁定动画为接头绕模型 Y 轴中心 `(8,8,8)` 平滑旋转 `90°`，用时约 `12 tick`；关闭和搜索状态的接头保持原角度，解除连接时平滑转回。连接点为静态模型，不再播放抓爪动画。副连接器使用相同动画，但不创建额外物理约束。

两端选择框、普通碰撞和 Sable 结构碰撞均使用半格底座；伸入槽内的接头不单独参与碰撞。编组由右键打开的字母频率与信道 GUI 设置，使用 `cargo_docking_frequency.png` 图集，按 `174×97` 的原像素菜单区域绘制。连接器底座和旋转接头使用相同状态颜色：未锁定为红色（`turnlock_connector_unlocked`）、搜索中为蓝色（`turnlock_connector_searching`）、已锁定为绿色（`turnlock_connector`）。连接点及其物品的 `display` 变换使用最新 `twistlock.json`，物品模型通过继承取得导出设置。

连接器以约5格范围搜索可用货柜接口。搜索目标必须满足：

- 位于另一个 Sable 物理结构。
- 本地方块朝向互为相反方向。
- 世界空间中的接口法线基本相对。
- 当前不存在冲突的结构间连接。

搜索阶段向两个结构施加相向线速度。全部货柜接口与同组连接器的表面距离进入约 `0.2` 格的锁定范围并通过朝向、占用检查后，创建唯一固定约束。

### 角度对齐

锁定时会精确对齐两个接口的法线，但不会强制所有货柜归到唯一世界角度。

绕接口法线的滚转角按以下等价姿态处理：

```text
0° / 90° / 180° / 270°
```

系统选择距离锁定瞬间相对姿态最近的候选角度，因此滚转修正最大不超过45°。这样可以保证两个方块视觉对齐，同时减少意外的大幅旋转。

## 物理载荷诊断

标准接口已取消超载断裂。连接是否有效由完整接口匹配决定，载荷、质量变化和碰撞峰值不会触发接口组的自动断裂。

载荷监控可观察线性载荷、角向载荷和参考负载率，仅在命令会话存在时读取物理冲量；超过 100% 也不解除约束。命令操作见[命令页](<../../06制作与开发/运维与验证/03_命令.md#物理接口监控>)，公式与配置只在[开发实现](<../../06制作与开发/开发实现/01_标准货柜对接.md#载荷诊断>)维护。

## 推荐工作流

1. 在运输载具上放置一个或多个货柜连接器。
2. 右键打开频率 GUI，为需要联动的连接器保存相同频率。
3. 在货柜结构模板中放置被动货柜接口。
4. 让连接器与接口正面大致相对并进入搜索范围。
5. 给予连接器组一次红石信号。
6. 等待磁力引导与固定约束建立。
7. 再次发送红石信号以断开连接。

## 与货运电磁铁的区别

货柜连接器面向可编组、可控制的标准货柜装卸，包含接口组、视觉副连接器和离散角度对齐。

货运电磁铁是更简单的通用物理连接装置，不使用接口组，也不进行姿态对齐。详见[货运电磁铁与磁吸板](<02_电磁铁与磁吸板.md>)。

## 注意事项

- 当前系统只负责物理连接，不传输物品、流体、红石或动力。
- 连接器和接口必须属于不同的物理结构。
- 目标货柜的所有标准接口必须由同一组连接器完整覆盖；缺少任意配对时无法正式连接。
- 标准接口不再按载荷自动断裂。
- 大量接口集中在很小范围时，应使用不同接口组控制主动连接器，减少目标歧义。
- 模板中的接口朝向应与预期装卸方向一致。
