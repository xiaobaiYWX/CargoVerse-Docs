# 围场核心与标记围栏

更新：2026-11-20。围场是世界活体仓库，生物装箱前继续在世界中活动。围场核心只提供范围和库存识别，不保存第二份实体库存。原生载荷与恢复契约见[生物运输](<../../02系统规则/货物与货柜/17_生物运输.md>)。

## 搭建

- 围场核心：`cargoverse:enclosure_core`，占地3×3、高2格；标记围栏：`cargoverse:enclosure_fence`。
- 标记围栏与核心底层处于同一水平面，可沿网格不规则弯折。两端接到核心后侧的5、6号接点；机身其他位置不接围栏。核心后侧底层三格参与闭环周长。
- 无需扳手确认；完整闭环自动生效，断开后失效，修复后恢复。有效外圈的围栏顶端显示范围标识，支线和合并后的内部围栏不显示。
- 专用围栏用于外圈标记；内部物理分隔可使用普通围栏，不参与范围识别。
- 一个闭环允许包含多个核心，读到相同范围、面积与容量。两个独立围场只有一条连接线时各自保持独立；连接形成共同外圈后读取共同外圈。闭环存在多个候选时取经过当前核心的最长有效外圈，不能通过增加核心重置距离。
- 闭环最大周长128格，包含核心；服务端`[livingEnclosure].maxPerimeter`可设置8～128。内部检测从核心底层平面向上8格，`height`可设置2～32。超出周长不回退为内部小圈。
- 拆除核心任一成员移除整机，但不删除围栏或世界生物。围场设施只能在静态世界使用；不为范围识别强制加载区块。

## 仪表与容量

核心保留四个仪表基座，编号1～4依次显示围场状态、周长、内部面积、最大容量。范围失效显示破损，数值仪表显示`--`。核心普通右键不输出测试信息。

内部面积按闭环内部的水平格数计算，边界格不计入；检测高度和内部放置方块不增加容量。最大容量为`floor(内部面积 / 4)`：例如35㎡容纳8只，不足4㎡容量为0。

该容量由整个围场共享，不按物种、接入终端或核心数量倍增。所有实际存活生物均占用卸货名额；未配置运输属性的生物也占用名额。玩家仍可手动放入超量生物，系统不删除超量个体，但满员后禁止继续卸货。普通终端或自动卸载机的自由批次可卸入可容纳部分，自动卸载机的定量批次必须有本轮所需空间。确认提交前重新检查数量。

库存只从可运输生物中按UUID稳定顺序识别不超过容量的个体，再按物种汇总。超出上限的个体继续在世界中活动，不录入库存；已识别个体离开后，后续刷新可识别剩余个体。

卸货生物在核心后方第2～4格、横向三格的固定区域生成，与核心底层同高并随朝向旋转。该区域须处于有效围场内部且留有净空；被挡住时腾出位置即可继续。水生生物共用相同位置，不寻找水源。

## 连接与库存

在核心左侧底层中部接口外安装独立[物流隧道入口](<02_物流隧道入口与链接器.md>)，入口背板贴住指定接口，入口使用与目标装卸或仓库终端入口相同的频率。正式隧道只连接入口，不直接连接围场核心；其他成员旁放入口不提供生物库存。

围场无需绑定贸易点，也可直接接入[货柜卸载机](<06_货柜卸载机.md>)。终端按入口网络频率读取库存，实际装卸另行核验真实隧道路径；玩家贸易和仓库管理操作还会核验各自的权限。多个入口或核心指向同一范围时不重复计算。线路断开不影响围场范围和世界生物，范围破损则暂停对应识别与转移。

一种EntityType一行，显示统一图标和只数`mob`；毛色、幼崽、名称、生命和主人属于个体状态，不拆成库存键。未知、死亡、骑乘／乘客、拴绳、多部件、首领、禁止捕获或不可原生搬运的实体不进入库存。识别每20tick刷新，提交使用新鲜候选；最多展示512种物种。

物种报价在相应公共交易终端配置，免费装卸由仓库管理终端提供。命名、驯服及装备个体的交易限制遵循[生物运输](<../../02系统规则/货物与货柜/17_生物运输.md>)，不能通过管理权限搬运其他玩家的宠物。

旧`player_bio_packer`和`player_biological_area_marker`已移除，不提供旧结构自动迁移。升级前备份，使用新核心及围栏重建；旧世界中的生物仍由Minecraft保存。
