# 货柜卸载机

更新：2026-11-20。货柜卸载机 `cargoverse:automatic_cargo_unloader` 通过红石将货柜中的物品送入原生物品仓储，或将生物释放到围场。设备独立使用，无需认领贸易点或检查货柜归属。流体装卸见[液体运输](<../../02系统规则/货物与货柜/13_液体运输.md>)。

## 安装与接线

1. 预留两个水平相邻的方块位置。放置时模型北面朝玩家，南面的检测器朝向货柜通道。
2. 在机身北面的指定接口外安装[物流隧道入口](<02_物流隧道入口与链接器.md>)，让入口背板贴住机身、开口接管线。仓库或围场也安装一个同频入口，再用[物流隧道](04_物流隧道.md)实际接通。
3. 在机身顶面长按 Create 原生数值框，将最大检测距离设为 1～16 格。让货柜进入光束，设备接入持续红石信号。

## 配置卸载规则

右键机身打开设置。第一组按钮选择允许任意货物，或只允许可达仓储中已有的货物。物品比较精确变体，生物比较物种。首次投放某种生物时可选允许任意货物。

第二组按钮选择尽量卸空或按设定组数卸载。组数为 1～999，鼠标滚轮调整，Shift 加滚轮以 10 为步长。物品一组等于该变体的一栈，生物一组为一只。定量模式下仓储装不下整批时暂停，只有货柜剩余不足设定量时按尾量卸载。

## 检测和运转

通电时机身显示激活贴图，检测器持续发射光束。光束终止于第一个命中表面，普通方块会挡住它，前方货柜也会遮挡后面的货柜。

无人机每次起飞记录当时的货柜重心和取货高度，飞行目标固定到本轮结束。光束继续按场景变化更新。一次往返为 170 游戏刻，正常刻速约 8.5 秒。落地时会复核首个命中是否仍为本轮货柜，并检查仓储路径及余量后提交。如果设备仍通电，会继续扫描并在条件允许时开始下一轮。

断电后立即恢复普通贴图，已起飞的无人机完成当前轮并在落地时复核。设备随后停止扫描和卸货。生物进入[围场核心后方的释放区](<05_围场核心与标记围栏.md>)，围场闭环、容量、落点净空均参与检查。
