# 生物打包机

更新：2026-11-03。已接入生物识别、按物种报价与通用生物装卸。原生载荷、容量和恢复契约见[生物运输](<../../02系统规则/货物与货柜/17_生物运输.md>)。

## 搭建与连接

- 方块ID：`cargoverse:player_bio_packer`；黄色标记杆：`cargoverse:player_biological_area_marker`。
- 模型占地两格宽、一格深，右侧自带长杆。其地面位置作为一个角，另外放置三根黄色杆组成正方形，用Create扳手点击打包机任一部件或标记杆确认。边长沿用2～18格，识别高度为边长的一半向上取整；以生物脚下参考点位于区域内判断。
- 三根杆必须同色、同高，四根独立杆不能成形。区域沿用现有重叠检查，拆除任一杆取消区域；拆除打包机任一部件移除整机和区域。
- 主方块的模型北面是唯一物流入口，随整体朝向旋转；右侧底座和上方长杆均不接隧道。不需要仓库收发器。
- 接入激活的贸易点后归属于该核心；区域尚未成形不阻碍其他贸易点设备工作。形成有效识别区后生物仓库显示连接成功。隧道断开、核心失效或区域失效，库存视图停止提供。
- 遵守玩家设施的静态世界限制：可以放在Sable结构上，但不能绑定或使用。整机质量1000Kpg，副部件不重复加质量。

## 库存与界面

生物继续存在于世界中，打包机只保存区域和网络归属，不保存一份实体库存。仓库管理终端切换生物页后按EntityType汇总，一种物种一个栏位，显示统一图标与只数`mob`；退出GUI后表面仪表继续显示该类型，可切换物种。毛色、幼崽、名称、生命和所有者不参与库存键。

可通过仓库管理GUI配置物种报价，通过通用终端装卸；管理装卸不收费，公共交易按报价结算。未知生物不进入视图；已死亡、骑乘／乘客、多部件、首领、NeoForge禁止捕获、不可跨维度的实体不进入视图。敌对身份本身不阻止识别，当前包含僵尸配置。

只扫描已加载且全部区域区块可用的识别区，不强制加载区块。实体扫描结果每20tick刷新，网络和区域可用性每次读取重验，配置重载立即失效缓存。最多同步512种物种；按UUID去重，不改动任何实体持久化数据。
