# 仓库管理终端

注册 ID：`cargoverse:player_trade_inventory_terminal`。本台查看显式关联的已加载原生库存，并提供免费货柜装卸，不保存任何物品、流体或实体副本，不设置公共出售或收购价格。

## 使用

通过本台背面接口接物流隧道，容器旁放置物流隧道入口，并将记录了本台地址的链接器放置在入口外侧；入口背面可连接保险库、箱子、木桶、储罐或围场核心的指定接口。可以独立使用；若绑定站点，则由所有者和授权管理员操作。站点绑定使用 GUI 侧栏，不要求核心接线。

本台长杆与三根绿色管理标记杆形成同高度、边长 2～18 格的正方形区域，使用 Create 扳手成区，区域高度为边长一半向上取整。装卸共用本台区域，不借用其他交易终端的固定范围。缺少区域只阻止管理装卸，不阻止打开库存界面或绑定。

SET 打开只读库存管理页，保留名称／ID／运输类型筛选、排序、介质选择和站点绑定。公共价格设置已经移到对应出售或收购终端，仓库页不能上架、下架或修改公共报价。管理页与交易终端管理员页共用新版玩家贸易点管理图集；固定控件由背景提供，物品栏位按实际库存动态绘制。绑定列表按搜索结果绘制，最多显示 9 条并可滚动；长站点名以 `...` 截断，已绑定项显示绿色勾，点击时再检查接入资格。

表面切换物品、流体及生物视图，保留货物图标、原生数量、操作单位及库存／容量。免费装卸不依赖报价或结算器，不计公共交易收益或经验；仍检查实际货柜、管理权限、容量、精确身份、确认会话占用和原生转移回执。

## 仓库类型切换

物品、液体和生物视图分别展示本台可达的保险库、储罐和识别区域。选择保存于仓库管理终端，退出后表面与管理装卸使用该介质；未连接类型显示空库存并拒绝转移。气态 Fluid 归入液体。

## 生命周期

断开物流只阻止不可达库存实际转移，仍可查看已显式关联的已加载库存，保留本台区域和站点绑定。取消绑定不改变原生库存。拆除外围管理杆解散本台区域，拆除任一终端成员清理整机；不删除其他终端的报价或容器内容。

保留现有模型、长杆、表面仪表及多方块生命周期。整台质量 1000 Kpg，仅控制器计重；放在 Sable 上不能绑定或使用，不做设施坐标投影。
