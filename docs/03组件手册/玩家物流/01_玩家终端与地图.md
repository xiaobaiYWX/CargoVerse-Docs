# 玩家贸易点：终端、表面 UI 与地图

## 1. 核心终端

贸易点管理核心的表面 UI 显示贸易点名称、业务组件状态、网络激活状态、结算器余额与余额比例、总交易额、所有者和净利润。绿色 PWR 激活物流网络，红色 STOP 解除激活；激活不要求搭齐全部业务设备。核心不提供 SET 或商品管理菜单，相关入口只在仓库管理终端上提供。黄色 `AUTH` 大按钮打开核心管理 GUI，仍不提供商品编辑入口：

- 核心放置后无主，点击黄色 AUTH 按钮打开注册界面，与已认领核心一致，右键终端其他位置不打开 GUI；绿色页签长按 3 秒注册到自己名下，红色页签长按 3 秒注销。未注册不占数量名额，注册时检查配置限额。
- 顶部显示贸易点名称，点击后可编辑，回车、失焦或关闭保存；初次注册默认“玩家名称的贸易点”。下方显示所有者名称。
- 已授权管理员按名称宽度拼接标签，逐项叉号移除；标签、下方输入文字和提示颜色均为 `#cdbca8`。输入玩家名称或 UUID 后点击加号添加，右侧滚动条浏览名单。只查询当前存档已有的玩家记录，名称由本地 UUID 缓存读取；按名称或 UUID 匹配，未找到直接拒绝。不查询在线名单、不添加其他兜底、不联网或自动生成 UUID。添加和移除仍仅限所有者。
- 注册/注销以自上而下的半透明绿色遮罩逐渐覆盖页签表示进度，只在持续按住且光标仍在按钮上时累计；提前释放、移出、窗口失焦或关闭取消。服务端独立校验三秒确认、菜单身份、距离和权限。达到数量上限时立即停止注册确认并在 GUI 内提示；长按期间名额被占用也会取消，释放名额后需重新长按。
- 注销解除全部绑定、移除报价与授权并返还结算器，保留核心方块和保险库内物品；生成新核心身份，旧菜单和连接不会复用。

结算器模型平时隐藏。玩家在左上方槽位副方块安装结算器后才显示；直接渲染装入物品的模型，不再维护终端专用副本，物品模型和贴图更新会自动生效。贸易点运行时不能取出。

## 2. 公共货物出售与收购终端

### 玩家货物出售终端

`cargoverse:player_container_loader` 使用货物出售终端模型与六项独立仪表：货物图标、名称、计划总价、计划装载质量、仓库剩余可售量和检测到的货柜名称，并显示货柜全息模型。名称立牌位于模型北面；预览不显示准星悬停名称。公共数量滑轨为 1～256 个操作单位，物品按最大堆叠数为一组、流体按 1000 mB、生物按一只。剩余库存使用 `stk`／`mB`／`mob`，尾量按实际比例显示。

装载区固定为 **16×16 格，8 格高**，从模型南面、紧贴终端背面向外延伸，底面与控制器底层同高，并随终端朝向旋转。不放置或消耗标记杆，不需要扳手组区，也不保存区域 UUID 或角点成员。终端自带的固定区域配置不作为独立物流网络端点。装载区域标记杆方块、物品及专用模型已移除；管理和生物标记杆继续使用。

默认居中对齐。贸易点所有者及获授权管理员可以在 `SET` 商品 GUI 左下角选择左对齐、居中或右对齐；左右按面向模型北面的玩家视角解释，以终端两侧外缘为基准，居中以整台终端横向中心为基准。设置保存在本台终端并同步范围显示，不影响同一核心的其他终端。普通玩家可以选商品，不能更改区域位置；服务端逐次重验管理权限。隧道接入口位于模型最右侧的侧面，随终端朝向旋转，背面不再接入。

黄色 `SET` 打开本站出售目录，左右箭头切换商品。GUI 显示全部已启用出售的物品、流体和生物，包含售罄商品，不按场内货柜筛选；浏览不要求存在货柜，也不触发装载区扫描。卡片显示剩余操作数量，耗尽后在图标上覆盖 `Sold out`。当前价取贸易点报价，没有自然站市场基准与涨跌数据，相关栏显示 `---`。选货按稳定货物 ID 提交给服务端，不以可变行号作为商品身份。

右侧拉杆打开共用装载确认页，只有确认后才实际转移货物并结算。区域内只识别距中心最近的货柜，距离相同时选择 ID 较小者；交易时重新核验区域内货柜、货物兼容性、权限、库存及资金。库存或区域发生变化后不沿用旧预览直接成交；多个终端检测到同一货柜时仍遵守确认会话占用。所有者与管理员在公共终端交易同样正常付款，免费管理装卸仍在仓库管理终端进行。

成交后复用[货运无人机](../货柜与装卸/15_货运无人机.md)表达搬运；动画忙碌时后续成交照常完成，不打断或排队补播。世界表面和确认页使用通用计量，缺失行情、签约数据时显示 `---`。关闭或强制取消确认不会撤销已完成交易，迟到结果不重新打开界面。

### 玩家货物收购终端

`cargoverse:player_cargo_unloader` 使用新的收购模型和六项仪表，显示装卸区当前货柜的实际货物图标、名称、计划收入、计划卸货质量、柜内余量及货柜名称，并提供全息预览。三种介质都不按本站收购报价过滤；未报价或暂停收购的货物仍显示，收入栏为 `---`，拉杆处提示不可交易的原因。

卸载区同样位于模型南面，固定为 **16×16×8**，默认居中，随朝向旋转；每台独立保存左／中／右对齐。GUI 的三个按钮只允许所有者和当前获授权管理员修改设置，撤销授权后立即失去操作权限。卸载区标记杆及终端长杆均已移除，不再用扳手组区、不保存角点或区域 UUID。右后侧柜体的外侧面是唯一隧道接入口，模型北面观察时位于最右侧后半格，接口朝模型西面。

黄色 `SET` 打开独立的本站收购目录，展示已启用的物品、流体和生物收购报价。无需区域内有货柜即可浏览；选卡片仅在当前 GUI 查看收购价，不改表面货物或实际交易目标。缺少自然站市场基准和涨跌数据时显示 `---`。余量按仓库可接收的原生数量换算成操作单位，容量耗尽后覆盖 `Sold out`；生物没有配置数量上限时显示 `∞`，实际释放净空仍在交易时校验。

数量滑轨为 1～256 个操作单位。所有介质通过拉杆进入共用卸载确认页，固体也需要确认后才结算。服务端重验当前最近货柜、授权、仓库容量、报价和结算器余额；金额向上取整，尾量按实际比例计算。打开、取消、失败或重放确认不会移动货物、重复入账或触发无人机。成功后双机错峰从货柜取回视觉纸箱，归位后箱子消失；动画忙碌不影响后续真实成交，也不打断或补播动画。

### 共用范围提示与归属

有效区域仅在玩家距离区域 8 格以内显示范围：完整线框、从底部向半高淡出的渐变侧面，以及底面装卸标识；不因外围杆重复绘制。底面标识上移 1.5 MCpx 避免闪烁，尺寸为短边的 75%，最大 10 格。

同一核心可连接多台出售、收购及仓库终端，各台使用自身区域和选择，不跨区域自动派单。核心激活不要求区域就绪；范围不完整只阻止对应终端的操作。Sable 结构上的设施仍不可绑定和使用。

## 3. 仓库管理终端

仓库终端为可选管理组件；管理装卸不收费、不依赖商品报价、结算器或公共装卸台，但仍需要终端和仓库收发器处于激活网络的有效路径上。使用本台长杆与三根绿色管理杆形成的区域，装卸共用，只识别一个货柜，不允许切换货柜。缺少区域时提示“标记区域未完成”，SET 商品设置仍可使用。表面保留模型基座，显示实际物品、数量、装载率、库存/容量和页码，移除旧完整度、行情和报价限制的管理含义。详细操作见[仓库管理终端](<03_仓库管理终端.md>)。

## 4. 商品管理 GUI

仓库终端 SET 使用单张图集绘制五列两行物品网格，底部页签切换出售／收购。两页都只列出保险库中数量大于 0 的精确物品变体，不再构造全部物品目录；上架前需先存入一个样本，名称／耐久／附魔等不同组件不能互相代替。

- 搜索支持名称、物品 ID 和本地化／原始运输分类；名称、数量、当前模式单价三种排序，再次点击可切换升降序。
- 滚轮或右侧滚动条按行浏览。物品格显示原生物品图标、数量和当前模式单价；绿／红箭头区分出售／收购，未上架显示 `--`，悬停查看完整名称、数量、分类和未缩写价格。
- 必须手动点击一个物品才可编辑价格或上／下架，初始不选中任何物品；选中格有高亮边框。
- 输入单价后点击“+”保存并上架该物品；点击删除按钮只清除该物品在当前模式的单价并下架，另一模式和其他物品不变，不删除实物。
- 切换商品、模式、排序、筛选、滚动或关闭界面不自动提交。没有整页删除操作；不再提供保留数量或收购目标。
- 服务端复核所有权、有效菜单、绑定、8 格距离和真实库存样本；只向打开菜单的所有者定向同步变化行。保险库不可用时明确提示并禁用操作。
- 右下角四类仓库选择独立于左侧出售／收购页签。当前有效保险库为固体库存，已连接叠加绿勾，其余未连接叠加红叉；可切到未连接类型查看空页面，但不能编辑固体报价或执行固体装卸。选择保存于终端，并同步到退出 GUI 后的表面显示和交互，详见[类型切换](<03_仓库管理终端.md#仓库类型切换>)。

## 5. 玩家贸易点信息柜

信息柜接入激活网络后展示贸易点的出售与收购目录；缺少它不阻止网络激活。绿色大按钮切换两种目录，界面只读，不负责修改库存配置。商品单价、库存或额度等内容通过统一仪表组件绘制。

## 6. 航标塔与地图发现

航标塔是可选组件，不影响贸易点完整性。当前只有一种航标塔，沿用 `player_trade_beacon` 注册 ID、模型及按钮，显示名改为“航标塔”；旧普通航标 `navigation_mark` 的方块与物品 ID 已直接移除，不做旧存档方块/物品兼容。

未接入时可独立使用：SET 按钮编辑普通地图标记名称，钮子开关控制广播；此时不属于任何贸易点，任何玩家都可以设置或挖掘。接入玩家贸易点激活网络后广播对应贸易点的名称和商品目录，设置/广播操作限所有者和授权管理员；连接工具只供所有者诊断或确认接入，不再远程绑定／解绑。失去路径或解除激活后保留名称和广播状态，回到普通标记模式。

### 命名与指南针校准 GUI

SET 按钮打开新命名界面。顶部输入广播名称，右侧勾选按钮（或回车）显式保存名称并关闭；直接关闭不会提交名称草稿。下方展示玩家背包，可普通点击、快捷栏交换或 Shift 点击移动物品。

- 左侧是每位查看者独立的临时槽，只接收一枚原版指南针，也可重新校准已有的磁石指南针；回溯指针不接受。
- 放入指南针后，点击校准图标，把这一枚指南针绑定到当前航标塔核心的位置。不消耗指南针，保留自定义名称等其他组件。
- 指南针使用原版磁石目标数据、名称、光效和指针逻辑；同维度指向航标塔坐标，跨维度沿用原版磁石指南针表现。航标不是原版磁石，因此关闭磁石 POI 存活校验，避免原版 Tick 清除绑定；没有新增指南针扫描或跟踪系统。
- 目标是固定维度坐标，关闭广播、改名或拆除航标不清除该坐标；不追踪 Sable 移动物体。
- 航标自身不存储物品。无论是否绑定成功，关闭 GUI 都返还临时槽和光标物品；背包已满、死亡或断线沿用原版掉落机制，避免吞物品。
- 未绑定航标任何玩家可设置；已绑定航标仅所有者和授权管理员可设置及校准。界面打开后拆塔、解绑/换绑、撤销权限、走出 8 格或进入 Sable 结构均使菜单失效并执行物品返还。

### 广播与地图

- 广播开启：航标旋转部件缓慢旋转，并向贸易地图发布点位。
- 广播关闭：旋转部件停在当前角度，立即撤下所有玩家地图上的该标记，所有者也不例外；未记录过该点位的新客户端不会获得资料。
- 恢复广播：使用同一标记 ID 重新显示，名称、位置和绑定后的商品摘要可以更新。
- 航标被破坏：删除服务端的活动广播记录，并向客户端撤下标记。

撤下标记仅改变地图显示，不抹除客户端已经学到的资料。已经选定的导航目标、潜在航线的收购目录匹配及信息卡查询继续使用历史坐标和商品摘要，不因关闭广播或撤下标记而取消。客户端缓存保存隐藏状态；登录和维度快照也会协调当前可见性，不会让已经关闭或破坏的航标因重新载入缓存而重新显示。贸易是否实际可用仍以交易时的服务端校验为准。

地图标记复用自然贸易点的商品展示样式。只要某种货物启用了出售或收购配置，就会出现在标记中；即使当前可售数量为零、保险库可插入空间不足或结算器余额暂时不足，也不隐藏配置项。原贸易点等级图标位置显示贸易点所有者头像，皮肤暂不可用时回退为默认 Steve/Alex 头像。

贸易地图当前从航运手册打开。点击玩家贸易点标记，固定信息卡显示名称、“玩家经营贸易点”和收购/出售目录；可使用指南针设置个人目的地，也可居中或关闭卡片。关闭卡片不取消目的地。手册中的推荐航线仅统计玩家名下物理货柜货物，不把贸易点仓库算作随身运输货量；详细交互见[航运手册与玩家档案](<../../02系统规则/玩家档案/README.md>)。
