# 物流隧道入口与频率网络

更新：2026-11-20。入口`cargoverse:logistics_tunnel_entrance`同时用于终端与仓储接入；原`cargoverse:tunnel_linker`保留方块和物品，目前不参与连接。

## 配置网络

1. 在出售、收购、仓库管理终端或[自动卸载机](<06_货柜卸载机.md>)的指定接口外放置一个空白隧道入口，创建新网络。入口背板朝终端、开口朝管线；手持入口点击终端时优先安装，不打开管理GUI。
2. 手持其他隧道入口右键已放置的入口，复制其频率，手持物品出现附魔光效并显示网络标识。手持已配置的入口时，64 格内已加载的同频入口会显示闪烁外框。
3. 用这些已复制频率的入口连接其他终端和仓库，加入同一网络。一个仓库入口即可供同频网络中的多台终端共享，不需要为每台终端安装独立链接器。
4. 使用实际物流隧道连接入口的开口。浏览可读取同频网络内已加载仓储，实际装卸还必须有有效管线；频率不同则无法访问，即使隧道已经连通。

空白入口每次放置都创建独立网络。对空气右键清除手持入口的频率，只影响手持物品；已有入口保持原网络。需要更换已放入口的频率时，将其拆下，复制所需频率后重新放置。普通破坏掉落为空白入口。

入口可独立放置，不因背后没有容器而掉落。侧面放置时按点击面朝向，地面／顶面放置保持水平朝向玩家。终端与仓储都通过入口接隧道，不再让管线直接连接终端本体。各设备接点见[物流隧道](04_物流隧道.md)。网络不授予贸易点管理权限，不传播站点所有权。

## 原生仓储

入口按背板接触面提供仓储类型。物品查询读取 NeoForge 物品能力，流体查询读取流体能力，生物查询只识别围场核心的专用接口。物品和流体保留原生插入、提取与侧面限制。入口缓存能力句柄，容器更换、入口转向或能力失效时重新识别，库存和容量仍从原生容器读取。支持箱子、木桶、Create保险库／储罐等通用接口设施。原版炼药锅遵循NeoForge原生离散流体规则：部分水位按实际容量读取，完整水锅／岩浆锅常规转移1000mB；不伪造连续液位，细雪不作为流体。

同一原生控制器或双箱接多个入口仍只计一次，其他模组按共享能力对象去重。围场核心仅在左侧底层中部接入同频入口，实体继续保存在世界中，实际卸货还检查围场范围、净空和容量。终端只读取自己入口所属频率的仓储，多个站点可共用同一网络，价格、权限和账户仍分别维护。

## 生命周期

- 频率保存在入口上，终端重命名或换绑站点不改变网络；保留入口并在原位置重建兼容终端，会继续使用该入口网络。
- 移除一台终端的入口只断开该终端；其他终端继续共享仓库。移除仓库入口立即停止读取该仓储，不删除原生内容。
- 改频率、方向、入口或管线使相关路径缓存失效，实际装卸重新核验。断线不清空报价、站点绑定或世界生物。
- 只登记已加载入口位置；区块加载回调不查询相邻世界，卸载时撤出索引。不为复制频率、浏览或恢复连接强制加载区块。
- 转移仍先模拟再通过原生接口执行，失败用回执补偿。技术预算见[物流隧道](04_物流隧道.md)。

旧链接器记录的终端地址不自动迁移。现有设施需要在终端接口安装入口，并把终端与仓库入口配置到同一频率，再连接管线。
