# 货柜蓝图打印机

## 定影器与打印

1. 手持空白货柜蓝图右键定影器，将一张蓝图转移到公开暂存槽，表面显示白色蓝图模型。
2. 用上下按钮选择货柜，绿色PRINT按钮打印。服务端重新检查目录、繁荣、许可、空白载体与付款，扣费后写入唯一配方ID，表面切换为蓝色模型。
3. 再次右键定影器取回物品，背包放不下的部分掉落。任意玩家均可存取，无所有者校验。空白蓝图也能直接取回。

定影器只接受空白货柜蓝图；已有蓝图时点击执行取出。已打印蓝图留在槽内时无法覆盖或再次扣费。内容随方块实体保存和同步；拆除任意结构成员时，槽内蓝图只掉落一次。打印即时完成，不再打开原材料确认页。


## 表面显示

五个翻牌显示器分别显示：最大装载量（U）、空柜质量（Kpg）、占用调度点、运输介质（物品／流体／生物）、蓝图打印费。保留型号页码、货柜名称、说明、能力图标与结构全息预览。编号仪表保留模型基座，按钮定位模型替换为通用按钮。上下切换按钮朝外排列；全息预览在原朝向上额外旋转90°，随终端水平朝向一起转动。碰撞与选中形状按机身、侧柜和倾斜面板分部缓存；斜面以1模型像素步长近似，移除旧前伸占位和上方空白区域的实体碰撞。

实现入口：`CargoManufacturingPlatformBlockEntity`、`CargoManufacturingPlatformSurfaces`、`CargoManufacturingPlatformDisplay`、`CargoManufacturingPlatformRenderer`。
