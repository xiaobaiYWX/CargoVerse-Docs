# 许可证注册终端

`cargoverse:license_registration_terminal` 使用世界表面微缩胶片投影完成许可证注册和注销。终端顶部翻牌显示器显示注册点定义的 `display_name`。

## 绑定

管理员模式下右键终端打开配置界面，设置贸易点实例 UUID。

终端不绑定玩家 UUID。当前交互玩家由每次服务端按钮请求确定。

贸易点 UUID 留空、实例不存在、贸易点没有制造商、没有 `registration_point` 模块或注册定义无效时，终端不提供业务内容。模型、按钮和各仪表仍正常显示，主投影提示未绑定；不会选择默认贸易点。

## 控件

终端使用四个实体按钮：

- `OK`：进入选中功能、推进重复注册提示、确认注销或完成注册；
- `BACK`：返回上一级；
- 上一页：在当前协议中向前翻页；
- 下一页：在顶层功能间循环，或在当前协议中向后翻页。

按钮模型、命中区域、高亮与按压动画来自公共交互组件。投影内容切换由微缩胶片组件维护动画状态。

## 注册许可证

未注册玩家进入后阅读九页注册协议。协议页使用上一页／下一页浏览；只有最后一页接受 `OK`。确认后创建玩家运输档案，写入：

- 随机执照 ID；
- 玩家姓名与 UUID；
- 注册日期；
- 注册点的 `license_type`；
- 贸易点所属制造商的显示名称作为签发机构；
- 贸易点制造商作为签发制造商；
- 注册定义的初始许可证等级；
- 注册物品奖励；
- 注册定义配置的签发制造商声望奖励。

注册完成后显示成功页。`reputation_rewards.reputation_rewards` 只在首次成功注册时计入当前许可证的签发制造商。

已持有有效许可证的玩家进入该功能时，`OK` 依次推进五页重复注册提示。流程不会创建第二份许可证、注册奖励或声望；最后一页只能通过 `BACK` 返回。

## 注销许可证

注销协议共五页，可用上一页／下一页浏览。最后一页按 `OK` 后执行注销：

- 清除当前许可证及许可证范围内的档案字段；
- 清除许可证经验和航运风格统计；
- 保留玩家已经购买、制造或获得的全部货柜；
- 保留制造商发现顺序和其他制造商声望，只清零本次注销许可证的签发制造商声望。

注销后玩家不能装货、卸货、制造或购买货柜；第二章货柜管理仍可查看和删除保留下来的个人资产。重新注册后，许可证经验与航运风格从新许可证重新计算，玩家生涯统计继续保留。

基础货柜使用独立型号，在蓝图打印机免费打印并由搭建器制造。它不属于注册奖励；注销／重注册不会绕过每人一个基础柜的持有限制。
