# 货物收购终端

`cargoverse:cargo_unloader` 是自然贸易点的货物收购终端，保留原卸载机注册 ID 和定位点绑定。玩家将柜内货物卖给本站；模型与表面布局独立于玩家贸易点卸载终端。

自然站收购终端使用单无人机与右侧停机位；玩家站收购终端使用双无人机与左侧停机位，控制台左右镜像。模型、仪表、拉杆、预览底座与缓存碰撞同步适配四个水平朝向。货柜模型预览以长边面向操作玩家，随终端朝向旋转。无人机与纸箱规则见[货运无人机](15_货运无人机.md)。

## 结构与绑定

- 控制器统一渲染完整模型，成员方块不重复绘制；
- 管理员可空手潜行右键打开子终端绑定列表，选择 128 格内的信息柜。世界生成时，结构内的设备会预填同一站点，管理员随后也可修改绑定；
- 终端在所有有效卸载点的范围合集内只识别一个货柜：优先选择距任一卸载点中心最近者，距离相同时选择货柜 ID 较小者；
- 没有有效贸易点或卸载点时，仪表保留外观并显示未绑定，卸载操作不可用。

定位点规则见[货柜定位点](16_货柜定位点.md)。

## 世界表面内容

终端按柜内实际载荷显示图标、货物名称、预计收入、计划卸载质量、柜内剩余数量、货柜名称和模型预览。物品、流体、生物统一读取当前货柜内容，不按本站收购目录过滤；本站没有报价时依然显示货物，收入栏显示 `---`。数量滑轨改变计划量，不因拖动滑轨重新扫描装卸区域。

- 数量滑轨选择 1～256 个操作单位：固体按最大堆叠数量为一组，流体为 1000 mB，生物为一只。
- 柜内数量按固体 `stk`、流体 `mB`、生物 `mob` 表达；固体余量可显示不足一组的小数。
- 货柜进入卸载区后，按拉杆下方的灰色 `SCAN` 按钮扫描。货柜离开后，下一柜需要重新按键扫描。
- 右侧确认拉杆先重验货柜、报价及交易条件。本站无法收购时直接提示原因，不打开可执行的交易；通过检查后打开通用卸载确认页。
- 黄色 `SET` 按钮打开本站收购目录；卡片选择只用于当前玩家查看报价，不改终端表面、计划量或确认拉杆所操作的实际货柜。
- 名称立牌显示在正面；货柜全息预览不提供准星悬停名称。

## 收购目录 GUI

收购目录具有独立的菜单、快照和屏幕实现，仅与出售界面共用图集。每屏为 5×3 张卡片，可滚动浏览本站收购的物品、流体和生物，不混入出售目录。打开和浏览不检测卸载区，也不要求场内存在货柜；真实卸载仍通过拉杆与服务端确认流程完成。

点击卡片只在客户端当前界面内选中条目，立即显示该条目的市场基准价、当前收购价及涨跌幅。当前收购价按实际浏览玩家的签约条件与本站动态收购修正计算；两名玩家的选择互不影响，服务端没有卡片选择或成交动作。

卡片下方显示今日剩余可收购量，以本条目操作单位换算：固体按物品最大堆叠数、流体按 1000 mB、生物按一只，支持原生尾量。无每日限制显示 `∞`。繁荣度不足的货物带锁，悬停可查看所需等级。已解锁条目的额度耗尽后覆盖 `Sold out` 图标，仍可选中查看报价。

服务端仅在界面打开期间每 10 tick 检查目录、价格和余量，内容变化才同步。菜单绑定打开时的终端实例及贸易点，离开 8 格范围、终端失效、换绑或贸易点注销后不可继续使用。关闭按钮仅关闭界面，既不提交卸载，也不保存表面选择。

## 卸载确认

交易成功后，双方自然终端共用[货运无人机](15_货运无人机.md)。收购方向从货柜处取得一个视觉纸箱并运回终端。

拉下确认拉杆后打开私有确认页。装卸共用 256×198 图集。左侧显示货物图标、名称和本次卸货数量。右侧显示柜内数量与容量、当日剩余收购额度及结算器余额。玩家贸易点在额度栏显示仓库库存，自然贸易点无限额时显示 `---`。底部显示市场修正、签约修正及卸货质量。

成功结算后，界面播放数值变化并自动退出。条件变化或结算失败时留在页面显示提示。

绿色确认按钮只提交一次，处理期间不可重复点击；结果状态在按钮右侧显示。右侧叉号始终可用，等待时也可取消未提交会话并关闭；已完成结算不会撤销，关闭后的迟到回执不会重新打开界面。取消和服务端重验边界与[装载确认](13_货柜装载机.md)共用。

装载与卸载确认共用文字对齐规则：当前值和增量在各自底图槽位内水平、垂直居中，确认文字带阴影；底部标签左对齐信息框，数值居中并带阴影。

## 卸载交易

服务端重新识别当前唯一货柜，并验证许可证、贸易点状态、货柜所有权与有效性、定位范围、精确物品及组件、容器兼容性、贸易点收购报价与当日额度，以及玩家是否携带可接收 `VB` 的虚空结算器。检测范围内的其他货柜不会通过按钮切换或参与本次交易。

```text
有效原生数量 = min(请求操作单位 × 操作步长, 柜内原生数量, 本站剩余收购额度)
单位价格 = 本站收购 unit_price × 动态价格修正 × 签约运输员卖价修正
收入 = ceil(单位价格 × 有效原生数量 / 操作步长)
```

签约运输员修正只在玩家许可证签发制造商与贸易点制造商一致时使用，最后应用。货损已直接扣件数，不叠加完整度修正。

成功后按物品栏顺序把 `VB` 写入玩家携带且仍有容量的虚空结算器，必要时可跨多台入账，随后减少或清空 Load。自然站交付与出售库存独立，受收购每日额度限制。许可证经验按目的地的收购配置和实际成交份数结算，缺省为 0。手动注册的自然站同样适用。玩家贸易点交付使用仓储容量和报价规则。站点繁荣度与制造商交付声望由[物资供应](<../../02系统规则/自然贸易点/03_物资供应.md>)单独结算。

结算器余额、货柜、贸易点、许可证经验、制造商声望和航运风格记录共享服务端串行补偿边界。卸空保留货柜资产。提交后质量、惯量和实体贴花进入统一物理刷新队列，同一货柜的连续交易按最后一次交易后的 `20 tick` 合并。
