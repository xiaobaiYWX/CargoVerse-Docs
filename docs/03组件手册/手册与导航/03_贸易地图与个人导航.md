# 贸易地图与个人导航

## 地图入口与折叠

贸易地图固定为手册第六章，由右上角地图边角书签进入；悬停高亮，悬停或选中不伸长。右页的折叠地图与入口共享右上锚点，点击后依次向左、向下展开，完成后才显示可操作地图。

展开共 14 帧、每帧 35ms，总长约 0.49 秒；收起以相同速度倒放。第一阶段沿入口右边缘向左展开，第二阶段锚定第一阶段末帧左边缘，底部折页贴图宽度变化不移动上半张地图。

地图边缘覆盖 `map_fold/border.png` 纸张边框，隐藏矩形画布边界。展开/收起期间隐藏实际地图且屏蔽其输入；切换章节必须先收图再翻页。点击纸张边缘或按关闭键收图；服务端档案刷新保留动画、待跳转章节和当前地图视图，完整关闭顺序见[入口交互](<01_手册与货柜HUD.md>)。

引导台另有独立地图编辑器，见下文硬件边界。

## 地图操作与信息卡

初次展开以玩家投影后的世界位置为中心，持续更新玩家位置及自身世界朝向；不额外叠加载具姿态，也不显示地图中心坐标和缩放系数。可拖动平移和滚轮缩放。

悬停标记只显示首次发现玩家、到访时间和归属模组等通用信息。点击普通结构、贸易点或普通航标打开固定右下角的信息卡，卡片与边框留有安全距离、保持固定 GUI 大小，不随地图缩放。点击地图空白或拖动不关闭卡片，使用关闭按钮关闭。

- 贸易点卡片显示大名称、归属制造商和收购/出售货物，不重复悬停的通用信息；玩家贸易点显示“玩家经营贸易点”。
- 普通结构显示大名称及第二行坐标，同样支持居中与导航。
- 卡片上方左侧为导航按钮，右侧为居中和关闭按钮；居中只改变视口，不设置目的地。

标记类型、商品图标、航标广播和卡片的共用绘制规则由[地图标记 GUI 规则](<../../06制作与开发/开发实现/地图/04_结构发现、图标与数据包规则.md#gui-行为>)维护，本页只记录手册侧交互。

## 左页：最近成交的自然贸易点

左页最多显示个人最近成交的三个自然贸易点，按最近成交顺序排列。在同一站点再次成交时，更新该站的名称、坐标及时间并移到首位。在新的站点成交时加入一条，满三条后移除最早的一条。

自然贸易点的货柜买卖及售货机购买在成功结算后记入档案。到访、未完成的交易和物资供应不会计入。成交记录随存档保存，已有的到访记录不会补入这一页。

同一维度的记录可以点击“在地图上显示”。已知站点会打开信息卡，其他记录按成交时保存的坐标居中。点击保留现有导航目标。其他维度的按钮置灰并提示站点所在维度。

## 右页：当前导航点

双击贸易点、普通结构或普通航标图标，或点击其卡片上的指南针，设为当前个人目的地，不强制收图。目的地图标左侧绘制导航标记。双击配对、命中容差和宿主隔离见[接口文档](<../../06制作与开发/开发实现/地图/05_导航架构与接口.md>)。

收图后右页下方显示名称、XYZ 坐标和水平直线航程。名称放大、最多两行；坐标和航程按实际换行紧凑排列，不重叠。航程单位 `m`、每格一米、带千位分隔，起点使用玩家经 Sable 投影后的世界坐标，不使用 shipyard 内部坐标。

普通结构用对应结构图标，普通航标用灯塔图标，自然贸易点用繁荣度图标，玩家贸易点用所有者头像。无目标时显示“暂无导航目的地”。区域右下角：

- 左侧垃圾桶清除个人目的地，不删除地图资料或标记，也不影响引导台目标。
- 右侧“在地图上显示”展开地图、居中当前目的地并打开信息卡；不替换目标，无目标时两个按钮置灰。

## 护目镜导航提示

选定个人导航点后，佩戴机械动力护目镜即可在游戏画面中看到目标标记。自然贸易点沿用当前繁荣度图标，玩家贸易点、普通结构与航标沿用各自的地图图标。图标下方第一行显示目标名称，第二行以米为单位显示水平航程。

目标进入镜头范围时显示，超出地形渲染距离时仍可定位。取下护目镜、隐藏游戏界面或清除导航点时，提示消失。

## 目标生命周期与硬件边界

信息卡、视口、个人目的地和引导台目标是不同状态。关闭卡片、拖动、居中、收图、翻页、重开手册或刷新档案都不取消个人目标；选择新目的地才替换。目标按类型与实例 ID 解析，已知名称、位置或繁荣度更新会反映到页面。退出世界、切换维度/玩家或目标资料不存在时清空。

关闭航标广播或撤下地图标记只隐藏显示，不删除已学习的名称、坐标及商品目录，因此保留已有导航目标。

个人具名目的地同步至服务端会话，不跨重连保存。手持手册右键引导台显式复制目标，空手右键引导台可在其独立地图设置目标，潜行右键配置 PID。方块目标及参数独立持久化，后续个人选择不自动改写方块，独立地图也不反写个人选择。

地图只处理玩家状态和目的地，不直接操控载具；已实现的转向引导不包含路径规划、避障或自动到达。服务接口和权限边界见[地图导航架构](<../../06制作与开发/开发实现/地图/05_导航架构与接口.md>)，动力与物理规则见[航行引导台与 PID](<../载具仪表/01_航行引导台与PID控制.md>)。
