# 11 玩家贸易点

玩家贸易点是由玩家在世界中搭建、出资和经营的运行时贸易设施。它与数据包定义并由结构生成的自然贸易点共用货物、货柜、地图图标和部分终端交互组件，但不依赖自然贸易点的资源表、繁荣度或自动生成经济。

## 当前实现边界

- 玩家贸易点没有资源表、繁荣度和凭空生成资金；库存与资金都必须真实存在。
- 核心终端负责身份、运行、结算、绑定和权限，玩家仓库终端负责持久化货物库存与报价。
- 终端交互分为核心、管理和公共三级权限；授权管理员只获得仓库与航标管理权。
- 货物不能通过终端物品携带。仓库解绑或核心拆除不会销毁库存，非空仓库也不能直接拆除。
- 公共交易与管理装卸都以服务端检测到的唯一物理货柜为准。
