# 11 玩家贸易点

玩家贸易点是由玩家在世界中搭建、出资和经营的运行时贸易设施。它与数据包定义并由结构生成的自然贸易点共用货物、货柜、地图图标和部分终端交互组件，但不依赖自然贸易点的资源表、繁荣度或自动生成经济。

## 本章内容

- [系统架构与生命周期](01_系统架构与生命周期.md)：核心终端、必须组件、绑定、启停和拆除规则。
- [库存、报价与结算](02_库存、报价与结算.md)：聚合库存、完整度、收购与出售配置、VB 结算和管理者装卸。
- [终端、表面 UI 与地图](03_终端、表面UI与地图.md)：各终端职责、检测区域、交互边界和航标广播。
