# 11 玩家贸易点

玩家贸易点是由玩家在世界中搭建、出资和经营的运行时贸易设施。它与数据包定义并由结构生成的自然贸易点共用货物、货柜、地图图标和部分终端交互组件，但不依赖自然贸易点的资源表、繁荣度或自动生成经济。

## 当前实现边界

- 玩家贸易点没有资源表、繁荣度和凭空生成资金；库存与资金都必须真实存在。
- 核心放置后无主，点击黄色 AUTH 按钮打开 GUI，长按绿色页签 3 秒手动注册；红色页签长按 3 秒注销并解除绑定，不删除保险库物品。注册才占数量名额。
- 管理核心负责身份、激活、结算、权限和报价；设备沿实体物流隧道接入，不再使用连接器逐台远程绑定。SET 商品管理入口在仓库管理终端上；Create 仓库保存实际内容，收发器定位存储。
- 每核心可连接最多 3 个保险库和 5 个普通储罐，分别汇总物品／流体库存；液体页、报价、公共确认装卸及免费管理装卸已接入；液体常规每份 1000mB，原生量以 mB 显示。生物和气体仓库仍未接入。
- 终端交互分为核心、管理和公共三级权限；授权管理员可管理装卸及航标设置，不能编辑商品报价或操作核心/连接工具。
- 货物不能通过终端物品携带。仓库解绑或核心拆除不会销毁保险库库存；删除旧永久清仓与非空管理终端拆除限制。
- 公共交易以服务端检测到的唯一物理货柜为准，所有身份均正常结算；仓库管理终端装卸免费，不检查报价或结算器，也不奖励经验，但仍要求相关端点具有到激活核心的有效路径。
- 每位所有者默认最多 3 个核心，按 UUID 跨维度统计，服务器配置可修改上限；拆除即释放名额。
- 玩家贸易设施允许放在 Sable 上但不能接入或使用，已存货物保留；六类多方块终端每台合计 1000 Kpg，仓库收发器也为 1000 Kpg。
