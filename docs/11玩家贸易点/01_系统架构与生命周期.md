# 玩家贸易点：系统架构与生命周期

## 1. 权威对象

玩家贸易点核心终端是一个贸易点的唯一权威对象，持有：

- 贸易点 UUID、所有者 UUID、所有者名称和贸易点名称；
- 启用或暂停状态；
- 虚空结算器及其 VB 余额；
- 各功能终端的位置与绑定关系；
- 每种货物的聚合库存和收购、出售配置；
- 累计交易额与净利润。

功能终端只保存核心 UUID 和本地显示状态。交易、库存变更、权限检查和货币结算均由服务端以核心终端的数据为准。

## 2. 组件构成

贸易点进入正常交易状态前必须同时具备下列组件：

| 组件 | 是否必须 | 职责 |
| --- | --- | --- |
| 虚空结算器 | 是 | 安装在核心终端中，作为整个贸易点的 VB 收发账户 |
| 玩家货柜装载机 | 是 | 在装载区域向其他玩家的货柜出售货物 |
| 玩家货物卸载机 | 是 | 在卸载区域收购其他玩家货柜中的货物 |
| 玩家装载区域 | 是 | 四根装载区域标记杆成功围成后，作为一个整体组件绑定 |
| 玩家卸载区域 | 是 | 四根卸载区域标记杆成功围成后，作为一个整体组件绑定 |
| 玩家仓库终端 | 是 | 供所有者免费管理仓库装卸，并打开详细库存设置界面 |
| 玩家贸易点信息柜 | 是 | 在同一终端中展示出售与收购目录 |
| 玩家贸易点航标塔 | 否 | 控制贸易地图发现与广播；不参与贸易点完整性判断 |

每种组件只有一个有效绑定位置。装卸区域在核心中保存逻辑区域的控制角位置，但四根标记杆共享同一个区域 UUID，属于一个整体组件，不分别占用组件槽位。某类组件已经绑定时，连接器会拒绝再绑定同类组件；需要先显式解绑旧组件。解绑或破坏必须组件会立即暂停交易。

## 3. 建设、绑定与启用

1. 放置核心终端后，由放置者成为贸易点所有者；其他玩家贸易点终端放下时没有所有者，也不会自动寻找附近核心。
2. 玩家手持贸易点终端连接器右键自己的核心终端，选择该核心。连接器与核心之间会出现连接线。
3. 保持手持连接器，右键尚未绑定的必须终端，即可将其绑定到已选核心；终端从核心继承所有者。已经绑定的终端不会自动转移到另一核心。
4. 选择与绑定范围固定为以核心终端为中心的 **32 格半径**。连接线靠近核心时为绿色，接近边界时逐渐转红；玩家越界后会自动取消选择。
5. 对空气右键、切换到其他物品、切换维度或离开服务器，都会取消当前核心选择。
6. 手持连接器潜行右键普通终端可解除单个绑定；潜行右键核心终端可解除该核心的全部组件绑定。解绑操作会校验贸易点所有者。
7. 装载、卸载区域标记杆放置时不绑定核心；四根同类标记杆组成有效正方形并用扳手探测成功后，区域才能作为整体被连接器绑定。四个角无需全部进入 32 格半径，只要至少一个角在范围内即可。
8. 在核心终端左上方的结算器槽位副方块上，手持虚空结算器右键完成安装。
9. 所有必须组件和结算器均就绪后，所有者才能启用贸易点。

手持连接器时，核心到已绑定组件的连接线才会显示。该可视化只用于确认拓扑，实际绑定关系始终由服务端核心数据和组件 UUID 校验。

组件所在区块暂时卸载时，已有绑定会保留，避免普通区块卸载导致贸易点误停。区块重新加载后会重新核验方块实体和核心 UUID；终端确实被破坏或替换时才会失去就绪状态。

## 4. 暂停与拆除

- 任一必须组件被破坏、解绑或替换后，贸易点立即暂停并回到未完整状态。
- 任一区域的四根标记杆中有一根被破坏，整个逻辑区域立即注销，其余标记杆解除区域链接。
- 航标塔缺失、停止广播或被关闭不会暂停贸易点。
- 贸易点启用期间不能取出虚空结算器；必须先暂停交易，再空手右键结算器槽位取出。
- 核心终端被破坏时，贸易点立即从世界索引注销，清除已加载功能终端的链接，删除航标的共享地图记录，并掉落其中的虚空结算器。

## 5. 权限边界

- 启用、暂停、安装或取出结算器、库存配置、航标设置和管理者装卸仅允许所有者操作。
- 普通玩家只能通过已启用贸易点的公共装载机、卸载机进行购买或出售。
- 所有关键交互均由服务端重新检查所有权、组件绑定、检测区域、库存、货柜兼容性和资金，客户端表面 UI 只负责展示与发起请求。
