# 玩家贸易点：系统架构与生命周期

## 1. 权威对象

玩家贸易点把核心、报价和原生物品／液体存储分开。

核心终端持有：

- 贸易点 UUID、所有者 UUID、所有者名称和贸易点名称；
- 物流网络激活或解除状态；
- 虚空结算器及其 VB 余额；
- 各功能终端的位置与绑定关系；
- 授权管理员列表；
- 累计交易额与净利润；
- 精确物品／流体变体的出售／收购单价和各自独立的上架开关；不再保存保留数量与收购目标。

Create 保险库是唯一实际物品存储，核心终端保存报价，仓库管理终端提供操作入口但不保存物品。收发器提供稳定附着点，库存操作从该点重新解析保险库，不维护库存副本。40 张正式自然站货物表仍为空，A／B 指令测试表已填充；不迁移旧开发版仓库物品。

其他功能终端只保存核心 UUID、继承的归属信息和本地显示状态。交易、绑定、权限、库存与货币变更均由服务端重新核验，客户端 GUI 和表面 UI 不具有最终决定权。

## 2. 组件构成

激活网络不要求组件齐全；下列组件提供现有物品／液体业务服务，具体交易检查本次所需设备及结算条件。只连接储罐也能激活与营业，不强制连接物品保险库：

| 组件 | 使用条件 | 职责 |
| --- | --- | --- |
| 虚空结算器 | 公共交易需要 | 安装在核心中，作为贸易点 VB 收发账户；激活和免费管理装卸不需要 |
| 玩家货柜装载机 | 公共装载需要 | 在装载区域向玩家货柜出售货物，不是网络激活前置 |
| 玩家货物卸载机 | 公共卸载需要 | 在卸载区域收购玩家货柜货物，不是网络激活前置 |
| 玩家装载区域 | 装载需要 | 对应装卸终端与三根同类杆成区，归属跟随该终端 |
| 玩家卸载区域 | 卸载需要 | 对应装卸终端与三根同类杆成区，归属跟随该终端 |
| 贸易点仓库收发器 | 访问相应库存需要 | 附着并定位保险库／普通储罐；报价由仓库 SET 编辑，保存在核心 |
| 玩家贸易点信息柜 | 展示目录需要 | 面向所有玩家展示出售与收购目录；缺失不阻止网络激活 |
| 仓库管理终端 | 管理装卸／商品编辑需要 | 免费管理装卸与所有者专用 SET，不替代仓库和有效区域 |
| 航标塔（接入模式） | 可选 | 控制地图发现与广播；缺失不阻止网络激活 |

普通功能组件当前仍各保留一个控制位置，仓库收发器使用多位置集合。一个主装卸终端与三根同类杆共享区域 UUID，区域不另计网络端点。归属由[物流隧道激活网络](06_物流隧道与激活网络.md)派生；重复同类设备不自动开启多机排程。支线失联只停用受影响设备，不自动关闭整个核心。

源码将三个概念分开：功能端点类型只包含真实设备；装卸区域是主终端持有的几何及成员关系；就绪状态单独供表面仪表显示，使用稳定的同步位。区域和结算器不会因显示状态而获得独立网络身份，状态灯也不是贸易点激活的统一门槛。仓库收发器仅维护现行多位置集合，不保留旧单仓入口。

## 3. 建设、接入与激活

1. 核心终端放置后没有所有者，也不占建点名额。点击核心上的黄色 AUTH 按钮打开 GUI（未认领与已认领核心入口一致，不是右键终端任意位置），长按下方绿色页签 3 秒，确认将贸易点注册到自己名下；默认名称为“玩家名称的贸易点”。其他终端同样不会自动归属或寻找附近核心。
2. 铺设“贸易点物流隧道”连接管理核心、功能终端与仓库收发器；装卸区域随其主终端接入，不单独连接外围标记杆。终端是端点，不传导网络；普通 Create 管道不参与连接。
3. 点击绿色 PWR 激活，按最短隧道路径发现设备、写入归属，不要求预先搭齐业务设备。红色 STOP 解除整网激活。
4. 默认最大传播距离为 32 格隧道，可通过服务器 `logisticsRange` 调整，不再使用直线 32 格绑定半径。
5. 核心处于其他已激活网络覆盖内时不能激活；两个独立已激活网络接通时不互抢既有占用。
6. 所有者正常放置的设备自动接入；他人放置的设备由所有者使用连接工具确认。工具只诊断／确认接入，不再远程选择核心或绑定、解绑。
7. 每台装卸终端自带一个主角点，与三根同类杆形成区域。外围杆不接隧道，区域随终端归属；当前仍各一台装载机、卸载机，多区域排程待细化。
8. 在核心的结算器槽位副方块上安装虚空结算器。注册、激活、具备交易条件分别判断。
9. 保险库／普通储罐通过附着式收发器接入网络；公共物品业务仍检查真实库存、结算器和本次装卸设备。六项仪表灯显示设备状态，不再作为激活的前置条件。

拓扑变化使有关路径立即拒绝业务，服务端更新阶段重建并清理失联归属；有备用有效路径的设备保留。报价、授权、原生物品和流体不因断线删除。

区块暂时卸载保留归属／占用，但跨越未加载区块的路径不可用，不强制加载。恢复后核验当前网络，不能仅凭旧组件 UUID 恢复业务。

## 4. 暂停与拆除

- 组件被破坏或失联后，依赖该设备的业务不可用，其他有效支线可继续使用；不自动注销或关闭整个核心。
- 任一区域的三根外围杆中有一根被破坏，整个逻辑区域注销，其余杆解除链接；拆除主终端同时清理区域，未加载成员在加载后按区域索引核验。
- 航标塔缺失、停止广播或被关闭不会暂停贸易点。
- 贸易点激活期间不能取出虚空结算器；必须先按 STOP 解除激活，再空手右键结算器槽位取出。
- 核心终端被破坏时，贸易点立即从世界索引注销，清除已加载功能终端的链接，删除航标的共享地图记录，并掉落其中的虚空结算器。实际物品继续保存在 Create 保险库中，不因核心拆除清空。
- 核心拆除会失去其报价配置；解绑收发器保留核心报价。两者都不清空保险库物品。拆除仓库管理终端仅解绑，不删除核心报价或保险库物品；管理装卸保留，但不恢复永久清仓。

主动注销不需要拆除方块：所有者在核心 GUI 长按红色页签 3 秒确认。注销会停业、解除全部终端及区域/收发器绑定，移除授权与报价、清空名称和统计并释放名额；已安装结算器返还至背包（空间不足按原版方式掉落）。核心保持原位但生成新的贸易点 UUID，旧连接选择、未加载组件和旧菜单不能接入再次注册的贸易点。Create 保险库实际物品不删除。没有创建费用、注销费用或冷却。

## 5. 权限边界

| 权限级别 | 终端或操作 | 可操作人员 |
| --- | --- | --- |
| 核心级 | 管理核心激活／关闭、结算器、仓库 SET 报价、权限、网络接入确认 | 仅所有者 |
| 管理 | 仓库终端免费装卸、航标设置 | 所有者或授权管理员 |
| 公共 | 玩家装载终端、玩家卸载终端、玩家贸易点信息柜 | 任何满足交易条件的玩家 |

未注册核心任何附近玩家均可按黄色 AUTH 按钮打开注册界面；已归属核心仅所有者可按同一按钮打开管理 GUI。顶部名称可点击修改并回车保存；管理员列表按名称长度拼接标签，每项有独立叉号移除，下方输入玩家名称或 UUID 后点击加号添加。管理员名称标签、输入框及占位提示使用 `#cdbca8`。目标只从当前存档 `playerdata/*.dat` 的已有玩家记录中查询，按名称或 UUID 匹配；授权列表最多保存 64 人。原版玩家数据不保存姓名，本地 UUID 缓存仅用于读取这些记录对应的名称，不提供额外候选。未找到直接拒绝，不查询在线名单、不做多源兜底、不查询外部服务器，也不为未知名称计算离线 UUID。已有授权不自动清除，误添加条目可点叉号移除。授权只覆盖管理类终端，不授予核心操作、绑定、解绑、破坏权限。

未绑定核心的普通功能终端不属于任何玩家，任何玩家均可拆除。一旦终端绑定并继承所有者，只有归属玩家可以破坏；授权管理员没有拆除权限。Create 保险库和外部自动化不受本模组终端权限系统保护。

所有关键交互均由服务端重新检查所有权或管理授权、组件绑定、检测区域、库存、货柜兼容性和资金，客户端表面 UI 只负责展示与发起请求。

## 6. 建点数量限制

服务器配置 `cargoverse-server.toml`：

```toml
[playerTradePoint]
maxPerOwner = 3
```

最小值为 1。按所有者 UUID 跨维度统计已注册核心，授权管理员不会增加配额。未加载、暂停营业或装入 Sable 的核心仍占名额。达到上限时点击注册立即提示并取消长按进度，核心仍保持未归属；长按中名额被占满也会取消确认。未注册核心不限制放置且可正常拆除。主动注销或实际拆除后立即释放名额，没有冷却或创建费用。调低配置不会删除已有核心。

计数使用全存档持久化核心索引，不为检查配额扫描或加载区块，同一核心重载不会重复占用名额。GUI 变更由服务端核对当前菜单、核心实体及 UUID、8 格距离、静态世界和所有权；注册/注销还验证单次令牌和至少三秒持续确认，竞争注册只有首个成功者取得归属。

## 7. Sable 与终端质量

所有玩家贸易点设施均可正常放在 Sable 结构上，但不能激活、接入或使用，即使结构静止也不例外。范围包括核心、物流隧道、公共装卸、信息柜、航标、仓库管理终端、仓库收发器和装卸区标记杆；标记杆也不能在结构中形成新区域。设施业务拒绝运行，不接管 Create 自身自动化。

已接入设施装入结构后停止业务；原生内容、核心身份与配额保留，派生设备归属随实际网络失联清理。设施业务按原始坐标校验，不进行设施坐标投影或自动迁移；返回静态世界后按实际路径重新核验，停用核心需重新激活。航标装入结构时撤下此前的静态地图标记，广播开关配置保留。

这不限制货柜运输：静态贸易点仍可识别并装卸区域内的 Sable 物理货柜。普通贸易点和载具仪表不受本规则影响。

核心、玩家装载/卸载终端、信息柜、航标、仓库管理终端每台多方块终端合计 **1000 Kpg**，占位方块不重复计重，所有朝向一致。单方块仓库收发器质量也是 1000 Kpg。标记杆保持既有无实体碰撞行为，不额外增加质量。
