# 玩家贸易点：终端、表面 UI 与地图

## 1. 核心终端

核心终端的表面 UI 显示贸易点名称、必须组件状态、当前运行状态、结算器余额与余额比例、总交易额、所有者和净利润。按钮用于启用、暂停交易及打开少量必要设置。黄色 `AUTH` 大按钮打开玩家权限配置 GUI；列表显示已授权管理员，输入框接受玩家名称或 UUID，添加和移除操作都只允许所有者执行。

结算器模型平时隐藏。玩家在左上方槽位副方块安装结算器后才显示；贸易点运行时不能取出。

## 2. 公共装载机与卸载机

公共装载机和卸载机不再自带固定检测区域。玩家需要分别使用四根装载区域标记杆和四根卸载区域标记杆建立两个独立区域：四根同类标记杆必须处于同一高度，并沿东南西北方向围成边长 2～18 格的正方形。标记杆放置后不会单独绑定；所有者使用 Create 扳手右键任意一根标记杆，探测成功后四根杆才形成一个逻辑区域，随后使用贸易点终端连接器将区域整体绑定到核心。

区域宽、深等于正方形边长，高度始终为边长的一半并向上取整。例如边长 5 格会建立 5×5×3 的检测范围，边长 18 格会建立 18×18×9 的检测范围。区域不是四个独立必须组件：装载区域和卸载区域各自只占核心终端的一个必须组件槽位。任意一根标记杆被破坏都会注销整个区域并暂停贸易点。

标记杆没有实体碰撞，玩家和实体可以像穿过火把一样通过，但仍保留选择轮廓以便交互。单根或尚未形成有效区域的标记杆不显示范围框。区域形成后，四个斜向伸缩部件沿各自正面平滑伸出，旋转组开始绕轴缓慢旋转；区域失效时先回到默认角度并停止，再将伸缩部件收回。装载和卸载标记杆共用动画结构，但使用不同贴图。

有效区域的范围提示只在玩家距离区域 8 格以内显示：完整线框保留，侧面改为从底部完全不透明、到区域半高完全透明的渐变色，不再铺设四周贴图；底面中央显示完全不透明的装载或卸载标识。标识相对底面上移 1.5 像素以避免与地面或地毯闪烁，尺寸取区域短边的 75%，最大不超过 10 格。

每个检测区域同时只识别距区域中心最近的一个货柜，距离相同时选择货柜 ID 较小者。终端不提供货柜切换功能；需要操作其他货柜时，应先将当前货柜移出区域或让目标货柜成为最近货柜。交易提交时服务端会按相同规则重新识别，防止显示对象与实际交易对象不一致。

候选货物遵循统一规则：

- 卸载模式只显示当前货柜内已有的货物；没有货柜时，仅货柜名称栏显示“无货箱”，其余货物信息留空。
- 装载模式在没有货柜时显示贸易点中有可用库存的货物；有货柜时只显示该货柜可装载且贸易点有可用库存的货物。
- 左右箭头切换候选货物，页码使用独立仪表显示。
- 数量滑轨按下后打开临时数值设置界面；确认后滑块移动到对应比例，不再直接拖动滑轨。

公共装载和卸载分别执行真实 VB 交易。货物完整度仪表显示仓库平均完整度或当前货柜货物完整度，与所处模式一致。

## 3. 玩家仓库终端

玩家仓库终端把管理者装载和卸载集成在同一台终端中：

- 钮子开关切换装载模式与卸载模式；
- 独立 LOAD、UNLOAD 按钮只在对应模式生效；
- SET 按钮打开库存管理 GUI，用于详细设置各商品的价格、保留数量、收购目标和最低完整度；
- 左右箭头始终切换货物候选，方向语义在所有终端中保持一致；
- 装卸候选、唯一货柜识别、无货柜状态、货柜兼容性和页码规则与公共终端共用同一套选择逻辑。

该终端操作免费，允许所有者及授权管理员使用；实际货柜由贸易点整体绑定的装载区域或卸载区域识别。授权管理员不能借此修改核心、绑定关系或终端归属。

## 4. 库存管理 GUI

库存管理 GUI 是表面 UI 无法容纳的详细设置界面。每行使用完整外框和竖向分隔线展示一种货物，包含单位价格、货物与库存、保留数量或收购目标、完整度。出售和收购按钮切换列表模式：

- 出售页只列出仓库已有的货物，编辑单位售价和保留数量；
- 收购页列出全部可用货物，编辑单位收购价、收购目标和最低完整度；
- 当前选中行使用高亮边框；输入值由服务端再次限制到合法范围。
- 左上角垃圾桶按钮用于永久清空仓库。仅所有者可以触发，持续按住 5 秒后销毁全部库存和交易配置；按钮使用红色覆盖显示确认进度，悬停提示该操作不会返还任何内容。

## 5. 玩家贸易点信息柜

信息柜是必须组件，使用单一终端展示贸易点的出售与收购目录。绿色大按钮切换两种目录，界面只读，不负责修改库存配置。商品单价、库存或额度、完整度等内容通过统一仪表组件绘制。

## 6. 航标塔与地图发现

航标塔是可选组件，不影响贸易点完整性。当前只有一种航标塔，沿用 `player_trade_beacon` 注册 ID、模型及按钮，显示名改为“航标塔”；旧普通航标 `navigation_mark` 的方块与物品 ID 已直接移除，不做旧存档方块/物品兼容。

未绑定时可独立使用：SET 按钮编辑普通地图标记名称，钮子开关控制广播；此时不属于任何玩家，任何玩家都可以设置或挖掘。绑定玩家贸易点后广播对应贸易点的名称和商品目录，设置/广播操作限所有者和授权管理员，连接器的绑定/解绑仍只限所有者。解除绑定后保留名称和广播状态，回到普通标记模式。

- 广播开启：航标旋转部件缓慢旋转，并向贸易地图发布点位。
- 广播关闭：旋转部件停在当前角度，立即撤下所有玩家地图上的该标记，所有者也不例外；未记录过该点位的新客户端不会获得资料。
- 恢复广播：使用同一标记 ID 重新显示，名称、位置和绑定后的商品摘要可以更新。
- 航标被破坏：删除服务端的活动广播记录，并向客户端撤下标记。

撤下标记仅改变地图显示，不抹除客户端已经学到的资料。已经选定的导航目标、潜在航线的收购目录匹配及信息卡查询继续使用历史坐标和商品摘要，不因关闭广播或撤下标记而取消。客户端缓存保存隐藏状态；登录和维度快照也会协调当前可见性，不会让已经关闭或破坏的航标因重新载入缓存而重新显示。贸易是否实际可用仍以交易时的服务端校验为准。

地图标记复用自然贸易点的商品展示样式。只要某种货物启用了出售或收购配置，就会出现在标记中；即使当前可售数量为零、收购目标已满或结算器余额暂时不足，也不隐藏配置项。原贸易点等级图标位置显示贸易点所有者头像，皮肤暂不可用时回退为默认 Steve/Alex 头像。

贸易地图当前从航运手册打开。点击玩家贸易点标记，固定信息卡显示名称、“玩家经营贸易点”和收购/出售目录；可使用指南针设置个人目的地，也可居中或关闭卡片。关闭卡片不取消目的地。手册中的推荐航线仅统计玩家名下物理货柜货物，不把贸易点仓库算作随身运输货量；详细交互见[航运手册与玩家档案](../12航运手册与玩家档案/README.md)。
