# 玩家贸易点：终端、表面 UI 与地图

## 1. 核心终端

核心终端的表面 UI 显示贸易点名称、必须组件状态、当前运行状态、结算器余额与余额比例、总交易额、所有者和净利润。按钮用于启用、暂停交易及打开少量必要设置。核心不再提供 SET 或商品管理菜单，相关入口只在仓库管理终端上提供。黄色 `AUTH` 大按钮打开核心管理 GUI，仍不提供商品编辑入口：

- 核心放置后无主，点击黄色 AUTH 按钮打开注册界面，与已认领核心一致，右键终端其他位置不打开 GUI；绿色页签长按 3 秒注册到自己名下，红色页签长按 3 秒注销。未注册不占数量名额，注册时检查配置限额。
- 顶部显示贸易点名称，点击后可编辑，回车、失焦或关闭保存；初次注册默认“玩家名称的贸易点”。下方显示所有者名称。
- 已授权管理员按名称宽度拼接标签，逐项叉号移除；标签、下方输入文字和提示颜色均为 `#cdbca8`。输入玩家名称或 UUID 后点击加号添加，右侧滚动条浏览名单。只查询当前存档已有的玩家记录，名称由本地 UUID 缓存读取；按名称或 UUID 匹配，未找到直接拒绝。不查询在线名单、不添加其他兜底、不联网或自动生成 UUID。添加和移除仍仅限所有者。
- 注册/注销以自上而下的半透明绿色遮罩逐渐覆盖页签表示进度，只在持续按住且光标仍在按钮上时累计；提前释放、移出、窗口失焦或关闭取消。服务端独立校验三秒确认、菜单身份、距离和权限。达到数量上限时立即停止注册确认并在 GUI 内提示；长按期间名额被占用也会取消，释放名额后需重新长按。
- 注销解除全部绑定、移除报价与授权并返还结算器，保留核心方块和保险库内物品；生成新核心身份，旧菜单和连接不会复用。

结算器模型平时隐藏。玩家在左上方槽位副方块安装结算器后才显示；贸易点运行时不能取出。

## 2. 公共装载机与卸载机

公共装载机和卸载机不再自带固定检测区域。玩家需要分别使用四根装载区域标记杆和四根卸载区域标记杆建立两个独立区域：四根同类标记杆必须处于同一高度，并沿东南西北方向围成边长 2～18 格的正方形。标记杆放置后不会单独绑定；所有者使用 Create 扳手右键任意一根标记杆，探测成功后四根杆才形成一个逻辑区域，随后使用贸易点终端连接器将区域整体绑定到核心。

区域宽、深等于正方形边长，高度始终为边长的一半并向上取整。例如边长 5 格会建立 5×5×3 的检测范围，边长 18 格会建立 18×18×9 的检测范围。区域不是四个独立必须组件：装载区域和卸载区域各自只占核心终端的一个必须组件槽位。任意一根标记杆被破坏都会注销整个区域并暂停贸易点。

标记杆没有实体碰撞，玩家和实体可以像穿过火把一样通过，但仍保留选择轮廓以便交互。单根或尚未形成有效区域的标记杆不显示范围框。区域形成后，四个斜向伸缩部件沿各自正面平滑伸出，旋转组开始绕轴缓慢旋转；区域失效时先回到默认角度并停止，再将伸缩部件收回。装载和卸载标记杆共用动画结构，但使用不同贴图。

有效区域的范围提示只在玩家距离区域 8 格以内显示：完整线框保留，侧面改为从底部完全不透明、到区域半高完全透明的渐变色，不再铺设四周贴图；底面中央显示完全不透明的装载或卸载标识。标识相对底面上移 1.5 像素以避免与地面或地毯闪烁，尺寸取区域短边的 75%，最大不超过 10 格。

每个检测区域同时只识别距区域中心最近的一个货柜，距离相同时选择货柜 ID 较小者。终端不提供货柜切换功能；需要操作其他货柜时，应先将当前货柜移出区域或让目标货柜成为最近货柜。交易提交时服务端会按相同规则重新识别，防止显示对象与实际交易对象不一致。

候选货物遵循统一规则：

- 卸载模式只显示当前货柜内已有的货物；没有货柜时，仅货柜名称栏显示“无货箱”，其余货物信息留空。
- 装载模式在没有货柜时显示贸易点中有可用库存的货物；有货柜时只显示该货柜可装载且贸易点有可用库存的货物。
- 左右箭头切换候选货物，页码使用独立仪表显示。
- 数量滑轨按下后打开临时数值设置界面；确认后滑块移动到对应比例，不再直接拖动滑轨。

公共装载和卸载分别执行真实 VB 交易，所有者与管理员同样正常付款。旧完整度显示已由真实物品数量/装载率替代。

## 3. 仓库管理终端

恢复为可选管理组件，不参与必须终端判定；管理装卸不收费、不依赖商品报价或公众营业。按模式直接使用核心的对应装卸区域，只识别一个货柜，不允许切换货柜。表面保留模型基座，显示实际物品、数量、装载率、库存/容量和页码，移除旧完整度、行情和报价限制的管理含义。详细操作见[仓库管理终端](05_仓库管理终端.md)。

## 4. 商品管理 GUI

仓库终端 SET 使用单张图集绘制五列两行物品网格，底部页签切换出售／收购。两页都只列出保险库中数量大于 0 的精确物品变体，不再构造全部物品目录；上架前需先存入一个样本，名称／耐久／附魔等不同组件不能互相代替。

- 搜索支持名称、物品 ID 和本地化／原始运输分类；名称、数量、当前模式单价三种排序，再次点击可切换升降序。
- 滚轮或右侧滚动条按行浏览。物品格显示原生物品图标、数量和当前模式单价；绿／红箭头区分出售／收购，未上架显示 `--`，悬停查看完整名称、数量、分类和未缩写价格。
- 必须手动点击一个物品才可编辑价格或上／下架，初始不选中任何物品；选中格有高亮边框。
- 输入单价后点击“+”保存并上架该物品；点击删除按钮只清除该物品在当前模式的单价并下架，另一模式和其他物品不变，不删除实物。
- 切换商品、模式、排序、筛选、滚动或关闭界面不自动提交。没有整页删除操作；不再提供保留数量或收购目标。
- 服务端复核所有权、有效菜单、绑定、8 格距离和真实库存样本；只向打开菜单的所有者定向同步变化行。保险库不可用时明确提示并禁用操作。

## 5. 玩家贸易点信息柜

信息柜是必须组件，使用单一终端展示贸易点的出售与收购目录。绿色大按钮切换两种目录，界面只读，不负责修改库存配置。商品单价、库存或额度等内容通过统一仪表组件绘制。

## 6. 航标塔与地图发现

航标塔是可选组件，不影响贸易点完整性。当前只有一种航标塔，沿用 `player_trade_beacon` 注册 ID、模型及按钮，显示名改为“航标塔”；旧普通航标 `navigation_mark` 的方块与物品 ID 已直接移除，不做旧存档方块/物品兼容。

未绑定时可独立使用：SET 按钮编辑普通地图标记名称，钮子开关控制广播；此时不属于任何玩家，任何玩家都可以设置或挖掘。绑定玩家贸易点后广播对应贸易点的名称和商品目录，设置/广播操作限所有者和授权管理员，连接器的绑定/解绑仍只限所有者。解除绑定后保留名称和广播状态，回到普通标记模式。

### 命名与指南针校准 GUI

SET 按钮打开新命名界面。顶部输入广播名称，右侧勾选按钮（或回车）显式保存名称并关闭；直接关闭不会提交名称草稿。下方展示玩家背包，可普通点击、快捷栏交换或 Shift 点击移动物品。

- 左侧是每位查看者独立的临时槽，只接收一枚原版指南针，也可重新校准已有的磁石指南针；回溯指针不接受。
- 放入指南针后，点击校准图标，把这一枚指南针绑定到当前航标塔核心的位置。不消耗指南针，保留自定义名称等其他组件。
- 指南针使用原版磁石目标数据、名称、光效和指针逻辑；同维度指向航标塔坐标，跨维度沿用原版磁石指南针表现。航标不是原版磁石，因此关闭磁石 POI 存活校验，避免原版 Tick 清除绑定；没有新增指南针扫描或跟踪系统。
- 目标是固定维度坐标，关闭广播、改名或拆除航标不清除该坐标；不追踪 Sable 移动物体。
- 航标自身不存储物品。无论是否绑定成功，关闭 GUI 都返还临时槽和光标物品；背包已满、死亡或断线沿用原版掉落机制，避免吞物品。
- 未绑定航标任何玩家可设置；已绑定航标仅所有者和授权管理员可设置及校准。界面打开后拆塔、解绑/换绑、撤销权限、走出 8 格或进入 Sable 结构均使菜单失效并执行物品返还。

### 广播与地图

- 广播开启：航标旋转部件缓慢旋转，并向贸易地图发布点位。
- 广播关闭：旋转部件停在当前角度，立即撤下所有玩家地图上的该标记，所有者也不例外；未记录过该点位的新客户端不会获得资料。
- 恢复广播：使用同一标记 ID 重新显示，名称、位置和绑定后的商品摘要可以更新。
- 航标被破坏：删除服务端的活动广播记录，并向客户端撤下标记。

撤下标记仅改变地图显示，不抹除客户端已经学到的资料。已经选定的导航目标、潜在航线的收购目录匹配及信息卡查询继续使用历史坐标和商品摘要，不因关闭广播或撤下标记而取消。客户端缓存保存隐藏状态；登录和维度快照也会协调当前可见性，不会让已经关闭或破坏的航标因重新载入缓存而重新显示。贸易是否实际可用仍以交易时的服务端校验为准。

地图标记复用自然贸易点的商品展示样式。只要某种货物启用了出售或收购配置，就会出现在标记中；即使当前可售数量为零、保险库可插入空间不足或结算器余额暂时不足，也不隐藏配置项。原贸易点等级图标位置显示贸易点所有者头像，皮肤暂不可用时回退为默认 Steve/Alex 头像。

贸易地图当前从航运手册打开。点击玩家贸易点标记，固定信息卡显示名称、“玩家经营贸易点”和收购/出售目录；可使用指南针设置个人目的地，也可居中或关闭卡片。关闭卡片不取消目的地。手册中的推荐航线仅统计玩家名下物理货柜货物，不把贸易点仓库算作随身运输货量；详细交互见[航运手册与玩家档案](../12航运手册与玩家档案/README.md)。
