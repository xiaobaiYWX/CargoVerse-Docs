# 仓库管理终端

注册 ID：`cargoverse:player_trade_inventory_terminal`。可选管理组件，每核心最多绑定一台；不加入营业必需槽位，也不替代仓库收发器。

## 使用与职责

1. 放置终端，由所有者使用终端连接工具绑定自己的核心。
2. 保险库仍通过收发器绑定。管理终端只保存绑定、模式、选中物品序号和本次数量，不保存实物或报价副本。
3. 钮子开关切换装载/卸载，分别点击对应 LOAD / UNLOAD；另一模式的按钮不会执行。
4. 数量滑轨沿用按住打开临时数值 UI 的交互，首版每次 1～100 个，可分次操作。
5. 黄色 SET 是商品管理 GUI 的唯一入口；核心不再提供该按钮或菜单。单价和两个独立上架开关仍保存在核心，保留数量与收购目标已移除。

## 管理装卸

管理装卸对所有者和授权管理员开放，不收费、不要求营业或安装结算器、不检查出售/收购报价和上架开关；不产生许可证/繁荣度经验，也不计为公共交易营业额。公共装卸台不因此免费。

终端直接使用核心已绑定的对应装卸区域，不依赖公共装卸终端。复用单货柜检测规则，不按玩家身份跳过更近的货柜或提供切换；可操作核心所有者或执行管理玩家本人拥有的货柜，其他玩家的货柜拒绝转移。

- 装载无货柜：浏览保险库中实际有数量的物品。
- 装载有货柜：只列出该货柜兼容且不与现有载荷混装的库存。
- 卸载：只显示当前货柜内的物品；无货柜时仅名称栏显示“无货箱”，其余货物栏留空。
- 始终校验精确组件、库存、容量、运输快照与保险库真实可插入空间；库存或空间不足不扣货。

转移遵循现有运输规则：入库结束运输，再出库建立当前运输快照；部分卸货保留时钟，追加先结算到期损耗再刷新。失败回滚本次触及槽位及货柜，不覆盖整仓状态。

## 界面与权限

表面基座保留，显示货柜名称、原生物品图标/名称、独立页码、货柜数量/容量、装载率、仓库该变体数量/可达容量、本次数量与操作状态；不恢复独立完整度、市场行情或虚拟仓容。

SET 只允许所有者；授权管理员虽能管理装卸，仍不能编辑报价、操作核心或绑定/解绑。商品菜单按仓库终端 8 格距离校验，并固定打开时的绑定核心，解绑、换绑、核心/终端拆除或远离后失效。没有保险库时可打开菜单查看不可用状态，但没有可选库存，不能上架或装卸。

商品 GUI 已改为五列两行网格，两页都只显示当前有库存的物品。先点击物品，再输入价格并按“+”上架；删除仅清除选中物品当前模式的价格并下架，不改另一个模式、其他物品或仓库实物。切换／筛选／关闭不自动保存。搜索、排序和滚动规则见[商品管理 GUI](03_终端、表面UI与地图.md#4-商品管理-gui)。

## 生命周期与限制

终端遵循通用多方块控制器生命周期：正常移除任一成员清理整台并解绑；特殊工具跳过回调仅破坏占位方块时，以控制器是否存在判定存续。拆除终端不删除核心报价或保险库物品，不恢复永久清仓或非空禁止拆除。

整台质量 1000 Kpg，仅控制器计重。可放在 Sable 上，但不能绑定或使用；不销毁物品，不做设施坐标转换。配置和实时仪表只在变化时同步，实时表面快照不携带整仓明细或完整物品组件。

## 本轮验证

商品 GUI 重制后：715 项单元测试与 77 项必需 GameTest 通过，覆盖搜索／排序／网格命中、图集裁切、单物品单模式修改包、无库存和错误组件样本拒绝上架、下架不影响其他报价／实物、零库存收购补货，以及原有管理装卸／权限／Sable／生命周期用例。已做静态图集布局检查，仍需游戏内视觉复核。

当前网络协议为 64，客户端与服务端需同版。验证期间既有 Sable 货轨用例出现间歇性失败，复跑全量通过；本轮未调整轨道逻辑。未提交。
