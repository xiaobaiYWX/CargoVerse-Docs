# 仓库管理终端

注册 ID：`cargoverse:player_trade_inventory_terminal`。可选管理组件，同一核心可接入多台；各台保存自己的检测区域及操作选择，共享核心库存、报价与权限，不替代仓库收发器。

## 使用与职责

1. 放置终端，通过物流隧道接入自己的管理核心并激活网络；不再逐台远程绑定，见[物流网络](06_物流隧道与激活网络.md)。
2. 保险库和储罐通过收发器绑定，分别最多 3／5 个原生多方块结构。管理终端只保存绑定、当前仓库类型、装卸模式、选中条目序号和本次数量，不保存实物或报价副本。
3. 钮子开关切换装载/卸载，分别点击对应 LOAD / UNLOAD；另一模式的按钮不会执行。
4. 数量滑轨沿用按住打开临时数值 UI 的交互，每次 1～100 份，可分次操作；物品每份 1pcs，液体每份 1000mB，表面显示换算后的原生量。
5. 黄色 SET 是商品管理 GUI 的唯一入口；核心不再提供该按钮或菜单。单价和两个独立上架开关仍保存在核心，保留数量与收购目标已移除。

## 管理装卸

管理装卸对所有者和授权管理员开放，不收费、不要求公共装卸台或安装结算器、不检查出售/收购报价和上架开关；仍要求管理终端与仓库收发器处于激活网络的有效路径上，并且本台检测区域完整。不产生许可证/繁荣度经验，也不计为公共交易营业额。公共装卸台不因此免费。

仓库终端自带的长杆为主管理标记点，逻辑角点位于长杆正下方的底层方块；再放三根绿色“玩家仓库管理区域标记杆”（`cargoverse:player_management_area_marker`），围成同高度、边长 2～18 格的正方形，使用 Create 扳手右键终端任一成员或外围杆成区。几何、重叠检查及动画复用公共终端规则，但不借用公共装卸机的区域。装载与卸载共用本台绿色区域。

区域及外围杆只是终端的本地激活零件，无独立物流入口，不占贸易网络端点，也不由核心统计区域就绪状态。没有完整区域时，本台表面提示“标记区域未完成”并禁止装卸；SET 商品编辑不受影响。复用单货柜检测规则，不按玩家身份跳过更近的货柜或提供切换；可操作核心所有者或执行管理玩家本人拥有的货柜，其他玩家的货柜拒绝转移。

多台终端不互相选择检测区域，也不共享当前介质、模式或货物序号。交易提交串行重新校验原生库存，库存不足时拒绝而不超扣；货柜有待确认交易时，免费管理装卸也不能绕过占用，需先完成或取消确认。

- 装载无货柜：浏览保险库中实际有数量的物品。
- 装载有货柜：只列出该货柜兼容且不与现有载荷混装的库存。
- 卸载：只显示当前货柜内的物品；无货柜时仅名称栏显示“无货箱”，其余货物栏留空。
- 始终校验精确组件、库存、容量、运输快照与保险库真实可插入空间；库存或空间不足不扣货。

转移遵循现有运输规则：入库结束运输，再出库建立当前运输快照；部分卸货保留时钟，追加先结算到期损耗再刷新。失败回滚本次触及槽位及货柜，不覆盖整仓状态。

## 界面与权限

表面基座保留，显示货柜名称、原生物品图标/名称、独立页码、货柜数量/容量、装载率、仓库该变体数量/可达容量、本次数量与操作状态；不恢复独立完整度、市场行情或虚拟仓容。

SET 只允许所有者；授权管理员虽能管理装卸，仍不能编辑报价、操作核心或绑定/解绑。商品菜单按仓库终端 8 格距离校验，并固定打开时的绑定核心，解绑、换绑、核心/终端拆除或远离后失效。对应类型没有有效仓库时可打开菜单查看不可用状态，但没有可选库存，不能上架或装卸；液体不要求同时连接物品保险库。

商品 GUI 已改为五列两行网格，两页都只显示当前有库存的物品。先点击物品，再输入价格并按“+”上架；删除仅清除选中物品当前模式的价格并下架，不改另一个模式、其他物品或仓库实物。切换／筛选／关闭不自动保存。搜索、排序和滚动规则见[商品管理 GUI](03_终端、表面UI与地图.md#4-商品管理-gui)。

## 仓库类型切换

商品 GUI 右下角按固体物品、液体、生物、气体顺序提供四个图标。服务端分别核验原生保险库和普通储罐；至少一个有效结构时对应图标叠加绿色勾，未连接或不可用时红叉。生物和气体库存尚未接入，不产生虚拟库存。

点击图标后由服务端确认并切换页面；切换清空当前商品选择和价格草稿、重置滚动，不自动保存报价。当前类型属于这台仓库终端的设置，退出或重开 GUI、保存重启后继续保留。其他玩家观察到的终端表面与交互使用相同类型，不是只修改当前客户端页面。

液体页汇总已连接储罐的真实流体，按流体 ID 和完整组件区分，使用原生图标、mB 数量与该变体可达容量。容量包含该变体已有储罐及空储罐，不重复加算其他流体占用的储罐；不同条目的可达容量不能相加当作全仓容量。支持搜索、排序、单选流体后编辑每 1000mB 的出售／收购单价，并提供免费管理装卸；不将流体伪装成物品。关闭 GUI 后表面继续使用液体名称、平面图标、mB 数量／容量与液体交互，不修改固体报价。损耗后最后不足 1000mB 的液体可免费完整回收，目标储罐需能容纳全部尾量。

未连接类型库存为空并显示“仓库未连接”，表面货物仪表清空。切回固体恢复正常库存与管理装卸。生物／气体不沿用流体储罐或固体库存。所有动作由服务端复核，伪造请求不能跨类型操作。

类型选择沿用 SET 的所有者权限，授权管理员不能通过此菜单改类型，但管理装卸依然按终端已保存类型执行。连接状态和所选类型的有界页面摘要每 10 Tick 检查且仅变化时发送；表面仅同步选中条目，不发送整仓或完整组件。排序、保存和删除等固定按钮已绘制在新版背景中，代码只处理命中、禁用和高亮，不重复叠加旧图块。

## 生命周期与限制

终端整体为底层、上层及第三层单格长杆成员，模型保留导出时下移一格的顶点，世界渲染补回一格；表面仪表和按钮保持世界位置。终端遵循通用多方块控制器生命周期：正常移除任一成员清理整台并解绑、解散本台区域；破坏外围杆只解散区域，其余杆解除成员关系。特殊工具跳过回调时由区域索引与已加载成员核验清理，不因区块卸载直接解散。拆除终端不删除其他终端、核心报价或保险库物品，不恢复永久清仓或非空禁止拆除。

整台质量 1000 Kpg，仅控制器计重。可放在 Sable 上，但不能绑定或使用；不销毁物品，不做设施坐标转换。配置和实时仪表只在变化时同步，实时表面快照不携带整仓明细或完整物品组件。

## 验证边界

商品管理需要验证搜索／排序／网格命中、单物品单模式报价修改、组件身份、库存校验，以及权限、Sable 限制与多方块生命周期。客户端布局仍需实机视觉复核；测试选择遵循[变更验证策略](<../06开发与运维/06_变更验证策略.md>)，不在正式功能文档保存阶段测试计数或提交状态。

客户端与服务端需同版；当前协议号以[运输数值运行时](../01货柜系统/01核心系统/14_运输数值运行时.md#保存采样与性能)为准。
