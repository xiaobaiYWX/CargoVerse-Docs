# 贸易点仓库收发器

注册 ID：`cargoverse:player_trade_vault_receiver`。一个贸易点最多绑定一个收发器。保险库本身不响应终端连接工具。

## 使用

1. 在 Create 物品保险库的一个外表面放置收发器，支持六面附着；不能附着其他方块。
2. 用终端连接工具选择自己的核心终端，再右键收发器完成绑定。32 格半径以收发器位置计算，同维度，所有者专属。
3. 绑定后使用亮起贴图；解绑后使用未激活贴图。亮起只说明已绑定，不保证当前区块加载或仓库没有冲突。
4. 潜行右键收发器解绑，潜行右键核心清除全部绑定。授权管理员不能绑定/解绑。
5. 使用绑定的仓库管理终端 SET 编辑单价并对选中物品分别上架／下架，仅所有者可用；核心仍保存报价，但不提供入口。仓库终端提供免费管理装卸，自动化仍直接连接保险库。

收发器替代原仓库终端的必须组件和指示灯槽位，核心仍显示六项必须终端；保险库不可用时不能实际交易或首次开业。新增方块质量为 1000 Kpg，不接收或复制物品。

## 拆分与合并

只保存收发器和其背后附着方块的位置，不把 Create 控制方块地址当作永恒仓库 ID。

- 每次使用从附着方块解析当前完整保险库。
- 拆分后只跟随收发器所在的那一组，另一组物品不再属于当前贸易库存。
- 不同贸易点已绑定的两个保险库合并时，双方暂停交易，显式解除竞争收发器的绑定后再恢复，避免共享库存被重复销售。
- 附着方块被移除后，收发器按附着方块规则掉落并解除绑定；保险库其他组成方块的拆除交给 Create。
- 仅拆除远处的部分保险库，不会将收发器转接到最近的其他保险库。

## 不加载与 Sable

绑定和使用都要求保险库完整结构已加载，不创建区块票据。未加载时保留绑定，恢复加载后重新解析。收发器或目标保险库在 Sable 上时不可绑定/使用，不做移动坐标投影。收发器可正常随结构组装，库存仍属于 Create，不清空物品。

## 实现边界

`PlayerTradeVaultSavedData` 只保存独占收发器地址索引，`PlayerTradeVaultInventory` 保存报价和短周期显示观察，`VaultItemTransfer` 在服务端事务中提交实际槽位变化。没有额外的库存保存、复制或旧仓库迁移层。
