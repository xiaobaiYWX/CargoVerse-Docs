# 玩家贸易点：保险库存储、报价与结算

## 唯一物品存储

实际物品只保存在 Create 保险库。玩家贸易点不再保存独立库存账本、虚拟容量或兜底物品，也不把保险库内容复制进核心存档。旧开发版 `ItemWarehouse` 不迁移；更新前需要自行取出旧库存或使用测试存档。

核心终端保存精确物品变体的报价配置，所有者通过仓库管理终端的黄色 SET 按钮打开商品管理 GUI，核心不再提供入口，收发器是保险库唯一绑定点，详见[贸易点仓库收发器](04_贸易点仓库收发器.md)。

保险库容量由 Create 的实际槽位、结构规模、服务器配置和物品堆叠上限决定，取消原全仓 5000 个限制。1 个实际物品仍为 1 库存单位；不可堆叠物品和普通材料实际占用槽位不同。

每个核心最多连接 3 个保险库多方块结构，按精确组件汇总库存和真实插入空间，装卸可跨保险库操作；失败回滚仅涉及本次触及的原生槽位。每个核心另有独立的 5 个普通流体储罐名额，流体只保存在 Create 储罐中；已接入库存、容量（mB）、液体报价、货柜公共交易和免费管理装卸；常规按 1000mB 整份转移，尾量保留。详见[液体运输](../01货柜系统/01核心系统/13_液体运输.md)。连接、重复绑定与拆分／合并规则见[仓库收发器](04_贸易点仓库收发器.md)。

## 报价与额度

```text
可售数量 = 出售启用 ? 该精确变体的实际数量 : 0
可收购数量 = 收购启用 ? 保险库实际可插入该精确变体的数量 : 0
```

仅配置非负整数单价和两个独立上架开关，价格可明确设为 0；不再设置、保存或同步保留数量及收购目标。出售不预留库存，收购由真实保险库空间、原生堆叠规则与资金限制；不限制外部自动化主动存取。

未配置商品价格默认为 0，出售与收购均关闭；没有从运输配置推导的隐含基础价格。玩家信息柜只显示实际数量、容量与该模式的配置单价，不显示无基准的涨跌；原模型仪表基座保留。自然贸易点信息柜的站点报价涨跌不受此调整影响。

按物品及完整组件精确匹配，不合并名称、耐久、附魔等不同变体。非空嵌套容器等不允许成为货物的物品仍可由 Create 保存，但不参与贸易点货柜装卸。

已配置的收购报价不因库存暂时归零而自动下架，仍可收货补库，但零库存项暂不显示在编辑网格中；保险库暂时不可用时 GUI 明确显示不可用，禁止交易，而不是创建一份空仓库。表面列表中的“容量”是当前变体在该槽位布局下的可达数量，不是所有商品都能同时达到的独立配额。

## 商品配置权限

仓库终端 SET 商品管理仅允许所有者，授权管理员不能打开或修改。菜单/修改包复核仓库终端实体、有效绑定核心、静态状态、所有权与距仓库终端 8 格交互距离，核心消失、终端解绑/换绑或玩家离开后不能继续编辑。保险库未绑定时可以打开菜单查看不可用状态，但没有可选物品，不能预先上架。出售和收购页都仅展示库存大于 0 的精确变体；首次上架必须先存入一个匹配组件的样本。

## 装卸与结算

公共装载：从保险库取出实际物品，装入货柜，由买方支付 VB 给核心结算器。
公共卸载：从货柜移除实际物品并插入保险库，由核心结算器支付卖方。
无论是否所有者或授权管理员，公共终端均正常结算。仓库管理终端另外提供免费管理装卸，不调用公共交易或奖励入口，不要求公共装卸机、报价或结算器；仍要求终端和仓库收发器具有到激活核心的有效物流隧道路径，并且该仓库终端自带的绿色标记区域完整。区域及标记杆不是独立网络部件。实物通过原生仓库接口转移，详见[仓库管理终端](05_仓库管理终端.md)和[物流网络](06_物流隧道与激活网络.md)。

货物出入保险库时遵循既有真实物品运输规则：入库结束运输，出库按当前规则建立新运输快照；部分卸货不刷新柜内剩余货物的时钟。40 张正式自然站货物表仍为空，A／B 指令测试表已填充，不自动恢复抽象货物。

运输经验只看收购目的地：玩家→自然和自然→自然成功成交时，按自然目的地收购报价奖励许可证与繁荣度经验；玩家→玩家和自然→玩家不奖励。玩家保险库中转不影响之后在自然目的地成交的奖励资格，货柜不再记录来源。免费仓库管理转移本身不奖励，未配置每组／每桶经验默认 0，尾量按比例每笔向下取整，详见[运输经验规则](../02贸易点系统/03_资源表定义.md)。

## 服务端一致性与自动化

列表使用短周期观察缓存，实际交易先失效缓存并重新校验实际库存、收发器/核心、区域、货柜和资金。可插入数量逐槽模拟，正式提交使用短生命周期槽位变更日志；失败仅回退本次触及槽位，不使用整份旧库存覆盖 Create 当前状态。库存缓存不是账本，不写存档。

自动化直接连接保险库，沿用 Create/NeoForge 物品接口。原物品打包机、输出选择、输入/输出锁定、注册、网络包和素材均删除，不再提供一个重复的物品出入口。

管理权限只保护本模组终端，不为原版/Create 的外部物品传输或破坏提供领地保护。

## 保存、拆除与加载

核心分别保存物品 `TradeOffers` 与液体 `FluidOffers` 报价，不保存物品或流体，也不在普通方块实体更新中广播完整报价组件和商品行。商品 GUI 只向已打开菜单的所有者定向同步有界显示行与保险库可用状态，10 Tick 检查且变化才发；公共信息柜仍发送独立的只读显示行。

拆除核心不删除保险库物品，但失去核心报价配置；解绑收发器或拆除仓库管理终端保留核心报价。取消“按住永久清空仓库”按钮及服务端包，也取消非空管理终端不可拆除的旧限制。保险库自身的存储、拆除和掉落完全交给 Create。

不为读取库存强制加载区块。保险库完整结构未加载、结构重组中、任一设施在 Sable 上或存在重复归属时，暂不可交易。静态贸易点仍可装卸 Sable 运输货柜。
