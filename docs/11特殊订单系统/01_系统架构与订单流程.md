# 系统架构与订单流程

## 身份与运行对象

| 对象 | 标识 | 说明 |
| --- | --- | --- |
| 特殊订单定义 | 资源 ID | 数据包中的订单模板，不指向某一座实际贸易点 |
| 贸易点定义 | 资源 ID | 某类贸易点，例如研究站或测试贸易点 B |
| 贸易点实例 | UUID | 世界中实际存在的贸易点，具有固定维度、坐标和功能端点 |
| 每日订单 | 稳定报价 ID | 某个发布实例在某个游戏日生成的共享报价 |
| 已领取委托 | 委托 ID | 玩家领取后的锁定运行数据 |
| SP 货柜 | 货柜实例 ID | 与委托一一对应的特殊货柜 |

订单定义只填写允许的贸易点定义 ID。系统生成每日订单时查询持久化贸易点注册表，从满足条件的实际贸易点实例中选择目的地，并把实例 UUID、检查点和距离锁定到报价中。

## 生成前提

发布端必须满足：

- 贸易点定义包含 `modules.special_orders`；
- 贸易点实例已经登记；
- 存在可用的订单接取终端和源检查点。

候选目的地必须满足：

- 与发布端处于同一维度；
- 贸易点定义 ID 在订单允许列表中；
- X/Z 水平直线距离位于订单范围内；
- 已登记订单交付终端和特殊订单检查点；
- 不是已经失效或永久移除的贸易点实例。

没有有效目的地时，该订单定义不会进入当日列表。特殊订单系统不会自动生成贸易点。

## 1. 每日订单生成

订单接取终端读取所属贸易点定义中的 `modules.special_orders`：

1. 按当前繁荣度过滤不满足 `min_prosperity_level` 的候选项。
2. 按 `weight` 加权抽取；同一订单定义在同一张列表中最多出现一次。
3. 为每个候选订单寻找有效的实际目的地。
4. 使用源贸易点实例和游戏日生成稳定结果。

同一贸易点、同一游戏日的玩家看到同一张订单板。`offer_slots` 允许 `1..5`；候选不足、目的地不足或报价已经被领取时，实际显示数量可以更少。

## 2. 领取订单

玩家确认领取时，服务端重新验证：

- 贸易点、订单定义和当日报价仍然有效；
- 玩家已经注册运输许可证；
- 玩家进行中的特殊订单少于 3 个；
- 当日报价尚未被领取或消费；
- 源检查点仍然有效；
- 检查点范围能够生成完整货柜。

验证通过后，系统在源检查点生成 SP 货柜并创建已领取委托。以下内容在领取时锁定：

- 源贸易点、实际目的贸易点和目的检查点；
- 实际距离、接取时间和截止时间；
- 难度、任务限制及其参数；
- VB、经验、声望和物品奖励；
- SP 货柜身份及订单显示数据。

后续数据包重载不会改写已领取委托的锁定内容。

## 3. SP 货柜与运输

| 内容 | 定义来源 |
| --- | --- |
| 结构模板 | `shipment.template` |
| 货柜显示名称 | `shipment.container_display_name` |
| 货物显示名称 | `shipment.cargo_display_name` |
| 贴花大类 | `shipment.cargo_class` |
| 总质量 | `shipment.total_mass` |
| 初始完整度 | `shipment.initial_integrity` |

SP 货柜不保存普通货物内容，也不能二次装卸。它只保存自身身份、当前完整度，以及温度、速度采样等限制运行状态。

`cargo_class` 只负责分类显示和贴花。特殊订单不会通过它反查 CargoGood；最多前 5 项环境／物理限制可以解析结构模板中的警示贴花占位符。

## 4. 到站交付

订单交付终端只显示目的地属于本站，且目标检查点与终端绑定相符的委托。玩家确认交付时，服务端依次检查：

1. 委托属于当前玩家。
2. 当前维度和贸易点实例正确。
3. 对应 SP 货柜仍存在且状态有效。
4. 货柜物理包围盒进入锁定的目的检查点范围。
5. 限时订单尚未超过截止时间。
6. 当前完整度满足全部交付限制。
7. 玩家携带的虚空结算器能够接收全部 VB。

全部通过后，系统删除 SP 货柜并一次性发放锁定奖励。物品优先进入背包，无法容纳的余量掉落在玩家附近。任一检查失败都不会部分结算。

## 5. 失效与清理

目的贸易点被永久移除、交付设施失效或订单定义被删除时，相关委托会进入清理流程，对应 SP 货柜也会被回收，不对玩家施加额外违约惩罚。

区块暂时卸载不等于贸易点失效。只要注册表记录和端点登记仍然有效，订单可以继续指向未加载区域，系统也不会因此强制加载区块。

## 固定限制

| 项目 | 当前限制 |
| --- | ---: |
| 单贸易点每日订单槽位 | `1..5` |
| 单玩家进行中委托 | 最多 3 个 |
| 单订单任务限制 | 最多 16 项，类型不可重复 |
| 单订单物品奖励条目 | 最多 16 项 |
