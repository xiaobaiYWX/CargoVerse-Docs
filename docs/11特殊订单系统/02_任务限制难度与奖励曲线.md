# 任务限制、难度与奖励曲线

## 系统定位

特殊订单任务限制是一套独立的合同规则系统：

- 定义直接写在特殊订单的 `constraints` 中。
- 接取时完整复制并锁定到玩家委托。
- 运行状态保存在对应 SP 货柜中。
- 不读取 CargoGood，不继承其他货物词条，也不进行双向转换。
- 每项限制可以独立提供订单难度加成。

部分环境与物理检测器在代码底层复用已有实现，但这只是实现细节，不改变特殊订单限制的配置入口、校验规则、运行对象和存档归属。本章是特殊订单限制的完整说明，不依赖其他词条文档。

## 通用结构

```json
{
  "type": "cargoverse:fragile",
  "difficulty_bonus": 2,
  "parameters": {
    "speed_delta_threshold": 3.0,
    "damage_amount": 5.0
  }
}
```

| 字段 | 约束 | 作用 |
| --- | --- | --- |
| `type` | 已注册的特殊订单限制 ID | 选择限制类型 |
| `difficulty_bonus` | `0..1000000` | 该限制对最终难度的固定加成 |
| `parameters` | 对象，可省略 | 当前限制自己的参数 |

每份订单最多包含 16 项限制，同一 `type` 不能重复。未知类型、重复类型或非有限数值都会使订单定义加载失败。

## 运行与失效规则

- 物理类限制每 20 tick 检测一次，环境类限制每 100 tick 检测一次。
- 持续损伤会根据实际经过 tick 折算为每秒数值，不因分桶调度降低或放大总伤害。
- 当前完整度降至零时，SP 货柜进入失效状态，停止后续限制检测，也无法交付。
- 限制产生的温度、燃烧状态和速度采样等运行数据只属于当前 SP 货柜。
- `cargoverse:radioactive` 只影响附近玩家，不损伤完整度，也不会直接使货柜失效。
- 最多前 5 项具有警示贴花的环境／物理限制可解析 SP 货柜模板中的警示贴花占位符。

## 合同类限制

### 运输时限 `cargoverse:time_limit`

```json
{
  "type": "cargoverse:time_limit",
  "difficulty_bonus": 1,
  "parameters": {
    "base_ticks": 18000,
    "ticks_per_1000_blocks": 6000
  }
}
```

| 参数 | 范围 | 作用 |
| --- | ---: | --- |
| `base_ticks` | `20..2147483647` | 装货、起飞、停靠等固定时间 |
| `ticks_per_1000_blocks` | `0..2147483647` | 每 1000 格增加的运输时间 |

```text
时限 tick = base_ticks
          + distance / 1000 × ticks_per_1000_blocks
```

结果按最近整数取整并限制为整数上限。没有此限制时订单不限时。超过截止时间会拒绝交付，但时限不会根据紧迫程度额外生成动态难度，只使用定义中的 `difficulty_bonus`。

### 最低完整度 `cargoverse:minimum_integrity`

```json
{
  "type": "cargoverse:minimum_integrity",
  "difficulty_bonus": 2,
  "parameters": {
    "minimum": 75
  }
}
```

| 参数 | 范围 | 作用 |
| --- | ---: | --- |
| `minimum` | `0..1000000` | 交付时允许的最低完整度 |

`minimum` 不能高于 `shipment.initial_integrity`，否则订单定义拒绝加载。当前完整度低于该值时拒绝交付；这项限制本身不会持续损伤货柜。

## 环境与物理限制

### 防潮 `cargoverse:moisture_proof`

```json
{
  "type": "cargoverse:moisture_proof",
  "difficulty_bonus": 2,
  "parameters": {
    "damage_per_second": 1.0
  }
}
```

| 参数 | 默认值 | 范围 |
| --- | ---: | ---: |
| `damage_per_second` | `1.0` | `>= 0` |

- SP 货柜入水时立即失效，原因是 `water_damage`。
- 淋雨时持续损失完整度，归零原因是 `rain_damage`。
- 淋雨检测货柜中心和包围盒 8 个角点；中心无遮蔽，或至少两个角点无遮蔽，即视为暴露。

### 防寒 `cargoverse:cold_proof`

```json
{
  "type": "cargoverse:cold_proof",
  "difficulty_bonus": 1,
  "parameters": {
    "damage_per_second": 1.0
  }
}
```

| 参数 | 默认值 | 范围 |
| --- | ---: | ---: |
| `damage_per_second` | `1.0` | `>= 0` |

SP 货柜处于低温且满足原版降雪条件的生态环境时持续损失完整度，归零原因是 `cold_damage`。

### 请勿倒置 `cargoverse:keep_upright`

```json
{
  "type": "cargoverse:keep_upright",
  "difficulty_bonus": 2,
  "parameters": {
    "damage_per_second": 1.0,
    "min_up_dot": 0.5
  }
}
```

| 参数 | 默认值 | 范围 | 作用 |
| --- | ---: | ---: | --- |
| `damage_per_second` | `1.0` | `>= 0` | 倾斜超限时每秒损失的完整度 |
| `min_up_dot` | `0.5` | `-1..1` | 货柜朝上方向与世界上方向的最低点积 |

实际点积低于阈值时持续损失完整度。阈值越高，允许的倾斜越小；归零原因是 `tipped_damage`。

### 易碎 `cargoverse:fragile`

```json
{
  "type": "cargoverse:fragile",
  "difficulty_bonus": 2,
  "parameters": {
    "speed_delta_threshold": 3.0,
    "damage_amount": 5.0
  }
}
```

| 参数 | 默认值 | 范围 | 作用 |
| --- | ---: | ---: | --- |
| `speed_delta_threshold` | `3.0` | `>= 0` | 触发损伤的速度变化阈值 |
| `damage_amount` | `5.0` | `>= 0` | 每次触发降低的完整度 |

系统保存上次速度采样。短时间速度变化超过阈值时受到一次损伤，归零原因是 `impact_damage`。

### 冷链 `cargoverse:cold_chain`

```json
{
  "type": "cargoverse:cold_chain",
  "difficulty_bonus": 2,
  "parameters": {
    "damage_per_second": 1.0
  }
}
```

| 参数 | 默认值 | 范围 |
| --- | ---: | ---: |
| `damage_per_second` | `1.0` | `>= 0` |

使用 SP 货柜物理中心判断生态环境。离开满足原版降雪条件的低温环境后持续损失完整度，归零原因是 `cold_chain_damage`。

### 高度限制 `cargoverse:height_limit`

```json
{
  "type": "cargoverse:height_limit",
  "difficulty_bonus": 1,
  "parameters": {
    "height_threshold": 256,
    "damage_per_second": 1.0
  }
}
```

| 参数 | 默认值 | 范围 | 作用 |
| --- | ---: | ---: | --- |
| `height_threshold` | `256` | 有限数值 | 允许的最高世界 Y 坐标 |
| `damage_per_second` | `1.0` | `>= 0` | 超高后每秒损失的完整度 |

SP 货柜物理中心严格高于阈值时触发，归零原因是 `height_limit_damage`。

### 避光 `cargoverse:light_sensitive`

```json
{
  "type": "cargoverse:light_sensitive",
  "difficulty_bonus": 1,
  "parameters": {
    "light_threshold": 7,
    "damage_per_second": 1.0
  }
}
```

| 参数 | 默认值 | 范围 | 作用 |
| --- | ---: | ---: | --- |
| `light_threshold` | `7` | `0..15` | 允许的最高综合本地亮度 |
| `damage_per_second` | `1.0` | `>= 0` | 亮度超限时每秒损失的完整度 |

使用 SP 货柜物理中心的原版综合亮度。亮度严格大于阈值时触发，归零原因是 `light_damage`。

### 放射性 `cargoverse:radioactive`

```json
{
  "type": "cargoverse:radioactive",
  "difficulty_bonus": 3,
  "parameters": {
    "radius": 6,
    "effect_ids": [
      "minecraft:weakness",
      "minecraft:wither"
    ],
    "effect_duration_ticks": 120,
    "effect_amplifier": 0
  }
}
```

| 参数 | 默认值 | 范围 | 作用 |
| --- | ---: | ---: | --- |
| `radius` | `2` | `2..16` | 玩家影响半径 |
| `effect_ids` | 空数组 | 最多 16 项 | 周期施加的药水效果 ID |
| `effect_duration_ticks` | `120` | `20..12000` | 单次效果持续时间 |
| `effect_amplifier` | `0` | `0..255` | 原版零起始效果等级 |

只遍历 SP 货柜所在维度内的附近玩家；旁观者不受影响。非法或未注册的效果 ID 不产生效果。放射性没有完整度失效原因。

### 易燃 `cargoverse:flammable`

```json
{
  "type": "cargoverse:flammable",
  "difficulty_bonus": 3,
  "parameters": {
    "ignition_temperature": 100.0,
    "sunlight_threshold": 12,
    "sunlight_heat_per_second": 1.0,
    "hot_biome_temperature_threshold": 1.5,
    "hot_biome_heat_per_second": 1.0,
    "cold_biome_temperature_threshold": 0.15,
    "cold_biome_cooling_per_second": 1.0,
    "shade_cooling_per_second": 0.5,
    "burning_damage_per_second": 2.0
  }
}
```

| 参数 | 默认值 | 范围 |
| --- | ---: | ---: |
| `ignition_temperature` | `100.0` | `0.001..1000000` |
| `sunlight_threshold` | `12` | `0..15` |
| `sunlight_heat_per_second` | `1.0` | `0..100000` |
| `hot_biome_temperature_threshold` | `1.5` | `-10..10` |
| `hot_biome_heat_per_second` | `1.0` | `0..100000` |
| `cold_biome_temperature_threshold` | `0.15` | `-10..10` |
| `cold_biome_cooling_per_second` | `1.0` | `0..100000` |
| `shade_cooling_per_second` | `0.5` | `0..100000` |
| `burning_damage_per_second` | `2.0` | `0..100000` |

温度规则：

- 强烈日照与炎热生态环境可以同时升温。
- 阴凉冷却与寒冷生态环境可以同时降温。
- 炎热与寒冷生态环境判定互斥。
- 日照和生态环境都使用 SP 货柜物理中心；日照还要求上方能直接看见天空。
- 隐藏温度限制在 `0..1000000`。
- 达到点燃温度后进入燃烧状态；阴凉或寒冷不会自动灭火。
- 接触水时温度立即归零，并解除燃烧状态。
- 水体检测覆盖物理中心及其上下、东南西北六个相邻位置。
- 燃烧期间持续损失完整度，归零原因是 `fire_damage`。

## 难度计算

订单生成时按实际目的地距离计算并锁定：

```text
距离难度 = difficulty.base
         + distance / 1000 × difficulty.distance_per_1000_blocks

最终难度 = 距离难度
         + 所有 constraints[].difficulty_bonus 之和
```

`distance` 使用源检查点与目的检查点的 X/Z 水平直线距离。当前版本不进行航路搜索，也不单独计算时间限制难度。

## 奖励与曲线

基础奖励支持：

| 字段 | 作用 |
| --- | --- |
| `void_bytes` | 基础 VB 奖励 |
| `license_experience` | 基础运输执照经验 |
| `manufacturer_reputation` | 基础委托方制造商声望 |
| `items` | 最多 16 种实体物品及基础数量 |

`rewards.reward_curve` 使用“难度—倍率”控制点。系统按难度排序，在相邻点之间线性插值；难度低于首点或高于末点时使用最近端点倍率。控制点难度不可重复。省略曲线等价于恒定倍率 `1`。

```text
数值奖励 = round(基础奖励 × 曲线倍率)
可缩放物品数量 = floor(基础数量 × 曲线倍率)
```

`items[].scale_with_difficulty` 为 `false` 时不应用倍率。单项物品结算数量限制为 `1..2304`。物品 ID 必须在运行环境中存在。

奖励在订单生成时计算、在领取时锁定。运输途中发生数据包重载、目的地距离变化或奖励曲线调整，都不会重新计算已领取委托。

## 平衡建议

- `difficulty.base` 表示装卸、停靠和订单本身的固定工作量。
- `distance_per_1000_blocks` 只表示距离增加的难度。
- `difficulty_bonus` 应反映具体限制的实际影响，不要简单按限制数量统一加分。
- 奖励曲线保持少量、单调、易读的控制点；先用平缓区间覆盖普通订单，再为高难度订单提高倍率。
- 不限时订单仍可通过距离、最低完整度和环境／物理限制形成难度。
