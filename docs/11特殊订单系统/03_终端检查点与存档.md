# 终端、检查点与存档

## 组件职责

| 组件 | 方块 ID | 主要职责 |
| --- | --- | --- |
| 订单接取终端 | `cargoverse:production_line_terminal` | 展示每日订单、领取委托、在源检查点生成 SP 货柜 |
| 订单交付终端 | `cargoverse:special_order_delivery_terminal` | 展示本站待交付委托并发起服务端结算 |
| 特殊订单检查点 | `cargoverse:special_order_checkpoint` | 提供 SP 货柜生成位置或交付检测范围 |

订单接取终端复用原生产线终端方块和多方块模型，但原生产线业务已经移除。

## 订单接取终端

- 左侧 5 个槽位显示当日订单名称。
- 主屏使用整块 MicroficheReader 显示货柜、目的地、距离、时限、限制和奖励。
- 翻页按钮切换当前订单，确认按钮领取订单。
- 管理员模式右键打开配置界面，绑定贸易点实例 UUID 和特殊订单检查点。
- 每日订单板属于贸易点实例，同一天内所有玩家共享。

接取成功时，系统以源检查点为货柜中心底面定位点。检查点范围必须能够容纳订单结构模板的实际尺寸，否则拒绝领取且不生成委托。

## 订单交付终端

- 北面上部为整块 MicroficheReader，显示本站等待交付的订单。
- 左右箭头切换委托，绿色 `OK` 按钮确认交付。
- 管理员模式右键打开配置界面，绑定贸易点实例 UUID 和特殊订单检查点。
- 终端正确登记后，所属贸易点才具备特殊订单交付能力。

终端只负责浏览和发起操作。实际归属、位置、状态、截止时间、完整度和结算器容量均由服务端在确认时重新检查。

## 特殊订单检查点

同一种检查点承担两种用途：

| 使用位置 | 作用 |
| --- | --- |
| 发布端 | 确定 SP 货柜生成中心底面坐标 |
| 目的端 | 提供 SP 货柜提交检测范围 |

检查点使用与装卸点相同的管理员范围配置 UI。玩家进入 16 格激活距离后显示绿色范围框，远离后自动隐藏。交付判定使用货柜物理包围盒与检查范围相交结果，不以终端坐标或单个方块位置代替。

## 绑定与端点登记

接取终端和交付终端只保存贸易点实例 UUID 与检查点绑定，不保存独立的贸易点定义副本。

解析检查点时优先使用终端显式绑定；未配置显式绑定时，按贸易点实例查询已经登记的特殊订单检查点。端点记录在区块卸载后仍然保留，因此订单生成与目的地筛选不需要加载远方区块。

只有贸易点永久移除或端点确认失效时才应注销记录。普通区块卸载不应取消订单或清除登记。

## 持久化职责

| 存档 | 当前版本 | 保存内容 |
| --- | ---: | --- |
| `cargoverse_special_orders` | `DataVersion=2` | 玩家已领取委托、锁定限制、奖励和 SP 货柜关联 |
| `cargoverse_special_order_endpoints` | `DataVersion=1` | 接取／交付终端和检查点的贸易点归属及位置 |

活动委托主要保存：

- 订单 ID、玩家 UUID、源／目的贸易点实例 UUID；
- 委托方制造商、维度和目的检查点；
- SP 货柜实例 ID；
- 接取时间、截止时间和锁定难度；
- 锁定任务限制；
- 锁定 VB、经验、声望和物品奖励。

版本 1 委托存档可继续读取；旧委托没有独立任务限制和物品奖励。不限时订单使用独立的无限截止状态，不以零 tick 代替。

每日订单不写入长期存档，而是根据源贸易点实例和游戏日稳定生成。已经消费的报价 ID 会保留有限时间，防止同一天重复领取。
