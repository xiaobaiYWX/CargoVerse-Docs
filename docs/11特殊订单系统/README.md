# 11 特殊订单系统

特殊订单是普通自由贸易之外的定向运输委托。贸易点每天发布一组订单；玩家领取后获得一只不可重新装卸的 SP 货柜，并把它送到订单锁定的实际贸易点检查点完成结算。

## 一句话模型

```text
订单定义 + 发布贸易点 + 当日可用目的地
                    ↓
                 每日订单
                    ↓ 领取并锁定
          玩家委托 + SP 货柜
                    ↓ 运输与检查
          目的检查点提交并结算奖励
```

## 核心对象

| 对象 | 生命周期 | 作用 |
| --- | --- | --- |
| 特殊订单定义 | 数据包重载周期 | 描述 SP 货柜、目的地条件、任务限制、难度和奖励 |
| 每日订单 | 一个交易日 | 发布贸易点从可用定义中抽取的共享报价，最多 5 项 |
| 已领取委托 | 从领取到完成／失效 | 锁定玩家、实际目的地、检查点、限制、截止时间与奖励 |
| SP 货柜 | 随委托生成和回收 | 承载订单运行状态，不允许普通装卸或内容调整 |

## 系统边界

- 目的地只从已登记的同维度贸易点实例中选择，不触发世界生成，也不扫描或强制加载远方区块。
- 每个贸易点每天最多展示 5 个订单；实际数量由 `modules.special_orders.offer_slots` 决定。
- 每名玩家最多同时持有 3 个进行中的特殊订单。
- SP 货柜没有普通货柜的容量、货物单位、空柜质量、调度点、特殊设计或设计缺陷。
- 特殊订单限制拥有独立的配置、校验、委托快照和存档，不从 CargoGood 自动读取或转换；底层检测器的复用不改变系统归属。
- 奖励支持 VB、运输执照经验、制造商声望与普通物品。
- 当前难度由距离项和各任务限制的固定加成组成；时限不会再额外计算一份动态难度。
