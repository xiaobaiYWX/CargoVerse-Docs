# 02 贸易点系统

## 开始制作贸易点结构

1. 复制[贸易点设计模板目录](03_贸易点设计模板/结构模板.md)，并分别填写结构、贸易点数据和随机功能三份文档。
2. 按[贸易点结构制作指南](02_贸易点结构生成层与制作规范.md)制作 NBT、模板池和世界生成文件。
3. 参考云天农庄的[结构模板](资源类/农场/云天农庄/结构模板.md)、[贸易点定义](资源类/农场/云天农庄/贸易点定义.md)和[随机功能定义](资源类/农场/云天农庄/随机功能定义.md)。
