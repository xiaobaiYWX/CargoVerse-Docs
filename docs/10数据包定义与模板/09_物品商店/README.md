# 物品商店设计

## 空白模板

| offer ID | 权重 | 解锁繁荣 | 结果类型与内容 | 基础价格（VB） | 库存类型 | 每日最大份数 |
| --- | ---: | ---: | --- | ---: | --- | ---: |
|  |  |  |  |  | `unlimited` / `limited` | 仅有限库存填写 |

同时填写商店名称、抽取次数和是否允许重复。商店商品不引用 CargoGood；有限库存按贸易点实例共享，并在交易日切换时重置。
