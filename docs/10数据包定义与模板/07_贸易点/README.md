# 贸易点设计

> 制造投放已调整为固定品牌中心＋概率工坊，部分贸易点不再提供制造服务；[查看分布与模板生成方案](<../08_货柜制造台/制造服务分布与模块生成方案.md>)。原型号材料与加工费保持不变。

[结构与功能文档入口](<结构搭建说明/README.md>)：每站保留一处实际共用平台，生成、装载、卸载按业务分时使用。

文档按“三大分类 → 贸易点中文名称”归档。总体说明保留身份、经济、功能与生成安排；建筑外观、装饰建议、既有模板和历史分区集中到一份参考文档。旧建筑清单不作为必须逐栋完成的交付要求，现有结构可按实际布局配置功能。

```text
resource/
└─ 梯田农林站/
   ├─ 00_总体说明.md
   ├─ 01_外观与装饰参考.md
   ├─ 02_货柜生成结构.md
   ├─ 03_装载区域结构.md
   ├─ 04_卸载区域结构.md
   ├─ 货柜制造台定义.md
   └─ 附件/（有专属附件时保留）
```

三份功能页分别说明业务方向、设备位置、定位范围、绑定和接入核对，**不对应三座新平台或三份必须新增的 NBT**。有工坊才提供制造，基础货柜领取取决于注册模块；纯收购或纯出售站在另一方向保留空间并明确不可交易。数据包资源 ID 和 JSON 路径保持原样。

[数据包落地状态与手工绑定方式](数据包落地状态.md)：新增 24 个经济定义已同步，自然结构待补。

建筑模板统一使用[结构模板工作流：多视角概念图到 NBT](<结构搭建说明/结构模板工作流.md>)，分为“拼接模板”和“整体贸易点”两种交付方式。两者均先生成完整贸易点效果图，再据此拆出建筑或建筑分段、派生局部参考、校准尺度并分别搭建，最后依据总图逐处拼接。首次生图即写入尺寸预算、门高、梯宽和柱跨，再由可信局部落实平面、柱网、围护、交通及外观细部。旧普通／高级流程停止使用；拼接交付的单体包围盒每轴不超过 32 格，整体贸易点内部的制作拆分不额外套用该上限。整体贸易点单边以 76 格为参考，按实际布局确定尺寸，不作为硬上限或必须填满的目标。实际保存工具的限制见[尺度校准与尺寸范围](<结构搭建说明/结构模板工作流.md#3-尺度校准与尺寸范围>)。

主体使用 Minecraft Java 1.21.1 原版内容，外观构件与材质贴近参考图，室内陈设与业务设备未要求时留待后续布置。概念多视图、尺度依据、实际 NBT 预览、尺寸、结构 ID 和交付方式汇总于本站 `01_外观与装饰参考.md`，总体说明提供入口；图片放在文档库 `assets` 中，使用标准相对链接，公开说明不包含本机路径或用户信息。

整站先有一张统一主参考板，确需细化的对象再各派生一张局部参考，同款重复部分共用参考。总图决定整体形体、比例与连接关系，局部图继承并细化对应部位，不能仅参考材质风格后另行设计。噪点、反光和扭曲细节不直接转成构件，尺寸偏差通过局部推算和坐标调整处理，不混用多版效果图作为并列标准。

连接方式依总图逐处确定，同一站点可以混用。紧密拼接适用于同一建筑的制作分段或两个直接相连的建筑；连廊或广场连接适用于有明显间隔、属于不同体块的建筑。分段制作不改变图中的连续建筑，有连廊也不意味着所有部分都必须分离。组装处理预定的墙柱、门洞、标高和屋面接口，整站交付组合后的 NBT，中间模型不默认另行提交。

每个贸易点实例都必须实际配置一座收发共用停机坪，未在单体描述中重复列出也不能省略。平台可包含在整站 NBT 中，或以独立模块拼装；每站收货与发货共用这一处实际平台。资源引用或图示不能代替实体作业面，只有建筑完成时不能据此认定整站完整。

文件按每站一套交付，目录内只放正式 NBT。单体方案包含专用建筑与 `cargo_platform.nbt`；整站方案可使用 `station.nbt`，包含全部站内主体、通路及一处实际平台，同时保留独立 `cargo_platform.nbt` 供平台单独调整。整站加载时不再重复放置平台。已有平台可复用，也可按整站布局、参考材质和实际货柜净空重新设计；已手工调整的平台不随主体重制自动覆盖。

收发停机坪中央保留醒目的 H 地面标识。标识使用对比色原版方块嵌入甲板，与作业面齐平，属于基本停机引导设施，纳入主体模板范围。平台需有实际作业面、设备预留、人员连接和飞行净空，普通院落、检修挑台及装配坞不能自动代替平台。

[Farmstead 参考模板分析](参考模板分析/Farmstead.md)：五类建筑参考样本，记录原版主体、朝向差异、构件细节及可复用做法。

## 结构文件路径

结构命名空间根目录下只使用 **大类／具体贸易点／文件名.nbt**，不再加 `trade_points` 前缀、功能小类或 `start`、`roads`、`buildings` 子目录。例如：

```text
generated/cargoverse/structures/resource/terrace_farm/cargo_platform.nbt
data/cargoverse/structure/resource/terrace_farm/cargo_platform.nbt
```

两者的加载名均为 `cargoverse:resource/terrace_farm/cargo_platform`。三大类仍为 `factory`、`market`、`resource`；英文目录用于结构资源 ID，中文文档目录保持现有命名。旧云中农场模板统一放在 `resource/cloud_farm/`，保留其独立世界结构及模板池 ID。经济定义、资源表、制造台和世界结构的 ID 不随 NBT 目录修改。

每站平台继续使用自己的 `cargo_platform.nbt`。通用平台制作源归档于 `CargoVerse-Assets/structure-sources/shared_cargo_platform.nbt`，不作为单独贸易点发布。已放置建筑不受文件搬迁影响；重新加载模板需使用新路径，已保存到世界里的结构方块旧名称需手动更新。

## 建筑材料选择

允许并鼓励使用丰富的 1.21.1 原版方块，按参考图选择材质、颜色、纹理和构件形状。本规则适用于新建和重制的单体、整站、平台及附属构筑物；旧说明中的材料限制与此冲突时，以本节为准。既有模板与原始提示词保留为历史版本记录。

- **仅排除六种方块：**铁块 `minecraft:iron_block`、金块 `minecraft:gold_block`、钻石块 `minecraft:diamond_block`、下界合金块 `minecraft:netherite_block`、绿宝石块 `minecraft:emerald_block`、信标 `minecraft:beacon`。
- **其余原版方块均可选用：**不再按拆取价值、是否为资源储存块或是否具备原版功能扩大禁用范围；铜及其各类构件、原矿块、石英、海晶石、各色玻璃、木材和其他原版材料均可按设计使用。
- **配色与表面：**主体材质与主色优先按建筑功能、结构形式和使用环境确定，再落实参考图中的颜色、纹理与表面效果。取消陶瓦优先和混凝土限量限制；陶瓦、混凝土及其他材料均可按功能与设计用作主材、辅材或强调材。
- **制造商识别：**按[八家制造商代表色](<../02_制造商/README.md#制造商代表色>)选择局部点缀，不作为建筑主色。颜色用于标牌、入口饰条、局部面板或短段色带；DMC 使用局部黄黑警戒，REX 无固定点缀色，按回收机构定位保留材料差异。规则从概念图延续到 NBT，不因品牌归属统一覆盖主体墙面、屋顶或框架。各模块与共用平台保持识别方式一致，主体材料仍可随用途变化，功能标线按需要搭配。具体要求见[制造商归属与特征色](<结构搭建说明/结构模板工作流.md#制造商归属与特征色>)。新规则不自动改变既有模板及图像。
- **构件与细部：**鼓励合理使用楼梯、台阶、墙、栅栏、活板门等形状，以及原版照明和功能方块还原参考图外观。材料开放不自动增加贸易点业务、模组设备绑定或室内陈设范围。
- **玻璃围护：**大面积窗墙、温室和采光顶使用连续的玻璃块或玻璃板，可选普通或染色版本；不混入铁栅栏模拟玻璃接缝、细窗格或框架。明确的柱梁、主屋架及外缘窗框按独立建筑构件处理，铁栅栏留给实际护栏、防护网等用途。此要求用于后续新建与重制，既有模板保持历史记录。
- **落实顺序：**概念阶段先按功能确定主材与辅材，再加入品牌点缀；落地时按参考图结合平面与柱网完成围护和构件层次，不将不同站点机械替换为相同的陶瓦墙、石砖顶与灰色框架。
- **局部构造完整性：**灯具不得覆盖柱、梁或墙，吊灯必须位于开间净空并有独立吊点；半砖檐口与完整墙梁之间先做连续封口，避免半格贯通缝；预期对称的窗组、门廊和重复开间统一从局部轴线推导，不能让两侧无缘由地差一至两格。建筑整体仍可按功能采用不对称布局。详见[构件完整性硬规则](<结构搭建说明/结构模板工作流.md#构件完整性硬规则>)。

## 目录分类的用途

只保留 factory（工业供应）、resource（资源供应）、market（消费与集散）三大导航分组。过去的农业、科研、航空等细类主要沿用了数据包路径，现有内容不足以支撑独立目录，因此改为由贸易点名称、定位和货物目录直接表达，不要求为分类填充更多站点。

文档目录调整不修改数据包 ID 中的 agriculture、research 等历史路径；这些是兼容引用，不代表还要维护一层文档分类。三大类也不限制制造服务，纯收购节点同样可以提供实体材料制造。

[60 款统一配方与分级制造投放](<../08_货柜制造台/制造配方与投放总表.md>)：材料与加工费已完成设计；仅固定中心和可选工坊节点配置制造目录，其余不配置制造模块，详见分布方案。
