## 建议结构内容

当前采用**旧礼堂与吊装庭院的一体式交换所**。旧石砌建筑承担遗物保管与协会登记，后加木廊承接营业和鉴定，右侧露天场地容纳静态吊机及残存拱墙，前方一座共用 H 平台承担实际货柜收发。

### 功能与形体

- **修补礼堂：**左后方高脊中厅与低侧廊共用空间，厚石扶壁和重复拱窗组织外立面；铜板和深板岩瓦以成片补缀方式覆盖屋面。中厅保持通高，侧面保留三个空保管龛。
- **旧门楼与木构营业廊：**残缺方塔附在礼堂前侧，只有首层通道承担使用功能；前方低木廊、登记室和条纹小雨篷共同构成营业入口。唯一主信息柜和既有协会注册模块的终端在登记室预留。
- **桁架吊机与鉴定庭院：**右后方四根落地柱托起双面桁架，中央链条和开口吊钩静态悬挂。东侧三格宽楼梯接到检修层；屋外场地留空，营业廊旁小棚预留有顶鉴定位置。
- **残拱与机械壳体：**后缘三组拱墙保留连续支墩，破损集中于顶部；少量铜质残壳由石托座承接。遗迹造型不侵入公共主路。
- **共用 H 平台：**右前方设置 25×25 格齐平作业面、两侧设备带与绕行空间。收货、发货和按需货柜生成分时使用同一平台，吊机不跨越其上空。

本版将旧四个单体的功能整合到同一站点，不重复增加独立仓房或第二个航空平台。本站仍以遗物回收、登记和有限交易为定位；静态吊机、遗迹及残壳不新增生产或鉴定机制。

### 材料与 REX 风格

REX **没有固定品牌点缀色**。本版保留回收材料原色：石砖、裂纹石砖、苔石砖和少量凝灰岩砖表现旧砌体；云杉木、去皮云杉梁柱和深色木板表现后加营业结构；斑驳、锈蚀与氧化色差由涂蜡暴露铜、锈蚀铜和氧化铜本身表达。礼堂主屋面采用成片铜板与深板岩瓦，避免用零碎随机色块填满屋顶。

灰色玻璃连续填入拱窗，独立石质窗边和扶壁沿固定开间布置。铁栏杆只用于平台防护。灯笼置于独立石座或木梁下的空气格，柱梁不断开；坡屋顶和半砖收口均先有完整实块背衬。单个拱窗及桁架按统一轴线生成，做旧只影响材料或指定的遗迹顶部。

全部使用 Minecraft Java 1.21.1 原版方块；不使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。屋面使用真实铜材，不再沿用旧版“禁用铜块”的限制。
