# 遗民打捞交换所 · 货柜生成结构

> **整站实物已更新（2026-10-01）：** 当前文件、整站坐标和设备配置见[整站导出实录](<00_结构总览.md#当前整站模板>)。本页保留业务安排、独立附件及导出前的安装方案；其中独立模板的局部坐标、旧尺寸和“待安装／未合入”状态不代表本批整站实况。


> 已配套 REX 制造商系列的独立货柜生产附属 NBT；实际落位、设备与绑定后续配置。本站制造与注册的启用条件按下文保留。

## 作用与启用条件

现有注册模块可发放基础货柜；规划必备的“打捞运输柜翻制棚”提供普通制造。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 现有 registration_point 通过注册终端提供，领取使用本生成点；注册权益独立保留 |
| 普通制造 | 固定专业工坊：打捞运输柜翻制棚；详见[任务与制造目录](<../定义设计/01_货柜制造台定义.md>) |
| 生成点 | 本站配置 1 个生成点；实际存在的注册终端／制造台各绑定此点 |
| 生成位置 | REX 专用生产附件的 24×24 露天场地；装载与卸载可按各自功能页改用 REX 独立场地，生成附件保持原范围 |
| 制造任务 | Salvage 旧世打捞柜 S／M／L |
| 业务边界 | 普通制造消耗玩家实体材料与加工费；资源表货物不是制造材料；不自动修理、移柜或生产货物 |

有限遗物通常仅 1 t 且不能混装，Salvage S 就可起步；M／L 主要为可再生特殊资源或普通样本扩量，不能用大容量承诺遗物利润倍增。记忆回声仍需避光，完善防护可在 H02 准备 Archive。

## 场地与结构

采用**遗民贸易协会（REX）· 露天修补制造场 01**，同制造商站点共用一份模板。本站按必需业务组件拼接该制造附件。原有整站文件尚未合入本附件，需以主接合口另行连接到站内道路；不直接覆盖原收发平台。

![REX 制造附件概念图](<../../../../../assets/images/trade_points/common/container_manufacturing/rex/open_yard_01/concept.png>)

![REX 制造附件实际 NBT](<../../../../../assets/images/trade_points/common/container_manufacturing/rex/open_yard_01/actual.png>)

全场露天，后侧仅保留六格深的设备与操作带、低矮工作台和旧材料架。八种涂蜡铜质地坪材料按错缝修补片混合铺装，间隔石砖、安山岩、深板岩及少量木板；所有生产面方块顶面齐平，以材质差异模拟修补和破损。 图片资产集中存放，由各站引用；完整平面、材料与提示词见[制造商模板说明](<../../../common/货柜生产附属结构/07_REX_露天修补制造场.md>)。

全场没有屋顶；灯柱、工作台、矮架和边栏位于生成空腔之外。设备位保留完整后缘，不用围栏封掉安装深度。定位点控制器需放在检测体积外，制造台朝向与实际占地后续按设备模型落实。

当前 NBT 只提供原版建筑与地面标识，不含模组终端、生成点、货柜实体、测试 UUID 或拼图绑定。现场需记录本附件原点、旋转以及控制器位置，再计算点位偏移；不能将上述局部坐标当成已完成配置。

## 与收发平台的分工

本站既有注册领取与固定工坊制造共用本附件的一处生成点，注册权益保持原定义。原 H 平台是既有收发方案；采用 REX 独立装卸场时，两个方向分别使用其功能页的新范围，不将本页制造附件的生成范围写入装卸定位点。

成品生成后，按现场运输方式移到收发区域或驶离，不假设自动移柜、自动排队或额外产生货物。本站原平台形体与记录仍见[外观参考](<01_外观与装饰参考.md>)、[装载结构](<03_装载区域结构.md>)和[卸载结构](<04_卸载区域结构.md>)。

## 设备与绑定

制造台、实际存在的注册终端与生成点绑定本站同一实例 UUID；业务终端指向同一个生成点 ID。装载、卸载终端仍绑定同一实例，使用各自装卸点。

点位偏移按目标原点减控制器位置计算，每轴 -64..64，范围每轴 1..32。检测空腔须为空气且能容纳目标货柜；后续配置以旋转和落位后的世界范围为准。保存二十格空气不能代替相邻建筑、地形与现场点位的实际安排。

## 工坊布局与交付

在修补礼堂外接入 REX 露天修补制造场，承载既有“打捞运输柜翻制棚”的业务。铜板与旧石材混合铺装，设备位、操作位和生产面完全露天，后侧仅保留低矮工作台与静态材料架。只有运输柜可制造，陈列样件和遗迹机器保持静态。

当前附属模板为 `common/container_manufacturing/rex/open_yard_01.nbt`，已交付独立 NBT，尚未合入本站整站文件。机器预留 5×4×6，另设操作位与 24×24 露天生产面；安装坐标见[本站货柜生成结构](<02_货柜生成结构.md>)。材料仍来自玩家背包与快捷栏，收发货继续使用原共用平台。

必备制造设施、随机装饰和外观变体见[本站生成规则](<../生成规则/00_生成规则.md#附属工坊生成>)；目录、材料和加工费见[制造台定义](<../定义设计/01_货柜制造台定义.md>)。
