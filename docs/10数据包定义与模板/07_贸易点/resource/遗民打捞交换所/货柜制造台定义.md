# 遗民打捞交换所 · 货柜制造功能安排

> 2026-09-28 分布调整设计，未修改代码、数据包或 NBT。取代此前“每个贸易点固定提供制造”的投放方式；型号的实体配方与加工费保持不变。

## 功能定位

**固定制造中心**。规划附带率：**100%**。打捞交换所兼营 REX 翻修工坊；维持既有低生成频率，不为造柜放大遗物供给。

[服务分布、建筑模块与生成绑定方案](<../../../08_货柜制造台/制造服务分布与模块生成方案.md>)。概率为本站单次附属池抽取的首抽目标，不是任意区块生成率，也不是最终可营业率。固定制造中心指该站点的完整规划包含必需制造模块，不保证出生点附近存在。

## 制造清单

本品牌完整目录共 3 款，所有尺寸均在本中心规划提供，仍受配方门槛限制。

| 柜型 ID | 加工费 VB | 许可／繁荣 | 实体材料 |
| --- | ---: | --- | --- |
| `cargoverse:rex/salvage_lm_s` | 70 | S／0 | `minecraft:iron_ingot` ×8、`minecraft:copper_ingot` ×8、`minecraft:oak_planks` ×8、`minecraft:leather` ×4 |
| `cargoverse:rex/salvage_lm_m` | 140 | M／1 | `minecraft:iron_ingot` ×16、`minecraft:copper_ingot` ×16、`minecraft:oak_planks` ×16、`minecraft:leather` ×8 |
| `cargoverse:rex/salvage_lm_l` | 280 | L／2 | `minecraft:iron_ingot` ×32、`minecraft:copper_ingot` ×32、`minecraft:oak_planks` ×32、`minecraft:leather` ×16 |

同型号跨站使用统一配方，材料来自玩家主背包与快捷栏；不使用贸易点库存、纯 VB 购买或新增生产线。工坊共用本站已有货柜生成／收发区域，普通制造柜照常占用调度点。

## 定义与结构的对应

制造目录 ID 沿用 `cargoverse:resource/salvage/remnant_exchange`；目标路径仍为 `data/cargoverse/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/resource/salvage/remnant_exchange.json`。经济定义配置唯一候选模块，权重 1、模块最低繁荣 0；各型号保留自身门槛。

建议主体结构文件为 `resource/remnant_exchange/manufacturing_workshop.nbt`，属于本站结构拼装的一部分。详细建筑尺寸与拼图接口安排见分布方案；该文件是待制作建议，不表示 NBT 已生成。

以下模块片段仅用于本制造中心／测试点，合入现有 `modules` 时保留其他功能。

```json
{
  "cargo_manufacturing_platform": {
    "min_prosperity_level": 0,
    "definitions_pool": [
      {
        "weight": 1,
        "definition": "cargoverse:resource/salvage/remnant_exchange"
      }
    ]
  }
}
```
