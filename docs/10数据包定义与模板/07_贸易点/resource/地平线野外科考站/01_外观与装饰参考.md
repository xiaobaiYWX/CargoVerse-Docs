## 建筑组成

按[结构模板工作流](<../../结构搭建说明/结构模板工作流.md>)执行，沿用同一张主参考板，以主轴测中的轮廓、比例和连接关系为依据。

- **[科考登记区](<#building-01>)：**登记位于三跨研究楼中央，入口有灰色门廊、浅台阶及玻璃侧亮；唯一主信息柜和既有 HRI 注册终端分别预留在入口两侧。
- **[样本研究区](<#building-02>)：**三段斜玻璃采光顶分别对应三个十格柱跨，灰色屋架从外墙柱连续延伸到屋面。前后通路联系样本分拣、登记封装和精密测量区。
- **[无人机机库](<#building-03>)：**右侧独立筒拱轮廓、厚门框和侧窗保持完整，前后山墙封闭屋顶与门楣之间的空间，机库侧门通过短廊连接研究楼。
- **[观测塔与天线](<#building-04>)：**左侧先由支腿与托臂承托高位甲板，甲板上布置切角气象舱，再由舱顶支架承托倾斜凹面天线。三格宽外梯通向观测甲板，台下为开放支承和玻璃短廊。
- **实际共用平台：**25×25 作业面与齐平 H 位于主楼正前，两条设备长带沿两侧布置，公共通路绕开作业面；全站只有一处航空收发平台。

### 材质与构造

灰色框架使用石砖、磨制安山岩及对应楼梯、半砖，浅色墙面使用平滑砂岩；屋顶采用暗海晶石的深绿灰色，天线采用平滑石英和磨制闪长岩。HRI 的蓝色通过少量蓝色混凝土用于门框、柱边、墙腰线与气象舱檐下，灰色框架与浅色主体仍占主要面积。

斜采光顶使用连续淡蓝色玻璃，垂直窗和短廊采用连续淡灰色玻璃，玻璃面内没有铁栅栏。铁栅栏只用于独立护栏和气象桅杆。薄檐、坡面与筒拱转折保留实体接合；吊灯和前伸支座只写入空格，保留柱、梁和墙体连续。窗组及机库门架分别按自身中心线生成。

全部使用 Minecraft Java 1.21.1 原版方块，未使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。内部只保留隔墙、楼板与必要通路，设备、家具、货物和业务终端继续留空。

## 文件与加载

存档相对目录：`generated/cargoverse/structures/resource/field_station/`。完整建站使用：

```text
cargoverse:resource/field_station/station
```

单独编辑同一平台时使用 `cargoverse:resource/field_station/cargo_platform`。编辑件对应整站 **X=18…56、Z=0…33**，组件原点相对整站为 **(18, 0, 0)**，地坪仍为Y=5；完整整站不再额外叠放它。

本次覆盖 `station.nbt` 和同平台编辑件。旧独立单体、早期收发台保留为历史资产，不参与当前组成。结构包含包围盒内空气；NBT尚未接入自然生成、Jigsaw或业务实例，经济与货柜制造设计继续沿用已有定义。
