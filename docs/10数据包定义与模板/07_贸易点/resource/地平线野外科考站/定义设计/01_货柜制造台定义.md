> 2026-10-01 已同步内置数据包：本站固定制造目录（2 条配方）及模块绑定已落地。整站通过指令生成时关联本站实例，自然投放规则已同步内置数据包；实机制造待验收。

## 结构与生成入口

[工坊布局、生成点与设备安装](<../结构设计/02_货柜生成结构.md#工坊布局与交付>) · [世界生成与附属工坊规则](<../生成规则/00_生成规则.md>)。本页维护服务定位、柜型目录、配方和功能绑定。

## 功能定位

**固定配套制造台**。野外队常需补充样本柜，但营地本身不是研究装备总厂。现场封装解决样本与测量仪出货，正式批量制造仍归 H02。

Explorer S／M 固定用于野外样本与测量仪封装。高容量和资料柜在 H02 准备；本站注册权益与普通付费制造分别处理。

目录围绕本站运输任务保留，不扩为制造商全系列；实体成本、许可、繁荣和调度点按现有配方执行。

## 货物任务与柜型选择

| 系列与规格 | 本地／关联航线中的用途 | 实际货物示例 |
| --- | --- | --- |
| Explorer 科考样本舱 S／M | 样本和野外测量仪的就地补柜 | 末地环境样本、地层岩芯、精密测量仪 |

柜型仅允许定义中的 CargoClass，不同货物不可混装；防护由现有 special_designs 决定，限时要求始终保留。

关联备柜节点：[H02 精密电子与测绘中心](<../../../factory/精密电子与测绘中心/定义设计/01_货柜制造台定义.md>)。具体规格以各节点目录为准；这些节点分别补充不同任务，并非每个节点都覆盖本站全部型号，也不保证在地图上相邻。

同型号跨站使用相同配方、加工费与门槛。成本仍是待平衡基线；系列首个必要 M 型调整至繁荣 0，许可证仍为 M。完整理由见[统一配方及投放表](<../../../../08_货柜制造台/制造配方与投放总表.md>)。

## 定义与实例绑定

目标定义 ID：`cargoverse:resource/sky_station/field_station`；目标路径：`data/cargoverse/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/resource/sky_station/field_station.json`。以下定义已同步内置数据包。制造台、生成点与营业核心共用本站 UUID，不新增锚点、库存或第二个贸易点。

合入 `modules` 的片段（保留本站其他功能）：

```json
{

    "min_prosperity_level": 0,
    "definitions_pool": [
      {
        "weight": 1,
        "definition": "cargoverse:resource/sky_station/field_station"
      }
    ]
  }
}
```
