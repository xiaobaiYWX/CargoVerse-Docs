## 功能定位

**测试专用**。规划附带率：**不参与自然生成**。仅用于手工验证和演示，不计入正式自然生成概率。

[服务分布、建筑模块与生成绑定方案](<../../../08_货柜制造台/制造服务分布与模块生成方案.md>)。概率为本站单次附属池抽取的首抽目标，不是任意区块生成率，也不是最终可营业率。固定制造中心指该站点的完整规划包含必需制造模块，不保证出生点附近存在。

## 定义与结构的对应

制造目录 ID 沿用 `cargoverse:resource/general/default`；目标路径仍为 `data/cargoverse/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/resource/general/default.json`。经济定义配置唯一候选模块，权重 1、模块最低繁荣 0；各型号保留自身门槛。

建议主体结构文件为 `resource/default/manufacturing_workshop.nbt`，属于本站结构拼装的一部分。详细建筑尺寸与拼图接口安排见分布方案；该文件是待制作建议，不表示 NBT 已生成。

以下模块片段仅用于本制造中心／测试点，合入现有 `modules` 时保留其他功能。

```json
{
  "cargo_manufacturing_platform": {
    "min_prosperity_level": 0,
    "definitions_pool": [
      {
        "weight": 1,
        "definition": "cargoverse:resource/general/default"
      }
    ]
  }
}
```
