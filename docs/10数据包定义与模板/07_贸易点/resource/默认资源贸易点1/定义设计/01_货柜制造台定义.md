## 功能定位

**测试专用**。固定配置制造台与一处生成点，注册领取与普通制造共用此点。仅用于手工验证和演示，不参与正式自然生成。

[服务分布、建筑模块与生成绑定方案](<../../../../08_货柜制造台/制造服务分布与模块生成方案.md>)。本站不使用附属池决定制造服务有无；测试实例需实际安装并绑定设备，文档中的目录不代表设备已接入。

## 制造清单

以下 4 款为保留的设计目录，尚未全部落地。当前运行时仅有 `cargoverse:aui/atlas_sd_s`，加工费 80 VB，配方最低繁荣 0、模块最低繁荣 1；不作为自然投放保底。

| 柜型 ID | 加工费 VB | 许可／繁荣 | 实体材料 |
| --- | ---: | --- | --- |
| `cargoverse:vbs/harvest_lm_s` | 90 | S／0 | `minecraft:iron_ingot` ×8、`minecraft:oak_planks` ×12、`minecraft:white_wool` ×4、`minecraft:glass` ×4 |
| `cargoverse:vbs/biopod_sd_s` | 120 | S／0 | `minecraft:iron_ingot` ×12、`minecraft:glass` ×12、`minecraft:white_wool` ×4、`minecraft:copper_ingot` ×4 |
| `cargoverse:aui/atlas_sd_s` | 80 | S／0 | `minecraft:iron_ingot` ×16、`minecraft:oak_planks` ×8、`minecraft:glass` ×4、`minecraft:redstone` ×2 |
| `cargoverse:aui/atlas_sd_l` | 320 | L／2 | `minecraft:iron_ingot` ×64、`minecraft:oak_planks` ×32、`minecraft:glass` ×16、`minecraft:redstone` ×8 |

同型号跨站使用统一配方，材料来自玩家主背包与快捷栏；不使用贸易点库存、纯 VB 购买或新增生产线。工坊共用本站已有货柜生成／收发区域，普通制造柜照常占用调度点。

## 定义与结构的对应

制造目录 ID 沿用 `cargoverse:resource/general/default`；目标路径仍为 `data/cargoverse/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/resource/general/default.json`。以下设计草案采用唯一候选模块，权重 1、模块最低繁荣 0；各型号保留自身门槛。当前实装模块最低繁荣仍为 1，记录于[贸易点定义](<00_贸易点定义.md#模块>)，本次不修改运行时。

以下模块片段仅用于本制造中心／测试点，合入现有 `modules` 时保留其他功能。

```json
{
  "cargo_manufacturing_platform": {
    "min_prosperity_level": 0,
    "definitions_pool": [
      {
        "weight": 1,
        "definition": "cargoverse:resource/general/default"
      }
    ]
  }
}
```
