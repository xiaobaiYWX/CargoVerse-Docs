## 结构文档与功能安排

外观、装饰、旧建筑清单和模板展示统一收录于[外观与装饰参考](<01_外观与装饰参考.md>)，已有站点无需按旧清单补齐建筑。功能页描述实际设备及可用条件，三项作业分时复用本站唯一共用平台。

| 文档 | 本站用途与启用条件 |
| --- | --- |
| [货柜生成结构](<02_货柜生成结构.md>) | 固定制造台与一处生成点；基础领取仅在已有注册模块时启用 |
| [装载区域结构](<03_装载区域结构.md>) | 启用方向：本站出售 3 条规则，玩家购买并装入货柜 |
| [卸载区域结构](<04_卸载区域结构.md>) | 启用方向：本站收购 2 条规则，玩家卸货并获得结算 |
| [货柜制造台定义](<../定义设计/01_货柜制造台定义.md>) | 测试制造台：货柜制造功能安排；按运输任务确定目录 |

功能结构页是安装与绑定说明，不要求分别导出三份平台 NBT。主体若已包含平台，独立 `cargo_platform.nbt` 仅作同平台编辑组件。当前外壳交付记录与设备安装、绑定、游戏内验收状态分开维护。
