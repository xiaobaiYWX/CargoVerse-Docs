# 默认资源贸易点1 · 货柜生成结构

> **历史单测试点（已替换）：** 本页保留旧建筑与设计记录，所列旧经济／制造定义不再发布。当前使用[测试贸易点 A／B](<../../../market/测试贸易点A/00_总体说明.md>)，覆盖全部正式商品与货柜；以新站目录为准。

> 功能安装设计；保留已有平台结构，本轮未放置业务方块或修改实例绑定。具备相关服务的设计前提不等于现场已可生成。

## 作用与启用条件

注册服务可领取基础货柜；制造模块用于手工测试。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 数据定义已有 `registration_point`；由许可证注册终端绑定生成点，按玩家已有基础货柜资格领取 |
| 普通货柜制造 | 沿用演示模块，受其繁荣与配方门槛限制 |
| 实际生成位置 | 本站唯一共用平台；注册终端或工坊可位于营业楼／附属建筑内，不在其房间里生成货柜 |
| 生成点数量 | 配置 1 个 `cargoverse:container_spawn_point`，所有本站生成服务复用此点 |
| 制造设计入口 | [本站配方与制造服务](<../定义设计/01_货柜制造台定义.md>)；不以有无工坊改变既有基础注册权益 |

“货柜生成结构”指交付空货柜所需的场地和定位设备；普通制造消耗实体材料与加工费，平台本身不持续产柜。

## 场地与结构

| 项目 | 本站安排 |
| --- | --- |
| 平台结构 ID | `cargoverse:resource/default/cargo_platform` |
| 平台文件尺寸 X × Y × Z | 43 × 12 × 35；此值为结构文件包围盒，不是货柜定位范围 |
| 交付方式 | 独立平台随站点拼装，本站只放置一座 |
| 坐标基准 | 本站独立 `cargo_platform.nbt` 的局部坐标，不是世界坐标；整站与组件坐标不得混用 |
| 建议作业范围 | (6, 5, 6) → (25, 24, 25)，含两端；尺寸 **20 × 20 × 20** |
| 地板与净空 | 起始 Y=5 为第一层空气，地板在 Y=4；地板和齐平 H 标线不计入检测体积 |

范围沿用既有共用作业空间记录，作为本轮安装初稿；尚未验证设备放置与现场净空。完整平台、设备带和通路见[本站外观与模板记录](<01_外观与装饰参考.md>)。定位点控制器坐标、偏移值与旋转后世界范围仍待实装记录；不把预留区写成已经完成的定位点配置。

延续 VBS 现有围护与通透廊棚，黄绿色和白色用于局部识别，公共货柜甲板保持干燥；水池、花槽、育种箱和冷藏陈列位于操作范围之外。

生成点布置在甲板边缘的检修位，位于上述生成体积外；原有灯具、围栏、设备棚柱及标牌同样放在范围外。营业区或工坊到此处保留至少 3 格宽人员路线，玩家可在边缘看见交付货柜并进入操作位置。

## 设备与绑定

- 生成点与实际服务终端绑定同一贸易点实例 UUID：经济定义 `cargoverse:resource/general/default`。主信息柜锚点沿用本站营业区，平台不再设置第二个主锚点。
- 各注册终端／制造台分别绑定这一个生成点 ID；装载、卸载仍使用各自类型的定位点，不能用生成点代替。
- 点放好后，用“目标范围原点减定位点位置”得到偏移，每轴限 -64..64；范围每轴限 1..32。若设备带位置不满足偏移限制，调整定位点位置。
- 生成检查要求**整个生成范围**为空气且不与已有物理结构相交；台阶、设备和现有空柜都不能留在范围内。货柜模板还必须完整放入，已加载区块与世界边界也需有效。
- 设备绑定、自然生成时的实例初始化与定位点 ID 写入按现有制作规范处理；不要将测试世界 UUID 或绝对定位点 ID 固化到可复用模板。

## 使用顺序与接入核对

玩家先在营业终端领取，或在实际存在的工坊提交制造；空出平台后交付货柜，再将货柜用于装卸或运走。已有货柜占用时先移走，不假定有自动移柜、排队或作业互锁功能。

接入时用本站可发放的货柜验证尺寸与空场生成；同一范围放入方块或已有货柜时应拒绝生成。普通制造失败不得消耗材料或加工费。检查旋转后的点位、净空及人员路线；基础货柜领取与普通制造分别验证，本站固定布置制造台与生成点，注册权益独立于普通制造配方。
