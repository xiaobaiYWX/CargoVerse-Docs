## 作用与启用条件

规划必备的“活体舱与水产包装工坊”提供普通制造。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 当前没有注册模块，不因制造设计新增基础领取 |
| 普通制造 | 固定专业工坊：活体舱与水产包装工坊；详见[任务与制造目录](<../定义设计/01_货柜制造台定义.md>) |
| 生成点 | 本站配置 1 个生成点；实际存在的注册终端／制造台各绑定此点 |
| 生成位置 | VBS 专用生产附件的 24×24 露天场地；装载与卸载可按各自功能页改用 VBS 独立场地，生成附件保持原范围 |
| 制造任务 | BioPod 活体运输舱 S／M／L；Harvest 农鲜周转柜 S／M |
| 业务边界 | 普通制造消耗玩家实体材料与加工费；资源表货物不是制造材料；不自动修理、移柜或生产货物 |

BioPod S／M／L 运禽羊、蜂群和鱼苗，鲜贝也可用其固定设计；普通鱼虾选择更经济的 Harvest S／M。更大批普通农鲜柜去 V01，全部时限照常生效。

## 场地与结构

采用**绿洲农业联盟（VBS）· 绿植高台制造场 01**，同制造商站点共用一份模板。本站按必需业务组件拼接该制造附件。原有整站文件尚未合入本附件，需以主接合口另行连接到站内道路；不直接覆盖原收发平台。

![VBS 制造附件概念图](<../../../../../assets/images/trade_points/common/container_manufacturing/vbs/open_yard_01/concept.png>)

![VBS 制造附件实际 NBT](<../../../../../assets/images/trade_points/common/container_manufacturing/vbs/open_yard_01/actual.png>)

后部仅设置六格深的二层开放操作平台，以侧梯连通；首层右侧和外围布置密集树叶、蕨类与花草。木柱梁、浅色柱脚和白色边缘构件配黄绿色标识，24×24 生产面、设备位与人员通路保持空旷。 图片资产集中存放，由各站引用；完整平面、材料与提示词见[制造商模板说明](<../../../common/货柜生产附属结构/06_VBS_绿植高台制造场.md>)。

二层为开放操作台，实际制造台位于首层设备位。平台楼板、立柱、楼梯、灯具和植物位于生成空腔之外。设备位保留完整后缘，不用围栏封掉安装深度。定位点控制器需放在检测体积外，制造台朝向与实际占地后续按设备模型落实。

当前 NBT 只提供原版建筑与地面标识，不含模组终端、生成点、货柜实体、测试 UUID 或拼图绑定。现场需记录本附件原点、旋转以及控制器位置，再计算点位偏移；不能将上述局部坐标当成已完成配置。

## 与收发平台的分工

货柜制造及实际存在的基础领取使用本附件的一处生成点。原 H 平台为既有收发方案；采用新增 VBS 独立装卸场时，两个方向各用其功能页记录的独立范围，不将本页制造附件的生成范围写入装卸定位点。

成品生成后，按现场运输方式移到收发区域或驶离，不假设自动移柜、自动排队或额外产生货物。本站原平台形体与记录仍见[外观参考](<01_外观与装饰参考.md>)、[装载结构](<03_装载区域结构.md>)和[卸载结构](<04_卸载区域结构.md>)。

## 设备与绑定

制造台、实际存在的注册终端与生成点绑定本站同一实例 UUID；业务终端指向同一个生成点 ID。装载、卸载终端仍绑定同一实例，使用各自装卸点。

点位偏移按目标原点减控制器位置计算，每轴 -64..64，范围每轴 1..32。检测空腔须为空气且能容纳目标货柜；后续配置以旋转和落位后的世界范围为准。保存二十格空气不能代替相邻建筑、地形与现场点位的实际安排。

## 工坊布局与交付

在育种温室侧接入 VBS 绿植高台制造场。首层设备与操作位保持干燥，养殖水体不进入生产面；二层为开放操作平台，植物只布置在净空外。成品按现场路线转运至原收发平台。

当前附属模板为 `common/container_manufacturing/vbs/open_yard_01.nbt`，已交付独立 NBT，尚未合入本站整站文件。机器在首层预留 5×4×6，另设干燥操作位、二层开放平台和 24×24 平整露天生产面；安装坐标见[本站货柜生成结构](<02_货柜生成结构.md>)。材料仍来自玩家背包与快捷栏，收发货继续使用原共用平台。

必备制造设施、随机装饰和外观变体见[本站生成规则](<../生成规则/00_生成规则.md#附属工坊生成>)；目录、材料和加工费见[制造台定义](<../定义设计/01_货柜制造台定义.md>)。
