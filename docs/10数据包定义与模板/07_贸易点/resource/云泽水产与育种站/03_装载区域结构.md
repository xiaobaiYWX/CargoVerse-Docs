# 云泽水产与育种站 · 装载区域结构

> 功能安装设计；本页不新增一座平台，也不表示设备已安装或绑定。

## 作用与本站业务

玩家从贸易点购买货物，经装载机装入自己的货柜；对应贸易点的**出售**方向。

**本站启用此方向，共 8 条资源规则。** 出售：冰鲜河鱼、冰鲜海虾、鲜采食用海带、净化鲜贝、家禽种群、育成绵羊、养殖鱼苗、授粉蜂群。

具体货物匹配、库存和价格以[本站资源表](<../../../06_资源表/resource/ecology/aquaculture_station.md>)及[总体说明](<00_总体说明.md>)为准。工坊有无不改变货物目录。

## 结构与设备布置

沿共用作业面外侧选用既有设备带，装载机与另一侧终端分列；具体控制器坐标尚未记录，现场量取后填入本页。平台形体与人员入口见[本站外观与模板记录](<01_外观与装饰参考.md>)。

延续 VBS 现有围护与通透廊棚，黄绿色和白色用于局部识别，公共货柜甲板保持干燥；水池、花槽、育种箱和冷藏陈列位于操作范围之外。

货柜装载机当前方块包围占地约为本地宽 3 × 高 2 × 深 2；安装时以完整多方块与模型外伸为准，朝向改变时宽深一起旋转。建议预留至少 3 格高设备空间，面板前留至少 3 格深操作通路，背侧留检修位置；若旧预留较窄，应调整外侧设备带，不能占用中央货柜净空。

控制面朝向人员操作带，玩家能同时看到设备与货柜；棚顶只覆盖设备位。地板上的用途牌写明“购买／装货”，灯具和栏杆布置在边界以外。公共路线从营业区沿平台外围进入，不穿过正在作业的货柜。

## 定位范围与关联

| 项目 | 本站安排 |
| --- | --- |
| 终端 | `cargoverse:container_loader` |
| 定位点 | `cargoverse:container_loading_point`，初版只需 1 个；终端可按现有能力绑定多个 |
| 贸易点 | `cargoverse:resource/ecology/aquaculture_station`；绑定与营业区相同的实例 UUID |
| 建议共用范围 | (45, 9, 7) → (69, 28, 31)，含两端，25 × 20 × 25；本站 `station.nbt` 的局部坐标 |
| 完整场地数据 | [货柜生成结构的场地与结构](<02_货柜生成结构.md#场地与结构>)；范围首层为空气，地板不计入 |
| 与其他业务关系 | 装载点与卸载点分别配置但指向同一世界范围；生成点按需分时复用，不增加第二处作业面 |

定位点放在作业体积外的甲板边缘；控制器坐标与偏移现场确定，每轴偏移 -64..64，范围每轴 1..32。当前范围是安装初稿，旋转后必须以世界范围显示确认。平台编辑组件需先换算到相同坐标基准，不直接照抄整站坐标。

## 操作与接入核对

玩家停放有效货柜后，在装载机选择货柜、货物和数量，确认购买。检查许可证、所有权、兼容类别、容量、出售库存与结算器余额，成功后增加柜内货物并扣款。

装载不自动制造货柜，材料库、展示车间和仓架不直接参与交易。

接入时验证范围内货柜可被选中、移出范围后不再被该点识别；核对空目录／库存不足等业务反馈、实际设备前站立空间及旋转后的范围。在已有共用区域各完成一次允许方向的交易，再确认货柜可驶离或移走。
