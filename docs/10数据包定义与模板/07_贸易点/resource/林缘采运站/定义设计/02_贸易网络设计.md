# 林缘采运站 · 贸易网络设计

> **已接入 · 2026-10-06：** 本页维护用途、商品组合与线路。精确库存、日补、报价和每日限额统一见[本站正式资源表](<../../../../06_资源表/resource/ground_station/woodland_logging_station.md>)，不在本页重复维护参数。

## 经营身份

由林地采运队经营，向不同买方提供原木，并自行采购工具和生活物资；不属于绿洲农业联盟的林务分站。

与品牌大站的货物流向属于自由交易，不表示加盟、受控库存或制造商声望归属。当前运行归属尚未改为 none，目标和发布值见本站定义页。

## 本站在网络中的职责

原木采运不扩成综合农林大站，只补充手工具和少量维修回收料。

站点 ID：`cargoverse:resource/ground_station/woodland_logging_station`。当前 **3 项出售 / 3 项收购**。地面站保留小规模、无制造／注册服务，全部收购逐项限额。
