# 林缘采运站 · 生成规则

> **已接入：** 已同步导出 NBT、贸易点定义、资源表、结构绑定及首版自然生成配置。预览来自实际 NBT；地形效果、货柜装卸和到访流程仍待游戏内验收。

## 环境与形态

针叶林边缘与林间较开阔缓地。群系仅表达林业环境，不能保证落点自动处在林缘。

## 地面标高与验证边界

模板营业主地坪为局部 Y=2、人员脚面 Y=3，作业平台为 Y=6。单模板 groundLevelDelta=1；投影采样值记为 H，start_height=1 后模板底层为 H，主地坪表面到达 H+3，装卸平台表面为 H+7。高低平台差来自实物，不能把装卸面也强压到同一地表高度。

当前关闭地形适配（none），并将起始高度较原配置抬高 3 格。结构保留地表高度投影；不进行额外地形融合，也没有全占地平坦度筛选。群系标签不保证平缓、河岸朝向、避开水体或避开其他建筑，尤其要检查河岸、高差及基础悬空。

全部地面小站共用一组 random_spread 候选布点，spacing=32、separation=16、frequency=1、salt=15487105。单格至多生成一个小站，G06 使用较低权重；不每站另叠一套网格。参数为本次接入基线，后续密度与群系统一调整，天空站原参数保持独立。

## 指令与实机验收

```mcfunction
/place structure cargoverse:trade_point/resource/ground_station/woodland_logging_station ~ ~ ~
/locate structure cargoverse:trade_point/resource/ground_station/woodland_logging_station
```

指令可用于模板和经济绑定检查；自然生成只作用于新区块，地形融合须在新原版区块中验证。/place structure 不会重新融合已生成地形，/place template 不建立经济实例。逐站测试不同朝向、信息柜、装卸机与实际货柜；没有制造或注册模块的设备不提供对应服务。
