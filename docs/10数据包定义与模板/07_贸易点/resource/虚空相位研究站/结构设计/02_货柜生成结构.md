## 作用与启用条件

本站固定配置制造台与一处生成点。本站没有注册模块，不额外增加基础货柜领取。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 当前没有注册模块，不因制造设计新增基础领取 |
| 普通制造 | 固定配套制造台：相位站应急封装舱；详见[制造目录](<../定义设计/01_货柜制造台定义.md>) |
| 生成点 | 本站固定安装 1 处生成点，所有实际存在的制造／注册终端绑定同一点 ID |
| 生成位置 | HRI 专用生产附件的 24×24 露天场地；装卸按各方向功能页使用独立范围 |
| 制造任务 | Archive 资料封存柜 S |
| 业务边界 | 普通制造消耗玩家实体材料与加工费；资源表货物不是制造材料；不自动修理、移柜或生产货物 |

本站固定提供 Archive S，解决末地小批异常物与资料周转；M 型在 H02 准备。是否满足配方、许可和运输条件仍由玩家准备情况决定。

## 场地与结构

采用**地平线研究院（HRI）· 下沉观察制造场 01**，同制造商站点共用一份模板。本站将该附件作为必需功能组件接入。原有整站文件尚未合入本附件，需以主接合口另行连接到站内道路；不直接覆盖原收发平台。

![HRI 制造附件概念图](<../../../../../assets/images/trade_points/common/container_manufacturing/hri/open_yard_01/concept.png>)

![HRI 制造附件实际 NBT](<../../../../../assets/images/trade_points/common/container_manufacturing/hri/open_yard_01/actual.png>)

灰色下沉生产场由高出两格的两侧步道与后部服务台围合，蓝色用于檐口、挡墙和地面标记。后部左侧是开敞设备棚、右侧是连续玻璃观察舱，中间以三格宽短梯连接；观察舱由面向梯顶的西侧入口进入。 图片资产集中存放，由各站引用；完整平面、材料与提示词见[制造商模板说明](<../../../common/货柜生产附属结构/04_HRI_下沉观察制造场.md>)。

屋顶、框架、灯具和边栏位于生成空腔之外。设备位保留完整后缘，不用围栏封掉安装深度。定位点控制器需放在检测体积外，制造台朝向与实际占地后续按设备模型落实。

当前 NBT 只提供原版建筑与地面标识，不含模组终端、生成点、货柜实体、测试 UUID 或拼图绑定。现场需记录本附件原点、旋转以及控制器位置，再计算点位偏移；不能将上述局部坐标当成已完成配置。

## 与收发平台的分工

普通制造固定使用 HRI 生产附件的一处生成点。本站没有注册模块，不额外增加基础货柜领取。 装载和卸载按各自功能页配置范围，采用分离式场地时不得把本生产附件坐标写入装卸定位点。

成品按现场运输方式移至装卸区域或驶离，不增加自动移柜、排队或额外货物。

## 设备与绑定

制造台、实际存在的注册终端与生成点绑定本站同一实例 UUID；业务终端指向同一个生成点 ID。装载、卸载终端仍绑定同一实例，使用各自装卸点。

点位偏移按目标原点减控制器位置计算，每轴 -64..64，范围每轴 1..32。检测空腔须为空气且能容纳目标货柜；后续配置以旋转和落位后的世界范围为准。保存二十格空气不能代替相邻建筑、地形与现场点位的实际安排。

## 工坊布局与交付

从主研究楼边缘接入 HRI 下沉观察制造场，高台设备棚预留单台制造设备，观察舱用于后续封装操作布置；模板本身不提供遮光或稳相业务效果。装饰替代仍为记录舱、备用观测舱和器材暂存舱，保持相同接口。

当前附属模板为 `common/container_manufacturing/hri/open_yard_01.nbt`，已交付独立 NBT，尚未合入本站整站文件。机器在 Y=3 高台上预留 5×4×6，第一层设备空气为 Y=4；另设观察操作位，24×24 露天生产地坪位于 Y=1；安装坐标见[本站货柜生成结构](<02_货柜生成结构.md>)。材料仍来自玩家背包与快捷栏，收发货继续使用原共用平台。

必备制造设施与随机装饰安排见[本站生成规则](<../生成规则/00_生成规则.md#附属工坊生成>)；目录、材料和加工费见[制造台定义](<../定义设计/01_货柜制造台定义.md>)。
