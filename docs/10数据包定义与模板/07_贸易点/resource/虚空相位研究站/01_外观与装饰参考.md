## 建议结构内容

当前交付为**一体式折线环廊与三叶庭院方案**。采用下方唯一主参考板，重新建立空间、开口、基础和屋盖；此前一体式版本的概念图与尺寸只作为历史记录，不再混用。

### 功能与体量

三个分离的八角研究舱围绕露天庭院布置。左右两舱采用相同柱墙与屋盖节奏，后侧观测舱略高；前方短前厅通过两段斜向玻璃廊连接侧舱，另外两段斜廊从侧舱通向后舱。庭院中央保留一个完整闭合、双墩支承的竖直稳相环。

前置 H 平台通过窄桥和两级楼梯接入营业前厅。基座沿实验舱、折线连廊和庭院轮廓收边，平台与主建筑之间能看见独立连接桥。两侧后方另设有实体立柱、铜质横梁和悬挂散热片的开放构架。

营业登记、样本验收、异常隔离和观测功能分别由前厅及三座空舱承接；储存与保障设备以后布置，不增加独立房屋或第二个平台。环架与散热构架只是静态建筑构件，不附加工作机制。

### 材料与制造商识别

主体采用石英砖墙、平滑石英檐口、深板岩砖柱与环架、石砖基座、磨制安山岩压顶、平滑石屋面和淡蓝玻璃。四处稳相环夹件及后方横梁使用涂蜡氧化切制铜。

HRI 的蓝色以蓝色混凝土短饰带和窄边圈表现，重复分布于窗下、门楣、玻璃廊下沿、稳相环内圈和 H 平台边缘；灰色石材保持为功能主材。八角舱窗面为连续玻璃，独立承重柱只位于实际结构轴线，铁栏杆只用于外缘防护。

灯具位于独立底座或有实块支承的屋面节点，放置时不替换柱梁；每层屋面先有完整封闭底板，再叠加八角收分、压顶和半砖。前厅双门、窗组和门柱沿同一局部中心线生成。

所有内容使用 Minecraft Java 1.21.1 原版方块；不使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。家具、研究设备、物资陈列与业务终端均留待后续布置。
