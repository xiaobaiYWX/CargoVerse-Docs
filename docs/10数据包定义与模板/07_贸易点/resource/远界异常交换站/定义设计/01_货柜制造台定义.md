# 远界异常交换站 · 远界应急补柜台

> 2026-10-01 已同步内置数据包：本站固定制造目录（1 条配方）及模块绑定已落地。整站通过指令生成时关联本站实例，自然投放规则已同步内置数据包；实机制造待验收。

## 功能定位

**固定配套制造台**。远端交换站常驻一台提供 Salvage S 的制造台，允许携带材料的承运人补充能装异常货物的小柜。只提供前哨能够维护的低复杂度框架，高防护与扩量准备仍有其他目的地。

在本站用带来的实体材料制造 Salvage S，承运非欧几何构件或时滞晶簇；避光等剩余要求继续生效。高防护 Archive 可在 H02 或 H03 准备，长途出发前仍应安排材料与载重。

不新增末地专属耗材或许可门槛，不消耗异常货物造柜，也不让有限库存随制造恢复。
