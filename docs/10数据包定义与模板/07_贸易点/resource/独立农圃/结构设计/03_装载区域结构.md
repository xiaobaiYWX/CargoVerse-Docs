# 独立农圃 · 装载区域结构

> **已接入：** 已同步导出 NBT、贸易点定义、资源表、结构绑定及首版自然生成配置。预览来自实际 NBT；地形效果、货柜装卸和到访流程仍待游戏内验收。

## 业务方向

贸易点出售、玩家买入：袋装麦粒、温室鲜果。按资源表有限出售库存营业，缺货时等待补货；日补为 0 的批次不自动恢复。

麦袋和鲜果筐在温室一侧作少量陈列，装载终端明确两种商品；鲜果的既有运输时限不因小站减免。

## 当前实物

定位点 `cargoverse:container_loading_point` 位于 (25, 5, 33)，偏移 (0, 2, 0)，检测尺寸 15×8×15，范围 (18, 7, 26) 至 (33, 15, 41)（最大边界不包含）。

两处作业位同属一个整站 NBT，分别安装装卸机与仓库信息柜；无需再次叠加平台模板。两类检测区域在实物中不重合，操作时将货柜放入对应方向的完整范围。

本方向共有 2 项货物规则，详见[资源表](<../../../../06_资源表/resource/ground_station/independent_farmstead.md>)。出售按各条目的有限库存和日补营业。

检测高度为 8 格，货柜须整体进入范围；部分 M 型超高货柜不适用当前点位。以实际柜型测试通行、放入、识别与交易，不能只凭平台外观判定兼容。
