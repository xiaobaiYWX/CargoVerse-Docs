## 本次采用的单栋参考

深色坡屋顶下的双开间石质维修屋。 两个维修开间共用一副屋架，中间留实心承重墩；侧面有人行门，后部可安排工具与备件。

本站由独立经营者维护，不因经营内容或采购设备而套用制造商配色、站徽。

## 从参考到方块尺度

- 模板包围盒为 **24×15×22**（宽×高×深），包含屋檐与附件。主墙范围为 X=3～21、Z=7～17；屋檐范围为 X=2～22、Z=6～18。
- 用两格高侧门校准人行尺度，再分别安排外石框、内木框、窄窗与屋面厚度。概念中的木纹、砖缝和人物仅作辅助，不逐条计成方块。
- 主屋与前场地坪均为 Y=1；正面维修开间平接铺地，取消首版贯通门前的一格台阶。
- 两个石框开口各 6 格宽，木门框后退一格；木框内净宽各 4 格、主体净高 4 格，顶部两端保留木托角。中墩宽 3 格，两端石墩各宽 2 格，均从同一中轴推导。
- 屋面最低一层为 Y=8，屋脊半砖为 Y=14；灰色封边下另设木质山墙边和横梁，不再用同一种深色屋瓦包住整个山墙边缘。
- 侧面窄窗为 1×3 格，后墙窗组为 3×2 格；窗台、边框、门楣分别落地。它们是有限方块尺度下的明确近似，不声称复制了图中的亚方块细线。

保留一栋双开间维修屋，不增加备件棚或参考中没有的烟囱。前场和侧门通路留空；只有从大开口可见的少量台面、空桶和工具块，不预装完整维修生产线。

## 材料与构件对应

| 图中部位 | 本次原版方块选择 |
| --- | --- |
| 主墙、石墩和外门框 | 石砖为主，安山岩、少量圆石与裂纹石砖作粗石填补；墙脚局部苔石砖，门框边角用磨制安山岩 |
| 深灰坡屋面 | 深板岩砖楼梯与脊部半砖；两端另用石砖楼梯、半砖形成可读的灰色封边 |
| 厚木檐、山墙饰板与托角 | 横向去皮橡木、橡木楼梯及半砖；实心木檐直接承接屋瓦，不留下贯通半格缝 |
| 内退门框与侧墙骨架 | 带皮橡木立柱、横向去皮橡木门楣；门框与外层石框分属不同深度 |
| 窄窗、后窗与侧门 | 普通玻璃板、石砖窗套、磨制安山岩窗底、外挑石砖窗台、橡木门 |
| 吊灯与安装点 | 灯笼、铁链、独立木托架；既有墙柱不因放灯而挖断 |
| 少量可见维修构件 | 橡木栅栏和半砖台面、空木桶、熔炉、锻造台、砂轮和少量花盆 |
| 外部铺地和沿墙植被 | 石砖、安山岩、少量砂砾与砂土，草方块、持久树叶、蕨和短草；不堆出独立景观体量 |

采用 Java 1.21.1 原版方块，执行[统一材料规则](<../../../README.md#建筑材料选择>)。玻璃接缝不以铁栏杆表达；细柱与灯座按需要采用墙系列。屋面、门廊和柱梁保持连续，灯具不替换结构构件。

本次用专门的双门框、分层屋檐、山墙边、窗套与托架坐标构建外观，复用范围仅限方块放置和 NBT 编码等底层工具。外观细部在导出前一次完成，不通过导出后反复检查和改型来追逐预览效果。

**编辑阶段不使用结构空位。** 室内外所有未放置构件的格子均写为空气；结构空位在后续手工调整完成后按需要添加。只覆盖同名 `building.nbt`，加载名称不增加第二个版本。
