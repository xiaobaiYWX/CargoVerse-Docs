## 作用与启用条件

本站固定配置制造台与一处生成点。已有注册领取与普通制造共用这一处生成点；原注册权益保持不变。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 现有 registration_point 通过注册终端提供，领取使用本生成点；与普通制造共用本站固定生成点 |
| 普通制造 | 固定配套制造台：能源备柜与退役源交接棚；详见[制造目录](<../定义设计/01_货柜制造台定义.md>) |
| 生成点 | 本站固定安装 1 处生成点，所有实际存在的制造／注册终端绑定同一点 ID |
| 生成位置 | HEC 专用生产附件的 24×24 露天场地；装卸按各方向功能页使用独立范围 |
| 制造任务 | Apollo 燃料化工柜 S／M；Reactor 屏蔽危货柜 M |
| 业务边界 | 普通制造消耗玩家实体材料与加工费；资源表货物不是制造材料；不自动修理、移柜或生产货物 |

普通燃料用 Apollo S／M；承接失效同位素源前准备 Reactor M。本站固定提供三款配套规格；更多罐柜在 E02、危废扩量规格在 E03 准备。

## 场地与结构

采用**赫利俄斯能源集团（HEC）· 红檐防护制造场 01**，同制造商站点共用一份模板。本站将该附件作为必需功能组件接入。原有整站文件尚未合入本附件，需以主接合口另行连接到站内道路；不直接覆盖原收发平台。

![HEC 制造附件实际 NBT](<../../../../../assets/images/trade_points/common/container_manufacturing/hec/open_yard_01/actual.png>)

灰色生产地坪与石砖防护棚，黑石柱架承托连续红色檐口；右后角为独立台基、阶梯挡墙与双排气造型立柱。红色陶瓦在棚檐、墙带、立柱色环和入口灯柱上重复出现，中央保持露天净空。 图片资产集中存放，由各站引用；完整平面、材料与提示词见[制造商模板说明](<../../../common/货柜生产附属结构/03_HEC_红檐防护制造场.md>)。

屋顶、框架、灯具和边栏位于生成空腔之外。设备位保留完整后缘，不用围栏封掉安装深度。定位点控制器需放在检测体积外，制造台朝向与实际占地后续按设备模型落实。

当前 NBT 只提供原版建筑与地面标识，不含模组终端、生成点、货柜实体、测试 UUID 或拼图绑定。现场需记录本附件原点、旋转以及控制器位置，再计算点位偏移；不能将上述局部坐标当成已完成配置。

## 与收发平台的分工

普通制造固定使用 HEC 生产附件的一处生成点。已有注册领取与普通制造共用这一处生成点；原注册权益保持不变。 装载和卸载按各自功能页配置范围，采用分离式场地时不得把本生产附件坐标写入装卸定位点。

成品按现场运输方式移至装卸区域或驶离，不增加自动移柜、排队或额外货物。

## 设备与绑定

制造台、实际存在的注册终端与生成点绑定本站同一实例 UUID；业务终端指向同一个生成点 ID。装载、卸载终端仍绑定同一实例，使用各自装卸点。

点位偏移按目标原点减控制器位置计算，每轴 -64..64，范围每轴 1..32。检测空腔须为空气且能容纳目标货柜；后续配置以旋转和落位后的世界范围为准。保存二十格空气不能代替相邻建筑、地形与现场点位的实际安排。

## 工坊布局与交付

燃料营业区边缘设空罐框架与隔离衬层工具架，真实材料台远离静态储罐；装饰替代为安全值班屋、备件棚、巡检工具房。

当前附属模板为 `common/container_manufacturing/hec/open_yard_01.nbt`，已交付独立 NBT，尚未合入本站整站文件。机器预留 5×4×6，另设操作位与 24×24 露天生产面；安装坐标见[本站货柜生成结构](<02_货柜生成结构.md>)。材料仍来自玩家背包与快捷栏，收发货继续使用原共用平台。已有注册领取与普通制造共用这一处生成点；原注册权益保持不变。

必备制造设施与随机装饰安排见[本站生成规则](<../生成规则/00_生成规则.md#附属工坊生成>)；目录、材料和加工费见[制造台定义](<../定义设计/01_货柜制造台定义.md>)。
