## 本次采用的单栋参考

一副连续木屋架下的开放制材厅与后部料库。 前部敞开作业，后部在同一屋顶下封闭为干燥料库。中央通道连通两区，短木料架及切石机收在屋檐内。

本站由独立经营者维护，不因经营内容或采购设备而套用制造商配色、站徽。

## 从参考到方块尺度

- 模板包围盒为 **24×18×22**（宽×高×深），水平仍为 24×22，包含屋檐、薄地基和外观附件。
- 以一格宽木柱、原版工作台面及人行通道判断局部尺度；木纹、砖缝和无法落成方块的细斜线不作为精确方块计数。屋架中的斜撑以楼梯、短梁和阶梯状椽木近似。
- 主屋范围 X=3～19、Z=4～18。前柱架 X=3、11、19，两个主开间围绕 X=11 对称；侧柱支承线为 Z=4、11、18。中段不增加落地中柱，保留开敞操作空间。
- 屋脊改为沿 Z 轴前后延伸，入口朝向开放山墙。木屋面的最低层 Y=8、屋脊 Y=17；前山墙横梁、吊柱和两侧短竖杆可见，后山墙封闭。
- 作业厅、料库和主要室外通路地坪均为 Y=1，取消首版的连续台阶。料库从 Z=12 起，中央入口 X=10～12，净宽三格、净高三格；两侧有打开的木门叶。
- 前部短木料架为 5×4 格，小锯台为 3×2 格；右前开间及中线保持通路，不把所有概念小道具塞入工作空间。
- 料库侧面采用两组 2×2 格窗，后部为成对 3×2 格窗；木窗台与窗楣单独制作，玻璃保持连续。

原右侧独立料库并入主屋后部，保持一个连续屋顶；不添加第二座建筑、长输送带或大型木堆。前山墙与屋架内部有意留空，用于表达敞开木棚，并非墙面漏封。屋面本身连续，檐口与料库墙顶有实体封口。

## 材料与构件对应

| 图中部位 | 本次原版方块选择 |
| --- | --- |
| 原木承重柱与石柱脚 | 带皮云杉原木、圆石和少量苔石；柱脚与木柱上下连续 |
| 桁架、横梁和前山墙 | 按轴向设置的去皮云杉原木、带皮云杉吊柱、短竖杆与外露椽木；不再用整片木板封住前山墙 |
| 主坡屋面与外缘 | 深色橡木楼梯和屋脊半砖；前后山墙边用云杉楼梯、倒置楼梯和端部木脊，区分瓦面与厚边 |
| 木托撑与柱头细部 | 云杉楼梯、短梁、薄云杉活板门箍片；支承落在柱梁交接处，不悬挂独立斜线 |
| 后部料库与门窗 | 橡木木板、云杉框架及打开的云杉门叶，纯玻璃板和外挑木窗台；不使用铁栏杆模拟玻璃缝 |
| 短木料架与木板垛 | 具有正确轴向的云杉原木、云杉栅栏支脚和半砖托条，木板垛保持低矮 |
| 小锯台 | 橡木倒置楼梯、上半砖台面和原版切石机；不预装模组加工设备 |
| 灯具 | 跨中铁链与灯笼，料库门前另设短木支架；灯具不替换完整柱梁 |
| 场地与沿墙植物 | 草地、砂土、少量土径、砂砾和圆石；树叶、蕨、短草和少量蒲公英形成低种植带 |

采用 Java 1.21.1 原版方块，执行[统一材料规则](<../../../README.md#建筑材料选择>)。玻璃接缝不以铁栏杆表达；细柱与灯座按需要采用墙系列。屋面、门廊和柱梁保持连续，灯具不替换结构构件。

本次按地坪、柱网、料库围护、屋架与木檐、短料架、锯台和照明逐项构建，复用范围仅为方块放置与 NBT 编码等基础工具。关键改动是屋脊方向和开放桁架，而非仅替换首版的木材颜色。

**编辑交付不添加结构空位。** 所有未占用格均保留为空气，结构空位由后续手工调整完成后添加。只覆盖原 `building.nbt`，沿用同一个加载名称；其余内部设备及营业功能继续留待后续配置。
