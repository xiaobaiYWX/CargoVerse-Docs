## 建筑制作参考（单栋版）

一副连续木屋架下的开放制材厅与后部料库。 前部敞开作业，后部在同一屋顶下封闭为干燥料库。中央通道连通两区，短木料架及切石机收在屋檐内。

本批以约 24 格的建筑尺度为准，优先保留一栋主建筑的完整柱网、墙窗、屋面与入口。附属功能合并到主屋内部、同屋架后部或同一建筑的开放开间，不将多栋建筑压缩叠放。

### 平面与构造

前柱架以 X=11 为中轴，立柱位于 X=3、11、19；侧柱位于 X=3、19，纵向支承线为 Z=4、11、18。Z=11 的中部不落地加柱，保留横向工作空间。料库从 Z=12 起，中央开三格宽、三格高通道，前部右开间可进入后再转入中线。

| 使用分区 | 建筑内位置（局部 X、Z，边界含端点） |
| --- | --- |
| 开放制材作业厅 | (3, 4) 至 (19, 11) |
| 同屋顶后部干燥料库 | (3, 12) 至 (19, 18) |
| 屋檐投影 | (2, 3) 至 (20, 19) |
| 短木料架 | (5, 5) 至 (9, 8) |
| 小锯台 | (16, 6) 至 (18, 7) |

基础、作业铺地、屋檐和木料附件均计入实际包围盒。屋脊沿 Z 轴，前山墙露出两道横梁、吊柱、短竖杆及斜向椽木；三角区有意保持开放，后山墙以木板封闭。深色橡木坡面与较亮云杉封边分开制作，长檐下有连续实木封口和托撑。灯具在柱梁完成后放入跨中空位，不覆盖立柱。料库的侧窗、后窗成组对齐，纯玻璃板不混入铁栏杆；不增加第二座建筑、长输送带或大型木堆。
