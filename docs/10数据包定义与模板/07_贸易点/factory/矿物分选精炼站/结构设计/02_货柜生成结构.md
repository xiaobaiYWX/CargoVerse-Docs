# 矿物分选精炼站 · 货柜生成结构

> **整站实物已更新（2026-10-01）：** 当前文件、整站坐标和设备配置见[整站导出实录](<00_结构总览.md#当前整站模板>)。本页保留业务安排、独立附件及导出前的安装方案；其中独立模板的局部坐标、旧尺寸和“待安装／未合入”状态不代表本批整站实况。


> 必备功能设计。采用已交付的制造商生产附件，尚未合入本站整站 NBT；设备、点位与实例绑定待接入。

## 作用与启用条件

每个完整贸易点都安装制造台与一处生成点。本站没有注册模块；只启用普通付费制造，不增加基础领取。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 当前没有注册模块，不新增基础领取 |
| 普通制造 | 固定配套制造台：精炼转运补柜台 |
| 生成点 | 安装 1 处有效生成点，制造台绑定同一点 ID |
| 生成位置 | DMC 生产附件的 24×24 露天生产面，与装卸作业范围分开 |
| 制造任务 | DMC Boreal 矿冶散料柜 M 型 |
| 业务边界 | 玩家实体物品与加工费；不使用贸易点库存，不增加材料转化或自动移柜 |

在本站制造 Boreal M，可运走铁精矿或铜精矿，也可准备下一批原矿运输。重金属滤渣属于危险货物，应先在 E03 准备 Reclaimer；Boreal 不能代替危废柜。

## 场地与结构

采用**深岩矿业集团（DMC）· 二层监控制造场 01**，同制造商站点共用一份模板。本站按必需业务组件拼接该制造附件。原有整站文件尚未合入本附件，需以主接合口另行连接到站内道路；不直接覆盖原收发平台。

![DMC 制造附件概念图](<../../../../../assets/images/trade_points/common/container_manufacturing/dmc/open_yard_01/concept.png>)

![DMC 制造附件实际 NBT](<../../../../../assets/images/trade_points/common/container_manufacturing/dmc/open_yard_01/actual.png>)

平整地面生产场后方为连续深色框架，首层安装制造设备，二层布置开放操作台和玻璃控制室。右侧两格净宽外梯直接连接梯顶平台与控制室东侧入口；黄色用于柱脚、栏杆柱和黄黑地面警戒，玻璃内不混入铁栅栏。 图片资产集中存放，由各站引用；完整平面、材料与提示词见[制造商模板说明](<../../../common/货柜生产附属结构/05_DMC_二层监控制造场.md>)。

制造台保持在首层，二层控制室只提供后续操作布置空间，不自动增加远程控制功能。屋顶、框架、楼梯、灯具和边栏位于生成空腔之外。设备位保留完整后缘，不用围栏封掉安装深度。定位点控制器需放在检测体积外，制造台朝向与实际占地后续按设备模型落实。

当前 NBT 只提供原版建筑与地面标识，不含模组终端、生成点、货柜实体、测试 UUID 或拼图绑定。现场需记录本附件原点、旋转以及控制器位置，再计算点位偏移；不能将上述局部坐标当成已完成配置。

## 设备与绑定

制造台、实际存在的注册终端与生成点绑定本站同一实例 UUID；业务终端指向同一个生成点 ID。装载、卸载终端仍绑定同一实例，使用各自装卸点。

点位偏移按目标原点减控制器位置计算，每轴 -64..64，范围每轴 1..32。检测空腔须为空气且能容纳目标货柜；后续配置以旋转和落位后的世界范围为准。保存二十格空气不能代替相邻建筑、地形与现场点位的实际安排。

## 工坊布局与交付

将 DMC 生产附件接在分选站检修侧，设备位与滤渣暂存区分开，保留矿柜内衬和固定件陈列。二层监控空间观察首层生产面；不把筛分或清污设备描述为制造材料来源。

本站没有注册模块；只启用普通付费制造，不增加基础领取。 设备位至少 5×4×6 并另设操作位，按本附件实际标高和朝向安装，材料及夹具陈列不得侵占生产空腔。
