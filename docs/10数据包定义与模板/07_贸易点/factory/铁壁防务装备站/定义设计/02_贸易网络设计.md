## 经营身份与职责

编号 **B01**；归属 **铁壁防务集团（BDS）**；资源 ID `cargoverse:factory/sky_station/defense_arsenal`。

**全新工具、防护与远行装备。** 供应矿镐、斧、锄、盾、箭与铜背罐；工具报价严格匹配默认全新状态，不收购损坏武器后自动当成新货。采购金属、皮革、火药与精密机构，形成装备工业上游。

本站保留既有货柜制造、注册与完整装卸功能；商品业务不改变结构、归属或生成规则。

## 业务边界

- 收购不增加本站库存，也不驱动本站产出；出售仅按本站库存与日补工作。
- 不将“废料”“设备”“研究样本”等用途名称作为额外货物身份；以实际物品 ID 和完整状态交接。
- 不设置全品类通吃目录。同站同一默认变体只经营一个方向，昂贵装备、研究与收藏需求有独立限额。
- 本轮不涉及流体、实体、带药效药水、装有内容的容器或任意损坏装备；它们需要明确的载荷支持或组件报价设计。
- 相同类别不代表相同报价，也不赋予市场资格。玩家自产货物在自然生成目的地成功出售时，也按本地收购配置获得许可证与繁荣度经验。
