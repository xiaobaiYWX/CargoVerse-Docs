# 铁壁防务装备站 · 货柜生成结构

> **整站实物已更新（2026-10-01）：** 当前文件、整站坐标和设备配置见[整站导出实录](<00_结构总览.md#当前整站模板>)。本页保留业务安排、独立附件及导出前的安装方案；其中独立模板的局部坐标、旧尺寸和“待安装／未合入”状态不代表本批整站实况。


> 已配套 BDS 制造商系列的独立货柜生产附属 NBT；实际落位、设备与绑定后续配置。本站制造与注册的启用条件按下文保留。

## 作用与启用条件

现有注册模块可发放基础货柜；规划必备的“防务装备封装工坊”提供普通制造。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 现有 registration_point 通过注册终端提供，领取使用本生成点；与普通制造共用本站固定生成点 |
| 普通制造 | 固定专业工坊：防务装备封装工坊；详见[任务与制造目录](<../定义设计/01_货柜制造台定义.md>) |
| 生成点 | 本站配置 1 个生成点；实际存在的注册终端／制造台各绑定此点 |
| 生成位置 | BDS 专用生产附件的 24×24 露天场地；装载与卸载继续使用本站原共用平台 |
| 制造任务 | Sentinel 安防装备柜 S／M；Bastion 驻防重装柜 L／X |
| 业务边界 | 普通制造消耗玩家实体材料与加工费；资源表货物不是制造材料；不自动修理、移柜或生产货物 |

Sentinel S／M 运弹药与小装备，Bastion L／X 运重炮并可拓展到巡逻艇；舰炮并非只能用大型柜，小柜许可与真实载重仍需玩家选择。

## 场地与结构

采用**铁壁防务集团（BDS）· 露天制造场 01**，同制造商站点共用一份模板。本站按必需业务组件拼接该制造附件。原有整站文件尚未合入本附件，需以主接合口另行连接到站内道路；不直接覆盖原收发平台。

![BDS 制造附件实际 NBT](<../../../../../assets/images/trade_points/common/container_manufacturing/bds/open_yard_01/actual.png>)

沿用首版已认可的深灰框架、绿色铜棚顶、外围护栏与黄黑警戒线；本次归入 BDS 系列，未重新改变其方块形体。 图片资产集中存放，由各站引用；完整平面、材料与提示词见[制造商模板说明](<../../../common/货柜生产附属结构/01_BDS_露天制造场.md>)。

| 模板尺寸 X × Y × Z | **31 × 22 × 31**；实体高 10 格，上部为空气净空 |

| 正面主接口 | Z=0、X=13…18，六格宽；邻接道路对齐 Y=1 地坪 |
| 左侧人员入口 | X=0、Z=13…16，四格宽，含石阶；沿边侧路线进入设备棚 |

屋顶、框架、灯具和边栏位于生成空腔之外。设备位保留完整后缘，不用围栏封掉安装深度。定位点控制器需放在检测体积外，制造台朝向与实际占地后续按设备模型落实。

当前 NBT 只提供原版建筑与地面标识，不含模组终端、生成点、货柜实体、测试 UUID 或拼图绑定。现场需记录本附件原点、旋转以及控制器位置，再计算点位偏移；不能将上述局部坐标当成已完成配置。

## 与收发平台的分工

货柜制造及实际存在的基础领取使用本附件的一处生成点。本站原 H 平台继续承担装载与卸载，两者使用自己的定位点及原共用范围；不再把本页的生成范围写入收发平台定位点。

成品生成后，按现场运输方式移到收发区域或驶离，不假设自动移柜、自动排队或额外产生货物。本站原平台形体与记录仍见[外观参考](<01_外观与装饰参考.md>)、[装载结构](<03_装载区域结构.md>)和[卸载结构](<04_卸载区域结构.md>)。

## 设备与绑定

制造台、实际存在的注册终端与生成点绑定本站同一实例 UUID；业务终端指向同一个生成点 ID。装载、卸载终端仍绑定同一实例，使用各自装卸点。

点位偏移按目标原点减控制器位置计算，每轴 -64..64，范围每轴 1..32。检测空腔须为空气且能容纳目标货柜；后续配置以旋转和落位后的世界范围为准。保存二十格空气不能代替相邻建筑、地形与现场点位的实际安排。

## 工坊布局与交付

装备库出货侧的固定架工位，弹药防潮内衬与舰炮缓冲托座分开示意；带防护侧墙的操作台朝向公共路，制造区不是第二座军械交易点。

当前附属模板为 `common/container_manufacturing/bds/open_yard_01.nbt`，已交付独立 NBT，尚未合入本站整站文件。机器预留 5×4×6，另设操作位与 24×24 露天生产面；安装坐标见[本站货柜生成结构](<02_货柜生成结构.md>)。材料仍来自玩家背包与快捷栏，收发货继续使用原共用平台。

必备制造设施、随机装饰和外观变体见[本站生成规则](<../生成规则/00_生成规则.md#附属工坊生成>)；目录、材料和加工费见[制造台定义](<../定义设计/01_货柜制造台定义.md>)。
