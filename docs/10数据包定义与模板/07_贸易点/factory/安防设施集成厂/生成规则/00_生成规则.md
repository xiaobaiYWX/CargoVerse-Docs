> **已接入数据包：** 本页是本站生成信息的维护入口。群系、权重、高度及共享布点参数由同步工具读取；不另设集中站点参数表。静态资源校核不代替新区块中的净空、分布和营业实测。

## 环境偏好与贸易联系

聚居区外围与工业航道，供应安防系统后外运至边境驻防站。

允许环境：平原、热带草原、森林、风袭森林。具体 ID 以下表为准，各候选群系同等允许；名单顺序不代表概率，本站不会在名单外的群系自然生成。

接收 H02 电子与光学材料、E01 电池，向 B03 供应安防系统和巡逻设施。 这些是货物目录与地域分布的联系，不是材料转化、邻站依赖或自动运输，也不保证交易伙伴相邻。

## 权重、间距与覆盖边界

全部天空站共用上述一组候选布点；spacing、separation 的单位为区块，1 区块为 16 方块。它们不是建筑外墙间距。当前共享网格作为调校基线，同一候选区至多生成一座天空站；本站没有独立叠加的布点组或排斥组。

本站权重只用于同一结构集内选型。群系不匹配或结构尝试失败后，会从剩余成员中重选，不能将本站权重除以全组权重直接写成最终出现率。地面站另用自己的布点组，本页不调整其参数，也不保证避开地面站、村庄或其他模组结构。

世界生成在生成点的 X/Y/Z 检查群系，不保证等于正下方地面 F3 显示的群系。基于原版主世界群系限制原版维度中的生成；其他模组维度复用这些群系时需自行覆盖放置规则。

## 悬空标高与净空

原版 single_pool_element 的 groundLevelDelta=1，模板底层为抽样高度减 1；平台面由模板内部坐标决定。本站最低模板底层 Y=191，最高抽样时顶部方块 Y=255，在原版主世界建造范围内。模板没有子拼图，不额外叠放旧主体、平台或制造附件。

没有地表投影、地形融合或覆盖整个占地的山体净空检测。四类高山群系（积雪山坡、尖峭山峰、冰封山峰、裸岩山峰）不纳入本轮天空站名单；其他群系及其边界仍可能靠近高山。含草甸、樱花树林、雪林或风袭地区的候选尤其需要检查平台底部和边缘，群系白名单不能保证无碰撞。

## 指令、发布与维护

```mcfunction
/place structure cargoverse:trade_point/factory/sky_station/security_works ~ ~ ~
/locate structure cargoverse:trade_point/factory/sky_station/security_works
```

指令用于检查模板与经济绑定，不代表已验证自然分布；`/place structure` 使用结构自身的高度规则，不会重新融合已生成地形。自然生成调整只作用于新区块，不会移动旧站或旧贸易点实例。

修改本页后，从模组工程目录运行 `node tools/structure-templates/sync-trade-point-runtime.cjs --worldgen-only`，只发布生成资源与生成记录，不重新导入模板、经济或制造配方。同一结构集的四项共享布点参数必须在成员页面保持一致，工具遇到冲突会停止；只改本站候选群系、权重和高度时无需同步改其他站。
