## 功能定位

**固定配套制造台**。船厂的主业是飞艇与港机，货柜属于配载服务。来港维修或提取大型部件的玩家可能顺便整备运输柜，但这里不再成为另一家完整货柜工厂。

Vulcan L 对应航电、叶轮和牵引车，Titan X 对应龙骨，Hermes M 对应较轻的普通零件装运。本站固定提供这些配载规格；更多规格在 A01／A02 准备。

目录围绕本站运输任务保留，不扩为制造商全系列；实体成本、许可、繁荣和调度点按现有配方执行。

## 货物任务与柜型选择

| 系列与规格 | 本地／关联航线中的用途 | 实际货物示例 |
| --- | --- | --- |
| Vulcan 精密工业柜 L | 本地航电、易碎叶轮和牵引车的常用专业规格 | 航电控制器、推进器叶轮、港区牵引车 |
| Titan 大宗结构柜 X | 已具备大型运输能力的龙骨承运者现场配载 | 飞艇龙骨模块 |
| Hermes 轻量化货柜 M | 普通叶轮／航电类兼容的低防护备选，需自行满足运输要求 | 推进器叶轮、航电控制器 |

柜型仅允许定义中的 CargoClass，不同货物不可混装；防护由现有 special_designs 决定，限时要求始终保留。

关联备柜节点：[A01 标准建材装配港](<../../标准建材装配港/定义设计/01_货柜制造台定义.md>)、[A02 通用机电装备厂](<../../通用机电装备厂/定义设计/01_货柜制造台定义.md>)。具体规格以各节点目录为准；这些节点分别补充不同任务，并非每个节点都覆盖本站全部型号，也不保证在地图上相邻。

## 定义与实例绑定

目标定义 ID：`cargoverse:factory/sky_station/airship_yard`；目标路径：`data/cargoverse/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/factory/sky_station/airship_yard.json`。以下定义已同步内置数据包。制造台、生成点与营业核心共用本站 UUID，不新增锚点、库存或第二个贸易点。

```json
{

    "min_prosperity_level": 0,
    "definitions_pool": [
      {
        "weight": 1,
        "definition": "cargoverse:factory/sky_station/airship_yard"
      }
    ]
  }
}
```
