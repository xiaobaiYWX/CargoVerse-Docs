## 建筑制作参考（单栋版）

铜绿坡屋顶、浅色石墙的单栋净水泵房。 控制、封装与缓冲设备的位置集中在屋内，门前保留封闭井盖与通路，右侧短管表达净水用途。

本批以约 24 格的建筑尺度为准，优先保留一栋主建筑的完整柱网、墙窗、屋面与入口。附属功能合并到主屋内部、同屋架后部或同一建筑的开放开间，不将多栋建筑压缩叠放。

### 平面与构造

主屋 X=3～19、Z=8～18；门厅 X=12～19、Z=5～7，前伸三格。主山墙中轴 X=11，小门厅以 X=15.5 为中轴，双扇门、木门框和小坡屋面围绕同一轴线排列。两个体块使用同一地坪，连接处开出四格宽通道，不留下两堵重叠的封闭墙。

| 使用分区 | 建筑内位置（局部 X、Z，边界含端点） |
| --- | --- |
| 净水主屋 | (3, 8) 至 (19, 18) |
| 前伸双门厅 | (12, 5) 至 (19, 7) |
| 封闭井盖 | (4, 2) 至 (7, 4) |
| 主屋檐投影 | (2, 7) 至 (20, 19) |
| 门厅屋檐投影 | (11, 4) 至 (20, 7) |

基础、门前铺地、屋檐和净水外观构件均计入实际包围盒。主屋面为铜绿坡面，下设独立深木色山墙边、实木檐口与托架；小门厅具有完整的墙、双扇门和独立小山墙。玻璃使用连续玻璃板，外挑石窗台与窗楣分别制作。柱梁先于灯具放置，吊灯与链条只占原有空气，不截断白色壁柱或石柱。低井盖封闭、管道为外观构件，不含水源或实际流体管网；室内设备仍留待后续布置。
