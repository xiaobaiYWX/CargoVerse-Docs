## 从参考到方块尺度

- 模板包围盒为 **24×18×22**（宽×高×深），包含基础、屋檐、管道和植被；水平仍保持 24×22。
- 先用两格高的门扇确定人行尺度，再分别安排门上亮窗、门楣、低门厅与高山墙。图中砖纹、铜锈斑点和玻璃反光不作为方块边界，也不加进额外柱网。
- 主屋 X=3～19、Z=8～18；门厅 X=12～19、Z=5～7，向前伸出三格。两者是同一建筑的紧密连接部分，内部以四格宽、四格高通道相通。
- 主屋、门厅地坪均为 Y=2，室外铺地 Y=1；门前用楼梯方块连接一格高差。双门及其两侧木框以 X=15.5 对齐，小门厅坡屋面采用同一半格轴线。
- 主山墙中轴 X=11，铜屋面檐口 Y=8、屋脊 Y=17；门厅屋面檐口 Y=7、双格屋脊 Y=11。保留高低体块和前后关系，不再以一块平雨棚代替图中的小门厅。
- 正面窗为 5×3 格，右侧主要窗为 4×3 格；后墙两扇 2×2 窗按主屋中轴成对排列。纯玻璃板、石窗台和窗楣分别制作，图中的细窗缝不转为铁栏杆。

本次保留一栋净水泵房，不增加独立储罐或附属棚。井盖降低为可辨识的薄石边盖板，右侧短管有落地支点、弯头和贴墙接口；屋内留空供后续布置设备，不写入水源、流体管网或容器库存。

## 材料与构件对应

| 图中部位 | 本次原版方块选择 |
| --- | --- |
| 铜绿主坡面与门厅小坡面 | 涂蜡锈蚀切制铜楼梯、台阶和端部整块；少量涂蜡氧化切制铜形成小片颜色变化，避免密集随机混色 |
| 山墙下沿、檐口与托架 | 深色橡木楼梯、半砖与横向去皮深色橡木；山墙边独立于铜瓦，低檐用实木连续封口 |
| 浅色墙体和正面凸壁柱 | 方解石墙面、平滑石英壁柱和局部窗楣；保持大面积浅墙，不套用制造商品牌色 |
| 柱脚、角柱、窗台与入口台阶 | 石砖、磨制安山岩，窗台采用上半部楼梯，窗楣采用上半砖，背后有实墙封口 |
| 大窗、后窗与双门 | 普通玻璃板、云杉双门、去皮云杉门框；两格高门扇上保留一格玻璃亮窗 |
| 低井盖 | 石砖半砖围边、下方磨制深板岩封底、闭合铁活板门盖板；不留开放井洞 |
| 短管与贴墙接头 | 涂蜡锈蚀切制铜、铜楼梯、涂蜡雕纹铜接口及涂蜡锈蚀铜活板门小阀面；安山岩支脚 |
| 檐下灯与地面灯座 | 灯笼、铁链、独立木托架、石砖墙方块矮灯柱；不以灯笼替换结构柱 |
| 铺地与沿墙绿化 | 石砖为主，少量安山岩、圆石与砂土；草方块、持久树叶、短草和蕨形成窄种植带 |

采用 Java 1.21.1 原版方块，执行[统一材料规则](<../../../README.md#建筑材料选择>)。玻璃接缝不以铁栏杆表达；细柱与灯座按需要采用墙系列。屋面、门廊和柱梁保持连续，灯具不替换结构构件。

本次按主屋、前伸门厅、屋面与深木封边、窗套、井盖和短管分别建立构件坐标，仅复用基础方块放置与 NBT 编码。灯具最后放到明确的空位和独立支座上。概念中的极细饰条及亚方块纹理使用原版方块的形状和材质近似，不把噪点识别成新设施。

**编辑阶段不添加结构空位。** 室内、门厅、通路和室外未占用格均为空气，结构空位由后续手工修改完成后添加。本次覆盖原 `building.nbt`，沿用原加载名称，不增加第二个版本入口。
