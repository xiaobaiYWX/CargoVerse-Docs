## 收售概览

出售：复合肥料、工业润滑油、密封树脂、萤石发光粉、下界石英晶簇、废酸回收桶。

收购：无。

货物标签、逐项初始库存、容量和日变化统一见关联资源表；两侧各自维护库存。

## 建议结构内容

**建筑形象：**浅灰封闭罐区、橙色管线和分色标签；地表建筑以整齐隔间体现管理。

| 建筑／分区 | 建议内容 |
| --- | --- |
| 化学品成品仓 | 肥料袋、润滑油桶、密封树脂桶按货物形态分别陈列。 |
| 特殊材料间 | 萤石发光粉与下界石英晶簇使用独立密封箱架。 |
| 废酸外运仓 | 废酸桶单独设置装货隔间，与普通产品通道隔开。 |
| 静态工艺设备区 | 储罐、混合塔和管线只表达生产背景，不增加原料收购或转化功能。 |

**行走与装卸路线：**营业入口 → 成品装货核心 → 隔离展示区；本站仅出售，不设置实际卸货终端。

**最小可营业核心：**贸易点信息柜（唯一注册锚点）、仓库信息柜、货柜装载机。保留装货操作区；本站没有收购目录，不设置可用的卸货终端。基础泊位须满足实际货柜尺寸与净空，不能只用展示货柜代替。必要终端及最低泊位集中在不会因可选支路缺失而失效的营业核心中。

**可选扩展：**可选添加防护围堰、检验亭与备用罐座。

以上陈列、工艺设备与建筑用途为美术和空间建议。除已绑定的业务终端外，不自动新增 NPC、加工、气候、库存或货物产出机制。首版没有绑定商店或货柜制造台，不把展厅、柜台或车间当成已接入这些功能。

## 功能与结构

首版 `modules: {}`，不额外绑定注册点。

首版不绑定物品商店和货柜制造台；现有默认演示模块的商品与配方不能直接代表本节点。后续按各制造商单独设计这些功能。

结构需设置一个贸易点信息柜注册锚点、货柜装载机、仓库信息柜、对应货柜的装卸泊位。所有终端绑定同一实例 UUID。

地图距离和环境危害需要在结构落点时确定；内容投放阶段不提供代码级许可、科技或区域准入限制。
