# 通用机电装备厂 · 精密工业柜装配间

> 2026-10-01 已同步内置数据包：本站固定制造目录（6 条配方）及模块绑定已落地。整站通过指令生成时关联本站实例，自然投放规则已同步内置数据包；实机制造待验收。

## 结构与生成入口

[工坊布局、生成点与设备安装](<../结构设计/02_货柜生成结构.md#工坊布局与交付>) · [世界生成与附属工坊规则](<../生成规则/00_生成规则.md>)。本页维护服务定位、柜型目录、配方和功能绑定。

## 功能定位

**固定专业工坊**。自动装卸机和精密机床从本站发出，轴承、液压件和传感器构成进出货的核心。本站承担需要缓冲、防潮的工业柜，而非 AUI 全系列商店。

接精密整机单时制造 Vulcan；只运普通液压件或常规小批零件时可选 Hermes，接受其没有专用防护的限制。大宗建材柜在 A01 准备。

不提供 Atlas、Nomad、Titan 全目录；不把 Hermes 宣传成具备 Vulcan 防护。

## 货物任务与柜型选择

| 系列与规格 | 本地／关联航线中的用途 | 实际货物示例 |
| --- | --- | --- |
| Vulcan 精密工业柜 M／L／X | 本站精密整机出货，并支撑飞艇、测绘和巡逻艇运输 | 精密机床、自动装卸机、测绘无人机 |
| Hermes 轻量化货柜 S／M／L | 普通零件与跨类补给的灵活配载选择，保留货物原有要求 | 液压执行缸、标准传动齿轮、航电控制器 |

柜型仅允许定义中的 CargoClass，不同货物不可混装；防护由现有 special_designs 决定，限时要求始终保留。

关联备柜节点：[A01 标准建材装配港](<../../标准建材装配港/定义设计/01_货柜制造台定义.md>)、[S02 远航货运枢纽](<../../../market/远航货运枢纽/定义设计/01_货柜制造台定义.md>)。具体规格以各节点目录为准；这些节点分别补充不同任务，并非每个节点都覆盖本站全部型号，也不保证在地图上相邻。

## 定义与实例绑定

目标定义 ID：`cargoverse:factory/sky_station/modular_equipment`；目标路径：`data/cargoverse/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/factory/sky_station/modular_equipment.json`。以下定义已同步内置数据包。制造台、生成点与营业核心共用本站 UUID，不新增锚点、库存或第二个贸易点。

合入 `modules` 的片段（保留本站其他功能）：

```json
{
  "cargo_manufacturing_platform": {
    "min_prosperity_level": 0,
    "definitions_pool": [
      {
        "weight": 1,
        "definition": "cargoverse:factory/sky_station/modular_equipment"
      }
    ]
  }
}
```
