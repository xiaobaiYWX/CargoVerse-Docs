# 工业化学品供应站 · 货柜生成结构

> 功能安装设计；保留已有平台结构，本轮未放置业务方块或修改实例绑定。具备相关服务的设计前提不等于现场已可生成。

## 作用与启用条件

规划固定工坊交付普通货柜。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 当前定义没有 `registration_point`；不安装对外注册／领取终端 |
| 普通货柜制造 | 本站规划必需的品牌制造工坊；目录与结构仍按制造方案接入 |
| 实际生成位置 | 本站唯一共用平台；注册终端或工坊可位于营业楼／附属建筑内，不在其房间里生成货柜 |
| 生成点数量 | 配置 1 个 `cargoverse:container_spawn_point`，所有本站生成服务复用此点 |
| 制造设计入口 | [本站配方与制造服务](<货柜制造台定义.md>)；不以有无工坊改变既有基础注册权益 |

“货柜生成结构”指交付空货柜所需的场地和定位设备；普通制造消耗实体材料与加工费，平台本身不持续产柜。

## 场地与结构

| 项目 | 本站安排 |
| --- | --- |
| 平台结构 ID | `cargoverse:factory/chemical_works/cargo_platform` |
| 平台文件尺寸 X × Y × Z | 33 × 5 × 31；此值为结构文件包围盒，不是货柜定位范围 |
| 交付方式 | 整站已含一座平台，独立文件为同平台编辑组件，正常加载只放整站 |
| 坐标基准 | 本站 `station.nbt` 的局部坐标，不是世界坐标；整站与组件坐标不得混用 |
| 建议作业范围 | (34, 3, 3) → (58, 22, 27)，含两端；尺寸 **25 × 20 × 25** |
| 地板与净空 | 起始 Y=3 为第一层空气，地板在 Y=2；地板和齐平 H 标线不计入检测体积 |

范围沿用既有共用作业空间记录，作为本轮安装初稿；尚未验证设备放置与现场净空。完整平台、设备带和通路见[本站外观与模板记录](<01_外观与装饰参考.md>)。定位点控制器坐标、偏移值与旋转后世界范围仍待实装记录；不把预留区写成已经完成的定位点配置。

延续 HEC 能源设施的围堰和独立设备基座，红黑色用于局部识别；罐体、管桥、冷却构件不跨越货柜范围，人员有直接的外围退路。

生成点布置在甲板边缘的检修位，位于上述生成体积外；原有灯具、围栏、设备棚柱及标牌同样放在范围外。营业区或工坊到此处保留至少 3 格宽人员路线，玩家可在边缘看见交付货柜并进入操作位置。

## 设备与绑定

- 生成点与实际服务终端绑定同一贸易点实例 UUID：经济定义 `cargoverse:factory/chemical/chemical_works`。主信息柜锚点沿用本站营业区，平台不再设置第二个主锚点。
- 本站实际提供的制造台绑定这一个生成点 ID；当前不安装注册领取终端；装载、卸载仍使用各自类型的定位点，不能用生成点代替。
- 点放好后，用“目标范围原点减定位点位置”得到偏移，每轴限 -64..64；范围每轴限 1..32。若设备带位置不满足偏移限制，调整定位点位置。
- 生成检查要求**整个生成范围**为空气且不与已有物理结构相交；台阶、设备和现有空柜都不能留在范围内。货柜模板还必须完整放入，已加载区块与世界边界也需有效。
- 设备绑定、自然生成时的实例初始化与定位点 ID 写入按现有制作规范处理；不要将测试世界 UUID 或绝对定位点 ID 固化到可复用模板。

## 使用顺序与接入核对

玩家在实际存在的工坊提交制造；空出平台后交付货柜，再将货柜用于装卸或运走。已有货柜占用时先移走，不假定有自动移柜、排队或作业互锁功能。

接入时用本站可发放的货柜验证尺寸与空场生成；同一范围放入方块或已有货柜时应拒绝生成。普通制造失败不得消耗材料或加工费。检查旋转后的点位、净空及人员路线；未配置注册模块时不宣称可领取基础货柜。
