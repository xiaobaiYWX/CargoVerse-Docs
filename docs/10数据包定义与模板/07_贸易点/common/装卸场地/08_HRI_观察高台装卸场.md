# HRI · 观察高台装卸场 01

地平线研究院的装载场与卸载场各提供一份独立 NBT，占地 **30×28 格**，各有完整 **16×16 露天作业面**。灰白石材作为主体，蓝色用于地面标识、角标和棚檐；后侧及右后侧形成高两格的观察台，前右侧布置低矮监测构件。

## 概念与尺度依据

![HRI 观察高台装卸场统一概念图](<../../../../assets/images/trade_points/common/cargo_yards/hri/concept.png>)

参考板由内置图片生成功能制作，[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/hri/concept_prompt.txt>)随资产保存。以主视图中的两级台阶、单格柱脚、栏杆和小棚柱跨校准，落地小棚为 7×7，后台进深七格，操作通路保留三格。图中的数字、附加英文名称与口号不作为尺度或制造商定义。

保留主视图的浅色作业面和蓝色十字（＋）／空心方框（□）；用途由图形区分，不使用降落场 H。标识外接 8×8、笔画两格，方框内为 4×4 浅色底。作业地坪与前侧接入统一齐平，参考图中的抬高效果集中在外围观察台，避免增加转运门槛。

装载场右前方为定向监测台，卸载场改为围绕小型样品台的检查框。两者仅是原版方块构成的外观设施，不横跨货柜平台，也不代表新增自动检测功能。后右玻璃棚、后左细监测杆与侧通路沿用同一布局。

## 按部位落实材料

| 图中部位与形状 | 实际方块 | 状态与用途 |
| --- | --- | --- |
| 灰色基础、挡墙与观察台 | 石砖、磨制安山岩、平滑石 | 完整支承；观察台高两格，接入采用石砖楼梯 |
| 浅色作业面与小仪器外壳 | 平滑石英、白色混凝土 | 中央作业面平整，仪器外壳只在场外 |
| 蓝色图形和识别条 | 蓝色混凝土 | 用于十字／方框、短角标和棚檐，不覆盖整个主体 |
| 细栏杆墩 | 安山岩墙 | 四向连接与中柱按几何明确设置 |
| 透明护栏 | 淡灰色染色玻璃板 | 显式连接；梯口断开，不掺入铁栅栏模拟玻璃缝 |
| 棚架与后部玻璃屏 | 磨制深板岩、灰色染色玻璃块 | 连续深色柱梁；玻璃屏位于设备预留以外 |
| 薄平棚顶 | 平滑石及其台阶 | 台阶有完整基层，柱梁交界连续 |
| 监测杆 | 磨制深板岩墙、磨制玄武岩 | 墙作细杆，横向玄武岩按 X 轴；短末地烛作天线 |
| 挡墙与杆顶光源 | 海晶灯 | 挡墙灯只装于非柱位，全部在作业范围外 |
| 独立端柱光源 | 珠光蛙明灯 | `axis=y`，支承完整 |
| 棚下灯与仪器短天线 | 末地烛 | 明确朝向，位于空格，不替换连续柱梁 |
| 检修地面板 | 涂蜡斑驳铜格栅 | `waterlogged=false`，下方基础封底 |
| 日光检测面板 | 阳光探测器 | 初始 `inverted=false,power=0`，加载后按原版环境更新；不接入贸易业务 |

全部方块来自 Minecraft Java 1.21.1 原版，排除铁块、金块、钻石块、下界合金块、绿宝石块和信标。模组终端、定位点、库存及实例绑定留待现场安装。

## 标高、尺寸与接口

两份模板采用相同局部坐标，正面朝 -Z，范围含两端。

| 项目 | 两份模板共用尺寸／坐标 |
| --- | --- |
| 文件尺寸 X × Y × Z | **30×22×28**；保存高度包含作业空气 |
| 实体高度 | **13 格**，最高为监测杆顶灯 |
| 首层地坪／观察台地坪 | **Y=1／Y=3**，相差两格 |
| 16×16 露天作业面 | **X=3…18、Z=2…17** |
| 16×20×16 作业空腔 | **(3, 2, 2) → (18, 21, 17)** |
| 高台设备位 | **(24, 4, 22) → (26, 6, 26)**，3×3×5 |
| 高台操作位 | **(20, 4, 22) → (22, 6, 26)**，3×3×5 |
| 首层三格侧通路 | X=20…22、Z=1…18，Y=1 |
| 三格前梯 | X=11…13；Z=19 下级 Y=2、Z=20 上级 Y=3，朝 +Z 上行 |
| 后側六格道路梯口 | X=8…13；Z=27 下级 Y=2、Z=26 上级 Y=3，朝 -Z 上行；外接地面 Y=1 |
| 正面六格接入 | X=8…13、Z=0，石阶 Y=1 |
| 后右小棚 | X=23…29、Z=21…27，7×7；屋顶基层 Y=8，台阶压顶 Y=9 |
| 前右监测／检查构件 | X=24…28、Z=3…10；短天线及小面板另在相邻外沿 |
| 装载终端／定位点 | `cargoverse:container_loader`／`cargoverse:container_loading_point` |
| 卸载终端／定位点 | `cargoverse:cargo_unloader`／`cargoverse:container_unloading_point` |

**货柜作业空气从 Y=2 开始，高台设备与操作空间从 Y=4 开始。** 地板、角标和齐平灯不计入作业体积。人员沿首层三格通路经前梯到观察台，也可通过后侧六格道路梯口接入；设备控制面朝西侧操作位。两份场地分别配置对应定位范围，再绑定同一贸易点实例，不因标高和局部坐标相同而合并世界范围。
