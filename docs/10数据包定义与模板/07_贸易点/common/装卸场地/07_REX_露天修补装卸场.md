# REX · 露天修补装卸场 01

遗民贸易协会的装载场与卸载场分别提供独立模板，每份占地 **30×28 格**，各有完整 **16×16 露天作业面**。全场采用单层开放布局，以不同氧化阶段的涂蜡铜板、旧石砖、深色石材及少量木板表现成片修补，保持铺装齐平，不以真正的缺口模拟损坏。REX 无固定品牌色，保留回收材料本色。

## 概念与尺度依据

![REX 露天修补装卸场统一参考图](<../../../../assets/images/trade_points/common/cargo_yards/rex/concept.png>)

参考板由内置图片生成功能制作，[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/rex/concept_prompt.txt>)随资产保存。主视图决定布局：前左作业面、右侧整理带、后左矮料架、后右空置设备位和两根偏置吊灯杆。整片场地不设屋顶或横跨作业区的吊架。

以一格宽栏杆端柱、两层矮架及前侧单级入口相互校准，并用三格人员通路、七格宽料架和设备预留核对平面容量。参考图的数字与纹理接缝不直接当作测量结果，右侧局部重复围栏收敛为一条完整外围边界。料架中的小杂物只保留为少量铜板样件，不复制图像噪点。

装载场使用齐平白色十字（＋），卸载场使用齐平白色空心方框（□）；外接范围 8×8、笔画厚两格，方框内部保留 4×4 修补底色。外围白线保持完整，H 仅用于降落场。右前部装载模板设置两个托盘、砂轮与切石机；卸载模板采用分格矮槽、铜格栅、空炼药锅与砂轮。

## 按部位落实材料

| 图中部位／可见形状 | 选用方块 | 必要状态与构造 |
| --- | --- | --- |
| 连续地基与旧石铺装 | 石砖、裂纹石砖、磨制安山岩、深板岩砖及裂纹深板岩砖 | 完整方块齐平铺设，裂纹只来自材质 |
| 铜质补板 | 涂蜡铜块、涂蜡斑驳铜块、涂蜡锈蚀铜块、涂蜡氧化铜块及对应切制铜 | 按几格宽的矩形补片错接，保留不同铜色，全部涂蜡 |
| 短木板修补条 | 云杉木板、深色橡木木板 | 仅少量连续短条，不在通路挖洞 |
| 细石栏 | 石砖墙 | 四向连接与中柱按端点、直段明确写入 |
| 木栏与铜质端墩 | 深色橡木栅栏、涂蜡切制铜、石砖 | 材质换段通过完整端墩连接，不将两种细栏直接硬接 |
| 后侧矮料架 | 去皮深色橡木原木、云杉木板及台阶 | 两层有支承的搁板，整体低于灯杆，样件少量放置 |
| 回收灯杆及偏置吊灯 | 去皮深色橡木原木、锁链、灯笼 | 横臂沿 X 轴，锁链沿 Y 轴，灯笼 `hanging=true`；不替换立柱 |
| 周界标灯 | 涂蜡氧化铜灯 | `lit=true,powered=false`；安装在独立端墩上 |
| 装载托盘与板样 | 云杉木板、涂蜡切制铜台阶 | 实心木底托住铜台阶，托盘远离人员通道 |
| 卸载分拣槽 | 石砖、裂纹石砖、涂蜡铜板、涂蜡锈蚀铜格栅 | 槽底完整、围边低矮；格栅 `waterlogged=false`，下方有封底 |
| 外露维护工具 | 砂轮、切石机、空炼药锅 | 保留原版交互，不预置库存、物品或加工进度 |

方块来自 Minecraft Java 1.21.1 原版，未使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。原版维护构件仅表达场地用途，模组终端与业务绑定仍留待现场配置。

## 标高、尺寸与接口

两份模板采用相同局部坐标，正面朝 -Z，范围含两端。

| 项目 | 两份模板共用尺寸／坐标 |
| --- | --- |
| 文件尺寸 X × Y × Z | **30×22×28**；保存高度包含作业空气 |
| 实体高度 | **9 格**，最高为后部灯杆横臂 |
| 作业及人员地坪 | **Y=1** |
| 16×16 露天作业面 | **X=3…18、Z=3…18** |
| 16×20×16 作业空腔 | **(3, 2, 3) → (18, 21, 18)** |
| 后右设备位 | **(24, 2, 20) → (26, 4, 24)**，3×3×5 |
| 后右操作位 | **(20, 2, 20) → (22, 4, 24)**，3×3×5 |
| 三格右侧通路 | X=20…22、Z=1…26，Y=1 |
| 后侧六格道路接口 | X=9…14、Z=27，Y=1 |
| 前侧六格台阶入口 | X=8…13、Z=0，Y=1，朝 +Z 上行 |
| 后左料架 | X=2…8、Z=23…25；装载为连续搁板，卸载为错高搁板 |
| 右前整理带 | X=23…28、Z=3…12；仅用于附属布景与原版维护构件 |
| 装载终端／定位点 | `cargoverse:container_loader`／`cargoverse:container_loading_point` |
| 卸载终端／定位点 | `cargoverse:cargo_unloader`／`cargoverse:container_unloading_point` |

作业空气从 **Y=2** 开始，地坪和白色印花不计入检测体积。人员从后侧道路沿三格右侧通路到操作位，设备控制面朝西。两份场地分别配置对应方向的定位范围，绑定同一贸易点实例；设备、操作空间和整个作业面均保持露天，灯杆及料架退出飞行净空。
