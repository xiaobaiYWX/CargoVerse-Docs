# DMC · 矿务转运装卸场 01

深岩矿业集团的装载场与卸载场分别交付独立 NBT。每份占地 **32×28 格**，提供 **16×16 露天作业面**，侧边操作台比作业地坪高两格，经三格宽台阶接入。装载场使用白色十字（＋），卸载场使用白色空心方框（□），不使用降落场的 H 标识。

## 概念与尺度

![DMC 矿务转运装卸场统一概念图](<../../../../assets/images/trade_points/common/cargo_yards/dmc/concept.png>)

本次使用内置图片生成功能制作一张统一参考板，见[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/dmc/concept_prompt.txt>)。按两格基础、两级台阶、三格通道和设备空间校准落地尺寸；图中的透视、文字标注及附加英文口号不作为尺寸或业务定义。装载始终对应贸易点出售、玩家购买，卸载对应贸易点收购、玩家出售。

装载场的右侧是低操作台、连续铜顶设备棚，后方设小型样本槽与砂轮；卸载场的左侧采用前低后高的铜顶棚、短风道与侧向铜格栅，后方放置空炼药锅和切石机。两份模板的作业面均在首层，操作台上的构件不伸入其上方。主体以灰色凝灰岩、安山岩与黑石承托，黄黑条纹集中在作业边缘，铜材保持自身颜色。

## 按部位落实材料

| 图中部位与形状 | 实际方块 | 状态与用途 |
| --- | --- | --- |
| 灰色基础、台缘和铺装 | 凝灰岩砖、磨制凝灰岩、雕纹凝灰岩砖、磨制安山岩、安山岩 | 完整方块承托；三格宽台阶使用凝灰岩砖楼梯 |
| 细石质护栏 | `tuff_brick_wall` 凝灰岩砖墙 | 按端点、直段及转角明确写入四向连接和中柱状态，不以整块加半砖替代 |
| 灯杆细柱 | `polished_blackstone_wall` 磨制黑石墙 | 独立细柱，蛙明灯下有连续支承 |
| 棚架柱梁 | 磨制玄武岩、磨制黑石砖 | 玄武岩 `axis=y`；柱网避开设备位与通路 |
| 铜板棚顶和风道 | 涂蜡锈蚀切制铜及其台阶，局部涂蜡斑驳切制铜 | 铜台阶均有完整基层承托；卸载棚高差处有实心封口 |
| 检修边带、侧屏及后屏 | `waxed_weathered_copper_grate` 涂蜡锈蚀铜格栅 | `waterlogged=false`；作为真实镂空构件使用 |
| 场地暖色照明 | `ochre_froglight` 赭黄蛙明灯 | `axis=y`；分别安装在地面与操作台灯柱上 |
| 棚下细条照明 | `end_rod` 末地烛 | `facing=down`，位于棚底空格，不替换柱梁 |
| 后侧入口指示灯 | `waxed_oxidized_copper_bulb` 涂蜡氧化铜灯 | `lit=true,powered=false`，以铜灯保存的点亮状态提供照明 |
| 装载后侧样本及维护构件 | 砂砾、凝灰岩砖样本槽、砂轮 | 砂砾下有支承；砂轮 `face=floor,facing=north` |
| 卸载后侧验收及维护构件 | 空炼药锅、切石机 | 保留原版交互；切石机 `facing=north`，不附带库存或业务配置 |
| 中心印花和警戒 | 白色、黄色、黑色混凝土 | 十字或方框外接 8×8，笔画厚 2 格；方框内部为 4×4 底色，全部齐平 |

镜像卸载场时同步变换墙连接和方块朝向。原版外露工具可交互，但不代表安装了货柜装载机、卸载机或其他贸易点业务设备。没有容器库存、配方进度、实体或实例绑定数据。

所有方块均来自 Minecraft Java 1.21.1 原版，未使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。

## 尺寸、标高与接口

| 项目 | 装载场 | 卸载场 |
| --- | --- | --- |
| 文件尺寸 X × Y × Z | **32×22×28** | **32×22×28** |
| 实体高度 | **11 格** | **12 格**；含短风道 |
| 首层地坪／侧台地坪 | **Y=1／Y=3** | 同左 |
| 16×16 作业面 | X=3…18、Z=4…19 | X=13…28、Z=4…19 |
| 16×20×16 作业空腔 | **(3, 2, 4) → (18, 21, 19)** | **(13, 2, 4) → (28, 21, 19)** |
| 设备位 | **(27, 4, 13) → (29, 6, 17)**，3×3×5 | **(2, 4, 13) → (4, 6, 17)**，3×3×5 |
| 操作位 | **(24, 4, 13) → (26, 6, 17)**，3×3×5 | **(5, 4, 13) → (7, 6, 17)**，3×3×5 |
| 三格地面侧通路 | X=20…22、Z=1…26，Y=1 | X=9…11、Z=1…26，Y=1 |
| 两级台阶 | X=26…28、Z=2…3，阶梯 Y=2…3，朝 +Z 上行 | X=3…5、Z=2…3，阶梯 Y=2…3，朝 +Z 上行 |
| 后侧道路接口 | X=8…13、Z=27，六格宽，Y=1 | X=18…23、Z=27，六格宽，Y=1 |
| 正面台阶接口 | X=8…13、Z=0 | X=18…23、Z=0 |
| 终端／定位点 | `container_loader`／`container_loading_point` | `cargo_unloader`／`container_unloading_point` |

坐标均为本方向独立 NBT 的局部坐标，含端点，正面朝 -Z；功能方块使用 `cargoverse` 命名空间。**货柜检测从首层 Y=2 开始，设备与操作空间从侧台 Y=4 开始**，两者标高分别记录，不能照抄 DMC 货柜制造附件或旧整站坐标。文件高度包含二十格作业空气，不等于实体建筑高度。

公共路线从后侧道路沿三格地面通路到前方两级台阶，再进入操作台。设备控制面朝人员操作位；模组设备、控制器、朝向、模型外伸和范围偏移留待现场安装。两份场地各自设置检测范围，绑定同一贸易点实例；灯柱、栏杆、棚顶及工具均不占用中央作业净空。

## 适用站点与交付

重工材料与矿机厂、矿物分选精炼站、深岩露天矿站均已有出售与收购业务，可按各自两份功能页接入。本次不修改资源规则、制造资格或领取条件。原整站、共用平台与货柜制造附件保留原文件，独立场地按现场布局拼接。

装载场：

```text
cargoverse:common/cargo_yards/dmc/loading_yard_01
```

卸载场：

```text

```
