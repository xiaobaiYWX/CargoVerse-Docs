# VBS · 绿植高台装卸场 01

绿洲农业联盟的装载场与卸载场分别提供独立模板。每份占地 **32×28 格**，首层保留 **16×16 露天作业面**；后侧采用无屋顶的开放操作台，地坪比作业面高五格。装载场以种植床与堆肥桶为特征，卸载场将前侧种植床改为浅水槽，搭配空炼药锅和铜活板门整理台。

## 概念与尺度依据

![VBS 绿植高台装卸场统一概念图](<../../../../assets/images/trade_points/common/cargo_yards/vbs/concept.png>)

参考板由内置图片生成功能制作，[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/vbs/concept_prompt.txt>)随资产保存。两份模块沿用同一平面关系：前左作业面、右侧低矮种植床、后侧开放高台和右侧直梯。主视图决定构图，图中尺寸文字不直接作为测量结果。

尺度以三格净宽直梯的五次整格上升、单格柱脚与低墙栏杆相互校准。后侧操作台深七格，扣除前后护栏后有五格可用进深；两种模板均不增设棚屋或温室。树叶只在台下和外围形成低矮绿化，保持柱网、入口和楼梯清晰。

装载场中心使用齐平白色十字（＋），卸载场使用齐平白色空心方框（□）；外接范围均为 8×8，笔画厚两格，方框内部保留 4×4 底色。H 仅用于降落场。黄绿色与白色集中在高台前缘、地面角标和入口标记，主体保留石材、木材与植物本色。

## 按部位落实材料

| 图中部位／可见形状 | 选用方块 | 必要状态与构造 |
| --- | --- | --- |
| 灰色地基、浅灰作业地坪 | 安山岩、石砖、平滑石、磨制安山岩 | 完整方块承托，标识与照明齐平 |
| 高台石柱脚与连续木梁 | 石砖、去皮橡木原木、橡木木板 | 柱轴向 Y，横梁按 X／Z 方向；梁柱不被灯具替换 |
| 高台前缘识别带 | 橡木木板、白色与黄绿色混凝土 | 两个主柱跨采用相同居中的短色带节奏 |
| 开放高台矮栏 | 圆石墙、去皮橡木原木端柱 | 明确四向连接、中柱和转角；梯口断开，其余边界连续 |
| 侧梯 | 石砖楼梯、石砖侧墙、圆石墙护栏 | 三格净宽、五级朝 +Z 上行；楼梯后方有完整落脚平台 |
| 外围及种植床低边界 | 苔石墙、苔石与泥土 | 墙构件按细截面使用，植物均有合法基底 |
| 植被 | 持久橡树叶、开花杜鹃树叶、蕨、滨菊与绒球葱 | 叶片 `persistent=true,distance=1`；花草种在泥土上，不悬空或伸入净空 |
| 独立方灯 | 赭黄蛙明灯 | `axis=y`；位于独立栏杆端柱或灯墩之上 |
| 地面补光 | 海晶灯 | 齐平布置于作业边线外或水槽旁 |
| 装载侧整理构件 | 堆肥桶 | `level=0`，不附带材料或生产进度 |
| 卸载侧浅水槽 | 石砖、水源 | 实心底与完整四壁围合，水只在槽内；不连接作业区 |
| 卸载侧集液与小台 | 空炼药锅、橡木栅栏支脚、涂蜡斑驳铜活板门 | 铜活板门按图中薄台面使用，水平关闭，不用整块铜代替 |

堆肥桶、炼药锅与活板门保留原版交互，仅作为外露附属构件。模组装卸设备、库存和实例绑定由落位后配置。方块来自 Minecraft Java 1.21.1 原版，排除铁块、金块、钻石块、下界合金块、绿宝石块与信标。

## 标高、尺寸与接口

两份模板局部坐标相同，正面朝 -Z，范围含两端。

| 项目 | 两份模板共用尺寸／坐标 |
| --- | --- |
| 文件尺寸 X × Y × Z | **32×22×28**；文件高度包含作业空气 |
| 实体高度 | **9 格** |
| 首层地坪／二层楼板 | **Y=1／Y=6**，相差五格 |
| 16×16 首层作业面 | **X=3…18、Z=3…18** |
| 16×20×16 作业空腔 | **(3, 2, 3) → (18, 21, 18)** |
| 二层设备位 | **(15, 7, 22) → (17, 9, 26)**，3×3×5 |
| 二层操作位 | **(19, 7, 22) → (21, 9, 26)**，3×3×5 |
| 后侧开放高台 | X=1…30、Z=21…27，楼板 Y=6，上方无屋顶 |
| 三格地面通路 | X=20…22、Z=1…26，Y=1 |
| 五级侧梯 | X=26…28、Z=16…20，阶梯 Y=2…6，朝 +Z 上行 |
| 梯顶落脚平台 | X=26…28、Z=21…26，楼板 Y=6 |
| 前侧六格入口 | X=8…13、Z=0，Y=1 |
| 后侧六格道路口 | X=14…19、Z=27，Y=1，从高台下方接入 |
| 装载终端／定位点 | `cargoverse:container_loader`／`cargoverse:container_loading_point` |
| 卸载终端／定位点 | `cargoverse:cargo_unloader`／`cargoverse:container_unloading_point` |

**货柜作业空气从首层 Y=2 开始，设备空间从二层 Y=7 开始。** 地板、印花与齐平灯不计入作业体积。文件保存至 Y=21 是为了清空上方空间，二层设备预留至 Y=9 也不表示那里有实体建筑。

设备控制面朝东侧人员操作位，从梯顶转入三格操作带；首层路径从后侧道路经高台下方接入右侧通路，再到直梯。两份模板各设对应检测范围，并绑定同一贸易点实例；设备所在楼层与首层检测范围分别配置，不能把二层标高套入货柜范围。植物和水槽不占作业面或通路。

## 适用站点与交付

梯田农林站、云泽水产与育种站、绿洲生物工程站均已有出售与收购方向，分别沿用各站资源规则。制造与基础领取继续按货柜生成结构页执行，装卸场不新增任何制造或领取资格。默认资源测试站不纳入正式站点接入记录。

装载场：

```text
cargoverse:common/cargo_yards/vbs/loading_yard_01
```

卸载场：

```text
cargoverse:common/cargo_yards/vbs/unloading_yard_01
```

相对存档目录：`generated/cargoverse/structures/common/cargo_yards/vbs/`，只交付两份正式 NBT。概念图、提示词、实际预览与分层平面统一放在文档资产中。原整站、共用平台及货柜制造附件各自保留，新装卸场按现场布局拼接；没有预装模组设备、控制器偏移、库存、实体或实例绑定。
