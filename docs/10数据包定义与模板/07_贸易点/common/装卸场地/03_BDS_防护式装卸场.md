# BDS · 防护式装卸场 01

铁壁防务集团的装载场与卸载场分别交付独立 NBT。每份占地 **30×26 格**，实体最高 **9 格**，包括 **16×16 露天作业面**、地面设备棚、三格宽操作通道和分段护墙。装载场中心用十字（＋），卸载场中心用空心方框（□）；H 仅用于降落场。

## 统一概念与形体

![BDS 防护式装卸场统一概念图](<../../../../assets/images/trade_points/common/cargo_yards/bds/concept.png>)

使用内置图片生成功能建立一张统一参考板，见[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/bds/concept_prompt.txt>)。以两格基础、三格通道、设备净空及柱跨校准实际尺寸；图中透视和文字标注不直接代替方块坐标。

装载场采用右侧连续护棚、窄窗端墙和低矮屋顶风帽；卸载场采用左侧前低后高的分段护棚，后段带短挑檐。围墙分段留缝，后方保留六格道路接口，正面保持开敞。所有柱梁、墙体、棚檐和照明都在作业空腔之外。

深板岩柱梁、石砖护墙及灰色石质地坪构成主体；深绿色沿棚檐、护墙嵌板和场地转角重复出现。白色印花、边线与地坪齐平。窄窗使用纯玻璃块，铁栏仅用于独立灯杆；灯具位于专用支座或梁间吊点，不切断柱墙。半砖屋面压在完整方块基层上。

模板只提供建筑空间，不安装内部家具、模组设备、货柜实体或业务绑定。全部使用 Minecraft Java 1.21.1 原版方块，排除铁块、金块、钻石块、下界合金块、绿宝石块与信标。

## 尺寸与接口

| 项目 | 装载场 | 卸载场 |
| --- | --- | --- |
| 文件尺寸 X × Y × Z | **30×22×26** | **30×22×26** |
| 实体高度 | 9 格；文件更高部分为作业空气 | 同左 |
| 地坪／设备空气底面 | **Y=1／Y=2** | 同左 |
| 16×16 作业面 | X=3…18、Z=4…19 | X=11…26、Z=4…19 |
| 16×20×16 作业空腔 | **(3, 2, 4) → (18, 21, 19)** | **(11, 2, 4) → (26, 21, 19)** |
| 中心印花 | 白色十字（＋），外接 8×8、笔画厚 2 格 | 白色空心方框（□），外框 8×8、边宽 2 格、内空 4×4 |
| 设备位 | **(24, 2, 13) → (26, 4, 17)**，3×3×5 | **(3, 2, 13) → (5, 4, 17)**，3×3×5 |
| 操作位 | **(20, 2, 13) → (22, 4, 17)**，3×3×5 | **(7, 2, 13) → (9, 4, 17)**，3×3×5 |
| 三格操作通道 | X=20…22、Z=1…24 | X=7…9、Z=1…24 |
| 面板前接近带 | X=23、Z=13…17 | X=6、Z=13…17 |
| 后侧道路接口 | X=9…14、Z=25，六格宽 | X=15…20、Z=25，六格宽 |
| 正面台阶接口 | X=9…14、Z=0 | X=15…20、Z=0 |
| 货流方向 | 贸易点 → 货柜 | 货柜 → 贸易点 |
| 终端／定位点 | `container_loader`／`container_loading_point` | `cargo_unloader`／`container_unloading_point` |

坐标均为各自独立 NBT 的局部坐标，含端点，正面朝 -Z；功能方块均使用 `cargoverse` 命名空间。两份模板设备区左右相反，不能互抄 X 坐标，也不能沿用旧整站或共用平台原点。设备面朝三格操作通道，实际朝向、模型外伸和控制器偏移另行安装配置。

装载、卸载范围分别设置，并绑定同一贸易点实例。公共路线沿外围和后侧接入，中心印花、地板不计入检测体积；天空上方保持二十格作业净空。原有制造及领取服务仍按各站生产附件和启用条件安排。

建筑交付不改变商品目录、制造资格或注册领取条件。旧整站、共用平台和货柜制造附件保留原文件，新场地另行按现场布局拼接。
