# 按制造商划分的独立装卸场地

装载对应**贸易点出售、玩家购买并装入货柜**；卸载对应**贸易点收购、玩家出售柜内货物**。两个模板是两个不同作业面，各自设置对应设备和定位点，并绑定同一贸易点实例。不能因为属于同一制造商就将两个定位范围合并。

每件平台上方保留二十格空气，地面、中心标识与齐平灯块不计入检测体积。实际货柜须落入本版 16×16 作业范围；生成服务继续按各站货柜生产附属结构配置，不因新增装卸场获得制造或注册能力。

选材执行[按图选择方块与构件形状](<../../结构搭建说明/结构模板工作流.md#按图选择方块与构件形状>)：墙系列、不同原版光源和可见功能构件均按参考图选用，不将已经制作的 AUI、SPL、BDS 材料表当作后续制造商的限定列表。内部设备预留不排除建筑外观所需的原版构件。

SPL 采用首层作业、二层操作的形式：首层地坪 Y=1，二层楼板 Y=7。设备从 Y=8 开始，但作业范围仍从首层 Y=2 开始；不同楼层和模板的坐标不混用。

新系列不自动改写既有整站或已手工修改的平台。[既有共用收发货平台](<../../结构搭建说明/共用收发货平台.md>)仍作为旧资产与坐标记录；采用分离式场地时，按本站装载、卸载功能页的新模板坐标重新落位，不混用旧整站原点。

共享加载路径为 `cargoverse:common/cargo_yards/<制造商>/loading_yard_01` 与 `cargoverse:common/cargo_yards/<制造商>/unloading_yard_01`。存档结构目录只放正式 NBT，概念图、平面与说明归入文档资产，实际设备和绑定由现场安装完成。
