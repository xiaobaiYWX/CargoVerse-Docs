# SPL · 双层操作装卸场 01

云港物流集团的装载场与卸载场分别交付独立 NBT。每份占地 **32×28 格**，首层保留 **16×16 露天作业面**；侧边操作廊架到二层，下方设置货箱堆场。装载用十字（＋），卸载用空心方框（□），不使用降落场的 H 标识。

## 概念与尺度

![SPL 装载与卸载场统一概念图](<../../../../assets/images/trade_points/common/cargo_yards/spl/concept.png>)

使用内置图片生成功能制作一张统一参考板，见[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/spl/concept_prompt.txt>)。两种场地沿用同一基础、柱跨、层高和材料，装载场右侧为连续棚顶操作廊，卸载场左侧为分段棚顶操作廊。以两格基础、六格层间高差和三格宽楼梯校准尺寸；参考图中的阶数、透视比例和尺寸文字不直接作为方块坐标。

深板岩柱梁与灰色石质地坪构成主体，橙色用在棚檐、柱脚、局部楼板边缘及场地边线，白色用于识别条、设备棚框架和中心印花。玻璃屏及顶棚采光带均采用纯玻璃块；铁栏仅用于真正的安全栏杆和货箱锁杆。照明设于独立支座或挑梁下方，不截断柱梁。

每份模板首层放置两只 **4×6×4 格静态货箱**：装载场为橙色与浅色，卸载场为深灰与橙色；另有少量低矮托盘。货箱由原版建筑方块搭成，没有实体、库存或运输功能。首层作业面与二层设备带明确分开，棚顶、支柱、楼梯、货箱均不侵入作业净空。

全部采用 Minecraft Java 1.21.1 原版方块，不使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。

## 尺寸、楼层与接入

| 项目 | 装载场 | 卸载场 |
| --- | --- | --- |
| 文件尺寸 X × Y × Z | **32×22×28** | **32×22×28** |
| 实体高度 | 14 格；保存高度包含作业空气 | 同左 |
| 首层地坪／二层楼板 | **Y=1／Y=7**，层间相差六格 | 同左 |
| 首层作业面 | X=3…18、Z=4…19，16×16 | X=13…28、Z=4…19，16×16 |
| 作业空腔 | **(3, 2, 4) → (18, 21, 19)**，16×20×16 | **(13, 2, 4) → (28, 21, 19)**，16×20×16 |
| 中心印花 | 白色十字（＋），外接 8×8、笔画厚 2 格 | 白色空心方框（□），外框 8×8、边宽 2 格、内空 4×4 |
| 二层设备预留 | **(27, 8, 11) → (29, 10, 15)**，3×3×5 | **(2, 8, 11) → (4, 10, 15)**，3×3×5 |
| 二层操作预留 | **(23, 8, 11) → (25, 10, 15)**，3×3×5 | **(6, 8, 11) → (8, 10, 15)**，3×3×5 |
| 三格宽外梯 | X=27…29、Z=2…7，六级朝 +Z 上行，阶梯 Y=2…7 | X=2…4、Z=2…7，六级朝 +Z 上行，阶梯 Y=2…7 |
| 梯顶横向平台 | X=23…29、Z=9，楼板 Y=7 | X=2…8、Z=9，楼板 Y=7 |
| 首层货箱前人员通道 | X=23…25、Z=1…26 | X=6…8、Z=1…26 |
| 后侧六格道路接口 | X=8…13、Z=27，地坪 Y=1 | X=18…23、Z=27，地坪 Y=1 |
| 正面六格接入 | X=8…13、Z=0，石阶 | X=18…23、Z=0，石阶 |
| 货流 | 贸易点 → 货柜 | 货柜 → 贸易点 |
| 终端 | `cargoverse:container_loader` | `cargoverse:cargo_unloader` |
| 定位点 | `cargoverse:container_loading_point` | `cargoverse:container_unloading_point` |

以上均为各自 NBT 的局部坐标，含端点，正面朝 -Z。地坪和印花不计入检测体积；**作业空腔从首层 Y=2 开始，设备与操作空间从二层 Y=8 开始**。二层设备绑定的是首层范围，不能将设备高度直接当成范围底面，也不能沿用 SPL 货柜制造附件的二层生产坐标。

设备控制面朝三格宽操作廊，外围人员路线经楼梯连接二层。实际设备、控制器、定位偏移与实例绑定另行安装；模板未写入业务设备、UUID、货柜实体或自动搬运装置。两份场地可按站点布局分别接入，装载、卸载各有独立范围，并绑定同一贸易点实例。

## 适用站点与交付

远航货运枢纽、云港民生集配站、天空城综合市场均可采用本套 SPL 附属模板。云港民生集配站已有出售与收购业务，可分别接入两份场地；**远航货运枢纽和天空城综合市场当前无出售规则，装载场仅作预留模板，交付建筑不等于启用购买货物的服务。** 卸载按各站现有收购目录启用，制造与领取服务仍按各站生成结构说明配置。

装载场：

```text
cargoverse:common/cargo_yards/spl/loading_yard_01
```

卸载场：


相对存档目录：`generated/cargoverse/structures/common/cargo_yards/spl/`，只包含上述两份正式 NBT。概念图、实际预览及平面统一存放于文档资产。现有整站、共用平台、货柜制造场和圆柱塔台保留原文件，新场地按现场设计另行拼接。
