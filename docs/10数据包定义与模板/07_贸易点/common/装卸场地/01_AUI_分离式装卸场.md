# AUI · 分离式装卸场 01

天穹联合工业的装载场与卸载场分别交付一份 NBT，适用于标准建材装配港、通用机电装备厂与飞艇总装与航修港。每份总占地 **28×24 格**，中央作业面 **16×16 格**；两个模板按独立实体拼接，不以同一块地面分时表达两个场地。

## 统一参考与形体

> 参考图保留初版形体；图中的 H 已在交付 NBT 中改为装载十字、卸载空心方框。地面标识以以下实际预览和平面图为准，H 仅用于降落场。

![AUI 装载场与卸载场概念参考板](<../../../../assets/images/trade_points/common/cargo_yards/aui/concept.png>)

两份设计由内置图片生成功能在同一参考板中建立统一尺度与材料，见[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/aui/concept_prompt.txt>)。以两格基础、三格操作通道与实际设备所需空间校准，图上的高度数字不作为保存尺寸；高低双棚实体高 9 格，L 形棚实体高 8 格，保存高度另含二十格作业空气。

灰色石质甲板与深板岩基础作为主体，白色柱梁、青色檐边和灯柱标记体现 AUI 识别。装载场中心为白色十字，卸载场中心为白色空心方框。两者均外接 8×8 格、笔画厚 2 格，与 16×16 作业面的中心对齐；方框内留 4×4 格底色。作业面、中心印花、角标与灯块全部齐平；栏杆与高灯柱位于边缘。设备只预留位置，不照搬概念图里的机器或柜台。全部使用 Minecraft Java 1.21.1 原版方块，不使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。

装载场的右侧是两段高低错落的设备棚，青色货流箭头由后方道路指向作业面；卸载场的设备棚位于左侧，采用 L 形屋面、短隔挡与后侧连续玻璃挡风屏，箭头由作业面指向站内。两个场地后部均保留空置描边区和人员通路，内部设备由后续布置。

## 尺寸与接口

| 项目 | 装载场 | 卸载场 |
| --- | --- | --- |
| 文件尺寸 X × Y × Z | **28×22×24** | **28×22×24** |
| 实体高度 | 9 格 | 8 格 |
| 地坪 | Y=1；Y=2 为第一层空气 | 同左 |
| 中心印花 | 十字（＋），8×8 外接、笔画厚 2 格 | 空心方框（□），8×8 外框、边宽 2 格、内空 4×4 |
| 16×16 作业面 | X=4…19、Z=2…17 | X=8…23、Z=2…17 |
| 16×20×16 作业空腔 | **(4, 2, 2) → (19, 21, 17)** | **(8, 2, 2) → (23, 21, 17)** |
| 设备位 | (24, 2, 8) → (26, 4, 12)，3×3×5 | (1, 2, 8) → (3, 4, 12)，3×3×5 |
| 操作位 | (20, 2, 8) → (22, 4, 12)，3×3×5 | (5, 2, 8) → (7, 4, 12)，3×3×5 |
| 设备侧通路 | X=20…22，三格宽 | X=5…7，三格宽 |
| 后侧六格接口 | X=9…14、Z=23，地坪 Y=1 | X=13…18、Z=23，地坪 Y=1 |
| 正面台阶 | X=9…14、Z=0 | X=13…18、Z=0 |
| 货流方向 | 站内 → 货柜 | 货柜 → 站内 |
| 终端 | `cargoverse:container_loader` | `cargoverse:cargo_unloader` |
| 定位点 | `cargoverse:container_loading_point` | `cargoverse:container_unloading_point` |

坐标均以**各自 NBT 包围盒最小角**为原点，正面朝 -Z，后侧道路接口朝 +Z。两件采用左右相反的设备布局，因此不能直接互抄 X 坐标。设备预留适配侧向安装，控制面朝操作通道，外侧留检修空间；实际设备朝向与模型外伸按安装位置处理。

同一贸易点中的装载场、卸载场各自保留独立作业范围，同时绑定本站实例。二者应通过后侧道路或外围步道与营业区域连接；人员路线绕过作业面。模板没有模组终端、定位点、测试 UUID、货柜实体、库存或自动移柜功能。

## 加载与交付

装载场：

```text
cargoverse:common/cargo_yards/aui/loading_yard_01
```

卸载场：

```text
cargoverse:common/cargo_yards/aui/unloading_yard_01
```

相对存档目录：`generated/cargoverse/structures/common/cargo_yards/aui/`，内含上述两份 NBT。本站已有主体、旧共用平台和货柜制造场未被重制；新场地的实际落位与业务设备接入另行配置。各站收售资源、制造目录和启用条件保持现有定义。
