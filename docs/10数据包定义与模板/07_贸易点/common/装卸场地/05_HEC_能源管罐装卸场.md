# HEC · 能源管罐装卸场 01

赫利俄斯能源集团的装载场与卸载场分别交付独立 NBT。每份占地 **30×30 格**，包含一块 **16×16 露天作业面**，实体高 **10 格**。灰白铺装和罐壳体现能源设施用途，红色集中在棚檐、罐体识别带和地面角标，黑色用于框架与管路。

## 概念与布局

![HEC 能源管罐装卸场统一概念图](<../../../../assets/images/trade_points/common/cargo_yards/hec/concept.png>)

两份模板采用同一张参考板，见[完整提示词](<../../../../assets/images/trade_points/common/cargo_yards/hec/concept_prompt.txt>)。实际以参考板中的左侧管罐带、右侧作业面和后侧低棚为布局依据，以五格直径罐体、三格维护通道及 16×16 作业面校准尺寸；提示词中的左右安排不覆盖最终图像中的统一布局。

装载场使用两只小型圆罐外壳与连续低棚，中心是白色十字（＋）。卸载场使用单罐、铜格栅设备箱、空炼药锅集液构件和两段错高棚顶，中心是白色空心方框（□）。标识外接 8×8 格、笔画厚两格，方框内部保留 4×4 底色，全部与地坪齐平。H 仅用于降落场。

设备与操作空间位于后棚，管罐与阀门布置在左侧设备带，均不伸入作业区上方。三格侧通路、棚前通路和后侧六格道路口连接场地，前侧另有六格台阶入口。

## 按部位落实材料

| 部位与形状 | 实际方块 | 状态与用途 |
| --- | --- | --- |
| 基础与铺装 | 石砖、磨制安山岩、安山岩、平滑石 | 完整方块承托；前侧入口使用石砖楼梯 |
| 细护栏、设备带隔栏 | `stone_brick_wall` 石砖墙 | 明确写入各段四向连接与中柱状态 |
| 细管与支承 | `polished_blackstone_wall` 磨制黑石墙、磨制黑石 | 墙构件沿管线连接，端部与接头有支承 |
| 五格直径罐体 | 白色混凝土、红色陶瓦、磨制黑石砖 | 四角退一格形成小型圆罐；红色陶瓦仅作环带 |
| 罐顶收分 | 平滑石英楼梯、平滑石及其台阶 | 楼梯朝内收分，台阶下有完整支承，罐内不放流体 |
| 棚架与红檐 | 磨制黑石砖、红色混凝土、平滑石及其台阶 | 柱梁连续，卸载棚两段高差处封实 |
| 后侧挡风屏 | 灰色染色玻璃块 | 纯玻璃；后侧道路口保持开放，不叠加铁栅栏 |
| 卸载设备箱 | `waxed_exposed_copper_grate` 涂蜡斑驳铜格栅 | `waterlogged=false`，作为真实通风外壳；黑石边框承托 |
| 管路接头与指示台 | 涂蜡斑驳切制铜 | 保持铜材自身颜色，不以品牌色覆盖 |
| 齐平地灯 | `redstone_lamp` 红石灯 | `lit=true`，下方基础内放红石块持续供电；灯位在 16×16 作业面之外 |
| 棚下照明 | `end_rod` 末地烛 | `facing=down`，挂在棚底空格，不替换柱梁 |
| 入口与设备指示灯 | `waxed_copper_bulb` 涂蜡铜灯 | `lit=true,powered=false`，立于独立基座或指示台上 |
| 外露阀门与集液构件 | 拉杆、空炼药锅 | 拉杆依据支承设为墙面或地面安装，初始 `powered=false`；保留原版交互 |

罐体、格栅箱与管路用于建筑外观，不表示实现燃料储运系统；模组装卸设备仍留空。所用方块均为 Minecraft Java 1.21.1 原版内容，未使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。

## 尺寸、标高与接口

两份模板采用相同局部坐标，正面朝 -Z，范围包含端点。

| 项目 | 两份模板共用尺寸或坐标 |
| --- | --- |
| 文件尺寸 X × Y × Z | **30×22×30**，保存高度包含作业空气 |
| 实体高度 | **10 格**，最高为罐顶阀门 |
| 作业与操作地坪 | **Y=1** |
| 16×16 作业面 | **X=12…27、Z=3…18** |
| 16×20×16 作业空腔 | **(12, 2, 3) → (27, 21, 18)** |
| 后棚设备位 | **(24, 2, 23) → (26, 4, 27)**，3×3×5 |
| 后棚操作位 | **(20, 2, 23) → (22, 4, 27)**，3×3×5 |
| 左侧三格维护通路 | X=9…11、Z=2…20，Y=1 |
| 后棚三格操作通路 | X=20…22、Z=20…29，Y=1 |
| 前侧台阶入口 | X=17…22、Z=0，Y=1，朝 +Z 上行 |
| 后侧六格道路接口 | X=17…22、Z=29，Y=1 |
| 装载终端／定位点 | `cargoverse:container_loader`／`cargoverse:container_loading_point` |
| 卸载终端／定位点 | `cargoverse:cargo_unloader`／`cargoverse:container_unloading_point` |

作业空气从 **Y=2** 开始，地板与印花不计入检测体积。设备控制面朝西侧操作位，定位点设在作业范围之外；终端朝向、模型外伸及绑定在落位后配置。两份场地分别配置对应检测范围，并关联同一贸易点实例，不能因局部坐标相同就共用世界范围。
