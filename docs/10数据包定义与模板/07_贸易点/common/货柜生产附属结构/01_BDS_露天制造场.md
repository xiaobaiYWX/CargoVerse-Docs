# BDS · 露天货柜制造场 01

本模板归入**铁壁防务集团（BDS）**系列，供铁壁防务装备站、安防设施集成厂与边境驻防补给港按各自制造服务条件使用。沿用已认可的首版实体、概念图与预览，当前按制造商目录组织；边境驻防补给港改为固定配套制造台。

本次采用独立户外生产场地方案，场地用于制成货柜生成。原贸易点的航空收发平台继续承担收货与发货，本模块不增加第二座 H 停机坪，也不因加载建筑自动启用制造服务。

## 01 · 露天制造场

### 主概念图

![通用货柜生产附属结构 01：概念图与俯视](<../../../../assets/images/trade_points/common/container_manufacturing/bds/open_yard_01/concept.png>)

先以完整附属模块生成一张主参考板，再据图落实生产地坪、周边通道、后部棚架和接合口。图中标注作为尺度预算，实际空间以方块坐标为准；没有为一个通用附件另行制作整座贸易点。参见[图片生成提示词](<../../../../assets/images/trade_points/common/container_manufacturing/bds/open_yard_01/concept_prompt.txt>)。

浅灰地坪和两格厚石砖基座形成低平台；后部铜屋盖由连续深灰柱梁承托。黄黑线位于生产面外缘，转角标记与地面齐平。灯具悬挂于边界支架，护栏仅设在周边；中心不放设备、货物、吊机、立柱或屋盖。

主体使用磨制安山岩、平滑石、石砖、深板岩砖、磨制深板岩和涂蜡锈蚀切制铜。黄色陶瓦／黄色混凝土和黑色混凝土只承担作业标识，橙色陶瓦用于少量反光色板，本次按深灰构件与绿色铜棚顶的既有外观归入 BDS，黄黑标记承担作业警戒。模板使用 Minecraft Java 1.21.1 原版方块，排除铁块、金块、钻石块、下界合金块、绿宝石块和信标。

### 尺寸与空间

| 项目 | 当前记录 |
| --- | --- |
| 模板文件 | `open_yard_01.nbt` |
| 水平占地 | **31 × 31 格**，包含全部屋檐、灯臂和边界构件 |
| 保存尺寸 X × Y × Z | **31 × 22 × 31** |
| 实体建筑高度 | 10 格；上部保存空气，用于保留生产净空 |
| 地坪 | Y=1；Y=2 为第一层空气 |
| 户外生产面 | X=4…27、Z=1…24，共 **24 × 24 格** |
| 生成净空建议 | (4, 2, 1) → (27, 21, 24)，含端点，**24 × 20 × 24** |
| 制造台设备与安装预留 | (4, 2, 25) → (8, 5, 30)，**5 × 4 × 6**；未放置设备 |
| 棚下操作位 | (11, 2, 26) → (17, 5, 28)，**7 × 4 × 3** |
| 左侧人员带 | X=1…3，沿生产面通向后部设备棚；边界标线可步行 |
| 后部棚盖 | X=0…20、Z=25…30；全部位于生产面上空范围外 |

所有坐标为本模板局部坐标，原点为包围盒最小角，正面为 -Z。生产范围的地板和齐平标线不计入空腔；需要保持为空气的是 Y=2 起的检测体积。设备位的后缘保持开敞，不用栏杆或背墙占用其六格深度。制造台的最终朝向、操作面和模型占地仍按实际设备安装。

保存高度 22 格包含地坪以上的 20 格空气，并不代表棚架高 22 格。接合时按地坪对齐，让整个 31×31 包围盒保持独立占位；模板中的空气不应用于覆盖相邻主体建筑。

### 拼接接口

| 接口 | 坐标与处理 |
| --- | --- |
| 正面主接口 | Z=0、X=13…18，六格宽，地坪 Y=1，与外部同高广场或连接模块直接相接 |
| 左侧人员入口 | X=0、Z=13…16，四格宽，设置一格石阶，可接外部人员路线 |
| 制造台安装侧 | 位于后部设备棚，与左侧人员带及棚下操作位相通；不需要为此在生产面内设固定通道障碍 |

正面主口直接面向生产区，用于敞开进出与场地拼接；日常设备操作可由侧边人员带进入后棚。安装到地表站或高架站时，由相邻模块处理高度差和基础支承，不拉长本模块的包围盒。

### 加载与功能边界

```text
cargoverse:common/container_manufacturing/bds/open_yard_01
```

存档相对位置：`generated/cargoverse/structures/common/container_manufacturing/bds/open_yard_01.nbt`。

本次只向结构目录交付这一个 NBT。概念图、实际预览、平面和说明保存在文档资产中；不向结构目录写入说明、清单或备份。

模板只包含建筑、地坪与标识，没有货柜制造台、货柜生成点、成品货柜、测试 UUID 或拼图绑定。实际启用时配置制造台目录，并将生成点的检测范围设为本模块的生产空腔；生成点和其他终端本体放在检测范围以外。若基础领取与制造共用一个生成点，两者同步指向该点，不因复用建筑新增多个互相冲突的生成服务。

本页是可独立选用的制造附属模板，不自动拼入 BDS 三站的现行整站。各站当前设备、装卸范围和生成点以对应发布结构总览为准；改造时再确认本附件是否采用，并配置本站制造目录。
