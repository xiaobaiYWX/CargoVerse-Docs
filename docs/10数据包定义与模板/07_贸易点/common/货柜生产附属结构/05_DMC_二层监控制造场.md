# DMC · 二层监控货柜制造场 01

供**深岩矿业集团（DMC）**复用的货柜生产附件。地面生产场保持平整，后部以连续柱梁支起二层操作台和控制室。重工材料与矿机厂作为固定工坊接入，深岩露天矿站与矿物分选精炼站均按固定配套制造台接入，各自目录以站点定义为准。

## 概念与结构

![DMC 二层控制平台统一概念图](<../../../../assets/images/trade_points/common/container_manufacturing/dmc/open_yard_01/concept.png>)

使用内置图片生成功能生成一张主透视与俯视统一的参考板，[原始提示词](<../../../../assets/images/trade_points/common/container_manufacturing/dmc/open_yard_01/concept_prompt.txt>)随资产归档。依据图中的平场、首层框架、二层控制室和右侧外梯搭建，忽略无法落实的细碎影像细节。

实际结构将右侧楼梯落实为**两格通行净宽、两侧各一列护栏**，水平占地为 **32×31 格**。这比初始提示中的 31 格宽增加一格，仍处于 32×32 的附属结构范围内；楼梯、护栏和控制室均退出 24×24 的生产场上空。

首层为开敞设备区，制造台和现场操作位置保留在地面。二层楼板比地坪高六格，左侧为开放操作平台，右侧为大玻璃控制室；向东开口直接通向楼梯顶端平台。控制室正面采用宽度为 3／4／3 的对称窗跨，窗内没有铁栅栏。上层栏杆只用于平台边缘，楼梯口与室内入口保持通行。

主体使用磨制安山岩、平滑石和深色石材框架；黄色陶瓦用于柱脚、栏杆柱与控制室识别带，少量黄色混凝土和黑色混凝土形成齐平警戒标线。深色框架保持连续，灯具布置在偏置支座、梁下或独立灯柱上；屋顶半砖由实体顶板承托。

## 尺寸与接口

| 项目 | 本模板局部坐标／尺寸 |
| --- | --- |
| 文件尺寸 X × Y × Z | **32 × 22 × 31** |
| 水平占地 | **32 × 31 格**，包含外梯、护栏和全部构件 |
| 实体高度 | **14 格**；保存高度含生产空腔 |
| 生产场、首层设备区地坪 | **Y=1**，保持平整、不下沉 |
| 二层楼板 | **Y=7**，比地坪高六格；Y=8 为二层第一层空气 |
| 户外生产面 | X=4…27、Z=1…24，**24×24 格** |
| 生成检测空腔 | (4, 2, 1) → (27, 21, 24)，**24×20×24**，含端点 |
| 首层制造台设备位 | (4, 2, 25) → (8, 5, 30)，**5×4×6** |
| 首层操作位 | (13, 2, 26) → (20, 4, 29)，**8×3×4** |
| 二层开放操作台 | X=2…12、Z=26…29，楼板 Y=7 |
| 二层控制室 | X=13…26、Z=27…30，楼板 Y=7 |
| 室内操作净空间 | (14, 8, 28) → (25, 10, 29)，**12×3×2**；灯具位于更高的 Y=11 |
| 外梯通行区域 | X=29…30、Z=19…24，六级，朝 +Z 上行；阶梯方块 Y=2…7 |
| 外梯两侧护栏 | X=28 与 X=31，均位于生产面外 |
| 梯顶平台 | X=29…30、Z=25…27，Y=7；转向西侧抵达控制室东入口 |
| 控制室入口 | X=26、Z=28…29，开口空气 Y=8…11 |
| 正面货柜接合口 | X=13…18、Z=0，六格宽，地坪 Y=1 |
| 左侧人员入口 | X=0、Z=13…16，四格宽，含侧向石阶 |

坐标以本附件包围盒最小角为原点，正面朝向 -Z。制造台仍安装在首层；二层仅提供观察和操作空间，不自动生成远程控制设备或改变业务终端规则。设备位后方敞开，完整六格安装深度不被墙栏占用。

生产范围没有屋顶、吊臂、楼梯或灯具跨入，警戒线与角标均与地面齐平，不设置 H 标志。上部保存空气仍属于模板占位，拼接时为包围盒保留空间，避免覆盖邻近建筑。
