# AUI · 双锯齿顶货柜制造场 01

供**天穹联合工业（AUI）**旗下贸易点复用的独立生产附属模板。标准建材装配港和通用机电装备厂按必需工坊接入，飞艇总装与航修港也作为必需组件接入；各站目录和材料来源保持独立。

## 概念与形体

![AUI 货柜制造场：主参考图与俯视](<../../../../assets/images/trade_points/common/container_manufacturing/aui/open_yard_01/concept.png>)

本版先生成一张完整模块参考板，再按可辨柱跨、生产面及设备空间落实方块模型。后部由两段同向锯齿采光顶组成；左侧设备跨完全开敞，右侧操作跨保留玻璃挡风屏。外围采用浅色柱脚、连续玻璃护栏、短灯柱和前方六格接合口，与 BDS 铜顶重框架版形成不同轮廓。见[原始提示词](<../../../../assets/images/trade_points/common/container_manufacturing/aui/open_yard_01/concept_prompt.txt>)。

主体选用磨制安山岩、平滑石、石英砖和平滑石英，玻璃独立连续填充；青色用于檐口、入口柱、地面短线、灯座和标识墙，白色框架保持真实承托。海晶灯设置在独立灯柱顶部或棚顶支座下，不截断承重柱梁。大面积地坪保持浅灰，中央没有 H 标识或装饰性设备。

全部采用 Minecraft Java 1.21.1 原版方块，不使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。玻璃中不混入铁栏杆；锯齿顶采用有连续背衬的实块与半砖收边。

## 尺寸与接口

| 项目 | 模板局部坐标／尺寸 |
| --- | --- |
| 文件尺寸 X × Y × Z | **31 × 22 × 31** |
| 水平占地 | **31 × 31 格**，包含全部棚顶、灯具和接合构件 |
| 实体高度 | 14 格；保存高度包含生产面上方空气 |
| 地坪 | Y=1；Y=2 起为空气 |
| 户外生产面 | X=4…27、Z=1…24，**24 × 24 格** |
| 生成净空 | (4, 2, 1) → (27, 21, 24)，**24 × 20 × 24** |
| 制造台设备位 | (4, 2, 25) → (8, 5, 30)，**5 × 4 × 6** |
| 棚下操作位 | (14, 2, 26) → (21, 5, 28)，**8 × 4 × 3** |
| 后部双锯齿棚 | X=0…23、Z=25…30，完全位于生产净空之外 |
| 正面主接合口 | Z=0、X=13…18，六格宽，地坪 Y=1 |
| 左侧人员入口 | X=0、Z=13…16，四格宽，含侧向石阶 |
| 左侧人员路线 | X=1…3，沿生产面外缘进入后部服务带 |

坐标均以本附属模板的包围盒最小角为原点，正面朝向 -Z；与 BDS 版共用生产面、设备位、地坪和主要接合口。操作空间和棚架形体不同，不能把 BDS 棚下坐标全部照搬到 AUI 版。

设备位后方不封墙或栏杆，确保六格深度完整可用。上方屋面、边灯、玻璃围护均不进入生产体积；地面边线与转角标记齐平。NBT 保存二十格生产净空，拼装时为整个包围盒保留独立占位，并对齐邻接道路地坪；不通过空气覆盖其他建筑来接合。

## 加载与安装边界

```text
cargoverse:common/container_manufacturing/aui/open_yard_01
```

相对存档目录：`generated/cargoverse/structures/common/container_manufacturing/aui/open_yard_01.nbt`。

本次交付一份可在同制造商站点复用的 NBT，未合并进各站原整站文件。模板不包含业务设备、货柜实体、测试 UUID、生成点绑定或拼图池配置；制造台、生成点控制器及设备朝向后续按实际模型安装，控制器位于检测空腔外。

按各站启用条件配置一处货柜生成点；实际存在的注册终端与制造台共同绑定该点。收发货仍使用各站原有共用 H 平台，不能把附属场地自动视为第二座装卸平台。货柜生成后如何搬运到收发区由现场运输安排，模板不提供自动移柜机制。
