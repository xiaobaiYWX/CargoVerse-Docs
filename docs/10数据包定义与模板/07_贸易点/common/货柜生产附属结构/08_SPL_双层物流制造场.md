# SPL · 双层物流货柜制造场 01

供**云港物流集团（SPL）**复用的独立附属结构。首层用于操作、设备安装与物流布景，二层为完整的露天生产平台。远航货运枢纽按必需工坊接入，云港民生集配站与天空城综合市场也按固定配套制造台接入。

## 概念与形体

![SPL 双层物流制造场概念图](<../../../../assets/images/trade_points/common/container_manufacturing/spl/open_yard_01/concept.png>)

由内置图片生成功能制作一张完整参考图，再按方块、货柜道具和楼梯的局部尺度确定层高。两层之间相差七格；侧梯据此落实为七级、两格通行净宽，而非直接照搬图中的透视阶数。见[概念提示词](<../../../../assets/images/trade_points/common/container_manufacturing/spl/open_yard_01/concept_prompt.txt>)。

深灰柱梁与灰色楼板承担主体，橙色沿楼板边缘、柱脚、护栏柱头和物流道具重复出现，白色用于柱身标识与齐平地面标线。三列、三排实体柱墩及连续纵横梁承托二层；首层保持开敞，后侧局部围墙避开实际制造台的安装空间。

首层两只橙色／浅色货运箱体由原版建筑方块搭成，侧面以交替材料表现加强筋，正面铁栏表现锁杆；另有少量木托盘和矮工作台。它们是静态物流道具，不包含货柜实体、存储库存或运输业务。二层仅有地坪、外围护栏及边灯，没有顶棚、机房或货物堆积，生产面没有 H 标识。

全部使用 Minecraft Java 1.21.1 原版方块，不使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。灯具设置在独立支座或梁间吊点，不截断柱梁。

## 尺寸与两层坐标

| 项目 | 模板局部坐标／尺寸 |
| --- | --- |
| 文件尺寸 X × Y × Z | **32 × 29 × 31** |
| 水平占地 | **32 × 31 格**，含右侧楼梯及栏杆 |
| 实体高度 | 13 格；更高部分为生产净空 |
| 首层地坪 | **Y=1**；设备与人员空间从 Y=2 开始 |
| 二层生产地坪 | **Y=8**；生产空腔从 Y=9 开始 |
| 二层露天生产面 | X=4…27、Z=1…24，**24 × 24 格** |
| 二层生成检测空腔 | **(4, 9, 1) → (27, 28, 24)**，24×20×24，含端点 |
| 首层制造台设备位 | (4, 2, 25) → (8, 5, 30)，**5 × 4 × 6**，后缘开敞 |
| 首层操作位 | (15, 2, 25) → (20, 5, 29)，**6 × 4 × 5** |
| 首层中央通道 | X=15…20，正面通至后部操作区 |
| 首层正面接口 | **X=15…20、Z=0**，六格宽，地坪 Y=1 |
| 左侧人员入口 | **X=0、Z=7…10**，四格宽，含石阶；内侧人员路线 X=2…4 |
| 外部侧梯 | X=29…30、Z=17…23，七级朝 +Z 上行，阶梯 Y=2…8 |
| 二层梯顶平台 | X=29…30、Z=24…29；经 X=28、Z=25…27 连入后部通路 |
| 二层后侧通路 | Z=25…27，连通梯顶与平台左侧通路 |

坐标以本附属模板包围盒最小角为原点，正面朝向 -Z。**首层制造台不在二层生产空腔内，不能沿用其他模板从 Y=2 开始的生成范围。** 本版为避开中间柱墩，正面接口和左侧入口也采用上表专用坐标。

生成点控制器放在检测体积外，按实际落位配置二层生成范围；首层制造台与实际存在的注册终端绑定同一生成点。二层外缘栏杆、灯具与楼梯均在空腔之外。侧梯用于人员通行，模板不提供货柜升降或自动移柜装置，成品转运按现场载具与搬运安排处理。

## 加载与服务边界

```text
cargoverse:common/container_manufacturing/spl/open_yard_01
```

相对存档文件：`generated/cargoverse/structures/common/container_manufacturing/spl/open_yard_01.nbt`。

共享目录交付一份独立 NBT，未合入各站原整站文件。首层接口对齐站内道路，整个包围盒保持独立占位。模板未写入实际制造设备、点位控制器、实例 UUID 或拼图绑定。

远航货运枢纽保留专业配载目录与 AUI 合作规格；云港民生集配站固定安装补柜亭，原注册领取与普通制造共用附件二层的一处生成点。每个实例只启用一处生成点。

天空城综合市场固定提供 Courier S 制造，二层生产面用于成品生成，不增加注册领取。原航空平台或分离式装卸场继续承担装卸，双层制造附件不替代收发场地。
