# HEC · 红檐防护货柜制造场 01

供**赫利俄斯能源集团（HEC）**旗下贸易点复用的独立生产附属模板。工业化学品供应站与净水与环境处理站按固定工坊接入，赫利俄斯燃料供应站也按固定配套制造台接入。建筑复用不改变各站目录、注册权益或材料来源。

## 概念与形体

![HEC 货柜制造场统一参考图](<../../../../assets/images/trade_points/common/container_manufacturing/hec/open_yard_01/concept.png>)

本版使用图片生成功能制作一张完整参考板，主视图与俯视图共同表达同一附件；随后按生产面、柱跨与设备预留落实方块结构。参考图见上，[生成提示词](<../../../../assets/images/trade_points/common/container_manufacturing/hec/open_yard_01/concept_prompt.txt>)随图归档。

后侧采用平顶防护棚，左跨向前后完全开敞，右跨以灰色实体墙、连续玻璃观察带和红色墙带围合操作位置。棚外右后角设置独立台基、阶梯状挡墙与两座排气造型立柱。中央保留完整露天生产面，外围设低护栏、短灯柱和人员通道，正面预留六格接合口。

以安山岩、磨制安山岩、平滑石和石砖作为主要地坪与防护材料，磨制黑石砖用于柱梁及排气立柱。红色陶瓦在檐口、墙带、立柱色环、入口灯柱和红白地面边界上重复出现，作为 HEC 识别色。灯具位于独立支座顶部或棚底的偏置挂点，不替换承重柱；玻璃观察带中不插入铁栏杆。屋顶半砖收边直接由连续实体屋面承托。

全部使用 Minecraft Java 1.21.1 原版方块，不使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。排气立柱与挡墙仅为建筑造型，不提供排气、净化或防护业务效果。

## 尺寸与接口

| 项目 | 模板局部坐标／尺寸 |
| --- | --- |
| 文件尺寸 X × Y × Z | **31 × 22 × 31** |
| 水平占地 | **31 × 31 格**，包含棚顶、灯具、排气立柱与全部外挑构件 |
| 实体高度 | **13 格**；保存高度包含上部生产空气 |
| 地坪 | Y=1，Y=2 为第一层空气 |
| 露天生产面 | X=4…27、Z=1…24，**24 × 24 格** |
| 货柜生成净空 | (4, 2, 1) → (27, 21, 24)，**24 × 20 × 24**，含端点 |
| 制造台设备位 | (4, 2, 25) → (8, 5, 30)，**5 × 4 × 6** |
| 棚下操作位 | (13, 2, 26) → (21, 5, 28)，**9 × 4 × 3** |
| 防护棚 | X=0…23、Z=25…30，完全位于生产净空之外 |
| 排气构筑物 | X=24…30、Z=26…30，占用后部独立台基 |
| 正面接合口 | Z=0、X=13…18，六格宽，地坪 Y=1 |
| 左侧人员入口 | X=0、Z=13…16，四格宽，含侧向石阶 |
| 左侧通道 | X=1…3，沿生产面边缘进入后部服务带 |

坐标以本附件包围盒最小角为原点，正面朝向 -Z。生产面、设备位、地坪和主要接合口与 BDS／AUI 共用规格；操作位与建筑形体按本版坐标安装。制造台设备位后缘不封墙，保留完整六格深度。

生产面上方无棚顶、吊臂或灯具，地面转角标记与边线齐平；中央不设置 H 标志。保存的空气同样属于 NBT 占位，拼装时为整个包围盒留出空间、对齐道路地坪，避免以空气覆盖邻近建筑。
