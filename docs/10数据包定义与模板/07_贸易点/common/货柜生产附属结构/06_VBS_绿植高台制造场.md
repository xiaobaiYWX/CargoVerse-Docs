# VBS · 绿植高台货柜制造场 01

供**绿洲农业联盟（VBS）**旗下贸易点复用的简洁生产附件：后部只设置一条二层开放操作平台，首层和外围以树叶、蕨类与花草形成绿化，地面保留完整生产场。梯田农林站、云泽水产与育种站、绿洲生物工程站均按固定工坊接入。

## 空间与绿化

生产场与首层设备区地坪均为 Y=1，二层楼板为 Y=7。二层是连续开放操作台，不包含房屋、温室或屋顶。木质柱梁配浅色石柱脚，平台边缘以白色构件和黄绿色标记体现 VBS 风格。

首层右侧设置较密的橡树叶、开花杜鹃树叶、蕨类与花草；外围以树叶绿篱和植物块围合。树叶设为持久状态。制造台预留、干燥操作位、楼梯口和侧通道保留空地，植物不进入生产净空。少量灯具位于柱顶或偏置支座下，连续柱梁不被灯具替换。

## 加载与接入

```text
cargoverse:common/container_manufacturing/vbs/open_yard_01
```

相对存档文件：`generated/cargoverse/structures/common/container_manufacturing/vbs/open_yard_01.nbt`。当前文件已替换本制造商之前的方案，沿用同一个加载名称。

采用 Minecraft Java 1.21.1 原版建筑与植物方块，未使用铁块、金块、钻石块、下界合金块、绿宝石块或信标。模板不预置实际制造台、注册终端、货柜实体、生成点或 UUID；操作平台也不自动提供远程业务功能。

| 使用站点 | 接入安排 |
| --- | --- |
| [梯田农林站](<../../resource/梯田农林站/结构设计/02_货柜生成结构.md>) | 固定工坊；既有注册领取与普通制造共用附件的一处生成点 |
| [云泽水产与育种站](<../../resource/云泽水产与育种站/结构设计/02_货柜生成结构.md>) | 固定工坊；保持设备与生产场干燥，养殖水体不接入场内 |
| [绿洲生物工程站](<../../factory/绿洲生物工程站/结构设计/02_货柜生成结构.md>) | 固定工坊；保留原制造目录与合作柜安排 |

三站共用外观，制造能力仍按各站定义。云泽水产与育种站、绿洲生物工程站继续没有基础领取服务。原 H 平台为既有收发方案；采用新增[VBS 分离式装卸场](<../装卸场地/06_VBS_绿植高台装卸场.md>)时，按各方向功能页单独接入，不能混用本制造附件的 Y=7 楼板或 24×24 生成范围。实际转运、落位和绑定后续配置；本附件尚未合入整站 NBT。
