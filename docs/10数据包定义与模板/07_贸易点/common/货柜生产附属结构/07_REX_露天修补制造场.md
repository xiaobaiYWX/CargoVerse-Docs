# REX · 露天修补货柜制造场 01

供**遗民贸易协会（REX）**复用的独立生产附属模板。采用完全露天的修补场，以回收铜板、旧石材和少量木板体现反复维修的场地历史，不设置固定品牌点缀色。

遗民打捞交换所保留专业目录；旧世珍品商馆和远界异常交换站固定安装制造台与一处生成点，各提供 Salvage S，不新增注册权益。

## 概念与形体

![REX 露天修补制造场概念图](<../../../../assets/images/trade_points/common/container_manufacturing/rex/open_yard_01/concept.png>)

一张完整附件概念图作为形体参考，生产空地占主体，后侧只留六格深的服务带。省去房屋、顶棚和大型吊机，以低矮旧护栏、两根独立高灯柱、露天设备空位和小型静态工作台形成轮廓。见[概念提示词](<../../../../assets/images/trade_points/common/container_manufacturing/rex/open_yard_01/concept_prompt.txt>)。

地面由大小不同、边缘错开的铜板修补片组成，局部沿接缝再补入小片材料；石砖、开裂石砖、安山岩、深板岩砖和木板穿插其间。生产地坪使用八种铜材：铜块及四种氧化阶段对应的切制／未切制变体，全部涂蜡。后侧样件另使用涂蜡雕纹铜块。颜色变化用于表达回收来源与维修年代，不依靠真实坑洞或凸起杂物模拟破损。

全部采用 Minecraft Java 1.21.1 原版方块。铜材统一涂蜡；生产面全部为顶面齐平的完整方块，不使用半砖、活板门或镂空格栅填补地坪。灯具设置在独立灯座或侧伸灯臂下，不替换柱身。

## 尺寸与接口

| 项目 | 模板局部坐标／尺寸 |
| --- | --- |
| 文件尺寸 X × Y × Z | **31 × 22 × 31** |
| 水平占地 | **31 × 31 格**，包括护栏、灯柱与后部工作区 |
| 实体高度 | 10 格；保存高度包含生产面上方空气 |
| 地坪 | Y=1；Y=2 为第一层空气 |
| 露天生产面 | X=4…27、Z=1…24，**24 × 24 格** |
| 生成净空 | (4, 2, 1) → (27, 21, 24)，**24 × 20 × 24** |
| 制造台设备位 | (4, 2, 25) → (8, 5, 30)，**5 × 4 × 6**；前后开敞 |
| 露天操作位 | (10, 2, 26) → (16, 5, 29)，**7 × 4 × 4** |
| 后部服务带 | Z=25…30，六格深；设备、操作位与工作台均不设屋顶 |
| 静态工作台与矮架 | X=18…28、Z=29；其前方保留通路 |
| 正面主接口 | Z=0、X=13…18，六格宽，地坪 Y=1 |
| 左侧人员入口 | X=0、Z=13…16，四格宽，含石阶 |
| 左侧通路 | X=1…3，沿生产面外缘进入后部服务带 |

坐标以附属模板包围盒最小角为原点，正面朝向 -Z。后侧设备位不封围栏，前后均保持完整安装宽度；人员操作位位于设备右侧，静态工作台在更右侧。所有灯柱、旧栏杆和架体均位于生产空腔之外。

## 加载与接入

```text
cargoverse:common/container_manufacturing/rex/open_yard_01
```

相对存档文件：`generated/cargoverse/structures/common/container_manufacturing/rex/open_yard_01.nbt`。

共享目录交付一份 NBT；场地未合并进各站原整站文件。对齐道路地坪后，以前方接口或左侧入口连接，给整个保存包围盒保留独立空间。工作台与架体只作静态布景，模板未放置实际制造台、注册终端、生成点控制器、货柜实体或业务绑定。

遗民打捞交换所现有注册领取和普通制造共用本附件的一处生成点，注册权益保持原定义；Salvage S／M／L 的制造目录、材料与费用不变。原 H 平台为既有收发方案；改用新增[REX 分离式装卸场](<../装卸场地/07_REX_露天修补装卸场.md>)时，按各方向功能页单独接入，不套用本附件的 24×24 生成范围。制造附件本身不增加装卸场。成品运输与设备朝向在现场安排。

旧世珍品商馆与远界异常交换站按固定配套制造台接入，使用 Salvage S 统一配方；不新增基础领取。模板已交付不表示两站已经安装设备，实际拼接与绑定待接入。
