# HRI · 下沉观察货柜制造场 01

供**地平线研究院（HRI）**旗下贸易点复用的独立货柜生产附件。精密电子与测绘中心使用固定工坊，地平线野外科考站和虚空相位研究站也固定接入制造台及一处生成点。

## 概念与高低关系

![HRI 双标高货柜制造场概念图](<../../../../assets/images/trade_points/common/container_manufacturing/hri/open_yard_01/concept.png>)

使用内置图片生成功能制作一张统一参考板，包含主透视与同一结构的俯视图；[生成提示词](<../../../../assets/images/trade_points/common/container_manufacturing/hri/open_yard_01/concept_prompt.txt>)与当前资产一起保存。根据图中的生产场、挡墙、平台和楼梯关系落实模板，不把局部噪点扩展成额外建筑。

中央为完整平整的露天生产场，两侧步道及后部服务台**高出两格**。正面货柜接口与生产地面平齐，人员通过左侧入口或后方三格宽短梯进入高台。生产场相对高台下沉，不需要在正面货柜通路中跨越台阶。

后部左侧为向前后开敞的设备棚，右侧为玻璃观察舱，楼梯与中间平台连通两者。观察舱入口设在面向梯顶的西侧，避免在下沉场上方留下没有落脚处的门洞；设备位后方不封墙。最右后角以小型仪器杆形成轮廓，所有屋面和仪器均位于生产净空之外。

灰色石材为主体，蓝色在棚檐、观察舱檐口、挡墙与齐平地面标记上重复出现，表达 HRI 特征。挡墙嵌灯由实体墙背衬，棚下灯装在顶板下，不截断柱梁。玻璃块用于观察窗，浅灰玻璃板用于高台护栏，玻璃内不混入铁栅栏；平屋面半砖直接落在实体顶板上。

## 尺寸与标高

| 项目 | 本模板局部坐标／尺寸 |
| --- | --- |
| 文件尺寸 X × Y × Z | **31 × 22 × 31** |
| 水平占地 | **31 × 31 格**，包含楼梯、屋面与仪器杆 |
| 实体高度 | **14 格**；其余保存高度用于生产净空 |
| 生产地坪／正面接合地坪 | **Y=1** |
| 高台、设备棚、观察舱地坪 | **Y=3**，比生产面高两格 |
| 户外生产面 | X=4…27、Z=1…24，**24 × 24 格** |
| 生成检测空腔 | (4, 2, 1) → (27, 21, 24)，**24 × 20 × 24**，含端点 |
| 高台制造台设备位 | **(4, 4, 25) → (8, 7, 30)**，**5 × 4 × 6** |
| 观察舱操作位 | (16, 4, 27) → (23, 7, 29)，**8 × 4 × 3** |
| 设备棚 | X=0…9、Z=25…30 |
| 观察舱 | X=14…25、Z=25…30；西侧开口 X=14、Z=27…28 |
| 后部连接楼梯 | X=10…12，Z=25 下级 Y=2、Z=26 上级 Y=3，梯顶地坪 Y=3 |
| 正面货柜接合口 | X=13…18、Z=0，六格宽，无高差 |
| 左侧人员入口 | Z=13…16，四格宽；X=0 下级 Y=2，X=1 上级 Y=3，向东进入高台 |
| 左侧高台步道 | X=1…2 主通路，边缘为玻璃护栏 |

正面朝向 -Z，全部坐标以附件包围盒最小角为原点。生产面与主接合口沿用前几版规格，**制造台设备位和观察舱的第一层空气为 Y=4，不能沿用 BDS／AUI／HEC 的 Y=2 设备标高**。

设备安装区域保留开口，人员通过侧向高台和梯顶平台抵达；制造设备按实际模型另行布置。生产地面没有凹凸装饰、立柱或 H 标记。净空内保存空气，接合时为整个包围盒预留独立空间，不以空气覆盖邻近建筑。
