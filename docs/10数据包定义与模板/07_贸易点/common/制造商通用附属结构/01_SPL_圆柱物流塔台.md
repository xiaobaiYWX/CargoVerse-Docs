# SPL · 圆柱物流塔台 01

云港物流集团风格的独立小型塔台。整体包围盒为 **12×18×12**，包括圆形基座、入口台阶、门雨篷和屋檐。塔身采用阶梯状圆形截面，上部扩大为环形玻璃观察室；可作为物流场地的独立观察与值守建筑。

## 概念与尺度

![SPL 圆柱物流塔台概念图](<../../../../assets/images/trade_points/common/manufacturer_annexes/spl/control_tower_01/concept.png>)

主参考由内置图片生成功能制作，形体采用圆柱塔身、环形玻璃观察室和圆形平屋顶。[当前概念提示词](<../../../../assets/images/trade_points/common/manufacturer_annexes/spl/control_tower_01/concept_prompt.txt>)。

尺寸以两格高门扇、两格净宽楼梯和三格高观察室为基准：塔身外接宽度约 8 格，观察室约 10 格，基座与屋檐最宽 12 格；首层地坪 Y=1，观察层地坪 Y=12，屋顶最高方块层为 Y=17。概念图中更细的圆弧和纹理不直接当作方块数量，实际采用方块能组成的阶梯圆形边界，不按图片比例扩大整体。

深灰深板岩柱带随圆形立面布置，浅色墙体间设置成对窄窗；橙色用于观察室下方环带、屋顶边缘和入口标识。上层使用连续普通玻璃，铁栏杆只围护室内楼梯口，不充当玻璃窗格。灯具在独立吊点或屋檐下方，保留柱梁完整。

## 空间与通行

| 项目 | 局部坐标或说明 |
| --- | --- |
| 文件尺寸 X × Y × Z | **12 × 18 × 12** |
| 外形 | 圆形基座、圆柱塔身、外挑环形观察室与圆形平顶 |
| 正面 | -Z |
| 主入口 | X=5…6、Z=2，门扇 Y=2…3；外部台阶在 Z=0 |
| 首层地坪 | Y=1 |
| 第一道楼梯 | X=3…4，Z=4→6，阶梯 Y=2→4，朝 +Z 上行 |
| 第二道楼梯 | X=7…8，Z=6→4，阶梯 Y=5→7，朝 -Z 上行 |
| 第三道楼梯 | X=3…4，Z=4→6，阶梯 Y=8→10，朝 +Z 上行 |
| 第四道楼梯 | X=7…8，Z=6→5，阶梯 Y=11→12，朝 -Z 上行 |
| 中间休息平台 | 地坪 Y=4、Y=7、Y=10；轮流在塔身前后折返 |
| 观察层地坪 | Y=12，楼梯口按实际通行范围留空并设围护 |
| 主要操作预留 | (3, 13, 3) → (8, 14, 4)，另有邻近窗边余量 |
| 观察层玻璃 | Y=13…15；层内保持三格高度，局部顶灯位于 Y=15 |
| 屋顶 | 实体顶板 Y=16；同形底半砖压顶 Y=17 |

所有坐标均以塔台包围盒最小角为原点。内部楼梯两格宽，通过三个平台折返抵达观察层；中心实体与塔身外墙共同形成支撑。顶部留空供后续布置控制台和设备，不预设业务终端。
