### 平面与构造

主屋 X=3～19、Z=8～18；左侧主屋脊沿 X=7，右侧较低屋脊沿 X=15，两段均沿 Z 轴延伸并在谷部衔接。前伸门廊位于 X=11～19、Z=3～7，与单门及楼梯共用 X=15 中轴。细桅杆位于右后侧，顶部观测件及避雷针计入总高 23 格。

| 使用分区 | 建筑内位置（局部 X、Z，边界含端点） |
| --- | --- |
| 值守木屋 | (3, 8) 至 (19, 18) |
| 偏右入口门廊 | (11, 3) 至 (19, 7) |
| 百叶观测箱 | (19, 1) 至 (21, 3) |
| 观测桅杆及顶部附件投影 | (20, 13) 至 (22, 17) |
| 左侧主坡屋面投影 | (2, 7) 至 (12, 19) |
| 右侧门廊与主屋连续坡面投影 | (10, 3) 至 (20, 19) |

基础、门前铺地、屋檐和观测构件均计入实际包围盒。两段石屋顶以较高坡面为准组合，交接谷部用完整石砖封合；外缘为安山岩封边和独立木饰板，前沿不额外填一堵遮挡山墙的墙。柱梁先于灯具放置，门廊灯直接挂在梁底，保持两格行走净空。连续玻璃不混入铁栏杆。HRI 标识以蓝色门边色块与门廊小饰块表达，图中文字铭牌未写入。

桅杆使用从地基连续向上的脚手架杆体，保留原版攀爬性质；顶部风向布、横臂和小观测件为静态外观构件，不采集气象数据。百叶箱采用独立支脚、石英主体、白桦活板门围面与薄顶盖，未制作额外维护棚。
