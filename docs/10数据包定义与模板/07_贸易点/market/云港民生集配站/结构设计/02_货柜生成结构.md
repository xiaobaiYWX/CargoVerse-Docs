## 作用与启用条件

本站固定配置制造台与一处生成点。已有注册领取与普通制造共用这一处生成点；原注册权益保持不变。

| 项目 | 本站安排 |
| --- | --- |
| 基础货柜领取 | 现有 registration_point 通过注册终端提供，领取使用本生成点；与普通制造共用本站固定生成点 |
| 普通制造 | 固定配套制造台：民生周转补柜亭；详见[制造目录](<../定义设计/01_货柜制造台定义.md>) |
| 生成点 | 本站固定安装 1 处生成点，所有实际存在的制造／注册终端绑定同一点 ID |
| 生成位置 | SPL 专用生产附件的 二层24×24 露天场地；装卸按各方向功能页使用独立范围 |
| 制造任务 | Courier 轻型配送柜 S／M；Express 特快专递舱 S |
| 业务边界 | 普通制造消耗玩家实体材料与加工费；资源表货物不是制造材料；不自动修理、移柜或生产货物 |

使用 Courier 跑麦粒、口粮和工装；准备小件医疗或电子运输时可选 Express。补柜亭固定提供目录，扩大干线运量前往 S02；灯具的易碎要求不会被这两系列消除。

## 场地与结构

采用**云港物流集团（SPL）· 双层物流制造场 01**，同制造商站点共用一份模板。本站将该附件作为必需功能组件接入。原有整站文件尚未合入本附件，需以主接合口另行连接到站内道路；不直接覆盖原收发平台。

![SPL 制造附件概念图](<../../../../../assets/images/trade_points/common/container_manufacturing/spl/open_yard_01/concept.png>)

![SPL 制造附件实际 NBT](<../../../../../assets/images/trade_points/common/container_manufacturing/spl/open_yard_01/actual.png>)

首层为柱网承托的开放物流作业区，两只静态货运箱体、木托盘和矮工作台位于通道之外；实际制造台与操作位预留在首层后侧。二层设置完整的 24×24 露天生产面，以右侧两格宽侧梯连接。深灰柱梁配灰色地坪，橙色边带与白色柱身标记体现 SPL 风格。 图片资产集中存放，由各站引用；完整平面、材料与提示词见[制造商模板说明](<../../../common/货柜生产附属结构/08_SPL_双层物流制造场.md>)。

首层屋面即二层生产楼板；柱梁在检测空腔下方，二层上方完全露天，灯具、边栏与侧梯均退出生成空腔。设备位保留完整后缘，不用围栏封掉安装深度。定位点控制器放在检测体积外并配置二层范围；首层制造台绑定该生成点，朝向与占地按实际模型落实。装饰货柜与托盘均为静态原版布景，不带货柜实体或库存。侧梯用于人员通行，不提供自动升降或移柜。

当前 NBT 只提供原版建筑与地面标识，不含模组终端、生成点、货柜实体、测试 UUID 或拼图绑定。现场需记录本附件原点、旋转以及控制器位置，再计算点位偏移；不能将上述局部坐标当成已完成配置。

## 与收发平台的分工

普通制造固定使用 SPL 生产附件二层的一处生成点。已有注册领取与普通制造共用这一处生成点；原注册权益保持不变。 装载和卸载按各自功能页配置范围，采用分离式场地时不得把本生产附件坐标写入装卸定位点。

成品按现场运输方式移至装卸区域或驶离，不增加自动移柜、排队或额外货物。

## 设备与绑定

制造台、实际存在的注册终端与生成点绑定本站同一实例 UUID；业务终端指向同一个生成点 ID。装载、卸载终端仍绑定同一实例，使用各自装卸点。

点位偏移按目标原点减控制器位置计算，每轴 -64..64，范围每轴 1..32。检测空腔须为空气且能容纳目标货柜；后续配置以旋转和落位后的世界范围为准。保存二十格空气不能代替相邻建筑、地形与现场点位的实际安排。

## 工坊布局与交付

营业区道路固定接入 SPL 双层物流制造场。首层安装制造台与操作位，二层露天生成成品；值班亭、包装棚和休息廊作为额外装饰，不替代生产附件。

当前附属模板为 `common/container_manufacturing/spl/open_yard_01.nbt`，已交付独立 NBT，尚未合入本站整站文件。机器位于首层 Y=1 地坪，预留 5×4×6 并另设操作位；24×24 露天生产面位于二层 Y=8，生成空气从 Y=9 开始；安装坐标见[本站货柜生成结构](<02_货柜生成结构.md>)。材料仍来自玩家背包与快捷栏，收发货继续使用原共用平台。已有注册领取与普通制造共用这一处生成点；原注册权益保持不变。

必备制造设施与随机装饰安排见[本站生成规则](<../生成规则/00_生成规则.md#附属工坊生成>)；目录、材料和加工费见[制造台定义](<../定义设计/01_货柜制造台定义.md>)。
