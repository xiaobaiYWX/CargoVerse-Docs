## 结构与生成入口

[工坊布局、生成点与设备安装](<../结构设计/02_货柜生成结构.md#工坊布局与交付>) · [世界生成与附属工坊规则](<../生成规则/00_生成规则.md>)。本页维护服务定位、柜型目录、配方和功能绑定。

## 功能定位

**固定专业工坊**。枢纽只收购货物，但承运人会在完成交货后扩充或改配下次任务所需货柜。制造服务围绕下一次取货组织，不能误写为本站有返程货可买。

Cargo 对应水泥、钢梁等大宗常规件；Courier／Express 服务跨航线周转。Nomad M、Vulcan M 是两项 AUI 签约装配，分别补齐本港大量接收的预制件／装卸机和航电／车辆，避免 SPL 自有目录无法覆盖主干订单。

仅引入 AUI 两个 M 型，不引入重载高阶或其他品牌全目录；本站资源表仍只收购。

## 货物任务与柜型选择

| 系列与规格 | 本地／关联航线中的用途 | 实际货物示例 |
| --- | --- | --- |
| Courier 轻型配送柜 S／M | 完成港务交货后的民生线路换装 | 长效口粮、袋装麦粒 |
| Cargo 干线周转柜 M／L | 钢梁、水泥及常规建筑材料干线周转 | 标准钢梁、袋装水泥 |
| Express 特快专递舱 S | 航电与小件跨线调度，仍需自行防潮／防碎 | 航电控制器、推进器叶轮 |
| Nomad 拓殖工程柜 M | 签约装配：港口接收的建筑模块与装卸机用固定架 | 飞艇龙骨模块、自动装卸机 |
| Vulcan 精密工业柜 M | 签约装配：本港接收的航电、叶轮和牵引车 | 航电控制器、推进器叶轮、港区牵引车 |

柜型仅允许定义中的 CargoClass，不同货物不可混装；防护由现有 special_designs 决定，限时要求始终保留。

关联备柜节点：[A01 标准建材装配港](<../../../factory/标准建材装配港/定义设计/01_货柜制造台定义.md>)、[A02 通用机电装备厂](<../../../factory/通用机电装备厂/定义设计/01_货柜制造台定义.md>)。具体规格以各节点目录为准；这些节点分别补充不同任务，并非每个节点都覆盖本站全部型号，也不保证在地图上相邻。

## 定义与实例绑定

目标定义 ID：`cargoverse:market/sky_station/longhaul_port`；目标路径：`data/cargoverse/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/market/sky_station/longhaul_port.json`。以下定义已同步内置数据包。制造台、生成点与营业核心共用本站 UUID，不新增锚点、库存或第二个贸易点。

合入 `modules` 的片段（保留本站其他功能）：

```json
{
  "cargo_manufacturing_platform": {
    "min_prosperity_level": 0,
    "definitions_pool": [
      {
        "weight": 1,
        "definition": "cargoverse:market/sky_station/longhaul_port"

    ]
  }
}
```
