# 远航货运枢纽 · 贸易点定义

## 当前状态

整站结构、经济定义、绑定及生成配置已接入；正式货物买卖表尚为空。实际物品报价为待落数据设计，不将拟议目录、价格和库存当作现行营业内容。地形、装卸与营业流程仍待实机验收。

## 身份与定位

编号 **S02**；归属 **云港物流集团（SPL）**；资源 ID `cargoverse:market/sky_station/longhaul_port`。

**仓储、转运与港口设备供应。** 集中供应 Create 保险库、漏斗、传送带、储罐和过滤器，让货运赚得的资金可直接用于物流设施。采购包装、系泊推进部件与日常补给，保持港口配套需求而非全商品交易中心。

本站保留既有货柜制造、注册与完整装卸功能；商品业务不改变结构、归属或生成规则。
