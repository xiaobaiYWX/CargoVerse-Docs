### 平面与构造

主屋墙柱范围 X=2～21、Z=5～18，统一屋面覆盖 X=1～22、Z=4～19；封闭店铺止于 X=14，右侧开放分类间收在 X=15～21。屋脊偏向店铺一侧，右坡缓缓延伸至分类间，不另加独立棚屋。

| 使用分区 | 建筑内位置（局部 X、Z，边界含端点） |
| --- | --- |
| 旧件检验铺 | (2, 5) 至 (14, 18) |
| 同屋顶内凹分类开间 | (15, 5) 至 (21, 18) |
| 店铺双门与前侧台阶 | 门位 X=11～12、Z=5；台阶 X=10～13、Z=3 |
| 店铺至分类间通道 | X=14、Z=13～14；净宽 2 格、净高 3 格 |
| 开放分类货架 | X=17～20、Z=10 与 Z=17；前侧和两组货架之间保留通道 |

正立面柱位为 X=2、9、14、21，侧面柱位沿 Z=5、11、18 排列；木柱落在石砖柱脚上，梁下设木托架。左侧展示窗为 4×3 格玻璃板，右侧双门上方设高窗，窗框与柱网分别建造。

屋面以半格高度分层，铜片和木补板按成片修补区域布置；每层抬高处下方补齐木质衬底，檐口与木梁接合。灯笼位于柱旁或梁下预留空位，不替换承重构件。玻璃不混入铁栏杆，货架的细支腿使用墙方块。基础、门前铺地、屋檐及烟囱均计入包围盒。独立经营，不采用 REX 标识。
