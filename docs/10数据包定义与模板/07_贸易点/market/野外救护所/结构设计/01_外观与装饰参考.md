## 本次采用的单栋参考

浅墙、宽窗、铜绿四坡屋面和居中门廊的救护屋。 登记、观察和清洁补给集中在一栋主屋内，门廊与两侧宽窗形成清晰入口；不预装治疗或复活功能。

本站由独立经营者维护，不因经营内容或采购设备而套用制造商配色、站徽。

## 从参考到方块尺度

- 模板包围盒为 **24×16×22**（宽×高×深），包含基础、木檐、烟道与外部附件，水平仍保持 24×22。
- 用两格高双门、上方一格亮窗和一格宽木柱校准入口，再安排窗、檐口和四坡顶；人物、玻璃反光与铜锈纹理不计作独立方块。
- 主屋 X=2～21、Z=7～18，门廊 X=8～15、Z=3～6。主屋与门廊地坪 Y=2，室外 Y=1，门前用楼梯方块连接一格高差。
- 门、门廊柱、小山墙和绿白标识统一使用 X=11.5 的中轴。前面两组宽窗为 4×3 格，侧面窄窗为 2×3 格，后面窄窗为 2×2 格；每组重复构件均由相同规则推导。
- 主四坡屋面从 Y=8 起，每向内一格抬高半格，最高铜屋面为 Y=11 的下半砖；主屋最高点由烟道的 Y=15 压顶决定。半格阶差下方填实，不留下连续镂空。
- 门廊小坡面檐口 Y=7、双格屋脊 Y=11，向后延续至与主屋面相接的位置，保留明确的小山墙与厚木边。绿白标识采用居中的 4×3 方块图案，是原图小标牌在有限方块尺度下的近似，未扩大整座门廊以容纳细线图案。

保持一栋矩形救护屋及其入口门廊，不增加独立清洁补给侧翼。补回前窗候诊凳、门边花桶、窄种植带和少量窗内盆栽；床位、隔间、医疗设备与营业绑定留待后续编辑。

## 材料与构件对应

| 图中部位 | 本次原版方块选择 |
| --- | --- |
| 浅色墙体 | 平滑砂岩，替换首版偏粉的白色陶瓦；以连续浅墙表达抹灰面 |
| 木框、门廊柱与连续檐口 | 带皮云杉立柱、按轴向设置的去皮云杉横梁，云杉倒置楼梯托架与山墙木边 |
| 四坡铜屋面 | 涂蜡锈蚀切制铜整块与半砖，逐格半格递升；少量涂蜡氧化铜作成片差异，小门廊使用铜楼梯及屋脊半砖 |
| 石墙脚、柱脚和入口踏步 | 石砖、磨制安山岩，室内桦木地板只铺在石边以内；入口使用石砖楼梯 |
| 宽窗、窄窗和双门 | 纯玻璃板、云杉双门、去皮云杉门框；外挑石窗台、木窗楣和必要室内木窗台分开制作 |
| 救护识别 | 小范围绿色混凝土底与白色混凝土十字，表示救护用途，不代表制造商品牌 |
| 独立灯座和灯具 | 木托架、完整梁底与灯笼；门边灯靠柱布置，未用灯具替换柱体 |
| 候诊附件 | 云杉楼梯长凳和活板门扶手、空木桶花槽、持久树叶与蕨盆栽；不附容器物品 |
| 烟道与罩顶 | 连续石砖烟道、局部磨制安山岩、磨制深板岩墙和半砖帽；上部薄构件有实体支承 |
| 前场与沿墙植被 | 石砖铺地、少量安山岩、砂砾和砂土；草地、树叶、短草与蕨组成窄种植带 |

采用 Java 1.21.1 原版方块，执行[统一材料规则](<../../../README.md#建筑材料选择>)。玻璃接缝不以铁栏杆表达；细柱与灯座按需要采用墙系列。屋面、门廊和柱梁保持连续，灯具不替换结构构件。

本次分别制作石基和柱网、墙面与窗组、逐层四坡顶、门廊与主屋面的连接、候诊附件和照明。各层屋面的下方实心背衬属于封口构造，避免薄屋面与完整墙梁接触时出现半格缝；不会将这一背衬扩展到室内可用空间。

**编辑交付不添加结构空位。** 室内外未占用格均保留为空气，结构空位由后续手工修改完成后添加。只覆盖原 `building.nbt`，使用同一个加载名称。
