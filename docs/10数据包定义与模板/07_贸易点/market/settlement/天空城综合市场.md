## 收售概览

出售：无。

收购：民用照明器具、温室鲜果、水培叶菜、冰鲜河鱼、冰鲜海虾、鲜采食用海带、净化鲜贝、陈酿佳酿、精工饰品、修复旧世艺术品。

货物标签、逐项初始库存、容量和日变化统一见关联资源表；两侧各自维护库存。

## 建议结构内容

**建筑形象：**明亮的石木街区、彩色棚布和清楚的市场招牌；可直接落在原版陆地聚落环境。

| 建筑／分区 | 建议内容 |
| --- | --- |
| 公共收货广场 | 集中布置卸货机和仓库信息，供生鲜与民用品整柜交付。 |
| 生鲜街 | 设置果蔬棚、鱼摊和水产陈列，强调消费去处而非新商店系统。 |
| 生活与珍品街 | 照明、酒馆陈列、饰品橱窗和小型艺术展厅共同表现不同层次的居民需求。 |
| 居民附楼 | 增加住宅门面、储藏间与公共休息区，让市场有稳定人口背景。 |

**行走与装卸路线：**地面入口 → 收货广场 → 中心信息亭 → 各类摊位街；货柜泊位与行人街道分开。

**最小可营业核心：**贸易点信息柜（唯一注册锚点）、仓库信息柜、货物卸载机。保留卸货操作区；本站没有出售目录，不设置可用的装货终端。基础泊位须满足实际货柜尺寸与净空，不能只用展示货柜代替。必要终端及最低泊位集中在不会因可选支路缺失而失效的营业核心中。

**可选扩展：**可选添加钟楼、喷泉、外摆棚或装饰 NPC 空间；首版不自动接入物品售货功能。

以上陈列、工艺设备与建筑用途为美术和空间建议。除已绑定的业务终端外，不自动新增 NPC、加工、气候、库存或货物产出机制。首版没有绑定商店或货柜制造台，不把展厅、柜台或车间当成已接入这些功能。

## 功能与结构

首版 `modules: {}`，不额外绑定注册点。

首版不绑定物品商店和货柜制造台；现有默认演示模块的商品与配方不能直接代表本节点。后续按各制造商单独设计这些功能。

结构需设置一个贸易点信息柜注册锚点、货物卸载机、仓库信息柜、对应货柜的装卸泊位。所有终端绑定同一实例 UUID。

地图距离和环境危害需要在结构落点时确定；内容投放阶段不提供代码级许可、科技或区域准入限制。
