## 从参考到方块尺度

- 模板包围盒为 **24×10×22**（宽×高×深），水平固定在 24×22 内，包含屋檐和附件。
- 以两格高的人行门、可用通路和实际柱跨校准；图中人物、文字和微小材质纹理不当作精确方块计数。
- 主屋与施工开间地坪 Y=2，室外地坪 Y=1；门前台阶处理这一格高差。
- 主屋 X=2～15，开放末开间 X=16～21，共用 Z=6～18 的纵向边界与 Y=7 横梁；侧面通道净宽 2 格、净高 3 格。
- 正门轴线 X=8.5，左右墙面开间对应布置窄窗；门头雨篷和台阶均围绕该轴线设置。
- 主屋保持低矮平屋顶和半格压边，施工开间前段留空、后段铺设浅坡木屋顶；木屋面接缝下方封实，不让半砖层差形成缝隙。

细节集中于可见构件：木柱石脚、檐口托架、门头雨篷、窗台、长凳、木桶花箱和少量材料堆。施工差异表现为同一建筑的完工程度，不额外加入独立棚屋；室内家具与营业设备留待后续编辑。

## 材料与构件对应

| 图中部位 | 本次原版方块选择 |
| --- | --- |
| 浅色墙与木框架 | 白色混凝土填充墙、橡木原木柱、去皮橡木横梁、石砖墙脚 |
| 已完成平屋面 | 磨制深板岩屋面及半格压边、磨制安山岩檐边、四处石砖台阶角帽 |
| 檐口与入口 | 连续橡木檐梁、楼梯托架、橡木台阶雨篷、云杉双门、石砖入口台阶 |
| 窗与门头 | 纯玻璃板、木窗台和木窗楣；玻璃中不混入铁栏杆 |
| 未完工末开间 | 连续橡木梁柱、侧后橡木栅栏、云杉木板与台阶后段屋盖 |
| 外部材料与家具 | 少量平滑砂岩、橡木板垛、空木桶、工作台、木长凳 |
| 铺地、照明与植被 | 粗泥、砂砾、圆石和局部石砖通道；梁下灯笼、树叶花箱、蕨和矮草 |

采用 Java 1.21.1 原版方块，执行[统一材料规则](<../../../README.md#建筑材料选择>)。玻璃接缝不以铁栏杆表达；细柱与灯座按需要采用墙系列。屋面、门廊和柱梁保持连续，灯具不替换结构构件。
