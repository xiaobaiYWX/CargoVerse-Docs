### 平面与构造

主屋 X=2～15，开放末开间 X=16～21，共用 Z=6～18 的纵向边界与 Y=7 横梁。主屋外檐范围 X=1～16、Z=5～19，后段木屋顶延至 X=22；两部分直接相接，侧墙通道连通室内和施工开间。

| 使用分区 | 建筑内位置（局部 X、Z，边界含端点） |
| --- | --- |
| 施工值守屋 | (2, 6) 至 (15, 18) |
| 同框架未封闭末开间 | (16, 6) 至 (21, 18) |
| 后段遮雨与材料区 | (16, 13) 至 (21, 18) |
| 正门与门头雨篷 | 双门 X=8～9、Z=6；雨篷 X=7～10、Z=4～5 |
| 主屋至施工开间通道 | X=15、Z=14～15；净宽 2 格、净高 3 格 |

正立面柱位为 X=2、6、11、15，形成净宽 3／4／3 格的墙面开间，双门与雨篷以 X=8.5 为共同轴线；外侧施工柱列为 X=21。侧面柱位沿 Z=6、12、18 排列，窄窗居于各自开间中部。柱梁先完成，托架与灯具再放入预留空位。

平屋面采用完整屋面板和半格高压边，檐口下方连续设置木梁；后段木屋顶与灰屋面交接处补齐衬底。施工开间只在侧面和后面设置围栏，正面入口及内部通道保持开放。基础、引道、屋檐及附件均计入包围盒。施工差异通过同一建筑的完工程度表达，不另设第二座值守屋或高大试装架。
