# 自然贸易点实际物品贸易网络

> **待落数据 · 2026-10-20 首轮设计。** 采用已实现的 schema 3 报价能力，替代旧抽象 CargoGood 经济方案。自然站本轮只更新设计文档，40 张运行表仍为空；A／B 两张测试表已单独接入互补实际物品目录。40 个自然站已完成首轮逐物品设计，两个指令测试站不参与本轮经济设计。

## 设计范围与维护位置

本轮覆盖 **24 个天空大站、16 个地面小站、149 种实际物品、189 条出售报价、315 条收购报价**。其中原版 90 种、Create 47 种、航空学 7 种、随航空学提供的 Simulated 5 种；按项目本地 Minecraft 1.21.1、Create 6.0.10、航空学 1.3.0 资源核对。不要求覆盖全部可运输物品，也不把物品装柜资格等同于市场准入。

| 内容 | 唯一维护位置 |
| --- | --- |
| 站点经济职责、商品组合与可选路线 | 本站 `定义设计/02_贸易网络设计.md` |
| 精确物品、rule_id、单价、库存、日补、限额、经验 | [06_资源表](<../06_资源表/README.md>)下本站对应表 |
| 字段语义、组件匹配、经验资格 | [现行报价规则](<../../02贸易点系统/03_资源表定义.md>) |
| 运输类别、质量、损耗与货柜保护 | [实际物品运输配置](<../01_物品运输/README.md>) |
| 制造商、结构与生成 | 本站既有定义、结构和生成页面，本轮不调整 |

不创建全局物品价格表或经验表。**同一物品在不同站点的报价与经验可以不同，只有具体收购条目赋予交付经验。** 本页的示例计算用于解释设计取舍，不作为第二份商品参数清单。

本轮仅使用默认完整组件变体，不设计药水效果、附魔装备、非空容器、流体、实体或整艘载具的交易。设备类商品是可放置的实际物品，买到设备不代表贸易点自动增加该设备对应的经营功能。

## 大小站分工

| 站点 | 业务定位 | 数量与约束 |
| --- | --- | --- |
| 天空大站 | 大宗材料、专业加工品、物流设施与成套设备 | 普通材料供应多柜；少数大宗需求不限额，设备、研究和收藏需求逐项设限 |
| 地面小站 | 地方货源、轻加工、居民消费、野外维护与普通材料回收 | 所有收购有每日限额；常规货源可连续供应数柜，整机更新通常每天仅需 2～4 件 |

天空站保留既有货柜制造、注册与完整装卸；小站不增加制造、注册或领柜服务。日常补给向小站下行，资源和地方加工品向大站上行，小站之间保留原木到制材、设备到农场、口粮到居民点等短线。

同类站没有父子库存关系。收购不建立库存，不触发本站产出；补货不要求玩家先交入原料。生产、配方和玩家工厂保留在实际物品系统中。

## 小站经营归属

继续采用 **12 种独立经营小站、4 种明确派驻小站**。G05 地层采样站与 G14 气象观测哨属于地平线研究院，G06 遗迹清理营属于遗民贸易协会，G08 航路巡防哨属于铁壁防务集团。

其他小站保持 `manufacturer: "none"`。采购某品牌设备或向品牌大站供货，不改变经营归属，也不产生第九家制造商。本轮不因缺少品牌修正而统一抬高独立站价格。

## 商品网络的三个层次

| 用途层次 | 实际商品示例 | 网络作用 |
| --- | --- | --- |
| 通用补给与材料 | 面包、纸、煤／木炭、木板、玻璃、空瓶 | 多源供应、广泛需求，提供顺路生意；通常每件差价较小 |
| 行业配套 | Create 传动杆、齿轮、金属板、管件、泵、电子管 | 连接同业及上下游，重点买方和设备供应方互相补给 |
| 专业与稀缺需求 | 航空气球蒙皮与螺旋桨、陀螺仪构件、浮空材料、有限遗物 | 需要特定接收方与货柜选择，单项库存和需求较小 |

这些是内容设计用途，不增加运行时分类或新的解锁机制。普通物资不全站复制：例如矿站需要燃料与木板，救护所需要纸、空瓶和食品，观测哨需要通信、玻璃与仪器。

面包安排在云港民生集配站、梯田农林站、边境驻防补给港和路畔货运驿站四种站型出售；纸、燃料、木材等也有多个来源。专业整机则允许只有主供站，以保留寻找货源与玩家自制的价值。城市和货运枢纽均只经营明确子集，不成为万能贸易点。

## 工业与航空业务如何形成分工

| 链路 | 主要分工 |
| --- | --- |
| 矿业—冶炼—设备 | 深岩露天矿站提供粗铁／铜／锌；精炼站提供金属锭和合金；重工厂提供板材与矿机；矿站再收购矿机、泵和保险库 |
| 通用机械—地方生产 | 机电厂供应轴、齿轮箱和加工设备；农林、净水、制材、机修站按自身规模采购 |
| 电子—控制—航空 | 测绘中心供应电子管、无线红石和陀螺仪构件；安防厂、观测哨、航空港及相位研究站分别提出不同需求 |
| 航空—物流—驻防 | 航修港供应蒙皮、螺旋桨及系泊件；货运枢纽和边境港收购；航修港采购板材、黏合剂、燃料与浮空材料 |
| 农业—食品—生活 | 农圃和农林站提供农作物，水产站和渔站提供鲜鱼；民生集配站与城市采购，并提供加工食品、文具与生活用品 |

上述联系是贸易机会，不是预设生产配方、强制顺序或生成邻接关系。玩家可以在任何符合现行规则的基地制造实际商品，运到匹配需求的站点出售。

## 报价原则

1. **先确定用途与供需，再填写本站整数单价。** 不从旧 CargoGood 基础价或价格倍率换算，不给运输分类附加市场价值。
2. 普通补给保留低绝对毛利；高价值机械通过较高资金占用、运输要求和有限需求形成差异。
3. 来源站和消费站可以对同一物品采用不同报价，但同站同一精确变体只经营一个方向。
4. 原料、压片、整机和压缩材料必须考虑原版／Create 配方的数量关系。玩家加工获利属于目标玩法；压缩、拆分或低成本加工导致的异常高回报需要在落地前核查。
5. 本轮不出售钻石、下界合金、创造物品、刷怪蛋、无限功能设备或未完成的序列装配中间体。避免将运输直接变成跳过全部探索与制造的商店。
6. 零价值采购、负价格清运与完成运输额外付费均不加入。当前方案所有报价均为正整数。

报价示例中的利润仅为目的地收购额减出发采购额，没有扣除运输损耗、燃料、维修、时间与资金成本，也未应用签约与行情。差价大不代表净收益一定更高。

## 数量、库存与每日限额

**1 个实际物品占 1 个货柜容量单位。** 当前 Atlas S 容量为 55、Atlas L 为 220，本轮不修改这些定义；旧 `t` 数值或物品最大堆叠数不能用作库存换算。

- 小站常规资源通常初始 128～256 件、上限 384～768 件、日补 96～192 件，可以形成多次集货；零料、装饰和设备另设小批数值。
- 大站主供资源通常初始 768～1536 件，上限 2048～4096 件；普通加工品与整机分别采用更小规模。具体差异以各表为准。
- 所有出售都设置有限库存。本轮不使用无限供应；需要时现行格式仍支持省略 `stock` 表示无限。
- 小站全部收购设置正数 `daily_limit`。居民口粮与建材额度明显高于仪器、工具和整机更新额度。
- 大站仅对部分粗矿、燃料或建材需求设置 `daily_limit: 0`；生活补给、加工品、整机和稀有物尽量保持明确的有限需求，允许工厂出现向其他实例或地区销售的动机。
- 唱片与回响碎片采用一次性少量出售批次，日补为 0；稀有但可持续来源的材料使用小额日补，不把两种情况混为一谈。

每日额度按站点实例共享，未用额度不积存。多个同型站点可以形成更多市场容量；不会凭本轮设计新增全服共享配额、距离限制或生产槽位。

库存扩大只解决站点过早售空，不解决轻型食品的货重低于货柜空重、55 件运力偏小等独立问题。不能通过放大价格、经验或显示单位掩盖运力与物理质量问题。

## 许可证与繁荣度经验

经验明确配置在**目的地收购条目**。本轮普通补给多数为每件 1～2 许可证经验，工业材料约 3～4，完整设备与专业材料约 4～8；特殊一次性交付另列，零料或容易大量取得的回收物可为 0。繁荣度经验单独填写，通常相同或更低，不按货款自动计算。

此处是设计取值范围，不是全局经验算法。即使两个买方收到同一物品，也可根据业务规模配置不同数值。

按现行 M 级门槛 2400 经验，完整交付 55 件实际货物时：

| 收购每件许可证经验 | 单批经验 | 从 0 达到 2400 的最少同量交付批次 |
| ---: | ---: | ---: |
| 2 | 110 | 22 |
| 3 | 165 | 15 |
| 4 | 220 | 11 |

这不是承诺每柜都能获得这些经验：设备可能没有 55 件可购或当日可收额度，货柜类别与保护也要匹配。高价少量设备未必比普通材料提供更多总经验。本轮保留现有许可证门槛和繁荣度升级阈值，实际批次时长和成长速度需实机验证。

现行目的地经验规则：

- 自然→自然、玩家→自然：按自然生成目的地成功收购的实际件数获得当地配置的两种经验。
- 玩家生产、探索所得、玩家保险库中转及管理员补货不限制后续成交经验；普通指令创建站作为目的地仍不奖励。
- 自然→玩家、玩家→玩家不奖励；货柜不再保存来源记录，仓库中转后到自然目的地成交仍可奖励。

因此，玩家工厂既能获得商品销售收入，也可通过向自然生成贸易点交付货物促进许可证和目的地繁荣度成长；奖励由目的地收购条目配置，缺省为 0，不把经验写入物品运输属性。

## 普通回收与不再使用的旧商品

回收业务只能使用实际物品。本轮采用铁粒、空瓶、燧石、碎石、砖、腐肉、骨头及完好标准备件等条目；这些物品依然是原物品，不注入“废弃物”身份或新价格组件。

收购空瓶不会增加某站药剂库存，收购腐肉不会按配方自动生产肥料，出售铁粒也不意味着系统拆解过装备。它们只是各站独立供需的内容解释。

旧口粮箱、净水补给箱、废酸回收桶、虚空混合物货物、航空核心部件等抽象名称不再作为报价 ID。净水站现阶段经营管件、滤料、空瓶及环境材料；相位研究站经营实际末地与浮空材料。真正的水、其他流体和实体业务留待对应载荷与设备实现。

## 配方、收入与后续验收

真实物品可以被合成、拆分、熔炼、洗涤或自动生产，价格审查必须覆盖实际配方。重点检查九粒／一锭、原木／木板／木棍、原矿／粉碎矿／金属、面粉／面团／面包、材料／设备和可复制收藏品的数量关系。

本轮不进行运行时成本推导。允许玩家加工获利，但必须防止买入廉价原料、低成本转换后反复向少数无限需求站点倾销，成为远高于实际运输的唯一最优玩法。每日限额只能控制每实例速度，不自动消除跨站套利或多人规模放大。

当前站点 `expected_daily_trade_value`、制造费用、签约修正、许可证门槛和货柜容量沿用原值，不随本轮文档自动修改。商品采购额可能高于旧抽象经济规模，特别需要联合观察活跃度与制造解锁速度；报价不能单独被视作完整经济平衡。

**静态设计检查：** 40 个站型都有出售与收购，每个站型至少有 2 个可获基准差价的直接接收站型；全部 189 条出售都有更高收购报价，全部收购都有自然货源。同站没有同一默认变体的买卖重叠，小站收购全部有限额，设计网络可通过多段货向连接全部站型。

这些结果只说明目录和报价可组合，不证明地图附近一定有买方，也不证明路线扣损后盈利。本轮未进行实机经济测试、全配方成本审计或种子分布测试。

未来落地顺序：先确认逐站目录与运输缺口，再批量写入 schema 3，使用新建经济实例验证装卸、实际价格、目的地经验、共享日限额与补货，最后按实测航程和资金周转调整数值。旧实例保存目录快照，普通 reload 不能直接用来验收新报价。
