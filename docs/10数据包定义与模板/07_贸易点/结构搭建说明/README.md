# 贸易点结构搭建说明

新建与重制统一执行[结构模板工作流：多视角概念图到 NBT](<结构模板工作流.md>)：先生成完整贸易点效果图，再从总图拆出建筑或建筑分段、派生必要局部参考、校准尺度并分别搭建，最后按总图逐处拼接。首次提示词明确门高、梯宽、柱跨与边界；局部构件用于判断实际尺度。原普通／一般流程和高级流程已停止使用。

整站先有一张统一主参考板，确定整体轮廓、建筑比例与连接关系；总平面由该图提取。确需细化的制作对象各派生一张局部参考，同款重复部分共用参考。派生图必须继承总图中的几何、材质和接口，不能只借用风格后重新设计；明显偏离总图的局部变化不采用。忽略噪点、反光和无法成立的扭曲细节，不默认反复生成整站校正版。

| 交付方式 | 设计与产物 |
| --- | --- |
| 拼接模板 | 从整站效果图拆出建筑、建筑分段或构筑物，制作各模块 NBT 并记录接口，连同本站平台组成完整贸易点 |
| 整体贸易点 | 从整站效果图拆分制作，再按总图组装；`station.nbt` 包含全部主体、连接与共用收发平台，中间模型不默认另行交付 |

两种方式采用同一外观还原标准，不固定模块数量，不要求每项功能都对应一栋房屋。尺寸先由门、台阶、柱脚与柱跨校准；拼接单体每轴不超过 32 格，全部外伸构件计入。整体贸易点单边以 76 格为参考，按实际功能确定尺寸，不作为硬上限或必须填满的目标。

拼接方式按总图逐处确定，可以在同站混用。**紧密拼接**用于同一建筑拆开的两部分，或两个直接连接的建筑，接缝处连续衔接柱墙、楼板与屋面；**连廊或广场连接**用于有明显间隔、属于不同体块的建筑，保留图中空地与通路。制作分段不等于独立房屋，有连廊也不意味着全站都要分离。各对象使用独立局部坐标，组装处理明确接口，不靠无计划覆盖形成过渡。整体贸易点的内部制作拆分不额外套用拼接交付的 32 格限制。

每站必须有一处实际收发共用平台，包含 H 标识、设备空间、人员连接和飞行净空。每站目录保留 `cargo_platform.nbt`；整站已含平台时不重复放置。平台的使用范围与实际坐标见本站功能结构页和外观参考及[共用收发货平台](<共用收发货平台.md>)。

单体、整站与平台均遵循[建筑材料选择](<../README.md#建筑材料选择>)。原版 1.21.1 材料只排除铁块、金块、钻石块、下界合金块、绿宝石块和信标，其余按参考图选用。

大面积玻璃统一使用连续的玻璃块或玻璃板，不混入铁栅栏模拟接缝或窗格；独立柱梁与主屋架按建筑构件处理，铁栅栏用于实际护栏、防护网等独立部位。该区别从概念图提示词延续到方块搭建。

## 文档分工

先从各站 `00_总体说明.md` 确认制造商、收售方向与可用服务，再按功能页安装设备。`01_外观与装饰参考.md` 集中保留原分栋描述、整站概念、尺寸、图片和交付历史；其中未采用的建筑只是可选参考。营业与主信息柜仍在原站内空间，三个功能页共同指向同一作业面。

| 文档 | 用途 |
| --- | --- |
| 02_货柜生成结构 | 生成场地、基础领取／制造启用条件、生成点与终端绑定 |
| 03_装载区域结构 | 贸易点出售货物，玩家买入；装载机、装载点和操作位置 |
| 04_卸载区域结构 | 贸易点收购货物，玩家卖出；卸载机、卸载点和操作位置 |
| 货柜制造台定义 | 实体材料配方、加工费、固定／概率工坊安排 |

货柜生成点本身不是制造台，外观车间也不自带制造功能。工坊采用[拼图附属池方案](<../../08_货柜制造台/制造服务分布与模块生成方案.md>)，装饰分支用于控制附带概率，不在附属建筑另造收发平台。

结构文件继续沿用现有交付与路径；功能页不要求拆分一体式站点或补齐旧分栋清单。不同站点的平台尺寸、标高与设备带已有差异，按本站记录调整，不能把通用模板坐标直接抄到整站中。

NBT、图片和附件不因文档合并而重制或删除。新做结构时按[结构模板工作流](<结构模板工作流.md>)记录设计，功能安装按[结构制作与绑定规范](<../../../02贸易点系统/02_贸易点结构生成层与制作规范.md>)接入；文件交付不等于已经营业。
