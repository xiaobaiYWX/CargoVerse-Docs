## 小站经营者与标识

普通小站默认独立经营，用本地站名、经营者招牌和适合环境的材料识别，不按行业自动套用制造商配色。采购设备上的品牌只表达产品来源。G05、G06、G08、G14 有明确机构派驻设定，按本站外观页保留有限的机构标识；不把这四站的规则推广到全部小站。

G01～G04 的归属及外观调整目前仅为设计目标，原始 NBT 与预览继续作为当前实物记录。各站经营背景见其总览与定义页。


## 小站场地规则

原设计为一到两栋小主体加紧凑露天交接场，优先整体 32×32，边长预算 48 格，全部突出部分计入。本次交付实际为 33×41～50，G01/G02/G05/G08 长边超出原预算 1～2 格，按维护者实物接入并记录，不自动裁切。48×48 也不保证任意起点只跨九个实际区块，严格区块占用还需约束对齐。

主屋建议 10×12～14×18，副屋 6×8～8×10，可以连檐或共墙。先放完整现有终端及至少 3 格操作通道，不能用缩小设备或删减部件换空间。不设大型 H 停机坪、载具维修区或货柜生产区。

当前八站在同一整站内使用相邻的独立收发作业位，各有装卸机、定位点及对应的收货／发货信息柜。八站现均启用双向业务，G07/G08 的预留装载设备用于本轮新增回收出售。一套唯一贸易点信息柜是实例锚点，全部不配置制造、注册、领柜或生成点服务。

原设计希望按 S/M 柜验证空间，部分 M 型柜高 12 格；当前导出两类检测范围均为 15×8×15，超过 8 格的货柜不能据此认定可用。货柜进出、完整检测与操作净空需按具体柜型实测；“小站”身份没有额外尺寸准入规则。

实际营业主地坪为局部 Y=2，货柜作业面为 Y=6，两处存在高差。室外自然留空用结构空位，室内及必要操作空间用空气；避免整片空气切割山体。当前地表投影偏移为 +1，整体较原配置抬高 3 格；terrain_adaptation=none，关闭额外地形融合。坡面上的基础落位仍需检查，G04 另验岸线。

## G09～G16 完整整站与建筑参考

八份完整整站已接入，实际水平尺寸为 32～33×45～46 格，双装卸检测范围各为 15×8×15。唯一贸易点信息柜、两类仓库信息柜、装卸机及定位点已静态核对；保留用户导出的地基延伸与填充标记。设备、地坪、生成参数和整站预览分别记录在本站目录。

此前八份 24×22 单栋建筑及其概念、材料和预览保留为[建筑制作参考](<地面小站建筑_G09-G16.md>)；单栋尺寸不代表完整场地。原 33×33 整站预算和 12 格检测高度目标均以本次实物替代。具体货柜净空、放入识别和交易仍需实机验证。

本批不增加制造、注册、领柜、生成点或大型停机坪。站点入口见[地面小站索引](<../README.md#地面小站>)。

## 制作与接入边界

当前大站使用完整整站模板，必需制造台和生成点已包含，不自动追加第二套工坊或装卸平台。2026-10-06 贸易网络已补齐双向目录，利用现有设备开展对应业务；设备可用性仍按实录与实机验收。

货柜生成点仅提供原点及偏移，生成占用以实际货柜 NBT 体积判断；装卸定位点才承担检测范围。所有服务与唯一信息柜使用同一实例，发布副本清理编辑绑定。原始导出、素材可用、运行时接入和实机可营业是不同状态，须如实记录。

小站结构检查器已按实际服务调整设备要求，继续按[生成与验收说明](<../结构生成规则与概率.md#生成指令与验收>)检查地形和真实交易。是否提供物品商店，以贸易点是否配置 `item_shop` 模块并放置售货机为准。
