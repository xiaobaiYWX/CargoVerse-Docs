# G09～G16 · 地面小站建筑主体

> 本页保留 2026-10-06 的单栋建筑制作记录。2026-10-07 用户导出的完整整站已接入，当前场地、设备与发布状态以各站结构总览为准；以下 building.nbt 与单栋预览不表示整站范围。

## 范围与后续拼装

七站为独立经营设施，仅 G14 气象观测哨采用 HRI 的局部蓝灰识别。每份包含薄基础、门前短引道和必要外观附件；G12 的料库、G15 的分类开间与 G16 的施工末开间均属于同一主建筑。

G09、G14 精细版的主屋与前廊地坪为局部 Y=3，室外地坪 Y=1，以两级台阶连接；G10、G12 精细版主屋和主要室外通路均为 Y=1；G11、G13、G15、G16 精细版主屋及相连门厅、门廊或开放开间为 Y=2、室外为 Y=1。

从 G10 精细重制起，新交付不再添加结构空位，室内外空白格均为空气，结构空位留待后续手工修改完成再添加。当前 G10～G16 已采用此规则，G09 不因后续规则变化自动改写。模板保留建筑空间，完整家具、模组终端与业务绑定由后续编辑完成。

**本页所记的单栋模板只包含建筑主体。** 当前用户导出的完整整站已补齐双装卸作业位、服务带、营业设备及运行绑定，以下为当时的制作边界。原 33×33 的整站预算需结合本次建筑重新排布，不能直接把两个 15×15 作业面压入 24×22 建筑模板，也不承诺拼装后仍是 33×33。

本批不增加制造、注册、领柜、生成点、H 停机坪或航修区。旧站模板和现有运行数据保持各自交付状态。
