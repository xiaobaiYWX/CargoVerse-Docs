# 实际物品货物与运输配置

货物内容直接使用 Minecraft 物品 ID 和完整组件；不再定义独立 CargoGood，也不将旧名称自动映射成实际物品。1 个物品占 1 库存/货柜容量单位，物品栈数量不是计量单位，质量另算。

## 身份和准入

同一货柜只装一种物品和一种完整组件状态。自定义名称、耐久、附魔等不同的物品不能混装。已知非空嵌套容器、无法无损编码的组件状态拒绝进入；无法恢复的已存内容整包隔离，保留原文，不回退成普通物品。

## 十四种业务分类

CargoClass 已调整为 14 类；完整边界、Create/航空学物品示例及 V4 图标见[实际物品分类](../../01货柜系统/01核心系统/05_货物类型.md)。none 仅为空状态，不能配置成运输类别；旧十一类无别名。首批已添加 77 个专用分组、1122 个明确物品 ID，另保留通用默认规则；覆盖范围、质量依据、损耗参数及全部分组索引见[首批运输数据](首批运输数据.md)，不代表所有物品已完成归类和平衡。

## 护目镜显示

佩戴 Create／航空学护目镜后，所有非空物品的悬停提示会显示按服务端运输配置解析的分类，不限于已进入贸易表的商品；十四种类别使用不同文字颜色，未配置物品采用服务端默认类别。提示不表示可以装柜或存在买卖报价。[显示规则及颜色](../../01货柜系统/01核心系统/05_货物类型.md#护目镜分类提示)。

分类映射只在登录／数据包同步时分包发送，客户端完整接收后替换，退出清空；悬停不额外请求数据，也不向物品添加组件。

## 分类、质量和运输要求

数据目录：`data/<namespace>/item_transport_profiles/<path>.json`。

```json
{
  "schema_version": 1,
  "cargo_class": "general_supplies",
  "unit_mass": 0.001,
  "transport_requirements": []
}
```

这份默认配置按每个物品 0.001 Kpg 计质量，是可通过数据包调整的初始值，不从已删除货物的质量表换算。全局必须且仅有一个不带 `membership_tag` 的默认配置；专用配置用该字段指向物品标签，覆盖默认分类。多个专用标签命中同一物品时拒绝发布新一代配置，保留上一完整快照；不从物品 ID 目录推断分类。

内置专用配置位于 `item_transport_profiles/<大类>/<分组>.json`，其 `membership_tag` 为 `cargoverse:transport/<大类>/<分组>`，对应 `tags/item/transport/<大类>/<分组>.json`。同组可以包含多个物品；属性不同时拆组，不给每个物品注入自定义组件，也不在一组中叠加多份运输配置。

例如玻璃方块组使用 construction_material、1 Kpg、速度变化阈值 3 / 每次损耗 10 件的易碎要求；玻璃板另组为 0.25 Kpg。内置数据暂不使用宽泛第三方标签，避免跨分类成员变化引发冲突。外部数据包可以覆盖名单和配置，但仍须通过唯一默认与无重叠校验。

运输词条使用固定整数 `loss_count`。非撞击词条另需 `loss_interval_ticks`；时限另需 `protection_ticks`。旧完整度、小数扣损和一次超时作废字段不再使用。货柜特殊设计移除对应要求，设计缺陷可添加要求；装柜时冻结最终结果，正在运输的货物不随 reload 偷换规则。

## 仓库

玩家贸易点仓库已改为 Create 保险库，通过附着式仓库收发器绑定；容量由保险库实际槽位和原生堆叠规则决定，不再维护自有库存或固定 5000 上限。报价与库存分开；只保存精确变体的单价和出售／收购上架开关，保留数量与收购目标已删除，不预留容量。GUI 两页均仅展示当前库存，需先存入样本才能上架。

入库先结算到期损耗，再丢弃运输快照和时钟；仓库不继续运输损耗。重新出库使用当前规则并开启新保护期，部分卸货不刷新柜中剩余货物。

## 自然贸易点

40 张自然站交易表仍为空，A／B 两张测试表已按实际物品方案填充，不保留旧抽象货物目录、图标和数量配置，也不自动生成替代真实物品目录。站点结构、制造、商店和注册等独立模块保留。

价格与两种运输经验属于具体交易报价，不是物品固有属性。运输 JSON 不接受价格、经验或市场资格字段，不因添加运输配置就自动开放交易。自然贸易点 schema 3 报价已接入收购侧每件许可证/繁荣度经验（缺省 0），并按服务端核验的自然生成目的地奖励全部实际成交件数，不区分货物来源；见[现行报价规则](../../02贸易点系统/03_资源表定义.md)。早期全局商品契约和目录已删除；40 张自然站表待落数据，A／B 测试表已填充。
