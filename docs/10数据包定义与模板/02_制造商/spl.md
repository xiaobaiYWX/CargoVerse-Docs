# 云港物流集团（`manufacturer.cargoverse.spl`）

## 品牌设定

英文名：**Skyport Logistics**

> 连接每一座天空之城。

云港物流集团是覆盖范围最广的运输与物流企业之一。与专注制造设备的工业集团不同，SPL 更关注货物流通本身，负责维护大量航线、贸易节点和运输网络。

SPL 生产的货柜并不追求极限性能，而是强调快速周转、低维护成本和高运输效率。其物流终端遍布各地，是许多小型贸易站和偏远聚居区的重要物资来源。

对于许多独立运输者而言，SPL 是他们进入天空贸易体系后接触到的第一个大型企业。

**主要领域：** 物流运输、贸易网络、货运服务、航线管理

**产品特点：** 快速装卸、高周转率、易维护

以上为世界观设定；下方货柜、声望及价格数据描述当前实现，具体机制以对应数据定义为准。

## 建筑特征色

代表色为**橙色、白色与深灰**。贸易点中用于标牌、入口饰条、局部面板或短段色带；主体材质与主色优先按建筑功能、结构形式和使用环境确定，不因品牌归属大面积统一换色。各单体和共用平台保持一致的局部识别。

通用规则见[制造商代表色](<README.md#制造商代表色>)；从概念图延续至 NBT，既有模板不自动换色。

## 贸易贡献

每 100 VB 的货物基础价值贡献 1 点声望；新装载的 solid／liquid／gas／living 未配置专属偏好，按 1 倍计入。下表是 JSON 当前保留的用途类键，不代表新货物仍按用途分类，也不会命中这些新形态。

| 偏好大类 | CargoClass | 声望倍率 |
| --- | --- | ---: |
| 红石与控制 | `electronics` | 1.5 |
| 通用物资 | `general_supplies` | 1.5 |
| 机械设备 | `machinery` | 1.5 |
| 机械零件 | `mechanical_parts` | 1.5 |
| 加工材料 | `processed_resource` | 1.5 |
| 工具与装备 | `tools_equipment` | 1.5 |
| 载具与部件 | `vehicle` | 1.5 |
| 食品与食材 | `food` | 1.5 |
| 物流与仓储 | `logistics_equipment` | 1.5 |

声望 = 交付数量 × 实际物品基础单价 ÷ 100 × 声望倍率。实际结算价、贸易表价格修正与声望价格优惠不参与该式，计算结果可以保留小数。偏好只改变声望贡献，不赋予贸易点额外收购品类。

## 声望价格修正

上表的买入／卖出倍率取代旧的固定签约倍率，并随制造商声望等级提高而改善。仅当玩家许可证签发制造商与当前贸易点制造商均为 `cargoverse:spl` 时生效，叠加于贸易表等既有价格修正之后，不作用于货柜制造加工费。

## 设计说明

贸易集散和承运服务方。转运口粮、净水、鲜货及日常物资，采购港口设备和通信设施；销售来源主要是采购与集散，不据此给其添加食品、机械等全产业制造能力。适合作为起步贸易入口。

当前新运输形态为 solid／liquid／gas／living。JSON 中的用途类偏好键不能命中新装载形态，未命中按 1 倍声望结算；偏好重设仍待设计。40 张正式自然站货物表为空，A／B 测试表已接入。本页为已落地的制造商数据；贸易网络商品分工见对应贸易点的定义设计。字段与计算规则见[制造商定义](<../../01货柜系统/01核心系统/08_制造商定义.md>)。
