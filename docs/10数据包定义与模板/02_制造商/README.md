# 制造商设计

八家制造商页面已收录完整背景、英文名、口号、主要领域与产品特点；游戏内简介使用中英文精简版本。HRI 中文名沿用**地平线研究院**。

世界观设定与数据参数分开维护：本次补充设定不调整容量、质量、耐久、声望或价格倍率。各家对新货物的供需关系见[货物设计口径](<../01_CargoGood/设计口径.md>)。

## 制造商代表色

以下为各制造商已确定的品牌代表色。用于贸易点建筑时，**功能决定主体材质与主色，制造商颜色形成清晰可见的局部识别**。适当增加入口饰条、重复立面面板、局部门架与平台边缘等元素，让不同方向都能辨认制造商；避免整站只有一两块很小的色板。各模块和共用平台保持一致的识别方式，不将整面墙、整片屋顶或全部框架涂满品牌色。材料本色与品牌色相近时仍可按功能正常使用。

| 制造商 | 代表色／识别方式 |
| --- | --- |
| [AUI · 天穹联合工业](<aui.md>) | 青色、浅灰、白色 |
| [BDS · 铁壁防务集团](<bds.md>) | 深绿、深灰 |
| [DMC · 深岩矿业集团](<dmc.md>) | 黑色、黄黑警戒 |
| [HEC · 赫利俄斯能源集团](<hec.md>) | 红色、黑色 |
| [HRI · 地平线研究院](<hri.md>) | 蓝色、灰色 |
| [REX · 遗民贸易协会](<rex.md>) | 无固定点缀色；按回收机构定位表现 |
| [SPL · 云港物流集团](<spl.md>) | 橙色、白色、深灰 |
| [VBS · 绿洲农业联盟](<vbs.md>) | 黄绿色、白色 |

DMC 的黄黑警戒以作业边缘、设备边界等局部条纹表现；各站必要的安全标线与 H 标识仍按功能设置。REX 不补造统一品牌配色，可保留回收材料原色和局部修补痕迹，具体组合服从建筑用途。规则从概念图延续至 NBT，具体见[制造商归属与特征色](<../07_贸易点/结构搭建说明/结构模板工作流.md#制造商归属与特征色>)。
