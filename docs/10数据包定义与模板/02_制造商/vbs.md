# 绿洲农业联盟（`manufacturer.cargoverse.vbs`）

## 品牌设定

英文名：**Verdant BioSystems**

> 在荒芜之地创造生命。

绿洲农业联盟致力于解决天空世界中的食物供应与生态问题。由于大量岛屿资源有限，VBS 发展出了高度集约化的农业技术，包括水培系统、生态循环设施以及人工培养环境。

与传统农场相比，VBS 的设施更加接近一个完整生态系统。其产品不仅包括食品和农业资源，也涉及生物研究、生态维护和环境恢复领域。

在许多远离自然资源的空岛聚居区，VBS 的生态设施是维持文明延续的重要保障。

**主要领域：** 农业生产、生态系统、生物技术

**产品特点：** 高效率、可持续生产、环境适应性强

以上为世界观设定；下方货柜、声望及价格数据描述当前实现，具体机制以对应数据定义为准。

## 贸易贡献

每 100 VB 的货物基础价值贡献 1 点声望；新装载的 solid／liquid／gas／living 未配置专属偏好，按 1 倍计入。下表是 JSON 当前保留的用途类键，不代表新货物仍按用途分类，也不会命中这些新形态。

| 偏好大类 | CargoClass | 声望倍率 |
| --- | --- | ---: |
| 农业物资 | `agriculture` | 1.5 |
| 食品与食材 | `food` | 1.5 |
| 化工与药剂 | `chemical_material` | 1.5 |
| 建筑构件 | `construction_material` | 1.5 |
| 加工材料 | `processed_resource` | 1.5 |

声望 = 交付数量 × 实际物品基础单价 ÷ 100 × 声望倍率。实际结算价、贸易表价格修正与声望价格优惠不参与该式，计算结果可以保留小数。偏好只改变声望贡献，不赋予贸易点额外收购品类。

## 声望价格修正

上表的买入／卖出倍率取代旧的固定签约倍率，并随制造商声望等级提高而改善。仅当玩家许可证签发制造商与当前贸易点制造商均为 `cargoverse:vbs` 时生效，叠加于贸易表等既有价格修正之后，不作用于货柜制造加工费。

## 设计说明
