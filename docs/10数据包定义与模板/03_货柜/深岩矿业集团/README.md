## 命名与初始运输

制造商代码：`DMC`。黑色柜体、黄色警示、耐磨装甲与明显承载结构。

基础货柜：[DMC Boreal 矿冶散料柜 M 型](<../../05_基础货柜/dmc_basic.md>)，M 级，基础领取占用 **0 调度点**。矿业起步采用 M 级例外，仍以 S 级许可证注册。
