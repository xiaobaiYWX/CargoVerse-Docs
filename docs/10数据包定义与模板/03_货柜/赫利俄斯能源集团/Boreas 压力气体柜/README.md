# Boreas 压力气体柜

HEC 的气密流体运输系列，当前开放固定容量、气密 2 的统一流体装卸与全型号测试制造；暂用同规格 AUI 结构，不模拟动态压缩或额外耐压等级。

| 型号 | 定义 ID | 容量 | 空重 Kpg | 普通调度点 |
| --- | --- | ---: | ---: | ---: |
| [M](boreas_hd_m.md) | `cargoverse:hec/boreas_hd_m` | 120000mB（120 份） | 90 | 2 |
| [L](boreas_hd_l.md) | `cargoverse:hec/boreas_hd_l` | 240000mB（240 份） | 190 | 4 |

唯一允许介质为 liquid，液态和气态 Fluid 均可装载。气密等级只控制封存和内外压湿交换，不授予温控、压缩、爆炸免疫或其他未声明保护。测试货物为岩浆燃气，接 Create 储罐及物流网络后即可实际装卸。HD 型号名称不新增独立对接机制；现用 AUI 占位结构的实际接口仍按方块定义判断。

专用结构、美术、最终容量和正式获取材料仍见[流体剩余事项](../../../../设计草案/待完成事项清单.md#液体深化)。现行计量、属性、仓储和测试方式见[液体运输](../../../../01货柜系统/01核心系统/13_液体运输.md)。
