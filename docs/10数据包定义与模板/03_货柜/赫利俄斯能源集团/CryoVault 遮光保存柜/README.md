# CryoVault 遮光保存柜

制造商：赫利俄斯能源集团 / Helios Energy Corporation

[返回制造商](<../README.md>) · [货柜目录](<../../README.md>)

通过遮光、防潮与固定设计保存敏感试剂、药品和样本，适合需要被动环境保护的运输。

允许分类：化工原料（`chemical_material`）、医疗物资（`medical_supply`）、水产生鲜（`aquatic`）、科研样本（`research_sample`）。未列出的分类均不允许。

消除的运输要求：避光、防潮、勿倒置。设计缺陷：无。所有货物的限时要求继续生效；御寒不代表冷藏或延长保质期。
