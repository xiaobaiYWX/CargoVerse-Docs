允许分类：化工与药剂（`chemical_material`）、食品与食材（`food`）、农业物资（`agriculture`）。分类按 2026-10-20 的十四类方案更新，未列出分类不允许。

消除的运输要求：避光、防潮、勿倒置。设计缺陷：无。所有货物的限时要求继续生效；御寒不代表冷藏或延长保质期。
