# Courier 轻型配送柜

制造商：云港物流集团 / Skyport Logistics

[返回制造商](<../README.md>) · [货柜目录](<../../README.md>)

为偏远聚落配送和独立运输者设计的轻型货柜，空重较低，适合小批物资周转。

允许分类：农业产品（`agriculture`）、水产生鲜（`aquatic`）、日常通用补给（`general_supplies`）、医疗物资（`medical_supply`）、电子设备（`electronics`）、工具器械（`tools_equipment`）、贵重物品（`valuables`）。未列出的分类均不允许。

消除的运输要求：无。设计缺陷：无。所有货物的限时要求继续生效；御寒不代表冷藏或延长保质期。
