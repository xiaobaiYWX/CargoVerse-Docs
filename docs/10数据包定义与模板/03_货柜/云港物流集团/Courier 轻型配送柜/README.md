## 职责与边界

合并 Cargo 为 S/M/L 配送线，统一防潮。与 Atlas 比更轻但更贵，与 Harvest 比更轻但容量较小。

- 目标形态：独立固体 solid。
- 当前 JSON 承载：独立固体 solid。
- 当前生效保护：防潮 D。
- 完整目标保护：防潮。
- 使用边界：无密封散料能力、无温控。
- 典型内容：生活成品、工具、书籍、包装物品。仅为例子，同形态同条件的物品不因行业或制造商被排除。
- 当前阶段：本期物品，可制造。

保护外观不等于程序效果。遮光、温控、生态维持和放射性屏蔽等未列入“当前生效保护”的部分只能作为后续结构预留，不能标成已经实装。
