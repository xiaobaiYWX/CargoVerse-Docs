## 职责与边界

合并 Nomad 的定向固定需求。与 Sentinel 同保护竞争，以较高成本换容量和较低空重；不再拆精密型与工程型。

- 目标形态：独立固体 solid。
- 当前 JSON 承载：独立固体 solid。
- 当前数值能力〔候选〕：围护 1、密封 1、缓冲 3；隔热、调温、遮光均为 0。M／L／X 均已显式声明。
- 能力方向：以缓冲与液态水隔离运输敏感固体，不提供无限防震；旧字母保护不再执行，定向安装不在现行核心内。
- 使用边界：无调温、无遮光；颗粒与粉末同属固体，不按用途拒装，围护 2 需求仍存在缺口。
- 典型内容：精密机构、传感器、玻璃与护目镜。仅为例子，同形态同条件的物品不因行业或制造商被排除。
- 当前阶段：本期物品，可制造。

以上为本系列当前七项输入，仍待路线平衡；不是旧词条免疫表，不改容量、空重、模板或配方。详见[运输数值运行时](../../../../01货柜系统/01核心系统/14_运输数值运行时.md)。
