# 按形态与保护选择货柜

更新：2026-10-21。使用独立固体、液体、气体、活体四大形态，本期仅开放实际物品 solid；粉粒不再作为独立承载类。这里不重新维护逐物品属性。

| 任务 | 当前可选系列 | 边界 |
| --- | --- | --- |
| 普通独立固体 solid | 本期全部开放系列 | 工具、瓶子、药水、设备及粉粒不因用途排除；仍检查准入与组件 |
| 颗粒／粉末物品 | 同属 solid；包括 Boreal、Silo | 根据具体物品条件及柜体保护判断风险，而非独立形态禁装 |
| 防震＋防潮＋定向固定 | Vulcan、Express、Sentinel、Explorer、Reliquary | Explorer／Reliquary 的遮光是完整设计目标，不在本期生效列表内 |
| 经济防震＋防潮 | CoreVault | 无 O 定向固定 |
| 仅需防潮 | Courier、Harvest | 基本形态仍为 solid |
| 开放大宗固定／防震固定 | Titan／Fortress | 都不防潮；Fortress 有防震及定向固定，仍需考虑具体货物受潮风险 |
| 易燃保护 | Apollo | 同为 solid，可装火药并提供 I 保护；其他缺少的保护仍按规则提示风险 |
| 散装液体 | 已接入 | Cistern／Crucible M/L 使用 AUI 占位结构；1000mB 整份装卸，非气体流体；见[液体规则](../../01货柜系统/01核心系统/13_液体运输.md) |
| 气体／活物 | 未开放 | Boreas／BioPod／Aquarium 待专项实现 |
| 冷藏／冷冻／屏蔽专项 | 本期不开放制造 | Eden／CryoVault／Reactor 的完整能力尚未实现 |

## 装载边界

- 一柜一种物品 ID＋完整组件状态，数量按件；同属 solid 不表示允许混装。
- empty_storage 仅已验证空态允许；blocked 不进入新装载。瓶装药水不是裸液体，鱼桶不等于已支持活物。
- 只有基本形态不匹配、准入失败或其他交易条件不满足才拒绝；缺保护提示风险，不直接变成品牌／用途禁装。
- 专用模型已接入本期 45 款；保护仍按定义生效，模型外观不自动授予温控或其他能力。货柜贴花直接取自物品属性声明，不决定装载资格。
