## 数据与制造边界

基础数值直接来自货柜定义；默认实际数值含制造商通用倍率，逐货物专项倍率见型号页。100 个正式 CargoGood 均有允许其分类的货柜，4 个未分类预留不开放运输。分类许可不保证自动消除货物的全部运输要求。

当前仍只有 Atlas S 与 Atlas L 两项基础制造示例，费用与等级门槛已同步 v3。其余型号的加工费、制造门槛和节点类型作为配方编制目标记录，材料数量及供应网络仍待设计；不得将表中规划价格视为已投放配方。

已制造货柜持有设备与兼容性快照，数据包重载不会自动重写既有快照。本轮未迁移存量资产。NBT 模板的物理质量、接口与游戏内表现仍需实测。
