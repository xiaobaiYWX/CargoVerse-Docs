## 完整型号格式

```text
[MFG]-[MODEL]-[INTERFACE]-[SIZE]-[OPTION]
AUI-Atlas-SD-S
DMC-Boreal-HD-XL
AUI-Atlas-SD-S-R  （后缀示例，尚未注册该变体）
```

MFG 固定三位大写，MODEL 使用系列英文全称并保留惯用大小写，INTERFACE 与 SIZE 大写；OPTION 可省略，省略时不保留末尾连字符，最多一个后缀。

中文显示名采用“制造商缩写＋系列全称＋规格＋型”，如 `AUI Atlas 标准干货柜 S 型`。文档按“制造商中文目录／系列目录／型号文件”组织：系列 README 提供职责与规格索引，每个型号独立成页；未实现系列和型号在开头明确标记。制造商页同时写英文全称，短 ID 不取代完整名称。

## 接口代码 INTERFACE

CIS（Cargo Interface Standard）是命名与结构制作约定，定义 JSON 没有 `interface_type` 字段。下列物理方式为美术／制作目标，不表示所有代码都已有对应可用方块或同一种运行实现。SD 的现行锁定规则见[货柜连接器与货柜接口](<../../03功能方块/02_货柜连接器与货柜接口.md>)；SI 见[货柜轨道系统](<../../03功能方块/08_货柜轨道系统概览.md>)。

| 代码 | 英文 | 中文 | 结构制作约定 |
| --- | --- | --- | --- |
| LC | Loose Cargo | 散装承载 | 无主动锁定；由载具货斗、摩擦和碰撞保持，适合低速运输。 |
| LM | Lashing Mount | 绑扎固定 | 货柜设置吊环／绑扎位置，载具提供绳索与固定装置。 |
| SD | Standard Docking | 标准对接 | 货柜提供接口方块，载具提供连接器；当前由固定物理约束锁定。 |
| MC | Magnetic Confinement | 磁力约束 | 货柜设置磁吸板，载具配货运磁铁；具体物理能力以实际方块实现为准。 |
| SI | Slipway Interface | 滑轨接口 | 货柜设置滑台接口，载具配当前逐格直线轨道；滑动与锁定按现行轨道实现。 |
| HD | Heavy Docking | 重型保持接口 | 加强连接点与重型保持机构；以现行连接方块与载具实测为准，须逐模板核验。 |

命名中的接口不会赋予电力、物品或流体传输能力。已有型号沿用现行 ID 的代号，不照抄早期表格重命名；尤其不要把厂商系列描述当作物理能力证明。

## 规格 SIZE

size_class 是定义中明确填写的规格，不按包络体积自动推断。旧文档两套体积范围互相冲突，且与部分 Atlas 包络不一致，具体硬尺寸范围待你确认；本次不擅自重定标准，也不宣称占位已通过旧标准。下表仅记录当前 Atlas 的真实包络。

| 代码 | 规格 | 当前 Atlas 包络 X×Y×Z | 参考体积 | 普通调度点基准 |
| --- | --- | --- | ---: | ---: |
| S | 小号 | 7×3×5 | 105 | 1 |
| M | 中号 | 9×4×6 | 216 | 2 |
| L | 大号 | 13×6×6 | 468 | 4 |
| X | 特大 | 15×8×9 | 1080 | 6 |
| XL | 超规格 | 17×8×9（扩展占位） | 1224 | 8 |

容量和空重以具体型号定义为准，不由内部体积换算。制作时记录真实包络、底面中心、接口位置和所需装卸空间；调度点免除仅用于基础权益资产，不改变普通型号数值。

## 特殊后缀 OPTION

变体须有已存在的基础型号，最多一个后缀，单独建立定义并显式调整数值与防护。字母只是命名，不会自动修改货物运输要求、固定件数损耗或制造价。

| 后缀 | 英文 | 中文 | 设计方向与现行字段边界 |
| --- | --- | --- | --- |
| R | Reinforced | 结构加强 | 通过结构外观、`special_designs` 和配方成本体现；不提供货柜耐久值。 |
| A | Armored | 装甲加强 | 通过明确的结构与防护词条实现；后缀不提供独立撞击减伤算法。 |
| W | Waterproof | 防水 | 以 special_designs 消除 moisture_proof，通常提高配方费用；不等于抗腐蚀。 |
| TP | Thermal Protection | 热环境防护 | 后续温控设计预留；本期不因后缀添加 cold_proof、cold_chain 或 time_limit，不表示已实现冷藏／冷冻。 |
| L | Lightweight | 轻量化 | 降低 empty_mass；如需改变易损要求须显式配置，不因后缀推导。 |

`L` 在 SIZE 位表示 Large，在 OPTION 位表示 Lightweight。例如 `AUI-Atlas-SD-L-L` 是大号轻量化命名示例，未注册。当前 64 个主型号尚无 OPTION 变体；命名规范不自动新增货柜。

## 2026-10-21 实际落地补充

本期 45 款已采用实际结构。Apollo 当前 M／L／X，Silo 当前 L／X／XL，均为重型连接点结构；旧定义 ID 中的 SD 和尺寸后缀不决定运行接口或实际规格。其它稳定 ID 同理，以 size_class 和实际 NBT 为准。
