# 货柜命名与品牌规范

整编自提供的《命名框架》。本页规范型号标识、资源命名和美术约定；现役系列与尺寸按当前 v3 数据更新。历史草案中的型号名单、整柜完整度、自动温控与接口能力不直接视为运行规则。

## 完整型号格式

```text
[MFG]-[MODEL]-[INTERFACE]-[SIZE]-[OPTION]
AUI-Atlas-SD-S
DMC-TitanHaul-HD-XL
AUI-Atlas-SD-S-R  （后缀示例，尚未注册该变体）
```

MFG 固定三位大写，MODEL 使用系列英文全称并保留惯用大小写，INTERFACE 与 SIZE 大写；OPTION 可省略，省略时不保留末尾连字符，最多一个后缀。

中文显示名采用“制造商缩写＋系列全称＋规格＋型”，如 `AUI Atlas 标准干货柜 S 型`。文档目录采用“制造商中文全称 → 系列全称 → 货柜定义”，制造商页同时写英文全称；短 ID 用于资源引用，不能取代完整名称。

| 资源 | 规则 | 示例 |
| --- | --- | --- |
| 货柜定义 ID | `cargoverse:<mfg>/<model>_<interface>_<size>[_<option>]` | `cargoverse:aui/atlas_sd_s` |
| 定义文件 | `cargo_containers/<mfg>/<model>_<interface>_<size>[_<option>].json` | `cargo_containers/aui/atlas_sd_s.json` |
| 正式模板 ID | `cargoverse:cargo/<mfg>/<model>/<mfg>_<model>_<interface>_<size>[_<option>]` | `cargoverse:cargo/aui/atlas/aui_atlas_sd_s` |
| NBT 文件 | `structure/cargo/<mfg>/<model>/<mfg>_<model>_<interface>_<size>[_<option>].nbt` | `structure/cargo/aui/atlas/aui_atlas_sd_s.nbt` |

资源 ID 使用小写和下划线，完整展示型号使用连字符。不为排版或翻译更名批量修改已有资源 ID。缺失模板的型号暂指向 Atlas S，其正式模板目标与缺失状态单独记录，不能从占位 NBT 反向改写型号名。

## 接口代码 INTERFACE

CIS（Cargo Interface Standard）是命名与结构制作约定，定义 JSON 没有 `interface_type` 字段。下列物理方式为美术／制作目标，不表示所有代码都已有对应可用方块或同一种运行实现。SD 的现行锁定规则见[货柜连接器与货柜接口](<../../03功能方块/02_货柜连接器与货柜接口.md>)；SI 见[货柜轨道系统](<../../03功能方块/08_货柜轨道系统概览.md>)。

| 代码 | 英文 | 中文 | 结构制作约定 |
| --- | --- | --- | --- |
| LC | Loose Cargo | 散装承载 | 无主动锁定；由载具货斗、摩擦和碰撞保持，适合低速运输。 |
| LM | Lashing Mount | 绑扎固定 | 货柜设置吊环／绑扎位置，载具提供绳索与固定装置。 |
| SD | Standard Docking | 标准对接 | 货柜提供接口方块，载具提供连接器；当前由固定物理约束锁定。 |
| MC | Magnetic Confinement | 磁力约束 | 货柜设置磁吸板，载具配货运磁铁；具体物理能力以实际方块实现为准。 |
| SI | Slipway Interface | 滑轨接口 | 货柜设置滑台接口，载具配轨道及节点；滑动与锁定按轨道实现。 |
| HD | Heavy Docking | 重型保持接口 | 加强连接点与重型保持机构；原方案的轴承约束为制作目标，须逐模板核验。 |

命名中的接口不会赋予电力、物品或流体传输能力。已有型号沿用现行 ID 的代号，不照抄早期表格重命名；尤其不要把厂商系列描述当作物理能力证明。

## 规格 SIZE

| 代码 | 英文 | 规格 | 包络体积设计参考（方块³） | 普通调度点 |
| --- | --- | --- | --- | --- |
| S | Small | 小号 | 0 < V ≤ 150 | 1 |
| M | Medium | 中号 | 150 < V ≤ 300 | 2 |
| L | Large | 大号 | 300 < V ≤ 750 | 4 |
| X | Extra | 特大 | 750 < V ≤ 1500 | 6 |
| XL | Extra Large | 超规格 | V > 1500 | 8 |
| SP | Special Order | 特别订单标记 | 按订单单独定义 | 不套用常规阶梯；订单运行机制待实现 |

体积按模板包络长×宽×高作为建模参考，包含内部空腔；当前加载器不按体积自动分级，也未重新验收旧模板是否符合范围。尺寸等级独立存于 `size_class`，运输容量、空重与耐久另按数据定义。普通制造许可由配方明确写入，不会仅凭型号自动设定。

基础货柜是取得方式，不是第六种尺寸或特殊后缀。七家采用 S，DMC 采用 M；全部基础资产免调度点，普通同型号仍按上表计点。

## 特殊后缀 OPTION

变体须有已存在的基础型号，最多一个后缀，单独建立定义并显式调整数值与防护。字母只是命名，不会自动修改货物运输要求、货柜耐久或制造价。

| 后缀 | 英文 | 中文 | 设计方向与现行字段边界 |
| --- | --- | --- | --- |
| R | Reinforced | 结构加强 | 提高 max_durability，通常增加 empty_mass 与配方价格；货物完整度不随名称改变。 |
| A | Armored | 装甲加强 | 通过明确的结构、防护和耐久平衡实现；后缀不提供独立撞击减伤算法。 |
| W | Waterproof | 防水 | 以 special_designs 消除 moisture_proof，通常提高配方费用；不等于抗腐蚀。 |
| TP | Thermal Protection | 热环境防护 | 按需要消除 cold_proof；不自动冷藏或延长保质期，是否额外增加 time_limit 必须另做明确设计。 |
| L | Lightweight | 轻量化 | 降低 empty_mass，通常降低耐久；如需改变易损要求须显式配置，不因后缀推导。 |

`L` 在 SIZE 位表示 Large，在 OPTION 位表示 Lightweight。例如 `AUI-Atlas-SD-L-L` 是大号轻量化命名示例，未注册。当前 60 个常规模型尚无 OPTION 变体；命名规范不自动新增货柜。

## SP 特别订单

SP 不属于常规尺寸递进或基础货柜权益。每家制造商维护一份“特别订单系列货柜”预留文档，后续规划 1～3 个模板；未定稿时保持空置。订单的接口、结构、适用货物、数值与获得方式均独立设计，不自动继承常规系列。

原稿提到的 Genesis、Relic、Blackbox 仅作为历史候选名，不视为已加载定义或已实现内容。Fortress 工事运输堡 XL 当前属于常规现役型号，不移入 SP。
