# Salvage 旧世打捞柜

[返回制造商](<../README.md>) · [货柜目录](<../../README.md>)

允许分类：贵重物品（`valuables`）、特殊资源（`special_resource`）、科研样本（`research_sample`）、电子设备（`electronics`）、异常货物（`anomalous_cargo`）。未列出的分类均不允许。

消除的运输要求：易碎。设计缺陷：无。所有货物的限时要求继续生效；御寒不代表冷藏或延长保质期。
