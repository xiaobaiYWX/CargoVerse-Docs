# Archive 资料封存柜

制造商：地平线研究院 / Horizon Research Institute

[返回制造商](<../README.md>) · [货柜目录](<../../README.md>)

为地平线研究院封存资料、文物与异常介质，采用缓冲、防潮、遮光及固定设计。

允许分类：电子设备（`electronics`）、贵重物品（`valuables`）、异常货物（`anomalous_cargo`）。未列出的分类均不允许。

消除的运输要求：易碎、防潮、避光、勿倒置。设计缺陷：无。所有货物的限时要求继续生效；御寒不代表冷藏或延长保质期。
