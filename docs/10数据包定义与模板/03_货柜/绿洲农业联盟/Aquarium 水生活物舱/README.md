## 职责与边界

活体容量采用总舱位＋单体尺寸＋数量上限，一柜同种、逐只保存，幼体按成年占用。运输货损对所有存活个体统一扣生命，死亡无任何掉落；详见[生物运输设计](../../../../设计草案/生物运输设计.md)。本系列最终舱位和环境参数仍待确定，运行定义尚未开放。

水生环境与陆生通风有根本差异，独立保留；如使用维持用水，其质量计入运行质量，不能作为可售液体。

- 目标形态：living 活物（明确水生适配范围）。
- 当前 JSON 承载：未开放。
- 当前生效保护：无专用保护。
- 完整目标保护：防逃逸、水环境、防冻结（目标）。
- 使用边界：不作为可交易液体罐；水为环境介质，不生成可售水货物。
- 典型内容：后续明确的鱼类或其他水生实体；不把鱼桶直接认定为实体载荷。仅为例子，通过准入且满足同等环境条件的生物不因行业或制造商被排除。
- 当前阶段：后续专项，未制造。

保护外观不等于程序效果。遮光、温控、生态维持和放射性屏蔽等未列入“当前生效保护”的部分只能作为后续结构预留，不能标成已经实装。
