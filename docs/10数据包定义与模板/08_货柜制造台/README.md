# 货柜制造台定义与当前投放

本目录维护原有贸易点即时制造渠道。独立的纸张蓝图、材料托管和逐层施工设备见[货柜搭建器](../../01货柜系统/01核心系统/18_货柜搭建器.md)；两者目前并存，独立配方使用`cargo_builder_recipes`目录，不继承贸易点繁荣度或VB加工费。

更新：2026-10-21。系统使用 schema 2 配方，材料来自玩家物品栏，加工费使用 VB；许可、繁荣度与调度点分别检查。每次即时制造一柜，不维护生产队列、抽象货物成本或贸易点库存材料。

正式目录共 75 条配方，覆盖 49 款。A／B 另提供 Reliquary 两款及 BioPod 三款，共 54 款。
