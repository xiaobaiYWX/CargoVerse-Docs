# 货柜制造台定义与当前投放

本目录维护贸易点蓝图打印目录。材料托管和逐层施工设备见[货柜搭建器](../../01货柜系统/01核心系统/18_货柜搭建器.md)；独立配方使用`cargo_manufacturing_recipes`目录，搭建器不继承贸易点繁荣度或VB打印费。

更新：2026-11-05。系统使用 schema 3 投放表，条目费用作为VB蓝图打印费；打印检查许可和繁荣度，调度点与材料在搭建器开工时检查。定影器存取与表面UI见[蓝图打印机](../../02贸易点系统/05_货柜制造台定义.md)。

正式目录共 75 条配方，覆盖 49 款。A／B 另提供 Reliquary 两款及 BioPod 三款，共 54 款。
