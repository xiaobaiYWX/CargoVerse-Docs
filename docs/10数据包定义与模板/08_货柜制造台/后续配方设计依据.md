## 制造用料方向

下表仅说明后续配方的材料方向，不是已经可加载的 stock_costs。通用描述如“屏蔽材料”“缓冲件”“装甲材料”不代表已注册 CargoGood；实际配方编制时必须回到现有货物目录选料，不能生成不存在的 ID。

| 制造商 | 用料方向 |
| --- | --- |
| AUI | 结构钢锭、标准货柜接口总成；工程／精密型另需缓冲与密封件 |
| SPL | 标准货柜接口总成、工业棉布、轻型框架材料 |
| DMC | 结构钢锭、强化承载件；CoreVault 另配防震与防潮内衬 |
| VBS | 密封树脂、工业棉布、固定架；BioPod／Eden 另配生物舱组件 |
| HEC | 结构钢锭、密封树脂、罐体固定件；Reactor 另配屏蔽材料 |
| HRI | 封装数据存储阵列、工业传感器、密封与缓冲件 |
| BDS | 结构钢锭、装甲材料、固定架与密封件 |
| REX | 旧世合金残片、筛选翻修件、缓冲包装 |


## 编制时必须落实

- 从正式 CargoGood 选择真实材料 ID，逐项写清 stock_costs 标签和数量；上表中的固定架、屏蔽材料等只是用途描述。
- 加工费与库存材料成本分别计算，费用不是包含物料的总工业成本。
- 制造台材料来自所属贸易点中 `create_inventory: true` 的收购库存；材料标签必须由资源表收购规则覆盖，不能只写进制造配方便假设库存自动存在。
- 确认材料来源与货柜兼容可达，避免必须先制造目标柜才能运来制造该柜的材料。
- 普通制造许可原则上等于尺寸，繁荣 S／M／L／X／XL 对应 1／2／3／4／5；基础货柜领取由独立权益提供，免点规则不由配方价格控制。
- 先为起步节点投放少量必需型号，逐步扩展 60 款；不以新节点设计自动承诺所有型号同时可购。
