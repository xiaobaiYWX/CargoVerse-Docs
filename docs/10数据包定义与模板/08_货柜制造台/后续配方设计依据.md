# 后续货柜制造配方设计依据

货柜制造配方只使用玩家物品栏中的实体物品与 VB 加工费。材料不读取 CargoGood、不占用贸易点收购库存，也不依赖资源表是否收购相同货物。

## 配方设计顺序

1. 确定货柜型号、Cargo Class、尺寸等级与制造商。
2. 选择 2～4 种能直观表达结构、功能或厂牌特点的普通实体物品。
3. 检查材料能否放入玩家主背包和快捷栏；不要用盔甲栏、副手、容器内部物品或附近仓储作为前提。
4. 为配方设置 VB 加工费、许可证等级与繁荣门槛。
5. 将同一套型号配方同步到所有提供该型号的制造台定义。同一型号不因贸易点不同而改变材料算法。

每条配方必须包含 1～8 项非空 `item_costs`。不能使用空材料配方、纯 VB 购买、`stock_costs`、CargoGood ID 或抽象吨位。

## 材料表达原则

| 用途 | 建议材料方向 | 说明 |
| --- | --- | --- |
| 主体框架 | 铁锭、铜锭、合适的板材标签 | 反映柜体强度与尺寸 |
| 透明／观察结构 | 玻璃或玻璃板 | 适合生物、精密或展示用途 |
| 控制与接口 | 红石、比较器、侦测器等 | 适合自动化、精密或数据货柜 |
| 密封与缓冲 | 羊毛、黏液球、皮革等 | 适合防震、保温、生物或危险品货柜 |
| 特殊结构 | 与功能直接相关的原版物品 | 保持少量且易理解，不引入不存在的占位材料 |

优先使用精确 `item`。只有确实希望多个同类物品可以混合支付时才使用 `tag`。标签中的每件物品都按一件计数，不进行铁块与铁锭之类的自动单位换算。

不把以下内容用于制造材料：

- 带改名、附魔、耐久、容器内容或其他非默认组件的物品；
- 会产生合成剩余物的物品；
- 只能从尚未制造的目标货柜运输而来的材料；
- 仅为占位而项目中并不存在的物品或标签。

## 厂牌材料方向

| 制造商 | 实体材料方向 |
| --- | --- |
| AUI | 铁锭、木板、玻璃、红石；工程与精密型号增加控制或缓冲材料 |
| SPL | 木板、羊毛、轻量金属与基础接口物品 |
| DMC | 铁锭、铜锭及高强度结构物品；重型型号提高框架用量 |
| VBS | 玻璃、羊毛、黏液类密封材料与生物舱相关物品 |
| HEC | 铁锭、铜锭、玻璃及危险品隔离相关物品 |
| HRI | 红石、侦测器、比较器、玻璃及缓冲材料 |
| BDS | 高用量金属、加固结构与密封材料 |
| REX | 常见金属、旧式结构材料与混合翻修部件 |

这些方向用于保持品牌辨识度，不是强制配方，也不代表已注册的新物品。实际定义只能引用当前注册表中存在的物品或非空物品标签。

## 尺寸与门槛

| 货柜等级 | 建议最低繁荣等级 | 设计重点 |
| --- | ---: | --- |
| S | 0 | 少量基础材料，作为最早可制造型号 |
| M | 1 | 提高框架用量，可增加一项功能材料 |
| L | 2 | 明显提高主体材料与加工费 |
| X | 3 | 使用更高成本的功能或强化材料 |
| XL | 4 | 仍控制在玩家物品栏可携带范围内，不用极端数量模拟吨位 |

许可证门槛依据货柜定义与站点定位填写。制造台模块门槛与配方门槛取较高值；基础货柜领取继续由注册终端处理，不在制造配方中设置免费入口。
