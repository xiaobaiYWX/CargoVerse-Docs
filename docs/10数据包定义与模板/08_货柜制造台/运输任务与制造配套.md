# 实际物品运输与制造配套

更新：2026-10-20。旧百项抽象货物路线、逐货物示例和独立完整度要求已撤下，不再将旧来源站／交付站视为当前交易内容。

## 选柜与备柜

1. 从[物品运输配置](../01_物品运输/README.md)确认物品分类、单位质量和运输要求；同种物品的完整组件变体不可混装。
2. 对照[十四类物品货箱兼容参考](../03_货柜/货物装载参考.md)选择允许装载该类别的柜型，进一步核对容量、防护及载具承载能力。容量按实际物品个数，不按栈或吨数。
3. 在提供该配方的贸易点制造空柜。材料、VB 加工费、许可证及繁荣门槛以[制造配方总表](制造配方与投放总表.md)和当前制造 JSON 为准；制造不会使用贸易点出售库存。
4. 确认出发点确有有效出售报价和库存、目的地有对应收购报价及额度，再安排装载与运输。具备制造服务不等于经营某种物品。

已有兼容空柜可以复用，不要求每批货物重新制造。防护只豁免对应运输要求，未豁免的要求仍需满足；损耗按规则直接扣除实际数量，不单独计算完整度折价。

## 当前验证与内容边界

40 张正式自然站货物交易表仍为空，不能沿用旧抽象商品线路；正式实际物品方案见[资源表设计](../06_资源表/README.md)，标记为“待落数据”的内容尚未发布。

A／B 指令测试站共覆盖 149 种实际物品，收售方向互补，并共用[全 60 型号制造目录](market/test_station/all_containers.md)。可用于验证制造、库存、支付、运输损耗和卸货闭环，但不代表正式经济平衡；指令测试站作为目的地不获得自然生成站的交付经验资格。

玩家贸易点使用 Create 保险库和仓库管理终端 SET 配置商品，管理装卸与公众付费交易分开；详见[玩家贸易点](../../11玩家贸易点/README.md)。
