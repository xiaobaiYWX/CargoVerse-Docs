# 八家制造商基础货柜

每家制造商提供一项初始运输权益，共 **8 项：7 款 S 级、1 款 M 级**。权益引用已有货柜型号，不额外复制物理定义，因此常规型号目录仍为 60 款。

基础资产的调度点占用统一为 **0**。同型号的普通购买／制造货柜仍使用其定义调度点；免点以资产 `starterContainer` 标记判定，而非型号名称、ID 或尺寸。

DMC 沿用 Boreal M 作为矿业起步例外。基础领取无需普通制造的等级与预算门槛，但依然检查资格、唯一权益、生成位置与空间；初始许可统一为 S，不扩大该许可证的普通制造权限。

VBS 保留 `oasis_basic` 和 `oasis_agriculture` 既有 ID，基础型号改为 Harvest S；旧的已领取资产不改型号快照，但免点立即生效。已注册而尚未领取者通过原权益 ID 领取当前 Harvest S。

已提供八项配套注册点定义，当前仅 VBS 绑定现有默认资源贸易点。其余七项供对应制造商的后续贸易点绑定，未在本轮新增地图贸易点。
