# 测试贸易点 A → B

## 身份

| 项目 | 设计值 |
| --- | --- |
| 订单 ID | `cargoverse:market/test_station/a_to_b` |
| 显示名称 | A 至 B 测试物资转运 |
| 发布贸易点 | `cargoverse:market/test_station/a` |
| 目的 | 验证接取、SP 货柜生成、限时与完整度限制、物品奖励及 B 点交付 |

## SP 货柜

| 字段 | 设计值 |
| --- | --- |
| 模板 | `cargoverse:cargo/aui/atlas/aui_atlas_sd_s` |
| 货柜名称 | SP 测试货柜 A-B |
| 货物名称 | 终端联调物资 A-B |
| CargoClass | `general_supplies` |
| 总质量 | 40 |
| 初始完整度 | 100 |

## 目的地与距离

| 字段 | 设计值 |
| --- | --- |
| 允许的贸易点定义 | `cargoverse:market/test_station/b` |
| 最小距离 | 0 |
| 最大距离 | 30000000 |

## 难度

| 项目 | 数值 |
| --- | ---: |
| 基础难度 | 1 |
| 每 1000 格距离难度 | 1 |
| 时限限制难度 | 1 |
| 最低完整度限制难度 | 1 |

```text
最终难度 = 3 + 实际距离 / 1000
```

## 任务限制

| 类型 | 参数 |
| --- | --- |
| 运输时限 | 基础 12000 tick；每 1000 格增加 4000 tick |
| 最低完整度 | 75 |

## 奖励

| 奖励 | 基础值 |
| --- | ---: |
| VB | 200 |
| 执照经验 | 20 |
| SPL 制造商声望 | 5 |
| 物品 | `minecraft:iron_ingot` ×1，随难度缩放 |

| 难度 | 倍率 |
| ---: | ---: |
| 0 | 1.0 |
| 5 | 1.5 |
| 10 | 2.0 |

## 贸易点绑定

测试贸易点 A 的 `special_orders` 每日提供 1 个槽位；本订单最低繁荣等级为 0，权重为 1。
