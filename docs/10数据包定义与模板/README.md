# 数据定义设计

本章整理现行数据格式、定义内容和待确认数值，并链接对应数据包来源。制造商、货柜和站点等内容先设计后同步；逐物品基础属性以独立 JSON 为唯一维护源，Markdown 只作规则说明与查阅表。

## 使用方式

1. 在对应定义目录中复制 `README.md` 的空白模板。
2. 填写内容定位、字段值、依赖和必要的数值计算。
3. 对照同目录中的现有定义调整整体平衡。
4. 将最终结果同步到对应 JSON。

以上流程适用于内容设计。逐物品属性直接编辑相应 JSON，再同步[查阅清单](<../14运输分类统计/README.md>)；不从清单反向生成共享配置。液体使用独立逐流体属性，见[液体运输配置](../01货柜系统/01核心系统/13_液体运输.md)；气体和实体仍待专项确认，不能按物品模板直接套用。

## 同步边界

- 设计文档使用易读表格，不直接复制完整 JSON。
- 资源 ID 与文件路径保留命名空间和目录层级。
- 结算单位固定为 `cargoverse:void_byte`。
- 开发阶段不记录已删除字段或兼容方案。
- 字段约束和运行逻辑仍以各系统说明为准。
