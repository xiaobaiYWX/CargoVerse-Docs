# 数据定义设计

本章用于先以 Markdown 设计内容与数值，再把确定结果同步到数据包 JSON。文档只保留定义内容、数值与对应的数据包来源。

## 使用方式

1. 在对应定义目录中复制 `README.md` 的空白模板。
2. 填写内容定位、字段值、依赖和必要的数值计算。
3. 对照同目录中的现有定义调整整体平衡。
4. 将最终结果同步到对应 JSON。

Markdown 是数值设计源，JSON 是游戏读取结果。修改 JSON 后也要同步回对应设计文档，避免两边长期不一致。

## 同步边界

- 设计文档使用易读表格，不直接复制完整 JSON。
- 资源 ID 与文件路径保留命名空间和目录层级。
- 结算单位固定为 `cargoverse:void_byte`。
- 开发阶段不记录已删除字段或兼容方案。
- 字段约束和运行逻辑仍以各系统说明为准。
