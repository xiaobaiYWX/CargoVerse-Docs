## 开发残留

确认没有运行调用方后，删除7个旧类：CargoCompactText、CargoAffixDefinitionParser、CargoAffixDefinition、ItemTransportRuleBook、SegmentedTextureProgressBar、CargoScrollArea、CargoUnitFormatter。它们分别属于旧GUI包装、旧词条解析模型和未接入正式链路的规则发布原型；不能因为仍有自测就视为正在使用的运行机制。

对应的12项原型自测退出；现行冻结恢复、整数损耗、界面布局和交易补偿验证保留。规则发布失败验证改为直接调用真实CargoDataReloadListener准备流程，确认失败时整份已发布快照与代号均不改变，不继续维护第二套测试用发布器。生产Java由899份降为893份（删除7份，新增1份共用基础设施）。

生产交易类不再包含TEST_FAILURE_POINT、failAtForTesting和InjectedFailure。世界故障测试迁入src/gametest的CargoTradeFaults／CargoTradeFaultMixin，仅由runGameTestServer显式启用；在真实变更及逆操作登记后注入，继续覆盖实际库存、资金、经验及生物事务回滚。JUnit直接让变更操作失败，仍检查倒序补偿、提交后不回滚，以及某个补偿失败不阻断其他补偿。

管理员诊断、稳定注册ID、正式模板锚点、冻结快照解码和美术资源没有按名称批量删除。旧仪表板素材记录改为历史来源说明，不再宣称已经移除的GUI原型是现行API。

## 架构收敛

| 范围 | 当前职责与行为 |
| --- | --- |
| PlayerSessionStore | 按ServerPlayer实例的弱身份键存储临时状态；账号UUID或循环使用的实体编号不合并连接；统一处理退出、换维度、服务器停止；值不反向保活玩家或世界 |
| 滑条 | 保留独立的40tick超时、权限、范围和数值校验，额外绑定原控制器及连接弱引用；替换方块和重连不继承旧令牌，结束只提交一次。公共监听器由CargoVerseSystems注册 |
| 连接工具 | 直接校验原锚点弱引用及稳定身份，避免重复解析UUID／重新寻找同位置设备；不加载区块；所有者／管理员及32／128格范围保持原规则 |
| 地图发现 | 检查位置、已进入结构与贸易点集合合并为一份不可变临时状态，发现完成后一起发布；长期地图与玩家导航目标不进入这个存储 |
| 地图头像缓存 | 不再满额整表清空；保留进行中的任务，按访问顺序移除已完成的旧请求；全在进行时暂停新查询，断线释放本地引用。任务归原版皮肤管理器所有 |
| 发布包 | 继续排除全部GameTest输出，额外拒绝生产交易类重新包含旧故障开关；不以源码目录拆分代替实际JAR复查 |

共用存储不承担业务权限、库存、事务或持久化，也不把不同会话的超时和提交方式统一成一个复杂协议。
