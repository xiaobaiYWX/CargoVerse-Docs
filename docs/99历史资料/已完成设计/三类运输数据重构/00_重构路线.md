## 三类内容

| 大类 | 子类 | 内容与维护入口 |
| --- | --- | --- |
| 运输物品数据 | 固体物品 | [逐ID属性与差异](<../../../05内容数据/01运输物品/固体/README.md>)：单件质量、准入、运输条件、贴花 |
| 运输物品数据 | 流体 | [流体规则](<../../../02系统规则/货物与货柜/13_液体运输.md>)：液态与气态Fluid，每桶质量、保存条件 |
| 运输物品数据 | 生物 | [实体属性](<../../../04数据规范/运输属性/03_生物.md>)：每只质量、舱位、环境、生命损耗条件 |
| 货柜数据 | 制造商／系列／型号 | [货柜目录](<../../../05内容数据/02货柜/README.md>)：介质、容量、空重、能力、living_chamber |
| 贸易点数据 | 交易列表 | [资源表](<../../../05内容数据/03贸易点/交易列表/README.md>)：按组／桶／只报价、库存、补货、限额、经验 |
| 贸易点数据 | 货柜制造 | [制造台定义](<../../../05内容数据/03贸易点/蓝图投放/README.md>)：型号、实体材料、加工费、制造点分配 |

制造商、模板、站点绑定与自然生成作为配套内容保留；不将本轮维护分组解释为新加载目录。自然站活体供货和水生运输不由此自动开放。

## 阶段与交付

| 顺序 | 状态 | 交付和边界 |
| --- | --- | --- |
| 1 固体物品 | 数据与查阅表已重构，验证见下方入口 | 2353 份 schema 3 属性。质量与柜容按件，装卸操作按组 |
| 2 流体与生物 | 已接入 | 流体每桶计量，生物逐只计重、逐只受伤。物种与流体覆盖以现行数据目录为准 |
| 3 货柜 | 已接入 | 现有定义、状态与能力统一在正式目录维护。详见[型号能力与结构质量](<../../../05内容数据/02货柜/型号能力与结构质量.md>) |
| 4 贸易列表 | 已接入 | 40 个自然站共 224 条出售、551 条收购，A／B 测试站互补覆盖 195 个精确商品身份 |
| 5 货柜制造 | 已接入 | 投放与测试覆盖数量随正式数据维护。详见[制造配方与投放](<../../../05内容数据/03贸易点/蓝图投放/制造配方与投放总表.md>) |

普通石料为 0.1 Kpg／件。柜体实际空重取结构基线与定义值中的较大值。

自然站报价支持物品、流体和生物，A／B 测试站用于互补验证。柜型与实际投放以正式目录为准。

## 第一阶段完成标准

全部当前注册物品除空气有明确属性；原准入与贴花保留；持续货损整数pcs按默认组大小换算。核验schema、参数、物品ID、默认堆叠与精确变体、部分数量、冻结与保存；数值不超过一位小数。静态质量和服务端验证不替代航程起吊实测。

## 本轮验证

65 项运输与活体 GameTest 全部通过，发布包检查通过。全量单元测试为 993／996。剩余三项分别涉及生物持久化访问边界、玩家站组件数量及就绪位，与本轮报价或载荷数值无关。

按基准收购价高于出售价连接站型，40 个自然站互相可达。149 种正式商品均有至少一处货源和一处有正价差的去向。实际行情、站点距离和当前库存会影响每趟收益。自然站报价在实例创建时冻结，请用新生成的站点验收。
