# 独立货柜制造配方

材料、搭建工时、许可、制造商声望要求和蓝图打印费在独立配方中维护，由贸易点蓝图打印机、蓝图测试工具和搭建器共用。当前73份配方，63款可制造，另10款已配方但待补齐模板。

运行目录：`data/<namespace>/cargo_manufacturing_recipes/<path>.json`。相对路径构成配方ID；例如`cargoverse:aui/atlas_sd_s`。

| 字段 | 规则与职责 |
| --- | --- |
| `schema_version` | 固定3 |
| `container` | 已存在的货柜定义ID，直接决定此配方制造哪个型号；一个型号只允许一份制造配方 |
| `duration_ticks` | 20～72000的整数，内置当前400 |
| `required_license` | S／M／L／X／XL／SP，正式打印和搭建共用的许可门槛 |
| `required_reputation` | 必填对象：`manufacturer`为制造商ID，`level`为该制造商已定义的声望等级（可为0）；打印和搭建均检查实际操作玩家 |
| `blueprint_cost` | `{ "currency": "cargoverse:void_byte", "amount": 80 }`，统一打印费，非负整数；基础型号必须为0 |
| `item_costs` | 1～8项实体材料 |
| `item_costs[].ingredient` | 严格二选一：`item`物品ID或`tag`原版物品标签ID |
| `item_costs[].count` | 1～4096的整数，实际物品个数 |

通过`container`建立配方到货柜定义的结果关联，加载时建立反向索引。未知货柜、同一货柜的重复配方、未知声望制造商／等级、非法数量、无效材料均拒绝发布；未配置配方的型号不进入打印目录。货柜定义继续负责容量、空重、能力和结构模板，不再需要在不同贸易点重复填写材料或打印费。

贸易点制造台使用schema4投放表：条目通过`cargo_container_definition`找到唯一的共用制造配方，只维护投放，不再接受繁荣、许可或价格字段。声望、许可和费用统一读取制造配方。贸易点繁荣度与模块最低繁荣不再影响蓝图解锁。贸易点打印机仅收取蓝图打印费，不扣材料或直接生成货柜。搭建器按蓝图配方ID读取同一材料表，使用相邻容器供料并托管施工；打印机只写入配方ID，不复制整份配方。

配方、货柜和贸易点依赖在同一批`CargoDataReloadListener`中预检并发布，错误不发布半批配置。已经开工的任务继续使用冻结模板、工时、材料与GUI投影。

[货柜搭建器与蓝图测试工具](<../../03组件手册/货柜施工/01_货柜搭建器.md>) · [贸易点蓝图投放表](<../../05内容数据/03贸易点/蓝图投放/README.md>)

基础型号在货柜定义中声明`tags: ["starter"]`和`dispatch_points: 0`。同一玩家只能同时持有一个基础资产（含施工中）；蓝图打印不占此名额，可以重复打印。蓝图免费不免除材料及许可要求。价格、配方变更不追改已开工任务。

## 制造商声望要求

```json
"required_reputation": {
  "manufacturer": "cargoverse:aui",
  "level": 2
}
```

这里表示需要操作玩家的AUI声望达到2级，不是2点声望经验；声望点数按制造商定义的等级表换算。可指定与货柜品牌不同的制造商；不会改用站点的归属品牌或玩家的签约品牌。0级不要求积累声望，基础型均配置0级。内置现有型号沿用原解锁等级数值，转为对应制造商的声望等级；尚未投放的扩充型号按规格配置M=1、L=2、X=3、XL=4。

正式打印每次读取点击玩家的数据，不向公用终端缓存个人解锁状态。搭建器开工再次检查施工玩家，即使取得他人蓝图也需达到要求；失败不收费、不提取材料、不占调度点。创造模式同样检查声望；蓝图测试工具仍可直接发放蓝图，实际施工仍受开工检查约束。已开工任务不会因声望变化中断。
