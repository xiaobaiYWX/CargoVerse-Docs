# 制造商定义

制造商定义维护身份信息、初始货柜型号、个人声望等级和签约承运人价格修正。所有货柜数值、兼容性、防护与缺陷规则都属于具体货柜定义。

## 路径与 ID

```text
data/<namespace>/manufacturers/<path>.json
```

文件生成 `<namespace>:<path>` 形式的制造商 ID。货柜定义和贸易点定义都引用该 ID；贸易点也可以使用字符串 `none` 表示无制造商归属。

## 结构示例

以下缩略示例展示字段格式；正式八家制造商使用 0～5 级声望，完整数据见[制造商设计](<../../05内容数据/04配套内容/制造商/README.md>)。

```json
{
  "schema_version": 1,
  "code": "AUI",
  "display_name": { "translate": "manufacturer.cargoverse.aui" },
  "description": { "translate": "manufacturer.cargoverse.aui.description" },
  "starter_container": "cargoverse:aui/atlas_sd_s",
  "reputation": {
    "levels": [
      { "level": 0, "required_points": 0, "display_name": "陌生人员", "buy_price_modifier": 1.0, "sell_price_modifier": 1.0 },
      { "level": 1, "required_points": 100, "display_name": "登记承运人", "buy_price_modifier": 0.99, "sell_price_modifier": 1.01 },
      { "level": 2, "required_points": 300, "display_name": "工业合作承运人", "buy_price_modifier": 0.98, "sell_price_modifier": 1.02 }
    ],
    "trade_contribution": {
      "value_per_point": 100.0,
      "cargo_class_preferences": {
        "processed_resource": 1.5,
        "mechanical_parts": 1.5
      }
    }
  }
}
```

## 基础字段

| 字段 | 规则 |
| --- | --- |
| `schema_version` | 必填整数 `1` |
| `code` | 必填，2～8 位大写字母或数字；全部制造商中唯一 |
| `display_name` | 必填，支持直接字符串或 Minecraft 文本组件 |
| `description` | 可省略；文本规则同上 |
| `starter_container` | 可省略；直接引用本制造商的 CargoContainer ID。省略时不提供初始货柜；未知型号或其他制造商的型号会拒绝加载 |

制造商定义只承担品牌身份及品牌规则。特殊设计与设计缺陷由货柜定义的 `special_designs` 和 `design_defects` 维护；空重由 `empty_mass` 定义，制造费用由贸易点绑定的制造配方提供。

## 声望等级

`reputation.levels` 必须至少包含等级 0，并满足：

- `level` 从 `0` 开始连续递增；
- 等级 0 的 `required_points` 必须为 `0`；
- 相邻等级的门槛必须严格递增；
- `display_name` 使用制造商等级称号。
- 每级必须填写有限正数 `buy_price_modifier` 与 `sell_price_modifier`；
- 更高等级的买入倍率不得上升、卖出倍率不得下降，并且至少一项必须严格改善。

玩家声望按制造商 ID 分别保存，当前点数达到的最高门槛决定显示等级和签约价格修正。等级称号支持翻译组件。蓝图仍须由本站目录投放，并满足配方配置的制造商声望与许可证门槛。

## 发现与手册排序

制造商首次通过以下任一事件写入玩家档案：注册该制造商签发的运输许可证，或在归属于该制造商的贸易点首次成功装载、卸载或提交物资。档案按事件发生顺序保存制造商 ID，个人航运档案第三章也严格按该发现顺序分页显示。后续交付沿用首次发现时的排序。

制造商归属为 `none` 的贸易点不会触发发现。未发现的制造商不显示在手册中。

## 物资供应声望

制造商站点按本次实际提交量占需求目标的比例发放个人声望，分批提交保留小数。每项总奖励在[物资供应表](<../../02系统规则/自然贸易点/03_物资供应.md#数据配置>)维护。独立站点的供应仍可推进站点繁荣度。

现行制造商定义还要求提供 `reputation.trade_contribution` 供配置解析校验，运行时交付声望取供应表。

## 声望价格修正

玩家注册时会把许可证签发贸易点的制造商写入个人档案。只有该制造商与当前贸易点制造商相同，才应用交易开始时玩家已达到声望等级的 `buy_price_modifier` 或 `sell_price_modifier`。

```text
装载价格 = 站点出售 unit_price × 实际数量 × 动态价格因子 × buy_price_modifier
卸货价格 = 站点收购 unit_price × 实际数量 × 动态价格因子 × sell_price_modifier
```

制造商修正位于价格计算的最后一层。无制造商贸易点、未注册玩家或制造商不匹配时，修正固定为 `1.0`。下一笔交易读取当前已达到的等级。

价格由本站逐条报价决定，货损已扣除实际数量。许可证经验按自然生成目的地的收购报价结算，贸易点繁荣度按公共供应阶段推进，个人制造商声望按实际供应贡献结算。
