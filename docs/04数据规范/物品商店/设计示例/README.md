# 物品商店设计

## 空白模板

| offer ID | 权重 | 解锁繁荣 | 结果类型与内容 | 基础价格（VB） | 库存类型 | 每日最大份数 |
| --- | ---: | ---: | --- | ---: | --- | ---: |
|  |  |  |  |  | `unlimited` / `limited` | 仅有限库存填写 |

同时填写商店名称、抽取次数和是否允许重复。商店商品直接定义实际物品；有限库存按贸易点实例共享，并在交易日切换时重置。

## 当前定义

当前没有内置物品商店定义。需要启用商店时，在数据包中新增定义，并在贸易点的 `item_shop.definitions_pool` 中显式引用。

字段规则见[商店体系](<../01_商店体系.md>)。
