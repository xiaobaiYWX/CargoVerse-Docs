# 生物运输字段与示例

## 运输JSON

路径：`data/<实体命名空间>/cargoverse_entity_properties/living/<实体路径>.json`。无配置不支持识别，不使用未知实体默认准入。支持数据包重载。

```json
{
  "schema_version": 3,
  "form": "living",
  "mass_per_entity": 20,
  "space_units": 3,
  "decal": "cargoverse:decal_none",
  "transport_conditions": {}
}
```

`mass_per_entity`为单只质量，`space_units`为成年舱位。运输条件沿用现行货物侧声明格式；所有生物使用同一运输舱准入，不再配置 `environment` 或按陆生／水生匹配。当前内置 80 种原版生物，凋零、末影龙不配置；逐种数值和配套状态见[生物内容表](../../05内容数据/01运输物品/生物/README.md)。

捕获、释放、全柜扣血与最低生命显示见[生物运输](<../../02系统规则/货物与货柜/17_生物运输.md>)，剩余实施与实机验收见[待完成事项清单](<../../90设计草案/待完成事项清单.md#生物专项>)。
