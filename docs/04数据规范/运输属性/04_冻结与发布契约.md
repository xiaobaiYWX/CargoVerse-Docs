# 基础属性、冻结快照与发布契约

更新：2026-11-03。文件定义、运行会话与网络版本分别维护，不用旧“词条豁免”字段代替现行数值规则。

## 单一维护入口

逐物品属性位于 `data/<命名空间>/cargoverse_item_properties/<form>/<物品路径>.json`。质量、形态、准入、贴花及运输条件在该文件维护。新注册格式为 schema 3 的 `transport_conditions`，与旧 `transport`／需求数组互斥；内置2319份固体属性全部使用schema 3；当前分布见[现行实现](<../../99历史资料/固体质量迁移/首轮实施与验证记录.md>)。流体采用独立属性目录。完整协议见[类型与参数](<00_配置公共协议.md>)。

同一路径按数据包优先级覆盖；不同目录重复声明、目录／form 不一致、未知物品、错误参数和无效贴花均拒绝整代。缺失文件才用源码默认，错误文件不能降级为默认。发布失败保留上一完整代。

## 数据分层

| 数据 | 职责 |
| --- | --- |
| ItemPropertyDefinition／FluidPropertyDefinition | 路径身份、形态、准入、质量、贴花及物品／流体条件 |
| ItemTransportRules | 一次编译为物品 ID 直接查询，无标签扫描或条件集合并 |
| TransportTypes／TransportConfiguration | 源码类型、强类型参数、语义冲突校验及统一编译；未接入类型实际编译报错 |
| CargoContainerDefinition／TransportCapabilities | 货柜的直接防护、设备能力及参数 |
| TransportSnapshot | 冻结货物条件、货柜能力与校准值 |
| TransportAbilityResponse／TransportEnvironmentSampler | 取得有效光照、机械防护及条件所需的外部观测 |
| TransportSession／TransportState／TransportInteriorState | 保存当前的条件计时和已提交事件。瞬时光照与机械读数恢复为未知 |
| TransportEvaluator | 结合在途时间、实际路线和柜体防护生成风险与扣量提案 |
| CargoContentCodec | 按真实介质编解码；未知或损坏内容保留原文隔离 |
| TransportPresentation／ItemCargoClassifications | 只读解释和有界元数据，不运行另一套损耗 |

## 冻结与失败边界

首次成功的正数装载冻结规则。追加必须兼容冻结规则，并继承当前的条件计时。卸空结束当前会话。区块恢复后重新建立观测基线。

声明贴花也被冻结；资源无法解析时显示 none，不因此丢弃货物。原生 ItemStack／FluidStack 卸出不附加全世界腐败组件。

兼容版本、迁移规则和无法解码载荷的隔离行为见[当前数据契约](<../../02系统规则/货物与货柜/07_运行时与存档.md#当前数据契约>)。观测与结算见[运输数值运行时](<../../02系统规则/货物与货柜/14_运输数值运行时.md>)。
