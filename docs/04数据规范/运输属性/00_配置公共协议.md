# 运输配置公共协议

逐项规则、数值和图标分开维护：[货物运输条件](<运输条件/README.md>)、[货柜能力](<../货柜/能力/README.md>)、[核心能力数值](<../../02系统规则/运输状态/README.md>)。本页仅维护共用数据契约。

## 配置归属

| 入口 | 职责 |
| --- | --- |
| `TransportTypes` | 源码注册条件／能力 ID、强类型参数、语义位置、名称和图标 |
| `TransportConfiguration` | 严格解析、字段校验，编译为共同过程，不为每个 ID 新增扣量 Handler |
| 逐物品／逐流体属性 | 精确身份、质量、贴花、准入与 `transport_conditions` |
| 货柜定义 | `abilities`；介质、容量、空重、模板和制造材料仍在原位置 |
| 运行会话 | 冻结声明、当前违规计时和事件去重 |

物品路径为 `data/<namespace>/cargoverse_item_properties/solid/<item>.json`；流体路径为 `data/<namespace>/cargoverse_fluid_properties/liquid/<fluid>.json`。一文件对应一实际对象。物品 `mass_per_item` 按单件计重，流体 `mass_per_bucket` 按 1000mB；价格和经验在具体贸易报价中配置。

物品／流体／生物的外部属性只接受 schema 3 的 `transport_conditions`，不再读取 schema 1／2 的旧配置。货柜沿用 schema 1，只接受 `abilities`，旧 `transport_capabilities`／根级 `thermal_control`／`special_designs`／`design_defects` 均作为未知字段拒绝。不新增独立 profile、继承覆盖或规则脚本。

## 组合与校验

- 未配置即无此条件／能力，不从用途、名称、形态或制造商猜测。注册参数对象不能统一用数值 0 代替，合法零边界按各项说明解释。
- 条件与能力使用不同注册表，不允许混填；未知 ID、未知字段、缺必填、非有限数、非法范围、非整数原生扣量及重复 JSON 键拒绝发布。
- 不同条件可以同时声明。每个词条用自己的宽限、结算周期和扣除量。同一轮到期的货损相加。冷冻与保温、高温与低温、避光与保持光照均独立结算，数据包可以声明没有共同安全区间的组合。
- 完整有效的一代数据才原子发布；失败保留上一代。首次成功正数装载冻结规则，不用 reload 追改在途状态。

## 共用损耗

```json
"loss": {"grace_ticks": 100, "interval_ticks": 200, "amount": 1}
```

`grace_ticks` 是每次持续不符合要求时的非负宽限，`interval_ticks` 是宽限结束后的扣量周期。首次扣量发生在本次违规持续达到 grace＋interval 时。重新符合要求时清零本次计时，下次违规重新计宽限。观测缺失时暂停计时。时间使用服务端 tick，20 tick＝1 游戏秒。

`amount` 为正整数原生数量：固体 pcs、液体 mB，不是栈或桶；生物解释为对每只存活个体施加的生命伤害，详见[生物运输](<../../02系统规则/货物与货柜/17_生物运输.md>)。周期结算使用商／余数，固体／液体合计封顶到现存数量，生物按生命伤害结算，不按只数封顶；不逐物品、逐 mB 或逐周期遍历。

冷冻和保温使用相同的 `loss` 结构。持续缺少主动调温时按各自的规则产生货损。PDA 显示条件是否满足，宽限计时由服务端处理。


## 显示与资源公共约定

GUI、仪表、PDA 和档案使用 `textures/gui/transport/icons.png`（252×254）。前两行是货柜能力，第三、四行是现行运输条件。能力按类型共用图案，等级仍由冻结数据提供并显示在悬浮名称中。绘制保持源区域比例，扫描动画限制在源区域内。

只有货物条件注册独立世界 PNG 贴花，能力不注册贴花。护目镜只显示有效条件名称和必要准入；物品栏不重复显示固体形态，不显示无需求标签。途中展示读冻结规则，查询不运行第二份损耗逻辑。

## 外部配置与冻结快照边界

全部内置资源已经迁入现行作者格式，旧输入分支已退出外部数据解析。物品／流体缺省 `transport_conditions` 表示无条件；货柜缺省 `abilities` 表示无能力，液体仍须显式具有合法舱室能力。未知字段、旧格式和混合格式拒绝发布，重载失败保留上一代。

存档冻结快照另由快照解码器读取，仍保留已支持的数值封套和旧能力换算，用于恢复现有载荷。它不构成外部数据包的兼容入口；当前冻结协议使用的字段不能当作空配置批量删除。未知／不支持的旧载荷继续原文隔离，不清空当作无货。
