# 流体运输属性格式

位置：`data/<流体命名空间>/cargoverse_fluid_properties/liquid/<流体路径>.json`。一文件对应一个实际注册的 Fluid ID，源流体和流动变体分别配置；内置内容使用相同参数，不新增继承机制。

## 字段

| 字段 | 含义 |
| --- | --- |
| `schema_version` | 内置统一为 3 |
| `form` | 固定为 `liquid`，也用于原生气态 Fluid |
| `mass_per_bucket` | 每 1000 mB 的 Kpg；合法范围 0～1000000；正式内容最多一位小数 |
| `decal` | 已注册的货类贴花方块 ID；无需贴花使用 `cargoverse:decal_none` |
| `transport_conditions` | 使用现有条件 ID 和参数；无特殊需求明确写 `{}` |

不包含价格、经验、货柜能力或物品准入字段。schema 3 不能混用旧 `transport`／`transport_requirements`。解析器接受的兼容输入不代表当前内置数据仍使用旧格式。

## 水的内置示例

```json
{
  "schema_version": 3,
  "form": "liquid",
  "mass_per_bucket": 1,
  "decal": "cargoverse:decal_general_supplies",
  "transport_conditions": {}
}
```

## 药水和原生组件

`create:potion` 的所有组件变体共用一个源流体属性，`create:flowing_potion` 配置相同参数。属性查询按 Fluid ID，不按药效、等级或时长分支。原生组件仍属于精确货物身份，存取时保留；共用运输属性不会让不同药水可以混装。普通／喷溅／滞留瓶装物品本身仍走固体通道。

未注册的名称、桶物品 ID 不能当作流体 ID。`minecraft:empty` 不允许作为货物。无显式属性的新 Fluid 使用每桶 1 Kpg、无运输条件、无贴花的默认值。

普通水瓶是例外：Create 将其转为 `minecraft:water`，因此使用水的属性。喷溅／滞留水瓶仍按其实际转换后的流体 ID 处理，不仅凭物品名称决定运输属性。

## 损耗和冻结

液体 `loss.amount` 为整批每次扣除的正整数 mB，不是桶数，也不按柜内桶数相乘；最终封顶到剩余量。易腐坏的间隔和预算都按等效老化 tick 累计；其他持续条件按不利暴露 tick 累计。详见[共用损耗](00_配置公共协议.md#共用损耗)。

装柜冻结本次属性、能力及换算规则。途中重载不改变已装质量、条件或贴花；追加要求冻结属性兼容，正常卸出仍允许。追加、部分卸出不刷新累计状态，卸空再装才开始新运输。

全部有效数据原子发布，未知字段、错误路径、未注册流体或非法贴花拒绝发布。运行时仍保留旧存档／旧格式兼容边界，不在内容调整中删除兼容读取。
