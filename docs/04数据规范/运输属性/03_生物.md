# 生物基础运输配置

现行路径：`data/<实体命名空间>/cargoverse_entity_properties/living/<实体路径>.json`。每个EntityType一份文件，schema_version固定为3、form固定为living。字段、示例及识别边界统一见[生物字段与示例](05_生物字段与示例.md)，本目录不重复维护配置副本。

[逐物种质量、舱位与环境阈值](<../../05内容数据/01运输物品/生物/README.md>)在内容数据中维护，本页只说明配置协议。

## living_chamber

生物货柜在原定义中额外声明：

```json
"capacity": 16,
"living_chamber": {
  "environment": "land",
  "max_entity_bytes": 65536,
  "max_total_bytes": 1048576
}
```

`capacity`为总舱位，不是只数；大体型物种在实体JSON中配置更高的`space_units`，不另配长宽高。不再配置`max_entities`，只数由舱位计算；单体字节上限1024～262144，默认65536；整柜按包含UUID、生命等包装的个体记录累计计费；总字节上限不小于单体上限，最大4194304，默认1048576。环境必填，未知字段拒绝。非生物柜不允许声明舱室。装载后冻结舱室及实体规则，重载不追改在途载荷。

具体装卸、贸易、生命周期和验证柜参数见[生物运输](<../../02系统规则/货物与货柜/17_生物运输.md>)。水生环境与其他后续项目见[统一待办](<../../90设计草案/待完成事项清单.md#生物专项>)。
