# 流体交易表配置示例

## 自然点报价

资源表仍为 schema 3。液体行使用 `type: "liquid"` 和 `fluid`，不使用 `item`：

```json
{
  "schema_version": 3,
  "sales": [
    {
      "rule_id": "water_sale",
      "type": "liquid",
      "fluid": "minecraft:water",
      "unit_price": 5,
      "stock": { "initial": 120, "capacity": 240, "daily_restock": 20 }
    }
  ],
  "acquisitions": []
}
```

上述起始库存为 120 份，即 120,000 mB。收购行同样使用 `type/fluid/components`。许可证经验字段 `license_experience_per_item` 按每 1000 mB 配置，尾量按比例折算后每笔向下取整，缺省为 0。目的地须为已验证的自然生成贸易点。流体作为供应需求时按每 1000 mB 配置目标量，见[物资供应](<../../02系统规则/自然贸易点/03_物资供应.md#数据配置>)。

运行时选择键为 `cargoverse:liquid/<namespace>/<path>`，组件变体追加摘要；组件原文才是身份依据。该带类型的内部键不是数据包里的流体 ID，避免与同名物品的库存、报价混用。
