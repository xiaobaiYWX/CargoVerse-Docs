# 蓝图投放目录定义

`cargoverse:cargo_manufacturing_platform`使用货柜蓝图打印机模型，作为自然贸易点的收费蓝图获取设备。沿用原制造台的方块ID、结构放置和贸易点模块绑定；玩家在搭建器中完成实际制造。

## 目录定义

投放表：`data/<namespace>/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/<path>.json`。路径构成定义ID，由贸易点模块的`definitions_pool`引用。

| 字段 | 当前规则 |
| --- | --- |
| `schema_version` | 固定4 |
| `display_name` | 目录名称 |
| `recipes` | 0～256个条目 |
| 条目`id` | 文件内唯一ID |
| `cargo_container_definition` | 货柜定义，必须存在且有唯一独立制造配方；目录内不重复 |

条目仅包含`id`和`cargo_container_definition`。繁荣度不参与解锁，条目不再允许`min_prosperity_level`、`required_license_level`或`currency_cost`。

材料、工时、许可、玩家个人制造商声望要求与统一打印费由[独立制造配方](<../货柜/02_制造配方.md>)维护。打印不扣材料，不占调度点，不需要建造空间；型号目录只负责投放，费用读取独立配方的`blueprint_cost`，不同站点使用同型号的同一费用。创造玩家跳过打印时的航运注册和许可检查，仍检查个人制造商声望并收取配置费用。声望不足提示所需制造商、要求等级和当前等级，保留空白蓝图与余额。
