# 注册点与基础货柜定义

注册点定义由贸易点的 `modules.registration_point` 模块选择，负责终端名称、许可证类型和初始等级。初始蓝图由签发制造商的 `starter_container` 决定；注册不提供其他奖励。

## 注册点路径

```text
data/<namespace>/trade_points/trade_points_subfunctions/registration_point_definitions/<path>.json
```

文件生成 `<namespace>:<path>` 形式的注册点定义 ID。

## 注册点结构

```json
{
  "schema_version": 1,
  "display_name": "绿洲农业联盟",
  "license_type": "绿洲农业联盟合约特派员",
  "initial_license_level": "S"
}
```

| 字段 | 规则与用途 |
| --- | --- |
| `schema_version` | 必填整数 `1` |
| `display_name` | 必填，最长 64 字符；显示在注册终端顶部翻牌显示器 |
| `license_type` | 必填，最长 64 字符；写入玩家许可证类型 |
| `initial_license_level` | 必填，`S`、`M`、`L`、`X` 或 `XL`；必须存在于玩家档案等级定义中 |

注册成功时，贸易点所属制造商的 `display_name` 写入许可证签发机构，注册点 `license_type` 写入许可证类型；贸易点 `manufacturer` 用于确定签约关系及附赠初始蓝图。无制造商或缺少可制造的初始型号及配方时注册失败，不创建半完成许可证。注册定义不再接受 `registration_rewards`、`reputation_rewards`。

## 贸易点模块绑定

```json
{
  "modules": {
    "registration_point": {
      "min_prosperity_level": 0,
      "definitions_pool": [
        {
          "weight": 1,
          "definition": "cargoverse:oasis_agriculture"
        }
      ]
    }
  }
}
```

贸易点实例注册时稳定抽取一个注册点定义。许可证注册终端只保存贸易点实例 UUID，并通过注册记录取得模块定义；贸易点繁荣等级低于 `min_prosperity_level` 时功能不可用。

## 初始蓝图与制造

制造商的 `starter_container` 指向本制造商专用初始型号；货柜配置 `starter` 标签、0调度点和空能力对象。注册时按该货柜查找独立制造配方，再直接给予一张已打印蓝图。背包满则掉落至玩家身边；无需空白蓝图或打印费，也不发放任何额外物资、货币或声望。

- 已有有效许可证时重复操作不发图；注销后重新注册每次发一张，不设置终身领取次数。
- 正式站点、A/B 测试站及管理员单方块打印工具均排除初始型号，服务端拒绝旧选择。
- 保留独立制造配方，蓝图费用为0；搭建器仍检查许可证、实体材料及建造空间。八款初始配方统一铁锭16件、紧固件箱4件、工业构件箱2件。
- 八家初始型号共享每人一个资产名额，施工开始立即占位。在建、已建、失效及待删除资产均占位；只有取消施工或实际删除资产后释放。
- 注销保留所有货柜和未使用蓝图；重复领取蓝图不影响持有限制。普通货柜正常占用调度点。
