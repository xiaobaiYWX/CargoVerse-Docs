# FTB Quests 可选兼容

FTB Quests 不是 Cargoverse 的必需前置。未安装 FTB Quests 时，货柜定义、买入终端、出售终端、玩家航运档案、货柜词条和运输许可均可正常工作。

安装 FTB Quests 后，任务编辑器会额外出现两个 Cargoverse 任务类型：

- 购买货柜
- 售出货柜

旧版的货柜生成、货柜重置和交付任务已经移除，不再保留兼容入口。

## 购买货柜任务

玩家通过 Cargoverse 买入终端成功购买指定货柜后，任务进度增加 `1`。

可配置字段：

| 字段 | 说明 |
| --- | --- |
| 货柜定义 ID | 要统计的完整货柜定义 ID，例如 `cargoverse:box_test`。 |
| 累计数量 | 完成任务所需的购买次数，最小为 `1`。 |

例如将货柜定义 ID 设置为 `cargoverse:box_test`、累计数量设置为 `10`，玩家累计成功购买十个该货柜后完成任务。

只有交易成功并实际生成货柜后才计数。购买失败、货币不足、超过持有上限或许可等级不足均不会增加进度。

## 售出货柜任务

玩家通过 Cargoverse 出售终端成功售出指定货柜后，任务进度增加 `1`。

可配置字段与购买任务相同：

| 字段 | 说明 |
| --- | --- |
| 货柜定义 ID | 要统计的完整货柜定义 ID。 |
| 累计数量 | 完成任务所需的售出次数，最小为 `1`。 |

只有出售结算成功、货柜实例被正常回收后才计数。失效货柜、扫描失败或不符合出售终端过滤条件的货柜不会增加进度。

## 进度范围

任务进度由 FTB Quests 的 `TeamData` 保存，因此遵循 FTB Quests 自身的队伍、任务重置和重复任务规则。Cargoverse 核心货柜归属仍然按单个玩家记录，不会因为安装 FTB Teams 而改为队伍共享。

FTB 任务只统计安装并启用对应任务之后发生的成功交易，不会回溯安装前的历史购买或出售次数。

## 技术边界

- 核心代码不直接引用 FTB API。
- FTB 类只存在于 `compat/ftb` 可选适配层。
- 模组依赖声明中的 `ftbquests` 类型为 `optional`。
- 未安装 FTB 时不会注册任务类型，也不会尝试读取 FTB 队伍数据。
