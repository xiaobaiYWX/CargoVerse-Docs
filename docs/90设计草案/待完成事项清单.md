### 物品与产品参数

- [ ] **待确认／实现：温度相关保存。** 为代表货物确定安全温区、航程、耐储存预算和温区速率；Eden／CryoVault 的效果来自实际温度，不另设品牌保存倍率。制冷过强仍可能冻结损伤，隔热不等于永久保冷。

- [ ] **待制作与投放。** CryoVault、原 Eden、Aquarium 及兼容隐藏系列按各自模板、业务和生活环境继续设计。BioPod、Cistern、Boreas、Crucible 需要专用结构。当前能力和配方以正式目录为准。

### 应用验收

- [ ] **待验收：装载与能力覆盖。** 高围护能覆盖粗料和细料，不因用途名拒装；高围护但未密封仍可能受潮；无老化声明的货物不运行保鲜损耗。
- [ ] **待验收：温度与老化。** 相同货物同温时老化一致；过冷会伤货；停用调温、改目标和重启不重置实际温度／累计老化；同原因热损伤和加速变质不重复扣量。

- [ ] **网络与会话异常输入。** 继续复核地图、手册、仓库和确认页的关闭后迟到回复、容器编号复用、reload 跨代快照及异常集合／组件输入；优先查真实服务端变更入口，不按客户端按钮是否隐藏判断授权。管理员配置、展示目录保护及制造确认的连接／维度／平台身份与旧令牌隔离已有回归；下一轮重点审查 `CargoTransferOrderService` 静态会话及货柜占用在退出、切换存档和服务器停止时的清理边界，并核对制造预览的客户端迟到回复。静态缓存模式是审查线索，不直接视为已发生货物损失。
- [ ] **Beta 安装与元数据门槛。** 用正式 JAR 在独立客户端和专服安装验证，核对明确前置、测试过的依赖版本及关键 Mixin 失效策略；正式发包前统一 Beta 版本标识、许可证文件、变更说明与已知限制。开发运行通过不等价于干净安装通过，不将源码中的当前版本号直接当作已经批准的发布版本。
- [ ] **发布资源与开发工具清单。** 逐项核定指令测试站、实验生成／发布脚本、占位结构和临时美术的发布用途；保留有正式用途的模板锚点和稳定注册 ID，不能按名称含 test／placeholder 直接删除。正式内容表完成后再决定测试站是否移至独立开发数据包。
- [ ] **吞错与降级语义。** 继续核验第三方物品／流体组件、原生物理和地图持久化失败的降级语义与实机诊断。装载目录整段静默返回空列表、预览质量失败补 1、地图规则字段错误静默套默认值已清理；真实的未知数据、损坏存档隔离及事务回滚保留。数据包旧输入的最终退出依赖前文内置数据迁入，不抢先删除仍被正式配置使用的解析。

## 跨专项验收门槛

以下作为各专项的完成门槛，不要求在纯文档整理时执行测试：

- [ ] **待验收：超远坐标原生物理精度。** 普通实机货轨捕获已由玩家确认；自动测试失败已定位到随机超远坐标的夹具初始偏移，固定近原点测试网格后连续两次全量回归通过，生产捕获逻辑未改。仍需结合 Sable 核验实际可用坐标范围；1400 万格测试可复现初始半格偏移及后续接触位移，不将近原点通过推广为全世界坐标保证。证据及专用探针见[变更验证策略](<../06制作与开发/运维与验证/06_变更验证策略.md>)。
- [ ] **待验收：客户端展示。** 各终端 pcs／mB／mob 布局、超长数字、2D 图标、扫描切换、资源重载及带自定义组件流体的显示。
- [ ] **待验收：Sable 实运。** 货柜移动／拆分时的质量、贴花、时限、区域检测和装卸；玩家贸易点设备只在静态世界使用的限制继续保持。
- [ ] **待验收：真实并发与自动化。** 多人同时提交、持续输入输出、断线、重启及原生仓库重组，不生成影子库存；取消／拒绝／部分执行／回滚守恒，服务端最终复核。
- [ ] **待验收：数据重载与扩展内容。** 属性装载冻结，reload 不改途中质量／需求／贴花；追加精确身份与冻结规则相符。新增流体／实体的标签、组件及原生存取逐项验证，不作任意模组兼容承诺。
- [ ] **待验收：规模与同步。** 不逐 mB 或逐计时周期循环，不因货量大线性增加采样；仅同步必要配置与读数，不逐 Tick 广播整仓／完整实体数据。
- [ ] **待执行：按变更范围验证。** 依[变更验证策略](<../06制作与开发/运维与验证/06_变更验证策略.md>)选择解析、资源、事务或世界测试；视觉、真实区块和多人压测有证据后再关闭对应条目。
