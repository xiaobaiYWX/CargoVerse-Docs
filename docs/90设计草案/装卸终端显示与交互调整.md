# 装卸终端显示与交互调整

本页仅记录尚需调整或验收的内容。现行装载端模型、商品选择、数量滑轨、拉杆与确认流程见[货柜装载机](<../03组件手册/货柜与装卸/13_货柜装载机.md>)；通用物品、流体、生物交付及详情摘要按正式文档执行。

## 下一阶段：旧卸载机

- 根据新的模型与素材确定卸载机仪表布局、实体控件和交互入口，再接入实现。
- 核定货柜、货物、可卸数量、预计收入与拒绝原因的展示；继续使用服务端交易预览和确认事务，避免新增另一套结算规则。
- 明确固体组数与原生件数、流体操作单位与 mB、生物只数与舱位的展示边界；余量以实际可交付数量结算。
- 清理被新布局取代的卸载仪表及资源时，先区分玩家终端仍在使用的内容。

## 客户端与异常验收

- 在普通世界和实际载具环境核验三种介质的图标、模型、超长文本、按钮命中与禁用反馈。
- 生物继续按物种汇总，服务端自动选择并重验个体；卸载按后进先出，保留栈顶无法释放时的提示和恢复边界，不增加逐只列表。
- 核验水生放置、部分成功／冲突反馈、关闭／强制退出后的迟到回执及重试；未转移个体保留归属，已转移个体不重复恢复。
