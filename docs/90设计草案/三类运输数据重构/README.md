# 三类运输数据包重设计

> 2026-11-03 数据已按总路线落地。本目录保留设计依据与尚未开放的产品候选，实机航程继续校准。

## 本轮结论

货物按运输对象分成物品、液体、生物三条通道；同一通道内用运输条件区别保护需求，用货柜能力提供保护。物品用途、制造商归属及贸易分类不再决定某柜能否装载。粉末、碎料仍是物品；气态 Fluid 仍走液体通道。

普通物品可以用普通柜，专业柜的价值是减少特定运输损耗。没有对应运输条件的货物，不为了让某种柜有用而强行添加限制。货柜等级也不形成“高一级即可全面替代”的单一路线。

本方案沿用已经注册的 13 种运输条件和 10 种货柜能力，不增加词条注册表、配置继承系统或另一套货物定义。本文的“参数档案／能力组合”只是编写清单；实际落数据时展开成现有 JSON 字段。
