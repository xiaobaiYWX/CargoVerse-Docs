# 实机航程验收

数据与自动验证结果见[总路线](<00_重构路线.md>)。以下保留实际运输待验收场景。

## 首批航程场景

以5分钟短程、15分钟标准程、30分钟长程作为候选观察窗口，均指已加载且运输系统实际推进的游戏时间，不把卸载离线时长算入。

| 同批货物 | 对照货柜 | 应观察到的差异 |
| --- | --- | --- |
| 3200pcs完整石料 | Courier S／Atlas S | 都无条件货损，只有柜体自重和被动能力差别 |
| 2880pcs细粉 | Atlas S／CoreVault S | 前者围护不足每分钟8pcs，后者消除逸散；采用双方都能装下的45组实际装量 |
| 易受潮粉料 | Silo／Vulcan | 干燥装入后前者只能延迟受潮，后者主动降湿；围护2不等于自动除湿 |
| 玻璃 | Atlas／Hermes／Sentinel | 速度变化耐受10／12／15；完全相同轨迹下缓冲有明确收益 |
| 蛋糕 | Courier／Express／Harvest | 分别暴露于朝向、老化的不同风险，不宣称其中一个全面保护 |
| 生肉 | 普通柜／Harvest | 热环境15分钟左右耗尽保鲜预算；冷藏延长，不刷新旧批预算 |
| 普通冰 | Harvest／CryoVault | 比较暖装降温阶段；仅设备最终目标够低不代表途中无损 |
| 带药效组件的药液 | Cistern／Crucible | 分别暴露与遮光；卸出药效组件完全一致 |
| 八种陆生对象 | BioPod各规格 | 按04章核验只数、舱位、货重、最低生命；兔／鸡／普通牲畜／山羊有效冲击耐受12／14／18／22 |
| 僵尸 | BioPod遮光开／关的受控对照 | 光照≤5时无光损；超限20秒后首次每只1HP；不按原版日晒机制推断 |
| 低压畜牧运输 | 相同稳压、密封1／2对照 | 极低外压下密封1可能补不过泄漏，密封2能维持；固定相同初值和观测 |

生物对照在玩家贸易点的有效黄色识别区内进行，配置每只报价；不能向A/B自然测试站塞入尚无来源后端的实体交易。遮光和密封对照可用临时验证定义，不要求增加玩家设备交互开关。命名个体走管理权限，普通未命名个体验证公共报价；覆盖装备拒绝、驯服主人权限、三只不同生命统一扣血和LIFO部分卸载。

碎料若以3200pcs装载，在持续不合格的30分钟中按当前配置损失240pcs，即7.5%。不同介质使用原生定量扣损，不保证损失比例一致。测试时同时覆盖1组／1桶小批量，防止小批次在提示出现前已全部损失；过重时优先调该商品间隔或扣量，不加一套隐含比例机制。

## 静态可达性检查

以下仅按当前交换模型推算，不代表实机已通过：

- Harvest隔热时间常数240秒、制冷0.3TU/s；外温70、目标8时，目标处回热约62÷240=0.26TU/s，小于制冷。理论可达，但从70冷到8约需8分钟，不能承诺装货后立即冷藏。
- 同条件运输普通冰，降到10TU约需7分钟；其宽限180秒、下一周期60秒后可能已有损耗。CryoVault常数480秒、制冷0.6TU/s，降到10约需112秒，因此深冷柜有明确的暖装优势。
- BioPod采用密封2，压差交换半衰期600秒；外压0、内压1时初始泄漏约0.0012/s，稳压0.02/s有余量。密封1半衰期15秒，外压0.2、内压0.7时漏压约0.023/s，大于设备补压，故不再使用旧密封1候选。
- 密封1湿度交换半衰期300秒；外湿100、内湿40时回湿约0.14/s，除湿1/s足以维持。气密只减慢交换，不把未知观测当成永远合格。

温度公式包含外部环境、初始内部值和控制方向；动态环境变化、暂停与实际采样会影响结果。火／熔岩接触100TU、压湿极端值、转弯与碰撞仍要实机记录。不能据静态推算给全部型号盖上“无损运输”结论。
