# 航运风格统计与雷达图

航运手册第一章中的雷达图表示近期运输风格，不表示累计成长或历史总量。五个轴均为 `0.0～1.0` 的倾向值：运载量、货物价值、丰富度、广域度和可靠度。

## 统一统计窗口

默认窗口为最近 `15000` 个承运货物单位·航段。交易次数不参与窗口截断，将同一次装卸拆成多次点击不会改变统计结果。边界航段按剩余货量比例计入；累计量不足 `minimum_cargo_units` 时不绘制数据多边形。

统计仅在玩家登记航运执照后产生。运输风格与经验资格是两套规则：玩家贸易点等有效航段也可参与风格统计；许可证/繁荣度经验只在自然生成贸易点成功收购时按当地报价结算，玩家来源也可获得。

## 航段状态

系统为玩家名下每个货柜维护一个候选航段状态。玩家在同一贸易点进行任意次数的成功装卸时，只刷新货柜操作后的候选载荷；当货柜第一次在另一个贸易点成功装卸时，系统先用操作前载荷结算上一航段，再用操作后载荷建立下一航段。

因此不需要判断物理离港时刻：

```text
贸易点 A 最后一次装卸后的状态
→ 在贸易点 B 第一次成功操作前确认 A→B
→ 执行 B 的装卸
→ 操作后的状态成为 B 点候选载荷
```

部分卸货后再次补装不会拆出虚假航段。后续航段使用补装完成后的实际载荷和装载率。

## 五轴算法

### 运载量

```text
单航段倾向 = 货柜规格系数 × 航段起始装载率
运载量 = Σ(航段货量 × 单航段倾向) ÷ Σ航段货量
```

### 货物价值

使用候选航段出发时冻结的实际货物平均取得成本，不再读取已删除的抽象商品基础价格，也不是当前收购或出售报价：

```text
平均单位成本 = 出发时剩余货物取得成本 ÷ 出发时货物件数
单项价值倾向 = 平均单位成本 ÷ (平均单位成本 + reference_unit_value)
货物价值 = 按窗口货量加权平均
```

平均单位成本保留小数，例如 4 件共支付 39 VB，按 9.75 VB/件统计，而不是截为 9。无取得成本的货物记 0；不计空柜成本。航段存档保留该均价，之后的市场调价不回写历史。`reference_unit_value` 只是雷达归一化基准，不给物品赋价。

### 丰富度

按实际物品及完整组件的内容键聚合窗口货量，不同组件变体分别统计。设某货物占比为 `p(g)`：

```text
有效货物种类数 = 1 ÷ Σp(g)²
丰富度 = (有效货物种类数 - 1) ÷ (target_effective_goods - 1)
```

结果限制为 `0～1`。

### 广域度

每个航段的货量各以 50% 计入起点和终点。设某贸易点占比为 `p(t)`：

```text
有效贸易点数 = 1 ÷ Σp(t)²
广域度 = (有效贸易点数 - 1) ÷ (target_effective_trade_points - 1)
```

### 可靠度

每个航段使用实际货物数量保持率，不读取独立完整度：

```text
航段可靠度 = 到达时剩余件数 ÷ 航段起始件数
可靠度 = 按窗口货量加权平均
```

数量保持率限制为 `0～1`，不会因为货物在更早航段已经受损而重复惩罚当前航段。完全损失且没有有效到达载荷时不形成有效完成航段。

## 数据包配置

默认路径：

```text
data/cargoverse/player_profiles/default.json
```

```json
"radar_chart": {
  "window": {
    "mode": "recent_cargo_units",
    "cargo_units": 15000,
    "minimum_cargo_units": 500
  },
  "load_scale": {
    "size_factors": {
      "S": 0.2,
      "M": 0.4,
      "L": 0.6,
      "X": 0.8,
      "XL": 1.0
    }
  },
  "cargo_value": {
    "reference_unit_value": 20
  },
  "richness": {
    "target_effective_goods": 8.0
  },
  "coverage": {
    "target_effective_trade_points": 6.0
  },
  "reliability": {}
}
```

`size_factors` 必须完整包含 S、M、L、X、XL，并且从 S 到 XL 不得递减。特殊货柜规格参与统计前也必须显式提供系数。

## 持久化与重置

候选航段和滚动历史保存在：

```text
cargoverse_player_shipping_style
```

重置命令：

```mcfunction
/cargoverse shipping_stats reset [targets]
```

该命令会同时清除目标玩家的已完成航段历史和未完成候选航段，不影响许可证、货柜实例、市场库存或任务进度。
