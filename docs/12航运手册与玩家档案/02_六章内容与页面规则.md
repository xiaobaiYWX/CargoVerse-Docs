# 六章内容与页面规则

本页记录手册页面显示什么；通用输入、弹层和阅读记忆见[入口交互](01_入口交互与货柜HUD.md)，统计公式、地图实现和正文制作分别在专门页面维护。

## 第一章：航运档案

第一章只有一个小页，显示玩家头像、姓名、UUID，以及执照 ID、许可证类型、签发机构、登记日期和有效期。另显示当前许可证等级与叠加印章、距离下一等级的进度、剩余调度点，以及运载量、货物价值、丰富度、广域度、可靠度五轴雷达图。

最高许可证等级印章保持完整颜色，较低等级印章按等级差逐级淡化，以稳定随机角度叠加。雷达图表示近期运输风格，不是历史累计成长，口径见[航运风格统计](08_航运风格统计与雷达图.md)。

未注册玩家不会因打开手册创建运输档案。身份、许可证、调度点和雷达区域保持空白，运输行为不写入其航运风格统计。

## 第二章：货柜管理

无有效许可证时仍可查看和管理玩家名下现存货柜。目录首页左侧按 S、M、L、X、XL 分组，只列出实际拥有的货柜；列表支持滚轮、悬停选中框和点击跳转。右侧固定展示玩家档案登记的基础货柜。

详情页按同一规格顺序扩展，每个书本小页容纳左右两个货柜。每项显示：

- 三维模型、货柜名称、GPS 坐标与调度点占用；
- 当前实际物品数量/容量和当前登记物品，不显示独立完整度；
- 空柜质量与称重质量，单位 `Kpg`；
- 特殊设计、设计缺陷，以及可运输货物类别图标；类别图标空间不足时自动换行。

词条和货物图标沿用公共悬停组件。删除按钮在当前书本打开二次确认；确认后删除货柜资产记录及其物理结构，不返还物品、货币或材料。服务端重新校验所有权、资产和物理状态。删除基础货柜后可到有效许可证对应的注册终端重新领取。

## 第三章：制造商声望

每个展开页左右各显示一个已发现制造商，包括徽章、文字标志、英文全称、介绍、当前声望、下一等级门槛、关系称号和数字等级；最高等级的下一门槛显示 `MAX`。

制造商不会预先填满手册。注册该制造商签发的许可证，或首次在其贸易点成功装载/卸载货物，才记录首次发现。档案持久保存该顺序，页面从左到右、再向后排列；重复交易不重新排序，归属 `none` 的贸易点不触发制造商发现。

## 第四章：生涯统计

左页显示累计承运与成功交付的数量和质量、平均货损率、完成航段、货物收支、净运输收益、最高单次收入及造访贸易点数量。右页展示累计承运量最高的货物分类及分类数据，并显示最近 8 次成功交付的日期、货物图标和本次净利润；图标支持悬停名称。

生涯数据不随许可证注销清除，精确口径和写入时机见[玩家生涯统计](09_玩家生涯统计.md)。

## 第五章：航运百科

### 手工首页与六个分类

首页只有一个跨页，左侧两行三列：启航指南、贸易与交易、货柜与运输、经营贸易点、地图与导航、载具与仪表。它们按玩家阅读需要分类，不对应五个一级代码系统；管理员、数据包和实现说明留在外部文档。

首次进入不自动选中分类，右侧提示先选择左侧按钮。悬停显示名称并高亮，选中保留轮廓；点击分类只更新右页，不播放翻页动画。右上显示分类图标、名称和简述，下方为该类真实 Markdown 条目列表。切换分类回到顶部，重复点击当前分类不重置。

子条目按 `order` 和稳定 ID 排列，空分类显示“暂无条目”。列表使用原生 114×12 背景，物品模型为 10px，行间 3px 空隙不响应点击；名称为右侧箭头预留宽度，超长省略并提供完整标题提示。省略或无效物品图标使用书本。超出显示区域时裁剪并滚动，不覆盖页面装饰。

首页背景为 `295×222`，书内位置 `(27,12)`；分类按钮宽 38px，启航指南高 38px，其余高 39px，保留原图比例。

### 条目阅读

点击列表进入文章，正文按文字和图片自动分页；一篇从左页开始，后续流向右页及下一跨页。一个跨页只属于一篇文章，奇数末页的右侧空白，不拼接下一篇。

- 书页箭头只翻当前条目；链接仅直达对应条目，不维护返回历史。
- 左页页码在左下角，右页页码在右下角；页码内侧相隔 2px 绘制原生 10×10 返回图标，两侧功能相同，空白末页不显示。
- 点击返回图标始终回百科首页，保留分类和列表位置，不同时显示文字返回或目录按钮。
- 正文图片点击可放大，查看层关闭后保持原阅读位置；完整输入规则见[入口交互](01_入口交互与货柜HUD.md)。

首页保持专用设计，只有实际文章正文使用 Markdown。作者从[条目制作流程](05_百科资源与条目制作.md)开始，不为每篇内容添加 Java 页面或 x/y 坐标。

## 第六章：贸易地图

右上地图边角书签进入最后一章。折叠时左页有三个潜在航线栏位，右页下方显示当前个人目的地；展开地图后使用共享地图画布，显示玩家朝向、已知结构、贸易点和航标。

潜在航线、折叠动画、信息卡、双击导航及快捷显示/清除规则统一见[贸易地图与导航](03_贸易地图与导航.md)，底层接口见[地图导航架构](04_地图导航架构与接口.md)。
