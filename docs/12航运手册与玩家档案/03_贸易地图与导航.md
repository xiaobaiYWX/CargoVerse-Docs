# 贸易地图与个人导航

## 地图入口与折叠

贸易地图固定为手册第六章，由右上角地图边角书签进入；悬停高亮，悬停或选中不伸长。右页的折叠地图与入口共享右上锚点，点击后依次向左、向下展开，完成后才显示可操作地图。

展开共 14 帧、每帧 35ms，总长约 0.49 秒；收起以相同速度倒放。第一阶段沿入口右边缘向左展开，第二阶段锚定第一阶段末帧左边缘，底部折页贴图宽度变化不移动上半张地图。

地图边缘覆盖 `map_fold/border.png` 纸张边框，隐藏矩形画布边界。展开/收起期间隐藏实际地图且屏蔽其输入；切换章节必须先收图再翻页。点击纸张边缘或按关闭键收图；服务端档案刷新保留动画、待跳转章节和当前地图视图，完整关闭顺序见[入口交互](01_入口交互与货柜HUD.md)。

航图台是独立的[原版地图桌](../13载具仪表/02_航图台与原版地图.md)，不打开贸易地图，也不共享其探索缓存或导航目标。引导台另有独立地图编辑器，见下文硬件边界。

## 地图操作与信息卡

初次展开以玩家投影后的世界位置为中心，持续更新玩家位置及自身世界朝向；不额外叠加载具姿态，也不显示地图中心坐标和缩放系数。可拖动平移和滚轮缩放。

悬停标记只显示首次发现玩家、到访时间和归属模组等通用信息。点击普通结构、贸易点或普通航标打开固定右下角的信息卡，卡片与边框留有安全距离、保持固定 GUI 大小，不随地图缩放。点击地图空白或拖动不关闭卡片，使用关闭按钮关闭。

- 贸易点卡片显示大名称、归属制造商和收购/出售货物，不重复悬停的通用信息；玩家贸易点显示“玩家经营贸易点”。
- 普通结构显示大名称及第二行坐标，同样支持居中与导航。
- 卡片上方左侧为导航按钮，右侧为居中和关闭按钮；居中只改变视口，不设置目的地。

标记类型、商品图标、航标广播和卡片的共用绘制规则由[地图标记 GUI 规则](../08地图系统/04_结构发现、图标与数据包规则.md#gui-行为)维护，本页只记录手册侧交互。

## 左页：潜在航线

服务端按完整 CargoGood ID 汇总玩家名下有效、装货且未待移除的物理货柜，包含基础货柜，不包含贸易点仓库，也不受货柜目录 64 条展示上限影响。货量以最近一次手册快照为准。

客户端始终取数量最多的前三种货物，在当前维度已经记录的贸易点中，按收购目录寻找每种货物最近的一个目的地；同一贸易点可以对应不同货物。数量相同按货物 ID，距离相同按实例 ID 排序。没有已知收购点时仍保留货物，右侧居中显示“需求未知”；不足三种时空栏只保留底图。

每栏左侧为货物图标，下方居中显示名称和数量（如 `50T`）；右侧显示贸易点名称、水平直线预计航程（格）和目的地**出售**商品，不重复收购目录。出售图标为 8px，每行七个、最多两行，超十四种预留最后位置显示剩余数量。目的地匹配和航程按一秒缓存刷新。

有货物的栏位右上方、信息框内提供“在地图上显示”按钮。名称为按钮预留空间，超长以 `...` 截断。已知需求时点击会展开地图、按实例 ID 居中对应贸易点并打开信息卡，保持缩放，不改变个人目的地；未知需求时灰化并提示“暂无已知收购贸易点”。空栏无按钮，地图展开时被遮挡按钮不产生悬停提示。

## 右页：当前导航点

双击贸易点、普通结构或普通航标图标，或点击其卡片上的指南针，设为当前个人目的地，不强制收图。目的地图标左侧绘制导航标记。双击配对、命中容差和宿主隔离见[接口文档](04_地图导航架构与接口.md)。

收图后右页下方显示名称、XYZ 坐标和水平直线航程。名称放大、最多两行；坐标和航程按实际换行紧凑排列，不重叠。航程单位 `m`、每格一米、带千位分隔，起点使用玩家经 Sable 投影后的世界坐标，不使用 shipyard 内部坐标。

普通结构用对应结构图标，普通航标用灯塔图标，自然贸易点用繁荣度图标，玩家贸易点用所有者头像。无目标时显示“暂无导航目的地”。区域右下角：

- 左侧垃圾桶清除个人目的地，不删除地图资料或标记，也不影响引导台目标。
- 右侧“在地图上显示”展开地图、居中当前目的地并打开信息卡；不替换目标，无目标时两个按钮置灰。

## 目标生命周期与硬件边界

信息卡、视口、个人目的地和引导台目标是不同状态。关闭卡片、拖动、居中、收图、翻页、重开手册或刷新档案都不取消个人目标；选择新目的地才替换。目标按类型与实例 ID 解析，已知名称、位置或繁荣度更新会反映到页面。退出世界、切换维度/玩家或目标资料不存在时清空。

关闭航标广播或撤下地图标记只隐藏显示，不删除已学习的名称、坐标及商品目录，因此不取消已有导航或潜在航线匹配。

个人具名目的地同步至服务端会话，不跨重连保存。手持手册右键引导台显式复制目标，空手右键引导台可在其独立地图设置目标，潜行右键配置 PID。方块目标及参数独立持久化，后续个人选择不自动改写方块，独立地图也不反写个人选择。

地图只处理玩家状态和目的地，不直接操控载具；已实现的转向引导不包含路径规划、避障或自动到达。服务接口和权限边界见[地图导航架构](04_地图导航架构与接口.md)，动力与物理规则见[航行引导台与 PID](../13载具仪表/01_航行引导台与PID控制.md)。
