# 手册入口、通用交互与货柜 HUD

## 物品与入口

玩家手持 `cargoverse:player_shipping_profile` 右键打开航运手册。物品使用独立三维模型与贴图，支持第一/第三人称、背包、掉落物和展示框等标准显示场景。

手册共六章，页面职责见[六章内容与页面规则](02_六章内容与页面规则.md)。左侧五个书签切换前五章，右上地图边角标签进入第六章；书页箭头在当前章节的小页范围内翻页。百科正文的箭头仅翻当前文章，不自动进入下一篇。

## 对准货柜的信息 HUD

主手或副手持有手册并对准货柜时，自动显示货柜信息，不需要右键或佩戴护目镜。仅放在背包内不会触发；切换其他物品、移开准星或打开界面时隐藏。

HUD 显示货柜名称、货物名称与数量、购入总价、货柜总质量、货物完整度、限时剩余时间、词条及所有者。不显示货柜规格、调度点、状态或重复的结算货币行。

- 购入总价以 `VB` 表示，等于货柜购入成本加当前剩余货物的购入成本，不是贸易点的实时收购报价。
- 总质量为货柜空载质量加当前货物质量，单位为 `Kpg`。
- 无运输词条的货物也显示完整度百分比和当前值/最大值；空柜显示“空柜”，完整度为横线。
- 无限时词条时，剩余时间显示横线；有限时时按当前货物的截止时间倒计时。

## 翻页与遮挡

章节切换与普通小页翻页沿用书本翻页动画。百科目录打开条目、链接打开其他条目、返回百科首页同样使用现有动画，动态文章页数不写入静态章节目录。

地图展开时切换章节，必须先完整收图再翻页；展开/收起动画期间不绘制实际地图和被遮挡页面交互。图片查看层、货柜删除确认窗口优先消费输入，不允许点击、滚轮或关闭操作穿透到下层。

百科只使用直达条目链接，不维护浏览历史。两侧有效正文页的页码旁均有返回图标，点击统一返回百科首页，保留原分类和列表位置。

## 关闭顺序

Esc、E 或玩家配置的背包快捷键可关闭手册；存在中间状态时先处理当前最上层内容：

1. 百科图片放大层打开：先关闭图片，再按一次才关闭手册。
2. 货柜删除确认窗口打开：先取消确认。
3. 地图展开或正在展开：先收图；展开中从当前帧反向收起。收图完成后再按一次才关闭手册。
4. 无弹层、无展开地图：关闭手册。

长按关闭键不会连续穿过收图和退出步骤，必须松开后再次按下。

## 阅读记忆与档案刷新

- 当前客户端会话按玩家 UUID 记住章节、小页、货柜目录滚动位置，以及百科分类、列表滚动和当前文章内容锚点；不跨游戏重启保存。
- 重开手册恢复阅读位置；动态货柜数量变化后，原小页不存在则回退到该章节最后一个有效小页。
- 重新进入地图章节时地图处于折叠状态，阅读记忆不保存展开状态；个人导航目标独立保存。
- 服务端档案快照刷新时保留当前阅读、翻页和收图状态，不因重新创建界面而跳页。百科正文资源变化时重新排版，优先按内容锚点恢复，条目已删除则返回百科首页。

状态来源与持久化边界见[本章总览](README.md)，地图交互细节见[贸易地图与导航](03_贸易地图与导航.md)。
