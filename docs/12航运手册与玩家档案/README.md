# 航运手册与玩家档案

本章统一记录航运手册的六章内容、交互与显示规则、贸易地图和导航接口，以及百科条目的制作方法。手册基础界面和图文框架已完成，后续工作以编写与校验百科内容为主。

航运手册是玩家档案系统的主要界面，不是新的业务系统。玩家档案负责身份、航运资格、制造商关系和长期运输进度；手册以只读快照展示这些数据，并提供货柜管理、地图和百科入口。

## 手册六章

| 顺序 | 内容 | 页面类型 |
| --- | --- | --- |
| 1 | 航运档案 | 身份、许可证、调度点、航运风格 |
| 2 | 货柜管理 | 货柜目录、基础货柜和动态详情页 |
| 3 | 制造商声望 | 按首次发现顺序展示关系和声望 |
| 4 | 生涯统计 | 长期累计、分类偏好和近期交付 |
| 5 | 航运百科 | 手工首页、六类目录、Markdown 图文正文 |
| 6 | 贸易地图 | 潜在航线、当前目的地和折叠地图 |

只有第五章的实际条目正文使用 Markdown。其他章节及百科首页保持专用布局，不要求内容作者调整坐标。

## 数据归属与保存范围

| 状态 | 权威来源及保存范围 |
| --- | --- |
| 登记身份、许可证签发信息、基础货柜关联、制造商发现和声望 | 服务端 `PlayerShippingProfileSavedData` |
| 许可证经验、近期航运风格、生涯统计 | 各自的服务端 SavedData，不与阅读位置混用 |
| 货柜详情和持有货物汇总 | 服务端货柜资产仓库，聚合为只读手册快照 |
| 已探索地形和已知标记 | 客户端地图缓存文件；公共标记由服务端同步 |
| 章节、子页、目录滚动和百科阅读书签 | 按玩家 UUID 保存的客户端运行会话，不跨游戏重启持久化 |
| 个人导航目的地 | 客户端选择并同步服务端会话，不写入 SavedData，不跨重连保存 |
| 航行引导台目标及 PID 参数 | 当前方块独立持久化，不随个人目标选择自动变化 |
| 百科正文、图片和排版 | 客户端资源；布局按需缓存，不进入档案网络包 |

服务端以玩家 UUID 为键组合档案快照，客户端不得通过修改界面数据直接改写档案。货柜删除等写操作必须经过服务端复核；许可证注销或终端移除不能隐式清除生涯统计。

## 与其他章节的边界

- 地图采样、纹样、空间索引、文件缓存和标记协议由[地图系统](../08地图系统/README.md)维护；本章只拥有手册入口、显示和目标会话规则。
- 引导台的局部方向计算、PID、动力输出和方块访问校验由[载具仪表](../13载具仪表/README.md)维护；手册不控制载具。
- 货柜物理实例归[货柜系统](../01货柜系统/README.md)，贸易库存、报价和营业额归对应贸易点；虚空字节余额由结算器物品承载。
- 许可证等级、调度点及定义字段见[玩家档案与货柜调度点](../01货柜系统/01核心系统/09_玩家档案与货柜调度点.md)，当前默认内容见[玩家档案数据定义](../10数据包定义与模板/04_玩家档案.md)。

本章由原玩家档案总览、功能方块中的手册/统计说明和百科设计草案整编而来；正式规则以本章为唯一维护入口，不保留另一套重复草案。
