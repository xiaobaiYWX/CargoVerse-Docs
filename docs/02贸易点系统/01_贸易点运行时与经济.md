# 贸易点运行时与经济

## 身份与绑定

贸易点定义 ID 描述配置，贸易点实例 UUID 区分世界中的具体站点。信息柜是实例注册锚点；结构内的装载机、卸载机、仓库信息柜、商店和其他终端只绑定实例 UUID，共享同一经济状态。

手动放置的贸易点不自动使用默认定义。定义或 UUID 留空、引用不存在、注册锚点失效时，业务终端不可用，也不会建立资源目录或库存。

## 资源目录初始化

贸易点定义通过 `resource_table` 引用一份资源表。实例首次建立状态时：

1. 按 CargoGood 完整 ID 排序解析所有标签规则；
2. 生成具体的出售目录和收购目录；
3. 验证同侧无重复、两侧无交叉；
4. 只为 `create_inventory: true` 的货物建立库存；
5. 将具体目录和库存策略写入经济存档。

资源表后续重载不会重选已有实例的货物。需要应用新目录时，应重新建立该贸易点实例状态。

## 两类库存

```text
TradePointState
├─ resourceCatalog
│  ├─ sales[]：具体货物、规则 ID、库存开关、容量、每日补货
│  └─ acquisitions[]：具体货物、规则 ID、库存开关、容量、每日消耗、满库策略
├─ outputCargoUnits：仅保存有库存的出售货物
└─ inputsCargoUnits：仅保存有库存的收购货物
```

出售库存与收购库存完全独立：

- 出售库存由玩家购买减少，按 `daily_restock_per_good` 恢复；
- 收购库存由玩家出售增加，按 `daily_consumption_per_good` 减少；
- 两侧不会互相转移，不存在材料转化；
- 每个匹配货物独享规则给出的完整容量；
- 无库存条目仍能交易，但不会创建或改变库存记录。

收购库存满时，`accept_when_full: false` 会按剩余空间限制交易；`true` 会继续付款接收，溢出部分立即处理，库存仍停在上限。

## 贸易日结算

贸易日长度由 `ticks_per_day` 决定。跨日时按经过的完整贸易日一次性结算：

```text
出售库存 = min(容量, 当前库存 + 每日补货 × 天数)
收购库存 = max(0, 当前库存 - 每日消耗 × 天数)
```

出售补货和收购消耗各自结算。活跃度不再计算或修正生产倍率。

## 活跃度与繁荣度

贸易行为累计的有效交易价值为：

```text
有效交易价值 = 实际交易数量 × CargoGood.base_value × 对应方向权重
```

日结时：

```text
负载 = clamp(当日有效交易价值 ÷ expected_daily_trade_value, 0, max_daily_load)
目标活跃度 = clamp(负载, 0, 1)
新活跃度 = 旧活跃度 + response_rate × (目标活跃度 - 旧活跃度)
```

活跃度保留为贸易点状态和显示数据，不再参与资源变化。玩家向贸易点出售货物时，CargoGood 的繁荣经验仍按实际数量加入，达到 `upgrade_experience` 门槛后逐级升级。

## 价格、制造商与声望

- `pricing.buy_price_multiplier` 是贸易点向玩家收购货物的倍率；
- `pricing.sell_price_multiplier` 是贸易点向玩家出售货物的倍率；
- 动态价格按具体 CargoGood 独立记录并在日结恢复；
- 玩家许可证的签发制造商与贸易点制造商相同时，最后应用 `signed_courier_bonus`；
- 玩家向有制造商归属的贸易点出售货物时，按货物价值和最高匹配偏好增加该制造商声望；
- `manufacturer: "none"` 不产生制造商声望，也不应用签约价格修正。

普通物品商店、货柜制造台和注册点仍是独立功能模块。物品商店从已解析的出售目录选择可用 CargoGood；功能终端不会向资源表增加货物。

## 生产线终端

生产线、原料转化和五个生产槽位已从贸易点经济中移除。生产线终端方块及模型暂时保留，但服务端日结、按钮交互和管理员配置均停用，主屏显示“功能已停用”。

## 加载与存档

货物、容器、制造商、基础货柜、功能定义、资源表、贸易点和结构绑定在同一数据快照中解析并交叉校验，成功后整体发布。

贸易点经济存档当前为 `DataVersion=9`。开发阶段不迁移旧生产线状态；非当前版本会直接丢弃并按当前定义重新建立。

实现依据：`TradePointState.java`、`TradePointStateCodec.java`、`TradePointInventoryService.java`、`TradePointDayProcessor.java`、`TradePointTransactionService.java`。
