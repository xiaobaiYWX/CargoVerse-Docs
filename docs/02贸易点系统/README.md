## 数据制作顺序

1. 定义制造商、货物、货币组和货柜。
2. 定义生产线池及其货物筛选条件。
3. 定义商店、货柜制造台和注册点等子功能。
4. 在贸易点定义中绑定制造商、生产池和模块候选池。
5. 创建结构模板与结构绑定，让同一贸易点实例的终端共享 UUID、模块选择和经济状态。
