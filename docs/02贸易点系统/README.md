## 数据制作顺序

1. 定义制造商、货物和货柜；所有币种字段固定填写 `cargoverse:void_byte`。
2. 定义资源表中的出售、收购、库存和每日周转规则。
3. 定义商店、货柜制造台和注册点等子功能。
4. 在贸易点定义中绑定制造商、资源表和模块候选池。
5. 创建结构模板与结构绑定，让同一贸易点实例的终端共享 UUID、模块选择和经济状态。
