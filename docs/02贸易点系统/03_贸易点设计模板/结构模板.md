```json
{
  "schema_version": 1,
  "structure": "cargoverse:<结构ID>",
  "trade_point_definitions": [
    { "weight": 1, "definition": "cargoverse:<type>/<类别>/<贸易点定义ID>" }
  ]
}
```

文件必须放在 `trade_point_structure_bindings/<type>/...`，其中 `<type>` 只能为 `factory`、`market`、`resource`，并与候选定义 ID 的第一段一致。
