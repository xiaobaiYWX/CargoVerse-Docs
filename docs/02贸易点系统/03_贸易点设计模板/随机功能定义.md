当前已实现的随机商店功能终端是物品售货机。贸易点不设置随机功能时，在此注明“无”并删除后续空表。

## 1. 基本信息

| 项目 | 内容 |
|---|---|
| 贸易点定义 ID | `cargoverse:<id>` |
| 随机功能 | 物品售货机 |
| 商店候选位置 | 待填写 |
| 商店绑定 | `modules.item_shop` |

## 2. 生成与绑定方式

- 是否生成物品售货机由结构模板池决定；需要空置概率时使用 `minecraft:empty_pool_element`。
- 物品售货机是否生成仍由结构模板池决定。
- 贸易点在注册时按 `modules.item_shop.definitions_pool` 加权抽取并持久化一个商店定义。
- 商品存放在 `trade_points/trade_points_subfunctions/shop_definitions/<shop_id>.json`。
- 文件路径中的 `shop_definitions/` 不属于定义 ID；例如 `shop_definitions/resource/general/default_shop.json` 的 ID 是 `namespace:resource/general/default_shop`。
