# 【贸易点名称】：贸易点定义设计模板

> 本页是新贸易点的内容设计工作表，不定义数据格式。现行字段、范围与生效时机见[贸易点定义](../05_贸易点定义.md)，池内字段见[生产线池](../04_生产线池定义.md)。

## 基本信息

| 项目 | 待填写 |
| --- | --- |
| display_name | 直接显示名称 |
| 定义 ID | namespace:resource或factory或market/分类/名称 |
| 文件路径 | data/namespace/trade_points/trade_points_definitions/类型/分类/名称.json |
| node_role | 节点角色 |
| tech_level | 初始选择生产线的科技门槛 |
| ticks_per_day | 日结周期 |
| 定位 | 产品、供应链角色、运输场景 |
| 内容状态 | 设计中／已注册／已完成实机验收 |

## 成长、活跃度与价格

记录 prosperity.initial_level 和 upgrade_experience；记录 activity 的初始值、expected_daily_trade_value、方向权重、max_daily_load、response_rate、production_multiplier.min/max。

记录 pricing.buy_price_multiplier（贸易点收购）与 sell_price_multiplier（贸易点出售），并说明 dynamic_price 是否开启。不要用“每日交易次数”替代有效交易价值。

## 独立功能与结构

普通商店定义位于 `trade_points_subfunctions/shop_definitions`，由 `modules.item_shop` 绑定并在贸易点注册时抽取。搭建台销售空柜不是这里的生产线产物。结构 NBT 与自然生成绑定按结构规范制作。
