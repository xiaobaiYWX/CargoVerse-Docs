## 1. 基本信息

| 项目 | 内容 |
|---|---|
| 贸易点定义 ID | `cargoverse:cloud_farm` |
| 当前随机功能 | 物品售货机 |
| 商店候选位置 | 农庄主楼 |
| 商店绑定 | `modules.item_shop` |

## 2. 生成与绑定方式

农庄主楼预留一个物品售货机结构接口：

- 是否生成物品售货机由结构模板池决定；需要空置概率时使用 `minecraft:empty_pool_element`。
- 物品售货机是否生成仍由结构模板池决定。
- 贸易点注册时按 `modules.item_shop.definitions_pool` 抽取一个商店定义并持久化；是否实际生成终端不影响抽取。
- 商品内容分别存放在 `trade_points/trade_points_subfunctions/shop_definitions/<shop_id>.json`。
