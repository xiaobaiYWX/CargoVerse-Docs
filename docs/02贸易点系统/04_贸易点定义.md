# 贸易点定义

贸易点定义保存站点级身份、经济参数、资源表引用和功能模块池。具体可交易货物及库存参数由独立资源表负责。

## 路径与 ID

```text
data/<namespace>/trade_points/trade_points_definitions/<resource|factory|market>/<分类>/<名称>.json
```

例如：

```text
data/cargoverse/trade_points/trade_points_definitions/resource/general/default.json
→ cargoverse:resource/general/default
```

路径至少包含“类型／分类／名称”三段，第一段只能为 `resource`、`factory` 或 `market`。

## 完整示例

```json
{
  "schema_version": 1,
  "manufacturer": "cargoverse:vbs",
  "display_name": "默认资源贸易点1",
  "node_role": "resource_site",
  "ticks_per_day": 24000,
  "tech_level": 2,
  "prosperity": {
    "initial_level": 2,
    "upgrade_experience": [30, 80, 180, 400, 800]
  },
  "activity": {
    "initial_activity": 0.0,
    "expected_daily_trade_value": 1000.0,
    "max_daily_load": 2.0,
    "input_trade_weight": 1.0,
    "output_trade_weight": 1.0,
    "response_rate": 0.25
  },
  "pricing": {
    "buy_price_multiplier": 0.8,
    "sell_price_multiplier": 1.2,
    "dynamic_price": {
      "enabled": false,
      "min_modifier": 0.7,
      "max_modifier": 1.3,
      "trade_step": 0.03,
      "daily_recovery_step": 0.05
    }
  },
  "resource_table": "cargoverse:resource/general/default",
  "modules": {
    "registration_point": {
      "min_prosperity_level": 0,
      "definitions_pool": [
        { "weight": 1, "definition": "cargoverse:oasis_agriculture" }
      ]
    },
    "item_shop": {
      "min_prosperity_level": 1,
      "definitions_pool": [
        { "weight": 1, "definition": "cargoverse:resource/general/default_shop" }
      ]
    },
    "cargo_manufacturing_platform": {
      "min_prosperity_level": 1,
      "definitions_pool": [
        { "weight": 1, "definition": "cargoverse:resource/general/default" }
      ]
    }
  }
}
```

## 顶层字段

| 字段 | 格式与作用 |
| --- | --- |
| `schema_version` | 必填整数，当前只接受 `1` |
| `manufacturer` | 制造商完整 ID，或精确字符串 `none`；决定声望归属与签约价格修正 |
| `display_name` | 必填非空字符串，贸易点显示名称 |
| `node_role` | 必填非空字符串，保存节点语义；当前不自动改变经济行为 |
| `ticks_per_day` | `1..2147483647`，贸易日长度 |
| `tech_level` | 非负整数，当前保存为站点元数据 |
| `prosperity` | 繁荣度初值及升级门槛 |
| `activity` | 活跃度初值、交易负载和响应参数 |
| `pricing` | 收购、出售及动态价格参数 |
| `resource_table` | 必填资源表 ID，必须在同轮数据中存在 |
| `modules` | 功能模块定义池，可为空对象 |

旧字段 `inventory_profile`、`production_pools` 以及 `activity.production_multiplier` 已删除，出现时会拒绝加载。

## 繁荣度

| 字段 | 规则 |
| --- | --- |
| `initial_level` | `0..upgrade_experience.length`，只用于新实例 |
| `upgrade_experience` | 最多 100 项正整数；数组索引对应当前等级，数值为升到下一级所需经验 |

玩家向贸易点出售 CargoGood 时会增加繁荣经验。达到门槛后逐级升级；最高等级不再积累溢出经验。

## 活跃度

| 字段 | 规则 |
| --- | --- |
| `initial_activity` | 有限数 `0..1` |
| `expected_daily_trade_value` | 有限正数，单日目标有效交易价值 |
| `max_daily_load` | 有限数 `0..1000` |
| `input_trade_weight` | 有限数 `0..1000`，玩家向贸易点出售时的权重 |
| `output_trade_weight` | 有限数 `0..1000`，玩家从贸易点购买时的权重 |
| `response_rate` | 有限数 `0..1`，每日向目标活跃度靠拢的比例 |

活跃度只由交易价值更新，不再产生生产倍率，也不影响资源表的补货和消耗速度。

## 价格

| 字段 | 规则 |
| --- | --- |
| `buy_price_multiplier` | 贸易点向玩家收购货物时的基础倍率，`0..1000` |
| `sell_price_multiplier` | 贸易点向玩家出售货物时的基础倍率，`0..1000` |
| `dynamic_price.enabled` | 是否为每种 CargoGood 启用动态修正 |
| `dynamic_price.min_modifier` | 可省略，默认 `0.7` |
| `dynamic_price.max_modifier` | 可省略，默认 `1.3`，不能小于下限 |
| `dynamic_price.trade_step` | 可省略，默认 `0.03` |
| `dynamic_price.daily_recovery_step` | 可省略，默认 `0.05` |

```text
玩家购买价格 = 数量 × 基础价值 × sell_price_multiplier × 出售动态因子 × 签约买入修正
玩家出售收入 = 数量 × 基础价值 × buy_price_multiplier × 收购动态因子 × 完整度 × 签约卖出修正
```

制造商签约修正始终在最后应用，且仅在许可证签发制造商与贸易点制造商相同时生效。

## 资源表

`resource_table` 只引用一份完整资源表：

```json
"resource_table": "cargoverse:resource/general/default"
```

首次创建实例时，资源表的标签规则会解析成具体 CargoGood 并写入经济状态。贸易点定义不再包含库存容量、生产线选择、生产数量或材料消耗关系。字段说明见[资源表定义](03_资源表定义.md)。

## 功能模块

`modules` 以模块 ID 为键。每项包含：

| 字段 | 规则 |
| --- | --- |
| `min_prosperity_level` | `0..最高繁荣等级`，模块解锁等级 |
| `definitions_pool` | 1～256 个候选；贸易点实例注册时按权重选择并保存 |
| `definitions_pool[].weight` | 整数 `0..1000000`；候选总权重必须大于 0 |
| `definitions_pool[].definition` | 对应模块定义注册表中的完整资源 ID |

当前正式模块为 `registration_point`、`item_shop` 和 `cargo_manufacturing_platform`。同一贸易点实例的终端共享已选模块定义；终端是否存在不会反向改变资源表。

## 生效时机

| 生效时机 | 字段 |
| --- | --- |
| 新实例建立时保存 | `prosperity.initial_level`、`activity.initial_activity`、`resource_table` 解析结果、模块抽取结果 |
| 运行时读取当前定义 | 名称、制造商、贸易日长度、繁荣门槛、活跃度参数、价格参数 |
| 当前仅作为元数据 | `node_role`、`tech_level` |

修改资源表不会改写已存在实例的具体货物目录。修改定义 ID 绑定会重建对应实例的经济状态。

实现依据：`trade/TradePointDefinition.java`、`TradePointDefinitionReloadListener.java`、`TradePointModuleSelector.java`。
