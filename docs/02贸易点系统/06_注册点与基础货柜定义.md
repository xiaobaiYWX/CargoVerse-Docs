# 注册点与基础货柜定义

注册点定义由贸易点的 `modules.registration_point` 模块选择，负责终端名称、许可证类型、初始等级和注册奖励。初始货柜由签发制造商的 `starter_container` 字段直接指定普通货柜型号。

## 注册点路径

```text
data/<namespace>/trade_points/trade_points_subfunctions/registration_point_definitions/<path>.json
```

文件生成 `<namespace>:<path>` 形式的注册点定义 ID。

## 注册点结构

```json
{
  "schema_version": 1,
  "display_name": "绿洲农业联盟",
  "license_type": "绿洲农业联盟合约特派员",
  "initial_license_level": "S",
  "registration_rewards": {
    "items": [
      {
        "item": "minecraft:wheat_seeds",
        "count": 32
      }
    ]
  },
  "reputation_rewards": {
    "reputation_rewards": 50
  }
}
```

| 字段 | 规则与用途 |
| --- | --- |
| `schema_version` | 必填整数 `1` |
| `display_name` | 必填，最长 64 字符；显示在注册终端顶部翻牌显示器 |
| `license_type` | 必填，最长 64 字符；写入玩家许可证类型 |
| `initial_license_level` | 必填，`S`、`M`、`L`、`X` 或 `XL`；必须存在于玩家档案等级定义中 |
| `registration_rewards.items[]` | 注册成功时一次性发放的物品，单项数量 `1..4096`，最多 64 项 |
| `reputation_rewards.reputation_rewards` | 首次注册成功时增加给签发制造商的声望点数，整数 `0..1000000` |

注册成功时，贸易点所属制造商的 `display_name` 写入许可证“签发机构”字段，注册点 `license_type` 写入许可证类型，贸易点的 `manufacturer` 写入隐藏的签发制造商 ID，用于注册声望奖励归属与签约价格修正。贸易点自身的 `display_name` 不再作为签发机构。声望奖励只在首次成功注册时发放，重复注册不会重复发放。无制造商归属的贸易点不能办理许可证。

## 贸易点模块绑定

```json
{
  "modules": {
    "registration_point": {
      "min_prosperity_level": 0,
      "definitions_pool": [
        {
          "weight": 1,
          "definition": "cargoverse:oasis_agriculture"
        }
      ]
    }
  }
}
```

贸易点实例注册时稳定抽取一个注册点定义。许可证注册终端只保存贸易点实例 UUID，并通过注册记录取得模块定义；贸易点繁荣等级低于 `min_prosperity_level` 时功能不可用。

## 制造商初始货柜配置

在 `data/<namespace>/manufacturers/<path>.json` 中添加字段（片段）：

```json
{
  "starter_container": "cargoverse:vbs/harvest_lm_s"
}
```

字段可省略，表示该制造商不提供初始货柜；填写时必须引用属于该制造商的现有货柜定义。领取时按该货柜定义找到唯一制造配方并发放已写入蓝图，不收打印费。后续制造遵守普通搭建器的材料、许可和调度点检查。已移除独立的初始货柜加载目录，注册定义不再接受 `registration_rewards.starter_container`。

## 初始蓝图权益

- 注册时记录签发制造商和本次注册的领取状态；申请领取时读取该制造商当前的 `starter_container` 并反查有效制造配方。
- 每次注册最多领取一张初始货柜蓝图。重复点击、切换终端、重启服务器、使用或销毁蓝图、销毁货柜均不恢复领取资格。
- 蓝图放入背包；背包已满时掉落在领取玩家旁。领取不生成货柜、不创建资产、不占用调度点，也不检查建造空间。
- 蓝图使用普通搭建器流程：需准备材料、满足货柜与配方许可，并有足够剩余调度点。制成货柜按普通资产占点。
- 注销许可证清除本次领取记录、许可证经验和航运风格，保留已制造的货柜；重新注册可再领取一张蓝图。
- 制造商未提供初始型号，或该型号缺少有效制造配方时拒绝领取，不消耗本次资格。

## 八家制造商初始方案

[基础货柜正式目录](<../10数据包定义与模板/05_基础货柜/README.md>)收录全部 8 项权益；[注册点正式目录](<../10数据包定义与模板/10_注册点/README.md>)提供各家的注册模块。所有具有制造商归属的正式空港贸易点均绑定对应制造商的注册模块；地面小型贸易点不提供注册服务。旧存档继续保留签发制造商、领取记录和货柜编号，不再读取旧的 StarterDefinition 字段。未领取者按签发制造商当前配置领取；已领取设备保留型号快照，不会因本次迁移重复发放。
