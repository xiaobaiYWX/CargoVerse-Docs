# 注册点与基础货柜定义

注册点定义由贸易点的 `modules.registration_point` 模块选择，负责终端名称、许可证类型、初始等级和注册奖励。基础货柜定义把注册权益映射到一个普通货柜型号。

## 注册点路径

```text
data/<namespace>/trade_points/trade_points_subfunctions/registration_point_definitions/<path>.json
```

文件生成 `<namespace>:<path>` 形式的注册点定义 ID。

## 注册点结构

```json
{
  "schema_version": 1,
  "display_name": "绿洲农业联盟",
  "license_type": "绿洲农业联盟合约特派员",
  "initial_license_level": "S",
  "registration_rewards": {
    "starter_container": {
      "definition": "cargoverse:starter_containers/oasis_basic"
    },
    "items": [
      {
        "item": "minecraft:wheat_seeds",
        "count": 32
      }
    ]
  },
  "reputation_rewards": {
    "reputation_rewards": 50
  }
}
```

| 字段 | 规则与用途 |
| --- | --- |
| `schema_version` | 必填整数 `1` |
| `display_name` | 必填，最长 64 字符；显示在注册终端顶部翻牌显示器 |
| `license_type` | 必填，最长 64 字符；写入玩家许可证类型 |
| `initial_license_level` | 必填，`S`、`M`、`L`、`X` 或 `XL`；必须存在于玩家档案等级定义中 |
| `registration_rewards.starter_container.definition` | 可省略；引用基础货柜定义 |
| `registration_rewards.items[]` | 注册成功时一次性发放的物品，单项数量 `1..4096`，最多 64 项 |
| `reputation_rewards.reputation_rewards` | 首次注册成功时增加给签发制造商的声望点数，整数 `0..1000000` |

注册成功时，贸易点所属制造商的 `display_name` 写入许可证“签发机构”字段，注册点 `license_type` 写入许可证类型，贸易点的 `manufacturer` 写入隐藏的签发制造商 ID，用于注册声望奖励归属与签约价格修正。贸易点自身的 `display_name` 不再作为签发机构。声望奖励只在首次成功注册时发放，重复注册不会重复发放。无制造商归属的贸易点不能办理许可证。

## 贸易点模块绑定

```json
{
  "modules": {
    "registration_point": {
      "min_prosperity_level": 0,
      "definitions_pool": [
        {
          "weight": 1,
          "definition": "cargoverse:oasis_agriculture"
        }
      ]
    }
  }
}
```

贸易点实例注册时稳定抽取一个注册点定义。许可证注册终端只保存贸易点实例 UUID，并通过注册记录取得模块定义；贸易点繁荣等级低于 `min_prosperity_level` 时功能不可用。

## 基础货柜路径与结构

```text
data/<namespace>/starter_containers/<path>.json
```

```json
{
  "schema_version": 1,
  "container_definition": "cargoverse:vbs/harvest_lm_s"
}
```

`container_definition` 必须引用存在的货柜定义。基础货柜沿用该型号的结构、容量、空柜质量、耐久、兼容货物、制造商特性，但不经过制造台配方、货币成本和库存材料成本。

## 基础货柜权益

- 注册时把基础货柜定义 ID 写入玩家档案，不立即生成实体货柜。
- 玩家可在任意可用注册终端查看档案中记录的基础货柜型号并申请领取。
- 每名玩家最多持有一个有效基础货柜；资产使用独立标记识别，不以型号判断。
- 基础货柜按自身定义正常占用调度点；领取权益不经过普通货柜制造配方。
- 领取必须绑定一个有效货柜生成点，模板必须能放入定位范围；完整生成范围必须已加载、处于世界边界内、不含遮挡方块且不与现存 Sable 物理结构相交。
- 基础货柜被删除后，档案中的实例 ID 会清空，玩家可以再次领取。
- 注销许可证会删除所有带基础货柜标记的资产，并清除基础货柜权益；普通货柜不受影响。
