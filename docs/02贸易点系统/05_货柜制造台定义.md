# 贸易点货柜蓝图打印机

`cargoverse:cargo_manufacturing_platform`使用货柜蓝图打印机模型，作为自然贸易点的收费蓝图获取设备。沿用原制造台的方块ID、结构放置和贸易点模块绑定；玩家在搭建器中完成实际制造。

## 目录定义

投放表：`data/<namespace>/trade_points/trade_points_subfunctions/cargo_manufacturing_platform_definitions/<path>.json`。路径构成定义ID，由贸易点模块的`definitions_pool`引用。

| 字段 | 当前规则 |
| --- | --- |
| `schema_version` | 固定3 |
| `display_name` | 目录名称 |
| `recipes` | 0～256个条目 |
| 条目`id` | 文件内唯一ID |
| `cargo_container_definition` | 货柜定义，必须存在且有唯一独立制造配方；目录内不重复 |
| `min_prosperity_level` | 最低繁荣，与模块门槛取较高值 |
| `required_license_level` | 蓝图获取许可；生存玩家需先注册航运身份 |
| `currency_cost.currency` | `cargoverse:void_byte` |
| `currency_cost.amount` | 0～2147483647的整数，蓝图打印费 |

材料与工时由[独立制造配方](../10数据包定义与模板/15_货柜制造配方/README.md)维护。打印不扣材料，不占调度点，不需要货柜生成点；型号目录与原有价格数值沿用现有投放表。创造玩家跳过航运注册和许可检查，打印仍收取配置费用。

## 定影器与打印

1. 手持空白货柜蓝图右键定影器，将一张蓝图转移到公开暂存槽，表面显示白色蓝图模型。
2. 用上下按钮选择货柜，绿色PRINT按钮打印。服务端重新检查目录、繁荣、许可、空白载体与付款，扣费后写入唯一配方ID，表面切换为蓝色模型。
3. 再次右键定影器取回物品，背包放不下的部分掉落。任意玩家均可存取，无所有者校验。空白蓝图也能直接取回。

定影器只接受空白货柜蓝图；已有蓝图时点击执行取出。已打印蓝图留在槽内时无法覆盖或再次扣费。内容随方块实体保存和同步；拆除任意结构成员时，槽内蓝图只掉落一次。打印即时完成，不再打开原材料确认页。

## 表面显示

五个翻牌显示器分别显示：最大装载量（U）、空柜质量（Kpg）、占用调度点、运输介质（物品／流体／生物）、蓝图打印费。保留型号页码、货柜名称、说明、能力图标与结构全息预览。编号仪表保留模型基座，按钮定位模型替换为通用按钮。上下切换按钮朝外排列；全息预览在原朝向上额外旋转90°，随终端水平朝向一起转动。碰撞与选中形状按机身、侧柜和倾斜面板分部缓存；斜面以1模型像素步长近似，移除旧前伸占位和上方空白区域的实体碰撞。

实现入口：`CargoManufacturingPlatformBlockEntity`、`CargoManufacturingPlatformSurfaces`、`CargoManufacturingPlatformDisplay`、`CargoManufacturingPlatformRenderer`。
