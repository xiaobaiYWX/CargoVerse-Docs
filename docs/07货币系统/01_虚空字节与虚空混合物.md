# 虚空字节与虚空混合物

CargoVerse 使用单一固定货币虚空字节（Void Byte，`VB`）。货币 ID 固定为：

```text
cargoverse:void_byte
```

系统不加载数据包货币组，不支持自定义币种、实体面额或找零。货物、货柜、商店和货柜制造台中保留币种字段，是为了让各定义明确表达结算单位；这些字段当前只能填写 `cargoverse:void_byte`。

## 虚空结算器

虚空结算器（Void Settlement Unit）是保存和转移虚空字节余额的实体物品，资源 ID 为 `cargoverse:void_settlement_unit`。

- 单个物品不可堆叠；
- 余额保存在物品数据组件 `cargoverse:void_byte_balance` 中；
- 余额使用非负整数，空数据按 `0 VB` 处理；
- 物品提示显示当前余额；
- 交易只识别玩家主物品栏和副手中携带的虚空结算器；
- 支付时可以跨多个已携带结算器依次扣款；
- 收入写入找到的第一个结算器；没有携带结算器时不能接收交易收入；
- 交易失败时通过支付或入账回执恢复已修改的余额。

虚空结算器本身就是实体钱包，但余额不是占用背包格位的多面额物品。终端价格仪表只显示缩写 `VB`；交易消息和一般说明可显示完整名称“虚空字节（VB）”。

## 已接入交易

统一货币服务已经用于：

- 货柜装载机购买贸易点输出货物；
- 货物卸载机出售货物并收取收入；
- 货柜制造台支付制造费用；
- 物品售货机支付商品费用；

服务端在提交时重新检查币种和余额。扣款、入账、库存、货柜资产及相关统计位于业务事务的补偿边界内；交易中止时不保留单独发生的余额变化。个人航运档案中的货柜删除属于永久清除，不发放 `VB`。

## 数据定义

货物与货柜：

```json
"trade_currency": "cargoverse:void_byte"
```

商店与货柜制造配方：

```json
"currency": "cargoverse:void_byte"
```

填写其他 ID 会被判定为不支持的币种，并使对应数据发布失败。虚空字节不是物品注册 ID，不能用 `cargoverse:void_settlement_unit` 代替。

## 虚空混合物

虚空混合物（Void Mixture）是独立的可流动异常物质，不是当前交易货币。相关资源为：

| 内容 | 资源 ID |
| --- | --- |
| 源流体 | `cargoverse:void_mixture` |
| 流动流体 | `cargoverse:flowing_void_mixture` |
| 桶 | `cargoverse:void_mixture_bucket` |
| 世界方块 | `cargoverse:void_mixture` |

虚空混合物可用桶放置和收取，使用标准 NeoForge 流体能力，可进入兼容的通用储罐和管道。它不会通过相邻源方块生成无限流体。虚空混合物转换为虚空字节的“虚空相位转存”尚未接入，因此携带流体、流体桶或便携储罐都不会增加可交易余额。

## 便携储罐

便携储罐资源 ID 为 `cargoverse:portable_tank`，方块形态和物品形态共享同一份流体内容。

- 容量固定为 `10000 mB`，即 10 桶；
- 只接受虚空混合物；
- 储罐物品不可堆叠；
- 放置时把物品中的流体写入方块实体，破坏时把剩余流体写回掉落物；
- 手持兼容流体容器右键方块可装入或取出流体；
- 方块只在底面向管道暴露流体能力，其他五个方向不能连接；
- 世界内和物品形态都会按实际液位渲染内部流体；
- 方块选择框与碰撞箱贴合当前储罐模型。

便携储罐使用标准物品流体能力，因此在物品形态下也能参与兼容的流体转移，但它不属于虚空字节支付链路。
