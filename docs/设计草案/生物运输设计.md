# 生物运输后续设计

首版玩家贸易点活体装卸、逐只载荷、后进先出、统一扣血和通用界面已归入[生物运输](../01货柜系统/01核心系统/17_生物运输.md)，本页只保留尚未完成的范围。

- 正式实体清单、质量、舱位、运输条件与保护参数按[生物运输数据设计](三类运输数据包重设计/04_生物运输设计.md)维护：首批八种陆生候选及BioPod能力已形成具体表与JSON，尚未落入运行数据。BioPod专用模板、制造材料及正式投放继续核定，当前验证数值不代替正式平衡。
- Aquarium水生环境、可靠的水体放置、维持资源与耗材质量。不能以湿度数值代替实际水生环境，也不能只改容量开启。
- 驯服、鞍、背包、装备、拴绳与模组缩放／世界关联的逐类兼容；原生NBT可保存不等于外部关联都能恢复。
- 自然贸易点活体交易的实体来源、生成／回收、价格筛选及经验结算；不将世界围栏库存伪装成抽象自然站库存。
- 释放部分成功与待恢复冲突的玩家反馈；保留原UUID和原文，不能通过丢弃数据或生成新UUID解决冲突。
- 真实重启／断电、跨维度、Sable运输、多人吞吐和第三方生成拒绝的实机验收。

实施和验收统一见[生物专项](待完成事项清单.md#生物专项)。后续仪表布局见[装卸终端显示与交互调整](装卸终端显示与交互调整.md)。
