# 货物系统重构：现行工程基线与收尾

更新：2026-10-20。本页合并分阶段实施记录，以当前代码为准，不再并列维护已经撤销的旧方案。核心架构替换和主要实际物品闭环已完成，现处于内容配置、联机验收与收尾阶段；40 张正式自然站货物表仍为空，A／B 指令测试表已接入，不表示交易框架尚未实现。

## 1. 首版边界

仅实现实际物品闭环；流体、实体以后专项设计，不建立空适配层。1 个实际物品 = 1 个货柜容量单位，不按栈、不显示为 t，质量独立计算。

一柜只存一种物品及一种完整组件状态；名称、耐久、附魔等不同变体不能混装。首版拒绝已知非空嵌套容器及无法无损编码的内容。缺失物品或损坏载荷隔离并保留原文，不降级为空柜。

## 2. 数据职责

| 数据 | 现行职责 |
| --- | --- |
| ItemCargoIdentity / ItemCargoPayload | 原生物品 ID、完整组件、整数数量 |
| ItemTransportProfile / ItemTransportSnapshot | 分类、单位质量、固定扣量要求；装载时冻结 |
| CargoContainerSnapshot | 设备、分类许可、容量、空柜质量 |
| CargoLoad / CargoLossClock | 实际载荷、运输状态、取得成本与时限 |
| ResourceTableDefinition / TradePointResourceCatalog | schema 3 站点报价、库存策略、每日额度与交付经验 |
| PlayerTradeVaultInventory | Create 保险库适配、精确变体报价及短周期观察缓存，不拥有实物库存 |

不保留抽象货物目录、全局物品基础价、全局经验或另一套仓库账本。运输可用性不代表自然贸易点必须收售该物品。

## 3. 仓储与交易

实际物品只存于 Create 保险库，通过附着式仓库收发器绑定核心。容量由真实槽位、堆叠规则及 Create 配置决定，不再有固定 5000 仓容。拆分跟随收发器附着点；合并出现重复归属时暂停交易。

仓库管理终端 SET 编辑核心保存的精确变体单价与独立上架开关，核心不再提供入口；未配置价格 0、买卖关闭。保留数量和收购目标已删除，出售按实际库存、收购按原生可插入空间限制，不预留仓位或限制外部自动化。两页只显示当前库存，需先存入样本才能上架，删除只清除选中物品当前模式的单价和开关，不自动保存草稿。公共装卸始终正常付费，包括所有者和授权管理员。

仓库管理终端已作为可选设施恢复，提供独立免费管理装卸与仅所有者可用的 SET，不保存实物，不依赖公众营业或报价。打包机、输入输出锁定与永久清仓仍已删除，不作为待开发设备。自动化直接访问保险库；本模组权限不替代领地保护。

交易重新校验实际库存、货柜、范围、绑定和资金，失败回滚本次变更，不用整仓旧快照覆盖 Create 当前内容。不为读取仓库强制加载区块。

## 4. 自然站点报价与经验

价格设置在具体交易处，不属于物品运输参数。schema 3 使用精确 item/components、本地 unit_price、可选出售 stock、收购 daily_limit，以及收购侧每件许可证/繁荣度经验，未配置经验为 0。

仅按收购目的地判定经验：自然→自然、玩家→自然均按实际成交件数发放目的地收购条目配置的两类经验；自然→玩家、玩家→玩家不奖励。自然生成身份由服务端核验目的地结构实例，不根据客户端、ID 前缀或所有权推断。手动普通点作为目的地仍不奖励。

不再记录来源批次或维护 FIFO 来源。自产、管理员补入及玩家保险库中转货物到自然目的地成交时均按报价奖励；仓库装卸本身不奖励。只计算实际成交件数，成功付款、货物和两类经验在同一补偿事务内提交，失败或重复请求不得重复奖励。

40 张自然站货物表仍为空；A／B 两张指令测试表已填充互补的 149 种实际物品。结构、制造、注册和普通物品商店保留。配置和示例见[实际物品报价与运输经验](../02贸易点系统/03_资源表定义.md)。

## 5. 权限、建点与 Sable

- 所有者独占核心交互、商品配置、授权名单和连接工具绑定/解绑。
- 授权管理员可用管理类终端，公共终端对所有玩家开放。
- 核心放置后无主，点击 AUTH 打开核心 GUI，长按绿色页签 3 秒注册；按所有者 UUID 跨维度计数，默认最多 3 个玩家贸易点，可配置；未加载、暂停营业仍计数。配置默认值变更不覆盖已有服务器配置。
- 所有者长按红色页签 3 秒注销或拆除核心均释放名额；注销清除绑定、授权、报价并返还结算器，但保留方块和保险库物品。不设创建费用或冷却；防频繁拆装以后另做。
- 核心授权只查询本存档 `playerdata/*.dat` 已有玩家，按名称或 UUID 匹配；本地 UUID 缓存仅提供这些记录对应的名称，不联网查询或生成离线 UUID。新玩家尚无保存记录、或本地缺少对应名称时直接拒绝添加，不引入兜底。
- 玩家贸易点设施可放置在 Sable 上，但不能绑定或使用，服务端校验并提示；不删除方块或仓库物品。
- 限制设施不限制货柜本身，静态贸易点仍可装卸 Sable 运来的货柜。

## 6. 存档与同步

开发期破坏性重构，不迁移旧抽象货物、完整度、自有仓库或旧经济数据，也不建立兑换表。

当前货柜根 DataVersion 5、实例 FormatVersion 9、物品载荷包络 1、经济 DataVersion 15、网络协议 64。来源批次已从载荷与存档中删除；商品 GUI 向打开菜单的所有者定向同步有界显示行。

运输配置与物品标签在标签绑定后编译并原子发布，冲突保留上一完整代，不在装卸 tick 扫描全注册表。

## 7. 界面与统计收尾

HUD 显示实际数量、剩余保护时间和质量，不恢复完整度或吨数。玩家信息柜无全局基准价，不显示伪涨跌，模型基座保留；普通站点信息柜仍以当地报价为基准。

航运风格货值轴改用出发时实际货物取得成本 / 件数，保留小数并存档，不读取固定 0 或旧基础价；不计空柜成本。风格统计不等于运输经验资格，算法见[航运风格](../12航运手册与玩家档案/08_航运风格统计与雷达图.md)。

## 8. 运输参数约定

### 8.1 分类

采用运输 JSON + 物品标签 + 唯一默认配置。当前 14 类、77 个专用组、1122 个明确物品 ID；默认 general_supplies / 0.001 Kpg / 无要求。此为首批覆盖，不表示全部物品已归类或平衡。

同一物品命中多个专用配置拒绝新一代；不用文件顺序、注册名或配方猜分类。追加要求完整身份和冻结规则一致，reload 不改途中货物。

### 8.2 固定数量损耗

词条每次扣固定整数件数，不是百分比；不足时扣到零，不生成损坏货物。易碎的实测速度向量变化可包含高速转弯，不宣称精确碰撞检测。环境采样只结算实际条件，不模拟未加载时的未知环境。

损耗后立即按剩余数量计算质量；交易按实际转移件数计价，不再叠加完整度折价。具体数值与已知局限见[首批运输数据](../10数据包定义与模板/01_物品运输/首批运输数据.md)。

### 8.3 时限

保护期结束后再经过完整扣量间隔首次扣货，之后周期扣固定整数。使用服务端游戏 tick，停服不推进；区块卸载期间按游戏时间推进，恢复时有界补算，不逐周期循环。

成功追加先结算旧到期损耗，再刷新整个有效载荷保护期；不恢复已损失数量。部分卸货不刷新。入库结束运输，重新出库使用当前规则和新保护期；不向物品组件写终身年龄。
