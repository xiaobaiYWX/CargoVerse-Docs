# 航运手册百科：Markdown 与排版规范

状态：首版制作基线 v1.0，2026-10-19。六分类首页、受限 Markdown、图文自动分页、页码旁返回图标及图片放大已完成阶段收尾，后续进入条目编写；每篇正式内容仍需游戏内视觉验收。实际资源路径、预算和刷新步骤见[制作说明](../12玩家档案系统/02_百科资源与Markdown制作.md)。

## 1. 目标与边界

第五章节作为游戏内百科，承载机制解释、方块与物品用途、操作步骤和注意事项。第六章节仍为贸易地图，不改变其他章节的专用排版。

核心目标：新增普通图文条目只添加 Markdown 和图片；不写 Java、不填 x/y 坐标、不按字数人工拆页。页面是排版结果，条目才是内容制作单位。

首版实现受限 Markdown，而非完整 CommonMark、HTML 浏览器或网页布局引擎。解析器、排版器、渲染器分离；本文没有列出的语法不承诺兼容。本文本身是设计说明，可以使用表格和代码围栏；游戏内正文的语法以第 4 节为准。

## 2. 内容组织与资源约定

### 2.1 文件位置与稳定 ID

建议客户端资源目录：

```text
assets/<namespace>/handbook/entries/<language>/<category>/<name>.md
assets/<namespace>/textures/handbook/<category>/<name>.png
```

例如 `assets/cargoverse/handbook/entries/zh_cn/player_trade_points/warehouse.md` 的条目 ID 为 `cargoverse:player_trade_points/warehouse`。ID 来自路径，不取显示标题，也不包含语言；同一条目的译文使用同一相对路径。子目录允许继续细分，但一级分类不变。

百科以帮助玩家理解和使用为目标，不照搬代码的五个一级系统。首页固定六个分类入口，内容侧重用途、操作、正常反馈与限制；只有影响玩家决策的数值才需说明，不介绍内部实现、存档结构或公式推导。

| 分类 ID | 显示名称 | 内容边界 |
| --- | --- | --- |
| `getting_started` | 启航指南 | 航运资格、基础货柜、货币与第一次运输的阅读路线 |
| `trading` | 贸易与交易 | 普通贸易点、购买与出售、装卸终端、结算与常见交易问题 |
| `containers` | 货柜与运输 | 抽象货物、货柜用途、装卸区域、运输和回收 |
| `player_trade_points` | 经营贸易点 | 自建贸易点、仓库、营业、权限、绑定和库存保护 |
| `map_and_navigation` | 地图与导航 | 地点发现、标记、潜在航线、个人目的地与目标交接 |
| `vehicle_instruments` | 载具与仪表 | 仪表基座、模块读数、航行引导台及其配置 |

分类名称由语言资源提供。跨系统知识确定一个主要分类，再用条目链接关联，不重复维护多份正文。

启航指南是推荐阅读路线，不重复其他分类的完整说明；地图与导航讲目标选择和地点信息，载具与仪表讲硬件操作及实际控制。管理员、数据包作者和模板制作者的详细资料继续放在外部文档，不另占百科首页入口。

### 2.2 可选的简易文件头

```markdown
---
order: 100
icon: minecraft:chest
---

# 仓库管理终端
```

- 文件头可省略；存在时必须位于文件开头，两行独立的 `---` 之间。
- 只允许 `order` 和 `icon` 两个键；这不是通用 YAML，不支持数组、对象、别名、表达式或多行值。
- `order` 为非负整数，默认 `1000`；相同时按完整条目 ID 排序。
- `icon` 为已注册物品 ID，用于目录图标；省略或物品不存在时使用统一书本占位图标，不阻止阅读。
- 文件头中的字符串按字面值读取并去除两端空白，不需要引号。
- 标题只取正文首个 `# 标题`，不在文件头重复填写。
- 分类从目录推导，将正文条目填入手工设计首页的右侧子条目列表，不逐篇增加 Java 页面；六个主分类按钮和简介是固定的首页设计。
- 重复键、未知键、无效 `order` 或不闭合文件头给出作者错误，不静默忽略。

### 2.3 资源包与语言

- 正文和图片属于客户端资源，不是服务端数据包，也不写入玩家档案快照。
- 允许资源包按完整资源路径覆盖正文和图片；同路径按资源包优先级选取，不拼接两份正文。
- 每个条目依次选择当前语言、`zh_cn`、`en_us` 的完整版本，重复候选跳过；当前以中文内容为默认。可以混合显示不同条目的回退语言，但不混合一篇文章的不同语言段落。
- 按稳定条目 ID 合并各语言目录，避免当前语言缺少译文时整条内容从目录消失。
- 分类和排序的跨语言一致性纳入制作检查；改变条目路径相当于更换 ID，已有内部链接需要同步修改。

## 3. 页面与导航模型

### 3.1 手工设计的首页（已接入）

第五章节只保留一个首页跨页，使用 `pages/encyclopedia_home.png`，位置为书内 `(27,12)`，尺寸 `295×222`。左侧六个分类按钮分两行三列，依次为启航指南、贸易与交易、货柜与运输、经营贸易点、地图与导航、载具与仪表；使用各自原图，宽 38px，启航指南高 38px，其余高 39px，不拉伸到统一方形。

首次进入时不自动选中分类，右侧提示先选择左侧分类。按钮悬停高亮并显示名称，选中状态保留轮廓；点击只切换右页内容，不播放翻页动画。右上虚线区域显示分类图标、名称与简述，下方框内显示子条目目录，超出时滚动。目录、图标和文字不覆盖底部装饰。

当前由 `HandbookCategory` 提供六类、图标和简介，子条目由实际 Markdown 资源生成，不再维护待编写提纲。条目可点击阅读，没有正文的分类显示“暂无条目”。客户端阅读记忆包含所选分类、列表滚动、当前文章和内容锚点，档案刷新也保留；不维护条目跳转历史，首页和阅读状态不发给服务端。

### 3.2 一篇条目可以跨多页

目录打开指定条目；文章页从左页开始，正文依次流向右页和后续书页。一个跨页只属于一个条目，条目结束时不把下一篇文章自动拼到空白右页。

书页箭头在当前条目的跨页范围内翻页，不自动切换到前后条目。首页目录和正文链接用于打开条目，返回按钮始终回百科章节首页，避免更新一篇文章后改变整个百科的全局页码。

显示 `1 / 4` 这样的条目内页码，不承诺稳定的百科总页码。奇数页条目的最后一个空白右页保持空白，不显示重复标题或正文页码。

### 3.3 阅读位置与交互

- 首页手工设计，子条目列表后续由正文资源生成；不要求作者用 Markdown 编写六分类首页。
- 各有效页的页码内侧提供返回图标，始终返回百科章节首页并保留分类及列表位置；内部链接只快速打开目标条目，不维护返回历史。
- 记忆条目 ID 和可见内容锚点，页码仅作为回退，不只记易变化的全局数字页码。
- 语言或资源重载后重新排版；优先恢复原内容块，块不存在时回退原条目有效页，条目不存在时回分类目录。
- 保留手册现有 Esc/E 关闭规则；图片放大层打开时先关闭图片层，不同时退出手册。
- 首版不增加解锁、任务、联网百科或阅读进度奖励。搜索可以后续增加，不作为首版排版框架的前置条件。

## 4. Markdown 规则

### 4.1 首版语法清单

| 内容    | 写法                                                       | 约定                    |
| ----- | -------------------------------------------------------- | --------------------- |
| 条目标题  | `# 仓库管理终端`                                               | 必须且仅有一个，位于文件头后的首个正文块  |
| 小节标题  | `## 使用方式`                                                | 段落层级，不强制另起页           |
| 次级标题  | `### 权限`                                                 | 最深三级；不支持四级及以上标题       |
| 段落    | 普通文字，空行分段                                                | 同段换行会合并，不按源码行数排版      |
| 强调    | `**不可恢复**`                                               | 使用粗体，不用改坐标或字号         |
| 短术语   | 行内反引号                                                    | 术语样式，可自动折行，不承诺代码编辑器功能 |
| 无序列表  | `- 第一项`                                                  | 首版仅一级列表               |
| 有序列表  | `1. 放置终端`                                                | 第一项确定起始号，后续自动连续编号；仅一级 |
| 图片与图注 | `![图注](namespace:textures/handbook/example.png)`         | 独占一块，图注在下方；空图注不占高度    |
| 普通提示  | `> 提示内容`                                                 | 相邻引用行组成一个提示框          |
| 注意或危险 | `> [!NOTE]` / `> [!WARNING]`                             | 首行类型标记不作为正文，后续引用行是内容  |
| 条目链接  | `[库存保护](entry:cargoverse:player_trade_points/warehouse)` | 跳转同一百科内的整篇条目          |
| 强制分页  | `<!-- pagebreak -->`                                     | 独占一行，后续内容转到下一张单页      |

标题标记与文字之间必须有空格。图片必须单独成行，不能嵌入文字段落。列表项之间可用空行，但首版不支持嵌套列表、缩进子段落或多块列表项。

### 4.2 换行与段落

推荐写法：

```markdown
这两行在源码里分开，
在游戏里仍然属于同一个段落。

空行后才是下一段。
```

源码普通换行合并规则：中文等 CJK 字符相邻时不插入空格；拉丁字母或数字相邻且两侧没有空白时插入一个空格；其余情况按标点和原有空白连接。作者不需要按页面宽度手动断行。

首版不支持行末两个空格或 `<br>` 强制换行。希望把“标签”和“说明”分开时，使用不同段落或列表，而不是连续堆空格、制表符模拟对齐。

### 4.3 图片参数

普通插图不需要任何参数：

```markdown
![终端的正面与操作区](cargoverse:textures/handbook/terminal_front.png)
```

确实需要控制图的占用范围时，可以追加：

```markdown
![绑定工具](cargoverse:textures/handbook/linker.png){width=48 max_height=48}
```

- 只有 `width`、`max_height` 两个可选参数，单位为手册逻辑像素，必须是正整数；可以只写一个。
- `width` 是图片盒的最大宽度，不是强制拉伸到该宽度；默认 `130`，不能大于正文宽度。
- `max_height` 是图片盒的最大高度；默认 `96`，不能大于正文区域高度。是否能放下还要计算图注。
- 图片保持宽高比，在盒内等比完整显示，水平居中；高度由最终比例确定，不按盒的最大高度额外留白。
- 默认允许等比放大小图，不裁边、不变形；像素图使用 nearest 采样，避免放大后被模糊。
- 图片尺寸从真实纹理读取，不要求作者填写原图尺寸。
- 一个图片块包含图片和图注，默认不拆页；复杂截图应裁出重点或点击放大，不通过缩小整页文字挤入。
- 图片参数是本框架的扩展，外部 Markdown 编辑器不一定能预览最终尺寸。

### 4.4 提示框

```markdown
> [!WARNING]
> 销毁库存不会返还货物。
> **该操作不可恢复。**
```

- 只支持普通提示、NOTE、WARNING 三种，未知类型报错，不自行猜测。
- 框内支持文字、强调、行内术语和条目链接，不支持图片、标题、嵌套引用和列表。
- 每个框是一个段落；多行引用合并为同一段文字。
- 默认整框换页；超过一整页时允许按行分成多个框，续框重复提示类型并标注“续”，不丢失文字。
- 颜色和边框由统一主题控制，正文不得用 HTML 自定义颜色。

### 4.5 链接、转义和不支持内容

- 条目链接首版不支持页码、标题锚点和外部网站；跨条目用稳定 ID，不使用显示标题猜目标。
- 链接不存在时显示清晰的无效链接样式和提示；禁止点击跳转，并在制作报告列出源文件与行号。
- 支持用反斜线转义 `\\`、`\*`、`\#`、`\[`、`\]`、`\(`、`\)`、`\!`、`\>`、反引号和 `\{`、`\}`，用于字面展示保留符号；行内术语中的内容按字面值处理。
- 图片目标只接受规范的客户端 PNG 资源 ID，不接受磁盘路径、相对路径、`..`、URL 或远程下载。
- 首版不支持表格、斜体、删除线、代码围栏、数学公式、脚注、HTML、SVG、动图、任意嵌套、内嵌脚本、Ponder 指令或多栏浮动布局。
- 唯一具有语义的 HTML 风格写法是独立的 `<!-- pagebreak -->`。其他单行 `<!-- 备注 -->` 可以作为作者注释，不显示、不参与布局；不支持多行或嵌套注释。
- 无法识别的普通行内符号按字面显示；看似标题、列表、图片、文件头等但违反规则的块级结构必须诊断，不能悄悄吞掉正文。

## 5. 对应排版规范

### 5.1 页面尺寸和基础主题

沿用当前 `PlayerShippingProfileLayout`：书本 `361×256`，左页安全区 `(36,20,130,200)`，右页安全区 `(183,20,130,200)`。以下尺寸均是逻辑像素，不是截图里的物理屏幕像素。

初始试排参数，允许后续全局调整，但不由文章单独填写坐标：

| 区域或项目 | 初始值 |
| --- | --- |
| 每页内容宽度 | 130 |
| 页头 | 高 28；条目标题最多两行 |
| 正文 | 页内 y=28，宽 130，高 158，底边 y=186 |
| 页脚 | y=190 开始，高 10；上方 4px 隔离带 |
| 正文字号 | 原版字体 1.0 倍，不自动缩小 |
| 正文行距 | 当前 `Font.lineHeight + 2`，通常为 11px |
| 段落、列表块、图片块之间 | 4px，相邻间隔取最大值，不相加 |
| 小节标题上下间隔 | 上 6px、下 4px；页首不加上间隔 |
| 图与图注间隔 | 3px；图注空时不保留 |
| 提示框 | 内边距 4px，边框计入实际占用尺寸 |

正文、图注、提示文字使用同一基础字号，图注和辅助信息以颜色区分，不默认缩成难以阅读的小字。颜色必须保证与羊皮纸底图的对比度。

页头条目标题使用 1.25 倍字号；小节标题使用 1.0 倍粗体。所有位置由排版器根据字体测量，不按中文字数估算。页头超两行时末尾加省略号并提供完整标题悬停提示，同时给作者长标题警告；正文不使用省略号截断。

标题在所有有效正文页重复，正文中的一级标题不再次占用正文空间。左页页码位于左下角，右页页码位于右下角；各有效页的页码内侧间隔 2px 放置 10×10 返回图标，空白末页不显示。无论点击哪侧图标、是否通过链接打开条目，都返回百科章节首页，不再同时放文字返回或目录按钮。控件命中区不能进入正文，翻页仍沿用书本外侧箭头。

### 5.2 流式排版与分页

基本顺序：测量当前内容块 → 尝试放入当前页 → 必要时整体移到下一页或按规则拆分 → 继续处理后续块。

1. 段落按实际字体和可用行宽折行，不依据源码行宽。
2. 段落允许跨页，条件允许时页尾和续页至少各保留两行；遇到极端尺寸，优先保留所有内容和前进能力，不无限重试分页。
3. 二级、三级标题至少与后面两行正文、一个列表项的起始部分或一个可放下的图文块同页，不把标题孤零零留在页底；连续标题作为标题链一起判断。
4. 列表统一悬挂缩进，续行与条目正文对齐；编号位置由实际最宽编号测量。长列表项可以跨页，序号只在首次出现处绘制，续页明确保持为同一项。
5. 图片和完整图注作为整体，当前页放不下就移至下一页。若在完整正文区域内仍放不下，先在作者声明的上限内缩小图片；仍不能容纳则报告尺寸/图注错误，不裁字或无限生成空页。
6. 提示框优先整体放置；本身超整页时按第 4.4 节的续框规则拆分，边框与内边距每个片段分别计算。
7. 图片不会跨过书脊，也不会自动横跨左右两页；首版不支持跨页大图。
8. 强制分页作用于下一张单页，不是下一次整本翻页：左页之后是右页，右页之后是下一个跨页的左页。
9. 位于正文开头、结尾或连续出现的强制分页合并/忽略，不制造无意义空白页。不支持为版面故意保留空页的指令。
10. 块在新页开始时不保留页首段前间隔；页尾不因段后间隔单独创建下一页。

长词、资源 ID 或长链接文字在必要时允许按字符边界折行，不横向越界；样式和链接命中区随行拆分。按 Unicode 码点/字形边界处理，不截断代理项或把组合字符拆成乱码。

### 5.3 图片放大

正文图片悬停提示“点击放大”；点击打开手册之上的独立查看层，保留当前阅读位置。

- 查看层沿用同一图片资源，居中等比适配屏幕，提供关闭按钮和图注。
- 首版只做适配查看，不要求拖拽、滚轮缩放或外部图片浏览器。
- Esc/E 或关闭按钮先关闭查看层，不穿透到下层手册。鼠标事件也不能穿透到百科链接或其他章节标签。
- 放大不会提高原图分辨率；作者应提供足以辨认重点的图片，而不是只保存130px宽的缩略图。
- 大型操作界面推荐拆成“总体图 + 局部图 + 对应说明”，而不是依赖一张无法阅读的整屏截图。

## 6. 内容制作模板

模板是内容顺序约定，不是要求作者选择固定页数或填定位参数。

### 6.1 机制说明模板

```text
条目标题
一句话说明
基本概念（段落）
示意图 + 图注
使用规则（列表）
注意事项（提示框）
相关条目链接
```

### 6.2 方块或物品模板

```text
条目标题
用途说明
外观图（小物件可设置较小 width）
使用条件
操作步骤
状态与反馈
限制、权限和破坏规则
相关条目链接
```

### 6.3 操作说明模板

```text
条目标题
操作前提
步骤小节
局部图 + 图注
对应文字或编号步骤
下一个步骤小节
必要时手动分页
完成结果与常见问题
```

只有在完成自动排版后仍有明确阅读需求时才插入手动分页，不把手动分页作为默认写作步骤。

可复制示例见同目录的 [百科条目制作模板](02_百科条目制作模板.md)。示例图片与条目 ID 仅演示写法，不表示资源已存在。

## 7. 作者体验与校验

### 7.1 最小工作流程

1. 复制模板到对应语言与分类目录，文件名确定稳定 ID。
2. 修改标题和正文，删除不需要的小节；可选填写顺序和目录图标。
3. 放入 PNG 并修改正文资源 ID；默认不填尺寸。
4. 资源重载，打开第五章节，自动看到分类和新条目。
5. 查看制作诊断，必要时只调整图片尺寸、段落组织或手动分页。

### 7.2 必需的制作工具

- 资源重载重建内容和排版，不要求重新编译模组或重启存档。
- 开发辅助显示可开关：页头/正文/页脚安全边界、块边界、条目 ID、块来源行号、当前页码。
- 诊断包含资源 ID、源行号、错误原因；同一轮资源加载汇总一次，不逐帧刷日志。
- 缺失或无法解码的图片显示具有尺寸的占位图与提示，正文仍能阅读。
- 语法错误导致不能可靠解析的条目显示错误页；其他有效条目继续可用，不使整个手册崩溃。
- 缺失链接仅禁用该链接。未知分类或条目缺失一级标题属于条目错误。
- 除阻止阅读的错误外，提供长标题、长图注、过多强制分页等作者警告，不据此悄悄更改内容含义。

### 7.3 安全与性能边界

- 只访问客户端资源管理器，不读取正文指定的磁盘文件、不联网、不执行内容中的代码。
- 先解析为带源位置的不可变内容块，再测量/分页，最终生成不可变布局与命中区；不要在每帧重新解析、换行和分页。
- 缓存键包含条目内容版本、语言/字体版本与版式版本；资源重载、语言或字体改变时失效。手册的屏幕位置变化不需要重新排版。
- 对单文件大小、条目数量、块数量和最终页数设置明确上限；具体预算在实现前用代表性内容确认。越界显示诊断，不静默截掉后半篇文章。
- 单个条目的排版必须保证取得进展：超高不可拆块明确报错，不因分页重试陷入循环。
- 目录可以即时建立，正文布局按阅读需要计算；避免首次加载就解码所有未阅读文章的大图。
- 图像资源尺寸测量和纹理解码结果复用，查看层与正文不重复维护独立大纹理副本。
- 教程展示只读，不接入玩家库存、交易执行、载具物理或导航目标写入。

## 8. 实现结构与验收

当前职责分层：资源发现与语言回退 → Markdown 解析与校验 → 内容模型 → 字体/图片测量 → 分页布局 → 绘制与交互。

第五章节只接入条目目录和布局结果；继续复用手册翻页动画、章节标签、关闭行为。旧 `PageCanvas` 是底层绘制入口，不要求现有其他章节改为 Markdown。

首版需覆盖的验证：

- 全部支持语法、转义、无效文件头、无效资源 ID、错误图片参数、缺失图片和链接。
- 中文、英文、混排、粗体测量、长数字/ID、不同字体资源和语言回退。
- 空文章、单段多页、页底标题、连续标题、多行列表项、超长提示框、图片与多行图注。
- 奇数正文页、连续/首尾分页、无法放入整页的块、不生成无限空白页。
- 图片点击命中区、跨行链接命中区、关闭不穿透、多次链接跳转后仍返回首页、资源重载后阅读恢复。
- 标准界面和小窗口下的清晰度及正文边界；不同 GUI 缩放不改变逻辑布局。

验收标准：用模板制作三篇不同类型的真实条目，不增加页面专用 Java，不填写 x/y，不逐篇修改排版器；正文无静默裁切，普通图片默认即可使用，例外可以通过已定义的少量参数处理。

## 9. 首版制作约定

1. 使用受限 Markdown，只有两项可选文件头，不引入通用 YAML/HTML。
2. 以条目为单位组织，多页自动流动，每篇从左页开始；目录自动生成。
3. 正文默认 1.0 倍字号，上下图文顺排，不做复杂分栏与绕图。
4. 图片完整等比显示、图注跟随、点击放大；只开放宽度与最大高度参数。
5. 默认自动分页，仅允许简单强制分页指令，不提供绝对定位。
6. 首版包含诊断和资源重载；Ponder、搜索、跨页图、表格与其他复杂内容后续独立扩展。

以上约定已在首版框架落地。页头、行距和图片上限由统一排版器管理，普通条目不另增定位参数，也不通过大量手工分页锁死正文。后续首先补充玩家真正需要的说明与截图，不扩展复杂跳转、网页式布局或技术文档功能。
