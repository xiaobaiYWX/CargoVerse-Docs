# 装卸终端显示与交互调整

更新：2026-11-03。本页仅保留待落地的通用装卸显示调整。通用生物装卸和PDA摘要已接入，见[生物运输](../01货柜系统/01核心系统/17_生物运输.md)；新仪表布局和客户端视觉仍待调整。

## 通用交互

固体、液体和生物继续共用现有装卸终端、仓库管理终端、确认GUI、实体按钮与PDA详情入口，不增加专用生物装卸终端或专用GUI。后续仪表布局与素材按用户新设计调整。

仓库管理终端和普通装卸终端均按物种显示一栏。玩家选择物种与只数，服务端按自动选择规则在提交前选定并重新核验实际个体；毛色、幼崽、生命值和归属不拆库存。识别缓存不能直接作为捕获依据，公开贸易与管理操作仍分别检查权限。

卸载按装入顺序的反序，不能选择任意个体，不能绕过无法释放的栈顶个体。确认与实际结果都按只数mob、舱位、质量和实际成功数量表达；未知字段显示“---”。

货柜详情沿用现有布局，物种图标通用，在主卡片显示最低生命的爱心数、物种x数量和舱位，不将生命及舱位放入运输条件仪表区，不同步逐只明细或全柜原生NBT。其他信息保留通用运输条件、核心数值、设备状态和权限。

## 事务与同步边界

共用状态、计量与生物载荷摘要分层维护。现行识别规则见[生物打包机](../11玩家贸易点/07_生物打包机.md)；服务端提交时重验实体、区域、网络、容量和权限。关闭界面取消未提交动作；已完成移交不因关闭而恢复或复制。实体载荷已有唯一归属和待释放恢复记录，独立于物品数量扣减。
