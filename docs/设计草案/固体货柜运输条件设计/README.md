# 固体货柜：按运输条件分工

> **待实现设计 · 2026-10-23。** 采用已落地的 solid／liquid／gas／living 四大类。本轮只设计固体货柜；不修改代码、物品属性、货柜 JSON、结构模板或配方。

颗粒、粉末、食物、工具都是 solid。形态只决定基本管线；货柜差异通过围护、密闭、缓冲、防潮、防火和有限保鲜体现。物品运输条件可叠加，不恢复用途 CargoClass，不增加品牌专属物品名单。

“易损易腐食物”“耐储存食物”“易燃易爆品”是设计用描述，不新增共享条件集或分类加载器。实现时仍逐物品直接声明条件，货柜声明对应保护；同样的条件在不同制造商之间具有相同语义。

共同机制以[数值驱动的运输要求、货柜能力与货损设计](../通用运输词条扩展讨论.md)为准；本目录仅维护固体应用，温度范围、能力缺陷、行为复用与时钟不再独立规定。

## 三个代表决策

- 蛋糕：solid，可进普通固体柜；易损、需要保持方向、易腐，普通柜承受冲击／倾斜风险和较短保鲜期。专用保鲜柜保护并延长时限。
- 马铃薯、胡萝卜、甜菜：solid，首版设为耐储存，无运输腐败时限；Harvest 等普通周转柜足够，不强迫购买冷链。
- 火药：solid，可装普通固体柜；同时有细料散失、防潮和易燃需求。Silo 解决前两项，Apollo 才同时覆盖易燃保护。不存在“危险品形态”。

只有形态、内容准入、容量等既有基础条件导致拒装；缺少运输保护仍是风险提示和实际损耗。“粉末运输柜”表示能力定位，不是只接粉末的隐藏准入。
