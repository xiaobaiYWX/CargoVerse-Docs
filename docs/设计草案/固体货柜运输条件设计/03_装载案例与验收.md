## 计划实施范围

1. 先完成固定数值维度、观测与扣量模型；新增货物填数值，显示词条不注册行为。
2. 将围护、防潮、冲击和方向作为代表维度迁移；再接入统一温度范围与保存期。
3. Eden、CryoVault 的目标能力与实际温度、保存效果一起确认；专用模板及制造入口另行验收。
4. 旧资产、旧快照和当前 JSON 继续使用现有规则，不能由文档更新自动改变行为。
5. 液体共用同一规则；气体、生物的实际承载仍留给专项，不由共用词条自动开放。

## 必验收行为

- 石材、粗颗粒、粉末、工具、食品均为 solid，不恢复 bulk/powder 准入分支。
- 无额外需求的石材不会因“制冷能力不足”“易进水”缺陷获得新货损。
- 围护基础 2、缺陷降低 1，最终明确为 1；粗料可被覆盖，细粉仍有风险。
- 新增碎石或矿渣只填围护需求；围护 2 的固体柜自然覆盖围护 1。更换描述名称不影响结果，也不增加执行次数。
- 围护不足与运动／倾斜共同触发散失；安全间歇暂停，不能通过反复短暂停船清零累计。
- Silo 的围护、防潮不能自动覆盖热风险；Apollo 的热保护需要明确适用条件，不表示世界爆炸免疫。
- 火药受潮与散失属于独立风险；同一散失行为两个显示名不能重复扣量。
- 冷藏＋防冻结得到非空温度范围时可同时满足；空交集在数据加载阶段报错。
- 食品温度达标不等于无限保鲜；保鲜效果不在温度条件失效后仍无条件生效。
- 耐储存农产品可不设时限，不按“食品”标签批量强迫冷藏。
- 固体按个、液体按 mB 扣量，均不超过剩余数量；零质量不免除数量损耗。
- 追加、部分卸货、转移、卸载区块和重启都按共同时间与快照规则验证，不维护固体专用例外。
- 系列 ID、模板、接口、容量及空重不因本轮设计更新而改变。
