# 从货物状态出发的运输数值设计

> **待实现草案 · 2026-10-24。** 本稿从货物为何散失、损坏或变质出发确定最小模型，不以保留或迁移现有词条为目标。未修改代码、数据包、货柜模板和运行中载荷。旧词条引擎在重构完成后删除，不长期双轨运行；旧数据保留原始记录隔离，具体边界见[实施契约](观测校准与生命周期契约.md)。

## 一、设计目标与边界

货物在运输中发生的结果可以归为三种：数量散失、状态损坏、随时间劣化。模型先回答造成这些结果的因素，再决定货柜如何改变货物所处条件。不能因为旧系统存在某个名称，就为它保留一个核心参数。

采用四层关系：

**外部环境／运动 → 货柜改变暴露条件 → 货物耐受与状态变化 → 数量损耗。**

词条只是对此结果的描述，不注册独立行为 ID，不参与保护判断。新增碎石、矿渣、食品或试剂，填写已有因素对应的物性即可。不能用数值模型尚未覆盖的名字，暗示已经获得新的物理效果。

本轮以固体和已落地的液体为应用对象，模型不按形态隔离。气体、生物仍须单独解决实际承载接口；不为它们提前构建完整生态、气体反应或压力容器仿真。

## 二、先确定六类影响因素

时间表示暴露持续多久，不单列为一种防护能力。

| 影响因素 | 观测／货物特性 | 可能发生什么 | 货柜能改变什么 |
| --- | --- | --- | --- |
| 机械作用 | 冲击、运动、倾斜；货物的冲击耐受和散落倾向 | 破损、洒落、细料逸散 | 缓冲传递、围护 |
| 温度 | 外部热状态、实际内部温度；安全区间及温度相关老化速度 | 冻结损伤、过热失稳、变质 | 热交换速度、主动调温 |
| 气压 | 航空学外部气压、内部气压；货物安全气压范围 | 低压／高压损伤、保压失效 | 密封与承压能力 |
| 外部液态水接触 | 降雨、浸水；货物水分敏感程度 | 受潮、溶损 | 阻止液态水侵入 |
| 光照 | 实际光照暴露；光敏程度 | 光照引起的劣化 | 遮光 |
| 物质向外散失 | 颗粒尺度、渗流／挥发倾向，必要时结合运动 | 掉落、渗漏、挥发／升华 | 围护、密封 |

机械与向外散失可以共用运动输入，不能给同一次掉落重复扣两次货。光照可以影响环境热输入，但光敏劣化与升温是不同因果；只有明确具备相应敏感性的货物才响应。

首版水分只处理可观测的液态水接触，不虚构空气湿度、露点或柜内凝露系统。压力只表示压力，不代表氧含量或可呼吸性。

腐蚀、辐射、微生物污染、化学反应暂不进入最小核心。它们确实可能影响货物或周围环境，但需要具体来源、作用对象和接触机制，不能塞进一个万能“危险程度”。后续有明确玩法时再扩展，也不按旧词条数量逐项补齐。重构切换后不为这些旧特殊行为保留第二套引擎；本轮只修改文档，当前运行功能尚未变动。

## 三、七项候选货柜能力

从上述因素推导，首版建议保留以下 **7 项能力**。这是实际能力数量，不用分组掩盖额外的保护字段。

| 能力 | 影响的条件 | 明确不承担的职责 |
| --- | --- | --- |
| 围护 | 限制颗粒／物体向外掉落与逸散；改善倾斜时的留存 | 不代表液密、气密、减震或品牌准入 |
| 密封 | 阻止液体／挥发成分交换、外部水侵入；控制压力交换 | 不代表能承受任意压差、耐腐蚀或调节气压 |
| 缓冲 | 降低外部冲击传递到货物的强度 | 不把匀速飞行当碰撞，不代替密封 |
| 隔热 | 减慢内外热交换 | 不主动产冷／产热，不提供无限保鲜 |
| 调温 | 向设定目标调节内部温度；等级决定可提供的调节强度 | 不独立提供“保鲜倍率”，不保证任何环境下都能达标 |
| 遮光 | 降低内部光照暴露 | 不自动隔热、防辐射或耐蚀 |
| 承压 | 保持封闭结构时可承受的内外压差 | 不等于气密，不自动给货物充气或增压 |

具体字段与逐级换算统一维护在[运输数值字段与能力等级](运输数值字段与能力等级.md)：围护、密封采用 0～2，其余五项候选采用 0～3；换算值属于首轮调试建议，仍待实测。高等级表示该项能力更强；不同能力不能简单相加为“总防护分”。货物的温度、压力范围及物理采样保留必要精度。

调温还需要**工作方向和目标温度设置**：关闭／制冷／加热／双向可调，目标受设备支持范围限制。这些是工作设置，不是新增货物保护等级。界面应说明“具备调温能力”与“当前正在制冷”的区别。若先只做制冷柜，其他模式可以留空，不为凑齐功能而实现。

不再独立设置保鲜等级、防冻结等级、防潮等级、坚固等级、固定等级和通用危险屏蔽等级。需要时分别由实际温度、密封、缓冲、围护与承压体现。不能声称一个缓冲等级已经真实模拟所有机械现象；暂不支持的特殊定向安装或结构破坏玩法明确留待后续。

缺陷优先由最终数值表达，例：“密封薄弱：1”“缓冲不足：0”。没有能力不自动是缺陷；普通干货柜无调温只是没有该功能。显示名称与正负文案不参加计算。

## 四、围护和密封：数值包含关系取代名单

| 等级 | 围护 | 密封 |
| --- | --- | --- |
| 0 | 基础承载，不保证留住散料 | 无专项交换隔离 |
| 1 | 留存粗颗粒 | 液密，同时隔离外部液态水 |
| 2 | 留存细料 | 气密，同时覆盖液密 |

这是游戏简化，不是现实工业认证。防尘不自动气密；若某类模型确实兼具两种能力，分别配置两项。形态、容量和内容安全仍是基本承载边界，等级不能让固体接口装入流体。

| 货物示例 | 需求／物性示例 | 在何时产生风险 |
| --- | --- | --- |
| 完整石块 | 无额外散失需求 | 不因缺少冷藏或气密就损坏 |
| 碎石、矿渣 | 围护 1 | 围护不足且运动／倾斜时散落 |
| 细粉 | 围护 2；需干燥者另有水分敏感性 | 围护不足时逸散，实测进水时受潮 |
| 普通水 | 密封 1，压力／温度敏感性单独设计 | 合规基础液体柜足以防渗漏 |
| 某种粘稠液体 | 密封需求及散失速率按具体物性填写 | 不仅凭“粘稠”自动推导无挥发性 |
| 挥发性液体／易升华固体 | 密封 2及明确的散失速率 | 密封不足时发生数量散失 |

需求不足时用统一缺口比较，不能给“碎石”与“粉末”创建两个互斥装载许可。等级不足代表风险，不自动成为新的拒装条件；基础设备无法合法承载的情况仍应拒绝。

密封不足的向外散失与外部进水使用不同的实际观测，却共用密封能力。只有水分敏感而无挥发倾向的货物，不能在晴天因低密封一直扣货。

## 五、温度与保鲜合为一条因果链

### 5.1 温度如何变化

货物只有一个实际内部热状态 T：

- 普通柜：T 随外部热状态变化。
- 隔热柜：变化更慢，但长期仍趋向外部条件；隔热不是永久维持初始温度。
- 制冷／调温柜：根据目标和可用调温能力改变 T，同时受到热交换影响；能力不足时不能瞬间达到目标。
- 工作关闭时仍保留当前 T，按隔热能力逐步恢复环境平衡。

温度求值只需一个有界、与经过 tick 一致的近似更新，不要求真实热力学求解。单位与环境映射另行校准，在未验证前不把抽象数值标成摄氏度。

首次装载没有可靠温度来源时按实际环境初始化，不默认所有新货已经处于最佳冷藏状态。保存并连续推进 T，追加、停用制冷、重启不能凭空重置到理想温度；具体事务处理遵循[生命周期契约](观测校准与生命周期契约.md)：追加继承当前状态，卸载／停机暂停。

### 5.2 货物怎样响应

货物仅按需要配置：

- 安全温度范围，用于过冷／过热的损伤。
- 在安全区间内的温度—老化速率关系，以及基础耐储存预算，用于随时间变质。

**货柜不再配置保鲜能力或独立保鲜倍率。** 制冷改变 T，T 决定老化速度；更强制冷只有确实改善货物温度时才改善保存效果。老化曲线可用少量温区分段，属于货物物性，不注册“食品”“试剂”的新行为词条。

示例仅说明逻辑：

- 常温且在安全区间：老化速率取 1。
- 合适冷藏区：老化速率可取 1/4。
- 高于适宜保存区但尚未触及损伤上限：老化可加快。
- 低于安全下限：发生冻结损伤，不能继续按“更冷更保鲜”奖励。

耐储存货物可以不声明老化预算。没有制冷不自动意味着损耗；货物本身有易腐性才累计老化。冷藏不会恢复已失去的寿命或已扣数量。

预算与货损仅在运输生命周期内生效，不将所有原版背包物品变成腐败物品。原先的蛋糕 20／80 分钟、生鲜 40／160 分钟不再作为目标参数保留；先确定运输时长、温区和货物物性，再重新平衡。

### 5.3 避免两个状态重复处罚

在安全温区内，按老化速率累计等效时间；越过直接损伤边界时，温度这一因素进入损伤分支，该时间段不再另算一份相同原因的“加速腐败货损”。其他独立因素仍可并行。

是否需要持续自反应、燃烧后自行维持等复杂状态，不从旧词条照搬。首版热损伤恢复到安全环境后停止新增暴露，已累计损伤与老化不逆转。真实爆炸、永久燃烧、化学转化不因显示名称被自动实现。

## 六、以航空学气压判断，不使用坐标限高

### 6.1 已核实的数据来源

工程中的[载具仪表采样](<../../../../CargoVerse-NeoForge-1.21.1/src/main/java/cn/or15/cargoverse/blockentity/VehicleInstrumentBlockEntity.java>)已经调用：

`DimensionPhysicsData.getAirPressure(level, worldPosition)`

类型来自 `dev.ryanhcode.sable.physics.config.dimension_physics`，属于当前航空学相关依赖所用的物理环境体系。现有仪表将有效返回值乘 100 显示为相对百分比；它不是已确认的帕斯卡／kPa。该核对只确认可复用的采样入口，不表示货物压力机制已实现。

货柜按自身实际世界位置采样；在移动载具上先转换坐标，不能使用子空间本地 Y 或玩家位置。使用服务端有效原始系数计算，显示时才转换／舍入。读取失败、非有限值或负值表示未知，不按零压处罚，也不退回自制的坐标限高规则。真实零值则不能当作缺失。

**相同气压应得到相同的压力风险判断，即使坐标高度不同。** 航空学内部如何通过维度环境与位置计算气压，由其负责；本模组不另写一份高度—压力映射。相同高度在不同物理环境中也可以产生不同结果。

### 6.2 压力如何到达货物

货物只需按需要声明安全气压范围 `[Pmin, Pmax]`。比较对象是内部气压 Pin，外部采样为 Pout。

首版最小方案：

1. 未达到气密等级：Pin 随 Pout；液密不等于保压。
2. 达到气密等级：封闭时保存当前内部气压，在有效保压期间保留它。
3. 当 `abs(Pin - Pout)` 超过货柜承压能力的全局换算上限：进入保压失效状态，Pin 按共同释放过程向 Pout 靠近；货物按实际 Pin 判断损伤。不是“外界低压立刻无视密封扣货”。
4. 保压恢复与释放完成采用明确的状态边界，不在阈值附近每个采样点反复开关。若此过程首版成本过高，可暂时只做随环境压力的开放运输，再单独开放保压柜，不能让气密等级默认获得无限保压。
5. 在低压地点直接装货并封闭，初始 Pin 就是当地压力；不自动得到标准压力。重新封闭不能刷新一个虚构的安全气压。

**气密决定能否隔离压力交换，承压决定能否承受压差。** 因而承压是精简后仍需独立保留的核心能力；与围护等级或制冷等级不能互相替代。

本轮不引入压缩机、恒压能源、容器爆裂、气体温压耦合或物态变化。冻结／沸腾等文案若需要真实相变产物，另行设计；当前只表达货损。密封液体柜如何表达压力按游戏模型统一处理，不声称实现液体真实体积弹性。

## 七、少量通用计算，不为每个表现维护状态

静态数据分三类：

| 对象 | 数据内容 |
| --- | --- |
| 货物 | 散失需求与速率、机械耐受、温度与气压范围、水分／光照敏感性、可选老化预算及温区速率 |
| 货柜 | 七项最终能力；必要的调温工作设置 |
| 共用规则 | 等级换算、环境采样、暴露条件与结算周期，不由制造商各自定义另一套尺度 |

动态状态仅在实际需要时保存：内部 T、需要保压时的 Pin／释放状态、老化累计，以及固定影响因素的暴露余数。没有老化声明的石材不维护一个无用保鲜倒计时。

运行只有几种计算：

- 等级缺口与条件暴露：围护、密封不足。
- 实际状态与容许范围比较：温度、压力。
- 衰减后的暴露与耐受比较：冲击、光照、水接触。
- 有效时间累积：不利暴露、温度相关老化。

同一数据因素只有一个最终配置和一份结算状态。换名字、同时显示两个说明不增加计算次数；不存在按“怕冷”“易碎”等 ID 求交集的调度器。

同一机械散落过程只扣一次；同一时段温度损伤与同源腐败择定一条结算路径。不同因素产生的货损可以并行，汇总后封顶为实际剩余数量。固体扣整数个，液体扣整数 mB，保留计时和老化余数；不另建抽象完整度百分比。

范围倒置、能力越界、损耗非整数等属于数据错误；货柜能力不足属于可解释的运输风险。缺省货物没有额外敏感性，缺省安全范围是不约束，不是零度／零压。

停止运行或没有可用环境样本时不编造离线暴露。保存连续状态以防重启洗掉累计；追加、部分卸货、区块加载与重新打包遵循[已确定的生命周期与冻结边界](观测校准与生命周期契约.md)：追加不刷新，卸载／停机暂停，原生卸出不携带运输寿命；能力在首笔成功装载时冻结。

## 八、词条内容与显示

具体名称、生成条件、正负用语、运输状态与示例统一维护在[运输词条目录与展示规则](运输词条目录与展示规则.md)，本页只维护底层数值。

词条分为货物特性、货柜设计、运输状态三处显示。货物特性来源于固有物性，装入合适货柜后仍存在；当前风险由实际能力与环境求值。只调整文本不能增加行为、修改数值或叠加计时。

调温等级表示能力，工作目标表示设置，实际内部温度表示状态。气压风险使用实际内部气压。正向设计、缺陷与临时环境风险不混用同一个无上下文名称。

## 九、设计核对案例

- 围护 2 的固体柜覆盖围护 1 的碎石；新矿渣无须增加任何行为 ID。
- 基础液密柜可运普通水，不因默认加入挥发而被迫购买专业柜。
- 同一柜中不同货物的老化不同，只由各自物性与实际 T 决定，不由制造商加成决定。
- 相同实际 T 的两柜，对同货物具有相同老化速度；不能再叠加独立保鲜倍率。
- 制冷越过货物安全下限会受损；隔热高但未制冷，不会凭空得到冷藏效果。
- 气密但承压不足的柜不能长期维持任意内部压力；承压强但漏气同样不保压。
- 相同航空学气压、相同内部状态下，不因绝对 Y 不同改变压力损伤；移动载具坐标正确。
- 在低压处封闭不会自动恢复标准压力；气压采样失败不伪装成真空。
- 稳定匀速不触发冲击货损；开放散料仍可因运动条件发生散失，两者不混淆。
- 单改描述名称不改变结果；无敏感性的货物不因缺少某种防护凭空受损。
- 数量归零后停止结算，不生成负数或重复扣量；重启不重置内部状态与累计时间。

## 十、下一步需要确认的数值

七项能力的候选字段与等级已经整理在[字段和等级表](运输数值字段与能力等级.md)。下一步以代表货物和航程验证下列参数；不按旧词条参数照搬。

1. 各等级的明确能力与换算，包括围护／密封层级和承压系数上限。
2. 按[观测校准契约](观测校准与生命周期契约.md)验证 TU／J 输入、候选算法和真实分布；校准前不批量配置正式货物。
3. 基于代表运输时长的温区老化曲线、预算及货损速率。
4. 实际航空学气压分布、货物容许区间与保压失效过程。
5. 冲击、运动、倾斜和液态水暴露的采样语义，避免重复处罚。
6. 实现并验收已经确定的追加、暂停、原生卸出及装载冻结契约。

本轮不重排货柜容量、空重、系列或制造配方。固体系列表只保留产品用途参考，待核心数值确定后再赋值。旧数据迁移另起实施步骤，不能反过来决定本稿需要多少个参数。
