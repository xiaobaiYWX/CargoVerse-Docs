# 运输数值字段与能力等级

> **详细设计草案 · 2026-10-24。** 承接[状态模型](通用运输词条扩展讨论.md)与[词条目录](运输词条目录与展示规则.md)。本页提出字段名称、类型、单位与首轮调试等级表。具体倍率、时间和阈值为候选平衡值，未写入代码或数据包，不代表游戏实测结论。

## 一、名称和归属

| 对象 | 建议分组 | 含义 |
| --- | --- | --- |
| 货物 | `transport` | 运输要求与耐受，直接写入逐物品／逐流体定义 |
| 货柜 | `transport_capabilities` | 七项最终能力等级 |
| 工作配置 | `thermal_control` | 调温方向、模式和目标，不是第八种能力 |
| 动态状态 | `transport_state` | 系统保存的内部温度、压力和累计状态，内容作者不填 |
| 说明 | `presentation` | 可选标题和设定文本，不参与计算 |

使用 snake_case。货物最低要求叫 required_level，货柜能力叫 *_level，安全界限叫 min／max，内部状态叫 internal_*。不用旧词条字母作为字段，不使用含糊的“总防护分”。

货物身份、形态、质量、容量、价格不在本轮重新命名。下列字段已有独立类型、严格解析，并在第二轮接入物品／流体 schema 2 的 transport 及柜型 transport_capabilities；候选数值示例不是正式平衡，不可批量替换内置数据。现行格式见[运输数值运行时](../../01货柜系统/01核心系统/14_运输数值运行时.md)，代码与验证边界见[实施方案](重构实施方案.md)。

## 二、类型、单位和缺省值

| 类型 | 单位与约束 | 编写／显示 |
| --- | --- | --- |
| 等级 | 非负整数，范围见对应能力表 | 各维独立，不相加成总等级 |
| 温度 | 有限数，抽象热度 TU | 内容尽量整数或一位小数；不是摄氏度 |
| 气压 | 有限非负相对系数 | 数据 0.8 显示 80%，允许超过 1，不截断为 100% |
| 压差 | 同一相对系数单位 | 0.2 指参考压力的 20%，不是当前压力的 20% |
| 冲击 | 有限正数，统一冲击指标 J | 可一位小数；物理转换校准前不标 m/s 或 g |
| 亮度 | 0～15 整数 | 内外亮度统一尺度 |
| 时间 | tick 整数 | 20 tick＝1 游戏秒；周期严格正数 |
| 货损 | 正整数，载荷原生数量 | 固体为个、液体为 mB，不用小数个 |
| 老化速率 | 有限正数，等效 tick／游戏 tick | 建议先用 0.2、0.5、1、2；不采用永久不老化的 0 |

编写精度不等于运行精度：内部温度、压力、衰减结果、计时余数保持足够精度，不能每次采样都舍入为一位小数。UI 舍入不参与判断。

可选约束缺失表示“不约束”，不是零度、零压或零耐受。省略无敏感性的整个分组。未知字段、越界等级、非有限值、负时间、残缺分组、倒置范围、非整数扣量必须报错。禁用损耗通过省略对应分组，不用零扣量生成假词条。

## 三、货物字段表

所有路径相对于 `transport`。同一维只声明一份数值，不通过多个显示词条追加规则。

| 中文名 | 推荐字段 | 数据类型与含义 | 对应显示 |
| --- | --- | --- | --- |
| 最低围护 | `containment.required_level` | 整数 1～2；无需求则省略 | 易散失 |
| 最低密封 | `sealing.required_level` | 整数 1～2，专门描述向外交换／散失 | 需液密／需气密 |
| 冲击耐受 | `impact.tolerance` | 正数 J，有效冲击超过此值才受损 | 易碎 |
| 水接触敏感 | `water_exposure` | 可选分组，存在即声明实际进水会伤害货物 | 怕水 |
| 亮度上限 | `light_exposure.max` | 整数 0～14；15 等价无约束，应省略 | 光敏 |
| 安全温度下限 | `temperature.min` | 可选有限 TU；min／max 至少存在一项 | 低温敏感 |
| 安全温度上限 | `temperature.max` | 可选有限 TU；两项都存在时 min≤max | 高温敏感 |
| 安全气压下限 | `pressure.min` | 可选非负系数；min／max 至少存在一项 | 低压敏感 |
| 安全气压上限 | `pressure.max` | 可选非负系数；两项都存在时 min≤max | 高压敏感 |
| 耐储存预算 | `aging.budget_ticks` | 正整数等效 tick | 易变质 |
| 温区老化速率 | `aging.temperature_rates` | 温度断点及对应正速率 | 曲线推导宜冷藏建议 |

water_exposure 无需另写 true，也不新增防潮等级：有效密封≥1且屏障未失效时隔离外部液态水；无实测水接触就不触发。空气湿度、凝露、蒸汽不属于首版字段。

温度与气压范围为闭区间，等于边界视为安全。冲击与亮度也只在严格超过上限时触发；不靠显示舍入判定。所有数值不因货物显示名或制造商改变含义。

### 3.1 共用损耗字段

围护、密封、水、光照、温度、气压各自附一份 `loss`：

| 字段 | 含义 |
| --- | --- |
| `grace_ticks` | 允许累计的不利暴露预算，非负整数 |
| `interval_ticks` | 预算用尽后每多少个不利暴露 tick 扣一次，正整数 |
| `amount` | 每次扣除的原生整数数量，正整数 |

累计达到 grace＋interval 首次扣货，之后每满 interval 扣一次。安全时暂停，不清零余数。等级不足 2 不自动双倍扣货，首版只比较是否不足，速度来自此处参数。

impact 使用 `damage_amount`，每次确认的独立冲击事件扣量；持续接触或同一次撞击的重复采样不能反复算事件。事件划分由共用采样规则确定。

aging 使用 `loss.interval_ticks／amount`，周期按等效老化 tick；不另设 grace，budget 就是保存预算。越过温度损伤边界时，不另叠加同源老化损耗。各原因的扣量汇总后封顶到剩余数量。

### 3.2 老化曲线

统一采用分段常数结构，例如：

```json
{
  "breakpoints": [20, 40],
  "rates": [0.2, 0.5, 1]
}
```

T＜20 时 0.2，20≤T＜40 时 0.5，T≥40 时 1。断点严格升序，rates 长度＝断点数＋1，首尾区段自然延伸。空断点与一个速率表示恒定老化。

曲线只在货物安全温区内生效；若安全下限 10，则 T＜10 进入低温损伤，不能获得低温奖励。此处只展示结构，不确定食品经济参数。

## 四、七项能力的正式候选名称

这些字段都在 `transport_capabilities` 下。内置内容建议显式填写七项；扩展定义缺省可按 0，但校核工具应提示未填能力。

| 中文名 | 推荐字段 | 级别 |
| --- | --- | --- |
| 围护等级 | `containment_level` | 0～2 |
| 密封等级 | `sealing_level` | 0～2 |
| 缓冲等级 | `cushioning_level` | 0～3 |
| 隔热等级 | `insulation_level` | 0～3 |
| 调温等级 | `thermal_control_level` | 0～3 |
| 遮光等级 | `light_blocking_level` | 0～3 |
| 承压等级 | `pressure_resistance_level` | 0～3 |

换算表只维护一份。制造商不能给自己的等级 2 另设更强倍率；可以通过不同能力组合、容量、空重和获取方式竞争。

### 4.1 围护

| 等级 | 候选名称 | 覆盖需求 | 结构方向 |
| --- | --- | --- | --- |
| 0 | 开放承载 | 无额外围护 | 平台、框架 |
| 1 | 粗料围护 | 围护 1 | 挡边、粗料围板 |
| 2 | 精细围护 | 围护 1、2 | 连续内衬、细料封口 |

等级 0 不让完整石材自动散失。围护 2 自然覆盖碎石与粉末；形态和安全准入独立。首版不增设没有内容支撑的围护 3。

### 4.2 密封

| 等级 | 候选名称 | 实际效果 |
| --- | --- | --- |
| 0 | 未密封 | 不提供交换隔离，内部压力随环境 |
| 1 | 液密封装 | 覆盖密封 1，隔离外部液态水；不保压 |
| 2 | 气密封存 | 覆盖密封 1、2，具备压力隔离前提；仍需承压 |

基础液体承载腔至少为 1；气密不自动开放气体载荷，也不代表耐腐蚀。精细围护不自动获得密封等级。

压力释放时应区分静态等级和有效屏障：若封闭腔暂时开放，不能继续享受气密保护，且实测水接触时不能宣称完全隔水。此为统一释放状态，不永久修改柜体等级。

### 4.3 缓冲

| 等级 | 候选名称 | 冲击传递比例 | 削减幅度 |
| --- | --- | ---: | ---: |
| 0 | 无专项缓冲 | 1 | 0% |
| 1 | 基础缓冲 | 0.7 | 30% |
| 2 | 增强缓冲 | 0.4 | 60% |
| 3 | 精密缓冲 | 0.2 | 80% |

`J_effective = J_external × transmission_ratio`，严格超过 tolerance 时触发事件损伤。

例：外部 J＝10，货物 tolerance＝3，等级 0～3 的有效冲击为 10、7、4、2，仅等级 3 覆盖此事件。外部升至 20，等级 3 仍有风险，不提供无限保护。

J 的单位归一、候选计算与事件分割遵循[观测校准契约](观测校准与生命周期契约.md)，必须实机校准。本表确定的是相对防护差距，不是已知碰撞速度。

### 4.4 隔热

| 等级 | 候选名称 | 热交换时间常数 τ | tick |
| --- | --- | ---: | ---: |
| 0 | 常规壳体 | 60 秒 | 1200 |
| 1 | 隔热内衬 | 120 秒 | 2400 |
| 2 | 加强隔热 | 240 秒 | 4800 |
| 3 | 高效隔热 | 480 秒 | 9600 |

恒定环境、关闭调温时：

`T_next = T_out + (T_current - T_out) × exp(-elapsed_seconds / τ)`

经过一个 τ，内外温差缩小约 63%，不是完全达到外部温度。等级 0 也不瞬间跳到环境。等级越高热交换越慢，同时也可能延缓需要的自然散热；不等于自动冷藏。

例：内部 20 TU，外部 60 TU，60 秒后，等级 0 约为 45.3 TU，等级 3 约为 24.7 TU。这是候选模型计算，不是实机结果。

### 4.5 调温

| 等级 | 候选名称 | 最大主动调节速度 | 理想无热交换时调整 20 TU |
| --- | --- | ---: | ---: |
| 0 | 无主动调温 | 0 TU/秒 | 不主动调节 |
| 1 | 基础调温 | 0.1 TU/秒 | 200 秒 |
| 2 | 增强调温 | 0.3 TU/秒 | 约 66.7 秒 |
| 3 | 高效调温 | 0.6 TU/秒 | 约 33.3 秒 |

更高等级提升能力，不强制目标更冷。表中时间仅为理想参考，不可直接显示为到达倒计时。

`thermal_control` 建议字段：

| 字段 | 意义 |
| --- | --- |
| `supported_modes` | 制造定义数组：cooling、heating、automatic 的有效子集 |
| `target_min／target_max` | 允许设置的目标范围，不承诺所有环境中均可维持 |
| `default_mode／default_target` | 制造后初始设置，默认建议 off |
| `mode／target` | 运行实例当前设置；off 总可用，其他方向须受支持 |

等级 0 不能启用调温；非零等级必须明确支持方向和合法范围。automatic 仅限同时具备加热／制冷方向的设备；模式不是行为词条。

主动调节不越过目标。被动热交换和主动调温一起计算，建议固定 1 tick 子步，避免跨大采样间隔跳过危险温区。温度下降需要过程，装入货物不默认已经预冷。本轮不增设电力或冷媒系统。

恒定环境下，维持温差 ΔT 约需 ΔT／τ 的主动速度。τ＝60 秒配调温 1，最多抵消约 6 TU 温差；配调温 2 约 18 TU。τ＝240 秒配调温 2 可抵消约 72 TU。仍受目标范围、初始温度及预冷过程限制。

### 4.6 遮光

| 等级 | 候选名称 | 削减亮度 | 外部 15 时内部值 |
| --- | --- | ---: | ---: |
| 0 | 无专项遮光 | 0 | 15 |
| 1 | 基础遮光 | 5 | 10 |
| 2 | 深度遮光 | 10 | 5 |
| 3 | 完全遮光 | 15 | 0 |

`L_internal = max(0, L_external - reduction)`。货物 max＝5，外部 15，等级 2 恰好满足；max＝4 则仍有风险。不能把能力等级 2 直接当成亮度 2。

完全遮光只隔离模型中的外部光照，不模拟货物自身发光。遮光不自动赠送隔热；若以后模拟辐射加热，需要明确能量输入关系。

### 4.7 承压

| 等级 | 候选名称 | 最大绝对压差 | 相对参考压力的显示 |
| --- | --- | ---: | --- |
| 0 | 无专项承压 | 0 | 不提供有效保压 |
| 1 | 基础承压 | 0.2 | 20% 压差 |
| 2 | 加强承压 | 0.5 | 50% 压差 |
| 3 | 高压差承载 | 1 | 100% 压差 |

`abs(Pin - Pout) ≤ max_difference` 时满足条件。首版内外压差采用同一绝对上限，不主动增压。

内部 1、外部 0.6，压差 0.4，需要等级 2 且密封 2；外部降至 0.3，压差 0.7，需要等级 3。低压地点封闭时 Pin＝0.4，不会因等级 3 自动恢复为 1。

外部压力来自航空学真实采样，不能换成固定世界高度。有效零压正常计算，无效采样不假定真空。这些等级需在不同航程压力样本中验证，不能保证当前世界已经支持全部场景。

释放过程候选：超限后以 5 秒时间常数向 Pout 靠近；压差降到上限的 80% 才允许重新封闭，避免抖动。无气密或承压 0 则随外部。释放状态和 Pin 必须保存，不因重启恢复旧安全压力。仅为游戏规则，不产生爆炸或永久破坏；释放时的有效密封见 4.2。

## 五、温度刻度的候选名称

| 参考锚点 | 名称 | 用途 |
| --- | --- | --- |
| 0 TU | 严寒端 | 低温调试 |
| 20 TU | 冷凉 | 冷藏条件参考 |
| 40 TU | 温和 | 一般环境参考 |
| 60 TU | 炎热 | 高温暴露参考 |
| 80 TU | 酷热端 | 强热环境参考 |

TU 没有摄氏度换算；不是所有货物在 0 冻结或在 40 安全。锚点帮助编写参数，风险仍比较各货物真实范围。内部 T 允许超出锚点，需有限并处于实施时约定的数值安全域。

首轮样例设备可统一目标范围 0～80 TU，先减少无关变量；专业柜后续再缩窄或扩展。环境映射已有[观测契约与 V0 候选公式](观测校准与生命周期契约.md)，但尚未实测定版，不能据此批量重写食品或冰块属性。

## 七、局部配置样例

### 7.1 怕湿细粉

```json
{
  "transport": {
    "containment": {
      "required_level": 2,
      "loss": {"grace_ticks": 0, "interval_ticks": 1200, "amount": 1}
    },
    "water_exposure": {
      "loss": {"grace_ticks": 200, "interval_ticks": 400, "amount": 1}
    }
  }
}
```

显示易散失、怕水。没有 sealing 分组不代表不怕水：sealing 描述向外交换，water_exposure 描述外部进水，两者读取同一密封能力。示例周期不是最终经济平衡。

### 7.2 适宜冷藏但不能过冷的货物

```json
{
  "transport": {
    "temperature": {
      "min": 10,
      "max": 60,
      "loss": {"grace_ticks": 200, "interval_ticks": 400, "amount": 1}
    },
    "aging": {
      "budget_ticks": 36000,
      "temperature_rates": {
        "breakpoints": [20, 40],
        "rates": [0.2, 0.5, 1]
      },
      "loss": {"interval_ticks": 400, "amount": 1}
    }
  }
}
```

T＝15 时较慢老化，T＝5 时低温损伤。仅为模型示例，不重设所有食品的固定保存时长。

### 7.3 冷藏柜能力样例

```json
{
  "transport_capabilities": {
    "containment_level": 2,
    "sealing_level": 1,
    "cushioning_level": 2,
    "insulation_level": 2,
    "thermal_control_level": 2,
    "light_blocking_level": 2,
    "pressure_resistance_level": 0
  },
  "thermal_control": {
    "supported_modes": ["cooling"],
    "target_min": 0,
    "target_max": 80,
    "default_mode": "off",
    "default_target": 15
  }
}
```

只说明未来格式，不指派给某制造商。没有气密和承压，不支持保压；具备液密不代表允许装流体，形态独立。默认关闭不能显示已冷藏。

## 八、校核和待实测事项

数学与语义要求：

- 围护 2 覆盖 1，密封 2 覆盖 1，不跨维度赠送能力。
- 缓冲越高传递冲击不增加，仍可能被更强冲击突破。
- 隔热越高被动热交换越慢，不自动变冷。
- 同目标调温越高，可用调节速度不降低，不强制更低目标。
- 遮光越高内部光照不增加。
- 承压越高允许压差不减少，无气密仍不保压。
- 缺省值、单位、边界和显示舍入唯一，不同厂家不另设解释。
- 各来源损耗汇总不超库存，固体／液体按各自原生整数数量结算。

必须实测的部分：冲击 J 映射与事件合并、温度环境映射、温控稳定性与采样间隔一致性、航空学实际压力分布、释放过程及平均航程下货损速度。

首轮先校验代表性内容，不在本轮批量落运行数据，不调整现有型号容量、空重和结构。
