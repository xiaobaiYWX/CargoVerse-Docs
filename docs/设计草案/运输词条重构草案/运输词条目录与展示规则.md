# 运输词条目录与展示规则

> **待实现内容设计 · 2026-10-24。** 以[运输基础数值](通用运输词条扩展讨论.md)为依据，设计首批玩家可读词条。本文不新增运行行为 ID、不修改代码或数据包。具体字段和候选逐级效果见[运输数值字段与能力等级](运输数值字段与能力等级.md)，最终参数仍须实测平衡。

## 一、词条分成三个位置

| 位置 | 表达对象 | 出现条件 | 示例 |
| --- | --- | --- | --- |
| 货物特性 | 货物本身的运输需求 | 存在有效物性配置，与当前货柜无关 | 易散失、易碎、低温敏感 |
| 货柜设计 | 货柜实际能力与结构短板 | 由最终能力数值及明确的设计基准产生 | 精细围护、气密封存、缓冲薄弱 |
| 本次运输状态 | 货物、货柜、环境共同产生的结果 | 对实际载荷求值后显示 | 围护不足、正在预冷、内部低压 |

**货物被安全保护后，特性仍然存在。** 玻璃放进缓冲柜依旧“易碎”，只是本次运输显示相应防护情况。缺陷影响柜体能力，不能让普通石材获得“易碎”特性。

三个位置不混排为一个正负词条列表。短名称帮助识别，展开说明提供数值、条件和结果；颜色只是辅助，状态必须有文字。

## 二、首批货物特性目录

下表中的“存在配置”均指有效、会产生作用的配置。损耗为零、范围不约束、缺省物性不生成假警告。不会为了让每件货物都有词条而填充“通用货物”等无效描述。

| 基础词条 | 数值依据／生成条件 | 默认说明 | 对应防护与玩家操作 |
| --- | --- | --- | --- |
| 易散失 | 最低围护大于 0，且散失损耗启用 | 围护不足时，运动或倾斜可能导致散失 | 使用满足需求的围护；减少相关暴露 |
| 需液密 | 向外交换损耗启用，密封需求为 1 | 密封不足时会发生数量损失 | 使用液密或更高密封能力 |
| 需气密 | 向外交换损耗启用，密封需求为 2 | 普通液密无法满足此货物的封存需求 | 使用气密封存 |
| 易碎 | 声明有限冲击耐受，并启用冲击损伤 | 传递到货物的冲击过大时受损 | 缓冲、平稳驾驶；匀速不算冲击 |
| 怕水 | 声明液态水敏感性及相应损耗 | 实测进水时受损，干燥环境不会仅因低密封扣货 | 密封隔离，避开进水暴露 |
| 光敏 | 声明亮度容许上限及光照损耗 | 内部光照超过上限时累积损伤 | 遮光、减少光照暴露 |
| 低温敏感 | 有有效温度下限及低温损伤 | 低于安全温度下限时受损 | 避免过度制冷，必要时适当调温 |
| 高温敏感 | 有有效温度上限及高温损伤 | 高于安全温度上限时受损 | 隔热延缓升温、制冷降低实际温度 |
| 易变质 | 有有限老化预算及启用的预算耗尽货损 | 运输期间按实际温度累计老化 | 检查实际温度、已累计年龄和运输时间 |
| 宜冷藏 | 安全温区内存在较低温且老化速率更慢的区段 | 合适冷藏可减缓老化，不会恢复已损失寿命 | 将实际温度维持在推荐保存区，而非一味降低目标 |
| 低压敏感 | 有有效气压下限及低压损伤 | 内部气压低于下限时受损 | 检查内部气压；需要时使用气密且承压足够的柜型 |
| 高压敏感 | 有有效气压上限及高压损伤 | 内部气压高于上限时受损 | 检查装载地点压力与可维持的内部状态 |

默认先采用这 **12 个基础显示词条**，不是十二种新行为。围护、密封、冲击、水分、光照、温度、老化和气压的计算仍来自基础模型。

“宜冷藏”是保存建议，不是拒装条件。若只是常温老化较快，不能显示成“必须冷藏”；“冷链运输”不再作为含义模糊的货物特性。推荐保存区由老化曲线的安全低速区段产生，不新建一个“保鲜需求等级”。

温度、气压阈值以该货物实际值展示。它们不因玩家当前所在位置安全而隐藏，也不按全局常温猜测是否值得提示。

### 2.1 哪些词条允许同时显示

- 易散失＋怕水：围护防止向外掉料，密封防止向内进水，各有意义。
- 易碎＋易变质：机械损伤和老化独立。
- 宜冷藏＋低温敏感：说明应该冷藏，但不能过冷。
- 高温敏感＋低温敏感：展开显示同一条安全温度带。
- 低压敏感＋高压敏感：展开显示同一条安全压力带。
- 需气密＋怕水：可由同一密封能力覆盖，但源物性并不相同；展开分别解释外逸和进水风险。

“需气密”已经覆盖较低密封需求，不再同时显示“需液密”；一份物性只有一个最终最低密封值。宜冷藏作为易变质说明内的建议徽标，可减少重复占位。

### 2.2 表现名称可以变化，实际依据不变

数值不能独自说明损失在故事中为何发生。例如密封需求 2 无法分辨挥发、升华或其他封存需求。因此区分默认功能名称与可选表现名称：

| 默认名称 | 可选表现名称 | 使用边界 |
| --- | --- | --- |
| 易散失 | 易散落、粉末逸散 | 均引用同一围护要求；不根据名称判断物品形态 |
| 需液密 | 易渗漏 | 仅改变向外散失的解释 |
| 需气密 | 易挥发、易升华 | 由内容作者选择解释；不能从“密封 2”自动推断化学性质 |
| 易碎 | 震动敏感、冲击易损 | 共用冲击判断，不暗示已有持续振动谱检测 |
| 高温敏感 | 遇热失稳、受热劣化 | 仍是高温损伤，不产生真实燃烧或爆炸 |
| 低温敏感 | 怕冻、遇冷失稳 | 仍是低温损伤，不生成冻结产物 |
| 易变质 | 易腐、保存期有限 | 共用老化状态，不自动生成腐败物品 |

表现名称只是每个数值维度的可选显示文本／翻译键，不创建一张运行词条注册表。文本缺省时使用默认名称；存在物性才允许显示对应替换名称。说明中的关键数值由系统生成，作者不能用文案覆盖数值事实。

“易燃易爆”“耐腐蚀”“辐射屏蔽”等在当前最小模型中没有足够的对应行为，首批不作为正式效果承诺。仅有高温扣量时优先使用“遇热失稳”，避免让玩家误以为会点燃周围方块或炸毁载具。

不按形态限制这些名称。例如液体可以显示“震动敏感”，固体可以显示“需气密”；实际可装载性仍由设备形态、安全准入和容量决定。

## 三、货柜能力词条与缺陷用语

### 3.1 能力名称直接来自最终数值

| 能力维度 | 正向显示 | 零能力／未配备的中性显示 | 明确设计缺陷的负向显示 |
| --- | --- | --- | --- |
| 围护 | 围护 1：粗料围护；围护 2：精细围护 | 开放承载 | 围护薄弱 |
| 密封 | 密封 1：液密封装；密封 2：气密封存 | 未密封 | 密封薄弱 |
| 缓冲 | 缓冲结构〔等级〕 | 无专项缓冲 | 缓冲薄弱 |
| 隔热 | 隔热保温〔等级〕 | 无专项隔热 | 隔热薄弱 |
| 调温 | 调温系统〔等级〕，附支持方向 | 无主动调温 | 调温能力偏低 |
| 遮光 | 遮光结构〔等级〕 | 无专项遮光 | 遮光不足 |
| 承压 | 承压结构〔等级〕，附最大容许压差 | 无专项承压 | 承压薄弱 |

正负用语是同一维度的两种描述，不要求“易碎”对应“坚不可摧”这种绝对反义词。当前等级之外不再添加独立缺陷参数来扣一次货。

只知道最终数值低，无法断言它是设计缺陷。没有明确基准时使用中性能力名称；相对明示基准确实降低时才显示缺陷，例如“密封薄弱：当前 1，设计基准 2”。基准仅供设计解释，不影响实际求值，也不要求为每款柜新增基准配置。

若以后保留基础值与修正值，最终值仍是唯一运行输入；界面可以展示“基础 2－修正 1＝实际 1”。不能同时显示“完全气密”和“密封薄弱”而不说明最终等级。

### 3.2 复合能力名称

部分玩家常用名称需要多项事实共同成立：

| 可显示名称 | 必要依据 | 不保证的内容 |
| --- | --- | --- |
| 支持冷藏 | 调温系统支持制冷，并存在可用冷藏目标范围 | 当前已开机、已降到目标、所有货物都适合 |
| 支持加热 | 支持加热方向及可用目标范围 | 自动防止一切低温损伤 |
| 支持保压 | 气密等级达标且承压能力大于 0 | 恒定标准压力、任意高度或环境都安全 |
| 支持隔水 | 液密或更高密封能力 | 空气除湿、干燥吸湿或防腐蚀 |
| 支持细料运输 | 精细围护 | 该细料的其他温度、水分、冲击需求也全部满足 |

复合名称是能力摘要，不生成第八种能力。展开显示其依据；基础能力页面仍能看到七项最终数值。冷藏目标尺度未确定前，可暂只显示“支持制冷”，不编造具体摄氏温度。

## 四、本次运输状态：说明现在发生什么

永久特性与实时风险分开。状态从实际计算输出取得，界面不能另算一套近似规则。

| 状态名称 | 显示条件 | 应附说明 |
| --- | --- | --- |
| 围护不足 | 该货物需求高于当前围护 | 需求／实际等级；是否正处于散失暴露 |
| 密封不足 | 对该货物的交换需求或水侵入保护不足 | 外逸与进水原因分别说明 |
| 冲击防护不足 | 已测传递冲击超过货物耐受 | 仅解释此次已观测冲击，不保证未来所有碰撞 |
| 正在预冷／升温 | 调温已运行，实际温度尚未进入目标带且方向正确 | 当前值、目标值；无可靠预测不显示到达时间 |
| 内部过冷／内部过热 | 实际内部温度越过货物安全下限／上限 | 实际温度、安全带、货损是否已开始 |
| 老化加快／冷藏减缓老化 | 实际温度对应的老化速率高于／低于参考速率 | 当前速率与剩余等效预算；无冻结的到货寿命承诺 |
| 内部低压／内部高压 | 实际 Pin 超出该货物安全范围 | 相对压力百分比及上下限，不显示固定限高 |
| 压差超限 | abs(Pin－Pout) 超过当前承压上限 | 当前压差、容许值及释放状态；不等同于货物已低压 |
| 水侵入暴露 | 已观测水接触且屏障不足，货物怕水 | 累计情况、预计下一次结算依据 |
| 光照过强 | 实际内部光照超过容许上限 | 当前值与上限 |
| 环境数据未知 | 必需采样缺失或无效 | 不能评估的因素；不标记安全，不假定零压 |
| 当前条件满足 | 当前可评估的要求都满足，且所需采样齐全 | 仅代表此刻，不保证未来路线和事故安全 |

对于只在事件发生时才能判定的冲击风险，静态面板显示缓冲与货物耐受，不能凭“尚未发生撞击”承诺防护充足。气密柜在低压环境中仍可能保持安全 Pin；外界压力低不能直接显示“货物低压”。

风险与已受损必须区分：

1. **防护缺口**：存在能力不足，但当前暴露尚未发生。
2. **不利暴露**：暴露已发生，尚未达到下一次损耗结算。
3. **正在损耗／本次已损耗**：由实际扣量事件确认，不能仅凭阈值越限就声称已扣货。
4. **已恢复当前安全条件**：风险触发已停止，历史损失与累计老化不会消失。

这些是状态描述，不是新增完整度或第四套属性。

## 五、显示与去重规则

- 装载前显示货物特性、货柜最终能力和已知防护缺口；装载后再显示实际内部温度／压力等状态。尚未创建的内部状态不凭空显示为安全。
- 同一围护需求只生成一个特性；同一密封最终需求只显示最高要求。相同因素的多个表现名采用一个主名，其他文本放入说明。
- 温度上下限并列存在时，紧凑视图合为“温度敏感”，展开列出低温／高温边界。气压同理合为“气压敏感”。合并仅影响显示。
- “易变质＋宜冷藏”优先显示为“易变质 · 宜冷藏”，展开仍是一份老化数据，不重复计时。
- 不以颜色或图标代替条件文字；缺陷和临时风险也不共用一个无上下文的红色标签。
- 词条数量较多时，紧凑面板优先展示正在损耗、当前暴露、防护缺口，再折叠其余特性。详细页面必须保留完整清单，不为适应固定槽位丢弃任何运行因素。
- 等级名称来自统一尺度，不按制造商重命名等级含义。货物表现名允许变化，数值说明、状态定义保持一致。
- 百分比气压仅在显示层舍入；实际判断使用原始系数。温度尺度未校准时不标摄氏度，也不显示伪精确倒计时。
- 普通无额外要求的货物显示“无额外运输要求”即可，不宣称“不会损坏”或对未来全部机制免疫。

## 六、典型内容组合

以下用于验证词条语义，未批量配置实际物品。

| 内容 | 货物词条 | 合适的能力方向 | 需要避免的误解 |
| --- | --- | --- | --- |
| 碎石／矿渣 | 易散失〔围护 1〕 | 粗料或精细围护 | 不创建矿业专柜许可 |
| 明确怕湿的细粉 | 粉末逸散〔围护 2〕、怕水 | 精细围护＋液态水隔离 | 只有围护不能防进水 |
| 普通水 | 需液密；温压敏感性仅在实际配置后显示 | 液密柜 | 不因是液体就自动“易挥发” |
| 明确挥发且怕冷的试剂 | 易挥发〔密封 2〕、低温敏感 | 气密及适合的温度条件 | 气密不代表耐蚀，制冷不是越低越好 |
| 对震动敏感的液体 | 震动敏感 | 缓冲 | 不禁止液体使用机械敏感特性 |
| 易腐食品 | 易变质 · 宜冷藏；易碎或怕冻视物性配置 | 合适温区的调温、必要的缓冲 | 冷藏不消除易碎，也不重置寿命 |
| 压力敏感样品 | 气压敏感〔实际安全带〕 | 必要时气密＋承压 | 不要求在固定 Y 以下运输 |
| 光敏固体／液体 | 光敏；其他物性另填 | 遮光 | 遮光不自动变成隔热或危险屏蔽 |

### 6.1 一个细粉装载示例

货物属性：围护需求 2、水分敏感；柜体：围护 1、密封 1。

- 货物页：“粉末逸散”“怕水”。
- 货柜页：“粗料围护”“液密封装”。
- 装载预览：“围护不足：需 2，当前 1”；水隔离需求被覆盖。
- 静止且无相应运动暴露：有围护缺口，不显示已损失。
- 运动触发暴露并达到扣量周期：状态显示散失及实际扣量。
- 将同一物品改名为“矿粉”不改变上述结果。

### 6.2 一个冷藏但不能冻结的示例

货物有安全温度下限，且安全温区中的适度降温可以减缓老化。

- 货物页：“易变质 · 宜冷藏”“低温敏感”。
- 货柜页：“支持制冷”“隔热保温〔等级〕”。
- 制冷尚未完成时：“正在预冷”，按当前真实 T 计算老化。
- 达到合适区间：“冷藏减缓老化”。
- 错误目标使 T 低于安全下限：“内部过冷”，使用温度损伤分支，不额外叠加同源变质损耗。

不需要判断“冷链词条与保温词条是否互斥”，也不需要一个独立的保鲜能力。

## 七、首版内容验收

1. 改词条名称、图标、翻译文本不改变损耗结果；增加别名不增加运行实例。
2. 未声明相应物性，不显示该特性；货柜缺陷不创造新的货物敏感性。
3. 同一词条可用于任意已支持形态，基本装载准入仍独立判断。
4. 货物特性始终可查；防护有效后只是相应风险消失，不删除该特性。
5. 缺口、暴露、已扣量、采样未知四类情况能明确区分。
6. 冷藏建议来源于实际老化曲线，保压摘要同时检查气密和承压。
7. 目标温度、实际温度与可用调温能力不会混为一个“制冷等级”提示。
8. 压力提示使用实际内部压力；不以绝对高度或外部低压直接判定货物受损。
9. 普通柜缺少专项能力显示中性说明，确有设计基准才称为缺陷。
10. 详细页面展示全部有效因素，紧凑显示合并不影响计算或隐藏未覆盖风险。
