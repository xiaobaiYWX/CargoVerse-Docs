# 运输数值系统重构实施方案

整理日期：2026-10-24。依据现有两份运输词条草案和当前物品／液体代码核对。第一轮基础内核已收尾，第二轮权威载荷与实际采样主路径已接通；当前数值引擎唯一运行，内置数据与 UI 投影留在第三轮。候选参数仍待内容验收，不以复杂校准工具作为继续实施前提。

[基础模型](通用运输词条扩展讨论.md) · [字段与等级](运输数值字段与能力等级.md) · [观测校准与生命周期契约](观测校准与生命周期契约.md) · [其他待完成事项](../待完成事项清单.md)

## 1. 重构目标与范围

本次不是增加一批 AffixHandler，而是把“词条 ID 驱动行为”整体替换为：

**环境与运动观测 → 货柜能力改变暴露 → 货物物性／动态状态 → 各原因损耗汇总 → 原生数量扣减。**

词条名称、图标、正负文案只是数值和状态的显示投影。货物的易碎等固有特性不会因货柜能保护它而从定义中消失；当前是否安全另行计算。

- 应用范围为已实现的实际物品和液体，共用数值求值；气体、生物不在本轮接入。
- 七项能力为围护、密封、缓冲、隔热、调温、遮光、承压。围护／密封 0～2，其余 0～3。
- 不改物品形态、精确组件身份、质量单位、货柜容量、空重、型号 ID、结构和制造配方。
- 不重做物流网络、Create 仓库、报价、钱包、自然点经验或装卸确认事务。
- 不加总防护分，不注册行为词条名单，不加入真实爆炸、化学反应、气体温压耦合或完整生态模拟。
- 草案等级换算暂作首轮调试值，不当作已验证的最终平衡参数。

## 3. 保留与替换的架构边界

建议按职责组织，而不是为每个显示词条建类。名称可随代码风格调整。

| 层次 | 建议职责 | 约束 |
| --- | --- | --- |
| 定义 | TransportProperties、ContainerCapabilities、ThermalControlDefinition | 类型化解析、范围校验、缺省值；不触碰世界或库存 |
| 冻结 | TransportRuleSnapshot | 货物物性和换算版本冻结；保留物品／液体原有质量、贴花及精确身份 |
| 观测 | TransportObservation、采样服务 | 世界位置、运动、冲击候选、环境 TU、气压、水接触、亮度；各因素独立有效性 |
| 实例状态 | TransportState、ThermalControlSettings | 内部 T、必要时的 Pin／释放状态、老化、各原因余数及有效观测时间 |
| 求值 | TransportEvaluator | 无库存副作用；输入规则、能力、状态、观测及有效时长，输出新状态、损耗和风险摘要 |
| 应用 | 运输更新服务＋现有 Repository | 权威一次写入状态／扣量，数量归零清载荷；沿用现有质量与外观失效通知 |
| 展示 | TransportPresentation | 生成固有特性、柜体设计及当前风险；显示 ID 可有图标，但不得调度行为 |

数量／计量继续由 CargoContent、CargoMeasure 等现有职责维护。计算层返回原生数量损耗，固体 pcs、液体 mB；不逐件或逐 mB 遍历，不为新规则复制第二套载荷或仓库事务。

货物规则不依赖柜体过滤。调温设置是货柜实例配置，模式／目标需持久化；空柜保留设置不意味着首版已经实现空柜预冷模拟。

## 4. 数据契约

### 4.1 作者数据

- 逐物品／逐流体文件保留原有 namespace 和形态目录，新增 transport 对象，替代 transport_requirements。
- 货柜定义新增 transport_capabilities 和必要的 thermal_control，替代 special_designs／design_defects 的行为作用。
- 新内置柜型定义显式填写七项能力；扩展定义缺省按草案约定处理，并输出校核提示。
- 无声明敏感性就不产生相应风险；无物品／流体定义时沿用当前默认质量、身份与准入安全边界，新运输物性缺省为空。
- 等级不足一般是可解释的运输风险，不成为用途分类许可。介质、容量、嵌套内容安全等硬准入继续独立。
- 基础液体承载腔最低液密等级属于柜体定义合法性；非法柜体不能靠“允许带风险装载”绕过。
- presentation 可提供设定文字，但不能覆盖风险生成条件或授予实际能力。
- 未知字段、残缺损耗分组、越界等级、非有限数、倒置范围、非整数扣量、曲线长度不符等拒绝发布。

### 4.2 冻结和 reload：采用装载冻结

首次正数装载成功提交时冻结货物物性、七项承运能力、调温支持约束和可恢复的全局换算／校准版本。制造不永久锁定七项能力；空柜下一次装载读取当前完整定义。容量、空重、模板的资产契约不在此处改变。

当前模式和目标仍可在本次冻结范围内调整，不刷新寿命。追加要求身份和计算规则兼容；reload 修改能力、物性或换算时拒绝混代追加，但允许已有载荷正常卸出。纯文案更新不影响兼容性。

快照必须能在重启后恢复必要的旧数值，不能只留版本号再使用最新常数。未知版本保留原始数据隔离，不转入旧引擎。具体事务、显示和定义删除规则以[冻结契约](观测校准与生命周期契约.md#六能力冻结装载冻结制造不永久锁定)为准，保存格式须按此边界设计。

## 5. 生命周期约定

| 事件 | 确定行为 |
| --- | --- |
| 首次装入 | 首笔成功提交冻结规则，必要 T／Pin 以有效环境初始化；取消或零转移不产生批次 |
| 成功追加 | 先结算旧量，新量继承既有 T／Pin、年龄、暴露及余数；不刷新、不加权返老还童 |
| 部分卸出 | 先结算再转移，剩余货物状态保持并继续运行 |
| 原生卸出 | 不向 ItemStack／FluidStack 写入运输寿命；再次装入按新运输开始，明确接受这一边界 |
| 全部卸空或损耗归零 | 清除载荷规则和状态，保留货柜身份及工作设置 |
| 卸载／停机 | 保存并暂停，恢复首样本建基线，不补算未知时段 |
| 单因素观测失败 | 暂停依赖链，其他有效因素继续；TU 失败同时暂停温度和老化 |
| 关闭调温 | 继续被动热交换，不重置内部温度与年龄 |
| 取消／失败／重试 | 只保留真实提交的数量与状态，不重复扣货，不制造运输批次 |

以上替代旧追加刷新保护期的规则。与原生库存往返能重开寿命是已接受的模型范围，不增设全世界物品腐败组件。详细边界及事务顺序见[生命周期契约](观测校准与生命周期契约.md#五追加卸出与暂停的确定语义)。

## 6. 采样与状态推进

### 环境、运动与有效性

- 以货柜真实世界采样位置为准，Sable 转换后再读气压、雨水、亮度和环境热状态；不能用子空间 Y、玩家位置或未旋转的世界轴包围盒冒充。
- 同一运输载具可共享基础运动观测；局部位置影响的环境、朝向及必要点速度仍按货柜求值，不能错误地全船共用一份环境。
- 气压复用当前 DimensionPhysicsData.getAirPressure 调用入口，保存有效非负原始系数；零值有效，非法值未知，不自写高度映射。
- TU 输入、采样分支、V0 候选公式及校准矩阵按[观测契约](观测校准与生命周期契约.md)执行。先完成观测与校准，再用于正式内容；不直接把群系温度当 TU 或摄氏度。
- 冲击按观测契约归一单位、参考点速度、重力与事件去重，采用待校准的 J 代理。现有间隔速度差不满足契约；provider 单位与定义原点未核实之前不得正式接入，tick 内短冲击盲区需实测。
- 普通静态货柜也应取得可用环境样本，不能因缺少刚体而跳过温度／水／光照；结构尚未加载则不得强制加载。

### 有界计算

草案提出的“固定 1 tick 子步”与“不随时间间隔线性循环”需要统一：

- 推荐恒定观测窗口内使用解析／分段有界推进，必要时在目标温度、安全温区、老化曲线断点和释放状态边界处分段。
- 若首版采用短子步近似，只限连续有效的短窗口，步数有硬上限；不得对长时间卸载／重启逐 tick 回放，不得用封顶积分把实际处于中间危险区的时间直接跳过。
- 阈值穿越与老化累计使用内部精度；UI 的整数或一位小数不回写计算。
- 各原因损耗通过商／余数常数时间结算，乘法前封顶防溢出。
- 温度越出直接损伤边界时，同期不重复结算同源老化损耗；独立水、光、压力等可并行，最后总量封顶一次扣。
- 温度／气压未知时不编造数据；暂停后的连续样本重新开始，不把整个缺样间隙当成新的有效窗口。

### 首版保压与调温

建议本轮完成草案中的有界 T／Pin 模型及释放回差，不引入真实压力容器仿真：

- 调温先支持实际内置柜需要的方向；off 必须可用，等级 0 不可启用；目标合法且主动变化不越过目标。
- 气密与承压独立，超差进入有限释放过程，达到回差条件后恢复；有效屏障状态供水／散失共同读取。
- 无气密或承压 0 随环境压力；低压封闭不会自动得到参考压力。
- 无电力／冷媒消耗只是首版明确简化，不描述为已具备资源供给系统。

## 8. 首轮代表内容与验收矩阵

| 代表内容 | 重点验证 |
| --- | --- |
| 无敏感性的完整石块 | 无调温／气密不凭空损坏，不创建无用老化计时 |
| 碎石／细粉 | 围护包含关系，运动散失与冲击不重复 |
| 怕水细粉 | 水接触独立于向外散失；晴天不因密封低持续扣 |
| 玻璃类物品 | 缓冲比例、严格超过耐受、独立冲击事件去重 |
| 易腐但怕冻结的食品 | 内部温度变化、老化曲线、安全区外去重、追加不洗状态 |
| 普通水 | 液密基础柜可运；mB 扣量、尾量质量、原有整桶交易不变 |
| 测试用挥发／光敏／压敏内容 | 只为验证机制，不冒充已有正式物品属性；气密／承压组合与释放回差 |
