# 液体运输后续设计与验收

基础液体业务已接入；已实现的配置、计量、身份、原生储罐、交易和装卸流程统一维护在[液体运输](../01货柜系统/01核心系统/13_液体运输.md)。本页只保留后续工作，不维护历史草案副本。

## 待深化内容

- 首批原版／Create／航空学流体的逐流体质量、词条和贴花平衡。缺失定义已有明确默认值：1000mB=1Kpg、无词条，不等于所有流体都已经完成内容设计。
- Cistern、Crucible 的专用结构和最终容量平衡；当前 M/L 暂定 120/240 桶，使用 AUI 同规格占位结构。
- [数值驱动的运输要求、货柜能力与货损设计](通用运输词条扩展讨论.md)：挥发、腐蚀与固体散失复用行为组件；温度用范围统一，保护与缺陷分开表达，不按介质隔离。衬层保护需要实际能力，名称不自动授予保护。
- 正式自然站液体交易表和投放配方；现有资源表已能声明流体 ID，但不自动生成经济内容。
- 生物和气体继续独立专项；共用 FluidStack 不代表液体柜能装气体。

## 待人工验收

1. 客户端各终端的 mB 数字、超长读数、图标平面效果、扫描切换及资源重载；自定义组件流体的图像表现另行验证。
2. Sable 运动／拆分货柜的质量、贴花、时限和装卸区域检测；玩家贸易点设备仍禁止在 Sable 中使用。
3. 多人同时确认、持续自动化输入输出、大型储罐拆分／合并、断线和区块卸载的实际表现。
4. 多种模组自定义流体的标签、精确组件、原生储罐兼容性；不把其他独立气体 API 自动映射为液体。

继续按受影响范围运行测试；自动回归不替代以上视觉和压力验收。
