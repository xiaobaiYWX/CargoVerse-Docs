## 普通货物与准入核对

未出现在上表的条目不得为了覆盖率强加词条。完整砖块与原石、普通金属武器工具护甲、普通结构件都可保留无保护需求；纸板装备按自身易受潮材质处理。由旧易碎／防潮转为普通的条目，应在落数据差异清单中逐项列出并核对外观与物品实际形态，不能把本名单当作已完成对所有模组物品的实机验证。
