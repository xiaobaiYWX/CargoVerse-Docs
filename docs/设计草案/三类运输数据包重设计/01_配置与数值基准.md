# 配置与数值基准

> 候选内容规范；字段按 2026-11-03 工程核对。数值不是实测结论。

## 三种运输对象

| 对象 | 属性路径（data/命名空间 下） | 容量含义 | 质量字段 | 原生损耗 |
| --- | --- | --- | --- | --- |
| 物品 | `cargoverse_item_properties/solid/物品路径.json` | 最大堆叠组数 | `unit_mass`：满一组的 Kpg | pcs |
| 液体，包括气态 Fluid | `cargoverse_fluid_properties/liquid/流体路径.json` | 桶；1 桶=1000 mB | `mass_per_bucket` | mB |
| 生物 | `cargoverse_entity_properties/living/实体路径.json` | 总舱位／单只 `space_units` | `mass_per_entity` | 逐只生命值损耗；新后端待验收 |

三类属性统一用 schema 3 与 `transport_conditions`；货柜仍用 schema 1 与 `abilities`。不得并列旧 `transport_requirements`、`transport` 或 `transport_capabilities`。显示名称、图标和说明由现有源码词汇提供，不新增独立词条数据包目录。

同一物品的空瓶／药水瓶均属于物品通道，均可易碎；瓶中内容不是散装液体。鱼桶不是活体运输载荷；不得利用重新分类绕开其现有准入策略。

## 数量和质量

物品容量 50 表示：最大堆叠 64 的物品可装 3200 pcs，最大堆叠 16 的可装 800 pcs，不可堆叠物品可装 50 pcs。货重=实际 pcs÷冻结最大堆叠数×每组质量，整柜最终按现行规则向上保留一位小数。

本轮保留已完成的逐物品质量表；其多数为 0、0.1、0.2、0.3，少量重型设备更高。不要把空重调整再叠加为逐物品质量十倍放大。微小物品允许零质量；零质量不免除容量与损耗。

固体柜空重候选为当前值÷5，保留一位小数。此为一次性内容换算，不新增运行倍率。例如 Atlas S 从 20 调至 4：50 组每组 0.1 的货物重 5，石料若每组 0.3 则重 15。它修正旧计量导致的空重主导，不承诺每种货物一定比柜体重。

液体柜保持当前容量、空重；水暂保留每桶 1 Kpg，M 型 Cistern 装满 120 桶时货重 120、空重 65。生物质量与舱位候选另列，不套用固体空重换算。

贸易数量、单价、经验、每日限额、制造材料与加工费不由本次质量换算自动推导。特别是物品组、桶、实体只数不能互换。

## 损耗尺度

| 类型 | 首轮候选尺度 | 说明 |
| --- | --- | --- |
| 普通碎料／粉料 | 每 1200 tick 扣 8 pcs | 以 64 堆叠物为典型，一分钟丢 1/8 组；仅能力不足时 |
| 受潮粉料 | 宽限 2400，间隔 1200，8 pcs | 与散失是独立风险，允许同时损失；不伪称只有一个渠道 |
| 玻璃冲击 | 每事件 1 pcs，耐受 10 | 保留现行玻璃基线；单位为 10 tick 采样间的速度变化（格／游戏秒） |
| 一般温光暴露 | 宽限 3600，间隔 1200 | 单次 pcs 按逐物品表；适当给初次调温留时间 |
| 散装液体 | 每 1200 tick 扣 1000 mB | 一分钟一桶；小批次损耗比例更高 |
| 活体 | 每次对每只扣 1 点生命 | 候选，不能当成扣 1 只；须验证新后端的实际扣血 |

以上是明确起点，不是把所有商品机械套为相同损耗。第一笔一般暴露损耗发生在宽限＋一个间隔后；易腐的预算单独计算；冲击按现行事件规则结算，没有每秒追加旧规则。

食品分为长期耐储、短期保鲜、冻结保存三档。不叠加多个含义相同的温度上限；冷冻运输与高温敏感共享上限槽，只选其一。温度上下限、光照上下限及推荐目标必须有交集。

## 能力标尺

| 能力 | 本方案候选档 | 实际填写 |
| --- | --- | --- |
| 围护 | 1 碎料、2 粉料 | `level:1/2` |
| 密封 | 1 液密、2 气密 | `level:1/2`；气密仍有缓慢交换 |
| 缓冲 | 普通／加强／高防护 | `level:1/2/3`，`velocity_change_bonus:2/5/8` |
| 真空隔层 | 保温／强保温 | `level:1/2`，`exchange_time_seconds:240/480` |
| 调温 | 保鲜／宽温／深冷 | 见货柜组合表；明确方向、目标范围及 TU/s |
| 压力调节 | 样品／生物稳压 | 双向、范围 0.5～1.5、0.02/s、level 1 |
| 湿度控制 | 干燥／活体环境 | 干燥范围 20～60、1/s；活体范围 40～80、0.5/s |
| 朝向保持 | 有／无 | `level:1`，不抵消直线冲击 |
| 遮光 | 完全遮光 | `level:1,reduction:15` |
| 内部照明 | 本轮不普配 | 尚无需要持续光照的首批常规货物，不为凑能力创造需求 |

不填写的能力视为未配备。等级不会自动换算连续参数，落数据时必须写齐速度、范围、增量和时间。等级 3 不代表全环境保护，也不自动减轻空重。

TU 为游戏温标，不是摄氏度。当前常规外温约 10～70 TU，接触火／熔岩为 100 TU；不能照抄现实冰点推断所有原版物品都应结冰或熔化。封装液体、原版常温稳定物是否损耗须逐项设计。
