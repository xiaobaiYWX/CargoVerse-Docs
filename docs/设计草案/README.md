# 设计草案与待完成事项

本目录只保留尚未落地的玩法规格和待办，不保留已完成步骤、废弃模型、历史规划或阶段测试流水。现行参数、公式和生命周期归入正式系统章节。

- [待完成事项清单](待完成事项清单.md)：唯一待办入口，集中维护候选内容参数、固体产品应用、液体深化、生物、物流细化、正式投放与验收；完成后删除条目。
- [三类运输数据包重设计](三类运输数据包重设计/README.md)：物品／液体／生物与八家制造商货柜的统一内容方案、73款现有型号处置及首批逐ID清单；仅设计，尚未批量落入运行数据。
- [生物运输设计](生物运输设计.md)：水生环境、特殊实体兼容、自然站交易与正式投放；首版现行规则见生物运输正式章节，剩余实施与验收在统一清单维护。
- [装卸终端显示与交互调整](装卸终端显示与交互调整.md)：现有物品／液体装卸终端的仪表、按钮和显示调整，及通用确认／详情的生物适配与共用生命周期边界；布局和素材待定。
- [运输配置公共协议](../01货柜系统/01核心系统/15_运输类型与参数.md)、[观测与生命周期](../01货柜系统/01核心系统/16_运输观测与生命周期.md)：已经实现的源码与运行契约，不在草案内复制。

现行规则请查阅[工程边界](../00一级系统总览/02_货物与贸易工程边界.md)、[运输数值运行时](../01货柜系统/01核心系统/14_运输数值运行时.md)、[物流隧道与激活网络](../11玩家贸易点/06_物流隧道与激活网络.md)、[液体运输](../01货柜系统/01核心系统/13_液体运输.md)及[货柜目录](../10数据包定义与模板/03_货柜/README.md)。内容参数仍在对应系列和资源表中维护，草案示例不代替正式投放数据。
