# 待实现设计

本目录保留尚未完成、待确认或待接入的设计；已落地操作规则在正式系统章节维护，不保留实现过程或历史方案。跨阶段实施清单可列出必要的已实现基线，但须逐项标注状态并指向正式规则，不维护历史版本副本。

- [玩家贸易点物流网络设计与实施清单](玩家贸易点物流网络设计与实施清单.md)：完整连接方案，逐项标注已实现、部分实现、待实现及待验收；平面／斜向网络与液体基础业务已落地，局部配对、气体和生物端点仍待细化。

- [固体货柜运输条件设计](固体货柜运输条件设计/README.md)：共同运输模型下的固体应用、系列分工及验收；不另建词条行为与互斥规则。
- [运输专项推进边界](运输专项推进边界.md)：物品基线与液体、气体、生物专项的共用边界、推进顺序及验收。
- [液体运输首版设计](液体运输首版设计.md)：基础液体装卸已落地；本页仅保留专用模板、参数平衡、正式经济内容及人工验收。共用基础设施见[正式架构](../01货柜系统/01核心系统/12_多类型载荷与计量.md)。
- [数值驱动的运输要求、货柜能力与货损设计](通用运输词条扩展讨论.md)：以固定能力数值和货物约束计算风险，取消按显示词条 ID 判断保护与冲突；共同机制的草案入口，尚未实现。
- [气体运输首版设计](气体运输首版设计.md)：c:gaseous 识别、标准流体存取、固定容量建议及气密／压力边界；本轮只补文档，不恢复实施。
- [生物运输首版设计](生物运输首版设计.md)：实体容量、捕获／释放、状态保真与唯一性的待确认项。
- [后续柜型目录](../10数据包定义与模板/03_货柜/README.md)：6 系列／15 型号仍未开放；另 2 系列／4 款液体柜需完成专用结构和深化设计。
- [自然贸易网络与报价设计](../10数据包定义与模板/07_贸易点/设计总览.md)：40 张自然站报价仍待落数据，逐站参数在资源表目录维护。
