# 虚空结算器

`cargoverse:void_settlement_unit` 是仅有物品形态的实体钱包，用于保存和转移虚空字节。虚空字节的资源 ID 为 `cargoverse:void_byte`，界面和仪表统一使用缩写 `VB`。

- 物品不可堆叠；
- 余额为非负 `long` 数据，单个结算器最多保存 `1,000,000 VB`；
- 交易只识别玩家主物品栏和副手携带的结算器；
- 支出可依次从多台结算器扣除；
- 收入按物品栏顺序写入所有仍有剩余容量的结算器，不依赖结算器所处栏位；
- 多台结算器的剩余容量总和必须能完整接收本次收入，否则交易失败且不会截断入账；
- 未携带结算器时不能完成需要付款或收款的交易；
- 支付、发放或后续事务失败时，余额通过补偿记录恢复。

虚空结算器没有方块形态，也不读取世界中的储罐、管道或虚空混合物作为交易余额。

## 与虚空混合物的关系

虚空混合物保留异常物质设定和封装货物表示，不作为结算器中的实际内容。虚空字节是结算单位，虚空结算器是余额载体；当前没有将虚空混合物货物转换为余额的功能。

完整结算规则和设定见[虚空字节与虚空混合物](../07货币系统/01_虚空字节与虚空混合物.md)。
