# 轨道节点、区间与铺设

本章说明货柜轨道节点的结构、放置约束、路径规划和编辑方式。

## 节点结构

货柜轨道节点是三格宽的多方块结构：

```text
[左侧副方块] [主方块] [右侧副方块]
```

玩家只放置主方块，左右副方块由系统自动创建。节点可安装在地面、墙面或天花板；其状态同时记录：

- `FACING`：安装面的外法线。
- `AXIS`：轨道在安装平面内的切线轴。
- `POWERED`：当前节点是否直接收到红石信号。

`AXIS` 不允许与 `FACING` 属于同一坐标轴。

### 放置要求

- 节点背面必须有可支撑方块。
- 左右副方块位置必须为空且可替换。
- 节点下方应始终贴合支撑面，不能悬空放置。
- 主、副方块均没有实体碰撞箱，但保留完整 `16 × 16 × 16 px` 选择框，便于选取、拆除和使用扳手。

拆除主方块会同时移除副方块，并永久删除连接到该节点的所有轨道区间。直接破坏副方块也会按主节点处理，避免遗留半个节点。

## 节点朝向编辑

未连接任何轨道时，使用 Create 扳手右键节点可在当前安装平面内切换合法轨道方向。旋转时系统会重新检查支撑面和两个副方块空间，条件不满足时不会改变状态。

已连接轨道后不允许普通旋转。潜行并使用 Create 扳手右键主方块或任意副方块，会清除该节点的全部轨道连接。该交互有独立事件入口，避免被 Create 自身的潜行扳手逻辑提前消费。

## 铺设流程

货柜轨道是专用铺设物品，不是逐格放置的方块。

1. 手持 `cargoverse:cargo_rail` 右键一个现有轨道节点，记录起点。
2. 指向另一个节点，客户端实时求解轨道路径。
3. 预览颜色表示当前结果：
   - 绿色：路径有效，可以确认。
   - 红色：方向、距离或几何条件无效。
   - 黄色：路径中存在障碍方块。
4. 再次右键终点节点，将请求发送至服务器。
5. 服务器重新求解并验证，成功后保存区间。

预览只用于反馈，服务器验证才是权威结果。玩家不能通过伪造客户端路径绕过长度、节点连接数或障碍检查。

## 路径类型

### 直线

当两个节点切线轴相同，且另外两个坐标方向正确对齐时，生成单一直线区间。

### L 型转弯

不同轴节点之间生成“直线 + 固定半径90°圆弧 + 直线”。每个区间最多包含一个弯道；多次转向必须增加中间节点并拆成多个区间。

当前转弯半径固定为 `3` 格。距离大于弯道所需空间时，以入口或出口直线段补足，不会放大弯道半径。

安装平面发生变化时，该平面转换本身就是本区间唯一的一次转弯，不能再叠加第二个平面内转弯。

## 创建限制

- 起点和终点必须是有效的主节点。
- 起终点不能相同。
- 任一节点已有两条连接时不能继续连接。
- 区间数学路径长度不能超过 `16` 格。
- 中间经过的不可替换方块会使铺设失败。
- 节点或副方块在确认前被修改时，服务器会拒绝旧预览请求。

## 轨道模型与物理路径

路径数据是唯一权威来源，客户端从同一份路径生成左右轨道模型、直道连接结构和弯道采样模型。模型不参与碰撞，也不决定物理约束位置。

左右轨道按节点稳定方向构造，不以“先点击 A 还是先点击 B”为依据，因此 `A → B` 与 `A ← B` 应得到一致的左右布局。

物理路径会沿轨道安装面法线相对模型下移 `10 px`，用于让滑台接口与模型中的实际承载位置对齐。此偏移只作用于物理计算。

## 失效与清理

轨道区间依赖两个端点：

- 任意端点主方块或副方块失效，区间立即从权威数据中移除。
- 客户端渲染缓存按区间 UUID 失效，不应继续显示残留模型。
- 区间删除时，绑定的滑台连接会解除并恢复自然质心。
- 删除一个节点不会误删只经过该节点附近、但端点属于其他节点的区间。
