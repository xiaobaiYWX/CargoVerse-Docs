# 货柜定位点

货柜定位点把装载、卸载与生成区域从业务终端中拆分出来。

| 类型 | 资源 ID | 使用方 |
| --- | --- | --- |
| 货柜装载点 | `cargoverse:container_loading_point` | 货柜装载机，可绑定多个 |
| 货柜卸载点 | `cargoverse:container_unloading_point` | 货物卸载机，可绑定多个 |
| 货柜生成点 | `cargoverse:container_spawn_point` | 货柜制造台、许可证注册终端，各绑定一个 |

## 定位点 ID

每个定位点根据维度、类型和方块坐标生成稳定 ID。终端保存这些 ID，运行时由定位点注册表解析其世界位置、偏移和范围。定位点必须与终端绑定到同一贸易点实例。

## 默认区域

管理员模式下右键定位点打开配置界面，可编辑偏移原点和范围尺寸，也可复制定位点 ID 或显示范围。

| 参数 | 默认值 | 限制 |
| --- | --- | --- |
| 原点偏移 | `0, 1, 0` | 每轴 `-64..64` |
| 范围尺寸 | `16 × 8 × 16` | 每轴 `1..32` |

范围以定位点坐标加偏移后的原点计算，三个尺寸依次对应世界的 X、Y、Z 轴，并覆盖恰好 `宽 × 高 × 深` 个方块位置。配置由服务端校验并保存，客户端输入不能越过钳制范围。

## 绑定规则

- 装载机在所有有效装载点范围内收集候选货柜；
- 卸载机在所有有效卸载点范围内收集候选货柜；
- 制造台只向其单一生成点范围内生成货柜；
- 注册终端领取基础货柜时使用其单一生成点；
- 生成前会检查完整生成点范围；范围内存在非空气方块或与任意现存 Sable 物理结构相交时拒绝生成；
- 货柜模板尺寸必须能完整放入生成点范围；范围未完全加载、超出世界边界或配置无效时同样拒绝生成；
- 定位点缺失、类型不符或贸易点不一致时，业务请求失败；
- 终端不会使用自身坐标作为后备定位。

生成失败会区分显示“物理结构占用”“遮挡方块及其坐标”“范围未加载”“超出世界边界”“范围不足”等原因。普通货柜制造会在扣除虚空字节和库存材料前完成检查，实际放置模板前还会对模板占地执行最终复检。

自然生成结构在生成阶段写入贸易点实例绑定和对应定位点 ID。结构缺少所需定位点时，相关终端保持不可用。
