# 货柜连接器与货柜接口

货柜连接器和货柜接口用于在运输载具与货柜之间建立可控的物理锁定。它们是 CargoVerse 内部的货柜对接系统，不依赖 `simulated:docking_connector`。

## 方块 ID

| 方块    | ID                                   | 角色      |
| ----- | ------------------------------------ | ------- |
| 货柜连接器 | `cargoverse:cargo_docking_connector` | 主动搜索与控制 |
| 货柜接口  | `cargoverse:cargo_docking_port`      | 被动接受连接  |

两个方块均支持六个方向放置。只有正面相对、位于不同 Sable 物理结构上的连接器与接口才能配对。

## 货柜连接器

货柜连接器一般安装在运输载具、吊装设备或固定装卸设施上。

它负责：

- 接收红石控制信号。
- 搜索附近可用的货柜接口。
- 引导两个物理结构互相靠近。
- 在接口进入锁定范围后建立固定物理约束。
- 维护连接器组的共享状态。

### 状态

连接器具有三种 BlockState：

```text
off
searching
connected
```

| 状态 | 含义 |
|---|---|
| `off` | 关闭，不执行目标搜索 |
| `searching` | 搜索并引导可用接口 |
| `connected` | 已建立物理连接 |

关闭状态收到一次红石信号后进入搜索状态。搜索基础持续时间为 `100 tick`，即约5秒；发现有效目标后会刷新搜索时间，直到完成连接或目标失效。

连接状态再次收到红石信号时，当前接口组断开并返回关闭状态。

## 货柜接口

货柜接口是完全被动的目标方块，通常随货柜结构模板一起保存。

- 不接受红石控制。
- 不主动搜索连接器。
- 不配置接口组。
- 不传输物品、流体或动力。
- 只负责提供物理连接锚点。

一个接口同时只能参与一组有效物理连接。

## 接口组

多个货柜连接器可以配置为同一个接口组。接口组由以下内容共同区分：

```text
所在物理结构 UUID + 第一绑定物品 + 第二绑定物品
```

第一、第二绑定物品是有顺序的，同样两个物品交换槽位后会形成不同的接口组。

### 设置方式

连接器面板上有两个物品槽位。玩家必须对准对应的小面板区域右键，才能写入绑定物品；空手点击对应槽位可清除该槽位。

槽位中的物品只作为组标识：

- 不会从玩家物品栏消耗。
- 不作为连接目标的匹配条件。
- 不会写入被动货柜接口。
- 显示物品与点击命中使用同一份六向模型坐标变换。

### 共享状态

同一物理结构上的同组连接器共享红石和显示状态，避免一个连接器已连接而其他连接器错误进入搜索状态。

同一接口组同时只允许连接一个其他物理结构：

- 一个连接器被选为物理主连接器，负责建立实际约束。
- 组内其他连接器作为视觉副连接器，不额外创建物理约束。
- 副连接器只有通过对应货柜接口校验后才显示为已连接，并计入接口组的有效连接器数量。
- 若载具需要同时连接多个独立结构，应配置多个不同的接口组。

被动货柜接口不要求拥有相同组名或绑定物品。

### 副连接器校验

主连接器完成真实对接后，系统会在同组连接器中校验视觉副连接器。每个有效副连接器必须能在已连接的目标物理结构上匹配一个独立的货柜接口。

副连接器匹配需要满足：

- 主动连接器和被动接口分别位于当前连接的两个物理结构上。
- 两个接口的世界空间朝向相反。
- 新匹配的接口表面距离不超过 `0.20` 格。
- 已经建立的有效副匹配在距离不超过 `0.25` 格时可以继续保留，避免边界抖动。
- 被动接口没有参与其他真实连接或其他接口组的副连接校验。
- 一个副连接器只能匹配一个被动接口，一个被动接口也只能支持一个副连接器。

系统使用一对一最大匹配计算有效副连接器，避免多个副连接器重复占用同一个货柜接口。主连接器在真实约束有效时固定计为一个有效连接器，因此：

```text
有效连接器数量 N = 1 个主连接器 + 通过校验的副连接器数量
```

副连接器校验结果不仅影响方块显示状态，也直接影响接口组的承载能力。

## 搜索与物理锁定

连接器以约5格范围搜索可用货柜接口。搜索目标必须满足：

- 位于另一个 Sable 物理结构。
- 本地方块朝向互为相反方向。
- 世界空间中的接口法线基本相对。
- 当前不存在冲突的结构间连接。

搜索阶段向两个结构施加相向线速度。接口表面进入约 `0.2` 格的锁定范围后创建固定约束。

### 角度对齐

锁定时会精确对齐两个接口的法线，但不会强制所有货柜归到唯一世界角度。

绕接口法线的滚转角按以下等价姿态处理：

```text
0° / 90° / 180° / 270°
```

系统选择距离锁定瞬间相对姿态最近的候选角度，因此滚转修正最大不超过45°。这样可以保证两个方块视觉对齐，同时减少意外的大幅旋转。

## 超载断裂与阈值计算

货柜接口组建立固定约束并完成对齐后，会读取 Sable `getJointImpulses()` 返回的最新约束冲量。Sable 分别提供世界空间中的线性冲量向量和角向冲量向量。

由于冲量会随物理子步长度变化，系统先用当前物理子步时长换算为等效载荷：

```text
线性载荷 F = |线性冲量| / Δt
角向载荷 T = |角向冲量| / Δt
```

其中：

- `Δt` 是当前 Sable 物理子步时长，而不是固定写死的游戏 tick 时长。
- `F` 是用于断裂判断的等效线性力。
- `T` 是用于断裂判断的等效角向力矩。

接口组的总阈值由有效连接器数量线性累加：

```text
线性阈值 F_limit = N × linearCapacityPerConnector
角向阈值 T_limit = N × angularCapacityPerConnector
```

负载率分别计算线性和角向占用，最终取较大者：

```text
线性负载率 = F / F_limit
角向负载率 = T / T_limit
接口负载率 R = max(线性负载率, 角向负载率)
```

当 `R >= 1.0`，即接口负载率达到或超过 `100%` 时，系统会将该组约束加入断裂队列，并在安全的服务器 tick 阶段断开整个接口组。线性载荷或角向载荷任意一项超过各自阈值都会触发断裂，目前不进行平滑、平均或多 tick 连续超载判定。

例如，单连接器线性容量为 `100000`，当前有三个有效连接器，则接口组线性阈值为：

```text
3 × 100000 = 300000
```

若同一时刻线性载荷为 `210000`，角向载荷为 `240000`，并且两项单连接器容量均为 `100000`，则：

```text
线性负载率 = 210000 / 300000 = 70%
角向负载率 = 240000 / 300000 = 80%
接口负载率 = max(70%, 80%) = 80%
```

### 配置项

阈值位于服务端配置的 `cargoDockingOverload` 节点：

| 配置项 | 默认值 | 作用 |
|---|---:|---|
| `linearCapacityPerConnector` | `100000.0` | 每个有效连接器贡献的等效线性力容量 |
| `angularCapacityPerConnector` | `100000.0` | 每个有效连接器贡献的等效角向力矩容量 |
| `graceTicks` | `2` | 十二 tick 对齐完成后继续忽略约束冲量的游戏 tick 数 |

十二 tick 的约束对齐期间不会执行超载断裂；对齐完成后还会应用 `graceTicks`，避免创建和收敛约束时的瞬时冲量被误判为正常运行载荷。

### 与货柜质量和速度变化的关系

在线性方向，可以用经典冲量关系粗略估算载荷：

```text
线性冲量 J ≈ m × Δv
线性载荷 F ≈ m × Δv / Δt
```

因此，更重的货柜、更短时间内的速度变化以及碰撞冲击都会提高线性载荷。角向部分近似为：

```text
角向冲量 L ≈ I × Δω
角向载荷 T ≈ I × Δω / Δt
```

其中 `I` 为相对约束轴的转动惯量。货柜质心距离接口较远时，即使线性运动不剧烈，也可能因为较大的力臂优先触发角向阈值。质量与线速度不足以单独确定角向阈值，实际配置应结合真实载具布局采样。

## 推荐工作流

1. 在运输载具上放置一个或多个货柜连接器。
2. 使用两个物品槽位为需要联动的连接器设置相同接口组。
3. 在货柜结构模板中放置被动货柜接口。
4. 让连接器与接口正面大致相对并进入搜索范围。
5. 给予连接器组一次红石信号。
6. 等待磁力引导与固定约束建立。
7. 再次发送红石信号以断开连接。

## 与货运电磁铁的区别

货柜连接器面向可编组、可控制的标准货柜装卸，包含接口组、视觉副连接器和离散角度对齐。

货运电磁铁是更简单的通用物理连接装置，不使用接口组，也不进行姿态对齐。详见[货运电磁铁与磁吸板](07_货运电磁铁与磁吸板.md)。

## 注意事项

- 当前系统只负责物理连接，不传输物品、流体、红石或动力。
- 连接器和接口必须属于不同的物理结构。
- 只有通过一对一校验的副连接器才会增加承载阈值；仅在视觉上靠近但未通过校验的连接器不提供容量。
- 断裂判定使用单个物理子步的瞬时峰值，剧烈碰撞可能立即触发断裂。
- 大量接口集中在很小范围时，应使用不同接口组控制主动连接器，减少目标歧义。
- 模板中的接口朝向应与预期装卸方向一致。
