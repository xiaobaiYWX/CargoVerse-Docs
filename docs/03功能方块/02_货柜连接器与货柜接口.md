# 货柜连接器与货柜接口

货柜连接器和货柜接口用于把货柜与运输载具锁定连接。它们是本模组内部的对接系统，不再依赖原版 `simulated:docking_connector`。

## 方块 ID

货柜连接器：

```text
cargoverse:cargo_docking_connector
```

货柜接口：

```text
cargoverse:cargo_docking_port
```

## 角色区别

### 货柜连接器

货柜连接器是主动方。

- 可以被红石激活。
- 激活后会寻找附近可连接的货柜接口。
- 会产生磁力引导。
- 满足距离和朝向条件后建立锁定。

### 货柜接口

货柜接口是被动方。

- 不会被红石激活。
- 不会主动寻找连接器。
- 只作为货柜连接器的连接目标。
- 适合放在货柜模板上。

## 使用方式

1. 在运输载具上放置货柜连接器。
2. 在货柜结构模板上放置货柜接口。
3. 让连接器正面对准接口。
4. 使用红石信号激活连接器。
5. 连接器会引导靠近接口，并在对齐后锁定。

## 注意事项

- 当前设计不传输物品，只负责物理连接。
- 货柜接口不会反向连接货柜连接器。
- 如果多个接口距离过近，应避免同时存在多个可能目标，防止连接目标不符合预期。
- 推荐让连接器和接口的正面完全相对。
