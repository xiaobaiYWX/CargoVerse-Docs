# 便携储罐与虚空结算器

## 虚空结算器

`cargoverse:void_settlement_unit` 是仅有物品形态的实体钱包，用于保存和转移虚空字节。虚空字节的资源 ID 为 `cargoverse:void_byte`，界面和仪表统一使用缩写 `VB`。

- 物品不可堆叠；
- 余额为非负 `long` 数据，不设置日常可达的储存上限；
- 交易只识别玩家主物品栏和副手携带的结算器；
- 支出可依次从多台结算器扣除；
- 收入写入扫描到的第一台结算器；
- 未携带结算器时不能完成需要付款或收款的交易；
- 支付、发放或后续事务失败时，余额通过补偿记录恢复。

虚空结算器没有方块形态，也不读取世界中的储罐、管道或虚空混合物作为交易余额。

## 便携储罐

`cargoverse:portable_tank` 同时具有方块和物品形态，容量固定为 `10000 mB`，只接受虚空混合物。

- 放置后可以使用普通流体容器灌入或取出；
- 作为物品时通过 NeoForge 物品流体能力与兼容设备交互；
- 方块的流体能力只在底面开放，其他方向不能连接管道；
- 破坏并拾取后保留内部流体，重新放置时恢复；
- 世界方块和物品模型都会按实际储量显示内部液体；
- 方块碰撞箱按紧凑模型尺寸设置，不占满整个方块空间。

## 虚空混合物

`cargoverse:void_mixture` 是不会自然生成、不会形成无限液源的流体。它可由桶装取和放置，也可通过通用流体管道与兼容储罐运输和保存。

虚空混合物与虚空字节属于同一设定链路，但当前版本没有实现二者之间的转换。交易系统不会把便携储罐内的虚空混合物识别为货币。

完整结算规则和设定见[虚空字节与虚空混合物](../07货币系统/01_虚空字节与虚空混合物.md)。
