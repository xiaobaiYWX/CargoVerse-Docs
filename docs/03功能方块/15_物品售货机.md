# 物品售货机

`cargoverse:item_vending_machine` 是两格宽、三格高的大型世界表面终端。前排工作台占半格深度，后排柜体为三格高；右前下方成员是控制器，左前下方成员兼作出货交互区。

## 放置与绑定

- 放置时一次检查并生成全部成员；空间不足则拒绝放置。
- 任意成员交互都会解析回控制器。
- 管理员模式右键可打开传统管理员 GUI，只设置贸易点 UUID。
- 手动放置后 UUID 默认为空；终端模型与仪表仍显示，但内容为空／未绑定。
- 商店定义来自贸易点注册记录的 `modules.item_shop`，终端不接受定义路径和默认定义回退。

## 世界表面内容

- 五行商品图标、名称、可购买余量和选中灯；
- 当前总费用与页码；
- 上／下商品选择按钮；
- `1..10` 购买数量滑轨；
- 绿色 `BUY` 按钮。

仪表基座是终端模型的一部分，不是运行时占位模型。内容、实体按钮和滑轨由世界表面 UI 渲染；模型、命中面与高亮边框均从组件锚点推导。

## 购买与库存

服务器在统一串行事务内重新读取贸易点、模块、offer、数量、货币和 output stock。`output_costs` 只按标签匹配贸易点已有的具体 CargoGood 行，不生成库存类型。支付、库存扣除、暂存物和经济记账任一步失败都会触发逆序补偿。

商品余量是当前 output stock 能满足该 offer 的购买次数，不是售货机本地库存。详细数据格式和匹配顺序见[物品售货机与商店定义](../04商店系统/01_商店体系.md)。

## 公共待领取区

购买成功后，结果物品写入售货机控制器的持久化待领取区：

- 不直接进入购买者背包；
- 任意玩家可右键左前下方出货成员领取；
- 满背包时不提取并提示；
- 只有部分空间时只提取实际可插入数量，其余继续留在终端；
- 普通领取不向地面抛出溢出物；
- 待领取区非空时才渲染出货箱模型；
- 拆除任意成员会清理整个结构，并在控制器位置把剩余物品掉落一次。
