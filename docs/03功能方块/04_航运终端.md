# 航运终端

航运终端用于查看和管理当前玩家名下的货柜实例，并显示玩家的运输许可等级与升级进度。货柜归属按玩家单独记录，不支持队伍共享。

注册 ID：

```text
cargoverse:shipping_terminal
```

## 货柜列表

右侧列表显示玩家当前持有的全部货柜。列表条目包含：

- 货柜名称
- 货柜等级
- 购买价格
- 当前状态：`运输中` 或 `已失效`

选择条目后，界面会显示对应结构预览和货柜详细信息。列表可按状态、价格、类型和等级排序。

## 运输许可

运输许可是 Cargoverse 独立维护的玩家经验系统。玩家成功出售带词条货柜后，会以货物类型常量的 `license_experience` 经等级与模板倍率修正后的结果为基础，根据当前完整度计算实际经验：`100%` 完整度获得 `10%` 奖励，`90%～不足100%` 获得完整经验，低于 `90%` 后线性降低。无词条货柜没有完整度，直接获得基础经验，不享受完美运输奖励。

许可等级依次为：

```text
S -> M -> L -> X -> XL
```

各等级使用累计许可经验判定：

| 许可等级 | 所需累计经验 |
| --- | ---: |
| `S` | `0` |
| `M` | `100` |
| `L` | `200` |
| `X` | `400` |
| `XL` | `800` |

买入终端会根据玩家当前许可等级限制可购买的货柜。未达到要求的货柜可以查看，但不能购买。`SP` 是特殊货柜等级，不属于普通许可升级序列。

航运终端顶部显示：

- 当前许可等级
- 当前等级进度百分比
- 下一许可等级
- 距离升级仍需的经验

## 删除货柜

航运终端可以删除选中的货柜实例。删除会同时清理对应物理结构和运行时记录。

### 有效货柜

- 可以删除。
- 返还实际购入资源的 `50%`。
- 返还数量按整数计算，小数部分舍去。

### 已失效货柜

- 可以删除。
- 不返还任何资源。
- 按钮会显示“删除货柜（无返还）”，用于提示该操作没有退款。

删除操作不可撤销。若货柜仍有出售价值，应优先运输至出售终端完成交易。

## 管理命令

服务器管理员可以使用以下命令清除自己或指定玩家的许可经验，并将等级重置为 `S`：

```text
/cargoverse license reset
/cargoverse license reset <targets>
```

该命令需要权限等级 `2`。
