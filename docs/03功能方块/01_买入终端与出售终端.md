## 制造台

候选来自贸易点注册时抽取的 `cargo_manufacturing_platform` 定义。制造时由服务端重新校验贸易点绑定、配方可见性、繁荣度、运输许可证、玩家调度点预算、货币、实时 `input_stock` 材料、生成空间和结构可用性；成功后创建满耐久、空 Load、带所有权的货柜并生成物理结构。存量占用超过预算时只禁止新增，不删除已有货柜。

材料严格从贸易点已经存在的输入库存中匹配与扣除，不会按标签凭空创建货物。货币、材料扣除和结构生成处于同一补偿事务；失败时恢复已扣资源。管理员可配置贸易点实例 UUID 和生成偏移。

制造台是仪表瞄准提示的第一版实机接入基准。玩家瞄准仪表时，边框直接沿组件实际绘制范围高亮，用途文字显示在准星旁；内容为空或终端未绑定时仍保留识别能力。当前映射为：

| 模型区域 | 准星提示 |
| --- | --- |
| 顶部名称／页码 | 货柜名称／制造配方页码 |
| 左侧 Cargo Class 投影 | 可运输货物类型 |
| 右侧缩微胶卷 | 货柜说明 |
| 五个特性图标 | 可满足运输要求 |
| 调度点字符牌 | 占用调度点 |
| 容量／空重／耐久字符牌 | 最大载货量／空货柜质量／最大耐久 |
| 三行材料图标、名称和状态灯 | 制造材料／制造材料库存状态 |
| 底部价格字符牌 | 制造费用 |
| 右侧三维投影底座 | 货柜模型预览 |

## 装卸设备

货柜装载机与货物卸载机都采用世界表面 UI：常用选择、数量和确认操作直接在模型表面完成，管理员模式右键才打开贸易点 UUID 与扫描范围配置界面。两者复用同一批封装仪表、按钮、滑轨及服务端射线校验，但各自拥有独立业务服务。

- 装载机从贸易点输出库存购买 CargoGood，扣除货币和库存后更新货柜 Load 与物理质量；详见[货柜装载机](13_货柜装载机.md)。
- 卸载机把柜内 CargoGood 卸入当前贸易点需求库存，根据数量、价格修正与完整度结算，并更新货柜 Load 与物理质量；详见[货物卸载机](14_货物卸载机.md)。

客户端展示快照只用于显示。按钮与滑轨动作进入服务端后会重新检查距离、结构、权限、所有权、贸易点状态、库存、容量、兼容性和币种，不能用客户端显示结果直接修改资产。

## 已删除的旧入口

- `cargoverse:cargo_loading_terminal`：方块、菜单、Screen、网络与资源均已移除；
- `cargoverse:cargo_handling_terminal`：方块、菜单、Screen、扫描支持、网络与资源均已移除；
- `cargoverse:cargo_assembly_terminal`：旧单方块、方块实体、菜单、Screen、网络包、贴图和专属业务均已移除；
- `cargoverse:shop_terminal`：旧方块、方块实体、购物车 Screen／Menu、网络包、贴图和旧商店定义链均已移除；
- 旧固定 `413×233` 装卸 GUI 与 `CargoTransferScreenSupport` 不再是当前架构；
- `cargoverse:trade_point_terminal` 的经济仪表板 GUI 已移除，经济摘要由贸易点信息柜的世界表面仪表承担。

不提供旧方块或旧菜单的兼容迁移层。旧开发存档如仍含这些已删除 ID，应先备份并在测试环境处理。

## 仍需验收

- 空柜→装货→运输→部分卸货→卸空→重新装载的完整闭环；
- 多玩家争用同一库存、支付或持久化失败时的事务补偿；
- 装卸后的实体贴花、词条、质量和存档重进一致性；
- 六向、多方块、不同 FOV 与运动结构下的世界表面位置和命中。
