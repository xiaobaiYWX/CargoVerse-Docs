# 重型接口与重型连接点

重型接口系统用于在一个固定设施或物理结构与另一个运动中的物理结构之间建立可旋转的轴承连接。它是独立于“货柜连接器与货柜接口”的全新系统，不复用旧系统的红石控制、接口组、磁力引导或固定锁定逻辑。

## 方块组成

| 方块      | ID                                        | 角色                            |
| ------- | ----------------------------------------- | ----------------------------- |
| 重型接口    | `cargoverse:heavy_docking_interface`      | 主动端；接收 Create 旋转动力并控制闭合、搜索和解锁 |
| 重型接口副方块 | `cargoverse:heavy_docking_interface_part` | 随主方块同步生成；提供实际捕获中心和接口侧模型       |
| 重型连接点   | `cargoverse:heavy_connection_point`       | 独立放置的专用被动端；只能被重型接口捕获          |

“重型接口”在物品栏中只有一个物品。放置主方块时，系统会在其朝向一侧同步生成副方块；副方块不能作为独立物品取得。重型连接点则是另一个完整、独立的方块物品，并不是重型接口的第三部分。

该系统不与以下既有系统交叉配对：

- `cargoverse:cargo_docking_connector` 与 `cargoverse:cargo_docking_port`。
- 货运电磁铁与磁吸板。
- Sable 或其他模组提供的通用连接器。

## 放置、碰撞与旋转

重型接口只能水平放置，主方块前方必须有可替换空间以容纳副方块。任一部分被正常破坏时，整套双方块结构会一并清理。

- 主方块保留完整碰撞箱和选择框。
- 副方块没有碰撞箱，但保留完整一格选择框，便于瞄准和使用扳手。
- 重型连接点的碰撞箱跟随模型，只占模型所在的半格厚度，不按完整方块处理。

重型接口未建立持久轴承连接时，可手持 Create 扳手右键主方块或副方块，使整套接口绕 Y 轴顺时针旋转90°。目标位置被占用时不会旋转；若当前存在尚未完成的临时捕获，旋转前会先释放临时约束和目标预留。

## Create 动力输入

重型接口使用 Create 动力网络驱动，但不是同轴传动。它按类似动力合成器的方式接受侧向小齿轮啮合：

- 动力轴线与接口水平朝向轴一致。
- 只能通过侧面齿轮啮合传递转速。
- 接口端面不提供轴杆连接。
- 方块对动力网络施加 `6 SU` 应力负载。

控制量是带方向的 RPM，而不是红石信号或单纯的“是否有应力”。正向旋转累计闭合行程，反向旋转累计解锁行程；停止转动不会继续推进。

完整闭合或解锁需要累计 `4` 转。理论行程时间为：

| 输入转速 | 单向完整行程 |
|---:|---:|
| `32 RPM` | 约7.5秒 |
| `64 RPM` | 约3.75秒 |
| `256 RPM` | 约0.938秒 |

正反方向由方块朝向换算。如果输入后闭合进度始终保持为零，应通过齿轮箱或反向齿轮改变转向。

## 状态与搜索窗口

运行状态依次为：

```text
未连接
  → 正转闭合并搜索
  → 捕获后临时对齐
  → 行程闭合且对齐完成
  → 持久轴承连接
  → 反转解锁
  → 未连接
```

搜索只发生在从未连接状态向闭合阈值推进的过程中，接口不会在完全打开且静止时持续扫描世界。

当同一对物理结构之间有多个重型接口同时进入捕获阶段时，它们按结构对共用一个临时固定引导约束，避免多个引导目标互相施加冲量。最先捕获者只负责临时引导，不自动成为最终主接口。引导结束时系统重新检查全部候选，从满足最终容差的候选中选择综合位置和轴向误差最小者作为主接口；如果没有候选合格，则整个组不会建立最终约束。主接口在自己的机械行程完全闭合时按当前位置建立旋转约束；其他接口保留候选与端点预留，必须分别等到自身机械行程完全闭合后再独立验收。轴承中心误差不超过 `0.5` 格且 West/East 轴线夹角不超过 `5°` 时按各自当前位置建立旋转约束，不会被强制吸附到标准锚点。未达到容差的接口释放连接点并禁止重新捕获，直到机械行程完全释放；它不会影响主接口或其他合格接口。位置容差固定为 `0.5` 格，不随世界坐标或距原点距离变化。

- 闭合未完成时停止动力：立即取消候选，释放临时锁定，并回到未连接状态；已累计的机械行程保留。
- 已闭合但没有捕获目标：进入“已闭合但空置”状态；必须先反转释放，再重新正转，才能开始新的完整搜索行程。
- 已建立连接后继续正转：保持闭合和连接，不会重复搜索。
- 已连接后反转：进入解锁状态，只有行程完全退回零点时才移除轴承约束。

## 捕获条件

捕获中心是重型接口副方块的世界空间中心。重型连接点必须同时满足以下条件：

1. 连接点中心位于捕获中心半径 `0.6` 格内。
2. 连接点与接口不属于同一个 Sable 物理结构。
3. 连接点必须位于运动中的 Sable 物理结构上。
4. 双方模型的 West-East 轴在世界空间中的无符号夹角不超过 `30°`。
5. 该连接点未被其他重型接口预留或连接。

接口主副方块可以作为普通世界方块安装，此时世界被视为静止侧，运动结构上的重型连接点仍可与其连接。双方都是普通世界方块时不会创建物理连接。

系统没有磁力引导阶段。候选一旦进入范围并通过方向检查，就直接进入临时对齐。

## 临时对齐与最终轴承

捕获后系统先创建临时固定约束，并在 `12 tick` 内逐步完成以下修正：

- 将双方锚点重合。
- 将双方 West-East 转轴对齐。
- 保留转轴正反方向的等价性，避免不必要的180°翻转。

同一对物理结构开始捕获时，系统先短暂收集同批候选，并在施加物理引导之前按初始位置误差和轴向误差选出唯一主接口。主接口一旦确定，本轮对接不再更换；只有主接口能够建立并推进共享临时固定约束，其他接口只作为从属候选，不会改变结构姿态。

主接口完成 `12 tick` 对齐并走完闭合行程后，先在主接口位置建立最终旋转约束。随后其他接口分别按 `0.25` 格位置容差和 `5°` 轴向容差进行校验：合格者直接在当前位置建立旋转约束。该约束的两侧锚点和局部转轴都会由锁定瞬间的世界位置、世界轴向反算，保证约束创建时位置误差和角度误差均为零，不再由物理引擎强制拉齐；不合格者释放预留并判定本轮锁定失败，完全反向释放前不会再次捕获。

最终化组使用单调的 `WAITING_FOR_MAIN → MAIN_LOCKED / MAIN_FAILED` 状态。慢速从属接口等待主接口期间，如果主接口反转、被破坏、端点失效或物理连接失效，组会进入 `MAIN_FAILED` 并立即通知所有尚未提交的从属接口释放候选和端点预留，避免永久停留在搜索状态。

最终连接允许双方绕指定轴旋转，不会像普通货柜接泊器一样把全部相对自由度永久固定。

## 模型锚点

锚点使用模型空间中的 0—16 坐标：

| 端点 | 锚点 `(X, Y, Z)` | 所在方块 |
|---|---|---|
| 重型接口 | `(5, 10, 8)` | 副方块 |
| 重型连接点 | `(5, 12, 8)` | 连接点方块 |

代码会根据各自水平朝向旋转这些局部坐标。修改模型时，必须同步核对锚点、West-East 转轴、方块状态旋转和碰撞箱，不能只调整可见几何。

## 存档与运行时边界

重型接口会保存闭合进度和逻辑连接记录。连接记录不保存会随结构移动而变化的世界坐标，而是保存：

- 对端 Sable 结构 UUID。
- 相对该结构 Plot 中心的局部方块坐标。
- `CANDIDATE`（临时对齐）或 `CONNECTED`（轴承连接）恢复阶段。

Sable 的临时固定约束和旋转约束句柄仍是运行时对象，不会直接序列化。区块或服务器重新载入后，接口会优先进入有界恢复队列，以指数退避等待双方结构和方块实体加载：候选阶段重新建立临时对齐，已连接阶段重新预留连接点并创建旋转约束。每个接口最多尝试 `120` 次，单次退避最长 `200 tick`，避免每 tick 无限制重试。

运行中的接口也使用三态端点验证：`VALID` 继续维护当前约束；`WAITING` 表示子世界、区块或方块实体暂未就绪，此时保存当前阶段并转入恢复队列；只有 `INVALID` 才代表端点确认永久失效并立即断开。该判定不依赖方块实体卸载回调一定按预期顺序触发。

若记录指向的结构或连接点确认无效，或者恢复预算耗尽，系统会清理残留预留与约束。原已连接记录明确降级为“已闭合但空置”状态，之后需要先反转完全打开，再重新正转捕获；不会用附近的其他连接点猜测替代目标。

重型连接点通过按维度和空间分桶维护的专用索引参与搜索。索引与占用表同样使用“结构 UUID + 局部坐标”作为连接点身份，避免不同移动结构具有相同局部坐标时互相覆盖。正常拆除和空间查询发现的惰性失效共用同一清理入口，都会删除空间记录、释放占用，并通知当前接口处理恢复或永久断开。新增逻辑不得改为扫描全世界方块，也不得把它注册到普通货柜接口索引中。

## 使用流程

1. 在固定设施或一个物理结构上放置重型接口，并为副方块预留一格空间。
2. 在另一个运动中的 Sable 物理结构上放置重型连接点。
3. 调整两者，使中心距离不超过0.6格且 West-East 轴夹角不超过30°。
4. 用 Create 小齿轮从侧面向主方块输入正确方向的旋转动力。
5. 保持动力，直到临时对齐和8转闭合行程全部完成。
6. 需要断开时反向输入动力，直到行程完全回到零点。

## 排查清单

无法捕获时依次检查：

1. 使用的是“重型连接点”，而不是普通货柜接口。
2. 动力确实传入主方块，主方块具有非零 RPM。
3. 转向为闭合方向，且动力保持时间足以完成8转行程。
4. 连接点位于运动中的 Sable 结构上，且双方不是同一个结构。
5. 测量的是副方块中心与连接点中心之间的距离。
6. 双方 West-East 轴夹角没有超过30°。
7. 连接点没有被另一套重型接口占用。
8. 接口若处于已闭合空置状态，先反转完全打开后再试。
