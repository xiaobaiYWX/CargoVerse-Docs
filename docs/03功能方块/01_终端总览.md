# 终端总览

## 终端职责

| 方块 | 资源 ID | 业务 |
| --- | --- | --- |
| 贸易点信息柜 | `cargoverse:trade_point_info_cabinet` | 注册贸易点实例、绑定定义并显示经济摘要 |
| 生产线终端 | `cargoverse:production_line_terminal` | 展示贸易点生产线与槽位状态 |
| 仓库信息柜 | `cargoverse:warehouse_info_cabinet` | 分页展示输入、输出库存 |
| 货柜制造台 | `cargoverse:cargo_manufacturing_platform` | 展示配方并扣除材料、货币，生成空货柜 |
| 货柜装载机 | `cargoverse:container_loader` | 购买贸易点输出货物并装入玩家货柜 |
| 货物卸载机 | `cargoverse:cargo_unloader` | 卸出货物、写入贸易点输入库存并结算 |
| 物品售货机 | `cargoverse:item_vending_machine` | 使用贸易点输出库存出售普通物品 |
| 许可证注册终端 | `cargoverse:license_registration_terminal` | 注册、注销运输许可证并领取基础货柜 |
| 货柜机械台 | `cargoverse:cargo_machinery_terminal` | 展示维修、改装与清理入口的占位信息 |
| 整柜收购终端 | `cargoverse:sell_terminal` | 独立整柜收购，成交后移除货柜 |

`cargoverse:trade_point_terminal` 与 `cargoverse:shipping_terminal` 是普通装饰方块，不持有方块实体、菜单或业务状态。

## 共享数据

贸易点信息柜是实例注册锚点。业务终端保存贸易点实例 UUID，并通过注册表读取同一份定义、模块选择、库存和经济状态。贸易点定义 ID 与实例 UUID 是两类标识，不能混用。

手动放置的终端不会自动选择默认贸易点。绑定为空、实例不存在或定义未加载时，终端保持不可用；模型、仪表基座与控件照常绘制，主仪表显示未绑定，其余业务内容留空。

## 定位职责

装卸与货柜生成不再以终端方块为扫描或生成原点：

- 装载机绑定一个或多个货柜装载点；
- 卸载机绑定一个或多个货柜卸载点；
- 货柜制造台与许可证注册终端各绑定一个货柜生成点。

没有有效定位点时，对应业务不可用，也不会回退到终端坐标。定位点格式见[货柜定位点](16_货柜定位点.md)。

## 交易边界

客户端快照只负责显示。服务端处理按钮动作时重新检查玩家距离、终端结构、权限、许可证、货柜所有权、定位范围、贸易点状态、库存、容量、兼容性和币种，并在事务内完成货币、库存、资产与统计更新。

货柜制造成功后创建满耐久、空载、带所有权的货柜；装载修改货柜 Load 并扣除输出库存与货币；卸载修改 Load、增加输入库存与货币，并记录许可证经验、航运风格和制造商声望。物理质量与贴花在事务提交后进入统一刷新队列。
