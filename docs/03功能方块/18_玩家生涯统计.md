# 玩家生涯统计

玩家生涯统计独立于运输许可证存在。许可证注销会清除当前许可证、许可证经验和航运风格窗口，但不会删除或归零生涯统计；玩家重新注册后继续在原有数值上累计。

权威数据保存在 `PlayerCareerStatisticsSavedData`。打开个人航运档案时，服务端把第四章当前需要的只读统计合并进档案快照；客户端不自行推算或修改生涯数据。

## 统计字段

| 字段 | 口径 |
|---|---|
| 累计承运量 | 每个完成航段的启运货物数量之和 |
| 累计运输质量 | 每个完成航段的启运数量乘启运时货物单位质量 |
| 累计成功交付量 | 成功卸货出售的货物数量之和 |
| 累计成功交付质量 | 成功出售数量乘货物快照中的单位质量 |
| 完成航段数 | 从一个贸易点前往另一个贸易点并在目的地发生有效货物操作的次数 |
| 货物销售总收入 | 成功卸货后实际发放的金额，包含所有价格与完整度修正 |
| 货物采购总支出 | 装货时实际扣除的货物采购金额，不包含货柜制造和物品商店消费 |
| 净运输收益 | `货物销售总收入 - 货物采购总支出`，查询时派生 |
| 损耗货物总量 | 航段数量损失与完整度下降折算量之和；删除仍装有货物的个人资产时，剩余货物按全损累计 |
| 最高单次收入 | 一次成功卸货实际获得的最高金额 |
| 造访贸易点数量 | 发生过有效装货或卸货交易的不同贸易点 ID 数量 |

第四章左页显示全部生涯统计字段，其中“损耗货物总量”以平均货损率呈现。页面同时按货物分类累计承运量与运输质量，以累计承运量最高的分类作为“最喜爱的货物类型”；承运量相同时依次比较运输质量和固定分类顺序。该分类的累计承运量与运输质量显示在右页。

右页“近期航段”保存并显示最近 8 次成功交付，按完成时间从新到旧排列。每行显示服务器完成交易时的日期、货物图标和本次净利润；悬停货物图标显示货物名称。部分交付的采购成本按交付前后载荷中保存的实际采购成本差额计算，因此每份成本只会进入一次净利润。

货币统计统一使用 CargoVerse 的结算数值，不保存货币 ID。

## 航段损耗

```text
数量损失 = max(0, 启运数量 - 到达数量)
完整度损耗折算 = 到达数量 × (1 - 到达完整度 / 启运完整度)
总损耗 = 数量损失 + 完整度损耗折算
平均货损率 = 累计总损耗 / 累计承运量
```

平均货损率按货量加权并钳制在 `0%～100%`，无已完成承运时显示 `0%`。航段候选保存启运货物单位质量和货物分类，因此后续数据包修改货物定义不会改写已经累计的运输质量或分类历史。

## 写入时机

- 装货事务成功：累计货物采购支出并登记贸易点；若该操作结束一个跨贸易点航段，同时累计航段数据。
- 卸货事务成功：累计交付量、交付质量、销售收入和最高单次收入，并登记贸易点；若该操作结束一个跨贸易点航段，同时累计航段数据。
- 旧识别器整柜回购成功：使用相同的交付、收入和航段口径。
- 玩家从航运档案删除装有货物的货柜，或维护系统因过期清理该资产：剩余货物计入全损。

装货机和卸货机的生涯统计写入与资产、贸易点库存、货币、许可证和航运风格共同进入交易补偿链。事务失败时恢复玩家写入前的完整生涯统计行，避免出现只记账而交易未完成的情况。
