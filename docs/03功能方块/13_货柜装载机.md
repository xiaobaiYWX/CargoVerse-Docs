# 货柜装载机

`cargoverse:container_loader` 是大型多方块世界表面终端，用于从贸易点出售目录购买货物并装入玩家货柜。普通玩家直接操作模型表面的仪表、按钮和滑轨。

## 结构与绑定

- 控制器统一渲染完整模型，成员方块不重复绘制；
- 放置时检查全部结构格，拆除成员会清理完整结构；
- 手动普通点由管理员使用终端连接工具绑定，绑定后保存实例和定位点关系；自然生成结构内绑定锁定；
- 终端在所有有效装载点的范围合集内只识别一个货柜：优先选择距任一装载点中心最近者，距离相同时选择货柜 ID 较小者；
- 没有有效贸易点或装载点时，仪表保留外观并显示未绑定，装载操作不可用。

定位点规则见[货柜定位点](16_货柜定位点.md)。

## 世界表面内容

竖直面板显示货柜名称、当前实际数量／容量、当前质量、物品名称与装载率，以及计划装载数量和质量。倾斜控制台显示候选物品图标与名称、词条、贸易点库存、单位质量、总价、数量滑轨和确认按钮。不显示独立完整度，也不存在货柜本体耐久。

控件包括：

- 左／右箭头切换可购买货物；
- 数量滑轨选择本次装载单位数；
- `LOAD` 按钮提交交易。

模型、命中区域、高亮和动画均由公共组件放置数据推导。

## 装载交易

服务端重新识别当前唯一货柜，并验证许可证、玩家所有权、货柜状态、定位范围、精确物品身份、容器兼容性、现有 Load、剩余容量、贸易点出售报价，以及玩家携带的虚空结算器和 `VB` 余额。检测范围内的其他货柜不会通过按钮切换或参与本次交易。

```text
单位价格 = 本站出售 unit_price × 动态价格修正 × 签约运输员买价修正
总价 = 单位价格 × 装载数量
```

签约运输员修正只在玩家许可证签发制造商与贸易点制造商一致时使用，并在其他价格修正之后计算。有库存条目的有效数量受出售库存限制，无库存条目不受贸易点库存限制；剩余容量不足时整次请求失败，不自动截断至容量。

成功后从玩家携带的一台或多台虚空结算器扣除 `VB`，按规则扣除出售库存，并更新货柜 Load、取得成本和物理质量。追加要求精确身份与运输快照一致，先结算旧时限损耗再刷新保护期，不恢复已损失物品。结算器余额、库存、货柜资产与贸易点记账处于同一服务端串行补偿事务。

事务提交后，货柜质量和实体贴花进入统一物理刷新队列。同一货柜的连续交易使用 `20 tick` 尾触发合并。
