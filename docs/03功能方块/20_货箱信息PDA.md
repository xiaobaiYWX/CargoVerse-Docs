# 货箱信息 PDA

物品 ID：`cargoverse:cargo_information_pda`。PDA 是货柜运行时的便携查看入口，不代替航运手册的资产目录，也不控制贸易交易。

## 简短 HUD

主手或副手手持 PDA、准星对准附近货柜时显示三项信息：

- 货柜名称；
- 实际运输货物的图标与数量，不直接显示货物名称；
- 归属玩家。

航运手册、护目镜或仅放在背包里的 PDA 不启用该 HUD。切换物品、移开准星或打开界面后隐藏。查询附带目标位置及维度，迟到的旧目标回复不覆盖当前显示。切换瞄准方块优先查询；同一目标显示后每 10 tick 刷新，尚未取得信息时每 4 tick 重试。服务端每 2 tick 接受一次请求，被限频拒绝不会推迟后续查询。

## 右键详情

手持 PDA 右键目标货柜打开状态 GUI，优先于被点击方块自身的交互，也不被货柜的常规交互保护拦截。可查看货物图标、名称及数量，货物购入总价、货柜含载荷的总质量、所有者、运输损耗和近期内部状态。读取与打开沿用点击/查询位置并校验持有物、距离、已加载状态和资产，不再通过服务端重复射线要求准星同步到完全相同的方块。

- 图集：`textures/gui/cargo_inspection.png`，原生 256×256，顶部、损耗卡、读数卡、清空按钮和侧边标签分别裁取拼装。底部按钮栏裁取 `(0,235,117,21)`，读数三段裁取起始行为 189、210、228，跳过透明分隔行；按钮命中区按新版 46×16 同步。
- 侧边按实际能力绘制图标；能力较多时像效果栏一样压缩间距重叠，不只保留前三项。悬停查看解释。
- 读数包括适用的温度 TU、相对压力、湿度、光照、密封/围护等级、速度窗口变化、倾角和剩余老化预算。一次显示两行，滚轮查看其余行。
- 无货物或货物没有运输要求时隐藏整个读数区域，不显示占位提示；只保留并上移右侧的清空按钮栏。按钮点击、悬停和长按进度同步移动。图集读数部件之间的透明分隔行不参与绘制。
- 条件符合显示绿色，不符合显示红色；暂停、过期或无观测时显示未知/灰色，不用零伪装成正常。剩余老化预算不是现实时间倒计时。
- 图标和状态复用运输系统的冻结规则、近期报告与只读运动摘要。界面刷新不会额外采样、推进运输过程或扣货；默认每秒请求一次详情，服务端限频。
- PDA 暂时使用原版普通物品模型与书贴图（`minecraft:item/generated`、`minecraft:item/book`）；GUI 本身完整使用提供的图集部件。

“运输损耗”是自上次装载/追加以来实际提交的原生货量损失，不是货柜耐久，也不是仅最后一次检测损失。它随货柜资产保存，完全损失或卸空后仍保留，下一次装载重置。读取详情不重复计损。

## 长按清空货物

仅所有者可对有可解析货物的有效货柜使用清空按钮。需要持续长按至少 3 秒，松手、移出按钮、失焦和关闭界面均取消。清空只删除载荷，不删除货柜，不返还物品或货币，不产生交付奖励；剩余货物作为主动丢弃计入生涯损耗，随后进入既有质量/惯量/贴花刷新队列。

服务端以一次性会话和长按令牌绑定玩家、维度、点击位置、货柜 ID 及货物身份/数量/成本。提交时复核仍手持 PDA、非旁观、目标区块已加载、投影后的物理世界距离不超过 8 格、相同资产及所有权。货物在长按期间发生变化则不能沿用原确认；不凭客户端声称的长按时长执行删除。

关闭、离开范围、换维度或切换物品后不再允许操作；迟到的刷新回复不能重新弹出详情。查看他人的货柜不授予清空权限。未知原文隔离的货物不可通过本按钮删除。
