# 货柜轨道系统概览

货柜轨道系统用于让 Sable 物理结构沿玩家铺设的轨道移动。它由轨道节点、轨道物品、滑台接口和运行时物理管理器组成。

轨道模型只是轨迹的视觉表现；真正的轨道是一条由两个节点定义、保存在世界数据中的数学路径。破坏任意端点后，对应路径立即失效并停止渲染。

## 组件

| 组件 | ID | 用途 |
|---|---|---|
| 货柜轨道节点 | `cargoverse:cargo_rail_node` | 玩家放置的三格宽端点结构 |
| 货柜轨道 | `cargoverse:cargo_rail` | 选择两个节点并创建轨道区间 |
| 滑台接口 | `cargoverse:cargo_rail_interface` | 安装在可移动 Sable 结构上的入轨接口 |

节点实际中心方块的方块 ID 为 `cargoverse:cargo_rail`。`cargo_rail_node` 是其物品 ID；不要在数据包中把二者混为一谈。节点两侧还会自动生成内部副方块 `cargoverse:cargo_rail_node_side`，玩家不需要单独获取或放置。

## 核心概念

### 节点

节点决定轨道端点、切线方向、安装平面和红石状态。一个完整节点由中间主方块和左右两个副方块组成，整体宽三格。

### 轨道区间

两个节点之间的一条完整连接称为一个轨道区间。区间拥有稳定 UUID，并独立保存几何路径、端点和运行状态。

- 单个节点最多连接前、后两个区间。
- 单个区间最大路径长度为 `16` 格。
- 每个区间只允许直线或一次 `90°` 转弯。
- 标准转弯半径为 `3` 格。
- 同平面和跨平面转弯使用同一种区间概念。

### 轨道组

运行时会把相连区间组织为轨道拓扑，但红石锁定仍以每个区间为单位判断。轨道组用于查找相邻路径、区间切换和连接恢复，不代表整组必然共享同一种红石状态。

### 滑台

带有滑台接口的 Sable 物理结构称为滑台。普通世界方块可以承载轨道节点，但滑台接口必须位于 Sable 物理结构中才能进入轨道。

## 玩家侧规则摘要

1. 放置两个货柜轨道节点。
2. 手持货柜轨道右键起点节点。
3. 移动视角查看到终点的实时路径预览。
4. 再次右键终点节点确认铺设。
5. 将滑台接口移动到只有一段连接的开放端点附近，使其被捕获。
6. 两端节点都接收红石信号时，区间允许滑动；任意一端未激活时，区间刚性锁定。

潜行右键或切换手持物品可以取消尚未确认的铺设。

## 当前运行参数

| 参数 | 当前值 | 作用 |
|---|---:|---|
| 转弯半径 | `3` 格 | 所有90°弯道的标准半径 |
| 区间最大长度 | `16` 格 | 超出时禁止创建 |
| 路径物理采样步长 | `0.25` 格 | 构造数学路径和物理段 |
| 开放端点查询范围 | `0.85` 格 | 端点周围空间索引查询范围 |
| 捕获横向误差 | `0.35` 格 | 接口到轨道线的最大捕获偏差 |
| 捕获相对线速度 | `2.0` | 超出时不捕获 |
| 捕获相对角速度 | `1.5` | 超出时不捕获 |
| 脱轨保持横向误差 | `1.25` 格 | 超出时解除连接 |
| 重新捕获冷却 | `20 tick` | 防止刚脱轨后立即反复捕获 |
| 轴向阻尼 | 每物理步保留 `90%` | 让无动力滑台逐渐减速 |
| 物理轨道偏移 | 模型下方 `10 px` | 仅移动物理轨迹，不移动渲染模型 |

这些数值是当前实现常量，不是数据包配置项。
