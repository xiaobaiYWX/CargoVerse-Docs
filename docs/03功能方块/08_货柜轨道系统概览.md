# 货柜轨道系统概览

货柜轨道是逐格放置、不可转向的直轨系统，用于约束带有滑车的 Sable 物理结构。每个轨道方块就是一格真实轨道，不再通过节点创建虚拟区间。

## 组件

| 方块／物品 | ID | 职责 |
| --- | --- | --- |
| 货柜轨道 | `cargoverse:cargo_rail` | 一格直轨，接收并沿连续直轨传播激活状态 |
| 货柜轨道滑车 | `cargoverse:cargo_rail_interface` | 安装在移动结构上的挂轨接口，保留既有注册 ID |
| 货柜轨道止冲器 | `cargoverse:cargo_rail_stop` | 被动末端挡块，阻止已挂轨滑车冲出 |

轨道、止冲器都是普通方块，没有方块实体或逐格 Tick。只有滑车持有挂轨记录。三者均位于货柜系统创造栏，使用扳手可调整安装面内的轴向。

## 使用流程

1. 在有支撑的表面逐格铺设直轨，放置时自动对齐已有的同面轨道或止冲器。
2. 给一格轨道红石信号，激活状态沿同轴、同面的连续直轨向两侧各延伸最多 8 格。
3. 在需要阻挡滑车的末端放置止冲器。
4. 将移动结构上的滑车接合面对准激活轨道；任意激活轨格都可捕获，不限定开放端点。
5. 捕获后先平滑对齐，再沿直轨双向滑动。当前位置断电时锁定，重新激活后继续允许滑动。

轨道本身不驱动滑车。运动由外力、载具动力和碰撞决定，并施加相对轴向阻尼。没有止冲器的开放末端允许滑车离轨。

## 当前边界与数值

| 项目 | 当前规则 |
| --- | --- |
| 轨道形状 | 只有直轨，无弯道、岔路或跨面转接 |
| 安装表面 | 东、南、西、北、上、下六面，轨道轴不能与安装面法线同轴 |
| 激活传播 | 从直接信号源向两侧各最多 8 格；不跨空隙、异轴、异面或止冲器 |
| 实体碰撞 | 轨道为贴支撑面的 3px 薄层；止冲器为完整一格 |
| 捕获查询 | 每个未挂轨滑车错峰每 5 Tick 查询附近真实轨格 |
| 捕获条件 | 横向距离 ≤0.6 格，轴／接合面误差 ≤15°，相对线速度 ≤8 m/s，相对角速度 ≤2.5 rad/s |
| 对齐阶段 | 8 Tick 渐进固定约束对齐 |
| 轴向阻尼 | 每游戏 Tick 保留相对速度的 85%，衰减后低于 0.05 m/s 归零 |
| 止冲限位 | 沿同一已加载连续直轨双向最多前瞻 64 格，更新现有关节行程限制 |

以上为实现常量，不是数据包参数。止冲器不捕获滑车、没有充能状态，也不传导轨道激活或红石。

## 已移除的旧系统

旧三格节点、副方块、起终点连线铺轨、数学路径、90°转弯、路径拓扑、质心覆盖、全局挂接 SavedData 与客户端路径预览均已移除。不再注册旧 `cargo_rail_node` 物品和 `cargo_rail_node_side` 方块，不提供旧节点／路径存档迁移；升级开发存档前应备份并重新铺设轨道。
