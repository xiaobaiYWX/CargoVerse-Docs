# 货物卸载机

`cargoverse:cargo_unloader` 是大型多方块世界表面终端，用于把玩家货柜内的货物出售给贸易点并完成结算。

## 结构与绑定

- 控制器统一渲染完整模型，成员方块不重复绘制；
- 手动普通点由管理员使用终端连接工具绑定，保存实例与定位点关系；自然生成结构内绑定锁定；
- 终端在所有有效卸载点的范围合集内只识别一个货柜：优先选择距任一卸载点中心最近者，距离相同时选择货柜 ID 较小者；
- 没有有效贸易点或卸载点时，仪表保留外观并显示未绑定，卸载操作不可用。

定位点规则见[货柜定位点](16_货柜定位点.md)。

## 世界表面内容

上方面板显示当前物品图标、名称、相对本站基准报价的涨跌和所选数量预计总价。下方面板显示唯一货柜名称、物品、实际数量／容量与装载率，不显示独立完整度。

贸易点不收购当前货物时，上方名称栏显示无法出售，图标与价格留空；货柜信息继续显示。

控件包括：

- 数量滑轨选择卸载单位数；
- `UNLOAD` 按钮提交交易。

点击 `UNLOAD` 后先打开玩家私有确认页，布局与装载确认统一。使用 256×256 图集，上方 256×247 为面板，底部是独立的进度条满填充贴图，不作为背景直接显示。左侧为物品图标、名称和本次卸货数量；右侧三行为柜内数量/容量、本次贸易贡献和结算器余额。中部增加许可证经验和制造商声望两条进度，底部显示市场修正、签约优惠和卸货质量。不显示完整度折价；经验预览使用服务端目的地资格和当地收购报价。

制造商声望与许可证经验均显示当前累计值、到下一等级的阈值和本次增量。进度按宽度裁取图集中的满填充纹理，保持原有颜色和纹理，不拉伸渐变或改用纯色。确认成功后，累计值在原页面内快速增加，本次增量同步归零，进度随之推进；达到最高等级时阈值显示 `MAX`。没有制造商声望数据时保留空槽并显示 `---`，不误显示为满级。较长数值可悬停查看完整内容。

绿色确认按钮只提交一次，处理期间不可重复点击；结果状态在按钮右侧显示。右侧叉号始终可用，等待时也可取消未提交会话并关闭；已完成结算不会撤销，关闭后的迟到回执不会重新打开界面。取消和服务端重验边界与[装载确认](13_货柜装载机.md)共用。

装载与卸载确认共用文字对齐规则：当前值和增量在各自底图槽位内水平、垂直居中，确认文字带阴影；底部标签左对齐信息框，数值居中并带阴影。卸载进度文字与条体留出间距，不移动填充贴图或修改奖励计算。

## 卸载交易

服务端重新识别当前唯一货柜，并验证许可证、贸易点状态、货柜所有权与有效性、定位范围、精确物品及组件、容器兼容性、贸易点收购报价与当日额度，以及玩家是否携带可接收 `VB` 的虚空结算器。检测范围内的其他货柜不会通过按钮切换或参与本次交易。

```text
有效数量 = min(请求数量, 柜内数量)
单位价格 = 本站收购 unit_price × 动态价格修正 × 签约运输员卖价修正
收入 = 单位价格 × 有效数量
```

签约运输员修正只在玩家许可证签发制造商与贸易点制造商一致时使用，最后应用。货损已直接扣件数，不叠加完整度修正。

成功后按物品栏顺序把 `VB` 写入玩家携带且仍有容量的虚空结算器，必要时可跨多台入账；随后减少或清空 Load。自然站交付不写入出售库存，受收购每日额度限制。制造商声望按本站收购基准价值与分类偏好独立计算；许可证和繁荣度经验仅在自然生成目的地成功收购时按全部实际成交件数奖励，未配置经验为 0。玩家贸易点交付使用保险库容量与报价规则，不产生这两种经验。

结算器余额、货柜、贸易点、许可证经验、制造商声望和航运风格记录共享服务端串行补偿边界。卸空保留货柜资产。提交后质量、惯量和实体贴花进入统一物理刷新队列，同一货柜的连续交易按最后一次交易后的 `20 tick` 合并。
