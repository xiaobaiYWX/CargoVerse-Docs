# 货物卸载机

`cargoverse:cargo_unloader` 是大型多方块世界表面终端，用于把玩家货柜内的货物出售给贸易点并完成结算。

## 结构与绑定

- 控制器统一渲染完整模型，成员方块不重复绘制；
- 管理员模式右键结构成员打开配置界面；
- 配置保存贸易点实例 UUID 和一个或多个货柜卸载点 ID；
- 终端在所有有效卸载点的范围合集内只识别一个货柜：优先选择距任一卸载点中心最近者，距离相同时选择货柜 ID 较小者；
- 没有有效贸易点或卸载点时，仪表保留外观并显示未绑定，卸载操作不可用。

定位点规则见[货柜定位点](16_货柜定位点.md)。

## 世界表面内容

上方面板显示当前货物图标、名称、收购价格涨跌和所选数量的预计总价。下方面板显示候选货柜名称、当前货物、当前数量／最大数量与货物完整度。

贸易点不收购当前货物时，上方名称栏显示无法出售，图标与价格留空；货柜信息继续显示。

控件包括：

- 数量滑轨选择卸载单位数；
- `UNLOAD` 按钮提交交易。

点击 `UNLOAD` 后先打开玩家私有的轻量确认页。左侧突出货物图标、名称、卸货数量与确认按钮；右侧紧凑显示柜内数量、结算器余额、制造商声望、许可证经验、价格修正、货物完整度和贸易贡献。卸货页不重复显示货物质量。

制造商声望与许可证经验均显示当前累计值、到下一等级的阈值和进度条。确认成功后，累计值在原页面内快速增加，本次增量同步归零，进度条随之推进；执行结果显示在左侧按钮下方，不与右侧明细争抢空间。达到最高等级时阈值显示 `MAX`。

## 卸载交易

服务端重新识别当前唯一货柜，并验证许可证、贸易点状态、货柜所有权与有效性、定位范围、CargoGood 定义、容器兼容性、贸易点收购目录，以及玩家是否携带可接收 `VB` 的虚空结算器。检测范围内的其他货柜不会通过按钮切换或参与本次交易。

```text
有效数量 = min(请求数量, 柜内数量)
单位价格 = 基础价值 × 贸易点买价修正 × 动态价格修正 × 完整度比例 × 签约运输员卖价修正
收入 = 单位价格 × 有效数量
```

签约运输员修正只在玩家许可证签发制造商与贸易点制造商一致时使用，并在完整度等其他修正之后计算。

成功后按物品栏顺序把 `VB` 写入玩家携带且仍有容量的虚空结算器，必要时可跨多台结算器入账；随后减少或清空 Load。交付货物不写入贸易点库存，所有目录内货物长期接收。制造商归属不为 `none` 时，出售货物同时按货物价值和最高匹配偏好修正增加该制造商声望。许可证经验与航运风格统计也在同一事务中更新。

结算器余额、货柜、贸易点、许可证经验、制造商声望和航运风格记录共享服务端串行补偿边界。卸空保留货柜资产。提交后质量、惯量和实体贴花进入统一物理刷新队列，同一货柜的连续交易按最后一次交易后的 `20 tick` 合并。
