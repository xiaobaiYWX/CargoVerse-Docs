# 直轨铺设、充能与止冲器

## 逐格铺设

手持货柜轨道直接放置，一件物品放置一格真实轨道，不需要先放节点、选择起终点或确认路径。沿轴向延长时继承已有轨道或止冲器的安装平面；在同面相邻轨道存在时优先对齐其轴向。相邻方向冲突或没有可对齐对象时，采用玩家在安装平面内的朝向。

轨道和止冲器背面必须有牢固支撑。失去支撑后对应方块移除，不删除其他独立轨格。当前不生成左右占位块。

## 朝向、扳手与模型

- `facing` 是支撑面的朝外法线，可取六个方向。
- `axis` 是轨道切线轴，只能使用安装平面内的两个合法轴。
- 普通扳手右键在该平面内切换轴向；潜行扳手右键使用 Create 的正常拆除流程，不再承担清除路径连接的功能。
- 结构旋转／镜像同步更新安装面和轴向。显示模型与物理锚点使用同一朝向约定。
- 模型的支撑底座贴支撑面，滑车接合端朝外。轨道挂轨线位于方块中心沿 `facing` 方向偏移 `-2/16` 格处。

轨道选中轮廓保持完整一格，实体碰撞仅为支撑面上的 3px 薄层。所有朝向都遵守此规则。

## 充能传播

轨道接收到直接红石信号时激活，并沿同轴同面的连续轨道向正、反方向各传播最多 8 格。多个直接信号源可以分别提供覆盖，但不会把相邻轨格的 `powered` 当作新信号源无限接力。

遇到空隙、其他方块、异轴轨道、异面轨道、止冲器或未加载区块时停止搜索，不强制加载区块。移除信号源、断轨或旋转轨格会更新受影响的局部范围，其他仍有效的直接信号源继续提供覆盖。轨道的激活状态不对外输出红石信号。

## 货柜轨道止冲器

在轨道末端放置 `cargoverse:cargo_rail_stop`。它会自动对齐已有轨道，轨道也能反过来对齐先放置的止冲器。

止冲器具有完整 `16×16×16px` 的实体碰撞箱和选中轮廓，不因安装方向改变。它没有 `powered` 属性，不充能、不传导红石或轨道激活，也不参与新滑车捕获。

对已经挂轨的滑车，系统识别同一承载结构、同轴同面且中间不断轨的止冲器，给滑动关节加入轴向行程界限，使锚点保持在最后一格真实轨道内。滑车能反向离开，不会像断电轨道那样永久固定在撞停位置。止冲器拆除、方向不匹配或与当前轨道断开后，相应行程界限清除。

止冲器不是可行驶轨格，不能用它桥接空隙、跨越断轨或延长充能范围。没有止冲器的末端不会自动变成挡停端。
