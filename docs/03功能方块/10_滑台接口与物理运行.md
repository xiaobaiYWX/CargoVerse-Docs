# 滑台接口与物理运行

滑台接口安装在 Sable 物理结构上，是结构进入货柜轨道的唯一物理锚点。本章说明捕获、约束、红石锁定、转弯和脱轨行为。

## 入轨条件

轨道不再扫描并捕获位于中段的接口。只有满足以下条件的节点才是捕获入口：

- 节点有效。
- 节点只连接一段轨道。
- 该节点位于所连区间的真实起点或终点。
- 因为只连接一段轨道，所以节点朝外的一端是拓扑开放端。

接口进入开放端点主方块附近后，系统从世界空间分桶索引中查询候选接口。捕获范围有意放宽到覆盖节点主体附近，但仍会检查接口到数学轨迹的横向距离、投影位置、相对线速度和相对角速度。

候选滑台还必须满足：

- 滑台接口属于 Sable 物理结构。
- 轨道承载结构与滑台不是同一个物理结构。
- 该滑台没有其他有效轨道连接。
- 接口不在刚脱轨后的冷却期。
- 接口有效面和轨道入口姿态满足当前对齐规则。

因此，正常入轨方式是从轨道开放端驶入，而不是把滑台直接放到任意轨道中段。

## 捕获与引导

开放端点找到候选接口后，系统先执行快速主动对齐，将接口引导到轨道锚点并校正为轨道切线姿态。只有位置和姿态进入允许误差后才创建物理约束。

捕获阶段的安全限制包括：

- 最大相对线速度 `2.0`。
- 最大相对角速度 `1.5`。
- 接口到轨道线的最大横向误差 `0.35` 格。
- 刚脱轨接口有 `20 tick` 重新捕获冷却。

## 滑动状态：Generic

区间两端节点都激活时，连接进入 `SLIDING_GENERIC`。

Generic 约束只开放轨道切线对应的一项线性自由度，同时锁定：

- 另外两项线性自由度；
- 三项相对角自由度。

系统不设置电机、不设置行程限制，也不关闭碰撞。因此：

- 滑台可沿轨道正反方向自由运动。
- 滑台不能横向或上下离轨。
- 滑台随轨道切线改变姿态。
- 滑台仍与承载结构、其他滑台和世界碰撞。
- 外力、摩擦和碰撞仍能影响运动。

弯道由同一条数学路径上的连续 Generic 约束帧实现。每个物理步根据当前投影重新计算位置、切线、侧向和法线基底，使直线、平面弯道与跨平面弯道使用同一套路径坐标。

## 锁定状态：Fixed

一个区间只有在两个端点节点都激活时才允许滑动。任意端点未激活时，连接切换为 `LOCKED_FIXED`：

```text
两端均激活 → Generic 自由滑动
任意端未激活 → Fixed 刚性锁定
```

切换到 Fixed 时采用滑台当时的相对位置与姿态，不会将其拉回区间中心或端点。重新激活后：

- 接口仍位于有效路径范围内：删除 Fixed，恢复 Generic。
- 节点或区间已经失效：删除 Fixed，解除连接。

## 区间切换

滑台接近当前区间端点时，系统查询该节点连接的下一段路径：

- 存在唯一兼容区间时，将连接索引转移到下一路径并重建 Generic。
- 端点是开放端且没有下一段时，滑台离轨进入自由状态。
- 节点拓扑无效或不能唯一决定下一段时，为避免错误连接而解除约束。

滑台移动方向决定从哪一端离开，轨道允许双向运行。

## 轨道阻尼

处于 Generic 滑动状态时，系统在物理线程中对相对轴向速度施加阻尼。每个物理步保留 `90%` 速度；绝对速度低于 `0.02` 时直接停止微小漂移。

阻尼只处理沿轨道方向的相对速度，不应给横向或角向自由度额外开放空间。

## 质心管理

大型或不对称结构的自然质心可能远离滑台接口。若仍以远端质心旋转，弯道会产生很大的切向速度与约束冲量。

当前实现以“滑台是否实际处于轨道连接中”为权威条件：

- 入轨后把轨道运行质心维护到接口锚点附近。
- 滑台结构在轨道上发生方块变化时，重新计算并更新质量属性，避免沿用旧结构快照。
- 正常离轨、轨道被拆除、连接失效或恢复失败时，立即按当前结构重新计算自然质心。
- 不使用入轨时保存的旧质心作为永久恢复值。

质心修改是运行时物理状态，不是货柜质量数据，也不会改变货柜定义中的显示质量。

## 脱轨条件

以下情况会解除轨道连接：

- 任一端点或当前区间被删除。
- 接口方块被破坏或不再属于原滑台。
- Sable 物理结构失效。
- 接口相对轨迹的横向误差超过 `1.25` 格。
- 区间拓扑改变后无法确定有效承接路径。
- 持久化恢复确认原连接已经不可恢复。

解除后会删除物理约束、清除连接索引、恢复自然质心，并设置短暂的重新捕获冷却。
