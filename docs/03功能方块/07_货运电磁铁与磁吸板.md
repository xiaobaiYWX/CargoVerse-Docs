# 货运电磁铁与磁吸板

货运电磁铁与磁吸板组成一套简化的通用物理连接系统。它适合临时固定货物、平台、吊装组件和其他不需要接口组管理的物理结构。

这套系统与货柜连接器相互独立，不共享搜索索引、状态或物理约束。

## 方块 ID

| 方块 | ID | 角色 |
|---|---|---|
| 货运电磁铁 | `cargoverse:freight_electromagnet` | 主动搜索与红石控制 |
| 磁吸板 | `cargoverse:magnetic_board` | 被动连接目标 |

两个方块均支持六个方向放置。

## 货运电磁铁

货运电磁铁负责搜索磁吸板、引导两个结构靠近并建立固定约束。

### 状态

```text
off
searching
connected
```

| 状态 | 行为 |
|---|---|
| `off` | 不执行搜索，使用关闭贴图 |
| `searching` | 搜索并吸引磁吸板，使用搜索贴图 |
| `connected` | 已建立固定约束，使用连接贴图 |

关闭状态收到一次红石信号后进入搜索状态。搜索基础持续时间为 `100 tick`，即约5秒。

发现有效磁吸板后，电磁铁会持续刷新搜索时间并吸引目标；没有找到目标时，倒计时结束后自动返回关闭状态，避免长期执行无意义搜索。

连接状态再次收到红石信号时会移除约束并返回关闭状态。

### 相邻电磁铁组

六个方向上直接相邻的货运电磁铁会自动组成一个连通组。连通关系可以继续向相邻电磁铁传递，不需要玩家输入组名或绑定物品。

组内共享红石信号和逻辑状态：

- 任意成员收到红石上升沿，整组同时进入 `searching` 状态。
- 每个成员仍按照自己的位置和朝向搜索磁吸板。
- 任意成员成功锁定后，整组同步显示 `connected` 状态。
- 再次触发组内任意成员时，整组解除连接并返回 `off` 状态。
- 没有成员找到目标且搜索时间全部结束后，整组统一返回 `off` 状态。

共享连接状态不代表复制物理约束。两个物理结构之间最多只会建立一条磁吸固定约束；第一组磁铁与磁吸板锁定后，同属这两个结构的其他电磁铁会停止配对，从而避免多条约束产生意外力矩。

## 磁吸板

磁吸板是被动目标方块：

- 不接受红石控制。
- 不主动搜索电磁铁。
- 不需要配置组名或绑定物品。
- 同时只能参与一个有效磁吸连接。

磁吸板模型和碰撞箱尺寸均为：

```text
16 × 16 × 3 px
```

碰撞箱会随六向 BlockState 一起旋转，不会按完整方块处理。磁吸板使用非完整方块渲染，相邻完整方块不会把整个磁吸板错误遮挡。

磁吸板的搜索距离、引导方向和固定约束锚点均以实际 `16 × 16 × 3 px` 碰撞箱中心计算，不按完整方块中心或完整方块表面计算。电磁铁侧的锁定锚点沿连接面法线向外偏移 `1.5 px`，使磁吸板贴合表面而不会嵌入电磁铁模型。

## 搜索与连接条件

货运电磁铁搜索约5格范围内的磁吸板。候选目标必须满足：

- 电磁铁与磁吸板属于不同的 Sable 物理结构。
- 世界空间中的连接面基本相对。
- 磁吸板当前未被其他电磁铁占用。
- 两个物理结构之间尚未存在其他货运电磁铁固定约束。

搜索期间，系统向两个结构施加大小相反的线速度，使连接面互相靠近。当前引导速度范围为 `0.12` 至 `0.56`，并根据目标距离渐变。连接锚点进入约 `0.2` 格的锁定距离后建立 Sable 固定约束。

## 姿态处理

磁吸系统只保留最基础的物理结构连接：

- 不进行平滑姿态对齐。
- 不强制旋转目标结构。
- 不进行 `0°/90°/180°/270°` 离散角度修正。
- 固定约束直接采用锁定瞬间两个结构的相对姿态。

因此，使用时应由玩家提前让两个连接面大致相对。系统负责拉近距离，不负责把歪斜结构自动摆正。

## 与货柜连接器的区别

| 功能 | 货运电磁铁 | 货柜连接器 |
|---|---|---|
| 被动目标 | 磁吸板 | 货柜接口 |
| 红石控制 | 支持 | 支持 |
| 分组方式 | 六向相邻自动成组 | 绑定物品配置接口组 |
| 物品绑定 | 不支持 | 支持双槽绑定 |
| 组内状态共享 | 支持，相邻组共享红石与状态 | 支持，接口组共享红石与状态 |
| 结构间约束数量 | 两个结构之间最多一条 | 同一接口组保持单一主约束 |
| 姿态对齐 | 不处理 | 最近90°离散姿态 |
| 典型用途 | 通用临时固定 | 标准货柜装卸 |

## 使用方式

1. 在主动结构上放置货运电磁铁。
2. 在目标结构上放置磁吸板。
3. 让两个方块的连接面大致相对。
4. 将二者移动至约5格搜索范围内。
5. 给予任意一块相邻组内的货运电磁铁一次红石信号。
6. 等待两个结构被吸引并锁定。
7. 再次给予红石信号以断开。

## 当前边界

- 只建立物理固定约束，不传输资源。
- 不支持一个磁吸板同时连接多个电磁铁。
- 同一对物理结构之间不会建立多条货运电磁铁约束。
- 不会自动纠正结构滚转角或倾斜角。
- 磁吸逻辑只在服务端运行；模型状态通过 BlockState 同步给客户端。
