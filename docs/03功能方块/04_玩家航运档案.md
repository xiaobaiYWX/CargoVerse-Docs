# 玩家航运档案

“玩家航运档案”是个人航运数据、货柜资产、百科与教程入口。它使用独立书本 GUI，旧航运终端不再承担任何业务。

物品 ID：

```text
cargoverse:player_shipping_profile
```

玩家手持该物品右键即可打开档案。当前执照登记入口仍是临时占位方块：

```text
cargoverse:license_registration_terminal_placeholder
```

只有手持档案右键该方块后，系统才会创建玩家档案记录。未登记时，第一页的个人信息、许可证、调度点数与航运雷达数据均保持空白，运输过程也不会写入玩家航运风格统计。

## GUI 框架

档案固定包含五个大章节，左侧书签用于切换章节；每个章节拥有自己的小页列表，书页下方箭头用于切换当前章节的小页。第一页不显示向前箭头，最后一页不显示向后箭头。

每个小页是一组左右书页，拥有独立背景图和左右两个内容渲染入口：

```text
PlayerShippingProfileContentCatalog
  -> Chapter
    -> SubPage
      -> PageBackground
      -> left PageRenderer
      -> right PageRenderer
```

左右安全绘制区均为 `130 × 200 px`。背景和内容使用书本原生像素坐标绘制；切换小页时先隐藏当前内容，再播放翻页动画，动画结束后提交目标章节与小页。

## 第一章节：航运档案

第一章节只有一个小页，已经接入：

- 航运执照 ID、登记贸易点及许可证类型；
- 玩家头像、姓名、UUID、登记日期和有效期；
- 剩余调度点数；
- 当前许可证等级、叠加印章及升级进度；
- 基于近期承运货量的五轴航运风格雷达图。

雷达统计窗口、航段判定及五轴算法详见[航运风格统计与雷达图](05_航运统计与雷达图.md)。

## 第二章节：货柜档案

第二章节由目录首页和可扩展的货柜档案页组成：

- 目录固定显示 S、M、L、X、XL 五个等级，并按等级与稳定顺序列出玩家名下货柜；
- 目录列表支持鼠标滚轮溢出滚动、条目悬停框选和点击直达对应档案页；
- 每个书本小页最多显示左右两个货柜，后续货柜自动扩展为更多小页；
- 档案页显示货柜模型、名称、GPS 坐标、调度点占用、耐久、当前载量、登记货物、空柜质量、称重质量、特殊设计、设计缺陷和可运输货物；
- 词条与货物类别图标复用公共悬停名称组件；
- 删除按钮在当前书本上叠加二次确认窗口，确认后永久清除货柜实例和物理结构，不返还物品或货币；成功后刷新当前档案，便于连续管理多个货柜。

第三至第五章节暂时只保留可导航的空白小页。

## 数据边界

档案数据分为三层：

1. `PlayerShippingProfileSavedData` 保存登记后才存在的档案身份信息；
2. `PlayerShippingProfileViewService` 聚合打开或刷新档案时所需的服务端权威快照；
3. `OpenPlayerShippingProfilePacket` 一次性同步快照，客户端页面只负责显示。

货柜删除由独立的服务端请求复核所有权和当前实例，客户端确认窗口不直接修改数据。后续章节需要新的服务端数据时，应先扩展快照数据和聚合服务，再扩展网络编码，最后将页面 renderer 注册到内容目录。物品类仅负责打开档案，不承载章节业务。

## 旧航运终端兼容边界

旧 ID `cargoverse:shipping_terminal` 仅保留为普通装饰方块，以保证既有世界、结构模板和资源包仍能解析该方块。保留内容只有：

- 方块与方块物品注册；
- 原水平朝向、方块状态、模型和纹理；
- 普通破坏属性与方块自掉落。

它不再拥有方块实体、菜单、GUI、右键交互、网络包、货柜查询、结构预览、许可证显示、货柜删除或退款能力。既有世界中的该方块加载后只是装饰物；旧方块实体数据不再参与运行。
