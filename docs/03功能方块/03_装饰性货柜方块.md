# 装饰性货柜方块

货柜方块用于搭建货柜结构模板。它们主要服务于视觉统一和物理重量控制。

## 基础特性

- 不可破坏。
- 物理重量为 `0.25 kpg`。
- 支持类似 Create 外壳方块的连接纹理。
- 与同类货柜方块相邻时，内部边框会隐藏，只保留外侧包边效果。

- 绿色货柜方块：`cargoverse:cargo_block_green`
- 蓝色货柜方块：`cargoverse:cargo_block_blue`
- 浅蓝色货柜方块：`cargoverse:cargo_block_light_blue`

## 推荐用法

- 使用同色方块构成一个完整货柜外壳。
- 用货柜接口作为货柜与载具连接位置。
- 不建议在货柜模板中混入过多高重量或高复杂度方块。
