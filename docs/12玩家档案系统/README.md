# 玩家档案系统

玩家档案系统负责“玩家是谁、取得了哪些航运资格、积累了哪些长期进度”。玩家航运手册是这一系统的主要入口，长期进度由服务端持久化，客户端接收展示快照；地图探索缓存保存在客户端，阅读位置和当前导航目的地暂只保存在客户端会话中。

## 当前范围

- 玩家航运手册及档案界面；
- 贸易地图的界面、地形缓存和标记同步；
- 航运许可证注册状态与等级经验；
- 制造商发现顺序、声望和签约状态；
- 玩家航运风格与雷达图数据；
- 生涯统计与近期航段记录；
- 玩家已登记货柜、基础货柜领取资格和注册港口信息；
- 档案界面所需的数据包定义与服务端视图聚合。

## 不属于本系统的内容

- 贸易点库存、报价和营业额属于相应贸易点系统；
- 物理货柜实例、装配状态和货物运行数据属于货柜系统；
- 虚空字节余额由结算器物品承载，不作为玩家档案余额保存。

## 数据原则

玩家档案以玩家 UUID 为稳定键，显示名称仅用于界面。服务端负责组合许可证、声望、生涯统计和货柜摘要形成只读视图；客户端不得通过修改界面数据直接改写档案。

许可证注销或某个终端被移除时，不应连带清除已经形成的生涯统计。各类数据的具体清理必须由对应功能显式触发。

## 贸易地图入口迁移

贸易地图已经与航图台拆分。航图台保留方块、六向放置、连接纹理和 2×2～5×5 完整方阵识别，右键不再打开地图，表面不再绘制地形或地图标记。地图数据与现有客户端缓存继续保留。

地图界面采用通用世界坐标作为打开时的中心，不再查询航图台控制块。地图实现细节见[地图系统](../08地图系统/README.md)。

航运手册已新增最后一个章节 `trade_map`，排在原有五个章节之后，使用贸易地图专用底图。玩家点击书本右上侧的地图边角标签，会沿用手册翻页动画进入该章节；该入口悬停时高亮，悬停和选中都不伸长。原有左侧五个章节标签及其交互保持原样。

进入章节后，右页显示夹在手册里的折叠地图。地图与章节入口共享右上锚点，悬停使用专用选中贴图；点击地图依次播放向左、向下的两段展开动画，完成后在纸张内显示实际贸易地图。地图区域内可拖动平移、滚轮缩放、悬停标记查看首次发现玩家、到访时间和归属模组。点击贸易点或普通结构打开固定信息卡，具体内容与按钮见[地图标记 GUI 规则](../08地图系统/04_结构发现、图标与数据包规则.md#gui-行为)。点击纸张边缘或按 Esc/E 反向播放收起动画。展开状态下选择其他章节，先完整收起地图，再开始翻页到目标章节。动画期间屏蔽重复点击，档案数据刷新会保留动画进度、待跳转章节及地图视图状态。

地图复用既有地形缓存、结构标记、贸易点商品摘要和导航标记。初次展开以玩家当前的世界位置为中心，位置标记持续更新。矩形地图画布上叠加专用 `map_fold/border.png` 纸张边框，遮住边界；展开和收起动画期间隐藏实际地图，只有完全展开后才启用绘制及交互。原独立地图 Screen 与打开桥接已移除，航运手册为唯一地图界面入口。

展开动画共 14 帧，每帧 35 毫秒，总时长约 0.49 秒；收起使用相同速度倒放。第一阶段由入口右边缘向左展开，第二阶段固定在第一阶段末帧的左边缘，底部折页引起的贴图宽度变化不会移动上半张地图。

## 潜在航线

地图章节左页提供三个潜在航线栏位。服务端按完整 CargoGood ID 汇总玩家名下所有有效、装有货物且未待移除的货柜，包含基础货柜；仅统计货物单位数量，不包含贸易点仓库，也不受货柜目录 64 条展示上限影响。该汇总随手册快照下发。

客户端始终展示当前持有数量最多的前三种货物，再在当前维度已经记录的贸易点中，根据收购商品目录寻找对应货物的最近目的地。每种货物只选择最近的一个贸易点，同一贸易点可以对应不同货物；没有已记录收购点时仍保留该货物，并在右侧居中显示“需求未知”。数量相同时按货物 ID 排序，距离相同时按贸易点实例 ID 排序，保持结果稳定。

每个栏位显示放大且居中的潜在航线标题、货物图标，图标下方两行分别显示货物名称和数量（例如 `50T`）。有已知需求时，右侧显示贸易点名称、预计航程和目的地出售货物图标，不再显示目的地收购货物列表。预计航程为玩家当前世界位置到目的地的水平直线距离，单位为格。商品图标沿用共享 CargoGood 展示组件，较长商品目录显示数量摘要；持有货物不足三种时，空栏位仅保留底图，不绘制标题、货物或“暂无”。目的地距离与地图商品摘要每秒重新匹配一次，货量以最近收到的服务端手册快照为准。

潜在航线卡片的第二、第三栏标题在已有位置基础上再下移 2px；三栏的货物图标、名称和数量在前一版布局基础上整体右移 4px，货物名称在图标下方居中。目的地详情压缩行距，出售商品图标按每行七个、最多两行显示，图标尺寸为 8px；超过十四种时预留最后一个位置显示剩余数量。

每个有货物的栏位左上角提供“在地图上显示”图标按钮。已知收购点时，点击后播放地图展开动画，将地图中心移至对应贸易点，并打开其信息卡；保持当前缩放，不改变个人导航目的地。目标按实例 ID 查找，不使用可能重名的显示名称。没有已知收购点时按钮灰化并提示“暂无已知收购贸易点”；空栏不绘制按钮。按钮提示仅在地图收起时显示，展开地图不会触发被遮挡按钮的提示。

## 当前导航目的地

在贸易点或普通结构的信息卡左上方点击指南针按钮，将该标记设为当前导航目的地。此操作只选择目标，不强制收起地图。收图后，右页下方的“当前导航点”区域显示：

- 目的地名称，放大显示，过长时最多换成两行；
- 目的地 XYZ 坐标；
- 从玩家当前投影后的世界坐标到目标的水平直线航程，使用 `m`，每格按一米显示，数值带千位分隔；
- 普通结构使用对应地图结构图标，普通贸易点使用繁荣度图标，玩家贸易点使用所有者头像。

图标右移 2px；名称、坐标和航程按实际文字行数紧凑排列，长名称或大坐标换行时不互相重叠。没有目标时显示“暂无导航目的地”。当前位置沿用 Sable 世界坐标投影，不能把 shipyard 内部坐标直接当作航程起点。

目标独立于信息卡和地图视图保存：关闭卡片、拖动地图、居中、翻页、收图、重新打开手册或刷新档案，不会自动取消目标；点击另一个导航按钮会替换目标。目标引用包含标记类型与实例 ID，每次读取重新解析已知标记，名称、繁荣度和位置更新会反映到页面。退出世界、切换维度/玩家或目标被移除时清空。

当前没有服务端导航指令、航向保持、路径规划或自动到达处理，也不跨重连保存目标。世界里的导航标记硬件与本节的个人目的地选择不是同一状态。后续跨系统接入边界见[导航架构与接口](01_地图导航架构与接口.md)。

## 关闭与阅读位置

- Esc、E 或玩家配置的背包快捷键均可关闭手册。若有货柜删除确认弹窗，先取消弹窗。
- 地图展开或正在展开时，第一次按关闭键只收起地图；展开中的地图会从当前帧反向收起。收起完成后，再按一次关闭手册；长按不会跨过这两个步骤。
- 当前客户端会话按玩家 UUID 记住章节、子页及货柜目录滚动位置。重新打开时恢复阅读位置；若货柜数量变化使原子页不存在，回退到该章节最后一个有效子页。
- 重新打开地图章节时显示折叠地图，需点击展开；阅读位置不包含地图展开状态。
