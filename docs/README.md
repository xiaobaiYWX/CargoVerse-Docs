## 维护原则

玩法描述、系统规则、组件操作、字段协议、具体实例分别有自己的维护位置。相同规则只维护一处正文，其他位置使用链接；不在首页重复容易失效的参数、数量或实施状态。

文档重排不改变源码、资源 ID、数据包加载目录或运行数据。每个贸易点及货柜型号的独立资料仍保留。
