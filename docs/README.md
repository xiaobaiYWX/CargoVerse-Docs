## 状态约定

| 标记 | 含义 |
| --- | --- |
| 已实现 | 已有代码或数据入口；以页面注明的验证范围为准，不等同于完成全部实机验收 |
| 预留 | 设计意图、占位入口或仅解析的数据字段，尚无完整运行功能；不得当作可用玩法 |
| 待验收 | 需要实机回归，或已发现实现与设计不一致；必须写明检查项和已知限制 |

一页可以包含多种状态，具体章节优先于页面摘要。旧开发记录的“完成”与测试数量只代表记录当时的版本。
