# Cargoverse 文档中心

这里是 Cargoverse 当前版本的正式文档入口，面向数据包作者、内容设计者、整合包维护者和服务器管理员。

## 文档状态

文档按用途分为两类：

- **实现文档**：描述当前代码和当前数据格式，可作为制作、配置和排错依据；
- **设计草案**：用于记录货柜型号、制造商和贸易点内容规划，不代表已经注册或实现。

如果实现文档与旧示例冲突，以当前实现文档和代码为准。项目处于开发阶段，不维护已废弃数据格式的兼容说明。

## 核心术语

| 术语 | 含义 |
|---|---|
| 货柜定义 | 数据包中一种可生成货柜模板及其可用 CargoType 配置 |
| 货柜实例 | 玩家购买后生成在世界中的实际物理货柜 |
| CargoType | 实例最终固化的货物类型，决定基础数值、经济方向和贴花 |
| cargo level | `S / M / L / X / XL / SP` 规格等级 |
| cargo units | 贸易点库存使用的抽象货物单位，不是质量或方块数量 |
| 词条 | 对运输环境或操作方式提出限制的货柜规则 |
| 完整度 | 仅带词条货柜拥有的共享货损值 |
| 贸易点定义 ID | 数据包中的贸易点类型，例如 `cargoverse:default` |
| tradePointId | 世界内一个贸易点实例的共享 UUID |
| 输入库存 | `inputs_cargo_units`，贸易点收购后供生产消耗的资源 |
| 产出库存 | `output_cargo_units`，贸易点可用于出售货柜的资源 |
| 结构绑定 | 将自然生成结构映射到一个或多个贸易点定义 |

## 维护规则

- 数据字段变化后必须同步更新对应章节；
- 命令变化后必须同步更新命令文档；
- 内容规划不得混入实现文档；
- 删除功能时同时删除入口文档和失效链接；
- 所有 Markdown 使用 UTF-8；
- 相对链接必须能从 GitHub 页面正常打开。
