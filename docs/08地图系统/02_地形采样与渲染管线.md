# 地形采样与渲染管线

## 五种填充区域

填充区域是持久化语义，不是由最终颜色反推的结果：

| 区域 | 判定 |
|---|---|
| `UNEXPLORED` | 客户端尚未采样该位置 |
| `VOID` | 已采样，但整列不存在有效方块或流体 |
| `WATER` | 最高有效表面为水体 |
| `LAVA` | 最高有效表面为岩浆 |
| `LAND` | 存在其他最高有效方块表面 |

未探索与虚空必须严格区分。缺少瓦片或缺少采样只能解释为未探索，不能提前推断为空岛之间的虚空。

## 羊皮纸底图

已探索区域共用 `base_map.png`，未探索区域使用 `unknown_base_map.png`。两者均按绝对世界像素坐标无缝平铺。

填充区域不再各自持有完整底图：水体直接保留普通羊皮纸原色；陆地、虚空与岩浆在同一底图上应用统一色彩调整。未探索底图提供独立 LOD 资源，缺少某一级时由程序从上一层生成，避免低缩放时高频纹理糊成一团。

基础底图及地表纹样必须满足：

- PNG RGBA；
- 宽高均为 2 的幂；
- 单边不超过 256 像素；
- 能以世界坐标无缝平铺；
- 不依赖 GUI 当前缩放或视口起点。

## 渲染顺序

单个地图瓦片按照以下顺序光栅化：

1. 聚合固定世界网格上的 LOD 语义采样；
2. 生成陆地边界、空岛侧壁和高度阴影所需遮罩；
3. 绘制普通或未探索羊皮纸底图；
4. 在陆地上叠加降水地表纹样；
5. 按绝对高度调整陆地明度；
6. 绘制陆地内侧墨线与两像素过渡区；
7. 绘制空岛南侧侧壁；
8. 绘制高度相关的低透明度伪阴影；
9. 最后散布植物纹样；
10. GUI 覆盖层绘制结构标记和玩家图标。

地形派生效果只改变图片，不回写语义缓存。

## 陆地边界与高度

只有陆地具有内侧边界。紧贴分界线的区域压低到接近黑色，继续向陆地内部两格使用统一过渡明度；包含对角邻接的距离计算负责连接阶梯海岸的内外拐角。

陆地明度按绝对表面高度分层：每 100 格变化一次，低处更暗、高处更亮。该明度只用于表达总体高度，不生成等高线，也不使用容易受到树木和房屋干扰的坡面光照。

高度差 50 格仍作为识别明显断层的基础阈值。跨瓦片计算会读取邻近语义光环，保证边界、侧壁与阴影连续。

## 空岛厚度与伪阴影

空岛侧壁从陆地下边缘向南挤出 5 个渲染像素。侧壁主体取陆地底图的低明度，真正暴露在外部的左右侧和底边使用接近黑色的封边；紧贴陆地边界的位置不重复生成第二条墨线。

伪阴影同样向南投射：

- 64 格视为基准地面高度；
- 每增加 16 格高度，满分辨率阴影距离增加 1 像素；
- 最小偏移 5 像素，最大偏移 20 像素；
- 阴影使用约 22% 的黑色明度压暗；
- 高处岛屿的阴影可以覆盖低处地形；
- LOD 下按聚合倍率缩减偏移距离。

侧壁和阴影都按照连续岛屿轮廓派生，不对每个显示像素单独制造不连续投影。
