# 08 地图系统

本章记录贸易航图、地图资源、客户端缓存和自然结构标记接口。地图结构标记使用独立通道，不与自然结构兼容规则混用。

地图实现文档继续保留在本章；贸易地图探索数据的一级业务归属为[玩家档案系统](../12玩家档案系统/README.md)，航运手册与航行引导台自带地图共用画布和玩家已知资料。

- [系统架构与本地缓存](01_系统架构与本地缓存.md)
- [地形采样与渲染管线](02_地形采样与渲染管线.md)
- [气候纹样与植物装饰](03_气候纹样与植物装饰.md)
- [结构发现、图标与数据包规则](04_结构发现、图标与数据包规则.md)

当前已解除航图台右键入口并移除表面地图绘制，保留航图台方块和拼接逻辑。航运手册右上侧的专用入口可进入最后一个章节，点击折叠地图并等待两段展开动画完成后显示实际地图。地图绘制和交互由可复用的 `TradeMapView` 承接，沿用客户端缓存、地形采样及标记同步；纸张边框遮挡矩形地图边界。切换其他章节前先收起地图再翻页。

普通结构与贸易点均可点击打开固定详情卡，支持导航、居中和关闭。左页潜在航线可快捷展开地图并打开目的地卡片；右页显示个人当前导航目标和实时航程。个人目标已同步至服务端会话，航行引导台可通过手册右键复制后独立保存并执行 PID 引导，不包含路径规划或自动到达。开发接口见[地图导航架构与接口](../12玩家档案系统/01_地图导航架构与接口.md)，硬件说明见[航行引导台与 PID 控制](../13载具仪表/01_航行引导台与PID控制.md)。

地图可双击标记设定当前宿主的导航目标，目的地图标左侧绘制导航标记，玩家图标按玩家世界朝向旋转。手册右页提供显示/清除个人目标按钮；引导台空手右键可直接打开独立地图，选择和清除仅写入该方块，潜行右键配置 PID。地图只处理玩家地图状态，不查询或控制载具，载具逻辑仅由仪表服务端执行。
