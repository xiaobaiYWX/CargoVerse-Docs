# 完成一趟运输

本页只串联玩法步骤，具体设备状态、参数和准入以对应规则为准。

1. 查看贸易点提供和收购的商品，确认运输目标及许可证要求。
2. 选择符合介质与保存需求的货柜；同一介质不代表所有保护需求都已满足。
3. 获取对应蓝图，在货柜搭建器中按材料和资产条件完成施工。
4. 使用装载设施确认货物身份和数量，将货柜通过合适接口连接到载具。
5. 运输途中通过 HUD 或 PDA 检查货物与柜内状态，按需要保持合适的运输条件。
6. 到达收货点后确认卸载与结算；玩家贸易点还需要满足经营者的报价、权限与库存条件。
