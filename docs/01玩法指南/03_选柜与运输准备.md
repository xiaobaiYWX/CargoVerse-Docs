# 按运输需求选择货柜

更新：2026-11-06。普通同介质货物不按用途或品牌禁止装载，保护不足体现为运输风险。下表仅列正式产品分工；预留、测试与关闭型号在非正式目录独立维护。

| 运输需求 | 产品线 | 区别与限制 |
| --- | --- | --- |
| 普通固体周转 | Atlas、Courier | Atlas 有密封，Courier 更侧重周转；都没有主动温控 |
| 大宗块材、矿料 | Titan、Boreal | Titan 侧重容量，Boreal 增加缓冲；不承诺温湿调节 |
| 小批易碎货物 | Hermes、Salvage | 都提供缓冲；空重与缓冲能力不同，无主动调温 |
| 正放与冲击保护 | Express、Sentinel、Fortress | 分别面向小快件、常规防护、超大批量；不代表防爆或危险屏蔽 |
| 粉料与干燥工业品 | Silo、CoreVault、Vulcan | 都提供围护；CoreVault、Vulcan 带湿度控制，Vulcan 另带缓冲 |
| 农副产品保鲜 | Harvest | 主动调温；正式规格仅 S／M／L |
| 温敏工业封装品 | Apollo | 温控与密封；不提供防爆、耐腐蚀或危险屏蔽保证 |
| 多条件固体样品 | Explorer、Reliquary | Explorer 主动调节，Reliquary 侧重被动隔热和机械保护 |
| 普通散装液体 | Cistern | 基础密封，缺专用模板 |
| 温敏工业液体 | Boreas | 更宽温控范围，缺专用模板；不是独立气体柜 |
| 温压敏感液体样品 | Crucible | 多条件环境控制，缺专用模板 |

## 装载边界

- 固体按完整物品身份及组件、流体按流体身份、生物按物种与原生数据执行现行装载规则；不因同介质而自动允许混装。
- 粉末与碎块是固体；瓶装物品与裸液体分别走固体与流体通道。原生鱼桶不等同于 Aquarium 已支持水生活物。
- 不符合准入或介质则拒装；保护不足按货物条件与柜内状态影响损耗。
- 密封不等于主动稳压，隔热不等于主动制冷，遮光不等于隔热；各能力只按已实现数据生效。
- 模板存在与制造开放是不同状态，查看型号页开头的两项标记；当前可制造不代表所引用模板合规。
