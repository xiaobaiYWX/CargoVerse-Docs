# 货柜适配与边界案例

| 情况 | 当前结果 |
| --- | --- |
| 石块、木板、瓶装物品、种粒、火药、面粉 | 均为 solid，所有允许 solid 的货柜具备基本承载资格 |
| 火药装入 Atlas | 可装，不存在粉末形态拒装；具体风险等待火药新 transport 条件赋值，不再执行旧 D／I 行为 |
| 火药装入 Silo | 可装，但不凭柜名或旧 D 保护豁免；只根据可执行条件、实际能力和环境判断；不把未落地条件当作已运行 |
| 石块装入 Silo | 允许，Silo 不再靠粉末白名单排除其他独立固体 |
| 空瓶与药瓶 | 同属 solid，完整物品身份仍不同，不能混装 |
| 声明相同形态但不同贴花 | 按物品 decal 选择，不由形态统一替换 |
| 带物品的箱子、非空储罐、生物桶 | 按准入和组件检查拒绝，不因 solid 放行 |
| 属性声明为 liquid／gas／living | 形态已定义，但当前实际物品管线不提供这些载荷的运输 |

Boreal、Silo 等名称与外观可以表达适合的用途，但不再形成隐藏的颗粒／粉末准入。容量、空重、实际接口与保护仍按独立型号定义维护。
