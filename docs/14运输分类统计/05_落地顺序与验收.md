# 当前验收与后续专项

当前已落实四大形态、2312 份逐物品属性、直接运输条件、显式贴花、源码默认值、护目镜元数据及冻结快照。后续深化仍逐物品修改，不回到共享条件组或用途白名单。

## 验收清单

- 唯一物品路径、目录／form 一致、无重复声明；未知物品和非贴花引用拒绝发布。
- 缺失文件使用默认；错误文件不降级成默认；规则失败不替换上一完整代。
- 质量、准入、固定数量损耗及完整组件身份正确；零质量仍占容量。
- 同属 solid 的火药、面粉、石块可进入 solid 柜；不同保护保留不同风险。
- decal 由声明选择并随载荷保存，重载不重写途中货物；卸空恢复 none。
- 登录／reload 元数据分包完整后替换；悬停不请求网络，物理贴花复用方块同步。
- 所有物品悬停不显示形态或默认来源；blocked 仅“无法装载”，空容器仅显示简短限制，运输需求无括号解释。无需求普通物品不新增运输提示行。
- Sable 装配、实际碰撞、满载起吊、客户端视觉和多人性能需另行实机验收。

液体计量、气体压力、活体保存释放及冷链维持机制按[专项边界](<../设计草案/待完成事项清单.md>)确认，不用空实现或修改白名单假装完成。验证按[变更范围](<../06开发与运维/06_变更验证策略.md>)选择。
