# 特殊内容准入决策

> **本期策略已接入新装载预检。** 清单 A 代码不是新 CargoClass。拒绝仅作用于新装载，不删除物品，不限制正常背包玩法；未知存储格式仍保守拒绝。

| 清单代码 | profile admission_policy | 本期处理 |
| --- | --- | --- |
| A0 | standard | 通过现有通用检查后允许；身份组件完整保留 |
| A1 | empty_storage | 只有已证明空态的容器允许；无法判空则拒绝 |
| A2 | blocked | 装填桶全部不进入本期新装载；空桶另有 A0 条目 |
| A2E | blocked | 生物桶拒绝；不将外壳 solid 当作活物支持 |
| A3 | blocked | 背罐、胶、末影箱、考古特殊状态等本期不接入，空态也不例外 |
| A4 | blocked | 清单中的管理／创造／刷怪对象排除；不在运行时猜测创造可得性 |
| X0 | 不进入规则成员 | 空栈与空气拒绝 |

四项原 U0 特殊材料已改为 A0/solid，不保留未决分支。A2/A3/A4 的排除是本期范围决定，不声称所有这些对象技术上不能保存。以后开放必须同时修改明确 ID 清单、状态校验和恢复测试；不因测试人员未填参数自动放行。

## 所有策略都执行的检查

现有 ItemCargoAdmission 检查继续保留：空栈、CONTAINER／BUNDLE_CONTENTS 中非空内容、CONTAINER_LOOT、BUCKET_ENTITY_DATA／ENTITY_DATA、已知方块实体库存和战利品字段，以及物品／流体 capability 的非空内容与非法槽数。blocked 优先拒绝，不调用装载写入。

不要清空组件后通过检查，也不要只检查默认 ItemStack。药水、附魔、名称、损伤、书本文字、地图身份、旗帜等合法组件按原值保存；分类本身不读取它们决定用途或危险度。地图的关联世界数据沿用同一存档，不新增跨世界搬运保证。

## A1 的判空契约

采用明确适配器登记表，不要求 profile 增加自定义脚本。每个 A1 ID 必须找到适配器；缺适配器或读取异常返回不支持，不降级 A0。

| 对象 | 必须证明的空态 |
| --- | --- |
| 原版箱、潜影盒、袋、熔炉等 | 通用组件、适用方块实体库存／书／唱片／战利品字段及物品能力全空；默认无存储组件的合法空物品视为空态 |
| 原版蜂巢／蜂箱 | 上述检查外，BEES 组件及兼容旧方块实体 Bees 列表均为空；不读取蜂蜜等级决定质量 |
| Create 包裹 | 适配依赖版本的包裹内容读取接口；包裹确认为空，不能只按外观 ID 放行 |
| Create 保险库／储罐及其他 A1 模组容器 | 标准 capability 与该版本已知持久存储格式均为空；无能力暴露不能当作空态证据 |

适配器只负责判空，不提取内部内容、不打包套娃、不计入内含物质量。蜂箱中存在生物时返回“请先移出内部生物”；包裹中有货返回“请先清空内部物品”；未知格式返回“此存储物品尚不支持验证空态”。

## 错误和恢复

拒绝原因至少区分：空输入、本期不支持、内含物品、内含流体、内含生物、延迟内容、无法确认空态、形态不匹配、容量不足。所有路径必须在扣除输入前完成；错误不吞物、不生成半成品资产。

旧货柜即使已装 A2/A3/A4 对象，也允许按旧快照卸出并恢复原 ItemStack，禁止静默清理。记录无法解码时保留原始数据并提示管理员修复，不以空物品替代。

## 必测状态对

空箱／装满箱、空袋／非空袋、空蜂箱／含蜂蜂箱、空包裹／非空包裹、空储罐／有流体储罐、空桶／水桶、普通空瓶／不同药水、附魔装备／普通装备、四项特殊材料、A3 空态／有状态、A4 默认物品。每组分别检查分类、准入、恢复组件和失败时输入数量。
