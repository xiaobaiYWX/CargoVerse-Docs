**正式落地分类与运输清单 · 2026-10-21。** T 编号只作检索统计；形态、质量、保护、准入和贴花以逐物品 JSON 为准，本表仅作查阅投影。单位质量只用 0、整数或一位小数。

每个 ID 仅在一份清单索引，实际需求直接在对应属性文件维护；后续保护只作设计注记，不生成词条。“—”表示本期没有该项需求。所有条目仍需通用准入检查。代码、数值和准入行为见[交付形态与运输条件](../03_交付形态与运输条件.md)及[准入决策](../07_特殊内容准入决策.md)。
