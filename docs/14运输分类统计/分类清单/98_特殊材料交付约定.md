四种特殊材料本期统一按注册物品的完整成品 solid 交付。这是确定的游戏装载约定，不对虚构材料的现实物态作判断。

本页 **4 个注册 ID**。T 为检索分组；N 为本期排除，X 为空值，均不是装载类。形态和准入以各行标注为准，按链接 JSON 的实际 schema 查阅；A 编号本身仅为文档准入记号。

每个 ID 仅在一份清单索引，实际需求直接在对应属性文件维护。保护／后续保护列尚未按新物性重编，不能据其字母或“—”推断是否正在生效；不从旧资料自动生成等级。所有条目仍需通用准入检查。详见[运输条件](../03_交付形态与运输条件.md)及[准入决策](../07_特殊内容准入决策.md)。
