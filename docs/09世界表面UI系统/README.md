# 09 世界表面 UI 系统

世界表面 UI 把信息、状态和实体控件直接绘制到方块或多方块结构表面。玩家以世界射线瞄准区域并交互，不需要打开传统 `Screen`。

## 当前组成

```text
业务服务与展示快照
        ↓
世界 UI 定义与表面锚点
        ↓
仪表／按钮／开关／滑轨组件
        ↓
方块实体渲染与服务端射线分发
```

框架提供：

- 多表面、六方向与多方块世界锚点；
- 世界命中坐标与逻辑画布坐标互转；
- `DISPLAY`、`OVERLAY`、`CONTROL` 三类表面；
- 默认背景、内框、文字、贴图和 ARGB 着色；
- 翻转字符牌、百分比值、增减指示器、进度条、图标监视器、状态灯、微缩胶片阅读机和全息投影；
- 四向按钮、带字大按钮、保持型开关与数值滑轨；
- 组件模型、姿态、命中区域、高亮、音效和动画的同源放置；
- revision 校验、服务端距离／结构／表面／区域复核；
- 滑轨拖动会话和多人操作隔离。

## 正式终端

世界表面 UI 用于生产线终端、贸易点信息柜、仓库信息柜、货柜制造台、货柜装载机、货物卸载机、物品售货机和许可证注册终端。

`InstrumentTestBlock` 仅用于独立预览仪表的比例、动画、频闪和光照，不属于玩法终端。

## 与传统 GUI 的边界

世界表面 UI 与传统 GUI 共享业务服务和展示格式，不共享 Screen 或 Menu 实例。需要文本录入的管理员配置继续使用传统 Screen；高频状态、选择、翻页、数量和确认操作放在世界表面。

客户端悬停只控制视觉反馈。服务端收到动作后使用真实射线重新计算命中，并由业务服务复核权限、库存、货币、资产和交易条件。

## 表面类型

| 类型 | 背景 | 用途 |
| --- | --- | --- |
| `DISPLAY` | 默认 `#333333` 与公共内框 | 独立显示屏或触摸屏 |
| `OVERLAY` | 透明 | 在模型自带仪表基座上绘制动态内容 |
| `CONTROL` | 透明 | 实体按钮、开关和滑轨交互面 |

普通正文默认使用 `#EBD8B5`。环境光用于屏幕框、仪表外壳和普通文字；只有具备发光语义的图标、数字或点亮状态灯使用 emissive 绘制。

## 分辨率

画布尺寸由物理显示区域和逻辑密度计算：

```text
逻辑宽度 = 显示宽度（MCpx）× 逻辑密度
逻辑高度 = 显示高度（MCpx）× 逻辑密度
```

| 规格 | 密度 | 单方块正面 | 用途 |
| --- | ---: | ---: | --- |
| 大屏信息 | 1 px／MCpx | 16×16 | 远距离数字和图标 |
| 大字体 | 4 px／MCpx | 64×64 | 状态、告警、倒计时 |
| 普通终端 | 8 px／MCpx | 128×128 | 常用终端信息与操作 |
| 精细屏幕 | 16 px／MCpx | 256×256 | 近距离图表和密集内容 |

一个连续多方块显示区域使用一张完整画布，不拆成互不相干的单方块画布。

## 绘制与交互

绘制时，控制器提供几何快照与 revision，公共渲染器建立表面上下文并绘制默认装饰，终端 renderer 再以逻辑坐标绘制动态内容。实体组件从同一 `place(...)` 结果得到模型姿态、当前命中面和细高亮边框。

交互时，结构成员先解析到控制器，服务端检查距离、区块和结构，再把真实世界命中转换为画布坐标，命中明确的动作区域后调用对应 handler。终端不保存客户端悬停状态。
