# 09 世界表面 UI 系统

世界表面 UI 把信息、状态和实体控件直接绘制到方块或多方块结构表面。玩家以世界射线瞄准区域并交互，不需要打开传统 `Screen`。

## 当前组成

```text
业务服务与展示快照
        ↓
世界 UI 定义与表面锚点
        ↓
仪表／按钮／开关／滑轨组件
        ↓
方块实体渲染与服务端射线分发
```

框架提供：

- 多表面、六方向与多方块世界锚点；
- 世界命中坐标与逻辑画布坐标互转；
- `DISPLAY`、`OVERLAY`、`CONTROL` 三类表面；
- 默认背景、内框、文字、贴图和 ARGB 着色；
- 翻转字符牌、百分比值、增减指示器、圆盘形仪表、指南针、姿态仪、垂直速度表、航迹偏差仪、进度条、图标监视器、状态灯、微缩胶片阅读机和全息投影；
- 四向按钮、带字大按钮、保持型开关与数值滑轨；
- 组件模型、姿态、命中区域、高亮、音效和动画的同源放置；
- revision 校验、服务端距离／结构／表面／区域复核；
- 滑轨拖动会话和多人操作隔离。

## 正式终端

正式圆盘仪表采用空基座加可消耗模块：最多四个，允许重复，按安装顺序显示并随数量切换布局；破坏返还基座及全部已装模块。现有指南针、姿态仪、垂直速度表、航迹偏差仪、速度表及气压计六种模块，另有独立的质量与最大静态升力翻牌方块。数据仍由各宿主按需读取自身 Sable 结构，组件只负责绘制。安装规则、模型 display、注册 ID 和数据边界见[模块化载具仪表](04_载具仪表方块.md)。

世界表面 UI 用于贸易点信息柜、仓库信息柜、货柜制造台、货柜装载机、货物卸载机、物品售货机和许可证注册终端。已移除的旧终端不再注册显示定义、renderer 或专用控件。

开发用测试设施有两个：`InstrumentTestBlock`（仪表测试方块，黑色）预览通用仪表及控件；`VehicleInstrumentTestBlock`（载具仪表测试方块，蓝色）预览真实 Sable 载具读数。两者均在载具仪表创造栏，不属于玩法终端。

通用测试面为 `592×192`，右侧包含每秒 25 单位在 `0 → 300 → 0` 往返的 `DialMeter`，以及指针最大 100、翻牌数字最大 999 的 `ClampedDialMeter` 预览。两者不是同一种数值契约，接入方式见[封装仪表组件规范](03_封装仪表组件规范.md)。

指南针、姿态仪、垂直速度表和航迹偏差仪位于蓝色载具仪表测试方块，按此顺序横向排列。放置到 Sable 结构上后，测试宿主自动读取自身所属结构，不扫描周围其他载具；仪表本身仍只接收参数并绘制。

指南针 `Compass` 保持红针与外壳固定，刻度盘跟随世界方位；姿态仪 `AttitudeIndicator` 使用客户端插值姿态计算出的横滚与俯仰；垂直速度表 `VerticalSpeedIndicator` 使用服务端读取并同步的真实物理速度 Y 分量。航迹偏差仪 `TrackDeviationIndicator` 显示水平运动方向相对船头的夹角，用白色扇区标识漂移，载具图标始终最上层；指针始终显示，水平静止或无有效航迹时默认对齐船头，白色填充仅在完全对齐时隐藏。

普通方块状态下，指南针仍有静态世界方位；姿态仪显示深色无数据窗口，垂直速度表显示 `--` 并隐藏指针。有效静止载具的速度 0 则正常显示 `00` 与零位指针。

载具仪表角度以 1°、垂直速度读数与指针目标以 1 m/s 取整，物理方向计算及动画插值保留必要精度。姿态填充与航迹扇区复用缓存，减少重复像素计算；航迹微小偏差仍显示为 ±1°，不因取整被误判为完全对齐。

组件职责已收拢为：宿主按需采样与换算，仪表处理读数和层级，几何辅助类生成整数像素填充，共享绘制工具处理旋转贴图。测试布局统一定义，动画缓存隔离世界会话；不提供统一 Sable 数据入口。详细边界见[封装仪表组件规范](03_封装仪表组件规范.md#28-绘制几何和宿主的职责)。

## 与传统 GUI 的边界

世界表面 UI 与传统 GUI 共享业务服务和展示格式，不共享 Screen 或 Menu 实例。需要文本录入的管理员配置继续使用传统 Screen；高频状态、选择、翻页、数量和确认操作放在世界表面。

客户端悬停只控制视觉反馈。服务端收到动作后使用真实射线重新计算命中，并由业务服务复核权限、库存、货币、资产和交易条件。

## 表面类型

| 类型 | 背景 | 用途 |
| --- | --- | --- |
| `DISPLAY` | 默认 `#333333` 与公共内框 | 独立显示屏或触摸屏 |
| `OVERLAY` | 透明 | 在模型自带仪表基座上绘制动态内容 |
| `CONTROL` | 透明 | 实体按钮、开关和滑轨交互面 |

普通正文默认使用 `#EBD8B5`。环境光用于屏幕框、仪表外壳和普通文字；只有具备发光语义的图标、数字或点亮状态灯使用 emissive 绘制。

## 分辨率

画布尺寸由物理显示区域和逻辑密度计算：

```text
逻辑宽度 = 显示宽度（MCpx）× 逻辑密度
逻辑高度 = 显示高度（MCpx）× 逻辑密度
```

| 规格 | 密度 | 单方块正面 | 用途 |
| --- | ---: | ---: | --- |
| 大屏信息 | 1 px／MCpx | 16×16 | 远距离数字和图标 |
| 大字体 | 4 px／MCpx | 64×64 | 状态、告警、倒计时 |
| 普通终端 | 8 px／MCpx | 128×128 | 常用终端信息与操作 |
| 精细屏幕 | 16 px／MCpx | 256×256 | 近距离图表和密集内容 |

一个连续多方块显示区域使用一张完整画布，不拆成互不相干的单方块画布。

## 绘制与交互

绘制时，控制器提供几何快照与 revision，公共渲染器建立表面上下文并绘制默认装饰，终端 renderer 再以逻辑坐标绘制动态内容。实体组件从同一 `place(...)` 结果得到模型姿态、当前命中面和细高亮边框。

交互时，结构成员先解析到控制器，服务端检查距离、区块和结构，再把真实世界命中转换为画布坐标，命中明确的动作区域后调用对应 handler。终端不保存客户端悬停状态。
