# 航行引导台与 PID 控制

航行引导台（`cargoverse:navigation_guide`）通过改变 Create 输出旋向与转速帮助载具指向目的地。它不是路径规划器，不提供避障、自动油门、到达判定或整套自动驾驶。

## 1. 安装与交互

方块占一格，可水平旋转。底部连接传动轴输入动力，四个水平面与 Y 轴的小齿轮啮合输出；顶部不能输入动力，侧面的独立动力源不能反向驱动引导台。自身应力消耗和新增容量均为零，输出负载仍计入输入网络，不凭空产生动力。

| 操作 | 结果 |
| --- | --- |
| 在航运手册中双击地图标记或点击信息卡导航按钮 | 更新该玩家的个人目的地 |
| 手持航运手册右键引导台（主手或副手） | 把当前个人目的地复制到该引导台，不同时打开手册 |
| 空手右键 | 打开该引导台的独立地图，不需要手册 |
| 潜行右键（包括手持手册或其他物品） | 打开 PID 配置界面，不复制或清除目的地 |
| 在引导台地图中双击标记或点击信息卡导航按钮 | 立即设置当前引导台的目的地，不修改手册目标 |
| 在引导台地图中点击“清除目的地” | 仅清除当前引导台的目标 |

手册尚未选择目标时显示提示，并保留引导台原有目的地。方块表面的翻牌仪表显示目的地名称；无目的地显示“未设置目的地”。静态模型的仪表基座保留，在其顶面绘制仪表。

每个引导台独立保存 `Destination`（维度、坐标、名称）及 `PidSettings`。不按放置者持续跟踪目标，不要求放置者在线；手册随后选择其他目标、隐藏地图标记或玩家离线不会改变已经复制的目的地。跨维度搬运后不会在错误维度继续引导。个人手册选择仍是会话状态，不跨重连保存；已写入引导台的快照则随方块保存。

引导台当前没有所有者/队伍权限，附近非旁观玩家可设置。配置包由服务端复核维度、方块加载状态、方块类型、8 格物理距离与参数范围。

独立地图复用玩家已经探索的地形、结构、贸易点和航标资料，不提供全图解锁。支持拖动、缩放、通用悬停、固定信息卡和导航高亮；“显示目的地”会居中并尽可能打开对应信息卡。已存目标没有可匹配的已知标记时仍保留坐标并可居中。Esc/E 或背包键直接退出，不清除已设目的地。玩家离开 8 格操作范围、切换维度、成为旁观者或方块被移除时自动关闭。

独立地图修改立即生效，无需应用；PID 参数仍须点击“应用”。引导台地图只编辑当前方块的快照，不会把目标反写到个人手册或其他引导台。多人编辑时以服务端最后接受的有效写入为准，重新打开读取最新方块快照。

## 2. PID 参数

固定 15° 减速区已移除。配置界面提供四个数字输入框以及“应用”“恢复默认”“取消”。恢复默认只修改输入框，须应用后才生效；Esc 和取消不保存。鼠标悬停输入框可查看单位和含义。

| 参数 | 默认值 | 可设置范围 | 含义与单位 |
| --- | --- | --- | --- |
| P | 0.05 | 0～100 | 根据当前角度误差转向；输出比例/度 |
| I | 0 | 0～100 | 累积持续未消除的误差；输出比例/(度·秒) |
| D | 0 | 0～100 | 根据误差变化率抑制转向惯性；输出比例·秒/度 |
| 死区 | 1.5° | 0.5°～180° | 夹角绝对值不超过该值时停转 |

非法数字、非有限数、负系数或小于 0.5° 的死区会被拒绝。旧存档没有参数或参数损坏时使用默认值。

计算步长为每游戏 Tick 0.05 秒。PID 使用角度、积分和微分的小数计算，输出需求为：

`P × 误差 + I × 累积误差 + D × 误差变化率`

需求限幅到 -1～1，再乘以输入转速绝对值。最终对称取整到 `0` 或 `±1～256 RPM`，且不超过输入转速绝对值的整数部分。同一整数档位不会因为小数变化反复刷新应力网络。下游齿轮的机械变比仍由 Create 处理，不强制将所有下游设备速度取整。

例如默认参数、64 RPM 输入、10° 误差时输出 32 RPM。输入为正或负不影响正常左右转向的判定；恰好正后方时沿用输入旋向，速度仍受整数档位/上限约束。无目标、失去输入或目标在局部水平面重合时停转。

积分使用条件累积及限幅避免长期满速时持续积累；微分使用 0.1 秒低通滤波，越过 ±180° 边界按最短角度差计算。进入死区、更换目标、修改参数或失去动力会重置控制历史；历史不写入存档。D 可以产生反向输出以制动，并非永远按当前目标所在侧转动。

建议先保持 I/D 为零，按载具响应调整 P；再按实际偏差/振荡调整 I/D。参数过大可能导致过冲或频繁换向，不能用同一组参数保证所有载具稳定。这里是调参说明，不代表已经测量特定载具的最佳参数。

## 3. 物理坐标与动画

参考 Simulated 原装导航台：服务端读取 Sable 当前 `logicalPose`，将引导台中心转换至世界坐标，再用姿态逆旋转把世界目标方向转换至载具局部坐标，最后在局部水平面按方块正面计算有符号夹角。不能先在世界水平面丢弃高度信息，否则载具侧倾、俯仰或倒转时会出现错误。

手册提供的目的地已经是世界坐标，不能再次作为 shipyard 坐标投影。载具运动中每 Tick 读取实时姿态，不缓存世界中心或旋转结果。

指针绕模型轴心平滑指向目标，使用角度追踪器沿最短路径越过 ±180°；无目标返回正面。中央传动杆随输入旋转，中间齿轮随输出旋转，不使用轴承模型。齿轮保留 Create 的位置相关咬合偏角。

变速时客户端保留累计旋转相位，避免 Create 默认“总时间 × 当前转速”重算产生抽搐。修正同时覆盖普通渲染和 Flywheel，仅作用于引导台输出及其下游源链；引导台输入轴和无关网络保留原行为。动画不参与 PID 控制，不在客户端篡改真实速度。

PID GUI 的绘制顺序为背景模糊、面板/文字、控件，不能在面板之后再次调用默认背景模糊。

## 4. 架构与性能边界

| 层 | 组件 | 职责 |
| --- | --- | --- |
| 玩家目标会话 | `PlayerNavigationService` / `NavigationTarget` | 保存可复制的个人坐标快照，不持有客户端地图对象 |
| 物理数学 | `NavigationGuideHeading` / `NavigationSteering` | Sable 姿态适配与纯夹角数学分离 |
| 控制 | `NavigationPidSettings` / `NavigationPidController` / `NavigationGuideOutputSpeed` | 参数、短期控制历史与整数输出档位 |
| Create 适配 | `NavigationGuideKinetics` / `NavigationKineticSourceIndex` | 更新相关下游源树，维护负载与实时拓扑 |
| 配置与访问 | `NavigationGuideConfiguration` / 配置网络包 | 共享只读访问规则，服务端负责目标/参数写入校验 |
| 地图宿主 | `NavigationGuideMapScreen` / `TradeMapInstrumentSelection` | 注入当前仪表的目标写入和高亮，不复用个人目标状态 |
| 客户端 | renderer、PID Screen、旋转相位辅助器 | 显示/输入/动画，不参与服务端控制 |

- 未设置有效目标时不查询物理结构姿态。
- 地图和手册共用玩家探索缓存，不重复采样和保存另一份地图；`TradeMapViewHost` 避免前台地图与后台纹理预热争抢焦点。地图只显示玩家状态，物理姿态与动力控制留在仪表服务端。
- 每个编辑器的已存目标仅在目标变化时扫描已知标记匹配高亮，不逐帧扫描；同目标不重复发包，展示文字只在目标变化时重建。打开界面与修改目标/PID 使用同一套加载状态、维度和距离规则，不强制加载区块。
- 数学与 PID 是每台固定规模计算，不做物理碰撞、射线、周边世界搜索或区块强制加载。
- 整数档位与输入不变时不执行调速；瞬时角度/控制数据不重复标记持久化配置脏状态。
- 调速复用每网络共享的源索引和后代列表；每次真实调速仍逐项检查当前父源和成员，同成员数换节点/换父源也会失效，不能只凭成员数缓存。
- 索引只存不可变坐标，不持有世界、方块实体或网络引用；弱网络键可回收，队列遍历有环路去重，不使用递归遍历长传动链。
- 每网络最多保留 32 个引导台根的后代列表，按 LRU 淘汰；大量嵌套引导台不会无限保留重复列表，淘汰只需要重新遍历，不改变结果。
- 客户端速度不变的同步包不追溯源链；首次分类对当前 Tick/源版本缓存正负路径，源变更立即失效，避免无关长网络的每个速度包都完整回溯。弱缓存值不保存实体/世界引用。显示面朝向变换缓存，配置数字只在输入变化时解析。
- 实际调速仍需 O(N + D) 的成员检查、Create 应力重算和 D 个下游速度同步。N 为加载网络成员数，D 为相关下游数；大型网络和多引导台共享网络仍是主要压力场景。

回归覆盖 10,000 节点稳定索引复用、换父源、同数量替换、环路、拆装、源丢失、整数档位、PID、持久化、网络校验与相位连续。尚未在真实大型载具上采样 MSPT、GC 或网络流量，不能把算法/回归结果当作实船性能测量。压力测试方法见[服务器性能检查](../06开发与运维/04_服务器性能检查.md)。
