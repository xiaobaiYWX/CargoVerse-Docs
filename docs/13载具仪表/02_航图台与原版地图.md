# 航图台与原版地图

航图台（`cargoverse:trade_map_table`）是展示原版地图的独立单方块。它只能朝上放置，普通世界和物理结构上都可使用，不需要绑定贸易点或组成方阵。

## 玩家操作

| 操作 | 结果 |
| --- | --- |
| 手持原版已绘制地图右键空桌 | 放入一张地图；生存模式消耗一张，创造模式不消耗 |
| 右键已有地图的桌子 | 地图旋转 90°，四次恢复原方向 |
| 潜行，主副手均为空时右键 | 取回地图；背包已满则掉落 |
| 拆除桌子 | 清空槽位，按原版方块掉落规则掉落存放的地图 |

每张桌最多保存一张地图；有地图时不会被新地图直接覆盖。相邻桌各自独立，放入不同地图可自行排布，但不合并库存或触发连接纹理、控制方块及尺寸判定。未经绘制的空地图、缺少地图 ID 的异常物品和其他物品不能放入。交互需要原版建造权限，不额外引入贸易点所有权。

地图铺在桌面上，默认像素方向为北上、东右，绘制面略高于桌面以避免重叠闪烁。旋转只影响展示，不改变地图本身的像素或地理范围。

## 数据与同步

- 方块实体只持有一个地图物品及四档旋转状态，物品组件（地图 ID、自定义名称等）随 NBT 保存；载入时将数量归一到一张、旋转归一到 0～3。
- 首次区块跟踪及放入、取回、旋转后，使用原版方块实体更新同步物品和旋转。
- 地图颜色、比例尺及装饰仍由原版 MapItemSavedData 保存，不复制进桌子的 NBT，也不建立另一套地图数据库。
- 有地图时，服务端每 10 Tick 按桌子位置错峰检查同维度玩家。只向 24 格内的玩家发送原版地图增量数据包，使未曾手持该地图的旁观者也能看到内容。
- 客户端直接调用原版 MapRenderer，复用地图纹理缓存和展示框的装饰过滤规则。桌面不显示一个额外的展示框实体。
- 桌子不执行地图物品的地形探索逻辑；地图内容仍按原版规则由持有同一张地图的玩家等原版来源更新。
- 物理结构上只为查看距离换算世界位置，不采样 Sable 的结构、质量、速度或姿态。

## 功能边界

航图台不再提供六向摆放、2×2～5×5 或 3×3 拼接，不再创建地形沙盘或载具三维模型。结构采集、动态方块静态补绘、模型裁切与对应缓存、测试均已清理；货柜系统原有的结构预览不受影响。

它与航运手册、航行引导台使用的贸易地图互不共享画布、探索缓存或导航目标；贸易地图的拖拽、缩放、贸易点商品图标和目的地编辑仍由原有入口提供。参见[地图系统](../08地图系统/README.md)及[航行引导台](01_航行引导台与PID控制.md)。

## 开发入口与验证

- TradeMapTableBlock：交互、朝上形状及拆除掉落。
- TradeMapTableBlockEntity：单槽物品、旋转、NBT 和原版地图数据更新。
- TradeMapTableRenderer：原版地图绘制，不拥有自己的三维网格缓存。
- WorldUiSurfaceOrientation：通用仪表测试使用的六向表面坐标工具；不再使用旧航图台命名或承担桌子拼接。

自动回归覆盖相邻桌独立存放、生存／创造消耗、拒绝非地图、四次旋转、物品组件及初始同步标签、异常存档归一、取回和拆除时不重复掉落。服务端测试不等同于客户端渲染验收；光照、着色器和多人实际观察效果仍以游戏内验证为准。
