# 质量配平方块

质量配平方块（`cargoverse:mass_trim_block`）用于手动调整载具的质量分布。将方块连接到需要配重的位置，用红石信号调整该位置的质量；不记录期望重心，不扫描其他配平方块，也不执行自动配平。

## 使用规则

- 六个面均可输入红石，多个输入取最大信号，不相加；支持红石线连接，自身不输出信号。
- 总质量为“当前信号等级 × 1 Kpg”：未充能的 0 级为 0 Kpg，最高 15 级为 15 Kpg，不额外计入外壳基础质量。
- 降低信号直接降低质量，断电回到零，不保留之前的配重。
- 可在同一载具的前后左右布置多个方块，分别调节输入。方块只影响其所在 Sable 结构；不跨独立结构合并计算或补偿。
- 普通世界中也能放置、接收信号并显示状态，但实际配重效果依赖其作为 Sable 物理结构的一部分。
- 保留完整一格实体碰撞箱；零质量不等于无碰撞。使用镐采掘，按原版掉落规则返还自身。
- 当前已加入载具功能创造物品列表，尚未添加合成配方或配置 GUI。

例如左侧增加货物后，可提高右侧配平方块的信号，让右侧增重以辅助配平；所需质量仍取决于货物与配平方块到重心的距离，并非一定等量。该方块只增减质量，不提供升力或推力，也不保证载具自动恢复水平。

## 模型和工作状态

使用质量配平器模型，外壳与 `core` 核心分别使用独立贴图。只有核心随信号逐级变亮，外壳保持原色：

- 0 级最暗，接近导出素材 `0.png`；
- 1～14 级逐档提高亮度；
- 15 级使用导出素材 `15.png` 的完整亮度；
- 背包、手持和掉落物始终显示未充能状态。

实现为一张亮色核心贴图配合 16 档灰度乘色，并非 16 套模型或贴图。亮度仅是工作状态的表面颜色反馈，不额外产生环境光，仍受游戏光照与着色器影响。开放模型不遮蔽相邻方块的面，不改变其完整实体碰撞箱。

## 架构与性能边界

- `MassTrimBlock` 只保存 `power=0..15`，放置与邻居变化时读取六面输入，等级未变则不写状态。无方块实体、Ticker、独立同步包或周期性全船扫描。
- `data/cargoverse/physics_block_properties/mass_trim_block.json` 使用 Sable 原生 `sable:mass` 和 `overrides` 将每个等级映射至对应质量。Sable 在正常方块状态变更路径中维护结构质量、质心与惯量，不复用货柜质量占位符或重建整船质量数据。
- `MassTrimBlockColors` 仅在客户端用已有 POWER 状态查询缓存的 16 档颜色；不每帧计算配重，也不向服务端请求颜色。
- 不主动加载区块，状态随原版方块数据保存与跟踪同步；客户端颜色不作为物理质量的权威来源。
- 频繁切换红石仍会产生原版方块状态更新和 Sable 物理属性刷新。大量方块接高速时钟的成本需实机测量，不能将“无 Ticker”理解为零开销。

本功能是手动配平，不恢复早期讨论的“记录目标质心、同载具统一求解、跨子结构自动配重”方案。零质量方块应连接到有正常结构质量的载具，不能将它视为独立无质量刚体控制器。

## 开发入口与验证

- `MassTrimBlock`：红石输入与 POWER 更新。
- `MassTrimBlockColors`：核心染色和物品未充能外观。
- `MassTrimDefinitionTest`、`MassTrimBlockColorsTest`：16 档质量定义、模型／贴图／掉落资源，以及颜色端点、单调递增和越界钳制。
- `MassTrimGameTests`：实际 Sable 属性读取、0～15 输入、最大输入选择、六面放置／断电、完整碰撞与不输出信号。
- `MassTrimPhysicsGameTests`：隔离结构上升降档、断电、拆除后质量／质心／惯量的增量更新与无幽灵质量；测试批次前后清理 Sable 结构。

代码仓库可运行 `gradlew.bat test jar` 和 `gradlew.bat runGameTestServer`。服务端回归不代替游戏内视觉验收，尤其是暗处核心显示、物品外观及着色器效果。
