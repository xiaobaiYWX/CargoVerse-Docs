# 载具仪表

载具仪表是下一阶段重点完善的系统，负责载具上的信息显示和直接交互。贸易地图已经从航图台拆出，归入玩家档案系统，当前通过航运手册打开。

## 当前内容

- 暂时保留的航图台方块、六向放置与拼接逻辑；
- 导航标记硬件；
- 航速仪表与仪表测试方块等现有原型。

航图台目前不打开地图，也不在表面绘制地图。地图业务入口说明见[玩家档案系统](../12玩家档案系统/README.md)。

## 后续边界

- 仪表只消费服务端或载具运行时提供的状态快照，不拥有贸易库存、货柜实例或玩家档案；
- 可复用的翻牌显示器、指示灯、按钮和滑轨继续由世界表面 UI 系统提供；
- 具体仪表的数值含义、更新频率、权限和交互结果归载具仪表系统；
- 新仪表应优先使用独立视图状态，避免渲染器直接查询多个 SavedData。

## 开始制作前的约束

1. 先定义仪表输入数据和服务端权威来源；
2. 再定义表面 UI 布局、刷新频率与断线/无载具时的空状态；
3. 最后接入按钮和网络操作，所有可改变世界状态的操作必须在服务端复核。

## 导航接入前的状态

手册已完成结构/贸易点的个人目的地选择、图标、坐标与实时水平航程展示。当前目标保存在客户端会话中，没有服务端导航指令或跨重连存储；现有世界导航标记也不等同于个人目的地。

新的航向保持方块尚未实现。接入前需要先确定公共导航领域模型、玩家和载具归属、维度限制、同步以及失效规则，再由服务端校验选择请求、让手册和硬件消费同一权威快照。载具服务端逻辑不得直接调用客户端 `TradeMapClient` 或依赖手册 Screen。具体边界见[地图导航架构与接口](../12玩家档案系统/01_地图导航架构与接口.md)。
