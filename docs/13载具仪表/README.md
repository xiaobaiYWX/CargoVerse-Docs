# 载具仪表

载具仪表负责载具上的信息显示和直接交互。贸易地图已经从航图台拆出；玩家探索数据归入玩家档案系统，航运手册与引导台独立地图共用地图画布，但各自处理目标。

## 当前内容

- 暂时保留的航图台方块、六向放置与拼接逻辑；
- 唯一航标塔（`player_trade_beacon`）：未绑定时广播普通标记，绑定后广播玩家贸易点；旧 `navigation_mark` 已移除且不保留旧 ID；
- 航速仪表与仪表测试方块等现有原型。
- [航行引导台与 PID 控制](01_航行引导台与PID控制.md)：自带地图或手册复制目标、独立保存目的地、可调 PID/死区、Create 四侧整数转速输出与性能边界。

航图台目前不打开地图，也不在表面绘制地图。地图业务入口说明见[玩家档案系统](../12玩家档案系统/README.md)。

## 后续边界

- 仪表只消费服务端或载具运行时提供的状态快照，不拥有贸易库存、货柜实例或玩家档案；
- 可复用的翻牌显示器、指示灯、按钮和滑轨继续由世界表面 UI 系统提供；
- 具体仪表的数值含义、更新频率、权限和交互结果归载具仪表系统；
- 新仪表应优先使用独立视图状态，避免渲染器直接查询多个 SavedData。

## 开始制作前的约束

1. 先定义仪表输入数据和服务端权威来源；
2. 再定义表面 UI 布局、刷新频率与断线/无载具时的空状态；
3. 最后接入按钮和网络操作，所有可改变世界状态的操作必须在服务端复核。

## 当前导航接入状态

手册已完成结构、贸易点与普通航标的个人目的地选择，并把具名世界坐标快照同步至服务端 `PlayerNavigationService`。个人目标不跨重连保存；引导台通过手册右键显式复制目标，或通过自带地图直接设置，随后独立持久化，不持续跟随放置玩家或手册当前选择。

航行引导台已经实现载具局部角度计算、目的地指针/翻牌仪表、可调 PID 和死区（最低 0.5°）、0/±1～256 RPM 输出。空手右键打开独立地图，手持手册右键复制个人目标，潜行右键配置 PID；清除按钮位于独立地图内。它不提供路径规划、避障或自动到达，载具服务端逻辑不调用客户端地图 Screen。具体跨系统边界见[地图导航架构与接口](../12玩家档案系统/01_地图导航架构与接口.md)。
