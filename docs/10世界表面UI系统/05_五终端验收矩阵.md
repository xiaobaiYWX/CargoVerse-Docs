# 七终端世界表面验收矩阵

> 更新日期：2026-09-03。文件名保留早期“五终端”称呼以维持已有链接；当前覆盖对象已经扩展为七个。自动化预检不能替代标为“实机待验”的项目。

## 覆盖对象

正式终端共七个：生产线终端、贸易点信息柜、仓库信息柜、货柜装载机、货物卸载机、货柜制造台、物品售货机。方块自身只支持四个水平朝向；底层框架可以表达上下与四侧表面，不表示大型终端允许朝上／朝下放置。

## 代码与几何预检

现有架构验证覆盖终端定义、surface 唯一锚点、画布尺寸、局部轴、中心投影、服务端射线和 `CONTROL` 命中。货柜制造台和物品售货机也使用同一组件 `place(...)` 结果驱动模型、命中面和高亮边框。

当前完整验证数量和执行时间记录在[重构状态与验收清单](../00_重构状态与验收清单.md)，不在本页复制可能过期的测试计数。

## 客户端实机矩阵

| 维度 | 每个终端的检查内容 | 状态 |
| --- | --- | --- |
| 四水平朝向 | 模型、文字、图标、按钮箭头、细高亮、点击与滑轨增减方向 | 实机待验 |
| 距离／视角 | 1、2、4、8 格；默认与宽 FOV；按钮边缘和仪表可读性 | 实机待验 |
| 光照／帧率 | 白天、夜晚、低帧率；环境光与自发光内容分离 | 实机待验 |
| 多方块接缝 | 瞄准成员格、边界、拆除成员、控制器失效和重建 | 实机待验 |
| 单人滑轨 | 不同 DPI／灵敏度、快速拖动、松键、离开距离和区块卸载 | 实机待验 |
| 装卸竞争 | 同一货柜、同一贸易点库存、同时 LOAD／UNLOAD | 自动化互斥通过；双客户端待验 |
| 制造竞争 | 同一 input stock 最后一份材料、货币和调度点边界 | 双客户端待验 |
| 售货竞争 | 同一 output stock 最后一份商品、重复 BUY、断线重试 | 双客户端待验 |
| 售货领取 | 跨玩家领取、满物品栏、部分空位、存档重进和拆除只掉落一次 | 实机待验 |
| Create／Sable 运动结构 | 坐标投影、显示、命中、细高亮和拖动会话 | 尚未宣称支持 |

实机记录必须写明世界、维度、坐标、终端朝向、客户端数量、FOV、GUI 缩放、鼠标灵敏度、结构是否运动以及失败截图。只记录“看起来正常”不能关闭对应项目。
