# 商店体系

商店终端通过数据包定义普通物品商品列表，并通过 `tradePointId` 绑定贸易点实例。商品的 `cargo_type` 用于读取对应贸易点资源的价格修正；商店自身仍维护当前上架列表与有限库存。

## 文件位置

```text
data/<namespace>/shop_definitions/<path>.json
```

示例：

```text
data/cargoverse/shop_definitions/default.json
```

对应商店定义 ID：

```text
cargoverse:default
```

## 示例

```json
{
  "commodity": [
    {
      "item": "minecraft:iron_ingot",
      "cargo_type": "ore",
      "display_name": "",
      "count": 3,
      "price": 64,
      "currency_id": "minecraft:emerald",
      "required_license": "S",
      "required_prosperity": 0.0,
      "max_purchase": 0,
      "weight": 1
    }
  ]
}
```

## 顶层字段

| 字段 | 说明 |
| --- | --- |
| `commodity` | 商品数组。 |

商店终端的节奏统一从绑定贸易点读取：

- 列表刷新跟随绑定贸易点的 `ticks_per_day`，也就是每次贸易点结算日后刷新列表。
- 有限库存补货同样以 `ticks_per_day` 为周期。
- 基础显示数量读取当前繁荣等级对应的 `upgrade_list_count`。
- 未绑定贸易点时，商店终端无法正常工作。

## 商品字段

| 字段 | 说明 |
| --- | --- |
| `item` | 商品物品 ID。 |
| `cargo_type` | 商品接入贸易点经济时使用的固定货物类型。留空或非法值会按 `none` 处理。 |
| `display_name` | 可选显示名，目前为空时使用物品默认名。 |
| `count` | 每次购买获得的物品数量。 |
| `price` | 基础价格。 |
| `currency_id` | 支付物品 ID。 |
| `required_license` | 所需运输许可等级。 |
| `required_prosperity` | 进入候选池所需贸易点繁荣等级，默认 `0`。 |
| `max_purchase` | 当前轮次有限库存。`0` 表示无限库存。 |
| `weight` | 稀有度式抽取权重。当前实现会换算为 `max(1, 1000 / weight)` 张抽取票，因此数值越小越容易出现。 |

## 贸易点联动

商店打开时会读取当前终端绑定的贸易点状态。

价格：

```text
商品价格 = 基础价格 × output_resources[cargo_type].sell_price_modifier
```

有限库存：

```text
有限库存 = max_purchase
```

列表刷新和有限库存补充都使用贸易点 `ticks_per_day`。当前库存倍率固定为 `1.0`，因此贸易点输入/产出库存不会放大商店的 `max_purchase`；商品价格只读取对应 `output_resources` 的 `sell_price_modifier`，不读取货柜交易形成的动态价格冲击。

## 繁荣度门槛

`required_prosperity` 使用贸易点繁荣等级，范围 `0~5`。

繁荣等级不足时，商品不会进入上架候选池。繁荣等级只升不降，因此已解锁商品不会因贸易点暂时不活跃而重新锁定。

## 库存和结算

`max_purchase = 0` 表示无限库存，不参与库存扣减。

`max_purchase > 0` 表示当前轮次库存。玩家加入购物车和结算时都会检查剩余库存；结算成功后从当前轮次扣除库存。

如果出货口仍有未领取商品，则无法再次结算。结算成功后，玩家需要右键商店终端主方块领取商品。

## 配置建议

- 商品“换批次”的节奏由贸易点 `ticks_per_day` 控制。
- 当前列表换批与有限库存补货均由贸易点 `ticks_per_day` 控制。
- 有限库存商品建议根据一个交易日的预期销量设置 `max_purchase`。
- 商品 `cargo_type` 使用规范化小写 ID，例如 `ore`、`component`、`supplies`。
