# 货柜命名与品牌规范

正式型号统一使用[标准货柜接口](<../../../03组件手册/连接与轨道/01_货柜连接器与接口.md>)。

## 型号与模板命名

中文型号按“制造商缩写＋系列全称＋规格＋型”书写，例如 `AUI Atlas 标准干货柜 S 型`。模板标识按“制造商－系列－代际－规格”书写，例如 `AUI-Atlas-G2-S`。实际规格取定义中的 `size_class`。各型号的导出路径见[新版模板系列代号](../../../05内容数据/02货柜/新版模板系列代号.md)。

| 资源 | 规则 | Atlas S 示例 |
| --- | --- | --- |
| G2 模板 ID | `cargoverse:cargo/<mfg>/<model>_g2/<mfg>_<model>_g2_<size>` | `cargoverse:cargo/aui/atlas_g2/aui_atlas_g2_s` |
| 工程 NBT 文件 | 在模板相对路径前加 `data/cargoverse/structure/`，末尾加 `.nbt` | `data/cargoverse/structure/cargo/aui/atlas_g2/aui_atlas_g2_s.nbt` |
| 已注册货柜定义 ID | 取型号页列出的稳定 ID，供蓝图、制造与存档引用 | `cargoverse:aui/atlas_sd_s` |

## 现行系列全称

确定制作的型号在正式目录维护；当前数量以型号状态表为准。历史型号及未使用资产见[历史归档](<../../../05内容数据/02货柜/99历史归档/README.md>)。系列和规格的缺失状态在[正式目录](<../../../05内容数据/02货柜/README.md>)下逐页维护。

**模板系列由 NBT 命名确定。** Cargo、Courier 是不同系列；G2版分别使用apollo_g2与boreas_g2，自身系列独立命名。显示名归并和存档 ID 兼容不能改变 NBT 的实际系列。旧文件可保留，但不能用作新系列缺失规格的替代物。

## 规格 SIZE

size_class 是定义中明确填写的规格，不按包络体积自动推断。旧文档两套体积范围互相冲突，且与部分 Atlas 包络不一致，具体硬尺寸范围待你确认；本次不擅自重定标准，也不宣称占位已通过旧标准。下表仅记录当前 Atlas 的真实包络。

| 代码 | 规格 | 当前 Atlas 包络 X×Y×Z | 参考体积 | 普通调度点基准 |
| --- | --- | --- | ---: | ---: |
| S | 小号 | 7×3×5 | 105 | 1 |
| M | 中号 | 9×4×6 | 216 | 2 |
| L | 大号 | 13×6×6 | 468 | 4 |
| X | 特大 | 15×8×9 | 1080 | 6 |
| XL | 超规格 | 17×8×9（扩展占位） | 1224 | 8 |

容量和空重以具体型号定义为准，不由内部体积换算。制作时记录真实包络、底面中心、接口位置和所需装卸空间；调度点免除仅用于基础权益资产，不改变普通型号数值。

## 特殊后缀 OPTION

变体须有已存在的基础型号，最多一个后缀，单独建立定义并显式调整数值与防护。字母只是命名，不会自动修改货物运输要求、固定件数损耗或制造价。

| 后缀 | 英文 | 中文 | 设计方向与现行字段边界 |
| --- | --- | --- | --- |
| R | Reinforced | 结构加强 | 通过结构外观、明确的 abilities 和配方成本体现；不提供货柜耐久值。 |
| A | Armored | 装甲加强 | 通过明确的结构与缓冲能力实现；后缀不提供独立撞击减伤算法。 |
| W | Waterproof | 防水 | 通过防水柜体能力抵消保持干燥货物的降雨与浸水暴露。 |
| TP | Thermal Protection | 热环境防护 | 通过真空隔层与主动调温参数体现；名称本身不赋予保护。 |
| L | Lightweight | 轻量化 | 降低 empty_mass；如需改变易损要求须显式配置，不因后缀推导。 |

`L` 在 SIZE 位表示 Large，在 OPTION 位表示 Lightweight。例如 `AUI-Atlas-G2-L-L` 是大号轻量化命名示例，未注册。OPTION 命名示例不是已注册型号，starter_* 基础权益变体另行定义；命名规范不自动新增货柜。

## 定义 ID 与实际规格

Apollo 三个定义 ID 的末尾为 S／M／L，对应的实际规格为 M／L／X。制作时分别使用 `apollo_g2` 的 M／L／X 路径。其他型号见[模板核对规则](<04_系列归属核对.md>)。
