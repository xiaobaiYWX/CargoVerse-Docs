# 模板系列归属与核对规则

更新：2026-11-09。普通缺失型号不得借用其他系列；明确指定的资产重新分配需逐型号记录。

## G2新版制作口径

后续制作以[新版模板系列代号](../../../05内容数据/02货柜/新版模板系列代号.md)及各型号G2章节为准。下文旧文件归属与缺失记录仅说明当前运行资产；不再要求补做旧名称。新代号不会自动切换运行引用，也不自动开放关闭型号。

## 命名是归属依据

`cargoverse:cargo/spl/cargo/spl_cargo_mc_l` 固定表示 SPL 制造商、Cargo 系列、MC 接口、L 规格。它不能计作 Courier 的 L 模板。同理 TitanHaul 不属于 Silo、Bastion 不属于 Sentinel、Recycle 不属于 Reliquary、Eden 不属于 Harvest。

当前文档仍按正式设计的系列名称列需求；定义资源 ID 可为存档兼容保留旧拼写，但不能用旧 ID、标签改写或显示名合并来改变 NBT 归属。实际规格以定义 size_class 对照 NBT 文件末尾规格；接口独立列出，不由旧引用推定。

## 状态分开判定

| 状态 | 判定 |
| --- | --- |
| 已绑定正确模板 | 制造商、系列、规格匹配，或已有明确的资产分配记录 |
| 正确 NBT 已有／引用错误 | 有同制造商、同系列、同规格文件，尚未正确接入；还需核对接口 |
| 模板缺失 | 正式规格在本系列目录无对应 NBT，其他系列同尺寸不能抵扣 |
| 未规划 | 正式产品线没有该规格，不生成补建任务 |
| 暂不开放／待验证 | 在所属系列与型号页明确状态；关闭兼容记录不自动列为制作任务 |
| 未使用 NBT | 全部 90 个定义均未引用；被错误引用的文件仍算有引用 |

## 特别核对

- 按 2026-11-09 明确指定的资产分配：Boreas 使用历史 Apollo SD 的 S／M／L 模板；Apollo 使用 Reactor HD 的 M／L／X 模板。保留 NBT 原文件名和既有定义 ID，这两组映射属于已确认绑定，不再列为模板缺失或引用错误。 Apollo 旧定义 ID 后缀 s／m／l 对应实际 M／L／X；Boreas 的 hd 定义 ID 对应实际 SD 模板接口。
- Courier S／M 自有 MC 模板存在，L 不存在；Cargo L 是独立 Cargo 系列资产。
- Silo 当前全部 L／X／XL 缺失本系列模板；待制作名称按稳定定义的 SD 约定标出，不沿用 TitanHaul 的 HD 接口作为已完成事实。
- Boreal X／XL 已有 boreal 命名的 SD 模板，虽然定义 ID 仍含 titanhaul_hd，实际 NBT 仍属于 Boreal；ID 的历史拼写不能反过来把文件判给 TitanHaul。

逐型号结论写在[正式目录](<../../../05内容数据/02货柜/README.md>)的制造商、系列、型号页。所有预留内容统一收录在[型号状态与制作安排](<../../../05内容数据/02货柜/型号状态与制作安排.md>)；未引用文件按真实系列独立维护在[未使用 NBT 系列表](<../../../05内容数据/02货柜/未使用NBT系列清单.md>)。

本轮未重命名或复制 NBT，HEC 的指定分配已接入，其余引用问题继续逐系列处理。
