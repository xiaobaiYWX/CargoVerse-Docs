# 模板系列归属与核对规则

21 个系列各有 S、M、L、X、XL 五份 G2 结构。

## G2新版制作口径

65 个正式型号各绑定同系列同规格模板，8 个基础型与普通型号共用。其余 40 份及装配限制见[预留清单](<../../../05内容数据/02货柜/99历史归档/未使用NBT系列清单.md>)。

## 命名是归属依据

`cargoverse:cargo/spl/cargo/spl_cargo_mc_l` 固定表示 SPL 制造商、Cargo 系列、MC 接口、L 规格。它不能计作 Courier 的 L 模板。同理 TitanHaul 不属于 Silo、Bastion 不属于 Sentinel、Recycle 不属于 Reliquary、Eden 不属于 Harvest。

当前文档仍按正式设计的系列名称列需求；定义资源 ID 可为存档兼容保留旧拼写，但不能用旧 ID、标签改写或显示名合并来改变 NBT 归属。实际规格以定义 size_class 对照 NBT 文件末尾规格；G2 模板统一使用标准货柜接口。

## 状态分开判定

| 状态 | 判定 |
| --- | --- |
| 已绑定正确模板 | 制造商、系列、规格匹配，或已有明确的资产分配记录 |
| 正确 NBT 已有／引用错误 | 有同制造商、同系列、同规格文件，尚未正确接入；还需核对接口 |
| 模板缺失 | 正式规格在本系列目录无对应 NBT，其他系列同尺寸不能抵扣 |
| 未规划 | 正式产品线没有该规格，不生成补建任务 |
| 暂不开放／待验证 | 在所属系列与型号页明确状态；关闭兼容记录不自动列为制作任务 |
| 未使用 NBT | 全部 90 个定义均未引用；被错误引用的文件仍算有引用 |

## 维护入口

逐型号结论写在[正式目录](<../../../05内容数据/02货柜/README.md>)的制造商、系列、型号页。历史型号及未使用资产见[历史归档](<../../../05内容数据/02货柜/99历史归档/README.md>)；未引用文件按真实系列独立维护在[未使用 NBT 系列表](<../../../05内容数据/02货柜/99历史归档/未使用NBT系列清单.md>)。
