# 自然贸易终端实现

玩家操作见[货物出售终端](../../03组件手册/货柜与装卸/13_货柜装载机.md)、[货物收购终端](../../03组件手册/货柜与装卸/14_货物卸载机.md)和[货运无人机](../../03组件手册/货柜与装卸/15_货运无人机.md)。本页说明实现职责与扩展边界。

## 组件职责

| 层次 | 主要入口 | 职责 |
| --- | --- | --- |
| 方块与碰撞 | `ContainerLoaderBlock`、`CargoUnloaderBlock`、对应 `Shapes` | 多方块装配、四向碰撞与控制器识别；整体模型由控制器渲染 |
| 终端状态 | 两个自然终端的 `BlockEntity` | 绑定、数量选择、区域检测、表面快照与短期飞行状态 |
| 表面布局 | `ContainerLoaderSurfaces`、`CargoUnloaderSurfaces` | 各自的仪表、按钮及滑轨锚点 |
| 共用几何 | `NaturalCargoTerminalGeometry` | 模型像素到方块及世界坐标的变换；不包含选货、报价或交易动作 |
| 表面显示 | `NaturalCargoSalesDisplay`、`NaturalCargoAcquisitionDisplay` | 只读取视图状态，显示实际货物和计划交易数据 |
| 目录 | 两套独立的 `Menu`、`Row`、`SnapshotPacket`、`Screen` | 共用图集，各自维护目录与选择语义 |
| 交易 | `CargoTransferOrderService`、`CargoTransferPreviewService`及各介质服务 | 私有确认、提交时重验、实际转移、结算、经验与失败恢复 |
| 搬运表现 | `CargoDroneVisuals`、`CargoDroneFlight`、`TradeCargoDroneRenderer` | 成交后生成冻结目标的视觉状态，客户端插值模型与纸箱 |

玩家贸易点使用独立的 `PlayerCargoUnloaderSurfaces`、`PlayerCargoUnloaderDisplay`及 `PlayerCargoTerminalWorldUi`。自然站更换表面模型或控件时，不修改玩家终端布局。通用货柜内容、计量、确认和事务可以共享；显示层不恢复按物品、流体、生物分别拼装旧自然终端快照的入口。

## 浏览与成交边界

出售目录选货需要服务端确认并更新终端表面；收购目录选货只保留在当前客户端屏幕。收购菜单无物品槽位、无选货提交包，也不接受菜单按钮包执行交易。打开目录不扫描装卸区、不要求货柜存在，目录检查仅在菜单打开期间进行，内容变化才发送快照。

收购菜单绑定打开时的玩家、终端对象和贸易点。服务端检查距离、结构、绑定和营业状态；快照包按菜单类型及菜单 ID 匹配，并限制行数。目录展示实际浏览者的签约报价；表面预计收入使用当前货柜所有者的条件，最终金额以确认提交时的玩家及授权重验为准。

表面区域检测与滑轨调节分开：周期刷新和实际确认会重新检测货柜，拖动滑轨只重算缓存货柜的计划量。实际载荷不按本站报价过滤；未报价货物仍显示，确认拉杆负责拒绝不可交易的载荷。每日收购额度统一通过 `TradePointAcquisitionLimit`换算原生余量，不在 GUI 维护第二份限额。

## 动画生命周期

真实事务提交成功并释放会话后才尝试发布视觉状态。视觉异常被隔离，不能撤销成交或要求玩家重试。动画进行期间的新成交正常执行，但不覆盖当前动画、不排队补播，也不重新取样目标位置。

服务端仅保留起始 Tick、冻结世界目标和搬运方向，通过方块实体更新同步；不将动画写入存档。客户端共用机体、纸箱和旋翼分件，派生两端的路线及收购双机错峰。运行边界覆盖整段双机流程，渲染包围盒同时包含终端和冻结目标。

动画不创建实体、掉落物、路径搜索或逐 Tick 坐标广播。移动结构缺少实际世界坐标时跳过视觉表现，不回退到存储空间坐标，不强制加载区块。时长与停靠表现见正式无人机手册。

## 资源维护与核验

终端本体与物品 `display`模型分别绑定各自导出的纹理；同名导出文件不能视为相同 UV。纸箱与无人机是动态分件，不重新烘焙进终端本体。收购和出售 GUI 只共用 `natural_cargo_sales.png`；其中预留按钮区域不自动注册行为。售罄标记在货物图标和选中效果之后，以更高 GUI 深度绘制。

定向单元测试覆盖四向表面与碰撞、原生计量、额度、快照边界及动画生命周期；运输 GameTest 覆盖实际成交、视觉防重入和只读目录不改表面。客户端接缝、命中手感、移动载具表现及多人实运仍按[待完成事项清单](../../90设计草案/待完成事项清单.md#终端仪表与交互调整)验收。
