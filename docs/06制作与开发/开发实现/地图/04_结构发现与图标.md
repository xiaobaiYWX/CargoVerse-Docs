# 结构发现与图标

## 发现条件

自然结构不会因为区块进入客户端视距而自动显示。服务端每 20 Tick 检查一次玩家位置，检测节奏与原版 `CriteriaTriggers.LOCATION` 一致，并调用：

```java
StructureManager.getStructureWithPieceAt(playerPosition, structure)
```

只有玩家所在方块进入真实结构部件包围盒后才会发现该结构。这与原版“进入下界要塞”等位置进度使用的结构判定链一致，也能自动支持注册为标准 Minecraft 结构的其他模组内容。

发现记录以玩家为单位发送。网络包只包含新发现标记，不包含地形图片或完整结构列表。客户端按维度保存实例 ID、结构 ID、标记位置、范围和发现信息。

贸易点结构会从这条自然结构发现通道排除，防止贸易点网络与通用结构标记产生重复图标。

## 贸易点到访信息

贸易点沿用相同的“进入真实结构部件”判定，但发送独立的个人贸易点标记。同步内容包括贸易点实例 ID、显示名称、繁荣等级、位置、结构范围，以及该实例资源表中已经固定的具体货物：

- 收购货物取自 `resourceCatalog.acquisitionGoods`；
- 出售货物取自 `resourceCatalog.saleGoods`；
- 无库存交易规则同样属于货物目录，不会因为 `create_inventory: false` 而从地图隐藏；
- 地图不重新匹配标签，也不读取数据包当前版本来猜测商品，因此显示口径与实际贸易点实例一致。

只有到访过的贸易点才会进入玩家的本地标记缓存。再次进入贸易点时会更新繁荣等级和货物目录。

## 图标与结构名称

客户端按结构注册 ID 选择图标。已配置专属图标的原版结构使用内置图标和本地化名称，同类变体共用图标，例如不同村庄和废弃传送门。未匹配的结构统一使用 `markers/unknown_structure.png`，名称从结构 ID 路径生成，例如 `forgotten_airship` 显示为 `Forgotten Airship`。原版下界化石和埋藏的宝藏继续不生成普通结构标记。

自然贸易点使用繁荣度图标，绑定航标发布的玩家贸易点使用所有者头像。

客户端普通结构标记文件使用版本 8，首次进入世界时按到访记录生成。服务端共享标记使用 NBT 版本 5，仅接受现行格式。客户端和服务端须使用相同的联机协议。

## GUI 行为

结构图标与地图地形使用同一套世界坐标变换。地图缩放低于 `0.4` 时标记按比例缩小，较高缩放时保持标记大小；鼠标命中区域使用实际绘制后的图标矩形。

悬停地图标记仅显示首次发现玩家、到访时间和归属模组等通用基本信息，不显示贸易商品。点击贸易点或普通结构图标后，详情卡固定在地图视口右下角，不重复绘制三条通用信息：

- 普通贸易点：放大的名称、归属制造商、收购与出售货物图标；
- 玩家贸易点：放大的名称、第二行“玩家经营贸易点”、收购与出售货物图标；
- 普通结构：仅放大的名称和第二行 XYZ 坐标，不显示制造商或贸易货物。

详情卡使用固定 `0.5` 显示比例，不随地图缩放，距离右侧和下侧视口边界各留 10px，避免纸张边框遮挡。名称与普通结构坐标按可用宽度适配字号。

详情卡上方统一提供三个按钮，使用原版按钮资源，带悬停高亮、提示与点击音效：

| 位置 | 功能 |
| --- | --- |
| 左上方指南针 | 将当前贸易点或结构设为当前宿主的目的地（手册个人目标或当前引导台） |
| 关闭按钮左侧的居中按钮 | 将地图中心移至所选标记，保持缩放，不修改导航目标 |
| 右上方“×” | 仅关闭信息卡，不取消导航目标 |

点击空白地图、再次点击同一标记或拖动地图都不会关闭详情卡；点击其他结构或贸易点替换所选详情。选中点移出视口时仍保持卡片，直到点击关闭按钮或已知资料失效。解绑、破坏航标或撤下地图显示时，客户端保留已知资料和目的地。卡片内部和按钮点击都不会拖动地图。普通结构和贸易点按类型及实例 ID 区分，重名或同 ID 不会互相串选。

制造商显示名称由服务端贸易点定义及制造商定义解析后下发。客户端贸易点缓存使用版本 6，每条记录直接保存制造商名称和显示状态。没有制造商归属的普通贸易点显示“无”。

地图界面不再绘制中心坐标与缩放系数，缩放和拖动交互保持可用。通用悬停卡片同样留出 10px 边距。

双击同一标记也可设置当前宿主的导航目标：两次点击须在 250ms 内，鼠标位移不超过 4 GUI 像素，类型和实例 ID 必须相同。单击仍只打开详情卡；拖动、缩放、空白点击或按钮点击会取消待配对状态。连续三击不会重复触发两次导航。

当前目的地的可见图标左侧绘制 `textures/gui/trade_map/marker_widgets.png` 中的导航徽记（38×38 源像素），跟随图标缩放；隐藏记录不因此重新显示。玩家标记使用同一图集中的玩家切片（26×52），以图标中心按玩家自身世界朝向旋转，北/东/南/西分别为 0°/90°/180°/-90°，地图不额外读取载具姿态。

最近成交站点的“在地图上显示”按钮会展开地图并聚焦同维度的贸易点。有已知资料时打开信息卡，其余情况按成交坐标居中。点击保留当前导航目的地。个人目标的显示、保存范围与后续导航接入边界见[航运手册与玩家档案](<../../../02系统规则/玩家档案/README.md>)及[导航接口](<05_导航架构与接口.md>)。
