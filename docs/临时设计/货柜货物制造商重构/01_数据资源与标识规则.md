## 1. 数据目录

三类定义分别使用独立数据包目录：

```text
data/<namespace>/cargo_goods/<class>/<good>.json
data/<namespace>/cargo_containers/<path>.json
data/<namespace>/manufacturers/<path>.json
```

定义 ID 由命名空间和相对文件路径推导，JSON 内不再重复填写 `id`。

```text
data/cargoverse/cargo_goods/raw_resource/ore.json
    → cargoverse:raw_resource/ore

data/cargoverse/cargo_containers/aui/atlas_sd_m.json
    → cargoverse:aui/atlas_sd_m

data/cargoverse/manufacturers/aui.json
    → cargoverse:aui
```

生产系统定义目录为 `data/<namespace>/trade_points/type/production_line_pools/<resource|factory|market>/<分类>/<池名>.json`，池 ID 从 `production_line_pools/` 后的相对路径推导，例如 `cargoverse:resource/agriculture/default`。池内 `lines[].id` 是局部标识。

贸易点定义已迁到 `data/<namespace>/trade_points/trade_points_definitions/trade_points_type/<resource|factory|market>/<分类>/<名称>.json`；从 `trade_points_type/` 后取 ID，例如 `cargoverse:resource/general/default`。两个目录独立扫描并与货物数据原子发布。详见 [生产线池定义](17_生产线池定义.md) 与 [贸易点运行时重构](18_贸易点定义与运行时重构.md)。

## 2. 数据格式版本

每个新定义文件都使用顶层整数字段：

```json
{
  "schema_version": 1
}
```

规则：

- 初始版本为 `1`。
- 缺少版本、版本不是整数或版本尚未支持时，该文件加载失败。
- 只有产生不兼容数据结构时才增加版本号。
- 存档数据版本与数据包定义版本分开管理。

## 3. 货物 ID 集合

一级分类是硬编码的 CargoClass，二级货物是可扩展的 CargoGood。

- 不再要求固定 20 个货物，也不限制为 cargoverse 命名空间。
- 允许相同完整资源 ID 覆盖内置定义；不同命名空间的同名货物互相独立。
- 首个路径段按现有硬编码 CargoClass 解析；未知分类的数据包定义正常加载，分类及图标统一回退 `none`，不注册新分类。货物完整 ID 保留，不合并不同货物；运行时沿用相同兜底规则。
- ID 必须严格符合两段 `namespace:class/good`，不得额外嵌套目录，最长 256 字符；有效货物总数上限 16384。
- 删除货物时必须同步清除容器、制造商、贸易点和商店中的引用，否则拒绝新数据集合。
- 空货柜不创建虚拟的货物定义，运行时省略 Load。

## 4. 引用关系

货柜容器定义使用完整资源 ID 引用制造商和货物：

```json
{
  "manufacturer": "cargoverse:aui",
  "allowed_cargo": [
    "cargoverse:raw_resource/ore",
    "cargoverse:raw_resource/wood"
  ]
}
```

跨定义引用在所有文件初步解析完成后统一校验：

1. 加载并校验货物定义。
2. 加载并校验制造商定义。
3. 加载货柜容器定义。
4. 加载有效货币组 ID。
5. 校验货物引用的交易货币组，以及货柜引用的制造商、货物和交易货币组是否存在。
6. 将制造商特性与货柜基础数据解析为可供运行时使用的最终型号参数。

## 5. 显示文本

货柜容器定义中的 `display_name` 和 `description` 是直接写入 JSON 的普通字符串：

```json
{
  "display_name": "AUI Atlas 标准货柜 M 型",
  "description": "Atlas 系列主力型号，在容量、重量和通用性之间取得平衡。"
}
```

货柜容器与货物名称均使用直接字符串，不通过翻译键链接语言文件。制造商的显示文本格式保持不变。

## 6. 重载原则

- 重载先在临时集合中解析所有数据。
- 只有整套数据和跨引用校验成功后，才原子替换当前有效定义集合。
- 任一悬空货物/制造商/货币组引用或词条解析失败时，本次新数据集合不生效。
- 数据重载不直接改写已有货柜实例的已解析快照。
