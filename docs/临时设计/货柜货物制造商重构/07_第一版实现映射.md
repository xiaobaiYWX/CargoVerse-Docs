## 3. 数据位置

```text
src/main/resources/data/cargoverse/
├─ cargo_materials/       20 个固定货物
├─ manufacturers/         8 家内置制造商
└─ cargo_containers/
   └─ aui/atlas_sd_m.json 首个端到端样本
```

第一版货物数值使用旧 S 级数据除以 10 个货物单位得到迁移候选值：

```text
unit_mass = 旧 base_mass ÷ 10
base_value = 旧 base_buy_price ÷ 10
单位经验 = 旧整柜经验 ÷ 10
```

这些值用于让数据框架形成完整闭环，不代表经济平衡已经定案。

## 4. 读取入口

其他系统后续统一从不可变数据集读取，不直接持有监听器内部映射：

```java
CargoDataSet data = CargoDataReloadListener.INSTANCE.get();

CargoMaterialDefinition ore = data.material(
    ResourceLocation.parse("cargoverse:ore")
).orElseThrow();

CargoDataSet.ResolvedContainerStats stats = data.resolveContainer(
    ResourceLocation.parse("cargoverse:aui/atlas_sd_m"),
    ResourceLocation.parse("cargoverse:ore")
).orElseThrow();
```

调用方需要保存定义快照时，应从返回的定义构造独立快照，不要只长期保存对象引用。数据包重载后，监听器会整体替换当前 `CargoDataSet`。

## 5. 原子重载顺序

```text
读取 cargo_materials
读取 manufacturers
读取 cargo_containers
        ↓
分别解析字段
        ↓
统一校验固定集合、跨文件引用和组合结果
        ↓
校验 Component 与结构模板
        ↓
一次性发布新的 CargoDataSet
```

准备或校验阶段抛出错误时，不会发布部分数据集。

## 6. 第一版内置制造商差异

本版只落实讨论中已经明确的基础方向：

| 制造商 | 第一版数据差异 |
| --- | --- |
| AUI | 通用容量 `×1.10` |
| DMC | 空质量 `×1.30`、耐久 `×1.50`、价值 `×1.10`、矿物容量额外 `×1.30` |
| VBS | 农产品和活体货物容量额外 `×1.25` |
| HRI | 容量 `×0.80`、空质量 `×1.10`、耐久 `×1.30`、价值 `×1.20` |
| SPL / HEC / BDS / REX | 暂时使用中性参数 |

温控能耗、特殊货物兼容和其他尚无明确数据字段的特性没有用近似字段代替。
