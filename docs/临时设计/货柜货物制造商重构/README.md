## 尚未归档结案的条件

当前采用分阶段整编，不再等待所有后续玩法完成才更新正式入口。但临时重构整体结案仍需：

1. 实体质量、词条调度和贴花在装卸后与 Load 一致。
2. 明确重载补装的快照规则、同名词条参数规则。
3. 完成制造→装载→运输→部分／全部卸货→存档重进的实机回归。
4. 验证多人／多终端库存竞争与异常恢复。

旧迁移器、固定 20 类限制、旧接口参数、旧价格常量、旧贸易点销售池及过期版本表不得再作为实现要求。后续维修／声望等保留为预留，不与已实现契约混写。
