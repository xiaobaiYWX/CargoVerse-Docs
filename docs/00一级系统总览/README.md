# 一级系统总览

CargoVerse 的业务内容统一归入五个一级系统。旧章节仍按具体主题保存，便于查找已有定义；本页负责说明业务所有权，避免终端、持久化数据和客户端界面继续按技术类型混放。

| 一级系统 | 职责 | 文档入口 |
| --- | --- | --- |
| 主要贸易点系统 | 普通终端、自然贸易点、资源表、库存经济、结构绑定和相关功能方块 | [贸易点系统](../02贸易点系统/README.md)、[普通功能方块](../03功能方块/README.md) |
| 玩家贸易点系统 | 私人贸易点的核心、管理与公共终端，聚合仓库、权限、装卸区和地图广播 | [玩家贸易点](../11玩家贸易点/README.md) |
| 货柜系统 | 货柜定义、模板搭建、物理实例、运输数据、轨道、对接和贴花 | [货柜系统](../01货柜系统/README.md) |
| 玩家档案系统 | 航运手册、贸易地图、许可证、制造商发现、声望、生涯统计和玩家持久化数据 | [航运手册与玩家档案](../12航运手册与玩家档案/README.md) |
| 载具仪表 | 载具端信息显示、导航硬件与航行仪表 | [载具仪表](../13载具仪表/README.md) |

## 共享基础设施

注册表、网络协议、世界表面 UI、配置、命令和维护任务是共享技术层，不作为独立内容系统。共享层只提供能力，业务规则仍由上表中的所属系统决定。例如：

- 世界表面按钮动画属于共享 UI，仓库按钮的权限与结果属于玩家贸易点系统；
- 终端连接工具同时连接普通和玩家贸易点，但两类贸易点分别执行自己的距离、锁定和所有权校验；
- 贸易地图读取贸易点信息，玩家探索数据由玩家档案系统维护，手册与仪表共用画布；个人目标和仪表目标分开保存，载具控制仅由仪表服务端处理；
- 玩家档案可展示货柜和贸易统计，但不拥有货柜实例或贸易点仓库。

## 兼容边界

- 整理目录不得修改已经发布的方块、物品、菜单或数据组件注册 ID；
- 不修改已有 NBT 字段、SavedData 名称和数据包路径；
- 新内容先确定一级系统归属，再增加服务端数据、网络快照和客户端表现；
- 跨系统写操作通过所属系统的服务完成，避免界面直接修改其他系统的持久化数据。
