# 货物与贸易工程边界

更新：2026-10-23。本页只描述当前数据、交易、权限和同步职责；未实现工作单独列出。

## 1. 首版边界

实际物品和液体（包含标准 Fluid 气体）闭环已接入共用资产封套、带类型身份、原生数量／操作份数、时钟及确认后端分发；实体存取及交易仍待专项实现，不建立空适配层。液体以整数 mB 保存、每 1000mB 常规装卸，完整规则见[液体运输](../01货柜系统/01核心系统/13_液体运输.md)。1 个物品组＝1 个货柜容量单位，组大小取精确物品的最大堆叠量并冻结；原生 pcs 数量与操作组数分开，质量按组定义并对整份载荷向上取至 0.1Kpg。

一柜只存一种物品及一种完整组件状态；名称、耐久、附魔等不同变体不能混装。首版拒绝已知非空嵌套容器及无法无损编码的内容。缺失物品或损坏载荷隔离并保留原文，不降级为空柜。

## 2. 数据职责

| 数据 | 现行职责 |
| --- | --- |
| CargoKind / CargoKey / CargoMeasure | 类型化选择键、原生计量与操作步长；物品 1pcs、液体 1000mB 一步 |
| CargoContent / CargoTransportRules | 真实载荷与冻结规则的通用读取／原生减量边界，已注册物品及液体流体实现 |
| ItemCargoIdentity / ItemCargoPayload | 原生物品 ID、完整组件、整数数量 |
| ItemTransportProfile / ItemTransportSnapshot | 分类、单位质量、固定扣量要求；装载时冻结 |
| CargoContainerSnapshot | 设备、分类许可、容量、空柜质量 |
| CargoLoad / CargoContent.session | 通用载荷封套、冻结数值会话、取得成本与原生扣量 |
| CargoTransferOrderService / CargoTransferBackends | 共用确认与货柜占用生命周期，按类型进入真实后端；已接入物品与液体后端 |
| ResourceTableDefinition / TradePointResourceCatalog | schema 3 站点报价、库存策略、每日额度与交付经验 |
| PlayerTradeVaultInventory | Create 保险库适配、精确变体报价及短周期观察缓存，不拥有实物库存 |
| PlayerTradeStorageSavedData / PlayerTradeFluidInventory | 多收发器独占绑定、普通储罐观察及报价配置，不拥有流体库存；TankFluidTransfer 执行原生槽位事务 |
| PlayerTradeLogisticsNetwork | 管理核心激活的实体隧道路径、端点归属与有界占用，不保存途中货物 |

不保留抽象货物目录、全局物品基础价、全局经验或另一套仓库账本。运输可用性不代表自然贸易点必须收售该物品。

## 3. 仓储与交易

实际物品只存于 Create 保险库，通过附着式仓库收发器绑定核心，每核心最多 3 组保险库。容量由真实槽位、堆叠规则及 Create 配置决定，不再有固定 5000 仓容。另可独立连接最多 5 组普通流体储罐，液体页及表面显示原生数量／容量（mB），已支持报价、公共装卸与免费管理装卸。拆分跟随附着点，同核心合并去重，跨核心合并时冲突结构不可用，未加载连接仍占名额。

仓库管理终端 SET 编辑核心保存的精确变体单价与独立上架开关，核心不再提供入口；未配置价格 0、买卖关闭。保留数量和收购目标已删除，出售按实际库存、收购按原生可插入空间限制，不预留仓位或限制外部自动化。两页只显示当前库存，需先存入样本才能上架，删除只清除选中物品当前模式的单价和开关，不自动保存草稿。公共装卸始终正常付费，包括所有者和授权管理员。

可选仓库管理终端提供独立免费管理装卸与仅所有者可用的 SET，不保存实物，不依赖公共装卸机、报价或结算器，但仍需要激活网络的有效路径。管理核心沿物流隧道发现设备，默认最短路径 32 格，不再由连接器远程绑定；断线清理下游派生归属而不删除原生内容。详见[物流隧道与激活网络](../11玩家贸易点/06_物流隧道与激活网络.md)。自动化直接访问保险库；本模组权限不替代领地保护。

交易重新校验实际库存、货柜、范围、绑定和资金，失败回滚本次变更，不用整仓旧快照覆盖 Create 当前内容。不为读取仓库强制加载区块。

## 4. 自然站点报价与经验

价格设置在具体交易处，不属于物品运输参数。schema 3 使用精确 item/components 或 type=liquid 的 fluid/components、本地 unit_price、可选出售 stock、收购 daily_limit，以及收购侧许可证/繁荣度经验，未配置经验为 0。物品按最大堆叠组、液体按每 1000mB 配置报价／库存／限额／经验；尾量正常成交，金额按比例向上取整数、经验每笔向下取整。载荷仍保存原生 pcs／mB。

仅按收购目的地判定经验：自然→自然、玩家→自然均按实际成交件数发放目的地收购条目配置的两类经验；自然→玩家、玩家→玩家不奖励。自然生成身份由服务端核验目的地结构实例，不根据客户端、ID 前缀或所有权推断。手动普通点作为目的地仍不奖励。

不再记录来源批次或维护 FIFO 来源。自产、管理员补入及玩家保险库中转货物到自然目的地成交时均按报价奖励；仓库装卸本身不奖励。只计算实际成交件数，成功付款、货物和两类经验在同一补偿事务内提交，失败或重复请求不得重复奖励。

40 张自然站货物表仍为空；A／B 两张指令测试表已填充互补的 149 种实际物品。结构、制造、注册和普通物品商店保留。配置和示例见[实际物品报价与运输经验](<../02贸易点系统/03_资源表定义.md>)。

## 5. 权限、建点与 Sable

- 所有者独占核心交互、商品配置、授权名单、物流网络激活和他人设备的接入确认；连接工具不再远程绑定／解绑。
- 授权管理员可用管理类终端，公共终端对所有玩家开放。
- 核心放置后无主，点击 AUTH 打开核心 GUI，长按绿色页签 3 秒注册；按所有者 UUID 跨维度计数，默认最多 3 个玩家贸易点，可配置；未加载、暂停营业仍计数。配置默认值变更不覆盖已有服务器配置。
- 所有者长按红色页签 3 秒注销或拆除核心均释放名额；注销清除绑定、授权、报价并返还结算器，但保留方块和保险库物品。不设创建费用或冷却；防频繁拆装以后另做。
- 核心授权只查询本存档 `playerdata/*.dat` 已有玩家，按名称或 UUID 匹配；本地 UUID 缓存仅提供这些记录对应的名称，不联网查询或生成离线 UUID。新玩家尚无保存记录、或本地缺少对应名称时直接拒绝添加，不引入兜底。
- 玩家贸易点设施可放置在 Sable 上，但不能绑定或使用，服务端校验并提示；不删除方块或仓库物品。
- 限制设施不限制货柜本身，静态贸易点仍可装卸 Sable 运来的货柜。

## 7. 界面与统计收尾

HUD 显示实际数量、剩余保护时间和质量，不恢复完整度或吨数。玩家信息柜无全局基准价，不显示伪涨跌，模型基座保留；普通站点信息柜仍以当地报价为基准。

航运风格货值轴改用出发时实际货物取得成本 / 件数，保留小数并存档，不读取固定 0 或旧基础价；不计空柜成本。风格统计不等于运输经验资格，算法见[航运风格](<../12航运手册与玩家档案/08_航运风格统计与雷达图.md>)。

## 8. 运输参数约定

### 8.1 分类与质量

三种源码形态为 solid／liquid／living，当前实际物品均为 solid。2315 份逐物品 JSON 直接声明质量、准入、贴花和条件；缺失时源码默认 solid／0.1 Kpg／standard／无条件／none 贴花。内置质量保持一位小数，零质量仍占容量并执行损耗和结算。

同一物品在不同形态目录重复声明时拒绝新一代；不用文件顺序、注册名或配方猜分类。追加要求完整身份和冻结规则一致，reload 不改途中货物。物品悬停隐藏分类及默认来源，仅保留必要的装载限制和运输需求，后台形态数据仍用于既有业务。

### 8.2 固定数量损耗

数值模型按原因扣固定整数原生数量，不是百分比；不足时扣到零，不生成损坏货物。旧按 ID 行为引擎不再运行；注册配置及已注册条件／能力求值已接通，内置数据迁入与实机验收仍未完成，详细查看已由 PDA 覆盖，不继续深化设备操作，见[实际完成度](../01货柜系统/01核心系统/14_运输数值运行时.md)。撞击按相隔 10 tick（0.5 秒）的两次速度向量差判断，缓冲增加耐受；急加速、急刹、急转与碰撞同等处理，一事件只扣一次，不作自由落体特判。倾角暴露独立结算。环境采样只结算实际条件，不模拟未加载时的未知环境。

损耗后立即按剩余数量计算质量；交易按实际转移件数计价，不再叠加完整度折价。具体参数见[当前运输规则](<../14运输分类统计/03_交付形态与运输条件.md>)。

### 8.3 数值年龄与生命周期

温度和有效连续观测推进运输年龄／暴露，旧绝对时限已退出；停机和不可用环境不补算，不逐 tick 或逐间隔回放。

追加前结算有效观测，但不刷新温度、压力、年龄或暴露余数；部分卸货同样保留状态。原生入库结束这部分数量的运输寿命，卸空再装按当前规则初始化，不向物品／流体组件写永久运输年龄。
